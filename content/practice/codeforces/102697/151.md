## Hiểu vấn đề 

Mặc dù tên như vậy nhưng bài toán này không yêu cầu xây dựng hoặc phân tích một hình tam giác. Nhiệm vụ chỉ đơn giản là đánh giá một hàm lượng giác cho một đối số dấu phẩy động được cung cấp. Dòng đầu vào đầu tiên xác định chức năng, sử dụng một trong các`sin`,`cos`,`tan`,`cosec`,`sec`, hoặc`cotan`và dòng thứ hai đưa ra giá trị mà hàm đó sẽ được đánh giá. Đầu ra được yêu cầu là giá trị dấu phẩy động thu được. Câu lệnh được lưu trữ xác nhận rằng đầu vào bao gồm chính xác một từ khóa thao tác theo sau là một giá trị dấu phẩy động và đầu ra là một kết quả dấu phẩy động. 

Sáu thao tác tương ứng với các định nghĩa thông thường 

[ 
\sin(x)=\sin(x), 
] 

[ 
\cos(x)=\cos(x), 
] 

[ 
\tan(x)=\frac{\sin(x)}{\cos(x)}, 
] 

[ 
\cosec(x)=\frac{1}{\sin(x)}, 
] 

[ 
\sec(x)=\frac{1}{\cos(x)}, 
] 

và 

[ 
\cotan(x)=\frac{\cos(x)}{\sin(x)}. 
] 

Đối số được diễn giải bằng radian, bởi vì Python`math.sin`,`math.cos`, Và`math.tan`các hàm sử dụng radian. Đầu vào mẫu`sin`theo sau là`2`sản xuất khoảng`0.9092974268256817`, chính xác là giá trị của (\sin(2)) tính bằng radian. 

Không có ràng buộc đầu vào lớn có ý nghĩa ở đây. Chỉ một thao tác được đánh giá, do đó, ngay cả một đầu vào có số chữ số rất lớn cũng sẽ không tạo ra vấn đề tổ hợp, giả sử giá trị có thể được biểu thị bằng trình phân tích cú pháp dấu phẩy động. Do đó, giới hạn thời gian một giây là quá đủ cho một số phép tính số học không đổi. Không có lý do gì để xem xét các thuật toán như lặp trên phạm vi, lập trình động hoặc tìm kiếm số.

## Giải pháp Python```python
import sys
import math

input = sys.stdin.readline

def solve():
    operation = input().strip()
    x = float(input())

    if operation == "sin":
        result = math.sin(x)
    elif operation == "cos":
        result = math.cos(x)
    elif operation == "tan":
        result = math.tan(x)
    elif operation == "cosec":
        result = 1.0 / math.sin(x)
    elif operation == "sec":
        result = 1.0 / math.cos(x)
    else:  # cotan
        result = math.cos(x) / math.sin(x)

    print(result)

if __name__ == "__main__":
    solve()
```Dòng đầu tiên được đọc dưới dạng chuỗi vì nó là tên thao tác chứ không phải là giá trị số. Đang gọi`.strip()`xóa dòng mới đó`readline()`lá ở cuối. 

Dòng thứ hai được chuyển đổi với`float`, điều này là cần thiết vì đầu vào có thể chứa các giá trị thập phân. Các hàm lượng giác trong`math`hoạt động theo radian, phù hợp với cách giải thích toán học được sử dụng bởi bài toán. 

Các hoạt động tương hỗ có chủ ý sử dụng các định nghĩa thay vì cố gắng tìm các hàm thư viện thay thế.`cosec`là`1 / sin(x)`,`sec`là`1 / cos(x)`, Và`cotan`là`cos(x) / sin(x)`. Trình tự thực hiện có ý nghĩa quan trọng đối với`cotan`, vì việc đảo ngược tử số và mẫu số sẽ tính ra tiếp tuyến. 

Không cần số học số nguyên, số học mô-đun, mảng, vòng lặp hoặc phép lặp số đặc biệt. Số nguyên Python cũng không bao giờ bị tràn, nhưng điều đó không liên quan ở đây vì tất cả các phép tính được thực hiện dưới dạng giá trị dấu phẩy động. 

trận chung kết`else`tay cầm`cotan`, vì câu lệnh giới hạn từ khóa ở sáu tên được chỉ định. Nếu có thể có từ khóa không hợp lệ thì nhánh cuối cùng rõ ràng sẽ thích hợp hơn, nhưng định dạng đầu vào đảm bảo hoạt động là một trong sáu nhánh đó.

import sys
import io
import math

def solve():
    operation = input().strip()
    x = float(input())

    if operation == "sin":
        result = math.sin(x)
    elif operation == "cos":
        result = math.cos(x)
    elif operation == "tan":
        result = math.tan(x)
    elif operation == "cosec":
        result = 1.0 / math.sin(x)
    elif operation == "sec":
        result = 1.0 / math.cos(x)
    else:
        result = math.cos(x) / math.sin(x)

    print(result)

def run(inp: str) -> str:
    global input
    old_stdin = sys.stdin
    old_input = input

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    try:
        output = io.StringIO()
        old_stdout = sys.stdout
        sys.stdout = output
        try:
            solve()
        finally:
            sys.stdout = old_stdout
        return output.getvalue()
    finally:
        sys.stdin = old_stdin
        input = old_input

# Provided sample
assert run("sin\n2\n") == "0.9092974268256817\n", "sample 1"

# All-zero-safe direct functions
assert run("sin\n0\n") == "0.0\n", "sin at zero"
assert run("cos\n0\n") == "1.0\n", "cos at zero"

# Boundary between positive and negative sine values
assert run("sin\n3.141592653589793\n") == "1.2246467991473532e-16\n", "sin(pi)"

# Reciprocal functions
assert run("cosec\n1.5707963267948966\n") == "1.0\n", "cosec(pi/2)"
assert run("sec\n0\n") == "1.0\n", "sec(0)"

# Cotangent at pi/4
assert run("cotan\n0.7853981633974483\n") == "1.0000000000000002\n", "cotan(pi/4)"

# Tangent at pi/4
assert run("tan\n0.7853981633974483\n") == "0.9999999999999999\n", "tan(pi/4)"
