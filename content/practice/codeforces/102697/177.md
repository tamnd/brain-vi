## Hiểu vấn đề 

Bàn cờ Ken Ken là một hình vuông Latin (n \times n). Mỗi ô nhận một giá trị từ (1) đến (n), mỗi hàng chứa mỗi giá trị chính xác một lần và mọi cột đều làm như vậy. Cấu trúc bổ sung là một tập hợp các lồng được kết nối. Một lồng sẽ cố định một ô thành một giá trị nhất định hoặc yêu cầu các giá trị trong các ô của nó đạt được mục tiêu bằng cách sử dụng phép cộng hoặc phép nhân. Các lồng trừ và chia luôn chứa đúng hai ô. Để trừ, chênh lệch tuyệt đối phải bằng mục tiêu. Để chia, giá trị lớn hơn chia cho giá trị nhỏ hơn phải bằng mục tiêu. Bản thân các lồng không yêu cầu các giá trị riêng biệt. 

Đầu vào mô tả ranh giới lồng dưới dạng bản vẽ ASCII. Kích thước bảng nằm trong khoảng từ 4 đến 7, vì vậy có nhiều nhất 49 ô. Giới hạn chính thức là 15 giây và 256 MB, mang lại cho chúng tôi nhiều không gian hơn đáng kể so với một bài toán cạnh tranh hai giây thông thường, nhưng việc tìm kiếm mù quáng trên tất cả các bài tập ô vẫn là vô vọng. 

Hậu quả quan trọng của (n \le 7) là mỗi ô riêng lẻ có nhiều nhất bảy giá trị có thể. Điều đó làm cho mặt nạ bit trở thành một đại diện tự nhiên cho các hạn chế về hàng và cột, trong khi miền nhỏ cũng giúp việc kiểm tra tính khả thi của lồng chính xác trở nên rẻ tiền. Chúng ta nên sử dụng số học lồng để cắt các nhánh trước khi tìm kiếm sâu thay vì tạo các ô vuông Latin tùy ý trước. 

Trường hợp cạnh phân tích cú pháp đầu tiên là một lồng có thể trải rộng trên nhiều ô, do đó đầu mối không nhất thiết phải có trong mọi ô. Ví dụ: mẫu đầu tiên chứa một cái lồng có hàng đầu tiên trông giống như`|40x        |2-     |`, nghĩa là`40x`lồng chiếm một số tế bào. Một trình phân tích cú pháp giả định mỗi ô đều có đầu mối riêng sẽ tạo ra các lồng hoàn toàn khác nhau và tạo ra bảng sai. Đầu ra chính xác cho mẫu đó là`25431`,`12345`,`34512`,`41253`,`53124`. 

Trường hợp cạnh thứ hai là phép trừ và phép chia không có thứ tự. Một cái lồng được đánh dấu`2-`chấp nhận các giá trị như 3 và 1 theo một trong hai thứ tự, trong khi`2/`chấp nhận 4 và 2 theo cả hai thứ tự. ## Giải pháp Python```python
import sys
import re
from functools import lru_cache

input = sys.stdin.readline
sys.setrecursionlimit(100000)

def solve(data: str) -> str:
    lines = data.splitlines()
    n = int(lines[0])

    board_lines = lines[1:2 * n + 2]
    width = 4 * n + 1
    board_lines = [line.ljust(width) for line in board_lines]

    # Find cages by flood filling through open walls.
    cage_id = [[-1] * n for _ in range(n)]
    cages = []

    for sr in range(n):
        for sc in range(n):
            if cage_id[sr][sc] != -1:
                continue

            cid = len(cages)
            cells = []
            stack = [(sr, sc)]
            cage_id[sr][sc] = cid

            while stack:
                r, c = stack.pop()
                cells.append((r, c))

                # Move right if there is no vertical wall.
                if c + 1 < n:
                    if board_lines[2 * r + 1][4 * c + 4] == ' ':
                        if cage_id[r][c + 1] == -1:
                            cage_id[r][c + 1] = cid
                            stack.append((r, c + 1))

                # Move down if there is no horizontal wall.
                if r + 1 < n:
                    segment = board_lines[2 * r + 2][4 * c + 1:4 * c + 5]
                    if all(ch == ' ' for ch in segment):
                        if cage_id[r + 1][c] == -1:
                            cage_id[r + 1][c] = cid
                            stack.append((r + 1, c))

            cages.append(cells)

    # Parse the clue belonging to each cage.
    cage_target = []
    cage_op = []

    for cells in cages:
        clue = None
        for r, c in sorted(cells):
            text = board_lines[2 * r + 1][4 * c + 1:4 * c + 5].strip()
            if text:
                clue = text
                break

        m = re.fullmatch(r'(\d+)([+\-/x])?', clue)
        target = int(m.group(1))
        op = m.group(2)

        cage_target.append(target)
        cage_op.append(op)

    board = [[0] * n for _ in range(n)]
    row_mask = [0] * n
    col_mask = [0] * n

    # Place all fixed single-cell cages.
    for cid, cells in enumerate(cages):
        if len(cells) == 1:
            r, c = cells[0]
            value = cage_target[cid]
            bit = 1 << (value - 1)

            if (row_mask[r] & bit) or (col_mask[c] & bit):
                return ""

            board[r][c] = value
            row_mask[r] |= bit
            col_mask[c] |= bit

    @lru_cache(maxsize=None)
    def product_can(cid, count, value):
        """
        Can 'value' be represented as a product of exactly 'count'
        integers from 1 through n?
        """
        if count == 0:
            return value == 1

        if value < 1:
            return False

        for x in range(1, n + 1):
            if value % x == 0:
                if product_can(cid, count - 1, value // x):
                    return True

        return False

    def cage_possible(cid, extra_r=-1, extra_c=-1, extra_value=0):
        """
        Check whether a cage can still reach its target.

        The optional extra assignment is used while evaluating a candidate
        without modifying the board.
        """
        cells = cages[cid]
        target = cage_target[cid]
        op = cage_op[cid]

        values = []
        for r, c in cells:
            if r == extra_r and c == extra_c:
                values.append(extra_value)
            else:
                values.append(board[r][c])

        if op is None:
            return values[0] == target if values[0] else target >= 1

        if op == '+':
            current = 0
            remaining = 0

            for v in values:
                if v:
                    current += v
                else:
                    remaining += 1

            return (
                current + remaining <= target
                and target <= current + remaining * n
            )

        if op == 'x':
            current = 1
            remaining = 0

            for v in values:
                if v:
                    current *= v
                else:
                    remaining += 1

            if current > target or target % current != 0:
                return False

            needed = target // current
            return product_can(cid, remaining, needed)

        # Subtraction and division cages contain exactly two cells.
        a, b = values

        if a == 0 and b == 0:
            for x in range(1, n + 1):
                for y in range(1, n + 1):
                    if op == '-' and abs(x - y) == target:
                        return True
                    if op == '/' and max(x, y) % min(x, y) == 0:
                        if max(x, y) // min(x, y) == target:
                            return True
            return False

        if a == 0:
            for x in range(1, n + 1):
                if op == '-' and abs(x - b) == target:
                    return True
                if op == '/' and max(x, b) % min(x, b) == 0:
                    if max(x, b) // min(x, b) == target:
                        return True
            return False

        if b == 0:
            for y in range(1, n + 1):
                if op == '-' and abs(a - y) == target:
                    return True
                if op == '/' and max(a, y) % min(a, y) == 0:
                    if max(a, y) // min(a, y) == target:
                        return True
            return False

        if op == '-':
            return abs(a - b) == target

        if min(a, b) == 0:
            return False

        return max(a, b) % min(a, b) == 0 and max(a, b) // min(a, b) == target

    def candidates(r, c):
        used = row_mask[r] | col_mask[c]
        cid = cage_id[r][c]

        result = []
        for value in range(1, n + 1):
            bit = 1 << (value - 1)
            if used & bit:
                continue

            if cage_possible(cid, r, c, value):
                result.append(value)

        return result

    def search():
        best_r = -1
        best_c = -1
        best_values = None

        for r in range(n):
            for c in range(n):
                if board[r][c] != 0:
                    continue

                vals = candidates(r, c)

                if not vals:
                    return False

                if best_values is None or len(vals) < len(best_values):
                    best_r = r
                    best_c = c
                    best_values = vals

                    if len(vals) == 1:
                        break
            if best_values is not None and len(best_values) == 1:
                break

        if best_values is None:
            return True

        cid = cage_id[best_r][best_c]

        for value in best_values:
            bit = 1 << (value - 1)

            board[best_r][best_c] = value
            row_mask[best_r] |= bit
            col_mask[best_c] |= bit

            if cage_possible(cid) and search():
                return True

            board[best_r][best_c] = 0
            row_mask[best_r] ^= bit
            col_mask[best_c] ^= bit

        return False

    if not search():
        return ""

    return '\n'.join(''.join(map(str, row)) for row in board)

def main():
    data = sys.stdin.read()
    sys.stdout.write(solve(data))

if __name__ == "__main__":
    main()

## Vỏ cạnh 

Một lồng nhiều ô chỉ có đầu mối trong ô đầu tiên sẽ được xử lý trong giai đoạn phân tích cú pháp tràn ngập. Đối với đoạn đầu vào`|40x        |2-     |`, bốn ô trước bức tường thứ hai được đặt vào một lồng và chỉ ô đầu tiên của nó mới đóng góp`40x`manh mối. Các ô khác có văn bản trống và không được coi là các ô riêng biệt. Điều này tái tạo cấu trúc lồng theo yêu cầu của mẫu đầu tiên. 

Một lồng trừ như`3-`với giá trị 1 và 4 được chấp nhận vì`abs(1 - 4) == 3`. Nếu người giải quyết thay vào đó chỉ tính toán`1 - 4`, nó sẽ từ chối cặp hợp lệ. Việc triển khai kiểm tra sự khác biệt tuyệt đối, vì vậy cả hai lệnh vật lý đều tương đương nhau. 

Một lồng phân chia như`2/`với giá trị 2 và 4 được chấp nhận vì`max(2, 4) // min(2, 4) == 2`. Việc kiểm tra tính chia hết được thực hiện trước tiên, do đó, một cặp như 2 và 3 sẽ bị loại bỏ thay vì được coi là thương số dấu phẩy động. 

Đối với lồng đơn bào như`2`, ô được gán ngay lập tức. Nếu giá trị đó đã xuất hiện trong cùng một hàng hoặc cột thì đầu vào sẽ không nhất quán và bộ giải sẽ từ chối nó. Trong một câu đố hợp lệ, điều này không thể xảy ra, nhưng việc kiểm tra rõ ràng sẽ ngăn không cho mặt nạ bên trong trở nên không nhất quán. 

Một lồng nhân lớn được xử lý mà không liệt kê mọi bộ dữ liệu có thể. Giả sử bốn ô phải nhân lên thành 24. Khi sản phẩm hiện tại là 6, mục tiêu còn lại là 4 và vẫn còn hai ô. đã được ghi nhớ`product_can`Hàm hỏi liệu 4 có thể được viết dưới dạng tích của hai giá trị từ 1 đến (n), giá trị nào thành công đến (1 \times 4) hoặc (2 \times 2) khi các giá trị đó có sẵn trong lồng. Việc cắt tỉa số học chính xác này mạnh hơn nhiều so với việc chỉ kiểm tra xem sản phẩm hiện tại có nằm dưới mục tiêu hay không. 

Cuối cùng, một ô có thể không có giá trị tương thích với cả hàng và cột của nó mặc dù lồng của nó trông vẫn khả thi về mặt số học. Quá trình quét MRV phát hiện tập hợp ứng cử viên trống ngay lập tức và quay lại. Đây là cơ chế then chốt giúp cho việc tìm kiếm không đi lang thang qua một phần các ô vuông Latinh mà số học lồng không bao giờ có thể cứu được.
