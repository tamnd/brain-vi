Một cách giải thích bạo lực có chủ ý sẽ mô phỏng việc giảm một nửa thay vì thực hiện trực tiếp phép toán số học. Ví dụ: người ta có thể liên tục trừ một giá trị khỏi một giá trị trong khi đếm xem giá trị đó chứa bao nhiêu cặp đơn vị, với cách xử lý đặc biệt đối với đơn vị chưa khớp. Điều này cuối cùng sẽ xác định câu trả lời, nhưng nó thực hiện công việc tỷ lệ thuận với độ lớn của đầu vào thay vì số lượng ca kiểm thử. ## Hướng dẫn thuật toán 

1. Đọc`n`, số lượng giá trị phải được xử lý. Dòng đầu tiên không biểu thị số cần chia nên được dùng riêng. 
2. Lặp lại chính xác`n`lần và đọc số nguyên tiếp theo. Xử lý chính xác`n`các giá trị giữ sự tương ứng giữa các trường hợp đầu vào và trường hợp đầu ra rõ ràng. 
3. Chia số nguyên cho`2`sử dụng`/`. Toán tử này là cần thiết vì các đầu vào lẻ ​​cần giữ lại phân số của chúng`.5`thành phần. 
4. Thêm kết quả vào đầu ra và in tất cả kết quả theo từng dòng. Việc xây dựng đầu ra trước tiên sẽ tránh các hoạt động đầu ra lặp đi lặp lại không cần thiết và cũng làm cho định dạng một kết quả trên mỗi dòng được yêu cầu trở nên rõ ràng. 

Tại sao nó hoạt động: cho mọi giá trị đầu vào`x`, thuật toán tính toán chính xác đại lượng toán học mà bài toán yêu cầu,`x / 2`. Vì mỗi trường hợp thử nghiệm là độc lập nên việc xử lý từng giá trị riêng biệt không thể ảnh hưởng đến bất kỳ kết quả nào khác. Do đó, đầu ra chứa một nửa đúng của mọi giá trị đầu vào theo thứ tự ban đầu. 

## Giải pháp Python```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    out = []

    for _ in range(n):
        x = int(input())
        out.append(str(x / 2))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()

## Trường hợp thử nghiệm 

Tuyên bố Gym ban đầu cung cấp một mẫu, vì vậy các bài kiểm tra còn lại bên dưới được xây dựng để thực hiện các trường hợp dễ thực hiện không chính xác nhất.```python
import sys
import io

def solve():
    n = int(input())
    out = []

    for _ in range(n):
        x = int(input())
        out.append(str(x / 2))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    global input
    old_stdin = sys.stdin
    old_input = input

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    try:
        solve()
        return sys.stdout.getvalue() if False else ""
    finally:
        input = old_input
        sys.stdin = old_stdin

def solve_string(inp: str) -> str:
    data = inp.split()
    n = int(data[0])
    values = map(int, data[1:1 + n])
    return "\n".join(str(x / 2) for x in values)

# Provided sample
assert solve_string(
    "5\n10\n32\n12\n35\n52\n"
) == "5.0\n16.0\n6.0\n17.5\n26.0", "sample 1"

# Minimum-size case
assert solve_string(
    "1\n1\n"
) == "0.5", "minimum value"

# All values even
assert solve_string(
    "4\n2\n4\n6\n100\n"
) == "1.0\n2.0\n3.0\n50.0", "all even values"

# All values odd
assert solve_string(
    "4\n1\n3\n5\n99\n"
) == "0.5\n1.5\n2.5\n49.5", "all odd values"

# Large number of test cases
large_input = "100000\n" + "\n".join(["1"] * 100000) + "\n"
large_expected = "\n".join(["0.5"] * 100000)
assert solve_string(large_input) == large_expected, "large test count"
```Người trợ giúp`solve_string`được sử dụng để xác nhận vì các giải pháp lập trình cạnh tranh thường ghi trực tiếp vào đầu ra tiêu chuẩn. Nó thực hiện phép tính tương tự như giải pháp được gửi trong khi làm cho văn bản trả về của nó dễ dàng so sánh.
