## Giải pháp Python```python
import sys
input = sys.stdin.readline

def solve():
    path = input().strip()

    # Orientation:
    # 0 = bottom, 1 = top, 2 = north, 3 = south, 4 = west, 5 = east
    # Initially every position contains its own physical face.
    ori = [0, 1, 2, 3, 4, 5]

    x = 0
    y = 0

    # Final stamp of every visited cell.
    last = {(x, y): ori[0]}

    for move in path:
        b, t, n, s, w, e = ori

        if move == 'U':
            # North -> bottom, south -> top,
            # top -> north, bottom -> south.
            ori = [n, s, t, b, w, e]
            y += 1

        elif move == 'D':
            # South -> bottom, north -> top,
            # bottom -> north, top -> south.
            ori = [s, n, b, t, w, e]
            y -= 1

        elif move == 'L':
            # West -> bottom, east -> top,
            # top -> west, bottom -> east.
            ori = [w, e, n, s, t, b]
            x -= 1

        else:  # move == 'R'
            # East -> bottom, west -> top,
            # top -> east, bottom -> west.
            ori = [e, w, n, s, b, t]
            x += 1

        last[(x, y)] = ori[0]

    cnt = [0] * 6
    for face in last.values():
        cnt[face] += 1

    cnt.sort()

    answer = sum((i + 1) * cnt[i] for i in range(6))
    print(answer)

if __name__ == "__main__":
    solve()

import sys

def solve_string(path: str) -> str:
    ori = [0, 1, 2, 3, 4, 5]
    x = 0
    y = 0
    last = {(x, y): ori[0]}

    for move in path:
        b, t, n, s, w, e = ori

        if move == 'U':
            ori = [n, s, t, b, w, e]
            y += 1
        elif move == 'D':
            ori = [s, n, b, t, w, e]
            y -= 1
        elif move == 'L':
            ori = [w, e, n, s, t, b]
            x -= 1
        else:
            ori = [e, w, n, s, b, t]
            x += 1

        last[(x, y)] = ori[0]

## Vỏ cạnh 

Пустой маршрут`""`содержит только стартовую клетку. Алгоритм создаёт словарь с одной записью`(0, 0) -> B`, после чего одна физическая грань получает частоту 1, а остальные пять получают 0. После сортировки это`0, 0, 0, 0, 0, 1`, поэтому единственной клетке назначается число 6 và ответ равен`6`. 

Маршрут`UD`không có vấn đề gì cả. После`U`клетка`(0, 1)`bạn có thể làm điều đó. После`D`кубик возвращается в`(0, 0)`, không có gì đáng ngạc nhiên khi bạn làm điều đó. Словарь заменяет запись`B`на`S`, поэтому в финальном состоянии присутствуют только`S`và`N`. Bạn có thể chọn 1 và 1, bạn có thể làm như vậy`1*5 + 1*6 = 11`. 

Маршрут`RLRL`bạn có thể làm điều đó, bạn có thể làm điều đó. После первого`R`появляется клетка справа, затем`L`возвращает кубик на старт, после следующего`R`снова посещается правая клетка, а последний`L`bạn có thể tìm thấy nó. Đây là một trong những điều bạn có thể làm để đạt được mục tiêu của mình. Nếu bạn muốn có một công việc tuyệt vời, bạn không cần phải lo lắng về việc làm của mình. 

Bạn có thể dễ dàng tìm thấy những gì bạn có thể làm trong thời gian ngắn. Например, клетка`(3, -3)`bạn có thể làm điều đó để có được một khoản tiền lớn, một người có thể cung cấp cho bạn một khoản tiền lớn và một khoản tiền lớn. Bạn có thể làm điều đó. После полного прохода частоты физических раней равны`3, 5, 5, 5, 6, 8`, поэтому оптимальное назначение чисел даёт`126`, không`0`. Bạn có thể dễ dàng tìm ra cách để đạt được mục tiêu của mình. 

Tất nhiên, bạn có thể làm điều đó để có được một khoản vay không cần thiết, bạn có thể làm điều đó bằng cách sử dụng nó на гранях обязаны быть ровно`1,2,3,4,5,6`. Ближайший аналог для тестирования логики оптимизации, это маршрут, после которого несколько bạn có thể dễ dàng tìm được một người có thể kiếm được nhiều tiền hơn. Bạn có thể dễ dàng tìm thấy những gì bạn có thể làm trong thời gian ngắn, và bạn không cần phải làm gì cả. Nếu bạn muốn có một công việc tốt, bạn không cần phải làm gì cả разрешения равенств.
