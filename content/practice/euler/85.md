[Bài toán Euler dự án 85](https://projecteuler.net/problem=85) 

## Giải pháp 

**Trả lời:**`2772`Để một lưới có chiều rộng$m$và chiều cao$n$, được đo bằng đơn vị bình phương. 

Chúng ta muốn đếm xem có bao nhiêu hình chữ nhật khác nhau có thể được tạo thành bên trong lưới. 

# Bước 1: Đếm các hình chữ nhật trong một$m \times n$lưới 

Một hình chữ nhật được xác định bằng cách chọn: 

- hai đường lưới dọc riêng biệt, 
- hai đường lưới ngang riêng biệt. 

MỘT$m \times n$lưới có: 

-$m+1$đường lưới dọc, 
-$n+1$đường lưới ngang. 

Vậy số hình chữ nhật là$$\binom{m+1}{2}\binom{n+1}{2}.$$sử dụng$$\binom{k}{2}=\frac{k(k-1)}2,$$chúng tôi nhận được$$R(m,n) = \frac{m(m+1)}2 \cdot \frac{n(n+1)}2.$$Vì thế$$R(m,n)=\frac{m(m+1)n(n+1)}4.$$Mục tiêu là:$$R(m,n)\approx 2{,}000{,}000.$$Chúng tôi được yêu cầu về khu vực lưới$$A=mn$$có số hình chữ nhật gần nhất với hai triệu. 

--- 

# Bước 2: Xác minh ví dụ nhỏ 

Đối với một$3\times2$lưới:$$R(3,2) = \frac{3\cdot4}{2}\cdot\frac{2\cdot3}{2} = 6\cdot3 = 18.$$Điều này phù hợp với tuyên bố vấn đề. 

--- 

# Bước 3: Chiến lược 

Số lượng hình chữ nhật tăng lên gần như$$\frac{m^2n^2}{4},$$vì vậy các giá trị gần mục tiêu sẽ có kích thước khoảng vài chục. 

Việc tìm kiếm mạnh mẽ trong phạm vi hợp lý là hoàn toàn khả thi. 

Cho mỗi cặp$(m,n)$: 

1. tính số hình chữ nhật, 
2. tính toán sự khác biệt từ$2{,}000{,}000$, 
3. giữ lưới tốt nhất. 

--- 

# Triển khai Python```python
TARGET = 2_000_000

best_diff = float('inf')
best_area = None
best_dims = None

# Search reasonable grid sizes.
# 100 is safely large enough.
for m in range(1, 101):
    for n in range(1, 101):

        # Number of rectangles in an m x n grid
        rectangles = (m * (m + 1) * n * (n + 1)) // 4

        diff = abs(rectangles - TARGET)

        # Update best solution if closer
        if diff < best_diff:
            best_diff = diff
            best_area = m * n
            best_dims = (m, n)

print("Best dimensions:", best_dims)
print("Area:", best_area)
print("Rectangle count:",
      (best_dims[0] * (best_dims[0] + 1) *
       best_dims[1] * (best_dims[1] + 1)) // 4)
print("Difference:", best_diff)
```---

# Kết quả tìm kiếm
