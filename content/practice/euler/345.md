[Vấn đề dự án Euler 345](https://projecteuler.net/problem=345) 

##Giải pháp 

**Trả lời:**`13938`Đây là một **vấn đề bài tập kinh điển**: 

- Chúng ta phải chọn đúng một số ở mỗi hàng. 
- Không có hai số được chọn có thể đến từ cùng một cột. 
- Chúng tôi muốn **số tiền tối đa có thể**. 

Về mặt toán học, nếu ma trận là$A=(a_{ij})$, chúng tôi tìm kiếm$$\max_{\sigma \in S_n} \sum_{i=1}^{n} a_{i,\sigma(i)}$$Ở đâu$S_n$là tập hợp các hoán vị của$\{0,1,\dots,n-1\}$. 

Đối với một$15\times 15$ma trận, vũ lực trên tất cả$15!$hoán vị là không thể:$$15! \approx 1.3\times 10^{12}$$Vì vậy chúng ta cần lập trình động. 

--- 

# Phân tích toán học 

Hãy: 

-$n = 15$-$dp(mask)$= tổng tối đa có thể đạt được sau khi gán một số hàng cho tập hợp các cột được biểu thị bằng`mask`. 

Mặt nạ bit có độ dài 15 biểu thị cột nào đã được sử dụng. 

Nếu như`mask`có$k$bit được thiết lập thì chúng ta đã gán các hàng$0,1,\dots,k-1$. 

Chuyển tiếp: 

Đối với mỗi cột không sử dụng$j$,$$dp(mask \cup \{j\}) = \max\left( dp(mask \cup \{j\}), \; dp(mask)+a_{k,j} \right)$$Ở đâu$$k = \text{number of set bits in } mask$$Tổng số trạng thái là:$$2^{15} = 32768$$và mỗi trạng thái thử tối đa 15 lần chuyển đổi, do đó độ phức tạp xấp xỉ$$15 \cdot 2^{15} \approx 5\times 10^5$$cái đó nhỏ xíu

    [813,883,451,509,615,77,281,613,459,205,380,274,302,35,805]
]

n = len(matrix)

# dp[mask] = best sum achievable using columns in mask
dp = [-1] * (1 << n)
dp[0] = 0

for mask in range(1 << n):

    # Number of rows already assigned
    row = bin(mask).count("1")

    # If all rows assigned, skip transitions
    if row == n:
        continue

    # Try assigning current row to any unused column
    for col in range(n):

        # If column not used yet
        if not (mask & (1 << col)):

            new_mask = mask | (1 << col)

            dp[new_mask] = max(
                dp[new_mask],
                dp[mask] + matrix[row][col]
            )

answer = dp[(1 << n) - 1]

print(answer)

### 2. Tạo bảng DP```python

```có$2^{15}$mặt nạ.
