## Giải pháp 

**Trả lời:**`57060635927998347`Đối với số vô tỉ$x$, lý thuyết phân số liên tục cho chúng ta biết rằng mọi **xấp xỉ tốt nhất** (theo nghĩa của bài toán) là hoặc 

- sự hội tụ của phân số liên tục của$x$hoặc 
- một phần trung gian (còn gọi là bán hội tụ). 

Đối với các số vô tỷ bậc hai như$\sqrt n$, việc mở rộng phân số liên tục là định kỳ và các điểm hội tụ có thể được tạo ra rất hiệu quả. 

--- 

# 1. Phân tích toán học 

hãy để$$x = [a_0;a_1,a_2,a_3,\dots]$$là phần tiếp theo của$x$. 

hội tụ của nó là$$\frac{p_k}{q_k},$$được tạo bởi$$p_k=a_k p_{k-1}+p_{k-2},\qquad q_k=a_k q_{k-1}+q_{k-2},$$với các giá trị ban đầu$$p_{-2}=0,\; p_{-1}=1,\qquad q_{-2}=1,\; q_{-1}=0.$$--- 

## Phần tiếp theo của$\sqrt n$Đối với không vuông$n$,$$\sqrt n = [a_0;\overline{a_1,a_2,\dots,a_t}]$$mang tính định kỳ. 

Phép lặp tiêu chuẩn là:$$m_{k+1}=d_k a_k-m_k,$$

$$d_{k+1}=\frac{n-m_{k+1}^2}{d_k},$$

$$a_{k+1}=\left\lfloor\frac{a_0+m_{k+1}}{d_{k+1}}\right\rfloor.$$--- 

## Xấp xỉ tốt nhất với mẫu số bị ràng buộc$D$Giả sử chúng ta có các điểm hội tụ liên tiếp$$\frac{p_{k-1}}{q_{k-1}}, \qquad \frac{p_k}{q_k}, \qquad \frac{p_{k+1}}{q_{k+1}},$$Và$$q_k \le D < q_{k+1}.$$Khi đó mọi ứng viên đều xấp xỉ tốt nhất với mẫu số$\le D$phải là: 

1. sự hội tụ$\frac{p_k}{q_k}$hoặc 
2. bán hội tụ chấp nhận được lớn nhất$$\frac{t p_k+p_{k-1}}{t q_k+q_{k-1}},$$Ở đâu$$t=\left\lfloor\frac{D-q_{k-1}}{q_k}\right\rfloor.$$Vì vậy chỉ **hai ứng viên** cần được kiểm tra. 

---

## Ví dụ:$\sqrt{13}$Phân số tiếp tục là$$\sqrt{13}=[3;\overline{1,1,1,1,6}].$$Hội tụ:$$3,\ \frac41,\ \frac72,\ \frac{11}3,\ \frac{18}5,\ \frac{119}{33},\dots$$Vì$D=20$: 

-$5 \le 20 < 33$- mẫu số bán hội tụ lớn nhất là$18$Các ứng cử viên là:$$\frac{18}5,\qquad \frac{65}{18}.$$Về mặt số lượng,$$\left|\sqrt{13}-\frac{18}5\right| < \left|\sqrt{13}-\frac{65}{18}\right|,$$vậy câu trả lời là$\frac{18}5$. 

Vì$D=30$, bán hội tụ lớn nhất trở thành$$\frac{101}{28},$$cái nào gần hơn$\frac{18}5$.

#2. Triển khai Python```python
from math import isqrt
from decimal import Decimal, getcontext

# We need very high precision because denominators go up to 10^12
getcontext().prec = 80

LIMIT = 10**12

def best_denominator_sqrt(n, D):
    """
    Returns the denominator of the best approximation to sqrt(n)
    with denominator bound D.
    """

    a0 = isqrt(n)

    # Ignore perfect squares
    if a0 * a0 == n:
        return 0

    x = Decimal(n).sqrt()

    # Continued fraction state
    m = 0
    d = 1
    a = a0

    # Convergents:
    # p[-2]=0, p[-1]=1
    # q[-2]=1, q[-1]=0
    p0, p1 = 1, a
    q0, q1 = 0, 1

    while True:

        # Generate next continued-fraction term
        m = d * a - m
        d = (n - m * m) // d
        a = (a0 + m) // d

        # Next convergent
        p2 = a * p1 + p0
        q2 = a * q1 + q0

        # Stop when next denominator exceeds D
        if q2 > D:

            # Largest admissible semiconvergent
            t = (D - q0) // q1

            # Candidate 1: convergent
            cand1_p, cand1_q = p1, q1

            # Candidate 2: semiconvergent
            cand2_p = t * p1 + p0
            cand2_q = t * q1 + q0

            # Compare distances to sqrt(n)
            err1 = abs(Decimal(cand1_p) / cand1_q - x)
            err2 = abs(Decimal(cand2_p) / cand2_q - x)

            if err1 <= err2:
                return cand1_q
            else:
                return cand2_q

        # Advance
        p0, p1 = p1, p2
        q0, q1 = q1, q2

def solve():
    total = 0

    for n in range(2, 100001):
        r = isqrt(n)

        # Skip perfect squares
        if r * r == n:
            continue

        total += best_denominator_sqrt(n, LIMIT)

    return total

print(solve())
```---
