## Giải pháp 

**Trả lời:**`476001479068717`Đối với số nguyên dương$n$, định nghĩa$s(n)$là số nguyên nhỏ nhất$m$như vậy$$n \mid m!.$$Chúng ta phải tính toán$$S(10^8)=\sum_{n=2}^{10^8} s(n).$$Điều quan trọng là phải hiểu$s(n)$thông qua việc phân tích các thừa số nguyên tố. 

--- 

# 1. Phân tích toán học 

Giả sử$$n=\prod p_i^{a_i}.$$Sau đó$n\mid m!$nếu cho mọi quyền lực chính$p_i^{a_i}$,$$v_{p_i}(m!)\ge a_i,$$Ở đâu$v_p(x)$là số mũ của$p$TRONG$x$. 

Như vậy:$$s(n)=\max_i s(p_i^{a_i}),$$vì vậy toàn bộ vấn đề giảm xuống lũy ​​thừa nguyên tố. 

--- 

## Quyền lực chính 

Đối với số nguyên tố cố định$p$, định nghĩa:$$f(p,a)=s(p^a).$$Chúng ta cần cái nhỏ nhất$m$như vậy$$v_p(m!)\ge a.$$Theo công thức Legendre:$v_p(m!)=\sum_{k\ge1}\left\lfloor\frac{m}{p^k}\right\rfloor$Vì thế$f(p,a)$là tối thiểu$m$thỏa mãn bất đẳng thức này. 

Ví dụ: 

-$f(5,1)=5$-$f(5,2)=10$bởi vì$10!$chứa đúng hai yếu tố$5$--- 

## Tính toán tất cả$s(n)$Đối với mọi quyền lực hàng đầu$q=p^a\le N$: 

1. Tính toán$m=f(p,a)$2. Mọi bội số của$q$phải thỏa mãn$s(k)\ge m$Do đó chúng ta có thể sàng:$$s(k)=\max(s(k),\,f(p,a)) \quad\text{for all }k\equiv0\pmod{p^a}.$$Điều này rất giống với một sàng sơ cấp. 

Tổng độ phức tạp xấp xỉ$$N\sum_{p^a\le N}\frac1{p^a},$$đủ nhanh để$N=10^8$trong mã được tối ưu hóa.

#2. Triển khai Python```python
from math import isqrt

N = 10**8

# ------------------------------------------------------------
# Legendre valuation: exponent of prime p inside m!
# ------------------------------------------------------------
def vp_fact(m, p):
    s = 0
    while m:
        m //= p
        s += m
    return s

# ------------------------------------------------------------
# Smallest m such that v_p(m!) >= a
# ------------------------------------------------------------
def min_m(p, a):
    lo, hi = 1, p * a

    while lo < hi:
        mid = (lo + hi) // 2

        if vp_fact(mid, p) >= a:
            hi = mid
        else:
            lo = mid + 1

    return lo

# ------------------------------------------------------------
# Sieve primes up to N
# ------------------------------------------------------------
is_comp = bytearray(N + 1)
primes = []

for i in range(2, N + 1):
    if not is_comp[i]:
        primes.append(i)

        if i <= isqrt(N):
            step = i
            start = i * i
            for j in range(start, N + 1, step):
                is_comp[j] = 1

# ------------------------------------------------------------
# Compute s(n) for all n <= N
# ------------------------------------------------------------
s = [0] * (N + 1)

for p in primes:

    power = p
    a = 1

    while power <= N:

        m = min_m(p, a)

        # every multiple of p^a needs at least m
        for k in range(power, N + 1, power):
            if s[k] < m:
                s[k] = m

        if power > N // p:
            break

        power *= p
        a += 1

# ------------------------------------------------------------
# Sum all values
# ------------------------------------------------------------
answer = sum(s[2:])
print(answer)
```---
