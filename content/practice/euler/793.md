[Vấn đề dự án Euler 793](https://projecteuler.net/problem=793) 

##Giải pháp 

**Trả lời:**`475808650131120`Cho phép$$S_0=290797,\qquad S_{i+1}=S_i^2 \bmod 50515093$$và xác định$$P(n)=\{S_iS_j \mid 0\le i<j<n\}.$$có$$N=\binom n2$$sản phẩm theo cặp. Từ$N$thật kỳ lạ đối với$n=1{,}000{,}003$, số trung vị là phần tử duy nhất có chính xác$N//2$sản phẩm bên dưới nó. 

Chúng tôi được yêu cầu$$M(1{,}000{,}003).$$--- 

# 1. Phân tích toán học 

## Bước 1: Tạo và sắp xếp chuỗi 

Trình tạo giả ngẫu nhiên tạo ra các số nguyên dương nhỏ hơn$50515093$. 

Cho phép$$A = \text{sorted}(S_0,S_1,\dots,S_{n-1}).$$Việc sắp xếp rất quan trọng vì nó cho phép chúng ta đếm sản phẩm một cách hiệu quả. 

--- 

## Bước 2: Chuyển bài toán trung vị thành bài toán đếm 

Xác định$$f(x)=\#\{(i,j): i<j,\ A_iA_j\le x\}.$$Sau đó$f(x)$đơn điệu ngày càng tăng. 

Nếu chúng ta có thể tính toán$f(x)$nhanh chóng thì số trung vị là nhỏ nhất$x$như vậy$$f(x)\ge \frac{N+1}{2}.$$Vì$$N=\binom{1{,}000{,}003}{2}=500002500003,$$thứ hạng mục tiêu là$$K=\frac{N+1}{2}=250001250002.$$Vì vậy chúng ta tìm số nguyên nhỏ nhất$x$với$$f(x)\ge K.$$--- 

## Bước 3: Đếm hai con trỏ 

Bởi vì$A$được sắp xếp, chúng ta có thể đếm các cặp theo thời gian tuyến tính. 

Sửa chữa$i$. Chúng tôi muốn lớn nhất$j>i$thỏa mãn$$A_iA_j\le x.$$BẰNG$i$tăng lên, mức tối đa này$j$không bao giờ tăng nên chúng ta sử dụng con trỏ giảm. 

Thuật toán: 

- Bắt đầu$j=n-1$. 
- Đối với mỗi$i$:

- Trong khi$A_iA_j>x$, giảm$j$. 
- Sau đó tất cả các chỉ số$i+1,\dots,j$công việc. 
- Thêm vào$j-i$để đếm. 

Điều này tính toán$f(x)$TRONG$O(n)$. 

--- 

## Bước 4: Tìm kiếm nhị phân 

Sản phẩm đa dạng từ$$0 \le A_iA_j \le A_{n-1}A_{n-2}.$$Từ$f(x)$là đơn điệu, tìm kiếm nhị phân tìm thấy giá trị trung bình trong khoảng 51 lần lặp vì phạm vi tìm kiếm nằm dưới$2^{52}$. 

Tổng độ phức tạp: 

- Sắp xếp:$O(n\log n)$- Mỗi lần đếm:$O(n)$- Tìm kiếm nhị phân:$O(n\log V)$Tốc độ này đủ nhanh để$n=1{,}000{,}003$.

#2. Triển khai Python```python
MOD = 50515093
N = 1_000_003

# ------------------------------------------------------------
# Generate the sequence
# ------------------------------------------------------------
S = [0] * N

x = 290797
for i in range(N):
    S[i] = x
    x = (x * x) % MOD

# ------------------------------------------------------------
# Sort values
# ------------------------------------------------------------
A = sorted(S)

# Number of pairwise products
total_pairs = N * (N - 1) // 2

# We want the lower/true median rank (1-based)
target = total_pairs // 2 + 1

# ------------------------------------------------------------
# Count how many pairs have product <= value
# ------------------------------------------------------------
def count_leq(value):
    count = 0
    j = N - 1

    for i, a in enumerate(A):

        while i < j and a * A[j] > value:
            j -= 1

        if j <= i:
            break

        count += (j - i)

    return count

# ------------------------------------------------------------
# Binary search for the median product
# ------------------------------------------------------------
lo = 0
hi = A[-1] * A[-2]

while lo < hi:
    mid = (lo + hi) // 2

    if count_leq(mid) >= target:
        hi = mid
    else:
        lo = mid + 1

print(lo)
```---

--- 

## Sắp xếp```python
A = sorted(S)
```Thứ tự sắp xếp cho phép đếm hai con trỏ đơn điệu. 

--- 

## Đếm cặp```python
while i < j and a * A[j] > value:
    j -= 1
```Đối với mỗi cố định$i$, di chuyển$j$đi xuống cho đến khi giới hạn sản phẩm được giữ nguyên. 

Sau đó:```python
count += (j - i)
```bởi vì mọi chỉ số giữa$i+1$Và$j$hoạt động. 

Thời gian chạy tổng thể là tuyến tính vì$j$chỉ giảm đi. 

--- 

## Tìm kiếm nhị phân```python
if count_leq(mid) >= target:
    hi = mid
else:
    lo = mid + 1
```Điều này tìm thấy giá trị nhỏ nhất có thứ hạng ít nhất là thứ hạng trung vị.
