[Vấn đề dự án Euler 332](https://projecteuler.net/problem=332) 

## Giải pháp 

**Trả lời:**`2717.751525`Đặt ba đỉnh của một tam giác cầu trên mặt cầu$x^2+y^2+z^2=r^2$là các vectơ nguyên$$\mathbf a,\mathbf b,\mathbf c \in \mathbb Z^3, \qquad \|\mathbf a\|=\|\mathbf b\|=\|\mathbf c\|=r.$$Chúng ta phải tìm, với mọi$1\le r\le 50$, diện tích tam giác cầu không suy biến nhỏ nhất và tính tổng chúng. 

--- 

# 1. Phân tích toán học 

Một tam giác cầu trên một mặt cầu có bán kính$r$có diện tích$$A = r^2 E,$$Ở đâu$E$là phần dư hình cầu. 

Đối với vectơ đơn vị$\mathbf u,\mathbf v,\mathbf w$, một danh tính tiêu chuẩn cho$$E = 2\arctan\!\left( \frac{|\mathbf u\cdot(\mathbf v\times\mathbf w)|} {1+\mathbf u\cdot\mathbf v+\mathbf v\cdot\mathbf w+\mathbf w\cdot\mathbf u} \right).$$Vì điểm của chúng tôi nằm trên bán kính$r$,$$\mathbf u=\frac{\mathbf a}{r}, \quad \mathbf v=\frac{\mathbf b}{r}, \quad \mathbf w=\frac{\mathbf c}{r}.$$Thay vào công thức:$$\mathbf u\cdot(\mathbf v\times\mathbf w) = \frac{\det(\mathbf a,\mathbf b,\mathbf c)}{r^3},$$Và$$1+\mathbf u\cdot\mathbf v+\mathbf v\cdot\mathbf w+\mathbf w\cdot\mathbf u = \frac{ r^2+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a }{r^2}.$$Vì thế$$E = 2\arctan\!\left( \frac{ |\det(\mathbf a,\mathbf b,\mathbf c)| }{ r\left(r^2+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a\right) } \right).$$Do đó diện tích hình cầu là$$\boxed{ A = 2r^2\arctan\!\left( \frac{ |\det(\mathbf a,\mathbf b,\mathbf c)| }{ r\left(r^2+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a\right) } \right) }.$$Một tam giác suy biến chính xác khi$$\det(\mathbf a,\mathbf b,\mathbf c)=0,$$vì khi đó ba điểm nằm trên cùng một đường tròn lớn. 

Vì vậy, thuật toán là: 

1. Tạo tất cả các điểm nguyên trên mặt cầu$x^2+y^2+z^2=r^2$. 
2. Liệt kê các bộ ba. 
3. Bỏ qua định thức$0$. 
4. Tính công thức diện tích trên. 
5. Giữ mức tối thiểu.

#2. Triển khai Python```python
import numpy as np
from math import isqrt

# ------------------------------------------------------------
# Generate all lattice points on x^2 + y^2 + z^2 = r^2
# ------------------------------------------------------------
points_by_r = {}

for r in range(1, 51):
    pts = []
    r2 = r * r

    for x in range(-r, r + 1):
        xx = x * x

        for y in range(-r, r + 1):
            zz = r2 - xx - y * y

            if zz < 0:
                continue

            z = isqrt(zz)

            if z * z == zz:
                pts.append((x, y, z))

                if z != 0:
                    pts.append((x, y, -z))

    points_by_r[r] = np.array(pts, dtype=np.int64)

# ------------------------------------------------------------
# Compute the minimum spherical triangle area for radius r
# ------------------------------------------------------------
def minimum_area(r):
    P = points_by_r[r]
    n = len(P)

    rr = r * r
    best = float("inf")

    # dot-product matrix
    D = P @ P.T

    for i in range(n - 2):

        A = P[i]

        # Cross products with all later points
        crosses = np.cross(A, P[i + 1:])

        for offset, c in enumerate(crosses, start=i + 1):

            # determinants with remaining points
            dets = np.abs(P[offset + 1:] @ c)

            mask = dets != 0
            if not mask.any():
                continue

            dets = dets[mask]

            # denominator term
            S = (
                D[i, offset]
                + D[offset, offset + 1:]
                + D[offset + 1:, i]
            )

            S = S[mask]

            denom = r * (rr + S)

            # area formula
            areas = 2 * rr * np.arctan2(dets, denom)

            m = areas.min()

            if m < best:
                best = float(m)

    return best

# ------------------------------------------------------------
# Sum A(r)
# ------------------------------------------------------------
total = 0.0

for r in range(1, 51):
    total += minimum_area(r)

print(f"{total:.6f}")
```--- 

#3. Hướng dẫn sử dụng mã 

### Tạo điểm mạng 

Đối với mỗi$r$:```python
x^2 + y^2 + z^2 = r^2
```được kiểm tra một cách triệt để. 

Bất cứ khi nào$z^2$là một hình vuông hoàn hảo, chúng tôi thêm các điểm tương ứng. 

--- 

### Kiểm tra thoái hóa 

Đối với vectơ$\mathbf a,\mathbf b,\mathbf c$,```python
det = abs(c · (a × b))
```Nếu giá trị này bằng 0 thì các điểm nằm trên một vòng tròn lớn, do đó tam giác bị loại trừ. 

--- 

### Tính diện tích 

Công thức được thực hiện chính xác là$$A = 2r^2\arctan\!\left( \frac{ |\det(\mathbf a,\mathbf b,\mathbf c)| }{ r\left(r^2+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a\right) } \right).$$---
