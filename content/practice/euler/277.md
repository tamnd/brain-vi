# 1. Phân tích toán học 

Các quy tắc là: 

-$D:\quad a_{n+1}=\dfrac{a_n}{3}$, hợp lệ khi$a_n\equiv0\pmod3$-$U:\quad a_{n+1}=\dfrac{4a_n+2}{3}$, hợp lệ khi$a_n\equiv1\pmod3$-$d:\quad a_{n+1}=\dfrac{2a_n-1}{3}$, hợp lệ khi$a_n\equiv2\pmod3$Quan sát chính là: 

> Mỗi bước là một phép biến đổi tuyến tính affine. 

Vì vậy, sau toàn bộ chuỗi các bước, giá trị bắt đầu là hàm affine của giá trị kết thúc. 

--- 

## Làm việc ngược 

Giả sử sau tất cả các bước chúng ta kết thúc ở một số nguyên nào đó$x$. 

Chúng tôi đảo ngược từng hoạt động. 

### Nghịch đảo của$D$

$$a_n = 3a_{n+1}$$### Nghịch đảo của$U$

$$a_{n+1}=\frac{4a_n+2}{3}$$Vì thế$$a_n=\frac{3a_{n+1}-2}{4}$$### Nghịch đảo của$d$

$$a_{n+1}=\frac{2a_n-1}{3}$$Vì thế$$a_n=\frac{3a_{n+1}+1}{2}$$--- 

Bây giờ chúng tôi xử lý ngược chuỗi yêu cầu. 

Đặt giá trị cuối cùng sau tất cả các bước là$x$. 

Sau khi soạn thảo một cách tượng trưng tất cả các bản đồ nghịch đảo, chúng ta thu được$$a_1 = \frac{205891132094649\,x+21110037246199}{2^{22}}$$Như vậy$a_1$là một số nguyên iff$$205891132094649\,x+21110037246199 \equiv 0 \pmod{2^{22}}$$Từ$2^{22}=4194304$, giảm hệ số modulo$4194304$:$$686265x+356599\equiv0\pmod{4194304}$$Bởi vì$$\gcd(686265,4194304)=1,$$có một giải pháp duy nhất modulo$4194304$. 

Giải quyết cho$$x\equiv 1966289 \pmod{4194304}.$$Vì vậy hãy viết$$x=1966289+4194304k.$$Thay thế vào biểu thức affine cho$a_1$:$$a_1 = 96521732651065 + 205891132094649\,k.$$Bây giờ chúng ta chọn cái nhỏ nhất$k$như vậy$$a_1>10^{15}.$$Đó là,$$96521732651065+205891132094649\,k>10^{15}.$$Điều này mang lại$$k=5.$$Kể từ đây$$a_1 = 96521732651065 + 5\cdot205891132094649 = 1125977393124310.$$--- 

#2. Triển khai Python```python
from math import gcd

# Required step sequence
s = "UDDDUdddDDUDDddDdDddDDUDDdUUDd"

# We derive:
# a1 = (A*x + B) / M
# where x is the value AFTER all steps.

A = 1
B = 0
M = 1

# Process inverses in reverse order
for ch in reversed(s):

    if ch == 'D':
        # x -> 3x
        A *= 3
        B *= 3

    elif ch == 'U':
        # x -> (3x - 2)/4
        A *= 3
        B = 3 * B - 2
        M *= 4

    elif ch == 'd':
        # x -> (3x + 1)/2
        A *= 3
        B = 3 * B + 1
        M *= 2

# Need:
# A*x + B ≡ 0 (mod M)

a = A % M
b = B % M

# modular inverse since gcd(a, M)=1
inv = pow(a, -1, M)

x0 = (-b * inv) % M

# General solution:
# x = x0 + M*k
#
# Then:
# a1 = (A*x + B)/M
#
# = base + A*k

base = (A * x0 + B) // M
step = A

LIMIT = 10**15

k = (LIMIT - base + step) // step

answer = base + step * k

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

### Xây dựng dạng affine 

Chúng tôi xử lý chuỗi ngược vì các công thức nghịch đảo là các bản đồ tuyến tính đơn giản. 

Chúng tôi duy trì:$$a_1 = \frac{A x + B}{M}$$Ở đâu$x$là điểm cuối chưa biết sau toàn bộ chuỗi. 

Mỗi bước nghịch đảo cập nhật$A,B,M$. 

--- 

### Giải tích phân 

cho$a_1$là một số nguyên:$$A x + B \equiv 0 \pmod M.$$Đây là một sự đồng đẳng tuyến tính. 

Bởi vì$A$là modulo khả nghịch$M$, có đúng một lớp thặng dư modulo$M$. 

--- 

### Tạo ra tất cả các giải pháp 

Mọi giải pháp hợp lệ là:$$x=x_0+Mk.$$Thay thế vào công thức affine mang lại:$$a_1=\text{base}+A k.$$Vì vậy, các giá trị bắt đầu hợp lệ tạo thành một cấp số cộng. 

Chúng tôi chọn cái nhỏ nhất vượt quá$10^{15}$.
