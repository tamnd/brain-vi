[Vấn đề dự án Euler 816](https://projecteuler.net/problem=816) 

##Giải pháp 

**Trả lời:**`20.880613018`Để giải quyết vấn đề này một cách hiệu quả$k = 2{,}000{,}000$, một lực lượng vũ phu$O(n^2)$so sánh là không thể ($\sim 2\times10^{12}$cặp). 

Cách tiếp cận đúng là thuật toán đường quét **cặp điểm gần nhất** cổ điển: 

- Tạo tất cả các điểm bằng cách sử dụng chuỗi giả ngẫu nhiên đã cho. 
- Sắp xếp điểm theo$x$-điều phối. 
- Duy trì một tập hoạt động được sắp xếp bởi$y$-điều phối. 
- Chỉ so sánh các điểm trong khoảng cách tốt nhất hiện tại. 

Thuật toán chạy trong$O(n \log n)$. 

Việc triển khai Python được sử dụng:```python
from math import sqrt
import bisect
import math

MOD = 50515093
n = 2000000

# Generate points
pts = [None] * n
s = 290797

vals = [0] * (2 * n)
for i in range(2 * n):
    vals[i] = s
    s = (s * s) % MOD

for i in range(n):
    pts[i] = (vals[2 * i], vals[2 * i + 1])

# Sort by x-coordinate
pts.sort()

best2 = float('inf')

# Active set sorted by y-coordinate: (y, x)
active = []
left = 0

for x, y in pts:

    d = math.sqrt(best2) if best2 < float('inf') else float('inf')

    # Remove points too far in x-direction
    while x - pts[left][0] > d:
        xx, yy = pts[left]
        idx = bisect.bisect_left(active, (yy, xx))
        active.pop(idx)
        left += 1

    # Candidate points within y-range
    lo = bisect.bisect_left(active, (y - d, -10**18))
    hi = bisect.bisect_right(active, (y + d, 10**18))

    for yy, xx in active[lo:hi]:
        dx = x - xx
        dy = y - yy
        ds = dx * dx + dy * dy

        if ds < best2:
            best2 = ds
            d = math.sqrt(best2)

    bisect.insort(active, (y, x))

answer = math.sqrt(best2)
print(f"{answer:.12f}")
```Xác minh đối với mẫu:
