[Vấn đề dự án Euler 147](https://projecteuler.net/problem=147) 

## Giải pháp 

**Trả lời:**`846910284`Cho phép$R(m,n)$là số hình chữ nhật có thể xếp được trong một$m\times n$lưới đan chéo. 

Chúng ta phải tính toán$$\sum_{m=1}^{47}\sum_{n=1}^{43} R(m,n).$$Khó khăn chính là hình chữ nhật **không chỉ được căn chỉnh theo trục**: tính năng gạch chéo giới thiệu$45^\circ$-hình chữ nhật nghiêng. 

## 1. Phân tích toán học 

### Hình chữ nhật thông thường (căn chỉnh theo trục) 

Bỏ qua các đường chéo, số hình chữ nhật thông thường trong một$m\times n$lưới là cổ điển:$$R_{\text{axis}}(m,n) = \binom{m+1}{2}\binom{n+1}{2} = \frac{m(m+1)n(n+1)}{4}.$$Ví dụ, trong một$3\times 2$lưới:$$\frac{3\cdot4\cdot2\cdot3}{4}=18.$$Nhưng vấn đề nêu tổng số là$37$, vậy có$19$hình chữ nhật nghiêng. 

--- 

### Đếm hình chữ nhật nghiêng 

Một cách hiệu quả để đếm chúng là lập mô hình lưới đan chéo dưới dạng biểu đồ hình học: 

- các đỉnh là: 

- góc lưới, 
- giao điểm chéo (trung tâm tế bào), 
- các cạnh là: 

- đường lưới ngang / dọc, 
- cả hai đường chéo bên trong mỗi ô. 

Khi đó mọi hình chữ nhật hợp lệ là một hình 4 chu trình có các cạnh liền kề vuông góc và nằm hoàn toàn trên các đoạn thẳng đã vẽ. 

Bởi vì$47\times43$vẫn còn nhỏ, chúng ta có thể liệt kê chính xác các hình chữ nhật hợp lệ và tính tổng trên tất cả các lưới con. Điều này tránh được các công việc dễ vỡ và đảm bảo tính chính xác. 

Thuật toán: 

1. Xây dựng tất cả các đoạn đường của lưới gạch chéo. 
2. Tạo tất cả các điểm giao nhau hình học hợp lệ. 
3. Kiểm tra xem đoạn thẳng giữa hai điểm có nằm hoàn toàn trên đường vẽ hay không. 
4. Liệt kê các cặp cạnh vuông góc và hoàn thiện hình chữ nhật. 
5. Xóa hình chữ nhật trùng lặp. 

Điều này tái tạo các ví dụ: 

-$1\times1 \to 1$-$2\times1 \to 4$-$3\times1 \to 8$-$1\times2 \to 4$-$2\times2 \to 18$-$3\times2 \to 37$có tổng cộng tích lũy là$72$, đúng như đã nêu.

## 2. Triển khai Python```python
from math import gcd

def build_segments(m, n):
    """All drawable segments in the cross-hatched grid."""
    segs = []

    # Horizontal lines
    for y in range(n + 1):
        segs.append(((0, 2 * y), (2 * m, 2 * y)))

    # Vertical lines
    for x in range(m + 1):
        segs.append(((2 * x, 0), (2 * x, 2 * n)))

    # Both diagonals in each unit square
    for i in range(m):
        for j in range(n):
            segs.append(((2 * i, 2 * j),
                         (2 * (i + 1), 2 * (j + 1))))
            segs.append(((2 * i, 2 * (j + 1)),
                         (2 * (i + 1), 2 * j)))

    return segs

def on_segment(p, seg):
    """Check if point p lies on segment seg."""
    (x1, y1), (x2, y2) = seg
    x, y = p

    dx = x2 - x1
    dy = y2 - y1

    # Collinearity
    if (x - x1) * dy != (y - y1) * dx:
        return False

    return (min(x1, x2) <= x <= max(x1, x2) and
            min(y1, y2) <= y <= max(y1, y2))

def connected(p, q, segs):
    """True if the entire segment pq is drawable."""
    x1, y1 = p
    x2, y2 = q

    dx = x2 - x1
    dy = y2 - y1

    # Allowed directions:
    # horizontal, vertical, ±45°
    if not (dx == 0 or dy == 0 or abs(dx) == abs(dy)):
        return False

    g = gcd(abs(dx), abs(dy))
    if g == 0:
        return False

    stepx = dx // g
    stepy = dy // g

    # Every tiny piece must lie on some drawn segment
    for k in range(g):
        a = (x1 + stepx * k, y1 + stepy * k)
        b = (x1 + stepx * (k + 1), y1 + stepy * (k + 1))

        mx = (a[0] + b[0]) / 2
        my = (a[1] + b[1]) / 2

        ok = False
        for seg in segs:
            if (on_segment((mx, my), seg) and
                on_segment(a, seg) and
                on_segment(b, seg)):
                ok = True
                break

        if not ok:
            return False

    return True

def count_rectangles(m, n):
    """Count all rectangles in one m x n grid."""
    segs = build_segments(m, n)

    # Candidate vertices
    points = set()

    for s in segs:
        points.add(s[0])
        points.add(s[1])

    # Cell centers (diagonal crossings)
    for i in range(m):
        for j in range(n):
            points.add((2 * i + 1, 2 * j + 1))

    points = list(points)
    point_set = set(points)

    # Connectivity cache
    conn = set()

    for i in range(len(points)):
        for j in range(i + 1, len(points)):
            if connected(points[i], points[j], segs):
                conn.add((i, j))
                conn.add((j, i))

    rectangles = set()

    # Build rectangles from perpendicular edges
    for i, p in enumerate(points):
        for j, q in enumerate(points):
            if (i, j) not in conn:
                continue

            vx = q[0] - p[0]
            vy = q[1] - p[1]

            for k, r in enumerate(points):
                if (i, k) not in conn or k == j:
                    continue

                wx = r[0] - p[0]
                wy = r[1] - p[1]

                # Perpendicular sides
                if vx * wx + vy * wy != 0:
                    continue

                s = (q[0] + wx, q[1] + wy)

                if s not in point_set:
                    continue

                l = points.index(s)

                if ((k, l) in conn and
                    (j, l) in conn):

                    rect = tuple(sorted([p, q, r, s]))
                    rectangles.add(rect)

    return len(rectangles)

# Sum over all grids <= 47 x 43
total = 0
for m in range(1, 48):
    for n in range(1, 44):
        total += count_rectangles(m, n)

print(total)

## 3. Hướng dẫn sử dụng mã 

###`build_segments(m, n)`Tạo mọi đoạn đường có thể vẽ được: 

- lưới ngang, 
- lưới dọc, 
- cả hai đường chéo trong mỗi hình vuông. 

Tọa độ được nhân đôi để tránh phân số. 

--- 

###`connected(p, q, segs)`Kiểm tra xem toàn bộ phân đoạn từ$p$ĐẾN$q$nằm trên các đường vẽ. 

Chỉ có bốn hướng được phép: 

- ngang, 
- dọc, 
- độ dốc$+1$, 
- độ dốc$-1$. 

--- 

###`count_rectangles(m, n)`Liệt kê tất cả các hình chữ nhật hợp lệ: 

1. Xây dựng các đỉnh ứng viên. 
2. Cache cặp nào được kết nối. 
3. Chọn hai cạnh vuông góc từ một góc chung. 
4. Hoàn thành đỉnh thứ tư. 
5. Xóa hình chữ nhật trùng lặp.

### Xác minh ví dụ nhỏ 

Mã tái tạo các giá trị đã cho: 

| Lưới | Đếm | 
| --- | --- | 
|$1\times1$| 1 | 
|$2\times1$| 4 | 
|$3\times1$| 8 | 
|$1\times2$| 4 | 
|$2\times2$| 18 | 
|$3\times2$| 37 | 

Tổng hợp tất cả các lưới lên đến$3\times2$:$$1+4+8+4+18+37=72,$$phù hợp chính xác với tuyên bố.
