[Vấn đề dự án Euler 811](https://projecteuler.net/problem=811) 

##Giải pháp 

**Trả lời:**`327287526`Một quan sát quan trọng là phép đệ quy chỉ phụ thuộc vào kiểu chạy 0 giữa các bit 1 của$n$. 

Vì$$n=(2^t+1)^r,$$khi$t$đủ lớn (và ở đây$t=10^{14}+31$), các khối nhị phân đến từ khai triển nhị thức$$(1+2^t)^r=\sum_{k=0}^r \binom{r}{k}2^{kt}$$không chồng chéo lên nhau. Do đó, vị trí 1 bit của$n$thu được trực tiếp từ việc khai triển nhị phân của các hệ số nhị thức. 

Sử dụng kết quả đánh giá dạng đóng của$A(n)$, người ta có thể tính toán$$H(10^{14}+31,62)\pmod{1\,000\,062\,031}.$$Chương trình Python sau đây đánh giá nó một cách hiệu quả:```python
MOD = 1_000_062_031

def b(n):
    return n & -n

def max_binom_bitlen(r):
    c = 1
    mx = 1
    for k in range(r + 1):
        mx = max(mx, c.bit_length())
        if k < r:
            c = c * (r - k) // (k + 1)
    return mx

def one_positions_via_binom(t, r):
    pos = []
    c = 1
    for k in range(r + 1):
        x = c
        while x:
            lsb = x & -x
            bit = lsb.bit_length() - 1
            pos.append(k * t + bit)
            x -= lsb
        if k < r:
            c = c * (r - k) // (k + 1)
    return pos

def A_from_positions(pos, mod):
    m = len(pos)

    v = [0] * m
    v[0] = 1
    for k in range(1, m):
        v[k] = (5 * v[k - 1] + 3) % mod

    ans = 1
    desc = pos[::-1]

    for i in range(m - 1):
        gap = desc[i] - desc[i + 1] - 1
        if gap > 0:
            ans = ans * pow(v[i + 1], gap, mod) % mod

    return ans

def H(t, r, mod):
    pos = one_positions_via_binom(t, r)
    return A_from_positions(pos, mod)

print(H(10**14 + 31, 62, MOD))
```Xác minh đối với mẫu:$$H(3,2)=A(81)=636056,$$mà chương trình tái tạo chính xác.
