[Vấn đề dự án Euler 412](https://projecteuler.net/problem=412) 

##Giải pháp 

**Trả lời:**`38788800`Cho phép$a=m-n$. 

Hình dạng$L(m,n)$là$m\times m$hình vuông với phía trên bên phải$n\times n$hình vuông bị loại bỏ. 

Nếu chúng ta xoay sơ đồ theo$180^\circ$, điều kiện 

- mỗi mục nhỏ hơn mục bên dưới và bên trái của nó 

trở thành điều kiện hoạt cảnh Young tiêu chuẩn 

- các mục tăng dần sang phải và hướng xuống dưới. 

Vì thế$\operatorname{LC}(m,n)$chính xác là số lượng hoạt cảnh Young tiêu chuẩn của phân vùng$$\lambda=(\underbrace{m,\dots,m}_{a\text{ rows}}, \underbrace{a,\dots,a}_{n\text{ rows}}).$$Tổng số tế bào là$$|\lambda|=m^2-n^2.$$Vì vậy chúng ta có thể sử dụng công thức độ dài móc thông thường:$$f^\lambda=\frac{(|\lambda|)!}{\prod_{c\in\lambda} h(c)}.$$--- 

#1. Chiều dài móc 

Chia sơ đồ thành ba vùng. 

Để hàng và cột bắt đầu từ$1$. 

## Vùng A:$1\le i\le a,\ 1\le j\le a$Những ô này nằm ở phía trên bên trái$a\times a$khối. 

Chiều dài móc của chúng là$$h(i,j)=2m-i-j+1.$$Để cố định$i$,$$\prod_{j=1}^{a} h(i,j) = \frac{(2m-i)!}{(m+n-i)!}.$$--- 

## Vùng B:$1\le i\le a,\ a<j\le m$Đây là các ô hình chữ nhật phía trên bên phải. 

Chiều dài móc của chúng là$$h(i,j)=2m-n-i-j+1.$$Để cố định$i$,$$\prod_{j=a+1}^{m} h(i,j) = \frac{(m-i)!}{(a-i)!}.$$--- 

## Vùng C:$a<i\le m,\ 1\le j\le a$Đây là những ô phía dưới bên trái. 

Chiều dài móc của họ lại là$$h(i,j)=2m-n-i-j+1.$$Viết$i=a+k$($1\le k\le n$),$$\prod_{j=1}^{a} h(i,j) = \frac{(m-k)!}{(n-k)!}.$$--- 

Kết hợp mọi thứ:$$\boxed{ \operatorname{LC}(m,n) = \frac{(m^2-n^2)!}{ \left( \prod_{i=1}^{a} \frac{(2m-i)!}{(m+n-i)!} \frac{(m-i)!}{(a-i)!} \right) \left( \prod_{k=1}^{n} \frac{(m-k)!}{(n-k)!} \right) } }$$với$a=m-n$.

#2. Thủ thuật số học mô-đun 

Chúng tôi cần$$\operatorname{LC}(10000,5000)\pmod{76543217}.$$Cho phép$$p=76543217.$$Hóa ra$p$là nguyên tố. 

Cũng,$$10000^2-5000^2=75\,000\,000 < p.$$Vì vậy mọi số hạng mẫu số đều khả nghịch modulo$p$. 

Giai thừa lớn duy nhất là$$75\,000\,000!.$$Sử dụng định lý Wilson:$$(p-1)! \equiv -1 \pmod p.$$Kể từ đây$$N! \equiv -\left(\prod_{k=N+1}^{p-1} k\right)^{-1} \pmod p,$$Ở đâu$$N=75\,000\,000.$$Chiều dài đuôi chỉ$$p-1-N = 1\,543\,216,$$đó là rất dễ quản lý.

#3. Triển khai Python```python
MOD = 76543217

m = 10000
n = 5000
a = m - n

# Total number of cells
N = m * m - n * n

# ------------------------------------------------------------
# Compute N! mod MOD using Wilson's theorem
#
# (MOD-1)! = -1 (mod MOD)
#
# Therefore:
# N! = -1 / product(N+1 ... MOD-1)
# ------------------------------------------------------------

tail = 1
for x in range(N + 1, MOD):
    tail = (tail * x) % MOD

num = (-pow(tail, MOD - 2, MOD)) % MOD

# ------------------------------------------------------------
# Precompute factorials up to 2m
# ------------------------------------------------------------

limit = 2 * m

fac = [1] * (limit + 1)
for i in range(1, limit + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (limit + 1)
invfac[limit] = pow(fac[limit], MOD - 2, MOD)

for i in range(limit, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

# ------------------------------------------------------------
# Compute hook product denominator
# ------------------------------------------------------------

den = 1

# Region A and Region B
for i in range(1, a + 1):

    # (2m-i)! / (m+n-i)!
    den = den * fac[2 * m - i] % MOD
    den = den * invfac[m + n - i] % MOD

    # (m-i)! / (a-i)!
    den = den * fac[m - i] % MOD
    den = den * invfac[a - i] % MOD

# Region C
for k in range(1, n + 1):

    # (m-k)! / (n-k)!
    den = den * fac[m - k] % MOD
    den = den * invfac[n - k] % MOD

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

answer = num * pow(den, MOD - 2, MOD) % MOD

print(answer)
```---
