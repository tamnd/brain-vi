[Vấn đề dự án Euler 487](https://projecteuler.net/problem=487) 

## Giải pháp 

**Trả lời:**`106650212746`Cho phép$$f_k(n)=\sum_{i=1}^n i^k, \qquad S_k(n)=\sum_{i=1}^n f_k(i).$$Chúng tôi cần$$\sum_{p} \left(S_{10000}(10^{12}) \bmod p\right),$$Ở đâu$p$chạy qua tất cả các số nguyên tố trong$$2\cdot 10^9 < p < 2\cdot 10^9+2000.$$Có 100 số nguyên tố như vậy. 

--- 

# 1. Phân tích toán học 

## Bước 1: Viết lại$S_k(n)$Mở rộng định nghĩa:$$S_k(n)=\sum_{i=1}^n \sum_{j=1}^i j^k.$$Hoán đổi thứ tự tính tổng:$$S_k(n)=\sum_{j=1}^n (n-j+1)j^k.$$Kể từ đây$$S_k(n) = (n+1)\sum_{j=1}^n j^k-\sum_{j=1}^n j^{k+1}.$$Vì thế:$$S_k(n)=(n+1)f_k(n)-f_{k+1}(n).$$Điều này ngay lập tức cho thấy rằng$S_k(n)$là một đa thức trong$n$mức độ$k+2$. 

Vì$k=10000$, mức độ là$10002$. 

--- 

## Bước 2: Nội suy đa thức modulo a số nguyên tố 

Đối với số nguyên tố cố định$p$, định nghĩa$$P(n)=S_{10000}(n)\pmod p.$$Từ$P(n)$là một đa thức bậc$10002$, biết giá trị của nó tại$$0,1,2,\dots,10002$$xác định nó hoàn toàn theo modulo$p$. 

Vì mọi số nguyên tố ở đây đều thỏa mãn$$p > 2\cdot 10^9 \gg 10002,$$tất cả các mẫu số giai thừa trong phép nội suy Lagrange đều là modulo khả nghịch$p$. 

Như vậy chúng ta có thể đánh giá$P(10^{12})$modulo$p$sử dụng phép nội suy Lagrange tiêu chuẩn trên các điểm liên tiếp. 

--- 

## Bước 3: Xây dựng bảng nội suy 

Ta tính tuần tự:$$f(i)=f(i-1)+i^{10000},$$và sau đó$$S(i)=S(i-1)+f(i).$$Cửa hàng$$y_i=S(i)\pmod p$$vì$0\le i\le10002$. 

Sau đó tính đa thức tại$x=10^{12}\bmod p$. 

Độ phức tạp trên mỗi số nguyên tố: 

-$10002$lũy thừa mô đun, 
-$O(10002)$nội suy. 

Chỉ với 100 số nguyên tố, điều này có thể dễ dàng thực hiện được. 

--- 

#2. Triển khai Python```python
from sympy import primerange

K = 10000
N = 10**12
D = K + 2   # degree of S_k(n)

# ------------------------------------------------------------
# Lagrange interpolation on points x = 0,1,2,...,D
# y[i] = polynomial value at i
# Evaluates polynomial at x modulo mod.
# ------------------------------------------------------------
def lagrange(y, x, mod):
    n = len(y) - 1

    # If x is already one of the known points
    if x <= n:
        return y[x] % mod

    # factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % mod

    # inverse factorials
    ifact = [1] * (n + 1)
    ifact[n] = pow(fact[n], mod - 2, mod)

    for i in range(n, 0, -1):
        ifact[i - 1] = ifact[i] * i % mod

    # prefix products:
    # pre[i] = (x)(x-1)...(x-(i-1))
    pre = [1] * (n + 2)
    for i in range(n + 1):
        pre[i + 1] = pre[i] * (x - i) % mod

    # suffix products:
    # suf[i] = (x-i)(x-(i+1))...(x-n)
    suf = [1] * (n + 2)
    for i in range(n, -1, -1):
        suf[i] = suf[i + 1] * (x - i) % mod

    ans = 0

    for i, yi in enumerate(y):
        # numerator product excluding (x-i)
        num = pre[i] * suf[i + 1] % mod

        # denominator inverse
        den = ifact[i] * ifact[n - i] % mod

        # sign from (-1)^(n-i)
        if (n - i) & 1:
            den = mod - den

        ans = (ans + yi * num % mod * den) % mod

    return ans

def compute():
    total = 0

    # primes in (2e9, 2e9+2000)
    primes = list(primerange(2_000_000_000, 2_000_002_000))

    for p in primes:

        # y[i] = S_K(i) mod p
        y = [0] * (D + 1)

        fk = 0
        sk = 0

        for i in range(1, D + 1):
            fk = (fk + pow(i, K, p)) % p
            sk = (sk + fk) % p
            y[i] = sk

        value = lagrange(y, N % p, p)

        total += value

    return total

print(compute())

## Xây dựng các giá trị đa thức```python
fk = (fk + pow(i, K, p)) % p
```Duy trì$$f_K(i)=\sum_{j=1}^i j^K \pmod p.$$Sau đó```python
sk = (sk + fk) % p
```duy trì$$S_K(i)=\sum_{t=1}^i f_K(t)\pmod p.$$Các giá trị này được lưu trữ để nội suy.

## Nội suy Lagrange 

Vì bậc đa thức là$10002$, giá trị tại$$0,1,\dots,10002$$xác định nó một cách duy nhất. 

Công thức nội suy là$$P(x)=\sum_{i=0}^{n} y_i \prod_{j\ne i} \frac{x-j}{i-j}.$$Việc sử dụng các tích số giai thừa và tiền tố/hậu tố giúp giảm việc đánh giá về thời gian tuyến tính.
