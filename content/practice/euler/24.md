## Giải pháp 

**Trả lời:**`2783915460`Để tìm hoán vị từ điển thứ một triệu của các chữ số`0–9`, chúng tôi sử dụng **hệ thống số giai thừa** thay vì tạo ra tất cả`10! = 3,628,800`hoán vị. 

Chúng tôi muốn hoán vị **1.000.000**, nhưng lập chỉ mục từ`0`làm cho việc tính toán trở nên dễ dàng hơn:$$999,999$$Ở mỗi bước, xác định chữ số nào ở vị trí tiếp theo bằng cách sử dụng khối giai thừa: 

-$9! = 362880$:$999999 \div 362880 = 2$phần còn lại$274239$→ chọn chữ số thứ 3:`2`Các chữ số còn lại:`0,1,3,4,5,6,7,8,9`-$8! = 40320$:$274239 \div 40320 = 6$phần còn lại$32319$→ chọn`7`Còn lại:`0,1,3,4,5,6,8,9`-$7! = 5040$:$32319 \div 5040 = 6$phần còn lại$2079$→ chọn`8`Tiếp tục quá trình này mang lại:`2783915460`### Mã Python sạch```python
from math import factorial

digits = list("0123456789")
n = 999999  # zero-based index

result = []

for i in range(9, -1, -1):
    f = factorial(i)
    index = n // f
    result.append(digits.pop(index))
    n %= f

answer = "".join(result)
print(answer)
```Truy tìm lựa chọn giai thừa xác nhận hoán vị:`2783915460`**Trả lời: 2783915460**
