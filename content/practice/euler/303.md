## Giải pháp 

**Trả lời:**`1111981904675169`Cho phép$$f(n)=\text{the smallest positive multiple of }n$$có phần mở rộng thập phân chỉ sử dụng các chữ số$0,1,2$. 

Chúng ta phải tính toán$$\sum_{n=1}^{10000}\frac{f(n)}{n}.$$--- 

# Phân tích toán học 

Quan sát quan trọng là về cơ bản đây là vấn đề **đường dẫn ngắn nhất/BFS trên phần dư**. 

--- 

## 1. Định dạng lại điều kiện 

Giả sử một số$x$chỉ sử dụng chữ số$0,1,2$. 

Chúng tôi muốn:$$x \equiv 0 \pmod n.$$Thay vì xây dựng trực tiếp các số nguyên lớn, chúng ta tính modulo$n$. 

Nếu hiện tại chúng ta có một số có số dư$r$, sau đó thêm một chữ số$d\in\{0,1,2\}$tạo ra phần dư mới$$r'=(10r+d)\bmod n.$$Do đó, mỗi phần còn lại là một nút trong biểu đồ: 

- đỉnh:$0,1,\dots,n-1$, 
- các cạnh:$$r \to (10r+d)\bmod n,\qquad d\in\{0,1,2\}.$$Chúng tôi tìm kiếm **số thập phân nhỏ nhất** (theo thứ tự từ điển/độ dài) đạt phần dư$0$. 

--- 

## 2. Tại sao BFS đưa ra số lượng tối thiểu 

Tìm kiếm theo chiều rộng khám phá các trạng thái bằng cách: 

1. chiều dài ngắn nhất trước tiên, 
2. trong cùng độ dài, thứ tự chữ số. 

Nếu chúng ta xếp các chữ số theo thứ tự$$0,1,2,$$sau khi bắt đầu từ$1$Và$2$, thì lần đầu tiên chúng ta đạt được số dư$0$chúng tôi có chính xác số hợp lệ nhỏ nhất. 

Điều này hoạt động vì so sánh thập phân tương đương với: 

1. ít chữ số hơn, 
2. nhỏ hơn về mặt từ điển trong số các số có độ dài bằng nhau. 

--- 

## 3. Xây dựng lại số 

Trong BFS chúng tôi lưu trữ: 

- phần còn lại trước đó, 
- chữ số được thêm vào. 

Sau đó khi còn lại$0$đạt được, chúng ta quay lại để xây dựng lại chuỗi thập phân. 

Cuối cùng:$$\frac{f(n)}{n}$$là một số nguyên nên chúng ta tính trực tiếp và tính tổng. 

--- 

#Triển khai Python```python
from collections import deque

def quotient(n):
    """
    Returns f(n) / n, where f(n) is the smallest positive
    multiple of n using only digits 0,1,2.
    """

    # Special case
    if n == 1:
        return 1

    # parent[r] = previous remainder used to reach r
    # digit[r]  = digit appended to reach r
    parent = [-2] * n
    digit = [''] * n

    q = deque()

    # Starting numbers: 1 and 2
    for d in [1, 2]:
        r = d % n

        if parent[r] == -2:
            parent[r] = -1
            digit[r] = str(d)
            q.append(r)

    # BFS over remainders
    while q:
        r = q.popleft()

        # Found divisible number
        if r == 0:
            break

        # Append digits 0,1,2
        for d in [0, 1, 2]:
            nr = (10 * r + d) % n

            if parent[nr] == -2:
                parent[nr] = r
                digit[nr] = str(d)
                q.append(nr)

    # Reconstruct the minimal number
    chars = []
    cur = 0

    while cur != -1:
        chars.append(digit[cur])
        cur = parent[cur]

    s = ''.join(reversed(chars))

    # Return f(n)/n
    return int(s) // n

# Compute the required sum
total = sum(quotient(n) for n in range(1, 10001))

print(total)
```--- 

# Hướng dẫn sử dụng mã 

## Khởi tạo```python
parent = [-2] * n
digit = [''] * n
```Các mảng này lưu trữ cây BFS. 

-`parent[r]`cho chúng ta biết phần còn lại trước đó, 
-`digit[r]`cho chúng ta biết chữ số nào đã được thêm vào. 

Một giá trị`-2`có nghĩa là “không được thăm viếng”.

## Tại sao điều này lại hiệu quả 

Đối với mỗi$n$: 

- chỉ có$n$số dư có thể có, 
- mỗi phần còn lại được truy cập một lần, 
- mỗi lượt truy cập thử 3 chữ số. 

Vì vậy độ phức tạp xấp xỉ:$$O(n)$$mỗi giá trị của$n$. 

Vì$n\le 10000$, cái này chạy nhanh thoải mái.
