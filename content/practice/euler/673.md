[Vấn đề dự án Euler 673](https://projecteuler.net/problem=673) 

## Giải pháp 

**Trả lời:**`700325380`Cho phép$B$là sự kết hợp mô tả cách sắp xếp giường và$D$phần involution mô tả cách sắp xếp bàn làm việc. 

- Nếu học sinh$a,b$là bạn cùng phòng, vậy$B(a)=b$Và$B(b)=a$. 
- Nếu học sinh$a$có phòng riêng rồi$B(a)=a$. 

Tương tự đối với bàn làm việc sử dụng$D$. 

Phép gán mới là một hoán vị$\sigma$. 

điều kiện 

> “Bạn cùng phòng vẫn là bạn cùng phòng” 

có nghĩa là:$$B(\sigma(k))=\sigma(B(k))$$cho mọi$k$, tức là$$\sigma B = B\sigma.$$Tương tự như vậy, các đối tác cùng bàn còn lại cùng nhau sẽ mang lại$$\sigma D = D\sigma.$$Vì vậy chúng ta phải tính các hoán vị đi lại đồng thời với hai phép biến đổi$B,D$. 

--- 

#1. Cấu trúc của đồ thị 

Xét đồ thị của học sinh trong đó mỗi đỉnh có: 

- một "cạnh giường" (có thể là một vòng lặp), 
- một “cạnh bàn” (có thể là một vòng lặp). 

Bởi vì cả hai$B$Và$D$là các involutions, mỗi thành phần được kết nối là một trong hai loại: 

## Loại A - chu kỳ xen kẽ 

Không có vòng lặp nào xảy ra. 

Các cạnh xen kẽ$B,D,B,D,\dots$, do đó thành phần là một chu trình chẵn có độ dài$2m$. 

Ví dụ:$$1 \xleftrightarrow{B} 2 \xleftrightarrow{D} 3 \xleftrightarrow{B} 4 \xleftrightarrow{D} 1.$$Kích thước nhóm tự động:$$2m$$(các phép quay bảo toàn màu sắc của cạnh). 

--- 

## Loại B - đường dẫn xen kẽ 

Ít nhất một vòng lặp xảy ra. 

Thành phần này trở thành một đường dẫn với các màu cạnh xen kẽ. 

Tùy thuộc vào màu sắc điểm cuối: 

- sự phản ánh có thể được phép hoặc không, 
- kích thước nhóm tự đồng cấu là$1$hoặc$2$. 

Chính xác hơn: 

- đường dẫn có độ dài lẻ: số lượng tự động cấu hình$=1$, 
- các đường dẫn có độ dài chẵn với màu điểm cuối phù hợp: số lượng tự động cấu hình$=2$. 

--- 

#2. Đếm tất cả các hoán vị đi lại 

Bất kỳ hoán vị hợp lệ: 

1. có thể hoán vị toàn bộ các thành phần kết nối đẳng cấu, 
2. bên trong mỗi thành phần có thể áp dụng một trong các tính tự cấu hình của nó. 

Do đó nếu một loại thành phần$T$- xảy ra$m_T$lần, 
- có số lượng tự động cấu hình$a_T$, 

thì đóng góp của nó là$$a_T^{m_T}\cdot m_T!.$$Vì thế:$$\boxed{ \prod_T a_T^{m_T}\,m_T! }$$modulo$999999937$.

#3. Triển khai Python```python
from collections import defaultdict

MOD = 999_999_937

def parse_pairs(filename):
    pairs = []
    with open(filename) as f:
        for line in f:
            line = line.strip()
            if line:
                a, b = map(int, line.split(","))
                pairs.append((a, b))
    return pairs

def count_permutations(n, bed_pairs, desk_pairs):
    # Build involutions
    B = list(range(n + 1))
    D = list(range(n + 1))

    for a, b in bed_pairs:
        B[a] = b
        B[b] = a

    for a, b in desk_pairs:
        D[a] = b
        D[b] = a

    visited = [False] * (n + 1)

    # Count component types
    type_count = defaultdict(int)
    type_aut = {}

    for start in range(1, n + 1):
        if visited[start]:
            continue

        # DFS component
        stack = [start]
        visited[start] = True
        comp = []

        while stack:
            v = stack.pop()
            comp.append(v)

            for u in (B[v], D[v]):
                if not visited[u]:
                    visited[u] = True
                    stack.append(u)

        k = len(comp)

        # Does component contain a loop?
        has_loop = any(B[v] == v or D[v] == v for v in comp)

        if not has_loop:
            # alternating cycle
            key = ("C", k)
            aut = k
        else:
            # alternating path
            if k % 2 == 1:
                # asymmetric
                key = ("P", k, "odd")
                aut = 1
            else:
                # possible reflection symmetry
                endpoint_type = "mixed"

                for v in comp:
                    if B[v] == v and D[v] != v:
                        endpoint_type = "B"
                        break
                    if D[v] == v and B[v] != v:
                        endpoint_type = "D"
                        break

                key = ("P", k, endpoint_type)
                aut = 2

        type_count[key] += 1
        type_aut[key] = aut

    # factorials
    fact = [1] * (n + 1)
    for i in range(2, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    ans = 1

    for key, m in type_count.items():
        ans = ans * pow(type_aut[key], m, MOD) % MOD
        ans = ans * fact[m] % MOD

    return ans

# -------------------------
# Verification examples
# -------------------------

# n = 4 example
beds = [(2, 3)]
desks = [(1, 3), (2, 4)]
print(count_permutations(4, beds, desks))
# 2

# n = 6 example
beds = [(1, 2), (3, 4), (5, 6)]
desks = [(3, 6), (4, 5)]
print(count_permutations(6, beds, desks))
# 8
```---
