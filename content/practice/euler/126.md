[Bài toán Euler dự án 126](https://projecteuler.net/problem=126) 

## Giải pháp 

**Trả lời:**`18522`Gọi kích thước hình hộp chữ nhật là$a \times b \times c$với$a \ge b \ge c \ge 1$, và để$L_k(a,b,c)$biểu thị số hình khối trong$k$-lớp thứ bao quanh hình hộp chữ nhật. 

Chúng ta được yêu cầu tìm ít nhất$n$chính xác như vậy$1000$sử dụng hình khối/lớp riêng biệt$n$hình khối. 

--- 

# 1. Phân tích toán học 

## Lớp đầu tiên 

Đối với hình hộp chữ nhật$a\times b\times c$, lớp đầu tiên bao phủ mọi khuôn mặt nhìn thấy được. 

Một hình hộp chữ nhật đặc có diện tích bề mặt$$2(ab+bc+ca)$$vì vậy lớp đầu tiên yêu cầu$$L_1 = 2(ab+bc+ca)$$hình khối. 

Ví dụ:$$3\times2\times1$$cho$$2(3\cdot2+2\cdot1+3\cdot1)=2(6+2+3)=22$$phù hợp với phát biểu vấn đề. 

--- 

## Lớp cao hơn 

Khi chúng ta thêm một lớp khác: 

- mọi khuôn mặt lộ ra đều mở rộng, 
- các cạnh góp phần tăng trưởng tuyến tính, 
- các góc đóng góp thêm hình khối. 

Một đạo hàm tiêu chuẩn cho:$$L_k(a,b,c) = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)$$vì$k\ge1$. 

--- 

## Xác minh công thức 

cho$3\times2\times1$: 

### Lớp đầu tiên ($k=1$)$$22$$### Lớp thứ hai ($k=2$)$$22 + 4(1)(3+2+1)+4(1)(0) =22+24 =46$$### Lớp thứ ba ($k=3$)$$22+4(2)(6)+4(2)(1) =22+48+8 =78$$### Lớp thứ tư ($k=4$)$$22+4(3)(6)+4(3)(2) =22+72+24 =118$$tất cả đều phù hợp với tuyên bố vấn đề. 

--- 

# Đếm các biểu diễn 

Chúng tôi xác định$$C(n)$$bằng số lượng bộ ba$(a,b,c,k)$sản xuất chính xác$n$hình khối:$$n = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)$$Chúng ta phải tìm cái nhỏ nhất$n$như vậy$$C(n)=1000.$$--- 

# Giới hạn tìm kiếm 

Chúng tôi tìm kiếm một cách có hệ thống trên: 

-$a \ge b \ge c \ge 1$- số lớp$k\ge1$và tính toán mọi kích thước lớp có thể đạt đến giới hạn đủ lớn. 

Bài toán Project Euler 126 được biết là có đáp án dưới đây$30000$, do đó giới hạn xung quanh$50000$còn hơn cả an toàn. 

Chúng tôi dừng vòng lặp khi lớp nhỏ nhất có thể đã vượt quá giới hạn. 

--- 

#2. Triển khai Python```python
from collections import defaultdict

LIMIT = 50000

# count[n] = number of cuboids/layers producing n cubes
count = defaultdict(int)

# Enumerate cuboid dimensions with a >= b >= c >= 1
for a in range(1, LIMIT):
    
    # Minimum layer for b=c=1
    if 2 * (a + 1 + a) > LIMIT:
        break

    for b in range(1, a + 1):

        # Minimum layer for c=1
        first = 2 * (a*b + a + b)
        if first > LIMIT:
            break

        for c in range(1, b + 1):

            # First layer
            base = 2 * (a*b + a*c + b*c)

            if base > LIMIT:
                break

            k = 1

            while True:
                n = (
                    base
                    + 4*(k-1)*(a+b+c)
                    + 4*(k-1)*(k-2)
                )

                if n > LIMIT:
                    break

                count[n] += 1
                k += 1

# Find smallest n with exactly 1000 representations
answer = min(n for n in count if count[n] == 1000)

print(answer)
```---
