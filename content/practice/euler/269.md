[Vấn đề dự án Euler 269](https://projecteuler.net/problem=269) 

## Giải pháp 

**Trả lời:**`1311109198529286`Cho phép$$P_n(x)=a_mx^m+a_{m-1}x^{m-1}+\cdots+a_0$$Ở đâu$a_ma_{m-1}\cdots a_0$là các chữ số thập phân của$n$. 

Chúng tôi tìm kiếm$$Z(10^{16})$$= số số nguyên dương$n\le 10^{16}$như vậy$P_n(x)$có **ít nhất một gốc số nguyên**. 

--- 

## 1. Phân tích toán học 

### Bước 1: Hạn chế các nghiệm nguyên có thể có 

Vì các hệ số là chữ số$0,\dots,9$, tất cả các hệ số đều không âm và hệ số cao nhất là dương. 

Nếu như$r>0$, sau đó$$P_n(r)>0$$bởi vì mọi số hạng đều không âm và số hạng dẫn đầu là số dương. 

Vì vậy ** gốc tích cực là không thể **. 

Theo định lý nghiệm số nguyên, bất kỳ nghiệm số nguyên nào cũng phải chia cho số hạng không đổi (chữ số cuối cùng), do đó mọi nghiệm số nguyên đều phải nằm trong$$\{0,-1,-2,\dots,-9\}.$$Vì vậy chỉ có **10 gốc ứng cử viên**. 

--- 

### Bước 2: Định dạng lại đánh giá đa thức 

Giả sử các chữ số thập phân của$n$là$$d_1d_2\cdots d_L.$$Sau đó$$P_n(r) = (((d_1r+d_2)r+d_3)\cdots)r+d_L.$$Đây là một sự tái phát của Horner. 

Chúng tôi muốn:$$P_n(r)=0.$$Đối với gốc cố định$r$, xác định trạng thái ngược: 

Nếu sau một số hậu tố chúng ta cần giá trị$t$, thì trạng thái trước đó$p$phải thỏa mãn$$pr+d=t.$$Như vậy$$p=\frac{t-d}{r}.$$Đối với mỗi chữ số$d\in\{0,\dots,9\}$, tiền thân này được xác định duy nhất hoặc không thể xác định được. 

Điều này làm cho lập trình động rất hiệu quả. 

--- 

### Bước 3: Bao gồm-loại trừ 

Chúng ta cần các số mà đa thức của nó có **ít nhất một** nghiệm nguyên trong số$$R=\{0,-1,-2,\dots,-9\}.$$Đối với bất kỳ tập hợp con$S\subseteq R$, cho phép$N(S)$là số số nguyên có đa thức triệt tiêu tại **mọi** căn bậc hai trong$S$. 

Sau đó bằng cách bao gồm-loại trừ:$$Z = \sum_{\emptyset\neq S\subseteq R} (-1)^{|S|+1}N(S).$$chỉ có$$2^{10}-1=1023$$tập con khác rỗng nên điều này là khả thi.

## 2. Triển khai Python```python
from functools import lru_cache

# Candidate integer roots:
# index 0 -> root 0
# index i -> root -i for i=1..9
ROOTS = [0] + [-i for i in range(1, 10)]

cache = {}

def count_subset(mask, length):
    """
    Count length-digit numbers whose polynomial
    vanishes at every root specified by 'mask'.
    """

    key = (mask, length)
    if key in cache:
        return cache[key]

    # Root 0 means last digit must be 0
    need_zero_root = (mask & 1) != 0

    # Negative roots included in this subset
    roots = [-i for i in range(1, 10) if (mask >> i) & 1]

    @lru_cache(None)
    def dp(rem_digits, targets):
        """
        rem_digits = number of digits still to place
        targets = tuple of required evaluation states
                  for each root
        """
        if rem_digits == 0:
            return 1 if all(t == 0 for t in targets) else 0

        total = 0

        for d in range(10):

            # Leading digit cannot be zero
            if rem_digits == 1 and d == 0:
                continue

            # Root 0 condition: LSD must be zero
            if need_zero_root and rem_digits == length and d != 0:
                continue

            prev_states = []
            ok = True

            # Backward transition:
            # p * r + d = target
            for r, t in zip(roots, targets):
                numerator = t - d

                if numerator % r != 0:
                    ok = False
                    break

                prev_states.append(numerator // r)

            if ok:
                total += dp(rem_digits - 1, tuple(prev_states))

        return total

    result = dp(length, tuple([0] * len(roots)))
    cache[key] = result
    return result

def compute_Z(limit_power):
    total = 0

    # Count numbers < 10^limit_power
    for length in range(1, limit_power + 1):
        union_count = 0

        for mask in range(1, 1 << 10):
            c = count_subset(mask, length)

            # Inclusion–exclusion
            if mask.bit_count() % 2 == 1:
                union_count += c
            else:
                union_count -= c

        total += union_count

    # Add 10^16 itself
    # P_{10^16}(x) = x^16, root x=0
    total += 1

    return total

print(compute_Z(16))

## 3. Hướng dẫn sử dụng mã 

### Nguồn gốc ứng viên 

Chúng tôi chỉ kiểm tra$$0,-1,-2,\dots,-9$$bởi vì không có nghiệm số nguyên nào khác có thể xảy ra. 

###`count_subset(mask, length)`Điều này được tính$L$-các số có đa thức biến mất tại **tất cả các nghiệm trong một tập hợp con**. 

Một bitmask mã hóa tập hợp con. 

Ví dụ: 

- bit 0 → gốc$0$- bit 1 → gốc$-1$- bit 2 → gốc$-2$v.v. 

### Lập trình động 

Chúng ta xây dựng số **ngược lại từ chữ số có nghĩa nhỏ nhất**. 

Giả sử hiện tại chúng tôi yêu cầu:$$P(r)=t.$$Chọn chữ số$d$buộc trạng thái trước đó:$$p=\frac{t-d}{r}.$$Nếu không chia hết thì chữ số đó không thể chia được. 

Ghi nhớ làm cho các trạng thái lặp lại cực kỳ nhanh chóng. 

### Bao gồm-loại trừ 

Chúng ta tính tổng tất cả các tập con khác rỗng:$$\sum (-1)^{|S|+1}N(S).$$Điều này đếm chính xác các số có **ít nhất một** gốc số nguyên.
