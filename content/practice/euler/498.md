[Vấn đề dự án Euler 498](https://projecteuler.net/problem=498) 

##Giải pháp 

**Trả lời:**`472294837`Cho phép$$F_n(x)=x^n,\qquad G_m(x)=(x-1)^m.$$Chúng tôi xác định$R_{n,m}(x)$là số dư khi$x^n$được chia cho$(x-1)^m$. Vì số chia có bậc$m$, phần còn lại có nhiều nhất là bậc$m-1$. 

Chúng ta tìm giá trị tuyệt đối của hệ số của$x^d$TRONG$R_{n,m}(x)$:$$C(n,m,d).$$Chúng tôi được yêu cầu tính toán$$C(10^{13},10^{12},10^4)\pmod{999999937}.$$--- 

# 1. Phân tích toán học 

Chúng tôi làm việc quanh điểm$x=1$. 

Định nghĩa$$y=x-1 \quad\Longrightarrow\quad x=1+y.$$Sau đó$$x^n=(1+y)^n.$$Modulo$y^m$, chỉ là cái đầu tiên$m$các số hạng của khai triển nhị thức tồn tại:$$R_{n,m}(x) = \sum_{k=0}^{m-1}\binom{n}{k}(x-1)^k.$$Vậy hệ số của$x^d$là$$a_d = \sum_{k=d}^{m-1}\binom{n}{k}[x^d](x-1)^k.$$Bây giờ mở rộng:$$(x-1)^k = \sum_{j=0}^k \binom{k}{j}x^j(-1)^{k-j}.$$Kể từ đây$$[x^d](x-1)^k = (-1)^{k-d}\binom{k}{d}.$$Vì thế$$a_d = \sum_{k=d}^{m-1} (-1)^{k-d}\binom{n}{k}\binom{k}{d}.$$--- 

## Đơn giản hóa tổng 

Sử dụng danh tính$$\binom{n}{k}\binom{k}{d} = \binom{n}{d}\binom{n-d}{k-d}.$$Cho phép$j=k-d$. Sau đó$$a_d = \binom{n}{d} \sum_{j=0}^{m-1-d} (-1)^j \binom{n-d}{j}.$$Bây giờ áp dụng danh tính nhị thức xen kẽ$$\sum_{j=0}^{r}(-1)^j\binom{N}{j} = (-1)^r\binom{N-1}{r}.$$Với$$N=n-d,\qquad r=m-1-d,$$chúng tôi nhận được$$a_d = (-1)^{m-1-d} \binom{n}{d} \binom{n-d-1}{m-d-1}.$$Từ$C(n,m,d)$là giá trị tuyệt đối,$$\boxed{ C(n,m,d) = \binom{n}{d} \binom{n-d-1}{m-d-1}. }$$--- 

## Kiểm tra lại các ví dụ 

### Ví dụ 1$$C(6,3,1) = \binom61\binom41 = 6\cdot4 = 24.$$Chính xác. 

--- 

### Ví dụ 2$$C(100,10,4) = \binom{100}{4}\binom{95}{5}.$$Điều này bằng$$227197811615775,$$phù hợp với phát biểu vấn đề.

# 2. Tính toán mô-đun 

Chúng tôi cần$$\binom{10^{13}}{10^4} \binom{10^{13}-10^4-1}{10^{12}-10^4-1} \pmod p,$$Ở đâu$$p=999999937.$$Từ$p$là số nguyên tố nên ta sử dụng định lý Lucas. 

--- 

## Phân hủy Lucas 

Viết số vào cơ số$p$. 

###Yếu tố đầu tiên$$10^{13}=10000\cdot p + 630000,$$Vì thế$$\binom{10^{13}}{10^4} \equiv \binom{10000}{0} \binom{630000}{10000} \pmod p.$$Như vậy$$\binom{10^{13}}{10^4} \equiv \binom{630000}{10000}.$$--- 

### Yếu tố thứ hai$$10^{13}-10^4-1 = 10000\cdot p + 619999,$$Và$$10^{12}-10^4-1 = 1000\cdot p + 52999.$$Kể từ đây$$\binom{10^{13}-10^4-1}{10^{12}-10^4-1} \equiv \binom{10000}{1000} \binom{619999}{52999} \pmod p.$$Vì thế$$C \equiv \binom{630000}{10000} \binom{10000}{1000} \binom{619999}{52999} \pmod p.$$Đây là tất cả các kết hợp thông thường dưới đây$p$, có thể tính được với giai thừa và nghịch đảo Fermat. 

--- 

#3. Triển khai Python```python
MOD = 999999937

def mod_comb(n, r, mod):
    """Compute C(n,r) mod prime mod."""
    if r < 0 or r > n:
        return 0

    r = min(r, n - r)

    numerator = 1
    denominator = 1

    for i in range(1, r + 1):
        numerator = (numerator * (n - r + i)) % mod
        denominator = (denominator * i) % mod

    return numerator * pow(denominator, mod - 2, mod) % mod

# Problem values
n = 10**13
m = 10**12
d = 10**4

# Lucas reductions already derived mathematically
a = mod_comb(630000, 10000, MOD)
b = mod_comb(10000, 1000, MOD)
c = mod_comb(619999, 52999, MOD)

answer = (a * b % MOD) * c % MOD

print(answer)
```--- 

#4. Hướng dẫn code 

##`mod_comb`Điều này tính toán$$\binom{n}{r}\pmod p$$sử dụng$$\binom{n}{r} = \frac{n(n-1)\cdots(n-r+1)}{r!}.$$Bởi vì$p$là số nguyên tố, chúng ta chia modulo$p$sử dụng định lý Fermat:$$a^{-1}\equiv a^{p-2}\pmod p.$$--- 

## Tính toán chính 

Chúng tôi sử dụng các mức giảm Lucas được rút ra ở trên:```python
a = mod_comb(630000, 10000, MOD)
b = mod_comb(10000, 1000, MOD)
c = mod_comb(619999, 52999, MOD)
```Sau đó```python
answer = (a * b % MOD) * c % MOD
```mang lại giá trị mong muốn.
