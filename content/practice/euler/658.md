[Vấn đề dự án Euler 658](https://projecteuler.net/problem=658) 

##Giải pháp 

**Trả lời:**`958280177`Cho phép$$I(\alpha,n)=\#\{\text{incomplete words over an alphabet of size }\alpha\text{ with length }\le n\}.$$chúng tôi muốn$$S(k,n)=\sum_{\alpha=1}^k I(\alpha,n)$$vì$k=10^7,\ n=10^{12}$, modulo$M=10^9+7$. 

--- 

##1. Đếm các từ chưa hoàn chỉnh 

Sửa một bảng chữ cái có kích thước$\alpha$. 

Đối với một chiều dài cố định$m$, tổng số từ là$\alpha^m$. 

Một từ hoàn chỉnh nếu mỗi chữ cái xuất hiện ít nhất một lần. Bằng cách bao gồm-loại trừ,$$\#\{\text{complete words of length }m\} = \sum_{j=0}^{\alpha}(-1)^j\binom{\alpha}{j}(\alpha-j)^m.$$Do đó số lượng từ không đầy đủ có độ dài$m$là$$\alpha^m- \sum_{j=0}^{\alpha}(-1)^j\binom{\alpha}{j}(\alpha-j)^m.$$Sau khi đơn giản hóa,$$\#\{\text{incomplete words of length }m\} = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}j^m.$$Kể từ đây$$I(\alpha,n) = \sum_{m=0}^{n} \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}j^m.$$Hoán đổi số tiền:$$I(\alpha,n) = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j} \sum_{m=0}^{n}j^m.$$Định nghĩa$$G_n(j)=\sum_{m=0}^{n}j^m.$$Sau đó$$I(\alpha,n) = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}G_n(j).$$--- 

##2. Tính tổng tất cả các kích thước bảng chữ cái 

Bây giờ tổng hợp lại$\alpha\le k$:$$S(k,n) = \sum_{\alpha=1}^{k} \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}G_n(j).$$Hoán đổi thứ tự một lần nữa:$$S(k,n) = \sum_{j=0}^{k-1} G_n(j) \sum_{\alpha=j+1}^{k} (-1)^{\alpha-j+1}\binom{\alpha}{j}.$$Định nghĩa$$c_{k,j} = \sum_{\alpha=j+1}^{k} (-1)^{\alpha-j+1}\binom{\alpha}{j}.$$Sử dụng các hàm tạo, người ta nhận được$$\sum_{j\ge0} c_{k,j}x^j = \frac{1+(-1)^{k+1}(1-x)^{k+2}} {(1-x)(2-x)}.$$Điều này mang lại một sự tái diễn tuyến tính cho các hệ số$c_{k,j}$, cho phép tất cả các hệ số được tạo ra trong$O(k)$. 

Cũng,$$G_n(j)= \begin{cases} n+1,& j=1,\\[4pt] \dfrac{j^{n+1}-1}{j-1},& j\ne1. \end{cases}$$Từ$n=10^{12}$, mỗi lũy thừa được tính theo lũy thừa mô-đun nhanh. 

Thuật toán hoàn chỉnh chạy trong$O(k\log n)$, khả thi đối với$k=10^7$.

## 3. Triển khai Python```python
MOD = 10**9 + 7

def solve(k, n):
    inv = [1] * (k + 3)
    inv[1] = 1
    for i in range(2, k + 3):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    # coefficients c_j generated from
    # (2 - x)C(x) = 1 + (-1)^(k+1)(1-x)^(k+2)

    c = [0] * (k + 1)

    sign = -1 if (k + 1) & 1 else 1

    # constant term
    rhs0 = 1 + sign
    c[0] = rhs0 * inv[2] % MOD

    # recurrence:
    # 2*c_j - c_{j-1} = sign * (-1)^j * C(k+2, j)

    comb = 1

    for j in range(1, k):
        comb = comb * (k + 3 - j) % MOD
        comb = comb * inv[j] % MOD

        rhs = comb
        if (j & 1):
            rhs = MOD - rhs

        if sign == -1:
            rhs = MOD - rhs

        c[j] = (c[j - 1] + rhs) * inv[2] % MOD

    ans = 0

    for j in range(k):
        coeff = c[j]

        if j == 0:
            g = 1
        elif j == 1:
            g = (n + 1) % MOD
        else:
            g = (pow(j, n + 1, MOD) - 1) % MOD
            g = g * inv[j - 1] % MOD

        ans = (ans + coeff * g) % MOD

    return ans

print(solve(10**7, 10**12))
```---
