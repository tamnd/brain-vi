##Giải pháp 

**Trả lời:**`356019862`Cho phép$$P(n)=n^4+an^3+bn^2+cn.$$Chúng tôi tìm kiếm số nguyên lớn nhất$m$như vậy$P(n)\equiv 0\pmod m$cho **tất cả** số nguyên$n$. 

--- 

# 1. Phân tích toán học 

## Bước 1: Đặc điểm$M(a,b,c)$Một thực tế tiêu chuẩn về đa thức có giá trị nguyên là: 

> Gcd của tất cả các giá trị của đa thức trên các số nguyên bằng gcd của hiệu số thuận của nó tại$0$. 

Tính toán sự khác biệt về phía trước của$P(n)$:$$\Delta P(0)=1+a+b+c,$$

$$\Delta^2 P(0)=14+6a+2b,$$

$$\Delta^3 P(0)=36+6a,$$

$$\Delta^4 P(0)=24.$$Vì thế$$M(a,b,c)=\gcd(1+a+b+c,\ 14+6a+2b,\ 36+6a,\ 24).$$Vì thế$M(a,b,c)$luôn luôn chia rẽ$24$. 

Kể từ đây$M$chỉ phụ thuộc vào$a,b,c \pmod{24}$. 

--- 

## Bước 2: Tính tuần hoàn của$M$Vì chỉ có dư lượng modulo$24$vấn đề,$$M(a+24,b,c)=M(a,b,c)$$(và tương tự cho$b,c$). 

Như vậy$S(N)$là một giả đa thức bậc ba có dấu chấm$24$. 

Viết$$N=24q+r,\qquad 0\le r<24.$$Đối với mỗi loại dư lượng$t\in\{1,\dots,24\}$, số số nguyên$\le N$phù hợp với$t\pmod{24}$là một trong hai$q$hoặc$q+1$. 

Tổng hợp các lớp dư lượng cho$$S(N)=Aq^3+B_r q^2+C_r q+D_r,$$trong đó các hằng số được xác định từ$24^3$khối dư lượng. 

Tổng số cả kỳ là$$A=\sum_{1\le a,b,c\le 24} M(a,b,c)=27984.$$Điều này tái tạo các kiểm tra:$$S(10)=1972,$$

$$S(10000)=2024258331114.$$--- 

## Bước 3: Nhập Fibonacci 

Chúng tôi cần$$\sum_{k=2}^{1234567890123} S(F_k)\pmod{10^9}.$$Vì số Fibonacci modulo$24$có thời kỳ Pisano$24$,$$F_{k+24}\equiv F_k\pmod{24},$$các hệ số$B_r,C_r,D_r$lặp lại với dấu chấm$24$. 

Như vậy$S(F_k)$trở thành tổ hợp tuyến tính của$$1,\quad F_k,\quad F_k^2,\quad F_k^3$$với hệ số modulo tuần hoàn$24$. 

Các chuỗi này thỏa mãn các phép truy toán tuyến tính, do đó toàn bộ chuỗi có thể được đánh giá bằng phép lũy thừa ma trận theo$O(\log n)$.

#2. Triển khai Python```python
from math import gcd
import numpy as np

MOD = 10**9
BIGMOD = 288 * MOD

# ------------------------------------------------------------
# Compute M(a,b,c)
# ------------------------------------------------------------

def M(a, b, c):
    return gcd(
        gcd(
            gcd(1 + a + b + c,
                14 + 6*a + 2*b),
            36 + 6*a),
        24
    )

# ------------------------------------------------------------
# Precompute the 24x24x24 residue cube
# ------------------------------------------------------------

cube = np.zeros((25, 25, 25), dtype=object)

for a in range(1, 25):
    for b in range(1, 25):
        for c in range(1, 25):
            cube[a, b, c] = M(a, b, c)

# 3D prefix sums
pref = cube.cumsum(0).cumsum(1).cumsum(2)

# ------------------------------------------------------------
# S(N)
# ------------------------------------------------------------

def S(N):
    q, r = divmod(N, 24)

    return (
        q**3 * pref[24,24,24]
        + q*q * (
            pref[r,24,24]
            + pref[24,r,24]
            + pref[24,24,r]
        )
        + q * (
            pref[r,r,24]
            + pref[r,24,r]
            + pref[24,r,r]
        )
        + pref[r,r,r]
    )

# ------------------------------------------------------------
# Verify examples
# ------------------------------------------------------------

assert S(10) == 1972
assert S(10000) == 2024258331114

# ------------------------------------------------------------
# Fibonacci residues mod 24
# ------------------------------------------------------------

fib24 = [0, 1]
for _ in range(22):
    fib24.append((fib24[-1] + fib24[-2]) % 24)

# ------------------------------------------------------------
# Build polynomial coefficients
# We work with 288*S(F_n) to avoid fractions.
# ------------------------------------------------------------

import sympy as sp

q = sp.Symbol('q')
x = sp.Symbol('x')

# Recover cubic polynomials for each residue
poly_by_r = {}

for r in range(24):
    vals = [S(24*k + r) for k in range(4)]
    poly = sp.interpolate(
        [(k, vals[k]) for k in range(4)],
        q
    )
    poly_by_r[r] = sp.expand(poly)

coeffs = []

for r in range(24):
    expr = sp.expand(
        288 * poly_by_r[r].subs(q, (x-r)/24)
    )
    P = sp.Poly(expr, x)

    # const, x, x^2, x^3
    coeffs.append([
        int(P.nth(0)),
        int(P.nth(1)),
        int(P.nth(2)),
        int(P.nth(3)),
    ])

# ------------------------------------------------------------
# State vector:
#
# [F_n^3,
#  F_n^2 F_{n+1},
#  F_n F_{n+1}^2,
#  F_{n+1}^3,
#  F_n^2,
#  F_n F_{n+1},
#  F_{n+1}^2,
#  F_n,
#  F_{n+1},
#  1,
#  accumulated_sum]
# ------------------------------------------------------------

mons = [
    (3,0),(2,1),(1,2),(0,3),
    (2,0),(1,1),(0,2),
    (1,0),(0,1),(0,0)
]

idx = {m:i for i,m in enumerate(mons)}

T = np.zeros((10,10), dtype=object)

# Fibonacci transition:
# (x,y) -> (y, x+y)

from math import comb

for j, (a,b) in enumerate(mons):
    for k in range(b+1):
        coef = comb(b, k)
        mon = (k, a+b-k)
        i = idx[mon]
        T[i,j] += coef

# ------------------------------------------------------------
# Phase-dependent matrices
# ------------------------------------------------------------

def make_matrix(t):
    A = np.zeros((11,11), dtype=object)

    A[:10,:10] = T
    A[10,10] = 1

    c = coeffs[(t+1) % 24]

    # depends only on F_{n+1}
    A[10,3] = c[3]
    A[10,6] = c[2]
    A[10,8] = c[1]
    A[10,9] = c[0]

    return A % BIGMOD

phase = [make_matrix(t) for t in range(24)]

# ------------------------------------------------------------
# Multiply matrices
# ------------------------------------------------------------

def matmul(A, B):
    return (A.dot(B)) % BIGMOD

# 24-step block
B = np.identity(11, dtype=object)

for t in range(24):
    B = matmul(phase[t], B)

# ------------------------------------------------------------
# Fast exponentiation
# ------------------------------------------------------------

def mpow(M, n):
    R = np.identity(11, dtype=object)

    while n:
        if n & 1:
            R = matmul(M, R)

        M = matmul(M, M)
        n >>= 1

    return R

# ------------------------------------------------------------
# Initial state at n=0
# ------------------------------------------------------------

state0 = np.array([
    0,0,0,1,
    0,0,1,
    0,1,
    1,
    0
], dtype=object)

K = 1234567890123

blocks, rem = divmod(K, 24)

state = mpow(B, blocks).dot(state0) % BIGMOD

for t in range(rem):
    state = phase[t].dot(state) % BIGMOD

# state[10] = 288 * sum_{k=1}^K S(F_k)

answer = ((state[10] // 288) - 2) % MOD

print(answer)

#3. Hướng dẫn sử dụng mã 

### Tính toán$M(a,b,c)$Chúng tôi sử dụng đặc tính sai phân hữu hạn:```python
gcd(1+a+b+c,
    14+6a+2b,
    36+6a,
    24)
```Điều này ngay lập tức hàm ý tính tuần hoàn theo modulo$24$. 

--- 

### Tính toán$S(N)$Từ$M$chỉ phụ thuộc vào dư lượng mod$24$, chúng tôi tính toán trước toàn bộ$24^3$khối lập phương một lần. 

Sau đó cho$$N=24q+r,$$chúng tôi đếm xem mỗi dư lượng xuất hiện bao nhiêu lần. 

Điều này làm giảm toàn bộ vấn đề để đánh giá một giả đa thức bậc ba. 

--- 

### Gia tốc Fibonacci 

Sự phụ thuộc vào$F_k$là bậc ba, vì vậy chúng tôi theo dõi tất cả các đơn thức đến mức$3$:$$F_k^3,\quad F_k^2F_{k+1},\quad \dots$$Quá trình chuyển đổi Fibonacci$$(F_k,F_{k+1})\to(F_{k+1},F_k+F_{k+1})$$gây ra một phép biến đổi tuyến tính trên các đơn thức này. 

Sau đó chúng tôi sử dụng phép lũy thừa ma trận nhanh để chuyển trực tiếp đến$$k=1234567890123.$$---
