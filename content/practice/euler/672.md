## Giải pháp 

**Trả lời:**`91627537`Cho phép$$g(1)=0,\qquad  g(n)= \begin{cases} g(n/7), & 7\mid n,\\[4pt] 1+g(n+1), & 7\nmid n. \end{cases}$$Và$$S(N)=\sum_{n=1}^N g(n),\qquad H(K)=S\!\left(\frac{7^K-1}{11}\right).$$Chúng ta phải tính toán$$H(10^9)\pmod{1117117717}.$$--- 

# 1. Phân tích toán học 

## 1.1 Tái diễn cho$g(n)$Viết$$n=7a+r,\qquad 0\le r\le 6.$$Nếu như$r=0$, sau đó$$g(7a)=g(a).$$Nếu như$1\le r\le 6$, chúng ta phải thêm$7-r$những cái để đạt được bội số tiếp theo của$7$:$$7a+r \to 7(a+1).$$Sau đó chia cho$7$, cho$a+1$. Kể từ đây$$g(7a+r)=(7-r)+g(a+1),\qquad 1\le r\le 6.$$Vì thế:$$\boxed{ g(7a+r)= \begin{cases} g(a), & r=0,\\ 7-r+g(a+1), & 1\le r\le 6. \end{cases}}$$--- 

#1.2 Tái diễn cho$S(N)$Cho phép$N=7a+r$. 

Đầu tiên tính toán toàn bộ khối:$$\sum_{i=0}^6 g(7a+i) = g(a)+\sum_{i=1}^6 (7-i+g(a+1)).$$Từ$$\sum_{i=1}^6 (7-i)=21,$$chúng tôi nhận được$$\sum_{i=0}^6 g(7a+i)=g(a)+21+6g(a+1).$$Bây giờ mở rộng$S(7a+r)$:$$S(7a+r) = S(7a-1)+g(a)+\sum_{i=1}^r (7-i+g(a+1)).$$Sau khi đơn giản hóa:$$\boxed{ S(7a+r) = 7S(a)+21a-6 +r\,g(a+1) +7r-\frac{r(r+1)}2 }$$vì$0\le r\le 6$. 

--- 

#1.3 Theo dõi$g(a+1)$Định nghĩa$$x(a)=g(a+1).$$Nếu như$N=7a+r$, sau đó$$N+1= \begin{cases} 7a+r+1, & r<6,\\ 7(a+1), & r=6. \end{cases}$$Vì thế:$$g(N+1)= \begin{cases} 6-r+g(a+1), & r<6,\\ g(a+1), & r=6. \end{cases}$$Vì thế$$\boxed{ x'= \begin{cases} x+6-r, & r<6,\\ x, & r=6. \end{cases}}$$--- 

# 1.4 Cơ số 7 chữ số của$\dfrac{7^K-1}{11}$Tính toán một số ví dụ trong cơ sở$7$:$$\begin{aligned} H(2):&\quad 4_7\\ H(3):&\quad 43_7\\ H(4):&\quad 431_7\\ H(5):&\quad 4311_7\\ H(6):&\quad 43116_7 \end{aligned}$$Các chữ số lặp lại với dấu chấm$10$:$$4311623550\,4311623550\cdots$$Thực vậy,$$\frac1{11} = 0.\overline{04311623550}_7,$$Vì thế$$\frac{7^K-1}{11}$$là người đầu tiên$K-1$các chữ số của việc lặp lại. 

Như vậy chúng ta chỉ cần xử lý chu kỳ chữ số lặp lại$$(4,3,1,1,6,2,3,5,5,0).$$--- 

#1.5 Chuyển trạng thái 

Duy trì trạng thái$$(S,x,a,1),$$Ở đâu

-$S=S(a)$, 
-$x=g(a+1)$, 
-$a$là giá trị tiền tố hiện tại. 

Chữ số nối thêm$r$biến đổi:$$a' = 7a+r,$$

$$x' = \begin{cases} x+6-r,& r<6,\\ x,& r=6, \end{cases}$$

$$S' = 7S+21a-6+r x+7r-\frac{r(r+1)}2.$$Đây là một phép biến đổi tuyến tính affine nên nó có thể được biểu diễn bằng một$4\times4$ma trận và lũy thừa nhanh chóng. 

Từ$K=10^9$, chúng tôi xử lý$$K-1=999999999$$chữ số. 

Độ dài chu kỳ chữ số là$10$, vì vậy chúng ta lũy thừa ma trận trong một chu kỳ đầy đủ.

#2. Triển khai Python```python
MOD = 1117117717

# Repeating base-7 digit cycle of (7^K - 1) / 11
cycle = [4, 3, 1, 1, 6, 2, 3, 5, 5, 0]

def mat_mul(A, B):
    """Multiply two 4x4 matrices modulo MOD."""
    n = 4
    C = [[0] * n for _ in range(n)]

    for i in range(n):
        for k in range(n):
            if A[i][k]:
                aik = A[i][k]
                for j in range(n):
                    C[i][j] = (C[i][j] + aik * B[k][j]) % MOD

    return C

def mat_pow(A, e):
    """Fast exponentiation of a 4x4 matrix."""
    n = 4
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]

    while e > 0:
        if e & 1:
            R = mat_mul(A, R)

        A = mat_mul(A, A)
        e >>= 1

    return R

def digit_matrix(r):
    """
    Matrix for appending one base-7 digit r.

    State vector:
        [S, x, a, 1]^T
    """
    const = (-6 + 7 * r - r * (r + 1) // 2) % MOD
    add_x = 0 if r == 6 else (6 - r)

    return [
        [7, r, 21, const],
        [0, 1, 0, add_x],
        [0, 0, 7, r],
        [0, 0, 0, 1],
    ]

# Build matrix for one full 10-digit cycle
cycle_matrix = [[1 if i == j else 0 for j in range(4)] for i in range(4)]

for d in cycle:
    cycle_matrix = mat_mul(digit_matrix(d), cycle_matrix)

K = 10**9
L = K - 1

q, rem = divmod(L, 10)

# Apply full cycles
M = mat_pow(cycle_matrix, q)

# Apply remaining digits
R = [[1 if i == j else 0 for j in range(4)] for i in range(4)]

for d in cycle[:rem]:
    R = mat_mul(digit_matrix(d), R)

# Total transformation
T = mat_mul(R, M)

# Initial state: S=0, x=g(1)=0, a=0
v = [0, 0, 0, 1]

result = sum(T[0][i] * v[i] for i in range(4)) % MOD

print(result)
```--- 

#3. Hướng dẫn sử dụng mã 

## Trạng thái ma trận 

Chúng tôi lưu trữ:$$[S,\ x,\ a,\ 1]$$Ở đâu:

-$S=S(a)$, 
-$x=g(a+1)$, 
-$a$là tiền tố base-7 hiện tại. 

Dấu vết bổ sung$1$cho phép chúng tôi mã hóa các hằng số ở dạng ma trận. 

--- 

##`digit_matrix(r)`Điều này mã hóa sự tái phát:$$\begin{aligned} S' &= 7S + r x + 21a + c_r,\\ x' &= x + (6-r)\quad (r<6),\\ a' &= 7a+r. \end{aligned}$$--- 

## Tính định kỳ 

Các chữ số lặp lại mỗi$10$, vì vậy thay vì xử lý$10^9$các chữ số riêng lẻ, chúng tôi: 

1. Xây dựng một ma trận cho toàn bộ chu trình, 
2. Nâng nó lên lũy thừa thích hợp bằng lũy thừa nhị phân, 
3. Xử lý các chữ số còn sót lại. 

Sự phức tạp chỉ$O(\log K)$.
