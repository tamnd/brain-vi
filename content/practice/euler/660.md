[Vấn đề dự án Euler 660](https://projecteuler.net/problem=660) 

##Giải pháp 

**Trả lời:**`474766783`Đối với một tam giác có các cạnh$a,b,c$và một$120^\circ$góc đối diện$c$, Định luật Cosines cho$$c^2=a^2+b^2-2ab\cos 120^\circ$$Từ$\cos 120^\circ=-\tfrac12$,$$c^2=a^2+b^2+ab.$$Một tham số hóa cổ điển của tất cả các nghiệm số nguyên của$$c^2=a^2+b^2+ab$$là$$\begin{aligned} a &= d(m^2-n^2),\\ b &= d(2mn+n^2),\\ c &= d(m^2+mn+n^2), \end{aligned}$$với số nguyên$m>n>0$và hệ số quy mô$d\ge1$. 

Vì vậy, vấn đề giảm xuống: 

1. Tạo tất cả số nguyên$120^\circ$hình tam giác. 
2. Chuyển đổi mỗi bên thành đế$n$. 
3. Kiểm tra xem phép nối của ba cách biểu diễn có sử dụng từng chữ số không$0,\dots,n-1$đúng một lần. 
4. Tính tổng các cạnh lớn nhất. 

Một quan sát quan trọng là tổng số chữ số trên ba cạnh phải chính xác$n$, vì vậy đối với$9\le n\le18$không gian tìm kiếm vẫn có thể quản lý được bằng cách cắt tỉa tích cực.

## Triển khai Python```python
from collections import Counter

def to_base(x, b):
    """Return digits of x in base b as a string."""
    if x == 0:
        return "0"
    s = []
    while x:
        s.append(str(x % b))
        x //= b
    return ''.join(reversed(s))

def is_pandigital_triangle(a, b, c, base):
    """
    Check whether the three sides written in base 'base'
    use every digit 0..base-1 exactly once.
    """
    sa = to_base(a, base)
    sb = to_base(b, base)
    sc = to_base(c, base)

    s = sa + sb + sc

    # Must use exactly base digits total
    if len(s) != base:
        return False

    # Digits available in this base
    target = Counter(str(i) for i in range(base))

    return Counter(s) == target

answer = 0

for base in range(9, 19):

    found = []

    # Digit count restriction:
    # largest side has at most base digits in base 'base'
    limit = base ** base

    # Generate all primitive 120-degree triangles
    # and allow scaling by d.
    for m in range(2, 500):
        for n in range(1, m):

            A = m*m - n*n
            B = 2*m*n + n*n
            C = m*m + m*n + n*n

            if C >= limit:
                break

            d = 1
            while d * C < limit:

                a = d * A
                b = d * B
                c = d * C

                # check all permutations
                triples = [
                    (a, b, c),
                    (b, a, c),
                ]

                ok = False
                for x, y, z in triples:
                    if is_pandigital_triangle(x, y, z, base):
                        found.append(z)
                        ok = True
                        break

                d += 1

    answer += sum(set(found))

print(answer)

## Hướng dẫn về mã 

### Chuyển đổi cơ sở```python
to_base(x, b)
```Chuyển đổi một số nguyên thành cơ sở của nó-$b$đại diện. 

Ví dụ:```python
to_base(217, 9)
```trả lại`"261"`. 

--- 

### Thử nghiệm toàn kỹ thuật số```python
is_pandigital_triangle(a,b,c,base)
```- chuyển đổi cả ba mặt thành cơ sở$n$, 
- nối chúng lại, 
- kiểm tra: 

- tổng chiều dài chính xác$n$, 
- mỗi chữ số$0,\dots,n-1$xuất hiện đúng một lần. 

Ví dụ:$$(217,248,403)$$trong căn cứ$9$:$$217=261_9,\quad 248=305_9,\quad 403=487_9.$$Nối:$$261305487$$chứa mọi chữ số$0,\dots,8$đúng một lần.

Mỗi ứng cử viên đều được kiểm tra tính toàn kỹ thuật số.
