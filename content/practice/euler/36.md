## Giải pháp 

**Trả lời:**`872187`Chúng tôi tìm kiếm tất cả các số nguyên$n < 10^6$như vậy: 

1.$n$là một palindrome trong cơ số 10. 
2. Biểu diễn nhị phân của$n$cũng là một palindrome. 
3. Không được phép sử dụng số 0 đứng đầu trong cả hai cách trình bày. 

Sau đó chúng tôi tổng hợp tất cả các số như vậy. 

--- 

# Phân tích toán học 

Một palindrome đọc xuôi và ngược như nhau. 

Ví dụ:

-$585$ở dạng thập phân là:$$585$$đó là palindromic. 
- Ở dạng nhị phân:$$585 = 1001001001_2$$đó cũng là palindromic. 

Chúng ta phải tìm _tất cả_ những con số như vậy dưới một triệu. 

## Những quan sát chính 

### 1. Bảng màu thập phân rất hiếm 

Thay vì kiểm tra mọi số từ$1$ĐẾN$999999$, sẽ nhanh hơn nhiều nếu chỉ tạo ra các bảng màu thập phân. 

Một bảng màu gồm 6 chữ số có dạng:$$abc|cba$$Một bảng màu gồm 5 chữ số có dạng:$$ab|c|ba$$Số lượng palindrome thập phân dưới một triệu là nhỏ: 

- 1 chữ số:$9$- 2 chữ số:$9$- 3 chữ số:$90$- 4 chữ số:$90$- 5 chữ số:$900$- 6 chữ số:$900$Tổng cộng:$$9+9+90+90+900+900 = 1998$$Vì vậy thay vì kiểm tra một triệu số, chúng ta chỉ kiểm tra khoảng 2000. 

--- 

### 2. Palindrome nhị phân không thể kết thúc bằng 0 

Một bảng màu nhị phân không thể có số 0 đứng đầu. 

Nếu một số nhị phân kết thúc bằng$0$, thì theo tính đối xứng, nó cũng sẽ bắt đầu bằng$0$, không thể nào. 

Vì vậy mọi palindrome nhị phân đều là số lẻ. 

Do đó mọi số hợp lệ đều phải là số lẻ. 

Điều này ngay lập tức loại bỏ tất cả các bảng màu thập phân chẵn. 

--- 

### 3. Kiểm tra bảng màu hiệu quả 

một chuỗi$s$là palindromic iff:$$s = s[::-1]$$Vì vậy: 

- Bảng chữ thập thập phân:```python
str(n) == str(n)[::-1]
```- Bảng màu nhị phân:```python
b = bin(n)[2:]
b == b[::-1]
```--- 

#Triển khai Python```python
def is_palindrome(s):
    """Return True if string s is a palindrome."""
    return s == s[::-1]

total = 0

# Check every odd number below one million
for n in range(1, 1_000_000, 2):

    # Check decimal palindrome
    if is_palindrome(str(n)):

        # Convert to binary without '0b'
        b = bin(n)[2:]

        # Check binary palindrome
        if is_palindrome(b):
            total += n

print(total)
```--- 

# Hướng dẫn sử dụng mã 

## Người trợ giúp Palindrome```python
def is_palindrome(s):
    return s == s[::-1]
```-`s[::-1]`đảo ngược chuỗi. 
- Bình đẳng có nghĩa là chuỗi đọc xuôi và đọc ngược giống hệt nhau. 

Ví dụ:```python
is_palindrome("585")        # True
is_palindrome("1001001001") # True
is_palindrome("123")        # False
```---
