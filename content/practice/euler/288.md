[Vấn đề dự án Euler 288](https://projecteuler.net/problem=288) 

##Giải pháp 

**Trả lời:**`605857431263981935`Cho phép$$N(p,q)=\sum_{n=0}^{q} T_n p^n,$$Ở đâu$$S_0=290797,\qquad S_{n+1}=S_n^2 \bmod 50515093,\qquad T_n=S_n\bmod p.$$chúng tôi muốn$$\operatorname{NF}(p,q)=v_p(N(p,q)!),$$số mũ của số nguyên tố$p$TRONG$N(p,q)!$. 

Đối với vấn đề này:$$p=61,\qquad q=10^7,$$và chúng tôi cần$$\operatorname{NF}(61,10^7)\bmod 61^{10}.$$--- 

# 1. Phân tích toán học 

Thực tế quan trọng là **công thức Legendre**:$$v_p(n!)=\sum_{k\ge1}\left\lfloor \frac{n}{p^k}\right\rfloor.$$Một danh tính tiêu chuẩn có nguồn gốc từ base-$p$tổng chữ số là$$v_p(n!)=\frac{n-s_p(n)}{p-1},$$Ở đâu$s_p(n)$là tổng các chữ số của$n$trong căn cứ$p$. 

--- 

## Bước 1: Căn cứ-$p$đại diện của$N(p,q)$Bởi vì mỗi$$0\le T_n < p,$$số$$N(p,q)=\sum_{n=0}^{q}T_n p^n$$đã _là_ căn cứ-$p$mở rộng của$N$. 

Vì thế,$$s_p(N)=\sum_{n=0}^{q}T_n.$$Kể từ đây$$\operatorname{NF}(p,q) = \frac{N-\sum T_n}{p-1}.$$Thay thế định nghĩa của$N$:$$\operatorname{NF}(p,q) = \frac{\sum_{n=0}^{q}T_n p^n-\sum_{n=0}^{q}T_n}{p-1}.$$Yếu tố theo từng kỳ hạn:$$\operatorname{NF}(p,q) = \sum_{n=0}^{q} T_n\frac{p^n-1}{p-1}.$$Định nghĩa$$R_n=\frac{p^n-1}{p-1}=1+p+p^2+\cdots+p^{n-1}.$$Vì thế$$\boxed{ \operatorname{NF}(p,q)=\sum_{n=0}^{q}T_nR_n }.$$--- 

## Bước 2: Giảm modulo$p^{10}$Chúng tôi chỉ cần modulo$61^{10}$. 

Quan sát:$$R_n = 1+p+\cdots+p^{n-1}.$$Đối với bất kỳ$n\ge 10$,$$R_n \equiv 1+p+\cdots+p^9 \pmod{p^{10}},$$bởi vì tất cả các quyền hạn cao hơn đều được chia cho$p^{10}$. 

Cho phép$$R=1+p+\cdots+p^9.$$Sau đó$$\operatorname{NF}(p,q) \equiv \sum_{n=0}^{9}T_nR_n + R\sum_{n=10}^{q}T_n \pmod{p^{10}}.$$Đây là sự đơn giản hóa quan trọng: chúng ta không bao giờ cần sức mạnh to lớn của$p$, chỉ có mười đầu tiên. 

--- 

#2. Triển khai Python```python
def solve():
    p = 61
    q = 10_000_000
    mod = p ** 10

    # Random generator seed
    S = 290797

    # R = 1 + p + p^2 + ... + p^9  (mod p^10)
    R = sum(p ** i for i in range(10)) % mod

    # Store first 10 T_n values separately
    first_terms = []

    # Sum of all T_n for n >= 10
    tail_sum = 0

    # Generate T_n values
    for n in range(q + 1):
        T = S % p

        if n < 10:
            first_terms.append(T)
        else:
            tail_sum += T

        S = (S * S) % 50515093

    # Compute contribution of first 10 terms exactly
    ans = 0

    for n in range(10):
        # R_n = 1 + p + ... + p^(n-1)
        Rn = sum(p ** i for i in range(n))
        ans += first_terms[n] * Rn

    # Contribution from all remaining terms
    ans += R * tail_sum

    ans %= mod

    return ans

print(solve())
```---

```Cuối cùng giảm modulo$61^{10}$.
