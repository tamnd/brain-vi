[Vấn đề dự án Euler 624](https://projecteuler.net/problem=624) 

## Giải pháp 

**Trả lời:**`984524441`Cho phép$M$là chỉ số tung khi xuất hiện lần đầu tiên của hai mặt ngửa liên tiếp (vì vậy tung$M-1,M$là HH). Chúng tôi tìm kiếm$$P(n)=\Pr(n\mid M)$$vì$n=10^{18}$, sau đó tính toán$$Q(P(n),p) \quad\text{with}\quad p=1{,}000{,}000{,}009.$$--- 

## 1. Phân tích toán học 

### Bước 1: Phân phối$M$Để có$M=m$, trình tự: 

- phải kết thúc bằng HH, 
- phải chứa **không có HH sớm hơn**. 

Số chuỗi nhị phân hợp lệ có độ dài$m$kết thúc ở HH đầu tiên là số Fibonacci. 

Cho phép$A_m$là số chuỗi hợp lệ kết thúc khi tung$m$. 

Nếu HH đầu tiên xảy ra lúc tung$m$, sau đó ném$m-1$Và$m$là H, H, và đầu tiên$m-2$lần tung phải tránh các đầu liên tiếp và kết thúc bằng chữ T. 

Điều này mang lại:$$A_m = F_{m-1}$$Ở đâu$F_k$là dãy Fibonacci ($F_0=0,F_1=1$). 

Kể từ đây$$\Pr(M=m)=\frac{F_{m-1}}{2^m}.$$Vì thế$$P(n) = \sum_{k\ge1} \frac{F_{kn-1}}{2^{kn}}.$$--- 

### Bước 2: Chuyển sang dạng đóng 

Sử dụng công thức Binet:$$F_m=\frac{\phi^m-\psi^m}{\sqrt5},$$Ở đâu$$\phi=\frac{1+\sqrt5}{2}, \qquad \psi=\frac{1-\sqrt5}{2}.$$Sau đó$$F_{kn-1} = \frac{\phi^{kn-1}-\psi^{kn-1}}{\sqrt5}.$$Thay vào tổng:$$P(n) = \sum_{k\ge1} \frac{1}{2^{kn}} \cdot \frac{\phi^{kn-1}-\psi^{kn-1}}{\sqrt5}.$$Mỗi phần đều có tính chất hình học nên sau khi tính tổng và đơn giản hóa:$$P(n) = \frac{ 2^nF_{n-1}-(-1)^n }{ 4^n-2^nL_n+(-1)^n },$$Ở đâu$L_n$là số Lucas:$$L_n = F_{n-1}+F_{n+1}.$$Kiểm tra các ví dụ: 

cho$n=2$:$$P(2)=\frac{4\cdot1-1}{16-4\cdot3+1} =\frac35.$$Vì$n=3$:$$P(3)=\frac{8\cdot1-(-1)}{64-8\cdot4-1} = \frac{9}{31}.$$Cả hai đều phù hợp với tuyên bố. 

--- 

### Bước 3: Giải thích mô-đun 

Chúng tôi cần$$Q\!\left(P(n),p\right)$$đó là phần dư duy nhất$q$thỏa mãn$$a \equiv bq \pmod p$$vì$P(n)=a/b$. 

Như vậy$$Q(P(n),p) = a\,b^{-1}\pmod p.$$Vậy ta chỉ cần modulo tử số và mẫu số$p$. 

Vì$n=10^{18}$, tính: 

-$F_{n-1}\pmod p$, 
-$F_{n+1}\pmod p$, 
-$L_n=F_{n-1}+F_{n+1}\pmod p$, 
-$2^n\pmod p$, 
-$4^n\pmod p$, 

sử dụng **Fibonacci nhân đôi nhanh** trong$O(\log n)$.

## 2. Triển khai Python```python
MOD = 1_000_000_009
N = 10**18

def fib(n, mod):
    """Fast doubling Fibonacci.
    Returns (F_n, F_{n+1}) modulo mod.
    """
    if n == 0:
        return (0, 1)

    a, b = fib(n >> 1, mod)

    # F(2k)
    c = (a * ((2 * b - a) % mod)) % mod

    # F(2k+1)
    d = (a * a + b * b) % mod

    if n & 1:
        return d, (c + d) % mod
    return c, d

# Fibonacci values
Fn_minus_1 = fib(N - 1, MOD)[0]
Fn, Fn_plus_1 = fib(N, MOD)

# Lucas number: L_n = F_{n-1} + F_{n+1}
Ln = (Fn_minus_1 + Fn_plus_1) % MOD

# Powers
pow2 = pow(2, N, MOD)
pow4 = pow(4, N, MOD)

# Since N = 10^18 is even, (-1)^N = 1
sign = 1

# Numerator and denominator modulo MOD
numerator = (pow2 * Fn_minus_1 - sign) % MOD
denominator = (pow4 - pow2 * Ln + sign) % MOD

# Modular division
answer = numerator * pow(denominator, MOD - 2, MOD) % MOD

print(answer)
```--- 

## 3. Hướng dẫn sử dụng mã 

### Nhân đôi nhanh chóng 

Danh tính:$$F_{2k}=F_k(2F_{k+1}-F_k),$$

$$F_{2k+1}=F_k^2+F_{k+1}^2$$cho phép tính toán Fibonacci trong$O(\log n)$. 

Hàm trả về:$$(F_n,F_{n+1})$$để chúng ta có thể phục hồi mọi thứ cần thiết. 

### số Lucas 

Chúng tôi sử dụng:$$L_n = F_{n-1}+F_{n+1}.$$### Công thức xác suất 

Kể từ khi$N$thậm chí là:$$(-1)^N=1.$$Như vậy:$$a = 2^N F_{N-1}-1,$$

$$b = 4^N - 2^N L_N + 1.$$Cuối cùng:$$Q(P(N),p)=a\,b^{-1}\pmod p.$$### Xác minh ví dụ nhỏ 

cho$n=2$:$$P(2)=\frac35$$và modulo$109$:$$5^{-1}\cdot3 \equiv 66.$$Vì$n=3$:$$P(3)=\frac9{31}$$và modulo$109$:$$31^{-1}\cdot9 \equiv 46.$$Cả hai đều đồng ý với tuyên bố vấn đề.
