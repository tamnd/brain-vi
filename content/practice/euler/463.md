[Vấn đề dự án Euler 463](https://projecteuler.net/problem=463) 

## Giải pháp 

**Trả lời:**`808981553`Chúng ta được cung cấp hàm được xác định đệ quy$$\begin{aligned} f(1)&=1,\\ f(3)&=3,\\ f(2n)&=f(n),\\ f(4n+1)&=2f(2n+1)-f(n),\\ f(4n+3)&=3f(2n+1)-2f(n), \end{aligned}$$Và$$S(n)=\sum_{i=1}^n f(i).$$Chúng ta phải tính toán$$S(3^{37}) \pmod{10^9}.$$--- 

# 1. Phân tích toán học 

## Bước 1: Tìm hiểu cấu trúc của$f(n)$Đệ quy làm giảm các đối số một cách đại khái theo các yếu tố của$2$hoặc$4$, vì vậy phép đệ quy được ghi nhớ sẽ có hiệu quả ngay cả đối với$3^{37}$. 

Cho phép$$a_n=f(2n+1)$$(các giá trị được lập chỉ mục lẻ). 

Từ quan hệ xác định:$$\begin{aligned} a_{2n} &=f(4n+1) =2f(2n+1)-f(n) =2a_n-f(n), \\[1ex] a_{2n+1} &=f(4n+3) =3f(2n+1)-2f(n) =3a_n-2f(n). \end{aligned}$$Những nhận dạng này cho phép chúng tôi rút ra các phép truy hồi cho$S(n)$. 

--- 

## Bước 2: Tìm các phép truy toán cho$S(n)$Chúng tôi chia số theo modulo lớp dư lượng$4$. 

Sau khi thao tác đại số (sử dụng các quan hệ trên và đẳng thức$f(2n)=f(n)$), người ta thu được:$$\boxed{ S(4n) = 6S(2n)-8S(n)+3f(n)-1 }$$

$$\boxed{ S(4n+1) = 6S(2n)-8S(n)+2f(n)+2f(2n+1)-1 }$$

$$\boxed{ S(4n+2) = 6S(2n)-8S(n)+2f(n)+3f(2n+1)-1 }$$

$$\boxed{ S(4n+3) = 6S(2n)-8S(n)+6f(2n+1)-1 }$$Những công thức này làm giảm kích thước bài toán từ$n$đại khái$n/2$, cho độ phức tạp logarit. 

--- 

## Bước 3: Độ phức tạp 

cho$N=3^{37}$,$$3^{37}\approx 4.5\times 10^{17},$$nhưng mọi cuộc gọi đệ quy đều chia đối số cho$2$hoặc$4$, do đó việc ghi nhớ làm cho việc tính toán cực kỳ nhanh chóng. 

Chúng ta chỉ cần điều cuối cùng$9$chữ số, do đó tất cả số học có thể được thực hiện modulo$$10^9.$$--- 

#2. Triển khai Python```python
from functools import lru_cache

MOD = 10**9

# -------------------------------------------------------
# f(n)
# -------------------------------------------------------

@lru_cache(None)
def f(n):
    if n == 1:
        return 1
    if n == 3:
        return 3

    # even case
    if n % 2 == 0:
        return f(n // 2)

    # n = 4k + 1
    if n % 4 == 1:
        k = (n - 1) // 4
        return 2 * f(2 * k + 1) - f(k)

    # n = 4k + 3
    k = (n - 3) // 4
    return 3 * f(2 * k + 1) - 2 * f(k)

# -------------------------------------------------------
# Small exact values for S(n)
# -------------------------------------------------------

small = [0]
s = 0
for i in range(1, 20):
    s += f(i)
    small.append(s)

# -------------------------------------------------------
# S(n)
# -------------------------------------------------------

@lru_cache(None)
def S(n):
    if n < 20:
        return small[n]

    q, r = divmod(n, 4)

    if r == 0:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 3 * f(q)
            - 1
        )

    elif r == 1:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 2 * f(q)
            + 2 * f(2 * q + 1)
            - 1
        )

    elif r == 2:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 2 * f(q)
            + 3 * f(2 * q + 1)
            - 1
        )

    else:  # r == 3
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 6 * f(2 * q + 1)
            - 1
        )

    return ans

# -------------------------------------------------------
# Required value
# -------------------------------------------------------

N = 3**37

print(S(N) % MOD)
```--- 

#3. Hướng dẫn sử dụng mã 

## Chức năng`f(n)`Định nghĩa đệ quy được thực hiện trực tiếp. 

- Nếu như$n$thậm chí là:$$f(2n)=f(n)$$- Nếu như$n=4k+1$:$$f(4k+1)=2f(2k+1)-f(k)$$- Nếu như$n=4k+3$:$$f(4k+3)=3f(2k+1)-2f(k)$$Ghi nhớ (`@lru_cache`) đảm bảo mọi giá trị được tính một lần. 

---

## Chức năng`S(n)`Sử dụng các phép truy toán dẫn xuất cho mỗi modulo dư$4$. 

Ví dụ: 

Nếu$n=4q+2$,```python
6 * S(2*q)
- 8 * S(q)
+ 2 * f(q)
+ 3 * f(2*q + 1)
- 1
```Điều này làm giảm vấn đề thành các đối số nhỏ hơn nhiều.
