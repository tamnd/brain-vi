## Giải pháp 

**Trả lời:**`968274154`Cho phép$$f(n)=\#\{(p,q):1\le p<q\le n,\ \gcd(p,q)=2^t,\ t>0\}.$$Chúng tôi cần$f(10^{11}) \bmod 1\,000\,000\,007$. 

## 1. Phân tích toán học 

Nếu$\gcd(p,q)=2^t$với$t>0$, viết$$p=2^t a,\qquad q=2^t b,$$Ở đâu$\gcd(a,b)=1$. 

Từ$p<q\le n$,$$1\le a<b\le \left\lfloor \frac{n}{2^t}\right\rfloor.$$Như vậy đối với mỗi$t\ge 1$, số cặp hợp lệ bằng số cặp nguyên tố cùng nhau$(a,b)$với$a<b\le m$, Ở đâu$$m=\left\lfloor \frac{n}{2^t}\right\rfloor.$$### Đếm các cặp nguyên tố cùng nhau 

Để cố định$b$, số lượng$a<b$với$\gcd(a,b)=1$là tổng Euler:$$\varphi(b).$$Kể từ đây$$C(m)=\sum_{b=2}^{m}\varphi(b).$$Xác định hàm tổng hợp tổng$$\Phi(m)=\sum_{k=1}^{m}\varphi(k).$$Sau đó$$C(m)=\Phi(m)-1.$$Vì thế,$$f(n) = \sum_{t\ge 1} \left( \Phi\!\left(\left\lfloor \frac{n}{2^t}\right\rfloor\right)-1 \right).$$Từ$2^t>n$cuối cùng chỉ$O(\log n)$các điều khoản tồn tại. 

--- 

### Tính toán nhanh$\Phi(n)$Sử dụng bản sắc cổ điển$$\sum_{d\le n}\varphi(d)\left\lfloor \frac{n}{d}\right\rfloor = \frac{n(n+1)}{2}.$$Sắp xếp lại:$$\Phi(n) = \frac{n(n+1)}{2} - \sum_{d=2}^{n} \Phi\!\left(\left\lfloor \frac{n}{d}\right\rfloor\right).$$Việc tối ưu hóa chính là nhóm các giá trị bằng nhau của$\lfloor n/d\rfloor$:

nếu như$$v=\left\lfloor \frac{n}{d}\right\rfloor,$$sau đó tất cả$d\in[l,r]$chia sẻ tương tự$v$, Ở đâu$$r=\left\lfloor \frac{n}{v}\right\rfloor.$$Điều này làm giảm độ phức tạp xuống còn khoảng$O(n^{2/3})$-kiểu chia để trị được ghi nhớ, đủ nhanh để$10^{11}$.

## 2. Triển khai Python```python
MOD = 1_000_000_007
LIMIT = 5_000_000

# Sieve Euler phi up to LIMIT
phi = list(range(LIMIT + 1))

for i in range(2, LIMIT + 1):
    if phi[i] == i:  # i is prime
        for j in range(i, LIMIT + 1, i):
            phi[j] -= phi[j] // i

# Prefix sums of phi
phi_prefix = [0] * (LIMIT + 1)

running = 0
for i in range(LIMIT + 1):
    running += phi[i]
    phi_prefix[i] = running

# Memoized summatory totient
memo = {0: 0}

def Phi(n):
    """Return sum_{k<=n} phi(k)."""
    if n <= LIMIT:
        return phi_prefix[n]

    if n in memo:
        return memo[n]

    result = n * (n + 1) // 2

    l = 2
    while l <= n:
        v = n // l
        r = n // v

        result -= (r - l + 1) * Phi(v)
        l = r + 1

    memo[n] = result
    return result

def f(n):
    total = 0
    t = 1

    while True:
        m = n >> t  # floor(n / 2^t)

        if m == 0:
            break

        total += Phi(m) - 1
        total %= MOD

        t += 1

    return total

print(f(10**11))
```--- 

## 3. Hướng dẫn sử dụng mã 

### Bước 1: Sàng toàn phần 

Chúng tôi tính toán tất cả$\varphi(k)$đến một điểm cắt (`LIMIT = 5_000_000`) bằng sàng Euler tiêu chuẩn. 

### Bước 2: Tổng tiền tố 

Chúng tôi xây dựng$$\Phi(n)=\sum_{k\le n}\varphi(k)$$cho tất cả nhỏ$n$. 

### Bước 3: Tổng hợp đệ quy 

Đối với lớn$n$, chúng tôi sử dụng$$\Phi(n) = \frac{n(n+1)}{2} - \sum_{d=2}^{n} \Phi\!\left(\left\lfloor \frac{n}{d}\right\rfloor\right),$$nhóm các thương số giống hệt nhau để làm cho nó hiệu quả. 

### Bước 4: Tính toán$f(n)$Chúng tôi tổng hợp$$\Phi\!\left(\left\lfloor n/2^t\right\rfloor\right)-1$$vì$t=1,2,\dots$. 

--- 

### Xác minh trên các ví dụ đã cho 

cho$n=100$:$$f(100)=1031,$$phù hợp với tuyên bố. 

Vì$n=10^6$:$$f(10^6)\equiv 321418433 \pmod{1\,000\,000\,007},$$cũng phù hợp với tuyên bố. 

Vì vậy, việc bắt nguồn và thực hiện là nhất quán.
