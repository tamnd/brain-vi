[Vấn đề dự án Euler 347](https://projecteuler.net/problem=347) 

##Giải pháp 

**Trả lời:**`11109800204052`Chúng ta cần tính toán$$S(N)=\sum_{\substack{p<q\\ p,q\text{ primes}}} M(p,q,N),$$Ở đâu$M(p,q,N)$là số nguyên lớn nhất$\le N$có ước số nguyên tố là _ chính xác _$p$Và$q$. 

Ví dụ,$$M(2,3,100)=96=2^5\cdot 3,$$

$$M(3,5,100)=75=3\cdot 5^2.$$Chúng tôi được yêu cầu$$S(10^7).$$--- 

# Phân tích toán học 

Một số được tính bằng$M(p,q,N)$có hình thức$$p^a q^b,$$với$$a\ge1,\qquad b\ge1,$$và không có thừa số nguyên tố nào khác. 

Vì vậy đối với các số nguyên tố phân biệt cố định$p,q$,$$M(p,q,N)=\max \{p^a q^b \le N\}.$$Nếu không có số đó tồn tại thì$M=0$. 

--- 

## Quan sát chính 

Giả sử$p q > N$. 

Khi đó số nhỏ nhất chia hết cho cả hai$p$Và$q$vượt quá$N$, Vì thế$$M(p,q,N)=0.$$Vì vậy ta chỉ cần cặp số nguyên tố thoả mãn$$pq \le N.$$Vì$N=10^7$, điều này có thể quản lý được. 

--- 

## Tính toán hiệu quả của$M(p,q,N)$Để cố định$p,q$, chúng tôi muốn$$\max p^a q^b \le N.$$Một lực lượng vũ phu trên tất cả các số mũ là đủ nhanh vì sức mạnh tăng theo cấp số nhân. 

Thuật toán: 

- Tạo ra mọi quyền năng của$p$:$$p,p^2,p^3,\dots$$lên tới$N$. 
- Tạo ra mọi quyền năng của$q$:$$q,q^2,q^3,\dots$$lên tới$N$. 
- Kiểm tra từng sản phẩm$p^a q^b\le N$, giữ ở mức tối đa. 

Số lượng quyền hạn là rất nhỏ:$$\log_2(10^7)\approx 23.$$Như vậy mỗi cặp chỉ tốn vài trăm thao tác. 

--- 

## Số cặp nguyên tố 

Chúng ta cần tất cả các số nguyên tố đến$N$, nhưng chỉ ghép với$$pq\le N.$$Đối với mỗi số nguyên tố$p$, có hiệu lực$q$thỏa mãn$$q\le \frac{N}{p}.$$Điều này dẫn đến khoảng vài trăm nghìn cặp - hoàn toàn khả thi. 

--- 

#Triển khai Python```python
from math import isqrt

N = 10_000_000

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
def prime_sieve(limit):
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[0:2] = b"\x00\x00"

    for i in range(2, isqrt(limit) + 1):
        if sieve[i]:
            step = i
            start = i * i
            sieve[start:limit + 1:step] = b"\x00" * (((limit - start) // step) + 1)

    return [i for i in range(limit + 1) if sieve[i]]

primes = prime_sieve(N // 2)

# ------------------------------------------------------------
# Compute M(p,q,N)
# ------------------------------------------------------------
def M(p, q, N):
    best = 0

    # Generate powers of p
    pp = p
    p_powers = []
    while pp <= N:
        p_powers.append(pp)
        pp *= p

    # Generate powers of q
    qq = q
    q_powers = []
    while qq <= N:
        q_powers.append(qq)
        qq *= q

    # Try all products
    for a in p_powers:
        for b in q_powers:
            val = a * b
            if val <= N:
                if val > best:
                    best = val

    return best

# ------------------------------------------------------------
# Compute S(N)
# ------------------------------------------------------------
total = 0

L = len(primes)

for i in range(L):
    p = primes[i]

    if p * p > N:
        break

    for j in range(i + 1, L):
        q = primes[j]

        if p * q > N:
            break

        total += M(p, q, N)

print(total)
```--- 

# Hướng dẫn sử dụng mã 

##Sàng lọc chính```python
primes = prime_sieve(N // 2)
```Chúng ta chỉ cần các số nguyên tố lên đến$N/2$, bởi vì nếu$p>N/2$, thì với mọi số nguyên tố phân biệt$q\ge2$,$$pq>N.$$Sàng tạo ra tất cả các số nguyên tố như vậy một cách hiệu quả. 

---

## Chức năng`M(p,q,N)`Đầu tiên chúng ta xây dựng tất cả sức mạnh của$p$:```python
pp = p
while pp <= N:
    p_powers.append(pp)
    pp *= p
```Tương tự cho$q$. 

Sau đó, chúng tôi kiểm tra mọi sản phẩm:```python
val = a * b
```Nếu nó thỏa mãn$$val \le N,$$chúng tôi tối đa hóa nó. 

--- 

## Vòng lặp tính tổng chính 

Với mỗi cặp số nguyên tố:```python
if p * q > N:
    break
```chúng tôi dừng lại ngay lập tức vì lớn hơn$q$chỉ tăng sản phẩm. 

Mỗi cặp hợp lệ đóng góp chính xác một giá trị$M(p,q,N)$.
