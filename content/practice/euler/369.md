[Vấn đề dự án Euler 369](https://projecteuler.net/problem=369) 

##Giải pháp 

**Trả lời:**`862400558448`Chúng tôi lập mô hình mỗi bàn tay theo 13 cấp bậc của nó. 

Đối với mỗi cấp bậc, chúng ta có thể chọn bất kỳ tập hợp con nào trong số 4 bộ (bao gồm cả bộ trống), do đó, mỗi cấp bậc đóng góp một trong 16 tập hợp con. 

MỘT$4$-card Badugi tồn tại nếu chúng ta có thể chọn bốn **cấp bậc riêng biệt** bao gồm tất cả bốn bộ đúng một lần - tương đương, trong biểu đồ lưỡng cực giữa cấp bậc và bộ, có sự trùng khớp về kích thước$4$. 

Chương trình Python sau đây thực hiện tìm kiếm lập trình động trên tất cả các cấu hình xếp hạng trong khi theo dõi xem kết quả phù hợp nào có thể đạt được.```
from collections import defaultdict
from functools import lru_cache

# All possible suit subsets for a rank:
# bit 0 = clubs, bit 1 = diamonds, bit 2 = hearts, bit 3 = spades
subs = list(range(16))

# Number of cards represented by each subset
sizes = [bin(x).count("1") for x in subs]

@lru_cache(None)
def trans(A, T):
    """
    A = bitmask describing which suit-sets can already be matched.
        If bit M is set, then suit-set M is achievable.

    T = suit subset available for the current rank.

    Return updated achievable mask after processing this rank.
    """
    reachable = [i for i in range(16) if (A >> i) & 1]

    B = A

    # Use current rank to extend a matching by one suit
    for M in reachable:
        for s in range(4):
            if (T >> s) & 1 and not ((M >> s) & 1):
                B |= 1 << (M | (1 << s))

    return B

# Initial state:
# only the empty matching is achievable
dp = {(1 << 0, 0): 1}

# Process all 13 ranks
for _ in range(13):
    nd = defaultdict(int)

    for (A, n), cnt in dp.items():
        for T in subs:
            nd[(trans(A, T), n + sizes[T])] += cnt

    dp = nd

# f[n] = number of n-card hands containing a Badugi
f = [0] * 53

for (A, n), cnt in dp.items():
    # bit 15 means all 4 suits can be matched
    if (A >> 15) & 1:
        f[n] += cnt

answer = sum(f[n] for n in range(4, 14))

print("f(5) =", f[5])
print("Answer =", answer)
```### Mã này làm gì 

- Mỗi cấp bậc độc lập chọn một tập hợp con các chất. 
-`A`theo dõi tất cả các kết hợp phù hợp hiện có thể phù hợp bằng cách sử dụng các cấp bậc riêng biệt. 
- Khi xử lý một tập hợp con xếp hạng mới`T`, chúng tôi có thể mở rộng bất kỳ kết quả phù hợp nào trước đó bằng cách thêm một bộ đồ chưa sử dụng từ`T`. 
- Nếu mặc vest`1111₂ = 15`trở nên có thể tiếp cận được thì sẽ có một bộ 4 bộ phù hợp đầy đủ, nghĩa là ván bài có chứa Badugi. 
- Chúng tôi tích lũy số lượng theo tổng kích thước bàn tay$n$. 

### Xác minh 

Chương trình tái tạo giá trị được đưa ra trong câu lệnh vấn đề:$$f(5)=514800$$trong đó xác nhận tính đúng đắn. 

Tổng số được tính là:$$\sum_{n=4}^{13} f(n) = 862400558448$$**Trả lời: 862400558448**
