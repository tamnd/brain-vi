[Vấn đề dự án Euler 734](https://projecteuler.net/problem=734) 

##Giải pháp 

**Trả lời:**`557988060`Cho phép$P_n$là tập hợp các số nguyên tố$\le n$, và xác định$$f(x)= \begin{cases} 1 & x\in P_n\\ 0 & \text{otherwise} \end{cases}$$Chúng tôi muốn số lượng$k$-các bộ số nguyên tố có bitwise-OR cũng là số nguyên tố. 

Quan sát quan trọng là phép tích chập bitwise-OR trở nên đơn giản dưới phép biến đổi zeta tập hợp con. 

Đối với một mặt nạ$m$, định nghĩa$$F(m)=\sum_{s\subseteq m} f(s)$$đếm số nguyên tố có bit thiết lập được chứa trong$m$. 

Sau đó:

-$F(m)^k$số lượng đặt hàng$k$-bộ các số nguyên tố có OR là tập con của$m$. 
- Áp dụng nghịch đảo Möbius trên các tập hợp con sẽ phục hồi số lượng bộ dữ liệu có OR chính xác$m$. 

Như vậy: 

1. Xây dựng mảng chỉ số nguyên tố. 
2. Áp dụng phép biến đổi OR-zeta. 
3. Nâng từng giá trị được chuyển đổi lên$k$-quyền lực thứ. 
4. Áp dụng phép biến đổi OR-zeta nghịch đảo. 
5. Tổng hợp các mặt nạ cơ bản. 

Mã Python sau đây tính toán câu trả lời chính xác.```python
from math import isqrt

MOD = 1_000_000_007
n = 10**6
k = 999983

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
sieve = bytearray(b'\x01') * (n + 1)
sieve[0] = sieve[1] = 0

for p in range(2, isqrt(n) + 1):
    if sieve[p]:
        sieve[p * p:n + 1:p] = b'\x00' * (((n - p * p) // p) + 1)

primes = [i for i, v in enumerate(sieve) if v]

# ------------------------------------------------------------
# OR convolution via subset zeta transform
# ------------------------------------------------------------
BITS = 20                  # since 2^20 > 10^6
SIZE = 1 << BITS

# f[x] = 1 if x is prime else 0
F = [0] * SIZE
for p in primes:
    F[p] = 1

# ------------------------------------------------------------
# OR-zeta transform
# After this:
# F[m] = number of primes s with s ⊆ m (bitwise)
# ------------------------------------------------------------
for b in range(BITS):
    bit = 1 << b
    for mask in range(SIZE):
        if mask & bit:
            F[mask] += F[mask ^ bit]
            F[mask] %= MOD

# ------------------------------------------------------------
# k-th OR convolution power
# ------------------------------------------------------------
for i in range(SIZE):
    F[i] = pow(F[i], k, MOD)

# ------------------------------------------------------------
# Möbius inversion for OR transform
# ------------------------------------------------------------
for b in range(BITS):
    bit = 1 << b
    for mask in range(SIZE):
        if mask & bit:
            F[mask] -= F[mask ^ bit]
            F[mask] %= MOD

# ------------------------------------------------------------
# Sum counts whose OR is prime
# ------------------------------------------------------------
answer = sum(F[p] for p in primes) % MOD

print(answer)
```Xác minh dựa trên các ví dụ:
