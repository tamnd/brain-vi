##Giải pháp 

**Trả lời:**`26241`Chìa khóa của vấn đề này là hiểu các con số trên các đường chéo tiến triển như thế nào khi đường xoắn ốc phát triển. 

Đối với một hình xoắn ốc có chiều dài cạnh$n$(Ở đâu$n$là số lẻ), lớp ngoài đóng góp chính xác bốn số góc mới. 

Ví dụ: 

- Chiều dài cạnh$1$: chỉ$1$- Chiều dài cạnh$3$: các góc là$3,5,7,9$- Chiều dài cạnh$5$: các góc là$13,17,21,25$- Chiều dài cạnh$7$: các góc là$31,37,43,49$Chúng ta cần theo dõi có bao nhiêu số đường chéo là số nguyên tố và xác định khi nào tỷ số đầu tiên giảm xuống dưới$10\%$. 

--- 

# Phân tích toán học 

##1. Công thức tính số góc 

Xét một hình vuông có độ dài cạnh lẻ$n$. 

Số lớn nhất trong lớp luôn ở góc dưới bên phải:$$n^2$$Kích thước bước giữa các góc liền kề là:$$n-1$$Vậy bốn góc là:$$\begin{aligned} c_1 &= n^2 \\ c_2 &= n^2-(n-1) \\ c_3 &= n^2-2(n-1) \\ c_4 &= n^2-3(n-1) \end{aligned}$$Ví dụ cho$n=7$:$$49,\ 43,\ 37,\ 31$$phù hợp với sơ đồ. 

--- 

## 2. Số mục chéo 

Mỗi lớp mới thêm 4 số đường chéo. 

Về chiều dài cạnh$n$:$$\text{total diagonal numbers} = 2n-1$$Kiểm tra:

-$n=1$:$1$-$n=3$:$5$-$n=5$:$9$-$n=7$:$13$Chính xác. 

--- 

##3. Tỷ lệ cơ bản 

Tại mỗi lớp: 

1. Tạo 4 số góc. 
2. Kiểm tra từng tính nguyên thủy. 
3. Cập nhật:$$\text{ratio} = \frac{\text{prime diagonal count}} {\text{total diagonal count}}$$Chúng tôi tìm kiếm điều đầu tiên$n$như vậy:$$\frac{\text{primes}}{2n-1} < 0.10$$--- 

#Triển khai Python```python
import math

def is_prime(n):
    """Return True if n is prime, else False."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    limit = int(math.isqrt(n))
    d = 3

    while d <= limit:
        if n % d == 0:
            return False
        d += 2

    return True

prime_count = 0
diagonal_count = 1   # starts with center value 1
side_length = 1

while True:
    side_length += 2

    square = side_length * side_length
    step = side_length - 1

    # The four corner values
    corners = [
        square,
        square - step,
        square - 2 * step,
        square - 3 * step
    ]

    # Count primes among the corners
    for c in corners:
        if is_prime(c):
            prime_count += 1

    diagonal_count += 4

    # Check ratio
    if prime_count / diagonal_count < 0.10:
        print(side_length)
        break
```---
