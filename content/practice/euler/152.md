## Giải pháp 

**Trả lời:**`301`Tìm kiếm mạnh mẽ trực tiếp trên tất cả các tập hợp con của$\{2,3,\dots,80\}$là không thể:$$2^{79} \approx 6\times 10^{23}.$$Chìa khóa để giải quyết vấn đề là khai thác các ràng buộc số học mạnh đến từ mẫu số và tính chia hết theo mô đun. 

--- 

# Phân tích toán học 

Chúng tôi tìm kiếm tất cả các tập hợp con$S \subseteq \{2,\dots,80\}$như vậy$$\sum_{n\in S}\frac1{n^2}=\frac12.$$Định nghĩa$$f(n)=\frac1{n^2}.$$Quan sát trọng tâm là hầu hết các số nguyên không bao giờ có thể tham gia vào một nghiệm hợp lệ do các hạn chế về tính chia hết của thừa số nguyên tố. 

--- 

##1. Lọc chia hết công suất 

Giả sử một số nguyên tố$p$xuất hiện đúng một mẫu số với giá trị lớn nhất$p$-adic quyền lực. 

Ví dụ: nếu$n$chia hết cho$p^k$và không có mẫu số được chọn nào khác chứa$p^k$, thì sau khi xóa mẫu số, tử số của số hạng đó khác 0 theo modulo$p$, trong khi tất cả những cái khác biến mất theo modulo$p$. Vì vậy việc hủy bỏ là không thể. 

Điều này tạo ra những hạn chế cực kỳ mạnh mẽ. 

--- 

### Ví dụ: số nguyên tố$79$Mẫu số duy nhất chia hết cho$79$là$79$chính nó. 

Nếu như$1/79^2$xuất hiện thì sau khi nhân với mẫu số chung, chúng ta sẽ nhận được modulo thặng dư khác 0$79$, không thể hủy được. 

Kể từ đây:$$79 \notin S.$$Lập luận tương tự loại bỏ nhiều con số. 

--- 

## 2. Xây dựng tập hợp được chấp nhận 

Việc loại bỏ đệ quy tiêu chuẩn chỉ để lại các số nguyên:$$\{2,3,4,5,6,7,8,9,10,12,14,15,18,20,21,24,28,30,35,36,40,42,45,56,60,63,70,72\}.$$Mọi giải pháp hợp lệ phải được chứa trong tập hợp này. 

Điều này làm giảm đáng kể không gian tìm kiếm:$$2^{28}\approx 2.68\times10^8,$$vẫn còn lớn, nhưng giờ đây đã khả thi với số học hợp lý chính xác và gặp nhau. 

--- 

## 3. Biểu diễn số nguyên chính xác 

hãy để$$L=\operatorname{lcm}(n^2 : n\in A),$$Ở đâu$A$là tập hợp được chấp nhận 

Sau đó$$\frac1{n^2} = \frac{L/n^2}{L}.$$Vậy phương trình trở thành$$\sum_{n\in S} \frac{L}{n^2} = \frac{L}{2}.$$Bây giờ mọi thứ đều là tổng tập hợp con số nguyên. 

Định nghĩa$$a_n = \frac{L}{n^2},\qquad T=\frac{L}{2}.$$Chúng ta phải đếm các tập hợp con với$$\sum a_n = T.$$--- 

## 4. Gặp nhau giữa chừng 

Chia bộ được chấp nhận thành hai nửa: 

- nửa bên trái$A_1$- nửa bên phải$A_2$Liệt kê tất cả các tập hợp con của mỗi nửa. 

Nếu như$$x+y=T,$$với$x$từ bên trái và$y$từ bên phải, sau đó chúng cùng nhau tạo thành một nghiệm hợp lệ. 

Sự phức tạp trở nên đại khái$$2^{14}+2^{14},$$cái đó nhỏ xíu 

--- 

#Triển khai Python```python
from math import gcd
from functools import reduce
from collections import Counter

# ------------------------------------------------------------
# Utility: least common multiple
# ------------------------------------------------------------

def lcm(a, b):
    return a * b // gcd(a, b)

# ------------------------------------------------------------
# Step 1:
# After modular/divisibility elimination, only these numbers
# can possibly appear in a solution.
# ------------------------------------------------------------

allowed = [
    2, 3, 4, 5, 6, 7, 8, 9, 10,
    12, 14, 15, 18, 20, 21, 24,
    28, 30, 35, 36, 40, 42, 45,
    56, 60, 63, 70, 72
]

# ------------------------------------------------------------
# Step 2:
# Convert the reciprocal-square equation into an integer
# subset-sum equation.
# ------------------------------------------------------------

# L = lcm of all n^2
L = reduce(lcm, (n * n for n in allowed))

# Integer weights
weights = [L // (n * n) for n in allowed]

# Target sum
TARGET = L // 2

# ------------------------------------------------------------
# Step 3:
# Meet-in-the-middle
# ------------------------------------------------------------

mid = len(weights) // 2

left = weights[:mid]
right = weights[mid:]

def subset_sums(arr):
    """
    Return Counter mapping:
        subset_sum -> number_of_ways
    """
    m = len(arr)
    sums = Counter()

    for mask in range(1 << m):
        s = 0
        for i in range(m):
            if mask & (1 << i):
                s += arr[i]
        sums[s] += 1

    return sums

left_sums = subset_sums(left)
right_sums = subset_sums(right)

# ------------------------------------------------------------
# Step 4:
# Count complementary pairs
# ------------------------------------------------------------

answer = 0

for s_left, count_left in left_sums.items():
    needed = TARGET - s_left

    if needed in right_sums:
        answer += count_left * right_sums[needed]

print(answer)
```---

## So sánh số tiền bổ sung 

Nếu một tập hợp con bên trái có tổng bằng$s$, thì tập con bên phải phải có tổng bằng$$TARGET - s.$$Vì thế:```python
answer += count_left * right_sums[needed]
```đếm tất cả các cặp tương thích.
