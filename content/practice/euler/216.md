[Dự án Euler Vấn đề 216](https://projecteuler.net/problem=216) 

##Giải pháp 

**Trả lời:**`5437849`Chúng ta phải đếm các số nguyên tố có dạng$$t(n)=2n^2-1,\qquad 1<n\le 50\,000\,000.$$Vấn đề nêu rõ rằng đối với$n\le 10\,000$, chính xác$2202$các giá trị là số nguyên tố. Chúng tôi cần số lượng lên tới$5\times 10^7$. 

--- 

# Phân tích toán học 

Chúng tôi tìm kiếm số lượng$n$như vậy$$2n^2-1$$là nguyên tố. 

Kiểm tra tính nguyên thủy trực tiếp cho tất cả$50$triệu giá trị là quá chậm trừ khi chúng ta khai thác cấu trúc đại số. 

--- 

##1. Cấu trúc đồng đẳng 

Giả sử một số nguyên tố$p$chia rẽ$2n^2-1$. Sau đó$$2n^2 \equiv 1 \pmod p$$ngụ ý$$n^2 \equiv \frac12 \pmod p.$$Tương đương,$$(2n)^2 \equiv 2 \pmod p.$$Như vậy$2$phải là thặng dư bậc hai modulo$p$. Bằng sự tương hỗ bậc hai,$$\left(\frac{2}{p}\right)=1 \iff p\equiv 1,7 \pmod 8.$$Do đó mọi ước số nguyên tố lẻ của$2n^2-1$thỏa mãn$$p\equiv 1 \text{ or } 7 \pmod 8.$$Với mỗi số nguyên tố như vậy$p$, sự phù hợp$$2n^2\equiv 1 \pmod p$$có đúng hai nghiệm modulo$p$. 

Điều đó có nghĩa là chúng ta có thể sàng tất cả các giá trị tổng hợp giống hệt như sàng nguyên tố. 

--- 

##2. Chiến lược sàng 

Xác định$$f(n)=2n^2-1.$$Ban đầu giả sử mọi$f(n)$là nguyên tố. 

Đối với mỗi số nguyên tố$p\equiv1,7\pmod8$: 

1. Giải quyết$$2n^2\equiv1\pmod p.$$2. Để hai gốc rễ$r_1,r_2$. 
3. Mỗi$$n\equiv r_1,r_2\pmod p$$cho$p\mid f(n)$. 

Chúng tôi đánh dấu tất cả như vậy$n$. 

Tuy nhiên, nếu$f(n)=p$chính nó, chúng ta phải _không_ đánh dấu nó là hỗn hợp. 

Điều đó chỉ xảy ra khi$$2n^2-1=p.$$Vì vậy trong quá trình sàng chúng ta chỉ đánh dấu khi$$2n^2-1>p.$$Điều này hoàn toàn tương tự với việc khởi động sàng thông thường ở$p^2$. 

--- 

## 3. Tính nghiệm 

Chúng ta cần giải pháp của$$2n^2\equiv1\pmod p.$$Nhân với nghịch đảo của$2$:$$n^2\equiv 2^{-1}\pmod p.$$Tương đương,$$(2n)^2\equiv2\pmod p.$$Như vậy nếu$s^2\equiv2\pmod p$, sau đó$$n\equiv s\cdot 2^{-1}\pmod p.$$Vì vậy chúng ta chỉ cần căn bậc hai mô đun của$2$modulo$p$, có thể đạt được thông qua Tonelli–Shanks. 

--- 

## 4. Độ phức tạp 

Chúng tôi sàng lọc$N=50\,000\,000$chỉ số. 

Mật độ hài trên các số nguyên tố cho tổng công xấp xỉ$$N\sum_{p}\frac{2}{p} \sim 2N\log\log N,$$điều này khả thi trong mã được tối ưu hóa. 

Đây là phương pháp giải tiêu chuẩn được chấp nhận cho bài toán Euler này. 

--- 

#Triển khai Python```python
from array import array
from math import isqrt

LIMIT = 50_000_000

# ------------------------------------------------------------
# Ordinary prime sieve up to sqrt(2)*LIMIT
# Any composite t(n)=2n^2-1 has a prime divisor <= sqrt(t(n))
# ------------------------------------------------------------

P = isqrt(2 * LIMIT * LIMIT - 1) + 1

is_prime = bytearray(b"\x01") * (P + 1)
is_prime[0] = is_prime[1] = 0

for i in range(2, isqrt(P) + 1):
    if is_prime[i]:
        step = i
        start = i * i
        is_prime[start:P + 1:step] = b"\x00" * ((P - start) // step + 1)

primes = [p for p in range(2, P + 1) if is_prime[p]]

# ------------------------------------------------------------
# Tonelli-Shanks modular square root
# Finds x such that x^2 = n (mod p)
# ------------------------------------------------------------

def tonelli(n, p):
    assert pow(n, (p - 1) // 2, p) == 1

    if p % 4 == 3:
        return pow(n, (p + 1) // 4, p)

    # write p-1 = q * 2^s with q odd
    q = p - 1
    s = 0
    while q % 2 == 0:
        s += 1
        q //= 2

    # find quadratic nonresidue z
    z = 2
    while pow(z, (p - 1) // 2, p) != p - 1:
        z += 1

    c = pow(z, q, p)
    x = pow(n, (q + 1) // 2, p)
    t = pow(n, q, p)
    m = s

    while t != 1:
        i = 1
        temp = (t * t) % p
        while temp != 1:
            temp = (temp * temp) % p
            i += 1

        b = pow(c, 1 << (m - i - 1), p)

        x = (x * b) % p
        t = (t * b * b) % p
        c = (b * b) % p
        m = i

    return x

# ------------------------------------------------------------
# Candidate array:
# 1 means "possibly prime"
# ------------------------------------------------------------

cand = bytearray(b"\x01") * (LIMIT + 1)
cand[0] = cand[1] = 0

# ------------------------------------------------------------
# Sieve using prime divisors
# ------------------------------------------------------------

for p in primes:
    if p == 2:
        continue

    # 2 must be quadratic residue mod p
    if p % 8 not in (1, 7):
        continue

    # sqrt(2) mod p
    s = tonelli(2, p)

    inv2 = (p + 1) // 2

    r1 = (s * inv2) % p
    r2 = (-r1) % p

    for r in (r1, r2):
        if r == 0:
            start = p
        else:
            start = r

        # ensure 2*n^2 - 1 > p
        while 2 * start * start - 1 <= p:
            start += p

        for n in range(start, LIMIT + 1, p):
            cand[n] = 0

# ------------------------------------------------------------
# Count survivors
# ------------------------------------------------------------

answer = sum(cand)

print(answer)
```--- 

# Hướng dẫn sử dụng mã 

## Thế hệ Prime 

Chúng tôi tạo ra tất cả các số nguyên tố lên đến$$\sqrt{2N^2-1}.$$Nếu như$2n^2-1$là hợp số, nó có thừa số nguyên tố không lớn hơn giới hạn này. 

--- 

## Tonelli–Shanks`tonelli(n,p)`tính căn bậc hai modulo một số nguyên tố:$$x^2\equiv n\pmod p.$$Chúng tôi sử dụng nó với$n=2$. 

--- 

## Xây dựng gốc 

Nếu$$s^2\equiv2\pmod p,$$sau đó$$n\equiv s\cdot2^{-1}\pmod p$$giải quyết$$2n^2\equiv1\pmod p.$$Gốc thứ hai là$-r_1$. 

--- 

## Đánh dấu vật liệu tổng hợp 

Đối với mỗi loại dư lượng:```python
for n in range(start, LIMIT + 1, p):
    cand[n] = 0
```đánh dấu mọi$n$như vậy$p\mid (2n^2-1)$. 

Vòng lặp```python
while 2 * start * start - 1 <= p:
    start += p
```ngăn chặn việc loại bỏ giá trị nguyên tố$2n^2-1=p$.
