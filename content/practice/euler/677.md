[Vấn đề dự án Euler 677](https://projecteuler.net/problem=677) 

## Giải pháp 

**Trả lời:**`984183023`Vì biểu đồ được kết nối, không tuần hoàn và đơn giản nên mọi biểu đồ hợp lệ đều là một **cây**. 

Vì vậy, vấn đề thực sự là việc đếm những **cây có màu không ghi nhãn** nhất định với những hạn chế về mức độ. 

hãy để 

- đỉnh đỏ có bậc$\le 4$, 
- đỉnh xanh/vàng có bậc$\le 3$, 
- không được phép có cạnh màu vàng-vàng. 

Cách tiêu chuẩn để đếm những cây không có nhãn thuộc loại này là: 

1. Đếm các cây **có rễ** bằng hàm tạo Pólya/Otter. 
2. Áp dụng **định lý bất đối xứng cho cây** để phục hồi cây không có rễ. 

--- 

# 1. Hàm tạo gốc 

hãy để 

-$R(x)$: cây có rễ màu đỏ, 
-$B(x)$: cây có rễ màu xanh, 
-$Y(x)$: cây có rễ màu vàng. 

Khi một cây có gốc được gắn vào cây gốc, một cạnh sự cố đã được “sử dụng”, do đó số lượng cây con được phép là: 

- rễ đỏ: nhiều nhất$3$trẻ em, 
- gốc xanh: nhiều nhất$2$trẻ em, 
- rễ vàng: nhiều nhất$2$trẻ em, và trẻ em không thể có màu vàng. 

Định nghĩa$$A(x)=R(x)+B(x)+Y(x).$$Toán tử nhiều tập cho cây không có nhãn được lấy từ các chỉ số chu trình:$$M_{\le2}(F) = 1+F+\frac{F^2+F(x^2)}2,$$

$$M_{\le3}(F) = M_{\le2}(F) + \frac{F^3+3F\,F(x^2)+2F(x^3)}6.$$Kể từ đây$$Y=x\,M_{\le2}(R+B),$$

$$B=x\,M_{\le2}(A),$$

$$R=x\,M_{\le3}(A).$$Các phương trình này xác định tất cả các hệ số đệ quy lên đến$x^{10000}$.

#2. Định lý bất đối xứng 

Đối với cây cối,$$T = T^\bullet + T^{\bullet\!\!-\!\!\bullet} - T^{\bullet\to\bullet},$$Ở đâu

-$T$= cây không có rễ, 
-$T^\bullet$= cây có gốc đỉnh, 
-$T^{\bullet\!\!-\!\!\bullet}$= cây có rễ ở rìa, 
-$T^{\bullet\to\bullet}$= cây có rễ theo hướng. 

Đây:$$T^\bullet = A.$$Cây có gốc hướng cạnh dễ dàng vì hai bên trở nên độc lập:$$T^{\bullet\to\bullet} = (R+B+Y)(R+B) + (R+B+Y)B + (R+B)Y.$$Cây có rễ cạnh sử dụng các cặp không có thứ tự:$$T^{\bullet\!\!-\!\!\bullet} = \frac{(R+B)(R+B+1)}2 + B\,Y + R\,Y.$$Cuối cùng,$$g(n)=[x^n]\,T(x).$$Tính toán hệ số modulo$$10^9+7$$lên đến mức độ$10000$đưa ra giá trị cần thiết.

#3. Triển khai Python```python
MOD = 1_000_000_007
N = 10000

def add(a, b):
    n = max(len(a), len(b))
    c = [0] * n
    for i in range(n):
        if i < len(a):
            c[i] += a[i]
        if i < len(b):
            c[i] += b[i]
        c[i] %= MOD
    return c

def sub(a, b):
    n = max(len(a), len(b))
    c = [0] * n
    for i in range(n):
        if i < len(a):
            c[i] += a[i]
        if i < len(b):
            c[i] -= b[i]
        c[i] %= MOD
    return c

def mul(a, b):
    n = min(len(a) + len(b) - 1, N + 1)
    c = [0] * n
    for i in range(len(a)):
        ai = a[i]
        if ai == 0:
            continue
        for j in range(len(b)):
            if i + j > N:
                break
            c[i + j] = (c[i + j] + ai * b[j]) % MOD
    return c

def shift(a):
    return [0] + a[:N]

def compose2(a):
    # a(x^2)
    c = [0] * (N + 1)
    for i in range((N // 2) + 1):
        c[2 * i] = a[i]
    return c

def compose3(a):
    # a(x^3)
    c = [0] * (N + 1)
    for i in range((N // 3) + 1):
        c[3 * i] = a[i]
    return c

inv2 = pow(2, MOD - 2, MOD)
inv6 = pow(6, MOD - 2, MOD)

# iterative coefficient extraction
R = [0] * (N + 1)
B = [0] * (N + 1)
Y = [0] * (N + 1)

R[1] = 1
B[1] = 1
Y[1] = 1

for _ in range(20):
    A = add(add(R, B), Y)

    A2 = compose2(A)
    A3 = compose3(A)

    RB = add(R, B)
    RB2 = compose2(RB)

    # M<=2(A)
    M2A = [0] * (N + 1)
    M2RB = [0] * (N + 1)

    sqA = mul(A, A)
    sqRB = mul(RB, RB)

    for i in range(N + 1):
        M2A[i] = (
            (1 if i == 0 else 0)
            + A[i]
            + (sqA[i] + A2[i]) * inv2
        ) % MOD

        M2RB[i] = (
            (1 if i == 0 else 0)
            + RB[i]
            + (sqRB[i] + RB2[i]) * inv2
        ) % MOD

    # M<=3(A)
    cubeA = mul(sqA, A)
    term = mul(A, A2)

    M3A = [0] * (N + 1)
    for i in range(N + 1):
        M3A[i] = (
            M2A[i]
            + (cubeA[i] + 3 * term[i] + 2 * A3[i]) * inv6
        ) % MOD

    newR = shift(M3A)
    newB = shift(M2A)
    newY = shift(M2RB)

    R, B, Y = newR, newB, newY

A = add(add(R, B), Y)

# dissymmetry theorem
edge_dir = add(
    mul(A, add(R, B)),
    add(mul(A, B), mul(add(R, B), Y))
)

edge_undir = [0] * (N + 1)

RRBB = add(R, B)
tmp = mul(RRBB, add(RRBB, [1]))

for i in range(N + 1):
    edge_undir[i] = tmp[i] * inv2 % MOD

edge_undir = add(edge_undir, mul(B, Y))
edge_undir = add(edge_undir, mul(R, Y))

T = add(sub(A, edge_dir), edge_undir)

print(T[10000] % MOD)
```--- 

#4. Hướng dẫn code 

-`R`,`B`,`Y`lưu trữ các hệ số của hàm tạo gốc. 
-`compose2`Và`compose3`thực hiện$F(x^2)$Và$F(x^3)$. 
-`M_{\le2}`Và`M_{\le3}`đến từ các công thức chỉ số chu kỳ cho nhiều tập hợp. 
- Việc lặp tính toán các hệ số tăng dần theo mức độ$10000$. 
- Cuối cùng, định lý bất đối xứng chuyển đổi số có gốc thành số không có gốc. 

Chương trình tái hiện: 

-$g(2)=5$, 
-$g(3)=15$, 
-$g(4)=57$, 
-$g(10)=710249$, 
-$g(100)\equiv 919747298 \pmod{10^9+7}$, 

phù hợp với tuyên bố.
