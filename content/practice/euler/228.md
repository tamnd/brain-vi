Một thực tế tiêu chuẩn về tổng Minkowski của đa giác lồi là: 

> Tập hợp các hướng cạnh (tương đương với các hướng pháp tuyến hướng ra ngoài) của 
> 
>$P+Q$là hợp các hướng của cạnh của$P$Và$Q$. 

Vì vậy, vấn đề giảm xuống còn việc đếm các hướng cạnh khác nhau xuất hiện giữa$$S_{1864},S_{1865},\dots,S_{1909}.$$--- 

# 1. Hình học của$S_n$Các đỉnh của$S_n$là$$v_k=\left(\cos\frac{(2k-1)\pi}{n},\, \sin\frac{(2k-1)\pi}{n}\right).$$Chúng cách đều nhau xung quanh vòng tròn đơn vị, được quay bởi$\pi/n$. 

Các đỉnh kề nhau thì vuông góc$$\frac{(2k-1)\pi}{n},\qquad \frac{(2k+1)\pi}{n}.$$Cạnh giữa chúng có hướng là trung điểm$$\frac{2k\pi}{n}.$$Do đó các hướng pháp tuyến bên ngoài của$n$các bên đều chính xác$$\frac{2k\pi}{n},\qquad k=0,1,\dots,n-1.$$Vì thế$S_n$đóng góp những hướng đi$$\left\{\frac{k}{n}\pmod 1\right\}.$$--- 

# 2. Các hướng khác nhau trong tổng Minkowski 

Hai hướng trùng nhau$$\frac{k_1}{n_1}\equiv \frac{k_2}{n_2}\pmod 1.$$Sau khi quy giản về số hạng thấp nhất, mỗi hướng tương ứng duy nhất với một phân số rút gọn$$\frac{a}{d},\qquad \gcd(a,d)=1.$$Hướng như vậy xuất hiện nếu$d\mid n$cho ít nhất một$n\in[1864,1909]$. 

Đối với mỗi mẫu số$d$, có chính xác$\varphi(d)$phân số rút gọn có mẫu số đó. 

Vì vậy: 

\boxed{ \text{# side} = \sum_{\substack{d\ge1\\ d\mid n\text{ cho một số }1864\le n\le1909}} \varphi(d) } 

ở đâu$\varphi$là hàm tổng Euler.

#3. Triển khai Python```python
from math import gcd

# Euler totient
def phi(n):
    result = n
    p = 2
    m = n

    while p * p <= m:
        if m % p == 0:
            while m % p == 0:
                m //= p
            result -= result // p
        p += 1

    if m > 1:
        result -= result // m

    return result

# Collect every divisor of numbers 1864..1909
divisors = set()

for n in range(1864, 1910):
    for d in range(1, int(n**0.5) + 1):
        if n % d == 0:
            divisors.add(d)
            divisors.add(n // d)

# Sum Euler totients
answer = sum(phi(d) for d in divisors)

print(answer)
