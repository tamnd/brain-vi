# 1. Phân tích toán học 

Chúng ta phải sử dụng các chữ số$1,2,\dots,9$đúng một lần và theo thứ tự. 

Được phép: 

- nối, 
-$+$,$-$,$\times$,$/$, 
- dấu ngoặc đơn tùy ý. 

Không được phép: 

- trừ đơn nhất. 

Chúng ta phải tìm mọi **số nguyên dương** có thể nhận được và tính tổng chúng. 

--- 

## 1.1 Biểu diễn bài toán con 

Xác định$$F(i,j)$$là tập hợp tất cả các số hữu tỉ có thể đạt được bằng cách sử dụng các chữ số liên tiếp$$(i+1)(i+2)\cdots j$$Ví dụ:

-$F(0,1)=\{1\}$-$F(1,3)$sử dụng chữ số$23$-$F(0,9)$là toàn bộ vấn đề 

Mỗi khối có thể: 

1. được sử dụng như một số nguyên nối, 
2. hoặc bị chia cắt vào một thời điểm nào đó$k$:$$[i,k) \quad\text{and}\quad [k,j)$$và được kết hợp bởi một phép toán nhị phân. 

Như vậy:$$F(i,j)=\{\text{concatenated integer}\} \cup \bigcup_{k=i+1}^{j-1} \left\{ a+b,\ a-b,\ a\times b,\ a/b \right\}$$cho tất cả$$a\in F(i,k),\quad b\in F(k,j),$$chỉ có phép chia khi$b\neq0$. 

--- 

##1.2 Tại sao cần có lý trí 

Biểu thức trung gian có thể không phải là số nguyên. 

Ví dụ từ tuyên bố:$$(1/23)\times((4\times5)-6)\times(78-9)=42$$Vì vậy chúng ta phải giữ số học hợp lý chính xác. 

Sử dụng dấu phẩy động sẽ tạo ra lỗi chính xác và hợp nhất các giá trị riêng biệt không chính xác. 

Vì vậy chúng tôi sử dụng kiểu hợp lý chính xác của Python:$$\texttt{Fraction}$$--- 

##1.3 Độ phức tạp 

Chỉ có:$$\frac{9\cdot10}{2}=45$$các khoảng chữ số. 

Mỗi khoảng kết hợp đệ quy các khoảng nhỏ hơn. 

Ghi nhớ làm cho việc tính toán hoàn toàn khả thi.

#2. Triển khai Python```python
from fractions import Fraction
from functools import lru_cache

digits = "123456789"

@lru_cache(None)
def values(i, j):
    """
    Returns the set of all rational values obtainable
    from digits[i:j].
    """

    result = set()

    # Option 1: concatenate all digits into one integer
    result.add(Fraction(int(digits[i:j]), 1))

    # Option 2: split into two parts
    for k in range(i + 1, j):

        left_values = values(i, k)
        right_values = values(k, j)

        for a in left_values:
            for b in right_values:

                result.add(a + b)
                result.add(a - b)
                result.add(a * b)

                if b != 0:
                    result.add(a / b)

    return result

# Compute all values using digits 1..9
all_values = values(0, 9)

# Keep only positive integers
reachable = {
    x.numerator
    for x in all_values
    if x.denominator == 1 and x > 0
}

answer = sum(reachable)

print(answer)
```---
