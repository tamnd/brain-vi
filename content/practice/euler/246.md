##Giải pháp 

**Trả lời:**`810834388`Giả sử hình elip được mô tả theo tọa độ có tâm ở tâm của nó. 

Dữ liệu đã cho là 

-$M=(-2000,1500)$-$G=(8000,1500)$- bán kính hình tròn$r=15000$Khoảng cách giữa$M$Và$G$là$$|MG|=10000.$$--- 

# 1. Suy ra hình elip 

Vì một điểm$P$, khoảng cách đến đường tròn là$$PM-r.$$Hình elip được xác định bởi$$PG = PM-r.$$Kể từ đây$$PG+ r = PM.$$Vậy tổng khoảng cách đến hai tiêu điểm là không đổi:$$PG+PM = 15000.$$Do đó hình elip có$$2a=15000 \quad\Rightarrow\quad a=7500.$$Tiêu cự là$$2c=10000 \quad\Rightarrow\quad c=5000.$$Như vậy$$b^2=a^2-c^2 =7500^2-5000^2 =56\,250\,000-25\,000\,000 =31\,250\,000.$$Trung tâm là$$\left(\frac{-2000+8000}{2},1500\right)=(3000,1500).$$Sử dụng tọa độ đã dịch chuyển$$x=X-3000,\qquad y=Y-1500,$$phương trình elip trở thành$$\frac{x^2}{56\,250\,000}+\frac{y^2}{31\,250\,000}=1.$$--- 

#2. Tiếp tuyến từ một điểm ngoài 

Xét một điểm bên ngoài$P=(x_0,y_0)$. 

Một dòng xuyên qua$P$có độ dốc$m$là$$y=m(x-x_0)+y_0.$$Viết nó như$$y=mx+c, \qquad c=y_0-mx_0,$$đường thẳng này tiếp tuyến với hình elip$$c^2=a^2m^2+b^2.$$Thay thế$c=y_0-mx_0$:$$(y_0-mx_0)^2=a^2m^2+b^2.$$Điều này đưa ra phương trình bậc hai cho hệ số góc tiếp tuyến:$$(x_0^2-a^2)m^2-2x_0y_0m+(y_0^2-b^2)=0.$$Giả sử hai hệ số góc tiếp tuyến là$m_1,m_2$. 

góc$\theta=\angle RPS$giữa các tiếp tuyến thỏa mãn$$\tan\theta = \left| \frac{m_1-m_2}{1+m_1m_2} \right|.$$Sử dụng công thức của Vieta và đơn giản hóa sẽ mang lại$$\tan^2\theta = \frac{ 4\left(b^2x_0^2+a^2y_0^2-a^2b^2\right) }{ \left(a^2+b^2-x_0^2-y_0^2\right)^2 }.$$Chúng tôi cần$$\theta>45^\circ \quad\Longleftrightarrow\quad \tan^2\theta>1.$$Vì thế$$4(b^2x^2+a^2y^2-a^2b^2) > (a^2+b^2-x^2-y^2)^2.$$Thay thế$$a^2=56\,250\,000, \qquad b^2=31\,250\,000,$$và đơn giản hóa:$$x^4+2x^2y^2+y^4 -300\,000\,000x^2 -400\,000\,000y^2 +14\,687\,500\,000\,000\,000 <0.$$Chúng ta phải đếm các điểm mạng thỏa mãn bất đẳng thức này và nằm ngoài hình elip$$\frac{x^2}{56\,250\,000} + \frac{y^2}{31\,250\,000} >1.$$--- 

#3. Đếm hiệu quả 

Để cố định$x$, bất đẳng thức là bậc hai trong$y^2$. 

Cho phép$z=y^2$. Sau đó$$z^2+(2x^2-400000000)z + x^4-300000000x^2+14687500000000000 <0.$$Vì thế$z$nằm chặt chẽ giữa hai gốc:$$z_\pm = 200000000-x^2 \pm 10000\sqrt{253125000-x^2}.$$Như vậy với mỗi số nguyên$x$, các số nguyên hợp lệ$y$thỏa mãn$$z_-<y^2<z_+,$$cùng với điều kiện mặt ngoài của elip.

#4. Triển khai Python```python
import math

# Ellipse parameters
a2 = 56_250_000
b2 = 31_250_000

def valid(x, y):
    x2 = x * x
    y2 = y * y

    # angle > 45 degrees
    lhs = 4 * (b2 * x2 + a2 * y2 - a2 * b2)
    rhs = (a2 + b2 - x2 - y2) ** 2

    # outside ellipse
    outside = (x2 / a2 + y2 / b2) > 1

    return lhs > rhs and outside

total = 0

# x-range comes from discriminant >= 0
for x in range(0, 15911):

    x2 = x * x
    d = 253_125_000 - x2

    if d <= 0:
        continue

    A = 200_000_000 - x2
    B = 10_000 * math.sqrt(d)

    low = A - B
    high = A + B

    if high <= 0:
        continue

    # approximate y-range
    ymin = max(0, int(math.sqrt(max(low, 0))) - 5)

    # move upward until valid
    while True:
        y2 = ymin * ymin
        if y2 > low and (5 * x2 + 9 * y2 > 281_250_000):
            break
        ymin += 1

    ymax = int(math.sqrt(high)) + 5

    # move downward until valid
    while ymax >= ymin and not valid(x, ymax):
        ymax -= 1

    count = max(0, ymax - ymin + 1)

    # symmetry in all four quadrants
    if x == 0:
        total += 2 * count
    else:
        total += 4 * count

print(total)
```--- 

#5. Hướng dẫn code 

-`valid(x,y)`kiểm tra: 

1. bất đẳng thức góc tiếp tuyến, 
2. điểm đó nằm ngoài hình elip. 
- Bất đẳng thức bậc bốn giảm xuống bậc hai trong$y^2$, tạo ra giới hạn rõ ràng cho$y^2$. 
- Chúng tôi lặp lại tất cả các số nguyên khả thi$x$các giá trị. 
- Đối với mỗi$x$, chúng tôi tính khoảng hợp lệ của$y$. 
- Theo tính đối xứng ta tính được: 

-$4$sao chép khi$x\neq0$, 
-$2$sao chép khi$x=0$. 

Chương trình chạy nhanh và đưa ra số đếm chính xác.
