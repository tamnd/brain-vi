[Vấn đề dự án Euler 674](https://projecteuler.net/problem=674) 

## Giải pháp 

**Trả lời:**`416678753`Cho phép$$\mathcal I(x,y)=(1+x+y)^2+y-x.$$Quan sát quan trọng đó là$\mathcal I$là một mã hóa nội xạ của các cặp số nguyên không âm có thứ tự. 

Thật vậy, viết$$s=1+x+y.$$Sau đó$$\mathcal I(x,y)=s^2+(y-x).$$Từ$0\le y-x\le s-1$về giá trị tuyệt đối, mọi giá trị đều nằm trong một khoảng duy nhất xung quanh hình vuông$s^2$. Do đó từ$n=\mathcal I(x,y)$chúng ta có thể phục hồi duy nhất: 

-$s=\lfloor \sqrt n\rfloor$, 
-$d=n-s^2=y-x$, 
- và do đó$$x=\frac{s-1-d}{2},\qquad y=\frac{s-1+d}{2}.$$Vì thế:$$\mathcal I(a,b)=\mathcal I(c,d)\iff a=c\text{ and }b=d.$$Điều đó có nghĩa$\mathcal I$hoạt động chính xác giống như một biểu tượng hàm tạo trong sự thống nhất thuật ngữ bậc nhất. 

--- 

#1. Chuyển vấn đề thành thống nhất 

Mọi biểu thức đều là: 

- một biến, hoặc 
-$\mathcal I(A,B)$. 

Vì vậy giải quyết$$e_1=e_2$$giảm đệ quy thành:$$\mathcal I(A,B)=\mathcal I(C,D) \iff A=C \text{ and } B=D.$$Đây là sự thống nhất tiêu chuẩn của Robinson. 

Ví dụ: 

-$A=\mathcal I(x,\mathcal I(z,t))$-$B=\mathcal I(\mathcal I(y,z),y)$Đối số phù hợp cho:$$x=\mathcal I(y,z), \qquad \mathcal I(z,t)=y.$$Thay thế:$$x=\mathcal I(\mathcal I(z,t),z).$$Đặt các biến miễn phí ở mức tối thiểu ($z=t=0$) cho:$$y=\mathcal I(0,0)=1,$$

$$x=\mathcal I(1,0)=3,$$và do đó$$A=B=\mathcal I(3,1)=23.$$Đúng như đã nêu.

# 2. Tại sao mức tối thiểu lại xảy ra khi tất cả các biến tự do đều$0$Đối với số nguyên không âm,$$\mathcal I(x+1,y)-\mathcal I(x,y)=2(1+x+y)>0,$$

$$\mathcal I(x,y+1)-\mathcal I(x,y)=2(2+x+y)>0.$$Vì thế$\mathcal I$đang tăng lên một cách chặt chẽ trong mỗi đối số. 

Sau khi hợp nhất, bất kỳ biến nào không bị ràng buộc bởi các ràng buộc đều là số nguyên không âm tự do. Vì biểu thức đều đơn điệu ở mọi biến nên giá trị đồng thời ít nhất thu được bằng cách đặt mọi biến tự do còn lại thành$0$. 

Do đó thuật toán là: 

1. Phân tích biểu thức thành cây. 
2. Cố gắng thống nhất. 
3. Nếu không thể → đóng góp$0$. 
4. Mặt khác tính biểu thức hợp nhất với tất cả các biến còn lại$0$. 

Chỉ có cái cuối cùng$9$cần phải có chữ số nên việc tính toán được thực hiện theo modulo$10^9$.

#3. Triển khai Python```python
from __future__ import annotations
import sys

MOD = 10**9

# -------------------------------------------------
# Term representation
# -------------------------------------------------

class Var:
    __slots__ = ("name",)

    def __init__(self, name: str):
        self.name = sys.intern(name)

class INode:
    __slots__ = ("a", "b")

    def __init__(self, a, b):
        self.a = a
        self.b = b

# -------------------------------------------------
# Parsing
# -------------------------------------------------

def parse_expr(s: str):
    i = 0
    n = len(s)

    def parse():
        nonlocal i

        if s[i] == "I":
            i += 2  # skip "I("

            left = parse()

            i += 1  # skip ','

            right = parse()

            i += 1  # skip ')'

            return INode(left, right)

        start = i
        while i < n and s[i].isalpha():
            i += 1

        return Var(s[start:i])

    return parse()

# -------------------------------------------------
# Unification
# -------------------------------------------------

def unify(t1, t2):
    subs = {}
    occurs_cache = {}

    def deref(t):
        while isinstance(t, Var) and t.name in subs:
            nxt = subs[t.name]

            # path compression
            if isinstance(nxt, Var) and nxt.name in subs:
                subs[t.name] = subs[nxt.name]

            t = nxt

        return t

    def occurs(vname, t):
        t = deref(t)

        key = (vname, id(t))
        if key in occurs_cache:
            return occurs_cache[key]

        stack = [t]
        seen = set()

        while stack:
            cur = deref(stack.pop())

            if isinstance(cur, Var):
                if cur.name == vname:
                    occurs_cache[key] = True
                    return True
            else:
                nid = id(cur)

                if nid in seen:
                    continue

                seen.add(nid)

                stack.append(cur.a)
                stack.append(cur.b)

        occurs_cache[key] = False
        return False

    stack = [(t1, t2)]

    while stack:
        a, b = stack.pop()

        a = deref(a)
        b = deref(b)

        if a is b:
            continue

        if isinstance(a, Var) and isinstance(b, Var):
            if a.name == b.name:
                continue

        if isinstance(a, Var):
            if occurs(a.name, b):
                return None

            subs[a.name] = b
            continue

        if isinstance(b, Var):
            if occurs(b.name, a):
                return None

            subs[b.name] = a
            continue

        if isinstance(a, INode) and isinstance(b, INode):
            stack.append((a.a, b.a))
            stack.append((a.b, b.b))
            continue

        return None

    return subs

# -------------------------------------------------
# Evaluation
# -------------------------------------------------

def i_op(x, y):
    s = (1 + x + y) % MOD
    return (s * s + y - x) % MOD

def evaluate(root, subs):
    memo = {}

    def deref(t):
        while isinstance(t, Var) and t.name in subs:
            t = subs[t.name]
        return t

    def rec(t):
        t = deref(t)

        if isinstance(t, Var):
            return 0

        tid = id(t)

        if tid in memo:
            return memo[tid]

        x = rec(t.a)
        y = rec(t.b)

        val = i_op(x, y)

        memo[tid] = val
        return val

    return rec(root)

# -------------------------------------------------
# Solve
# -------------------------------------------------

def least_simultaneous_value(e1, e2):
    subs = unify(e1, e2)

    if subs is None:
        return 0

    return evaluate(e1, subs)

def main():
    with open("I-expressions.txt") as f:
        terms = [parse_expr(line.strip())
                 for line in f if line.strip()]

    total = 0

    n = len(terms)

    for i in range(n):
        for j in range(i + 1, n):
            total += least_simultaneous_value(
                terms[i], terms[j]
            )

    print(total % MOD)

if __name__ == "__main__":
    main()
```--- 

#4. Hướng dẫn code 

## Phân tích cú pháp`parse_expr`chuyển đổi chuỗi như$$I(x,I(z,t))$$thành cây nhị phân: 

-`Var(name)`-`INode(left,right)`--- 

## Thống nhất`unify(t1,t2)`thực hiện thống nhất Robinson: 

- biến vs biến, 
- biến và thuật ngữ ghép, 
- hợp chất vs hợp chất. 

Việc kiểm tra xảy ra sẽ ngăn chặn sự thay thế theo chu kỳ như:$$x = I(x,y).$$Nếu thống nhất thất bại, không có giải pháp không âm.
