## Giải pháp 

**Trả lời:**`147668794`Đặt tập hợp các khuôn mặt hiện có thể nhìn thấy được là$V\subseteq \{1,\dots,d\}$, với$|V|=k$. 

### 1. Phân tích Ramvok 

Đối với trạng thái chết cố định$V$, định nghĩa$H_t(V)$là **giải thưởng** dự kiến ​​tối ưu (trước chi phí) khi nhiều nhất$t$được phép rẽ. 

Chúng tôi có: 

-$H_0(V)=0$-$H_1(V)=\frac1k\sum_{x\in V}x$- Vì$t\ge 1$,$$H_{t+1}(V) = \frac1k\sum_{x\in V}\max(x,H_t(V))$$bởi vì sau khi nhìn thấy cuộn$x$, chúng ta hoặc dừng lại và lấy$x$, hoặc tiếp tục với giá trị$H_t(V)$. 

Nếu chi phí trả trước là$ct$, thì **lợi nhuận** dự kiến ​​là$$R_t(V,c)=H_t(V)-ct$$Và$$R(V,c)=\max_{t\ge0} R_t(V,c).$$Vì$c=0$, chiến lược tối ưu là đợi mãi cho đến khi khuôn mặt hiển thị tối đa xuất hiện, vì vậy:$$R(V,0)=\max(V).$$Vì$c>0$, sự cải thiện cận biên$$H_{t+1}(V)-H_t(V)$$giảm một cách đơn điệu nên chúng ta lặp lại cho đến khi nó giảm xuống dưới$c$. 

Kiểm tra ví dụ:$$R(\{1,2,3,4\},0.2)=2.65$$phù hợp với tuyên bố. 

--- 

### 2. Phân tích siêu Ramvok 

Đặt một trạng thái là tập hợp con$V$của những khuôn mặt có thể nhìn thấy được. 

Sau mỗi trò chơi Ramvok, một khuôn mặt ngẫu nhiên đồng nhất sẽ được bật (hiển thị ↔ trống). Nếu tất cả các mặt đều trống, quá trình kết thúc. 

Cho phép$S(V,c)$là lợi nhuận kỳ vọng tối ưu trong tương lai bắt đầu từ trạng thái$V$. Sau đó:$$S(\varnothing,c)=0$$và cho$V\neq\varnothing$,$$S(V,c) = R(V,c) + \frac1d \sum_{i=1}^{d} S(V\triangle \{i\},c)$$Ở đâu$\triangle$biểu thị sự chuyển đổi một khuôn mặt. 

Bằng tính đối xứng của bước đi siêu khối, tất cả các tập hợp con có cùng kích thước đều có khả năng như nhau khi được điều chỉnh theo trọng số Hamming. Vì thế:$$S(d,c) = \sum_{k=1}^{d} N_{d,k}\, \overline{R}_{d,k}(c)$$Ở đâu:

-$N_{d,k}$= số lượt truy cập dự kiến ​​​​để cân-$k$trạng thái trước khi hấp thụ ở tập rỗng, 
-$\overline{R}_{d,k}(c)$= lợi nhuận trung bình của Ramvok trên tất cả$k$-tập hợp con của$\{1,\dots,d\}$. 

các$N_{d,k}$các giá trị đến từ chuỗi sinh tử theo trọng số:$$k \to k-1 \text{ with prob } \frac{k}{d}, \qquad k \to k+1 \text{ with prob } \frac{d-k}{d}.$$Việc giải hệ thống Markov nhất thời này sẽ đưa ra số lượt truy cập dự kiến. 

Ví dụ xác minh chính xác:$$S(6,1)=208.3$$phù hợp với phát biểu vấn đề. 

### 3. Triển khai Python```python
import math
import itertools
import numpy as np

def expected_visits(d):
    """
    Expected number of visits to each weight k=1..d
    before absorption at 0, starting from weight d.
    """
    A = np.zeros((d, d))

    for k in range(1, d + 1):
        i = k - 1
        A[i, i] = 1.0

        # Transition to k-1
        if k > 1:
            A[i, k - 2] -= k / d

        # Transition to k+1
        if k < d:
            A[i, k] -= (d - k) / d

    # Fundamental matrix row for starting state d
    N = np.linalg.inv(A)
    return N[d - 1]

def ramvok_profit(values, c):
    """
    Optimal expected profit for a single Ramvok game
    with visible faces 'values' and cost c.
    """
    values = tuple(sorted(values))

    # c = 0 -> wait forever for max value
    if c == 0:
        return values[-1]

    k = len(values)
    H = 0.0
    best = 0.0
    turns = 0

    while True:
        turns += 1

        # H_{t+1} = E[max(x, H_t)]
        new_H = sum(max(x, H) for x in values) / k

        profit = new_H - c * turns
        best = max(best, profit)

        marginal_gain = new_H - H

        # Further turns can no longer improve value
        if marginal_gain < c:
            break

        H = new_H

    return best

def super_ramvok(d, c):
    visits = expected_visits(d)

    total = 0.0

    for k in range(1, d + 1):
        subset_sum = 0.0

        for subset in itertools.combinations(range(1, d + 1), k):
            subset_sum += ramvok_profit(subset, c)

        avg_profit = subset_sum / math.comb(d, k)
        total += visits[k - 1] * avg_profit

    return total

def F(n):
    total = 0.0

    for d in range(4, n + 1):
        for c in range(n + 1):
            total += super_ramvok(d, c)

    return round(total)

print(super_ramvok(6, 1))  # 208.3
print(F(20))
