[Vấn đề dự án Euler 253](https://projecteuler.net/problem=253) 

## Giải pháp 

**Trả lời:**`11.492847`Hãy để con sâu bướm có$n$các mảnh được sắp xếp vào các vị trí$1,2,\dots,n$. 

Chúng tôi đặt các mảnh theo thứ tự ngẫu nhiên thống nhất. 

Ở mỗi giai đoạn, các vị trí bị chiếm giữ tạo thành một số khối liền kề (“phân đoạn”). 

Chúng tôi quan tâm đến$$M = \max(\text{number of segments seen during the process}).$$Vì$n=40$, chúng ta phải tính$$\mathbb E[M].$$--- 

# 1. Phân tích toán học 

## Động lực phân đoạn 

Giả sử chúng ta đặt một quân cờ vào vị trí$x$. 

Chỉ có ba khả năng: 

- không có hàng xóm nào bị chiếm đóng$\Rightarrow$một phân khúc mới được tạo$\Rightarrow \Delta S = +1$- chính xác một người hàng xóm đang ở$\Rightarrow$một phân khúc hiện có được mở rộng$\Rightarrow \Delta S = 0$- cả hai người hàng xóm đều bị chiếm đóng$\Rightarrow$hai phân đoạn hợp nhất$\Rightarrow \Delta S = -1$Do đó, quá trình này hoàn toàn được xác định bởi mô hình các khoảng trống. 

--- 

## Biểu diễn khoảng cách 

Thay vì lưu trữ các vị trí đã chiếm giữ, chúng tôi lưu trữ _khoảng trống_. 

Khoảng cách được thể hiện bằng$$(g,L,R)$$Ở đâu:

-$g$= số ô trống trong khoảng trống 
-$L \in \{0,1\}$: ranh giới bên trái có bị chiếm dụng không? 
-$R \in \{0,1\}$: ranh giới bên phải có bị chiếm dụng không? 

Ban đầu:$$[(40,0,0)]$$(một khoảng trống hoàn toàn). 

Nếu chúng ta đặt một mảnh vào trong một khoảng trống, khoảng trống đó sẽ chia thành hai khoảng trống nhỏ hơn. 

Điều này mang lại DP đệ quy rõ ràng. 

--- 

## Xác suất DP 

Xác định$$F(state,s,m)$$là xác suất để bắt đầu từ: 

- cấu hình khoảng cách hiện tại =`state`- số lượng phân đoạn hiện tại =$s$chúng tôi không bao giờ vượt quá$m$các phân khúc trong tương lai. 

Sau đó: 

- nếu$s>m$, trở lại$0$- nếu không còn khoảng trống thì quay lại$1$Nếu không thì tính trung bình trên tất cả các vị trí có thể. 

Cuối cùng,$$P(M \le m)=F(\text{initial},0,m).$$Sử dụng danh tính$$\mathbb E[M] = \sum_{k\ge1} P(M\ge k) = \sum_{k\ge1} \left(1-P(M\le k-1)\right),$$chúng tôi có được sự mong đợi một cách chính xác.

#2. Triển khai Python```python
from functools import cache
from collections import defaultdict

N = 40

@cache
def transitions(state, segs):
    """
    Generate all transitions from a given state.

    state = tuple of gaps (g, L, R)
    segs  = current number of segments
    """

    total_empty = sum(g for g, _, _ in state)

    out = defaultdict(int)

    for idx, (g, L, R) in enumerate(state):

        others = list(state[:idx] + state[idx + 1:])

        for pos in range(1, g + 1):

            # Number of occupied neighbours
            c = 0
            if pos == 1 and L:
                c += 1
            if pos == g and R:
                c += 1

            # Segment count change
            if c == 0:
                new_segs = segs + 1
            elif c == 1:
                new_segs = segs
            else:
                new_segs = segs - 1

            new_state = others[:]

            left_len = pos - 1
            right_len = g - pos

            if left_len > 0:
                new_state.append((left_len, L, 1))

            if right_len > 0:
                new_state.append((right_len, 1, R))

            new_state = tuple(sorted(new_state))

            out[(new_state, new_segs)] += 1

    return total_empty, list(out.items())

def probability_max_at_most(m):

    @cache
    def F(state, segs):

        if segs > m:
            return 0.0

        if not state:
            return 1.0

        total_empty, trans = transitions(state, segs)

        ans = 0.0

        for (new_state, new_segs), count in trans:
            ans += count * F(new_state, new_segs)

        return ans / total_empty

    return F(((N, 0, 0),), 0)

# Compute expectation
expectation = 0.0

for k in range(1, N + 1):
    p_le = probability_max_at_most(k - 1)
    expectation += 1.0 - p_le

print(f"{expectation:.6f}")
```--- 

#3. Hướng dẫn sử dụng mã 

##`transitions(state, segs)`Đối với mọi vị trí trống trong mọi khoảng trống: 

- determine how many occupied neighbors it touches
 - cập nhật số lượng phân đoạn 
- chia khoảng trống thành các khoảng trống con trái/phải 
- tổng hợp các trạng thái kết quả giống hệt nhau 

Điều này làm giảm đáng kể không gian trạng thái. 

--- 

##`F(state, segs)`Xác suất ghi nhớ đệ quy:$$F = \Pr(\text{never exceed } m)$$Các trường hợp cơ bản: 

- đã vượt quá$m$

$\Rightarrow 0$- không còn ô trống$\Rightarrow 1$Nếu không thì tính trung bình trên tất cả các vị trí tiếp theo có thể có. 

--- 

## Kỳ vọng cuối cùng 

Chúng tôi sử dụng$$\mathbb E[M] = \sum_{k=1}^{N} \left(1-P(M\le k-1)\right).$$---
