##Giải pháp 

**Trả lời:**`157055.80999`Cho phép$$x = ka+1,\qquad y = kb+1,$$Ở đâu$a,b\sim U[0,1]$. 

Sau đó$(x,y)$được phân bố đều trên hình vuông$$[1,k+1]\times[1,k+1],$$diện tích của ai là$k^2$. 

Albert ghi bàn$k$điểm chính xác khi nào$$k-\tfrac12 \le \sqrt{x^2+y^2} < k+\tfrac12.$$Vậy ta cần diện tích phần hình vuông nằm bên trong hình vành khuyên$$(k-\tfrac12)^2 \le x^2+y^2 < (k+\tfrac12)^2.$$--- 

# 1. Xác suất hình học 

Xác định$$A(R)=\text{area}\left(\{(x,y)\in[1,\infty)^2:x^2+y^2\le R^2\}\right).$$Vì$R>1$, đường tròn cắt đường thẳng$y=1$Tại$$x=\sqrt{R^2-1}.$$Kể từ đây$$A(R)=\int_1^{\sqrt{R^2-1}} \left(\sqrt{R^2-x^2}-1\right)\,dx.$$sử dụng$$\int \sqrt{R^2-x^2}\,dx = \frac12\left( x\sqrt{R^2-x^2} + R^2\arcsin\frac{x}{R} \right),$$chúng tôi có được sau khi đơn giản hóa:$$A(R) = 1-\sqrt{R^2-1} + R^2\left( \frac{\pi}{4}-\arcsin\frac1R \right).$$Vì vậy, xác suất mong muốn cho một giá trị cố định$k$là$$P_k = \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k^2}.$$Sự đóng góp điểm số dự kiến ​​​​từ lượt$k$do đó là$$E_k = kP_k = \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k}.$$Như vậy tổng kỳ vọng là$$E = \sum_{k=1}^{10^5} \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k}.$$--- 

#2. Triển khai Python```python
import math

def A(R):
    # For R <= 1 the region is empty
    if R <= 1.0:
        return 0.0

    return (
        1.0
        - math.sqrt(R * R - 1.0)
        + R * R * (math.pi / 4.0 - math.asin(1.0 / R))
    )

def expected_value(n):
    total = 0.0

    for k in range(1, n + 1):
        outer = A(k + 0.5)
        inner = A(k - 0.5)

        total += (outer - inner) / k

    return total

# Check the example from the problem
print(round(expected_value(10), 5))

# Compute the required answer
ans = expected_value(100000)

print(f"{ans:.5f}")
```---
