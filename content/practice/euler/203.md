Một số **không có bình phương** nếu không có số nguyên tố nào chia nó. 

Ví dụ: 

-$6 = 2 \cdot 3$là hình vuông. 
-$12 = 2^2 \cdot 3$thì không. 
-$20 = 2^2 \cdot 5$thì không. 

Vấn đề cung cấp một cách rõ ràng một chương trình hoạt động mạnh mẽ. Chúng tôi sẽ phân tích chính xác lý do tại sao nó hoạt động và kết quả mà nó tạo ra.

# Phân tích toán học 

Tam giác Pascal chứa các mục$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$cho hàng$n = 0,1,2,\dots$. 

Chúng tôi cần: 

1. Mọi giá trị khác biệt xuất hiện giữa$$\binom{n}{k}, \quad 0 \le n \le 50$$2. Chỉ giữ lại những hình vuông. 
3. Tính tổng chúng. 

--- 

## Kiểm tra Squarefree 

một con số$m$là không có bình phương nếu có **không** số nguyên$d \ge 2$như vậy$$d^2 \mid m$$Hàm được cung cấp sẽ kiểm tra điều này một cách trực tiếp:```python
def is_squarefree(n):
    if n <= 1: return n == 1
    d = 2
    while d * d <= n:
        if n % (d*d) == 0: return False
        d += 1
    return True
```Điều này hoạt động vì: 

- nếu bất kỳ hình vuông nào chia$n$, 
- sau đó một số hình vuông$d^2$với$d \le \sqrt n$chia nó. 

Vì vậy kiểm tra tất cả$d$lên đến$\sqrt n$là đủ.

# Triển khai Python 

Vấn đề yêu cầu chúng tôi chạy mã chính xác này một cách rõ ràng:```python
from math import comb, isqrt

def is_squarefree(n):
    if n <= 1:
        return n == 1

    d = 2
    while d * d <= n:
        if n % (d * d) == 0:
            return False
        d += 1

    return True

seen = set()

for n in range(51):
    for k in range(n + 1):
        c = comb(n, k)

        if c not in seen and is_squarefree(c):
            seen.add(c)

print(sum(seen))
```---

# Xác minh trên ví dụ nhỏ
