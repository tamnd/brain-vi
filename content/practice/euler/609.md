[Vấn đề dự án Euler 609](https://projecteuler.net/problem=609) 

##Giải pháp 

**Trả lời:**`172023848`Cho phép$$\pi(n)=\#\{p\le n : p \text{ prime}\}.$$MỘT$\pi$-chuỗi là dãy hữu hạn$$u=(u_0,u_1,\dots,u_m)$$với$m\ge1$,$u_{i+1}=\pi(u_i)$, và mọi số hạng đều dương. 

Đối với mỗi chuỗi$u$, cho phép$c(u)$là số phần tử không nguyên tố trong$u$. 

Chúng tôi xác định:$$p(n,k)=\#\{u : u_0\le n,\ c(u)=k\},$$Và$$P(n)=\prod_{k:\,p(n,k)>0} p(n,k).$$Chúng tôi được yêu cầu:$$P(10^8)\pmod{1\,000\,000\,007}.$$--- 

# 1. Phân tích toán học 

## 1.1 Cấu trúc của một$\pi$-trình tự 

Bắt đầu từ$x=u_0$, trình tự buộc phải:$$x,\ \pi(x),\ \pi(\pi(x)),\ \dots$$cho đến khi nó đạt tới$1$, bởi vì$\pi(1)=0$và trình tự phải luôn dương. 

Như vậy mọi giá trị ban đầu$x\ge2$tạo ra chính xác một chuỗi tối đa. 

Ví dụ:$$10\to4\to2\to1.$$hợp lệ$\pi$-các chuỗi đều là tiền tố có độ dài ít nhất$2$:$$(10,4),\quad (10,4,2),\quad (10,4,2,1).$$--- 

## 1.2 Mô tả đệ quy 

Xác định$V(x)$là nhiều tập hợp của tất cả các giá trị$c(u)$cho các chuỗi bắt đầu từ$x$. 

Nếu như$x>1$, cho phép$$y=\pi(x).$$Cho phép$$b(x)= \begin{cases} 0,&x\text{ prime}\\ 1,&x\text{ non-prime} \end{cases}$$Sau đó: 

- trình tự ngắn nhất$(x,y)$đóng góp$$b(x)+b(y),$$- mỗi chuỗi dài hơn có được bằng cách thêm vào trước$x$đến một trình tự từ$y$, thêm$b(x)$đến số không nguyên tố. 

Vì thế:$$V(x)=\{b(x)+b(y)\}\cup\{b(x)+t:t\in V(y)\}.$$Điều này mang lại độ sâu đệ quy rất nhỏ, bởi vì việc áp dụng lặp đi lặp lại$\pi$thu nhỏ số lượng cực kỳ nhanh chóng. 

Vì$10^8$:$$10^8\to5761455\to412849\to\cdots\to1$$vì vậy độ sâu tối đa là rất nhỏ (dưới 16). 

--- 

## 1.3 Phân nhóm bằng nhau$\pi(x)$Một quan sát quan trọng:$$\pi(x)=y$$giữ cho tất cả$$x\in[p_y,\ p_{y+1}-1],$$Ở đâu$p_y$là$y$-thứ nguyên tố. 

Bên trong khoảng này: 

- có chính xác một số là số nguyên tố ($p_y$), 
- phần còn lại là tổng hợp. 

Vì vậy tất cả các số có cùng$\pi(x)$chỉ chia làm hai loại: 

1. số nguyên tố$p_y$, 
2. sự kết hợp giữa$p_y$Và$p_{y+1}$. 

Vì vậy ta chỉ cần tính$V(y)$một lần cho mỗi người$y\le \pi(10^8)$. 

Từ$$\pi(10^8)=5\,761\,455,$$điều này là hoàn toàn khả thi.

#2. Thuật toán hiệu quả 

Chúng tôi sàng lọc tất cả các số nguyên tố lên đến$10^8$. 

Sau đó với mỗi$y\le\pi(10^8)$: 

1. tính toán$V(y)$từ đệ quy, 
2. thêm đóng góp từ: 

- số nguyên tố$p_y$, 
- các số tổng hợp với$\pi(x)=y$. 

Bởi vì độ sâu đệ quy rất nhỏ nên chúng tôi chỉ lưu trữ một vectơ số lượng ngắn. 

Độ phức tạp: 

- sàng:$O(n\log\log n)$, 
- DP: về cơ bản là tuyến tính$\pi(n)$. 

--- 

#3. Triển khai Python```python
MOD = 1_000_000_007
N = 10**8
K = 16                      # safely larger than maximum depth

# ------------------------------------------------------------
# Odd-only sieve
# ------------------------------------------------------------

size = N // 2
sieve = bytearray(b'\x01') * size
sieve[0] = 0

limit = int(N**0.5)

for i in range(3, limit + 1, 2):
    if sieve[i // 2]:
        start = i * i // 2
        sieve[start::i] = b'\x00' * (((size - start - 1) // i) + 1)

primes = [2] + [2 * i + 1 for i in range(1, size) if sieve[i]]

m = len(primes)             # pi(10^8)

# ------------------------------------------------------------
# primality up to m
# ------------------------------------------------------------

is_prime_small = bytearray(m + 1)

for p in primes:
    if p <= m:
        is_prime_small[p] = 1

# ------------------------------------------------------------
# pi(x) for x <= m
# ------------------------------------------------------------

pi_small = [0] * (m + 1)

c = 0
for i in range(1, m + 1):
    c += is_prime_small[i]
    pi_small[i] = c

# ------------------------------------------------------------
# DP storage
#
# C[y][k] = number of sequences starting at y
#            having exactly k non-primes
# ------------------------------------------------------------

C = [[0] * K for _ in range(m + 1)]

# final p(n,k)
P = [0] * K

for y in range(1, m + 1):

    # build V(y)
    if y > 1:
        z = pi_small[y]

        by = 0 if is_prime_small[y] else 1
        bz = 0 if is_prime_small[z] else 1

        # shortest sequence (y, z)
        C[y][by + bz] += 1

        # longer sequences
        for k in range(K - by):
            C[y][by + k] += C[z][k]

    # --------------------------------------------------------
    # Contributions from x with pi(x)=y
    # --------------------------------------------------------

    bz = 0 if is_prime_small[y] else 1

    # prime x = p_y
    P[bz] += 1
    for k in range(K):
        P[k] += C[y][k]

    # composite x with pi(x)=y
    if y < m:
        gap = primes[y] - primes[y - 1] - 1
    else:
        gap = N - primes[-1]

    P[1 + bz] += gap

    for k in range(K - 1):
        P[k + 1] += gap * C[y][k]

# ------------------------------------------------------------
# Final product
# ------------------------------------------------------------

ans = 1

for v in P:
    if v:
        ans = (ans * (v % MOD)) % MOD

print(ans)
```---

## Tính toán$V(y)$Đối với mỗi$y$:```python
z = pi_small[y]
```Sau đó:```python
C[y][by + bz] += 1
```thêm chuỗi ngắn nhất$(y,z)$. 

Kế tiếp:```python
C[y][by + k] += C[z][k]
```mở rộng mọi chuỗi từ$z$.

Tất cả các số có$\pi(x)=y$được xử lý cùng nhau.

- một số nguyên tố$x=p_y$, 
- nhiều hợp số giữa các số nguyên tố liên tiếp. 

Điều này làm giảm công việc rất nhiều.
