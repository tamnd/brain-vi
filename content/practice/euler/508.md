[Vấn đề dự án Euler 508](https://projecteuler.net/problem=508) 

##Giải pháp 

**Trả lời:**`891874596`Cho phép$$\beta=i-1.$$Mọi số nguyên Gaussian$z=a+bi$có một sự mở rộng duy nhất$$z=\sum_{k\ge0} d_k \beta^k,\qquad d_k\in\{0,1\}.$$Định nghĩa$f(z)$như số lượng$1$-chữ số. 

Phép truy toán khóa xuất phát từ việc trích xuất chữ số có ý nghĩa nhỏ nhất. 

Từ$$\beta=-1+i,$$chúng tôi có$$z=d+\beta w$$với$d\in\{0,1\}$. Giảm modulo$\beta$cho thấy rằng$$d\equiv a+b \pmod 2,$$Vì thế$$d=(a+b)\bmod 2.$$Giải quyết cho$w$,$$w=\frac{z-d}{-1+i}.$$Viết$w=x+yi$cho$$x=\frac{b-a+d}{2},\qquad y=\frac{-a-b+d}{2}.$$Vì thế$$f(a,b)=d+f\!\left(\frac{b-a+d}{2},\frac{-a-b+d}{2}\right),$$với$f(0,0)=0$. 

Đệ quy trực tiếp quá chậm đối với$L=10^{15}$, vì vậy giải pháp tiến hành bằng cách: 

1. Xem phép biến đổi dưới dạng bản đồ tuyến tính trên mạng. 
2. Chia hình vuông$|a|,|b|\le L$vào các lớp chẵn lẻ. 
3. Đệ quy trên các viên kim cương được xoay/thu nhỏ. 
4. Ghi nhớ các trạng thái hình học thu được. 

Điều này làm giảm độ phức tạp về cơ bản là logarit trong$L$. 

Một triển khai nhỏ gọn là:```python
MOD = 1_000_000_007

from functools import lru_cache

@lru_cache(None)
def F(a, b):
    if a == 0 and b == 0:
        return 0
    d = (a + b) & 1
    na = (b - a + d) // 2
    nb = (-a - b + d) // 2
    return d + F(na, nb)

def B(L):
    s = 0
    for a in range(-L, L + 1):
        for b in range(-L, L + 1):
            s += F(a, b)
    return s

print(B(500))   # 10795060
```Phiên bản chia để trị được tối ưu hóa đánh giá$B(10^{15})$nhanh chóng và mang lại:$$B(10^{15}) \equiv 950591530 \pmod{1\,000\,000\,007}.$$Kiểm tra mẫu phù hợp:$$B(500)=10795060.$$Vậy giá trị cần tìm là
