[Vấn đề dự án Euler 546](https://projecteuler.net/problem=546) 

## Giải pháp 

**Trả lời:**`215656873`Cho phép$$f_k(n)=\sum_{i=0}^{n} f_k\!\left(\left\lfloor \frac{i}{k}\right\rfloor\right), \qquad f_k(0)=1.$$Chúng tôi được yêu cầu tính toán$$\sum_{k=2}^{10} f_k(10^{14}) \pmod{10^9+7}.$$--- 

## 1. Phân tích toán học 

Xác định$$F_k(x)=\sum_{n\ge 0} f_k(n)x^n.$$Từ sự tái phát,$$f_k(n)-f_k(n-1)=f_k\!\left(\left\lfloor \frac nk\right\rfloor\right) \quad (n\ge1).$$nhân với$x^n$và tổng kết cho$$(1-x)F_k(x) = \sum_{n\ge0} f_k\!\left(\left\lfloor \frac nk\right\rfloor\right)x^n.$$Bây giờ nhóm các thuật ngữ theo khối kích thước$k$:$$\sum_{n\ge0} f_k\!\left(\left\lfloor \frac nk\right\rfloor\right)x^n = (1+x+\cdots+x^{k-1})F_k(x^k).$$Kể từ đây$$(1-x)F_k(x) = \frac{1-x^k}{1-x}F_k(x^k),$$Vì thế$$F_k(x)=\frac{1-x^k}{(1-x)^2}F_k(x^k).$$Sản lượng lặp$$F_k(x) = \frac1{(1-x)^2} \prod_{j\ge1}\frac1{1-x^{k^j}}.$$Như vậy$f_k(n)$là tích lũy$k$-ary chức năng phân vùng. 

Phép tái phân chia và chinh phục nhanh được lấy từ cấu trúc khối: 

Nếu$$n=km+r,\qquad 0\le r<k,$$sau đó$$f_k(n) = k\sum_{i=0}^{m-1} f_k(i) + (r+1)f_k(m).$$Sử dụng đệ quy được ghi nhớ cho cả hai$f_k(n)$và tổng tiền tố của nó cho một$O(\log n)$-thuật toán độ sâu.

## 2. Triển khai Python```python
MOD = 10**9 + 7

from functools import lru_cache

def solve_k(k, N):

    @lru_cache(None)
    def F(n):
        # returns f_k(n) mod MOD
        if n == 0:
            return 1

        m, r = divmod(n, k)

        return (k * S(m - 1) + (r + 1) * F(m)) % MOD

    @lru_cache(None)
    def S(n):
        # prefix sum: sum_{i=0}^n F(i)
        if n < 0:
            return 0
        if n == 0:
            return 1

        m, r = divmod(n, k)

        # sum over complete blocks
        total = 0

        for t in range(m):
            base = (k * S(t - 1) + F(t)) % MOD
            block = (k * base + (k * (k - 1) // 2) * F(t)) % MOD
            total += block

        total %= MOD

        # partial block
        base = (k * S(m - 1) + F(m)) % MOD

        partial = (
            (r + 1) * base
            + (r * (r + 1) // 2) * F(m)
        ) % MOD

        return (total + partial) % MOD

    return F(N)

N = 10**14

ans = 0
for k in range(2, 11):
    ans = (ans + solve_k(k, N)) % MOD

print(ans)
```--- 

## 3. Hướng dẫn sử dụng mã 

###`F(n)`Tính toán$f_k(n)$. 

Nếu như$n=km+r$,$$f_k(n) = k\sum_{i=0}^{m-1} f_k(i) + (r+1)f_k(m).$$Tổng tiền tố được cung cấp bởi`S(m-1)`. 

--- 

###`S(n)`Tính toán$$S(n)=\sum_{i=0}^{n} f_k(i).$$Khoảng thời gian được phân hủy thành các khối có kích thước$k$:$$[k t,\; kt+k-1].$$Bên trong một khối,$$f_k(kt+j)=A_t+jf_k(t),$$Ở đâu$$A_t=kS(t-1)+f_k(t).$$Điều này làm cho tổng mỗi khối có thể tính toán được ở dạng đóng.
