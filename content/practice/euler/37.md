**Trả lời:**`748317`## 1. Phân tích toán học 

Chúng tôi tìm kiếm **chỉ mười một số nguyên tố** đó là: 

- tự khẳng định mình, 
- giữ nguyên số nguyên tố khi liên tục cắt bớt các chữ số **từ trái sang phải**, và 
- giữ nguyên số nguyên tố khi liên tục cắt bớt các chữ số **từ phải sang trái**. 

Ví dụ:$$3797 \to 797 \to 97 \to 7$$Và$$3797 \to 379 \to 37 \to 3$$tất cả vẫn còn nguyên tố. 

Chúng ta phải tìm **tổng** của tất cả các số nguyên tố như vậy, ngoại trừ$2,3,5,7$. 

### Những quan sát chính 

#### Quan sát 1: Hạn chế về chữ số 

Đối với mọi số nguyên tố có thể cắt ngắn nhiều chữ số: 

- **chữ số cuối cùng** phải là$3$hoặc$7$, vì số nguyên tố$>5$không thể kết thúc bằng chữ số chẵn hoặc 5. 
- Các chữ số bên trong không thể là số chẵn hoặc 5, nếu không một số phần bị cắt bớt sẽ trở thành hợp số. 

Vì vậy, thí sinh chỉ sử dụng các chữ số từ:$$\{1,3,7,9\}$$(có thể ngoại trừ chữ số đứng đầu). 

Điều này làm giảm đáng kể không gian tìm kiếm.

### Kiểm tra tính nguyên thủy hiệu quả 

Chúng tôi sử dụng phép chia thử lên tới:$$\sqrt{n}$$vì nếu$n = ab$, ít nhất có nhiều nhất một thừa số$\sqrt n$. 

Thuật toán: 

- từ chối$n<2$, 
- xử lý nhanh các số chẵn, 
- kiểm tra các ước số lẻ lên đến$\sqrt n$. 

Độ phức tạp rất nhỏ vì chỉ có 11 số hợp lệ.

## 2. Triển khai Python```python
import math

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    limit = int(math.sqrt(n))
    for d in range(3, limit + 1, 2):
        if n % d == 0:
            return False
    return True

def is_truncatable_prime(n):
    """Check if n is truncatable from both directions."""
    s = str(n)

    # Exclude single-digit primes
    if len(s) == 1:
        return False

    # Left-to-right truncations
    for i in range(len(s)):
        if not is_prime(int(s[i:])):
            return False

    # Right-to-left truncations
    for i in range(len(s), 0, -1):
        if not is_prime(int(s[:i])):
            return False

    return True

found = []
n = 11  # smallest possible multi-digit prime

while len(found) < 11:
    if is_prime(n) and is_truncatable_prime(n):
        found.append(n)
    n += 2  # skip even numbers

answer = sum(found)

print(found)
print(answer)
```---
