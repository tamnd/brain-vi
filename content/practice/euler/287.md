[Vấn đề dự án Euler 287](https://projecteuler.net/problem=287) 

##Giải pháp 

**Trả lời:**`313135496`Hãy để kích thước hình ảnh là$2^N\times 2^N$, và xác định$$C = 2^{N-1},\qquad R^2 = 2^{2N-2}.$$Một pixel$(x,y)$là đen nếu$$(x-C)^2+(y-C)^2 \le R^2.$$Vì thế$D_N$đơn giản là đĩa rời rạc có bán kính$2^{N-1}$tập trung vào$(C,C)$. 

--- 

# 1. Phân tích toán học 

Nút tứ giác đại diện cho một vùng hình vuông được căn chỉnh theo trục$$[x_0,x_0+s-1]\times [y_0,y_0+s-1]$$với độ dài cạnh$s=2^k$. 

Đối với mã hóa: 

- vùng đơn sắc có giá **2 bit** 

-`10`cho màu đen 
-`11`cho màu trắng 
- chia chi phí 

-`0`cộng với bảng mã của bốn đứa trẻ. 

Do đó, nếu một khu vực được trộn lẫn, chi phí của nó là$$1+\sum_{\text{4 children}} \text{cost(child)}.$$Vì vậy, vấn đề giảm xuống: 

> Xác định xem một hình vuông nằm hoàn toàn bên trong hình tròn, hoàn toàn bên ngoài hay hỗn hợp. 

--- 

## Quan sát hình học chính 

Đối với vùng hình vuông: 

### Toàn màu đen 

Toàn bộ hình vuông có màu đen nếu pixel **xa nhất** tính từ tâm vẫn nằm trong hình tròn. 

Vì khoảng cách bình phương là lồi nên điểm xa nhất của hình vuông luôn là một trong bốn góc. 

Như vậy xác định$$d_{\max}=\max_{\text{corners}} (x-C)^2+(y-C)^2.$$Nếu như$$d_{\max}\le R^2,$$toàn bộ khu vực là màu đen. 

--- 

### Trắng hoàn toàn 

Toàn bộ hình vuông có màu trắng nếu pixel **gần nhất** ở giữa nằm ngoài hình tròn. 

Điểm gần nhất có được bằng cách kẹp tọa độ trung tâm vào khoảng vuông:$$x_n = \min(\max(C,x_0),\,x_0+s-1),$$

$$y_n = \min(\max(C,y_0),\,y_0+s-1).$$Sau đó$$d_{\min}=(x_n-C)^2+(y_n-C)^2.$$Nếu như$$d_{\min}>R^2,$$toàn bộ hình vuông có màu trắng. 

--- 

### Ngược lại: hỗn hợp 

Nếu cả hai điều kiện đều không thỏa mãn thì ranh giới của hình tròn sẽ cắt hình vuông nên chúng ta chia thành bốn góc phần tư. 

--- 

#2. Công thức đệ quy 

hãy để$$F(x_0,y_0,s)$$là độ dài mã hóa tối thiểu cho hình vuông đó. 

Sau đó:$$F= \begin{cases} 2 & \text{if entirely black or entirely white},\\[4mm] 1+\displaystyle\sum_{i=1}^4 F_i & \text{otherwise}. \end{cases}$$Độ sâu đệ quy chỉ$N=24$và chỉ các vùng chạm ranh giới mới được mở rộng. 

--- 

#3. Triển khai Python```python
from functools import lru_cache

N = 24

CENTER = 1 << (N - 1)
R2 = 1 << (2 * N - 2)

@lru_cache(None)
def solve(x0, y0, size):
    """
    Return the minimal quadtree encoding length
    for the square:
        x in [x0, x0 + size - 1]
        y in [y0, y0 + size - 1]
    """

    x1 = x0 + size - 1
    y1 = y0 + size - 1

    # ---------------------------------------------------------
    # Test whether the whole square is black.
    # The farthest point from the center is one of the corners.
    # ---------------------------------------------------------

    max_d2 = max(
        (x - CENTER) ** 2 + (y - CENTER) ** 2
        for x in (x0, x1)
        for y in (y0, y1)
    )

    if max_d2 <= R2:
        return 2  # "10"

    # ---------------------------------------------------------
    # Test whether the whole square is white.
    # Find the nearest point in the square to the center.
    # ---------------------------------------------------------

    nearest_x = min(max(CENTER, x0), x1)
    nearest_y = min(max(CENTER, y0), y1)

    min_d2 = (
        (nearest_x - CENTER) ** 2 +
        (nearest_y - CENTER) ** 2
    )

    if min_d2 > R2:
        return 2  # "11"

    # ---------------------------------------------------------
    # Mixed region: split into four quadrants.
    # ---------------------------------------------------------

    half = size // 2

    return (
        1 +  # leading split bit "0"
        solve(x0,         y0 + half, half) +  # top-left
        solve(x0 + half,  y0 + half, half) +  # top-right
        solve(x0,         y0,        half) +  # bottom-left
        solve(x0 + half,  y0,        half)    # bottom-right
    )

answer = solve(0, 0, 1 << N)

print(answer)
```---
