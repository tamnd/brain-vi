## Giải pháp 

**Trả lời:**`20574308184277971`Hãy để bảng được$9\times 12$, vậy có$108$tổng số tế bào 

Vì mỗi triomino bao phủ chính xác$3$ô, mỗi ô đều sử dụng chính xác$$108/3 = 36$$triomino. 

Khó khăn chính là bộ ba có thể mở rộng qua các ranh giới hàng, do đó, DP theo từng hàng đơn giản là không đủ. Giải pháp tiêu chuẩn là cách tiếp cận **lập trình động cấu hình bị hỏng**. 

--- 

# 1. Phân tích toán học 

Chúng ta có sáu hướng của triomino: 

- Hai kèn tromino thẳng: 

- ngang$1\times 3$- thẳng đứng$3\times 1$- Bốn kèn tromino hình chữ L. 

Chúng tôi xử lý từng ô của bảng theo thứ tự hàng lớn. 

--- 

## Đại diện biên giới 

Tại bất kỳ thời điểm nào, một số ô trong tương lai đã bị chiếm giữ bởi các phần được bắt đầu trước đó. 

Bởi vì một triomino thẳng đứng có thể kéo dài tối đa hai hàng xuống dưới, nên chỉ cần nhớ sự chiếm chỗ của: 

- hàng hiện tại 
- hàng tiếp theo 
- hàng nối tiếp 

Đối với chiều rộng$9$, điều này được thể hiện một cách tự nhiên bằng bitmasks. 

Một tối ưu hóa phổ biến là: 

- xử lý từng ô một, 
- duy trì chỗ ở cho hai hàng tiếp theo so với vị trí hiện tại. 

Công thức tương đương tồn tại; đệ quy sạch nhất là:$$F(pos, mask_0, mask_1, mask_2)$$Ở đâu:

-$pos$= chỉ mục hàng hiện tại, 
-$mask_0$= chỗ ngồi của hàng hiện tại, 
-$mask_1$= chỗ ngồi của hàng tiếp theo, 
-$mask_2$= chỗ ngồi của hàng tiếp theo. 

Mỗi mặt nạ có 9 bit. 

Khi hàng hiện tại đầy:$$mask_0 = 2^9 - 1 = 511$$chúng tôi tiến lên:$$(mask_0,mask_1,mask_2)\to(mask_1,mask_2,0)$$và chuyển sang hàng tiếp theo. 

--- 

## Điền vào ô trống đầu tiên 

Ở mỗi giai đoạn: 

1. Tìm bit trống ngoài cùng bên trái trong$mask_0$. 
2. Hãy thử mọi hướng triomino bao phủ ô đó. 
3. Cập nhật mặt nạ cho phù hợp. 

Điều này đảm bảo: 

- không chồng chéo, 
- không bỏ sót, 
- mỗi lần xếp gạch được tính chính xác một lần. 

--- 

## Tại sao điều này lại hiệu quả 

Đây là đối số transfer-DP/profile-DP cổ điển. 

Tương lai chỉ phụ thuộc vào ranh giới giữa các ô được xử lý và chưa được xử lý. 

Vì triomino có chiều cao tối đa là 3 nên trạng thái chỉ cần 3 hàng thông tin. 

Có thể quản lý được số lượng trạng thái có thể truy cập (tối đa vài trăm nghìn) và tính năng ghi nhớ giúp tìm kiếm nhanh chóng.

#2. Triển khai Python```python
from functools import lru_cache

W = 9
H = 12
FULL = (1 << W) - 1

# ---------------------------------------------------------
# Helper routines
# ---------------------------------------------------------

def bit(mask, c):
    return (mask >> c) & 1

def setbit(mask, c):
    return mask | (1 << c)

# ---------------------------------------------------------
# Recursive profile DP
# ---------------------------------------------------------

@lru_cache(None)
def solve(row, m0, m1, m2):
    """
    row = current row index

    m0 = occupancy mask for current row
    m1 = occupancy mask for next row
    m2 = occupancy mask for row+2
    """

    # Finished all rows
    if row == H:
        return 1 if (m0, m1, m2) == (0, 0, 0) else 0

    # If current row is completely filled,
    # advance frontier downward
    if m0 == FULL:
        return solve(row + 1, m1, m2, 0)

    # Find first empty column
    c = 0
    while bit(m0, c):
        c += 1

    ans = 0

    # -------------------------------------------------
    # Try all 6 triomino orientations
    # -------------------------------------------------

    # 1) Horizontal 1x3
    if c + 2 < W:
        if (not bit(m0, c + 1)
                and not bit(m0, c + 2)):
            ans += solve(
                row,
                setbit(setbit(setbit(m0, c), c + 1), c + 2),
                m1,
                m2
            )

    # 2) Vertical 3x1
    if row + 2 < H:
        if (not bit(m1, c)
                and not bit(m2, c)):
            ans += solve(
                row,
                setbit(m0, c),
                setbit(m1, c),
                setbit(m2, c)
            )

    # 3) L-shape: cells
    # (r,c), (r+1,c), (r,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m1, c)
                and not bit(m0, c + 1)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c),
                m2
            )

    # 4) L-shape:
    # (r,c), (r+1,c), (r+1,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m1, c)
                and not bit(m1, c + 1)):
            ans += solve(
                row,
                setbit(m0, c),
                setbit(setbit(m1, c), c + 1),
                m2
            )

    # 5) L-shape:
    # (r,c), (r,c+1), (r+1,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m0, c + 1)
                and not bit(m1, c + 1)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c + 1),
                m2
            )

    # 6) L-shape:
    # (r,c), (r,c+1), (r+1,c)
    if c + 1 < W and row + 1 < H:
        if (not bit(m0, c + 1)
                and not bit(m1, c)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c),
                m2
            )

    return ans

print(solve(0, 0, 0, 0))
```---

## Hằng số```python
W = 9
H = 12
FULL = (1 << W) - 1
```

`FULL = 511`có nghĩa là mọi ô trong một hàng đều bị chiếm dụng. 

--- 

## Định nghĩa trạng thái```python
solve(row, m0, m1, m2)
```mã hóa chỗ ngồi của ba hàng liên tiếp. 

--- 

## Thăng tiến hàng```python
if m0 == FULL:
    return solve(row + 1, m1, m2, 0)
```Khi hàng hiện tại hoàn thành: 

- hàng tiếp theo trở thành hiện tại, 
- hàng thứ ba trở thành tiếp theo, 
- một hàng trống mới được thêm vào. 

--- 

## Ô trống đầu tiên```python
c = 0
while bit(m0, c):
    c += 1
```Việc chuẩn hóa là rất quan trọng: 

luôn điền vào ô trống ngoài cùng bên trái trước. 

Điều này ngăn cản việc đếm trùng lặp. 

--- 

## Vị trí mảnh 

Mỗi hướng kiểm tra: 

- giới hạn, 
- ràng buộc chồng chéo. 

Sau đó các bit tương ứng được thiết lập. 

Ví dụ: kèn tromino dọc```python
if row + 2 < H:
    if (not bit(m1, c)
            and not bit(m2, c)):
```yêu cầu cùng một cột ở hai hàng tiếp theo để trống.
