[Vấn đề dự án Euler 942](https://projecteuler.net/problem=942) 

## Giải pháp 

**Trả lời:**`557539756`Cho phép$$p = 2^q-1$$với$q=74\,207\,281$, Và$p$xuất sắc. 

Chúng tôi tìm kiếm giải pháp tích cực tối thiểu của$$x^2 \equiv q \pmod p.$$Đối với số nguyên tố Mersenne,$2$có đơn đặt hàng$q$modulo$p$, vì vậy$q$- cội nguồn của sự đoàn kết trong$\mathbb F_p$là$$1,2,2^2,\dots,2^{q-1}.$$Một đẳng thức tổng Gauss bậc hai cổ điển cho$q\equiv1\pmod4$,$$G=\sum_{a=0}^{q-1}\left(\frac aq\right)2^a$$thỏa mãn$$G^2=q.$$Từ$$\left(\frac 0q\right)=0, \qquad \left(\frac aq\right)= \begin{cases} 1 & a \text{ quadratic residue mod } q,\\ -1 & \text{otherwise}, \end{cases}$$chúng ta có thể viết lại:$$G = 1+2\sum_{r\in QR(q)}2^r \pmod p,$$Ở đâu$QR(q)$là tập các thặng dư bậc hai khác 0 modulo$q$. 

Vì$q\equiv1\pmod8$(đúng ở đây), tổng Gauss này là căn bậc hai _lớn hơn_, vì vậy$$R(q)=p-G.$$Như vậy$$R(q) = 2^{q+1}-3 - 2\sum_{r\in QR(q)}2^r.$$Chúng tôi chỉ cần modulo này$M=10^9+7$, do đó tất cả các tính toán được thực hiện modulo$M$. 

Một trực tiếp$O(q)$tính toán là khả thi. 

Mã Python:```python
q = 74207281
MOD = 10**9 + 7

# mark quadratic residues mod q
qr = bytearray(q)
half = (q - 1) // 2

for i in range(1, half + 1):
    qr[(i * i) % q] = 1

s = 0
p2 = 2

for r in range(1, q):
    if qr[r]:
        s = (s + p2) % MOD
    p2 = (p2 * 2) % MOD

# p2 == 2^q mod MOD
ans = (2 * p2 - 3 - 2 * s) % MOD

print(ans)
```Điều này đánh giá để:
