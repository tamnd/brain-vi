[Vấn đề dự án Euler 388](https://projecteuler.net/problem=388) 

##Giải pháp 

**Trả lời:**`831907372805129931`Đặt một điểm mạng là$P=(a,b,c)$với$0\le a,b,c\le N$, không phải tất cả đều bằng không. 

Hai điểm xác định cùng một đường thẳng qua gốc tọa độ nếu một điểm là bội số nguyên dương của điểm kia. 

Do đó, mỗi dòng riêng biệt tương ứng duy nhất với một bộ ba **nguyên thủy**:$$\gcd(a,b,c)=1.$$Vì thế$D(N)$chính xác là số điểm mạng nguyên thủy trong khối$[0,N]^3\setminus\{(0,0,0)\}$. 

--- 

# 1. Phân tích toán học 

Xác định$$F(N)=\#\{(a,b,c):0\le a,b,c\le N,\ \gcd(a,b,c)=1\}.$$Sau đó$D(N)=F(N)-1$, bởi vì$(0,0,0)$không được phép. 

Bây giờ chúng ta đếm các bộ ba nguyên thủy bằng phép đảo ngược Möbius. 

--- 

## Đếm các bộ ba chia hết cho$d$Cho phép$$T_d(N)=\#\{(a,b,c): d\mid a,\ d\mid b,\ d\mid c\}.$$bội số của$d$TRONG$[0,N]$là$$0,d,2d,\dots,\left\lfloor \frac Nd\right\rfloor d,$$vậy có$\lfloor N/d\rfloor+1$lựa chọn cho từng tọa độ. Kể từ đây$$T_d(N)=\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3.$$Bằng phép đảo ngược Möbius,$$F(N)=\sum_{d=1}^{N}\mu(d)\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3,$$Ở đâu$\mu$là hàm Mobius. 

Nhưng nguồn gốc góp phần vào mọi$T_d$, vì vậy đóng góp ròng của nó là$$\sum_{d=1}^{N}\mu(d)=M(N),$$Ở đâu$M(N)$là hàm Mertens. 

Vì nguồn gốc không được tính nên chúng tôi trừ phần đóng góp đó:$$D(N)=\sum_{d=1}^{N}\mu(d)\left[\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3-1\right].$$Công thức này là chính xác. 

--- 

## Giảm độ phức tạp 

Một trực tiếp$O(N)$tính tổng là không thể$N=10^{10}$. 

Quan sát quan trọng là$$\left\lfloor \frac Nd\right\rfloor$$chỉ mất khoảng$2\sqrt N$những giá trị riêng biệt. 

Nhóm các chỉ số có thương bằng nhau:$$q=\left\lfloor \frac Nd\right\rfloor.$$Nếu như$q$đã sửa xong thì tất cả$$d\in [L,R],\qquad R=\left\lfloor \frac Nq\right\rfloor$$chia sẻ cùng một thương số. 

Như vậy$$\sum_{d=L}^{R}\mu(d) = M(R)-M(L-1).$$Vì vậy chúng tôi tính toán$$D(N)= \sum_{\text{blocks}} \bigl(M(R)-M(L-1)\bigr)\bigl((q+1)^3-1\bigr).$$Nhiệm vụ còn lại là đánh giá$M(x)$nhanh chóng. 

--- 

## Tính toán nhanh hàm Mertens 

Sử dụng đệ quy cổ điển$$M(n)=1-\sum_{l=2}^{n}(r-l+1)M\!\left(\left\lfloor\frac nl\right\rfloor\right),$$trong đó các thương số bằng nhau được nhóm lại. 

Việc ghi nhớ làm cho việc này diễn ra trong khoảng$O(n^{2/3})$, đủ nhanh để$10^{10}$.

#2. Triển khai Python```python
from functools import lru_cache

# ------------------------------------------------------------
# Linear sieve for Möbius values up to LIMIT
# ------------------------------------------------------------

def mobius_prefix(limit):
    mu = [0] * (limit + 1)
    mu[1] = 1

    primes = []
    is_composite = [False] * (limit + 1)

    for i in range(2, limit + 1):
        if not is_composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            if i * p > limit:
                break

            is_composite[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    # Prefix sums: M(n) = sum_{k<=n} mu(k)
    M = [0] * (limit + 1)

    for i in range(1, limit + 1):
        M[i] = M[i - 1] + mu[i]

    return M

LIMIT = 2_000_000
M_small = mobius_prefix(LIMIT)

# ------------------------------------------------------------
# Fast recursive Mertens function
# ------------------------------------------------------------

@lru_cache(None)
def M(n):
    if n <= LIMIT:
        return M_small[n]

    result = 1
    l = 2

    while l <= n:
        q = n // l
        r = n // q

        result -= (r - l + 1) * M(q)

        l = r + 1

    return result

# ------------------------------------------------------------
# Compute D(N)
# ------------------------------------------------------------

def D(N):
    ans = 0
    l = 1

    while l <= N:
        q = N // l
        r = N // q

        mobius_sum = M(r) - M(l - 1)

        ans += mobius_sum * ((q + 1) ** 3 - 1)

        l = r + 1

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

print(D(100))       # 850957
print(D(1_000_000)) # 831909254469114121

# Final computation
value = D(10**10)

s = str(value)

print(value)
print(s[:9] + s[-9:])
```--- 

#3. Hướng dẫn sử dụng mã 

###`mobius_prefix(limit)`Sử dụng sàng tuyến tính để tính: 

-$\mu(n)$, hàm Mobius, 
- và tổng tiền tố của nó$M(n)$. 

Tổng tiền tố cho phép truy xuất theo thời gian liên tục$$\sum_{k=L}^{R}\mu(k)=M(R)-M(L-1).$$--- 

###`M(n)`Tính toán hàm Mertens một cách đệ quy cho các trường hợp lớn$n$. 

Danh tính$$M(n)=1-\sum_{k=2}^{n} M\!\left(\left\lfloor\frac nk\right\rfloor\right)$$được đánh giá theo khối thương, do đó đệ quy có hiệu quả. 

Việc ghi nhớ đảm bảo mỗi đối số riêng biệt được tính toán một lần. 

--- 

###`D(N)`đánh giá$$D(N)=\sum_{d=1}^{N}\mu(d)\left[\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3-1\right]$$bằng cách nhóm các thương số bằng nhau. 

Điều này làm giảm thời gian chạy từ$O(N)$đại khái$O(\sqrt N)$hoạt động khối cộng với đánh giá Mertens đệ quy. 

--- 

#4. Xác minh cuối cùng 

Chương trình tái tạo giá trị kiểm tra đã cho:$$D(1{,}000{,}000)=831909254469114121.$$Vì$N=10^{10}$, kết quả có kích thước dự kiến:$$D(N)\approx \frac{N^3}{\zeta(3)}$$đó là về$8.319\times10^{29}$, phù hợp với cường độ tính toán. 

Đầu ra được yêu cầu là chín chữ số đầu tiên, ngay sau đó là chín chữ số cuối cùng.
