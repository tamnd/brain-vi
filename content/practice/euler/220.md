[Vấn đề dự án Euler 220](https://projecteuler.net/problem=220) 

##Giải pháp 

**Trả lời:**`139776963904`Cho phép

-$A_n$biểu thị sự mở rộng của biểu tượng`a`sau đó$n$viết lại, 
-$B_n$biểu thị sự mở rộng của biểu tượng`b`sau đó$n$viết lại. 

Quy tắc viết lại là$$a \to aRbFR,\qquad b \to LFaLb$$và con rồng đầy đủ là$$D_n = F A_n$$bởi vì$D_0 = Fa$. 

Quan sát quan trọng là: 

- số bước tiến tăng gấp đôi sau mỗi thế hệ, 
- nhưng tổng chiều dài chuỗi tăng theo cấp số nhân, 
- vì vậy chúng tôi không thể tạo ra$D_{50}$một cách rõ ràng. 

Thay vào đó, chúng tôi tính toán đệ quy: 

1. vectơ chuyển vị của mỗi khối, 
2. hướng thay đổi sau khi thực hiện nó, 
3. số bước tiến bên trong nó. 

Sau đó, chúng tôi “bỏ qua” toàn bộ khối đệ quy bất cứ khi nào có thể. 

--- 

# Phân tích toán học 

Chúng tôi sử dụng hướng dẫn$$0=\text{up},\quad 1=\text{right},\quad 2=\text{down},\quad 3=\text{left}.$$Một bước tiến về phía trước theo hướng$d$là:$$(0,1),(1,0),(0,-1),(-1,0).$$Đối với mỗi khối đệ quy, chúng tôi lưu trữ:$$(\Delta x,\Delta y,\Delta d,\text{steps})$$ý nghĩa: 

- chuyển vị ròng, 
- vòng quay ròng, 
- số lượng`F`hướng dẫn. 

--- 

##Cấu trúc đệ quy 

cho$n\ge1$,$$A_n = A_{n-1} \; R \; B_{n-1} \; F \; R$$

$$B_n = L \; F \; A_{n-1} \; L \; B_{n-1}$$Các biểu tượng`a,b`bản thân họ không làm gì ở cấp độ$0$, Vì thế$$A_0=B_0=\varepsilon$$với độ dịch chuyển bằng không và bước bằng không. 

--- 

## Số bước tiến 

hãy để$f_n$là số lượng`F`lệnh trong$A_n$. 

Từ đệ quy:$$f_n=f_{n-1}+f_{n-1}+1$$với$f_0=0$. 

Như vậy$$f_n = 2^n-1.$$Vì thế$D_{50}$chứa$$1+(2^{50}-1)=2^{50}$$bước về phía trước, lớn hơn một cách thoải mái so với$10^{12}$. 

--- 

# Bỏ qua đệ quy hiệu quả 

Giả sử chúng ta muốn cái đầu tiên$k$bước vào bên trong$A_n$. 

Đối với mỗi khối con: 

- nếu toàn bộ khối con chứa$\le k$các bước, chúng tôi bỏ qua nó ngay lập tức bằng cách sử dụng chuyển vị được tính toán trước của nó; 
- nếu không chúng ta sẽ lặp lại vào khối đó. 

Điều này chỉ mang lại sự phức tạp$O(n)$.

#Triển khai Python```python
from functools import lru_cache

# Rotate a vector clockwise by 90 degrees d times
def rotate(v, d):
    x, y = v
    for _ in range(d % 4):
        x, y = y, -x
    return x, y

# ------------------------------------------------------------
# Precompute properties of A_n and B_n
#
# Returns:
#   (dx, dy, dir_change, steps)
# ------------------------------------------------------------

@lru_cache(None)
def props(symbol, n):

    # Base case: a and b do nothing at level 0
    if n == 0:
        return (0, 0, 0, 0)

    if symbol == 'a':
        seq = ['a', 'R', 'b', 'F', 'R']
    else:
        seq = ['L', 'F', 'a', 'L', 'b']

    x = y = 0
    d = 0
    steps = 0

    for t in seq:

        if t in 'ab':

            dx, dy, dd, ss = props(t, n - 1)

            # Rotate displacement into current orientation
            rdx, rdy = rotate((dx, dy), d)

            x += rdx
            y += rdy

            d = (d + dd) % 4
            steps += ss

        elif t == 'F':

            move = [(0, 1), (1, 0), (0, -1), (-1, 0)][d]

            x += move[0]
            y += move[1]
            steps += 1

        elif t == 'L':
            d = (d - 1) % 4

        elif t == 'R':
            d = (d + 1) % 4

    return (x, y, d, steps)

# ------------------------------------------------------------
# Walk the first k forward steps inside symbol_n
# ------------------------------------------------------------

def walk(symbol, n, k, pos=(0, 0), direction=0):

    x, y = pos
    d = direction

    if n == 0 or k == 0:
        return (x, y, d, k)

    if symbol == 'a':
        seq = ['a', 'R', 'b', 'F', 'R']
    else:
        seq = ['L', 'F', 'a', 'L', 'b']

    for t in seq:

        if k == 0:
            break

        if t in 'ab':

            dx, dy, dd, ss = props(t, n - 1)

            # Skip whole block if possible
            if ss <= k:

                rdx, rdy = rotate((dx, dy), d)

                x += rdx
                y += rdy

                d = (d + dd) % 4
                k -= ss

            else:
                x, y, d, k = walk(t, n - 1, k, (x, y), d)

        elif t == 'F':

            move = [(0, 1), (1, 0), (0, -1), (-1, 0)][d]

            x += move[0]
            y += move[1]

            k -= 1

        elif t == 'L':
            d = (d - 1) % 4

        elif t == 'R':
            d = (d + 1) % 4

    return (x, y, d, k)

# ------------------------------------------------------------
# Full dragon D_n = F + A_n
# ------------------------------------------------------------

def solve(n, steps):

    # Initial instruction F
    x, y = (0, 1)
    steps -= 1

    if steps > 0:
        x, y, d, rem = walk('a', n, steps, (x, y), 0)

    return x, y

# ------------------------------------------------------------
# Verification against the example
# ------------------------------------------------------------

print(solve(10, 500))      # should be (18, 16)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

print(solve(50, 10**12))
```--- 

# Hướng dẫn sử dụng mã 

##`props(symbol, n)`Điều này đệ quy tính toán hiệu quả hoàn chỉnh của$A_n$hoặc$B_n$: 

- sự dịch chuyển, 
- hướng cuối cùng, 
- số bước tiến. 

Các giá trị này được ghi nhớ nên mỗi trạng thái được tính một lần. 

--- 

##`walk(symbol, n, k, ...)`Điều này chỉ thực hiện đệ quy lần đầu tiên$k$những bước tiến về phía trước. 

Tối ưu hóa khóa:```python
if ss <= k:
```có nghĩa là: 

> toàn bộ khối đệ quy vừa khít với ngân sách còn lại, 
> 
> nên chúng tôi bỏ qua nó ngay lập tức. 

Nếu không chúng ta sẽ tái diễn sâu hơn. 

--- 

##`solve(n, steps)`Con rồng bắt đầu bằng chữ cái đầu`F`, sau đó thực hiện$A_n$. 

Vì vậy chúng tôi: 

1. di chuyển một lần đến$(0,1)$, 
2. xử lý đệ quy các bước còn lại.
