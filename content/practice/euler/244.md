##Giải pháp 

**Trả lời:**`96356848`Hãy để chúng tôi mã hóa$4\times 4$xếp từng hàng dưới dạng một chuỗi có độ dài$16$, sử dụng 

-`r`= gạch đỏ 
-`b`= gạch xanh 
-`.`= hình vuông trống 

Từ báo cáo vấn đề, hai cấu hình là:$$S = \texttt{".rbbrrbbrrbbrrbb"}$$

$$T = \texttt{".brbbrbrrbrbbrbr"}$$Nhiệm vụ là: 

1. Tìm **tất cả các đường đi ngắn nhất** từ$S$ĐẾN$T$, 
2. Tính tổng kiểm tra của từng đường dẫn, 
3. Tính tổng các tổng kiểm tra đó.

# Phân tích toán học 

Đây là bài toán tìm đường đi ngắn nhất cổ điển trên đồ thị hữu hạn. 

- Mỗi cấu hình bảng là một nút. 
- Một bước di chuyển hợp pháp sẽ tạo ra lợi thế. 
- Mọi cạnh đều có trọng số bằng nhau$1$. 

Do đó, thuật toán đúng là: 

- **Tìm kiếm theo chiều rộng (BFS)** từ trạng thái bắt đầu. 

Bởi vì BFS khám phá các trạng thái theo thứ tự khoảng cách tăng dần, nên lần đầu tiên chúng tôi đạt được mục tiêu, chúng tôi đảm bảo đã tìm thấy độ dài di chuyển tối thiểu. 

--- 

## Chuyển đổi trạng thái 

Giả sử hình vuông trống ở tọa độ$(x,y)$. 

Một động thái: 

-`L`có nghĩa là một viên gạch trượt vào chỗ trống, 
- tương đương với ô trống di chuyển sang phải. 

Tương tự: 

| Di chuyển | Chuyển động trống | 
| --- | --- | 
| L | đúng | 
| R | trái | 
| Bạn | xuống | 
| D | lên | 

--- 

# Tính toán tổng kiểm tra 

Đối với một chuỗi di chuyển$m_1,m_2,\dots,m_n$,$$c_0 = 0$$

$$c_{k+1} = (243c_k + \text{ASCII}(m_{k+1})) \bmod 100000007$$Giá trị ASCII: 

| Di chuyển | ASCII | 
| --- | --- | 
| L | 76 | 
| R | 82 | 
| Bạn | 85 | 
| D | 68 | 

--- 

#Triển khai Python```python
from collections import deque

MOD = 100000007

# Start and target configurations
START = ".rbbrrbbrrbbrrbb"
TARGET = ".brbbrbrrbrbbrbr"

# Move definitions:
# (move_char, dx, dy)
#
# dx,dy describe movement of the BLANK square.
moves = [
    ('L',  1,  0),   # blank moves right
    ('R', -1,  0),   # blank moves left
    ('U',  0,  1),   # blank moves down
    ('D',  0, -1),   # blank moves up
]

def neighbors(state):
    """Generate all legal next states."""
    i = state.index('.')
    x, y = i % 4, i // 4

    for ch, dx, dy in moves:
        nx, ny = x + dx, y + dy

        if 0 <= nx < 4 and 0 <= ny < 4:
            j = ny * 4 + nx

            s = list(state)
            s[i], s[j] = s[j], s[i]

            yield ''.join(s), ch

def checksum(path):
    """Compute checksum of a move string."""
    c = 0
    for ch in path:
        c = (c * 243 + ord(ch)) % MOD
    return c

# BFS
queue = deque([START])

# predecessor map:
# state -> (previous_state, move_used)
prev = {START: (None, None)}

while queue:
    state = queue.popleft()

    if state == TARGET:
        break

    for nxt, move in neighbors(state):
        if nxt not in prev:
            prev[nxt] = (state, move)
            queue.append(nxt)

# Reconstruct shortest path
path = []

cur = TARGET
while prev[cur][0] is not None:
    cur, move = prev[cur]
    path.append(move)

path.reverse()
path = ''.join(path)

print("Shortest path length:", len(path))
print("Path:", path)
print("Checksum:", checksum(path))
```---

## 3. Tìm kiếm theo chiều rộng```python
queue = deque([START])
```BFS khám phá các vị trí trong việc tăng số lần di chuyển.

```lưu trữ cách chúng tôi đến từng tiểu bang lần đầu tiên.
