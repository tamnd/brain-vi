[Vấn đề dự án Euler 613](https://projecteuler.net/problem=613) 

##Giải pháp 

**Trả lời:**`0.3916721504`Cho tam giác vuông có các đỉnh 

-$A=(0,0)$, 
-$B=(30,0)$, 
-$C=(0,40)$, 

vậy cạnh dài nhất là cạnh huyền$BC$chiều dài$50$. 

Vì một điểm$P=(x,y)$bên trong tam giác, nếu con kiến ​​chọn một hướng ngẫu nhiên đều thì xác suất nó thoát ra qua cạnh$BC$bằng với độ rộng góc của hướng chạm vào$BC$, chia cho$2\pi$. 

Chiều rộng góc đó chính xác là góc phụ thuộc bởi đoạn$BC$Tại$P$:$$p(P)=\frac{\angle BPC}{2\pi}.$$Do đó xác suất mong muốn là trung bình của đại lượng này trên toàn bộ tam giác:$$\Pr(BC) = \frac{1}{\text{Area}(\triangle)} \iint_{\triangle} \frac{\angle BPC}{2\pi} \,dA.$$Diện tích tam giác là$$\frac{30\cdot 40}{2}=600.$$Vì$P=(x,y)$,$$\angle BPC = \cos^{-1} \!\left( \frac{(B-P)\cdot(C-P)} {|B-P||C-P|} \right).$$Rõ ràng:$$B-P=(30-x,-y), \qquad C-P=(-x,40-y).$$Vì vậy chúng tôi đánh giá bằng số$$\frac{1}{600} \int_0^{30} \int_0^{40-\frac43x} \frac{ \cos^{-1} \left( \frac{(30-x)(-x)+(-y)(40-y)} {\sqrt{(30-x)^2+y^2}\sqrt{x^2+(40-y)^2}} \right) }{2\pi} \,dy\,dx.$$### Triển khai Python```python
import mpmath as mp

# High precision
mp.mp.dps = 50

def subtended_angle(x, y):
    # vectors from P=(x,y) to B and C
    bx, by = 30 - x, -y
    cx, cy = -x, 40 - y

    # dot product
    dot = bx * cx + by * cy

    # magnitudes
    norm_b = mp.sqrt(bx * bx + by * by)
    norm_c = mp.sqrt(cx * cx + cy * cy)

    # angle BPC
    cos_theta = dot / (norm_b * norm_c)
    return mp.acos(cos_theta)

def integrand(y, x):
    # probability from point (x,y)
    return subtended_angle(x, y) / (2 * mp.pi)

# upper boundary of the triangle:
# y = 40 - (4/3)x
def integrate_x(x):
    ymax = 40 - (4 * x / 3)
    return mp.quad(lambda y: integrand(y, x), [0, ymax])

# integrate over triangle and divide by area
area = 600
result = mp.quad(lambda x: integrate_x(x), [0, 30]) / area

print(result)
print(round(result, 10))
```### Hướng dẫn sử dụng mã 

1. **`subtended_angle(x, y)`** 

Tính góc$\angle BPC$sử dụng công thức tích số chấm:$$\cos\theta = \frac{u\cdot v}{|u||v|}.$$2. **`integrand(y, x)`** 

Chuyển đổi góc thành xác suất bằng cách chia cho$2\pi$. 
3. **Giới hạn tam giác** 

Cạnh huyền là$$y = 40-\frac43x,$$vì vậy đối với mỗi$x\in[0,30]$,$$0\le y\le 40-\frac43x.$$4. **Tích hợp kép** 

Chúng tôi lấy tích phân số trên tam giác và chia cho diện tích$600$tính trung bình trên tất cả các vị trí bắt đầu.
