## Giải pháp 

**Trả lời:**`2304215802083466198`Cho phép$$S=\sum_{n=1}^{10^{11}} s(n,10^8),$$Ở đâu$s(n,m)$là tổng của các thừa số nguyên tố **khác biệt**$p\le m$của$n^{15}+1$. 

Điều quan trọng là đảo ngược thứ tự tính tổng. 

--- 

## 1. Viết lại tổng 

Một số nguyên tố$p$góp phần vào$s(n,10^8)$nếu$$p\mid n^{15}+1,$$tức là$$n^{15}\equiv -1 \pmod p.$$Vì thế,$$S=\sum_{p\le 10^8} p\cdot \#\{1\le n\le 10^{11}: n^{15}\equiv -1 \pmod p\}.$$Vì vậy với mỗi số nguyên tố$p$, chúng ta chỉ cần đếm các lớp dư lượng theo modulo$p$thỏa mãn$$x^{15}\equiv -1 \pmod p.$$--- 

#2. Cấu trúc của giải pháp 

Đối với số nguyên tố lẻ$p$, nhóm nhân$$(\mathbb Z/p\mathbb Z)^\times$$là trật tự tuần hoàn$p-1$. 

Quan sát:$$x^{15}\equiv -1 \iff (-x)^{15}\equiv 1.$$Vì vậy, các giải pháp tương ứng chính xác với gốc thứ 15 của sự thống nhất. 

Do đó số lượng giải pháp là$$d=\gcd(15,p-1),$$kể từ đây$d\in\{1,3,5,15\}$. 

Đối với số nguyên tố$p>5$, điều này chỉ phụ thuộc vào$p\bmod 30$: 

|$p\bmod 30$|$d$| 
| --- | --- | 
|$1$|$15$| 
|$11$|$5$| 
|$7,13,19$|$3$| 
|$17,23,29$|$1$|

# 3. Đếm số lần xuất hiện lên tới$10^{11}$Sửa một số nguyên tố$p$. 

Viết$$10^{11}=qp+t,\qquad 0\le t<p.$$Mỗi modulo lớp dư lượng hợp lệ$p$xuất hiện: 

- chính xác$q$lần trong số$1,\dots,10^{11}$, 
- cộng thêm một lần xuất hiện nếu dư lượng là$\le t$. 

Vì vậy, nếu dư lượng hợp lệ là$r_1,\dots,r_d$, sau đó$$\#\{n\le 10^{11}: p\mid n^{15}+1\} = dq+\#\{i:r_i\le t\}.$$Do đó, việc tính toán hoàn toàn theo mô-đun. 

--- 

#4. Tạo rễ hiệu quả 

Nếu$u^{15}\equiv1$, sau đó$n\equiv -u\pmod p$giải quyết sự đồng nhất. 

Vì vậy, chúng ta tạo ra nhóm con của nghiệm thứ 15. 

Để có được một bộ sinh của nhóm con thứ tự$d$, chúng tôi tính toán$$g=a^{(p-1)/d}\pmod p$$cho các cơ sở thử nghiệm nhỏ$a$. 

Sau đó$$1,g,g^2,\dots,g^{d-1}$$chính xác là gốc rễ thứ 15 của sự thống nhất. 

Các giải pháp tương ứng là$$n\equiv -1,-g,-g^2,\dots \pmod p.$$--- 

#5. Triển khai Python```python
from math import isqrt

# ---------------------------------------------------------
# Odd-only sieve of Eratosthenes
# ---------------------------------------------------------
def iter_odd_primes_upto(limit):
    size = (limit + 1) // 2
    sieve = bytearray(b"\x01") * size
    sieve[0] = 0

    r = isqrt(limit)

    for i in range(1, (r // 2) + 1):
        if sieve[i]:
            p = 2 * i + 1
            start = (p * p) // 2
            sieve[start::p] = b"\x00" * (((size - start - 1) // p) + 1)

    idx = sieve.find(1, 1)

    while idx != -1:
        yield 2 * idx + 1
        idx = sieve.find(1, idx + 1)

# ---------------------------------------------------------
# Test whether g has exact order 15 mod p
# ---------------------------------------------------------
def is_order_15(g, p):
    return (
        g != 1 and
        pow(g, 3, p) != 1 and
        pow(g, 5, p) != 1
    )

# ---------------------------------------------------------
# Find generator of subgroup of order d
# ---------------------------------------------------------
def find_generator(p, d):
    exp = (p - 1) // d

    for a in range(2, 100):
        g = pow(a, exp, p)

        if d in (3, 5):
            if g != 1:
                return g

        else:  # d == 15
            if is_order_15(g, p):
                return g

    raise RuntimeError("generator not found")

# ---------------------------------------------------------
# Main solver
# ---------------------------------------------------------
def solve(L=10**11, M=10**8):

    # d = gcd(15, p-1) determined by p mod 30
    d_table = [1] * 30
    d_table[1] = 15
    d_table[11] = 5
    d_table[7] = d_table[13] = d_table[19] = 3

    ans = 0

    # prime 2
    ans += 2 * ((L + 1) // 2)

    for p in iter_odd_primes_upto(M):

        d = d_table[p % 30]

        q, t = divmod(L, p)

        # only residue is -1 mod p
        if d == 1:
            cnt = q + (1 if t == p - 1 else 0)
            ans += p * cnt
            continue

        # subgroup generator
        g = find_generator(p, d)

        threshold = p - t

        u = 1
        extra = 0

        for _ in range(d):
            if u >= threshold:
                extra += 1
            u = (u * g) % p

        cnt = d * q + extra

        ans += p * cnt

    return ans

print(solve())
