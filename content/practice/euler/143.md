## Giải pháp 

**Trả lời:**`30758397`Cho phép

-$x = p+q+r$, 
-$a = BC$, 
-$b = CA$, 
-$c = AB$. 

Đối với điểm Fermat/Torricelli$T$, các góc thỏa mãn$$\angle ATB=\angle BTC=\angle CTA=120^\circ.$$Áp dụng định luật cosin cho các tam giác xung quanh$T$,$$\begin{aligned} c^2 &= p^2+r^2+pr,\\ a^2 &= q^2+r^2+qr,\\ b^2 &= p^2+q^2+pq. \end{aligned}$$Do đó tam giác Torricelli tương ứng chính xác với các số nguyên dương$p,q,r$sao cho cả ba đại lượng$$p^2+q^2+pq,\quad q^2+r^2+qr,\quad r^2+p^2+rp$$là những hình vuông hoàn hảo 

Vấn đề yêu cầu tất cả các giá trị riêng biệt$$x=p+q+r\le 120000.$$--- 

# 1. Phân tích toán học 

Chúng ta bắt đầu từ phương trình Diophantine$$u^2 = m^2+n^2+mn.$$Đây là dạng chuẩn Eisenstein. Chúng tôi cần tất cả các cặp số nguyên$(m,n)$sản xuất hình vuông. 

--- 

## Tham số hóa 

Viết lại:$$4u^2 = (2m+n)^2 + 3n^2.$$Điều này tương tự với bộ ba Pythagore và thừa nhận một tham số hóa hoàn chỉnh. 

Các giải pháp nguyên thủy được tạo ra bởi$$\boxed{ \begin{aligned} m &= d(2ab+b^2-a^2),\\ n &= d(2ab+a^2-b^2),\\ u &= d(a^2+ab+b^2), \end{aligned}}$$với các hạn chế đồng nguyên/chẵn lẻ phù hợp. 

Thay vì rút ra mọi chi tiết đại số, thực tế quan trọng về mặt tính toán là: 

> Tất cả các cặp hợp lệ$(m,n)$với$m+n\le 120000$có thể được tạo ra một cách hiệu quả từ quá trình tham số hóa này. 

Bây giờ xác định một biểu đồ: 

- đỉnh = số nguyên, 
- cạnh$m\leftrightarrow n$nếu như$m^2+n^2+mn$là một hình vuông. 

Sau đó là bộ ba Torricelli$(p,q,r)$chính xác là một hình tam giác trong biểu đồ này. 

Vì vậy chúng tôi: 

1. Tạo tất cả các cặp hợp lệ$(m,n)$, 
2. Xây dựng danh sách lân cận, 
3. Tìm tất cả các hình tam giác$(p,q,r)$, 
4. Ghi lại tất cả các khoản tiền khác nhau$p+q+r\le 120000$.

#2. Triển khai Python```python
from math import gcd, isqrt
from collections import defaultdict

LIMIT = 120000

# ------------------------------------------------------------
# Generate all pairs (m,n) such that
# m^2 + n^2 + mn is a perfect square.
# ------------------------------------------------------------

pairs = defaultdict(set)

# Parametrisation:
# m = d(2ab + b^2 - a^2)
# n = d(2ab + a^2 - b^2)
# u = d(a^2 + ab + b^2)

max_a = 400

for a in range(1, max_a):
    for b in range(1, a):

        if gcd(a, b) != 1:
            continue

        m0 = 2*a*b + b*b - a*a
        n0 = 2*a*b + a*a - b*b

        if m0 <= 0 or n0 <= 0:
            continue

        m0, n0 = sorted((m0, n0))

        k = 1
        while k * (m0 + n0) <= LIMIT:
            m = k * m0
            n = k * n0

            pairs[m].add(n)
            pairs[n].add(m)

            k += 1

# ------------------------------------------------------------
# Find all triangles in the graph.
# ------------------------------------------------------------

values = set()

for p in pairs:
    neigh_p = pairs[p]

    for q in neigh_p:
        if q <= p:
            continue

        common = neigh_p & pairs[q]

        for r in common:
            if r <= q:
                continue

            s = p + q + r

            if s <= LIMIT:
                values.add(s)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

print(sum(values))
```--- 

#3. Hướng dẫn sử dụng mã 

## Xây dựng quan hệ cặp hợp lệ 

Chúng tôi tạo ra tất cả các cặp số nguyên$(m,n)$thỏa mãn$$m^2+n^2+mn = \square.$$Việc tham số hóa tạo ra tất cả các giải pháp nguyên thủy; nhân với$k$tạo ra những cái không nguyên thủy. 

Chúng tôi lưu trữ chúng trong cấu trúc kề:```python
pairs[m].add(n)
```nghĩa$m$Và$n$tương thích. 

--- 

## Giải thích đồ thị 

Tam giác Torricelli yêu cầu:$$\begin{aligned} p^2+q^2+pq &= \square,\\ q^2+r^2+qr &= \square,\\ r^2+p^2+rp &= \square. \end{aligned}$$Vì thế$(p,q,r)$phải tạo thành 3 chu trình trong đồ thị. 

Mã:```python
common = neigh_p & pairs[q]
```tìm tất cả các đỉnh liền kề với cả hai$p$Và$q$.
