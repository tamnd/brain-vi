[Vấn đề dự án Euler 96](https://projecteuler.net/problem=96) 

##Giải pháp 

**Trả lời:**`24702`Chìa khóa của vấn đề này không phải là lý thuyết số sâu mà là thiết kế một thuật toán tìm kiếm chính xác đáng tin cậy và hiệu quả để giải các câu đố Sudoku. 

Lưới Sudoku là một **vấn đề thỏa mãn ràng buộc**: 

- Mỗi hàng phải chứa các chữ số$1$–$9$đúng một lần. 
- Mỗi cột phải chứa các chữ số$1$–$9$đúng một lần. 
- Mỗi$3\times3$hộp phải chứa chữ số$1$–$9$đúng một lần. 

Nhiệm vụ Project Euler cung cấp 50 câu đố, mỗi câu đố có một giải pháp riêng. Đối với mỗi câu đố đã giải, chúng tôi trích xuất số có 3 chữ số được tạo bởi ba chữ số đầu tiên của hàng trên cùng và tính tổng chúng. 

--- 

# Phân tích toán học 

Giả sử một ô trống. 

Cho phép:

-$R$= các chữ số đã được sử dụng trong hàng của nó, 
-$C$= các chữ số đã được sử dụng trong cột của nó, 
-$B$= các chữ số đã được sử dụng trong nó$3\times3$hộp. 

Sau đó, các ứng cử viên được phép là$$\{1,\dots,9\}\setminus (R\cup C\cup B).$$Một câu đố được giải khi mỗi ô có đúng một giá trị. 

--- 

## Tìm kiếm quay lại 

Suy luận logic thuần túy nói chung là không đủ nên chúng tôi sử dụng tìm kiếm đệ quy. 

### Chiến lược 

1. Tìm ô trống có **ít ứng viên nhất**. 
2. Thử từng ứng viên. 
3. Tái diễn. 
4. Nếu xảy ra mâu thuẫn, hãy quay lại. 

Heuristic “giá trị còn lại tối thiểu” này cực kỳ quan trọng vì nó cắt bớt cây tìm kiếm một cách đáng kể. 

--- 

# Đại diện hiệu quả 

Chúng ta có thể biểu diễn các ràng buộc bằng cách sử dụng các tập hợp. 

Đối với mỗi hàng, cột và hộp, hãy giữ nguyên các chữ số đã sử dụng. 

Đối với một tế bào$(r,c)$:$$\text{box}(r,c)=3\left\lfloor \frac r3 \right\rfloor+\left\lfloor \frac c3 \right\rfloor.$$Các chữ số ứng cử viên được tính toán nhanh chóng từ các sai số đã đặt.

# Triển khai Python```python
from urllib.request import urlopen

# Download the Sudoku file
url = "https://projecteuler.net/project/resources/p096_sudoku.txt"
data = urlopen(url).read().decode().strip().splitlines()

# Parse puzzles
puzzles = []
for i in range(0, len(data), 10):
    grid = [list(map(int, data[i + j + 1])) for j in range(9)]
    puzzles.append(grid)

DIGITS = set(range(1, 10))

def solve(grid):
    """
    Solve a Sudoku puzzle using recursive backtracking
    with minimum-candidate heuristic.
    """

    # Track used digits
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]

    # Initialize constraint sets
    for r in range(9):
        for c in range(9):
            v = grid[r][c]
            if v:
                rows[r].add(v)
                cols[c].add(v)
                boxes[(r // 3) * 3 + (c // 3)].add(v)

    def backtrack():
        best = None
        best_candidates = None

        # Find empty cell with fewest candidates
        for r in range(9):
            for c in range(9):
                if grid[r][c] == 0:
                    b = (r // 3) * 3 + (c // 3)

                    candidates = (
                        DIGITS
                        - rows[r]
                        - cols[c]
                        - boxes[b]
                    )

                    if len(candidates) == 0:
                        return False

                    if best is None or len(candidates) < len(best_candidates):
                        best = (r, c, b)
                        best_candidates = candidates

        # No empty cells => solved
        if best is None:
            return True

        r, c, b = best

        # Try each candidate
        for v in best_candidates:
            grid[r][c] = v
            rows[r].add(v)
            cols[c].add(v)
            boxes[b].add(v)

            if backtrack():
                return True

            # Undo move
            grid[r][c] = 0
            rows[r].remove(v)
            cols[c].remove(v)
            boxes[b].remove(v)

        return False

    backtrack()
    return grid

total = 0

for puzzle in puzzles:
    solved = solve(puzzle)

    # Extract top-left 3-digit number
    value = (
        solved[0][0] * 100
        + solved[0][1] * 10
        + solved[0][2]
    )

    total += value

print(total)
```---

## Phân tích tập tin 

Mỗi câu đố trong tệp văn bản có: 

- một dòng tiêu đề như`Grid 01`- theo sau là 9 hàng chữ số. 

Chúng tôi xử lý các khối gồm 10 dòng cùng một lúc.```python
for i in range(0, len(data), 10):
```và chuyển đổi các hàng thành danh sách số nguyên. 

--- 

## Theo dõi ràng buộc 

Chúng tôi duy trì:```python
rows = [set() for _ in range(9)]
cols = [set() for _ in range(9)]
boxes = [set() for _ in range(9)]
```Những cửa hàng này những chữ số đã được sử dụng. 

Chỉ số hộp là:```python
(r // 3) * 3 + (c // 3)
```đưa ra những giá trị$0$bởi vì$8$. 

--- 

## Tính toán ứng viên 

Đối với ô trống:```python
candidates = DIGITS - rows[r] - cols[c] - boxes[b]
```Điều này trực tiếp thực hiện các ràng buộc về tính hợp pháp của Sudoku. 

--- 

## Heuristic ứng viên tối thiểu 

Chúng tôi tìm kiếm ô khó nhất trước tiên:```python
if best is None or len(candidates) < len(best_candidates):
```Điều này làm giảm đáng kể sự phân nhánh. 

--- 

## Quay lui đệ quy 

Đối với mỗi ứng viên:```python
grid[r][c] = v
```chúng tôi cập nhật các ràng buộc, lặp lại và hoàn tác nếu cần. 

Điều này đảm bảo một giải pháp chính xác vì mọi khả năng pháp lý đều được khám phá một cách có hệ thống.
