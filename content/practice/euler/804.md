[Vấn đề dự án Euler 804](https://projecteuler.net/problem=804) 

##Giải pháp 

**Trả lời:**`4921370551019052`Cho phép$$Q(x,y)=x^2+xy+41y^2.$$Từ$g(n)$đếm số cặp số nguyên$(x,y)$với$Q(x,y)=n$, chúng tôi có$$T(N)=\sum_{n=1}^N g(n)$$đó chính xác là số điểm mạng số nguyên thỏa mãn$$x^2+xy+41y^2 \le N,$$loại trừ$(0,0)$(từ$n\ge 1$). 

Viết lại dạng bậc hai:$$4Q=(2x+y)^2+163y^2.$$Vì vậy chúng ta đếm các cặp số nguyên$(x,y)$như vậy$$(2x+y)^2+163y^2\le 4N.$$Đối với một cố định$y$, cho phép$$r=\left\lfloor \sqrt{4N-163y^2}\right\rfloor.$$Sau đó$t=2x+y$phải thỏa mãn$|t|\le r$và có cùng tính chẵn lẻ như$y$. Số lượng như vậy$t$là$$r + \mathbf{1}_{r\equiv y \pmod 2}.$$Tổng hợp tất cả hợp lệ$y$đưa ra một$O(\sqrt N)$thuật toán:```python
from math import isqrt

def T(N):
    M = 4 * N
    ymax = isqrt(M // 163)

    total = -1  # exclude (0,0)

    for y in range(ymax + 1):
        r = isqrt(M - 163 * y * y)
        count = r + ((r & 1) == (y & 1))

        total += count if y == 0 else 2 * count

    return total

print(T(10**3))   # 474
print(T(10**6))   # 492128
print(T(10**16))
```Điều này tái tạo các kiểm tra đã cho: 

-$T(10^3)=474$-$T(10^6)=492128$và tính toán:$$T(10^{16}) = 4921370551019052.$$**Trả lời: 4921370551019052**
