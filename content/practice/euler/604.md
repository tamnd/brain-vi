##Giải pháp 

**Trả lời:**`1398582231101`Cho đồ thị đi qua các điểm mạng$$P_0,P_1,\dots,P_m$$với sự gia tăng nghiêm ngặt$x$-tọa độ và$y$-tọa độ. 

Xác định các vectơ bước$$v_i=P_i-P_{i-1}=(a_i,b_i),\qquad a_i,b_i\in \mathbb Z_{>0}.$$Đối với hàm tăng lồi chặt, hệ số góc phải thỏa mãn$$\frac{b_1}{a_1}<\frac{b_2}{a_2}<\cdots<\frac{b_m}{a_m}.$$Do đó, mọi hệ số góc có thể xảy ra nhiều nhất một lần, do đó mọi vectơ có thể được coi là nguyên thủy:$$\gcd(a_i,b_i)=1.$$Cũng,$$\sum a_i\le N,\qquad \sum b_i\le N.$$Do đó bài toán trở thành: 

> Chọn càng nhiều vectơ mạng dương nguyên thủy càng tốt, với độ dốc tăng dần, tuân theo 
> 
> 
> 
> 
>$$\sum a_i\le N,\qquad \sum b_i\le N.$$--- 

# 1. Đặt hàng theo$a+b$Đối với một vectơ nguyên thủy$(a,b)$, xác định “chi phí” của nó$$c=a+b.$$Để tối đa hóa số lượng vectơ, rõ ràng chúng ta lấy các vectơ có giá trị nhỏ nhất có thể có của$a+b$. 

Đối với một cố định$s$, các vectơ nguyên thủy với$a+b=s$là$$(a,s-a),\qquad 1\le a<s,\quad \gcd(a,s)=1.$$Có chính xác$$\varphi(s)$$các vectơ như vậy. 

--- 

#2. Chi phí cho một bộ vỏ hoàn chỉnh 

Hãy cân nhắc việc sử dụng **tất cả** các vectơ nguyên thủy với$a+b=s$. 

Vì tập hợp đối xứng dưới$a\leftrightarrow b$,$$\sum a=\sum b=\frac{s\varphi(s)}2$$(vì$s=2$, điều này bằng$1$). 

Vì vậy, nếu chúng ta lấy tất cả các vỏ$2,3,\dots,m$, sau đó$$X(m)=Y(m)=\frac12\sum_{s=2}^m s\varphi(s).$$Số vectơ được sử dụng là$$V(m)=\sum_{s=2}^m \varphi(s).$$Do đó số điểm mạng là$$F=V(m)+1.$$--- 

#3. Một phần lớp vỏ cuối cùng 

hãy để$m$đạt cực đại sao cho$$X(m)\le N.$$Xác định công suất còn lại$$R=N-X(m).$$Bây giờ chúng ta có thể lấy thêm các vectơ từ lớp vỏ tiếp theo$s=m+1$. 

Mỗi vectơ như vậy có tổng chi phí$s$, vì vậy mọi vectơ được thêm vào đều tiêu thụ chính xác$s$đơn vị từ ngân sách tổng hợp$$(\sum a_i)+(\sum b_i)\le 2N.$$Ngân sách tổng hợp còn lại là$2R$, do đó các vectơ phụ tối đa là$$\left\lfloor \frac{2R}{s}\right\rfloor .$$Vì thế$$\boxed{ F(N)=1+\sum_{k=2}^m\varphi(k) +\left\lfloor \frac{2\left(N-\frac12\sum_{k=2}^m k\varphi(k)\right)} {m+1} \right\rfloor }$$Ở đâu$m$là cực đại với$$\frac12\sum_{k=2}^m k\varphi(k)\le N.$$Điều này tái tạo tất cả các giá trị đã cho: 

-$F(3)=3$-$F(9)=6$-$F(11)=7$-$F(100)=30$-$F(50000)=1898$--- 

#4. Triển khai Python```python
from array import array

N = 10**18

# ---------------------------------------------------------
# Compute Euler phi up to a sufficient limit.
# The required m is about (pi^2 N)^(1/3) ~ 2.15e6.
# ---------------------------------------------------------

LIMIT = 3_000_000

phi = array('Q', range(LIMIT + 1))

for p in range(2, LIMIT + 1):
    if phi[p] == p:                 # p is prime
        for k in range(p, LIMIT + 1, p):
            phi[k] -= phi[k] // p

# ---------------------------------------------------------
# Accumulate complete shells
# ---------------------------------------------------------

used = 0          # X(m)
count = 1         # initial lattice point
s = 2

while True:

    # contribution of the complete shell a+b=s
    add = (s * phi[s]) // 2

    if used + add > N:
        break

    used += add
    count += phi[s]
    s += 1

# ---------------------------------------------------------
# Partial next shell
# ---------------------------------------------------------

remaining = N - used
extra = (2 * remaining) // s

answer = count + extra

print(answer)
```--- 

#5. Hướng dẫn sử dụng mã 

###Sàng toàn phần```python
phi = array('Q', range(LIMIT + 1))
```Khởi tạo$\phi(n)=n$. 

Đối với mỗi số nguyên tố$p$,```python
phi[k] -= phi[k] // p
```thực hiện công thức tích Euler$$\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).$$--- 

### Xây dựng shell hoàn chỉnh 

Đối với vỏ$s$,```python
add = (s * phi[s]) // 2
```là số tiền được thêm vào cả hai$x$- Và$y$-tổng số. 

Chúng tôi tiếp tục lấy toàn bộ vỏ trong khi ngân sách cho phép. 

Số vectơ được thêm vào là```python
count += phi[s]
```bởi vì vỏ$s$chứa chính xác$\varphi(s)$các vectơ nguyên thủy. 

--- 

### Vỏ cuối cùng một phần 

Sau shell hoàn chỉnh cuối cùng:```python
remaining = N - used
extra = (2 * remaining) // s
```thêm càng nhiều vectơ càng tốt từ lớp vỏ tiếp theo. 

Cuối cùng,```python
answer = count + extra
```đưa ra tổng số điểm mạng.
