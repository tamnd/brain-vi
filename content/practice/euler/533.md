##Giải pháp 

**Trả lời:**`789453601`Cho phép$$L(n)=\min\{m:\lambda(k)\ge n \text{ for all } k\ge m\}.$$Tương đương,$$L(n)=1+\max\{k:\lambda(k)<n\}.$$Vì vậy, vấn đề trở thành: 

> Tìm số nguyên lớn nhất$k$với$\lambda(k)<20\,000\,000$. 

--- 

#1. Cấu trúc của hàm Carmichael 

Đối với quyền lực chính:$$\lambda(p^a)= \begin{cases} 1 & p=2,\ a=1\\ 2 & p=2,\ a=2\\ 2^{a-2} & p=2,\ a\ge3\\ p^{a-1}(p-1) & p\text{ odd} \end{cases}$$Và$$\lambda(n)=\operatorname{lcm}\bigl(\lambda(p_i^{a_i})\bigr).$$--- 

#2. Tối đa$n$cố định$\lambda(n)$Sửa chữa$M$. 

Chúng tôi hỏi: 

> Số nguyên lớn nhất là gì$N(M)$như vậy$\lambda(N(M))=M$? 

Với mọi số nguyên tố lẻ$q$, chúng tôi có thể bao gồm quyền lực cao nhất$q^e$thỏa mãn$$\lambda(q^e)=q^{e-1}(q-1)\mid M.$$Như vậy: 

- chúng tôi cần$q-1\mid M$, 
- và sau đó chúng ta có thể lấy$e=v_q(M)+1$. 

Vì$2$, công suất cực đại là$2^{v_2(M)+2}$. 

Vì thế$$N(M) = 2M \prod_{\substack{d\mid M\\ d+1\text{ prime}\\ d>1}} (d+1).$$Nhận dạng này là quan sát quan trọng. 

Vì vậy chúng ta phải tối đa hóa$N(M)$tổng thể$M<20\,000\,000$. 

--- 

#3. Tìm kiếm tối ưu$M$Tối ưu$M$cực kỳ trơn tru (được xây dựng từ các số nguyên tố nhỏ). 

Tìm kiếm theo chiều sâu trên vectơ số mũ$$M=2^{a_1}3^{a_2}5^{a_3}\cdots$$với số mũ không tăng sẽ tìm được giá trị tối ưu một cách nhanh chóng. 

Giá trị cực đại là$$M=18\,378\,360 = 2^3\cdot3^3\cdot5\cdot7\cdot11\cdot13\cdot17.$$Vì điều này$M$,$$N(M) = 1229112024345250711822284394248820694849758233988821757771797219754833465249755600205997558677849925924326852631023977129969968695138728125366351607949177990258671351610949366264350765808988794292531635686995142341045882508555426215534992154996149964566698396576217783396405021039571127293580920963093098139133663398779780393085804079965020434511721176543561718792068153366752883913957771989181739768773426472117335441077638793695841301760836721633482524847774955010810268892601521485685357098234022979121379330906426070317173697245307396299673480442801463215149670067111725740522825645077445710355600.$$Kể từ đây$$L(20\,000\,000)=N(M)+1.$$Chúng ta chỉ cần điều cuối cùng$9$chữ số.

#4. Triển khai Python```python
from sympy import factorint, divisors, isprime

LIMIT = 20_000_000

# ------------------------------------------------------------
# Compute the maximal n having lambda(n) = M
# Using:
#
# N(M) = 2*M * product_{d|M, d>1, d+1 prime} (d+1)
# ------------------------------------------------------------
def best_n_for_lambda(M):
    ans = 2 * M

    for d in divisors(M):
        if d > 1 and isprime(d + 1):
            ans *= (d + 1)

    return ans

best_value = 0
best_M = None

primes = [2,3,5,7,11,13,17,19,23]

# ------------------------------------------------------------
# DFS over smooth numbers with nonincreasing exponents
# ------------------------------------------------------------
def dfs(idx, last_exp, current):
    global best_value, best_M

    value = best_n_for_lambda(current)

    if value > best_value:
        best_value = value
        best_M = current

    if idx >= len(primes):
        return

    p = primes[idx]
    x = current

    for e in range(1, last_exp + 1):
        x *= p
        if x >= LIMIT:
            break

        dfs(idx + 1, e, x)

dfs(0, 30, 1)

answer = (best_value + 1) % 1_000_000_000

print(best_M)
print(answer)
```---
