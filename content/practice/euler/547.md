[Vấn đề dự án Euler 547](https://projecteuler.net/problem=547) 

## Giải pháp 

**Trả lời:**`11730879.0023`Cho phép$$E(R)=\frac1{\operatorname{area}(R)^2}\iint_{R\times R} \|P-Q\|\,dP\,dQ$$là khoảng cách dự kiến ​​​​giữa hai điểm ngẫu nhiên thống nhất trong một khu vực$R$. 

Đối với một tấm hình vuông rỗng, vùng này là$$L = O\setminus H,$$Ở đâu

-$O$là bên ngoài$n\times n$quảng trường,
-$H$là cái bị loại bỏ$x\times y$hình chữ nhật. 

Chúng ta phải tính toán$$S(n)=\sum_{\text{all laminae}} E(L).$$Vì$n=40$, tích phân hình học thô bạo là không thể trừ khi chúng ta rút ra được tích phân hình chữ nhật dạng đóng. 

--- 

# 1. Phân tích toán học 

## Bước 1 - Tích phân cặp hình chữ nhật 

Xác định$$I(A,B)=\iint_{A\times B}\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}\,dA\,dB.$$Sau đó$$E(R)=\frac{I(R,R)}{\operatorname{area}(R)^2}.$$Vì vậy đối với một tấm lamina$L=O\setminus H$,$$I(L,L) = I(O,O)-2I(O,H)+I(H,H).$$Vì thế mọi thứ quy giản về việc đánh giá$I$cho các hình chữ nhật thẳng hàng với trục. 

--- 

## Bước 2 - Nguyên hàm 

hãy để$$r=\sqrt{x^2+y^2}.$$Một danh tính hữu ích là$$\frac{\partial^2}{\partial x\,\partial y} \left( \frac{xyr}{3} +\frac{x^3}{6}\operatorname{asinh}\frac{y}{x} +\frac{y^3}{6}\operatorname{asinh}\frac{x}{y} \right) =r.$$Việc tích phân một lần nữa cho cả hai biến sẽ mang lại giá trị nguyên thủy bậc bốn:$$Q(x,y)= \frac{x^4y}{24}\operatorname{asinh}\frac{y}{x} +\frac{xy^4}{24}\operatorname{asinh}\frac{x}{y} -\frac{x^4r}{60} +\frac{x^2y^2r}{20} -\frac{y^4r}{60}.$$Sau đó bằng cách lặp đi lặp lại bao gồm-loại trừ, 

cho hình chữ nhật$$R_1=[a,b]\times[c,d], \qquad R_2=[e,f]\times[g,h],$$chúng tôi có được$$I(R_1,R_2) = \sum (-1)^{i+j+k+l} Q(x_i-u_j,\; y_k-v_l),$$Ở đâu$$x_i\in\{a,b\}, \quad u_j\in\{e,f\}, \quad y_k\in\{c,d\}, \quad v_l\in\{g,h\}.$$Điều này đưa ra một biểu mẫu đóng chính xác chỉ với 16 đánh giá. 

--- 

## Bước 3 — Đếm tất cả các lá mỏng 

Để cố định$n$: 

- chiều rộng lỗ$x$:$1\le x\le n-2$, 
- chiều cao lỗ$y$:$1\le y\le n-2$, 
- lệch trái$a$:$1\le a\le n-x-1$, 
- phần bù đáy$b$:$1\le b\le n-y-1$. 

Mỗi vị trí được tính riêng biệt, bao gồm cả các phép quay/phản xạ chính xác như đã nêu. 

Đối với mỗi tấm:$$E(L) = \frac{ I(O,O)-2I(O,H)+I(H,H) }{ (n^2-xy)^2 }.$$Tổng hợp tất cả các giá trị này mang lại$S(n)$.

#2. Triển khai Python```python
import math

# Fourth-order primitive
def Q(x, y):
    x = abs(x)
    y = abs(y)

    r = math.hypot(x, y)

    val = 0.0

    if x > 0:
        val += x**4 * y * math.asinh(y / x) / 24.0

    if y > 0:
        val += x * y**4 * math.asinh(x / y) / 24.0

    val += (
        -x**4 * r / 60.0
        + x**2 * y**2 * r / 20.0
        - y**4 * r / 60.0
    )

    return val

# Rectangle pair integral
# rectangle format: (x1, x2, y1, y2)
def rect_pair_integral(R1, R2):

    a, b, c, d = R1
    e, f, g, h = R2

    xs = [a, b]
    us = [e, f]
    ys = [c, d]
    vs = [g, h]

    total = 0.0

    for i, X in enumerate(xs):
        for j, U in enumerate(us):
            for k, Y in enumerate(ys):
                for l, V in enumerate(vs):

                    total += (
                        (-1) ** (i + j + k + l)
                        * Q(X - U, Y - V)
                    )

    return total

def S(n):

    outer = (0, n, 0, n)

    # Cache repeated rectangle computations
    cache = {}

    def RP(A, B):
        key = (A, B)

        if key not in cache:
            cache[key] = rect_pair_integral(A, B)

        return cache[key]

    outer_outer = RP(outer, outer)

    total = 0.0

    for x in range(1, n - 1):
        for y in range(1, n - 1):

            # self-integral of hole depends only on x,y
            HH = RP((0, x, 0, y), (0, x, 0, y))

            area = n * n - x * y

            for a in range(1, n - x):
                if a + x > n - 1:
                    continue

                for b in range(1, n - y):
                    if b + y > n - 1:
                        continue

                    hole = (a, a + x, b, b + y)

                    I = (
                        outer_outer
                        - 2 * RP(outer, hole)
                        + HH
                    )

                    total += I / (area * area)

    return total

print(round(S(3), 4))
print(round(S(4), 4))
print(round(S(40), 4))

#3. Hướng dẫn sử dụng mã 

###`Q(x,y)`Triển khai nguyên hàm cấp 4 dạng đóng dẫn xuất ở trên. 

--- 

###`rect_pair_integral`Sử dụng công thức bao gồm-loại trừ 16 góc:$$\sum (-1)^{i+j+k+l}Q(\cdots).$$Điều này đánh giá chính xác$$I(R_1,R_2).$$--- 

###`S(n)`Liệt kê mọi vị trí hình chữ nhật bên trong hợp lệ. 

Đối với mỗi tấm: 

1. tính toán$I(O,O)$, 
2. trừ$2I(O,H)$, 
3. thêm$I(H,H)$, 
4. chia cho bình phương diện tích. 

Sau đó tổng hợp tất cả các laminae.
