-$P(1)=1$-$P(9)=6$-$P(1000)=510$-$S(n)=\sum_{k=1}^n P(k)$-$S(1000)=268271$Chúng ta phải tính:$$S(10^{18}) \bmod 987654321$$--- 

# 1. Phân tích toán học 

## Bước 1: Lặp lại cho$P(n)$Sau lần chuyền từ trái sang phải đầu tiên$1,2,\dots,n$: 

- tất cả các số lẻ bị loại bỏ, 
- danh sách còn lại là$$2,4,6,\dots,2\left\lfloor \frac n2 \right\rfloor$$Chia mọi thứ cho$2$. Bài toán còn lại trở thành quá trình loại trừ tương tự nhưng bắt đầu từ hướng ngược lại. 

Nếu chúng ta biểu thị người sống sót bằng$P(n)$, thì phép tái diễn trò chơi loại trừ cổ điển là:$$P(n)=2\left(1+\left\lfloor\frac n2\right\rfloor-P\!\left(\left\lfloor\frac n2\right\rfloor\right)\right)$$với trường hợp cơ sở$$P(1)=1.$$Tương đương, đối với$n\ge1$,$$P(2n)=P(2n+1)=2(n+1-P(n)).$$Điều này ngay lập tức giải thích tại sao các cặp chẵn/lẻ liên tiếp lại có giá trị bằng nhau. 

--- 

## Bước 2: Tìm phép truy toán cho$S(n)$Định nghĩa$$A(n)=\sum_{k=1}^n P(2k).$$Sử dụng phép truy hồi:$$P(2k)=2(k+1-P(k)),$$Vì thế$$A(n) =\sum_{k=1}^n 2(k+1-P(k)).$$Vì thế$$A(n) =2\sum_{k=1}^n k + 2n -2S(n).$$Từ$$\sum_{k=1}^n k=\frac{n(n+1)}2,$$chúng tôi nhận được$$A(n)=n(n+1)+2n-2S(n) =n^2+3n-2S(n).$$--- 

## Bước 3: Thể hiện$S(2n)$Và$S(2n+1)$Bởi vì$$P(2k-1)=P(2k),$$chúng tôi có$$S(2n) =1+2\sum_{k=1}^{n-1}P(2k)+P(2n).$$Đó là,$$S(2n)=1+2A(n)-P(2n).$$Thay thế các công thức:$$A(n)=n^2+3n-2S(n),$$Và$$P(2n)=2(n+1-P(n)).$$Sau khi đơn giản hóa:$$\boxed{ S(2n)=2n^2+4n-1-2S(n)-2S(n-1) }$$Tương tự,$$S(2n+1)=S(2n)+P(2n+1).$$Từ$P(2n+1)=P(2n)$,$$S(2n+1)=1+2A(n),$$kể từ đây$$\boxed{ S(2n+1)=2n^2+6n+1-4S(n) }$$Những lần lặp lại này làm giảm đối số đi một nửa mỗi lần, do đó độ phức tạp chỉ là$O(\log n)$. 

--- 

#2. Triển khai Python```python
from functools import lru_cache

MOD = 987654321

@lru_cache(None)
def S(n):
    # Base cases
    if n <= 0:
        return 0
    if n == 1:
        return 1

    # Even case: n = 2m
    if n % 2 == 0:
        m = n // 2
        return (
            2 * m * m
            + 4 * m
            - 1
            - 2 * S(m)
            - 2 * S(m - 1)
        ) % MOD

    # Odd case: n = 2m + 1
    else:
        m = n // 2
        return (
            2 * m * m
            + 6 * m
            + 1
            - 4 * S(m)
        ) % MOD

answer = S(10**18)
print(answer)
```---
