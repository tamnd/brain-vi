##Giải pháp 

**Trả lời:**`20313839404245`Đặt tổng đặc biệt tối ưu cho kích thước$n$là$$A=\{a_1<a_2<\cdots<a_n\}.$$Chúng ta cần tập hợp tổng đặc biệt tối ưu cho$n=7$, sau đó nối các phần tử thành chuỗi được yêu cầu. 

--- 

# 1. Phân tích toán học 

một bộ$A$là một **tập hợp tổng đặc biệt** nếu với hai tập con rời rạc không trống bất kỳ$B,C\subseteq A$: 

1.$S(B)\neq S(C)$2. Nếu$|B|>|C|$, sau đó$S(B)>S(C)$Chúng tôi muốn tập hợp số tiền đặc biệt với tổng số tiền tối thiểu. 

--- 

## Thuộc tính cấu trúc chính 

Giả sử$$a_1<a_2<\cdots<a_n.$$Điều kiện (2) có thể được kiểm tra một cách hiệu quả. 

Đối với các số dương được sắp xếp, trường hợp xấu nhất vi phạm điều kiện (2) là: 

- nhỏ nhất$k+1$yếu tố 

so với 
- lớn nhất$k$các phần tử. 

Như vậy chúng ta chỉ cần:$$a_1+a_2+\cdots+a_{k+1} > a_n+a_{n-1}+\cdots+a_{n-k+1}$$cho tất cả những gì có liên quan$k$. 

Vì$n=7$, điều này trở thành:$$a_1+a_2 > a_7$$

$$a_1+a_2+a_3 > a_7+a_6$$

$$a_1+a_2+a_3+a_4 > a_7+a_6+a_5$$Những bất bình đẳng này làm giảm đáng kể việc tìm kiếm. 

--- 

## Cấu trúc gần tối ưu 

Tuyên bố vấn đề đưa ra heuristic: 

Nếu$$A=\{a_1,\dots,a_n\}$$là tối ưu thì tập hợp gần tối ưu cho kích thước$n+1$là$$B=\{b,a_1+b,\dots,a_n+b\},$$Ở đâu$b$là phần tử ở giữa của$A$. 

Sử dụng tối ưu$n=6$bộ$$\{11,18,19,20,22,25\},$$heuristic đưa ra:$$\{20,31,38,39,40,42,45\}.$$Điều này rất gần với mức tối ưu thực sự, vì vậy chúng ta chỉ cần tìm kiếm gần đó. 

--- 

## Điều kiện (1): tổng tập hợp con riêng biệt 

Đối với một bộ kích thước$7$, chỉ có$$2^7-1=127$$tập hợp con không trống. 

Chúng ta có thể tính tổng mọi tập hợp con và đảm bảo không có hai tập hợp con rời rạc nào có tổng bằng nhau. 

Cách tiếp cận bitmask tiêu chuẩn hoạt động tốt: 

- đại diện cho mỗi tập hợp con bằng một bitmask, 
- tính tổng của nó, 
- nếu hai tập hợp con có tổng bằng nhau và mặt nạ khác nhau thì loại bỏ tập hợp đó. 

--- 

## Chiến lược tìm kiếm 

Chúng tôi tìm kiếm xung quanh trung tâm heuristic:$$(20,31,38,39,40,42,45).$$Bởi vì các tập hợp tối ưu được phân cụm chặt chẽ, nên việc tìm kiếm DFS/quay ngược có giới hạn sẽ nhanh chóng tìm thấy tập hợp lệ tối thiểu. 

Điều tối ưu đã biết hóa ra là:$$\{20,31,38,39,40,42,45\}.$$Tổng của nó là$$20+31+38+39+40+42+45=255.$$Do đó, chuỗi được yêu cầu là:$$20313839404245.$$--- 

#2. Triển khai Python```python
from itertools import combinations

def satisfies_rule_two(arr):
    """
    Check:
    If |B| > |C| then S(B) > S(C)

    For sorted positive arrays, it is enough to verify:
    sum(first k+1) > sum(last k)
    """
    n = len(arr)

    for k in range(1, n // 2 + 1):
        if sum(arr[:k + 1]) <= sum(arr[-k:]):
            return False

    return True

def satisfies_rule_one(arr):
    """
    Check:
    No two disjoint non-empty subsets have equal sums.
    """

    n = len(arr)

    # map: subset_sum -> list of masks producing that sum
    sums = {}

    for mask in range(1, 1 << n):

        s = 0
        for i in range(n):
            if mask & (1 << i):
                s += arr[i]

        if s not in sums:
            sums[s] = [mask]
        else:
            # equal sum found; ensure subsets are not disjoint
            for other in sums[s]:
                if (other & mask) == 0:
                    return False

            sums[s].append(mask)

    return True

def is_special_sum_set(arr):
    return (
        satisfies_rule_two(arr)
        and satisfies_rule_one(arr)
    )

best = None
best_sum = float('inf')

# Near-optimum template from the problem statement
base = [20, 31, 38, 39, 40, 42, 45]

# Search nearby
def search(pos, current):
    global best, best_sum

    n = len(base)

    if pos == n:

        if sum(current) >= best_sum:
            return

        if is_special_sum_set(current):
            best = current[:]
            best_sum = sum(current)

        return

    # small perturbations around the heuristic set
    for delta in range(-3, 4):

        val = base[pos] + delta

        if current and val <= current[-1]:
            continue

        current.append(val)

        # early pruning using rule two
        if satisfies_rule_two(current):
            search(pos + 1, current)

        current.pop()

search(0, [])

print(best)
print("set string =", "".join(str(x) for x in best))
```---
