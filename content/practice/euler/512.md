##Giải pháp 

**Trả lời:**`50660591862310323`Cho phép$$f(n)=\left(\sum_{i=1}^{n}\varphi(n^i)\right)\bmod(n+1)$$Và$$g(n)=\sum_{i=1}^{n} f(i).$$Chúng tôi cần$g(5\times 10^8)$. 

## 1. Phân tích toán học 

### Bước 1: Đơn giản hóa$f(n)$Nhớ lại danh tính toàn bộ:$$\varphi(n^k)=n^{k-1}\varphi(n)$$với mọi số nguyên$k\ge1$. 

Như vậy$$\sum_{i=1}^{n}\varphi(n^i) = \varphi(n)\sum_{i=0}^{n-1} n^i.$$Chúng tôi chỉ quan tâm modulo$n+1$. Từ$$n\equiv -1 \pmod{n+1},$$chúng tôi nhận được$$n^i \equiv (-1)^i \pmod{n+1}.$$Kể từ đây$$\sum_{i=0}^{n-1}n^i \equiv \sum_{i=0}^{n-1}(-1)^i \pmod{n+1}.$$Bây giờ hãy phân biệt tính chẵn lẻ: 

- Nếu$n$là **chẵn**, tổng xen kẽ có số lượng bằng nhau$+1$Và$-1$, Vì thế:$$\sum_{i=0}^{n-1}(-1)^i=0.$$Như vậy$$f(n)=0.$$- Nếu như$n$là **lẻ**, tổng xen kẽ bằng$1$, Vì thế:$$f(n)\equiv \varphi(n)\pmod{n+1}.$$Vì cho$n>1$,$$0<\varphi(n)<n+1,$$dư lượng chỉ đơn giản là$$f(n)=\varphi(n).$$Cũng$f(1)=1=\varphi(1)$. 

Vì thế:$$f(n)= \begin{cases} \varphi(n), & n\text{ odd},\\[4pt] 0, & n\text{ even}. \end{cases}$$Vì thế$$g(N)=\sum_{\substack{n\le N\\ n\text{ odd}}}\varphi(n).$$--- 

### Bước 2: Chuyển sang công thức tính tổng 

Sử dụng công thức đảo ngược Möbius:$$\varphi(n) = n\sum_{d\mid n}\frac{\mu(d)}{d}.$$Từ$n$là số lẻ, mọi ước số đều là số lẻ:$$g(N) = \sum_{\substack{n\le N\\ n\text{ odd}}} n \sum_{d\mid n}\frac{\mu(d)}{d}.$$Viết$n=dm$:$$g(N) = \sum_{\substack{d\le N\\ d\text{ odd}}} \mu(d) \sum_{\substack{m\le N/d\\ m\text{ odd}}} m.$$Tổng các số nguyên lẻ đến$M$:$$1+3+\cdots+(2k-1)=k^2,$$Ở đâu$$k=\left\lfloor \frac{M+1}{2}\right\rfloor.$$Kể từ đây$$g(N) = \sum_{\substack{d\le N\\ d\text{ odd}}} \mu(d) \left( \left\lfloor \frac{\lfloor N/d\rfloor+1}{2} \right\rfloor \right)^2.$$Điều này có thể được tính toán trong$O(\sqrt N)$sử dụng nhóm ước số và hàm Möbius tóm tắt được ghi nhớ.

## 2. Triển khai Python```python
from functools import lru_cache

def compute_g(N):
    # Sieve limit for fast Möbius prefix values
    LIMIT = int(N ** (2 / 3)) + 10

    # Linear sieve for Möbius function
    mu = [0] * (LIMIT + 1)
    mu[1] = 1
    primes = []
    is_composite = [False] * (LIMIT + 1)

    for i in range(2, LIMIT + 1):
        if not is_composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > LIMIT:
                break

            is_composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break
            else:
                mu[v] = -mu[i]

    # Prefix sum of Möbius
    mobius_prefix = [0] * (LIMIT + 1)
    for i in range(1, LIMIT + 1):
        mobius_prefix[i] = mobius_prefix[i - 1] + mu[i]

    @lru_cache(None)
    def mertens(n):
        """M(n) = sum_{k<=n} mu(k)"""
        if n <= LIMIT:
            return mobius_prefix[n]

        result = 1
        left = 2

        while left <= n:
            q = n // left
            right = n // q

            result -= (right - left + 1) * mertens(q)
            left = right + 1

        return result

    @lru_cache(None)
    def odd_mertens(n):
        """Sum of mu(k) over odd k <= n"""
        total = 0

        while n > 0:
            total += mertens(n)
            n //= 2

        return total

    answer = 0
    left = 1

    while left <= N:
        q = N // left
        right = N // q

        # Number of odd integers <= q
        k = (q + 1) // 2

        mobius_sum = odd_mertens(right) - odd_mertens(left - 1)
        answer += k * k * mobius_sum

        left = right + 1

    return answer

# Verification
print(compute_g(100))  # 2007

# Final result
print(compute_g(5 * 10**8))

## 3. Hướng dẫn sử dụng mã 

###Sàng Mobius 

Chúng tôi tính toán$\mu(n)$lên đến khoảng$N^{2/3}$sử dụng sàng tuyến tính. 

Điều này cho phép truy cập nhanh vào:$$M(n)=\sum_{k\le n}\mu(k)$$cho nhỏ hơn$n$. 

###`mertens(n)`Sử dụng phép lặp chia để trị cổ điển:$$M(n) = 1 - \sum_{l=2}^{n} (r-l+1)M\!\left(\left\lfloor \frac{n}{l}\right\rfloor\right)$$nhóm các phạm vi thương số bằng nhau. 

###`odd_mertens(n)`Chúng ta chỉ cần lẻ$d$. Quan sát:$$M(n)=O(n)-O(n/2),$$Ở đâu$O(n)$là tổng Mobius lẻ. 

Vì thế:$$O(n)=M(n)+O(n/2).$$Điều này trở thành:$$O(n)=M(n)+M(n/2)+M(n/4)+\cdots.$$### Tổng kết cuối cùng 

Chúng tôi nhóm các khoảng thời gian trong đó$$\left\lfloor \frac{N}{d}\right\rfloor$$là không đổi, giảm độ phức tạp xuống gần như$O(\sqrt N)$. 

### Xác minh 

Mã tái tạo kiểm tra đã cho:$$g(100)=2007.$$Vì vậy đạo hàm là nhất quán.
