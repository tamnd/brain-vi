[Vấn đề dự án Euler 813](https://projecteuler.net/problem=813) 

##Giải pháp 

**Trả lời:**`14063639`Cho phép$$a \otimes b$$biểu thị sản phẩm XOR. 

Quan sát quan trọng là tích XOR chính xác là phép nhân của đa thức nhị phân trên trường$\mathbb F_2$. 

--- 

# 1. Phân tích toán học 

Viết số nguyên dưới dạng nhị phân:$$n=\sum n_i2^i,\qquad n_i\in\{0,1\}$$và liên kết với nó là đa thức$$f_n(x)=\sum n_i x^i$$qua$\mathbb F_2$. 
Phép nhân dài thông thường trong cơ số$2$, với XOR thay thế phép cộng, chính xác là modulo nhân đa thức$2$. Vì thế:$$f_{a\otimes b}(x)=f_a(x)f_b(x).$$--- 

## Bước 1: Đa thức tương ứng với$11$

$$11_{10}=1011_2$$Vì thế$$f(x)=x^3+x+1.$$Như vậy$$P(n)=11^{\otimes n}$$tương ứng với$$f(x)^n.$$--- 

#2. Khai thác cấu trúc số mũ 

Chúng tôi cần$$P(8^{12}\cdot 12^8).$$Thừa số mũ:$$8^{12}\cdot 12^8 =(2^3)^{12}(2^2\cdot 3)^8 =2^{36} \cdot 2^{16}\cdot 3^8 =2^{52}3^8.$$Kể từ đây$$P(8^{12}12^8) =f(x)^{2^{52}3^8}.$$--- 

## Bước 2: Bản đồ Frobenius trong$\mathbb F_2$Trong đặc điểm$2$,$$(a+b)^2=a^2+b^2.$$Do đó với mọi đa thức$g(x)$,$$g(x)^{2^k}=g(x^{2^k}).$$Vì thế:$$f(x)^{2^{52}3^8} = \left(f(x)^{3^8}\right)^{2^{52}} = f(x^{2^{52}})^{3^8}.$$Cho phép$$f(x)^{3^8}=\sum_i c_i x^i, \qquad c_i\in\{0,1\}.$$Sau đó$$f(x)^{2^{52}3^8} = \sum_i c_i x^{i2^{52}}.$$Cuối cùng, chuyển đổi trở lại số nguyên có nghĩa là đánh giá tại$x=2$:$$P(8^{12}12^8) = \sum_i c_i 2^{i2^{52}}.$$Modulo$M=10^9+7$, định nghĩa$$r=2^{2^{52}} \pmod M.$$Sau đó$$P(8^{12}12^8)\equiv \sum_i c_i r^i \pmod M.$$Vì vậy, nhiệm vụ giảm xuống: 

1. Tính toán$f(x)^{6561}$qua$\mathbb F_2$, 
2. Đánh giá nó ở$r$. 

--- 

#3. Triển khai Python```python
MOD = 10**9 + 7

# Polynomial for 11 = 1011_2 = x^3 + x + 1
# Bit i = coefficient of x^i
f = (1 << 0) | (1 << 1) | (1 << 3)

# XOR-polynomial multiplication over GF(2)
def mul(a, b):
    res = 0
    shift = 0

    while b:
        if b & 1:
            res ^= (a << shift)
        shift += 1
        b >>= 1

    return res

# Fast exponentiation of polynomials over GF(2)
def poly_pow(a, n):
    res = 1

    while n:
        if n & 1:
            res = mul(res, a)

        a = mul(a, a)
        n >>= 1

    return res

# Compute f(x)^(3^8)
g = poly_pow(f, 3**8)

# r = 2^(2^52) mod MOD
r = pow(2, 2**52, MOD)

# Evaluate polynomial g at r modulo MOD
ans = 0
power = 1

while g:
    if g & 1:
        ans = (ans + power) % MOD

    power = (power * r) % MOD
    g >>= 1

print(ans)
```--- 

#4. Hướng dẫn code 

## Mã hóa đa thức```python
f = (1 << 0) | (1 << 1) | (1 << 3)
```mã hóa$$x^3+x+1.$$Mặt nạ bit số nguyên lưu trữ các hệ số đa thức. 

--- 

## Phép nhân```python
res ^= (a << shift)
```thực hiện phép nhân đa thức$\mathbb F_2$: 

- sự dịch chuyển tương ứng với việc nhân với$x^{\text{shift}}$, 
- XOR tương ứng với modulo phép cộng$2$. 

--- 

## lũy thừa```python
g = poly_pow(f, 3**8)
```tính toán$$(x^3+x+1)^{6561}.$$--- 

## sự thay thế Frobenius 

Thay vì xử lý trực tiếp số mũ$2^{52}3^8$, chúng tôi sử dụng$$g(x^{2^{52}})$$trở thành đánh giá tại$$r=2^{2^{52}} \pmod{10^9+7}.$$--- 

#5. Xác minh ví dụ nhỏ 

cho$n=2$:$$P(2)=11\otimes 11.$$Đa thức:$$(x^3+x+1)^2=x^6+x^2+1.$$Đánh giá tại$x=2$:$$2^6+2^2+1=64+4+1=69,$$phù hợp với tuyên bố. 

--- 

# 6. Xác minh cuối cùng 

- Mức độ$f^{6561}$là$3\cdot6561=19683$, hoàn toàn có thể quản lý được. 
- Chỉ sử dụng số học XOR, khớp chính xác với định nghĩa. 
- Đẳng thức Frobenius hợp lệ vì các hệ số đều có đặc tính$2$.
