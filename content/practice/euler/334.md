[Vấn đề dự án Euler 334](https://projecteuler.net/problem=334) 

## Giải pháp 

**Trả lời:**`150320021261690835`Hãy để các bát được lập chỉ mục bằng số nguyên và để$a_i$biểu thị số hạt đậu trong bát$i$. 

Chúng tôi được phép di chuyển$$(\ldots,a_{i-1},a_i,a_{i+1},\ldots) \to (\ldots,a_{i-1}+1,a_i-2,a_{i+1}+1,\ldots)$$bất cứ khi nào$a_i\ge 2$. 

Điều quan trọng là tránh mô phỏng hàng tỷ bước di chuyển. 

## 1. Phân tích toán học 

### Bước 1: Xác định bất biến 

Mỗi bước di chuyển sẽ bảo toàn: 

#### Tổng số hạt$$N=\sum_i a_i$$vì chúng ta bỏ đi 2 hạt đậu và thêm 2 hạt đậu vào. 

#### Mômen thứ nhất (tâm khối)$$M=\sum_i i\,a_i$$từ$$(i-1)+(i+1)-2i=0.$$Như vậy cả hai$N$Và$M$là bất biến. 

--- 

### Bước 2: Tìm đại lượng thay đổi có thể dự đoán được 

Xét khoảnh khắc bậc hai$$Q=\sum_i i^2 a_i.$$Một bước di chuyển tại vị trí$i$thay đổi$Q$qua$$(i-1)^2+(i+1)^2-2i^2.$$Mở rộng:$$(i^2-2i+1)+(i^2+2i+1)-2i^2=2.$$Vì vậy ** mỗi bước di chuyển đều tăng$Q$chính xác là 2**. 

Kể từ đây:$$\boxed{ \text{moves} = \frac{Q_{\text{final}}-Q_{\text{initial}}}{2} }$$Vì vậy chúng ta chỉ cần cấu hình ổn định cuối cùng. 

--- 

### Bước 3: Đặc trưng trạng thái ổn định cuối cùng 

Trạng thái ổn định chỉ có 0 hoặc 1 hạt đậu mỗi bát. 

Trong số tất cả các trạng thái ổn định có cố định$N$Và$M$, cái có thể tiếp cận được là sự sắp xếp độc đáo giảm thiểu$$\sum x_i^2$$tùy thuộc vào: 

-$N$các vị trí chiếm giữ, 
- số nguyên phân biệt, 
- tổng số tiền$M$. 

Bởi vì hàm bình phương là hàm lồi nên các bát được sử dụng phải **càng liên tiếp càng tốt**. 

Vì vậy, các vị trí cuối cùng là:$$a,\ a+1,\ \ldots,\ a+N-1$$ngoại trừ cái lớn nhất$r$các vị trí được dịch chuyển bởi$+1$. 

Cho phép$$T=\frac{N(N-1)}{2}.$$Sau đó viết$$M-T = aN + r, \qquad 0\le r < N.$$Các vị trí chiếm giữ cuối cùng là:$$a,\ a+1,\ldots,a+N-r-1,$$Và$$a+N-r+1,\ldots,a+N.$$Điều này cho phép chúng ta tính toán$Q_{\text{final}}$trực tiếp. 

--- 

### Bước 4: Tạo dãy 

Chúng tôi được cung cấp:$$t_0=123456$$Và$$t_i= \begin{cases} t_{i-1}/2 & \text{if even}\\ \lfloor t_{i-1}/2\rfloor \oplus 926252 & \text{if odd} \end{cases}$$với$$b_i=(t_i\bmod 2^{11})+1.$$Các điều khoản đầu tiên là:$$b_1=289,\qquad b_2=145$$phù hợp với tuyên bố. 

Đối với ví dụ chỉ có hai cái bát, công thức cho chính xác$$3419100$$chuyển, kiểm tra tính đúng đắn.

## 2. Triển khai Python```python
def generate_b(n=1500):
    t = 123456
    b = []

    for _ in range(n):
        if t % 2 == 0:
            t //= 2
        else:
            t = (t // 2) ^ 926252

        b.append((t % (2 ** 11)) + 1)

    return b

def sum_squares_arithmetic(start, length):
    """
    Sum of:
        start^2 + (start+1)^2 + ... + (start+length-1)^2
    """
    if length <= 0:
        return 0

    n = length
    return (
        n * start * start
        + 2 * start * (n * (n - 1) // 2)
        + (n - 1) * n * (2 * n - 1) // 6
    )

# Generate the 1500 bowls
b = generate_b(1500)

# Invariants
N = sum(b)
M = sum(i * x for i, x in enumerate(b))

# Initial quadratic moment
Q_initial = sum(i * i * x for i, x in enumerate(b))

# Determine final stable configuration
T = N * (N - 1) // 2
a = (M - T) // N
r = (M - T) % N

# Final occupied bowls:
# a, a+1, ..., a+N-r-1
# a+N-r+1, ..., a+N
left_count = N - r

Q_final = (
    sum_squares_arithmetic(a, left_count)
    + sum_squares_arithmetic(a + left_count + 1, r)
)

# Each move increases Q by exactly 2
moves = (Q_final - Q_initial) // 2

print(moves)
```--- 

## 3. Hướng dẫn sử dụng mã 

### Tạo chuỗi 

Chúng tôi tính toán$t_i$đệ quy và chuyển đổi thành$$b_i=(t_i \bmod 2048)+1.$$Điều này tạo ra:$$b_1=289,\quad b_2=145,$$phù hợp với phát biểu vấn đề. 

### Tính toán các bất biến 

Chúng tôi tính toán: 

- tổng số đậu:$$N=\sum b_i$$- giây phút đầu tiên:$$M=\sum i\,b_i$$- mô men bậc hai ban đầu:$$Q_{\text{initial}}$$### Xây dựng cấu hình cuối cùng 

Chúng tôi giải quyết:$$M-T=aN+r,$$Ở đâu$$T=\frac{N(N-1)}{2}.$$Điều này xác định sự sắp xếp ổn định duy nhất. 

### Tính số lần di chuyển 

Vì mỗi bước di chuyển đều tăng$Q$đúng bằng 2:$$\text{moves} = \frac{Q_{\text{final}}-Q_{\text{initial}}}{2}.$$Đối với mẫu có$289,145$, điều này tái tạo:$$3419100.$$---
