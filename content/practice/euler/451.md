[Vấn đề dự án Euler 451](https://projecteuler.net/problem=451) 

## Giải pháp 

**Trả lời:**`153651073760956`Chúng tôi muốn tất cả các số nguyên$m$như vậy$$m^2 \equiv 1 \pmod n,$$bởi vì một phần tử là mô-đun nghịch đảo iff của chính nó$m^{-1}\equiv m\pmod n$. 

Vấn đề xác định$I(n)$lớn nhất như vậy$m<n-1$. 

--- 

# 1. Phân tích toán học 

Chúng ta phải giải quyết$$x^2 \equiv 1 \pmod n.$$Tương đương,$$(x-1)(x+1)\equiv 0 \pmod n.$$Cấu trúc khóa xuất phát từ Định lý phần dư Trung Quốc. 

--- 

## Bước 1: Giải modulo lũy thừa nguyên tố 

Đối với một quyền lực nguyên tố lẻ$p^k$:$$x^2\equiv 1 \pmod{p^k}$$có đúng hai nghiệm:$$x\equiv \pm 1 \pmod{p^k}.$$Đối với quyền hạn của$2$: 

- modulo$2$: một giải pháp 
- modulo$4$: hai giải pháp 
- modulo$2^k$vì$k\ge 3$: bốn giải pháp$$x\equiv \pm1,\quad \pm(1+2^{k-1}) \pmod{2^k}.$$--- 

## Bước 2: Phân tách CRT 

Nếu$$n=\prod p_i^{a_i},$$sau đó mọi giải pháp modulo$n$thu được bằng cách chọn độc lập một giải pháp modulo cho mỗi lũy thừa chính và kết hợp chúng với CRT. 

Do đó, các giải pháp không tầm thường phát sinh bằng cách gán một số thừa số lũy thừa nguyên tố cho phần dư$+1$và những thứ khác dư lượng$-1$. 

--- 

## Bước 3: Đặc trưng cho lời giải lớn nhất 

Giả sử$$n=ab,\qquad \gcd(a,b)=1.$$Lấy hệ thống CRT$$x\equiv -1 \pmod a,\qquad x\equiv 1 \pmod b.$$CRT đưa ra một giải pháp độc đáo modulo$n$. 

Mọi sự thoái hóa không tầm thường đều xuất phát từ sự chia rẽ như vậy. 

Nếu như$x$là một giải pháp, thì cũng vậy$n-x$. 

Do đó giải pháp lớn nhất dưới đây$n-1$được lấy từ giải pháp không tầm thường _smallest_. 

Vì vậy hãy xác định$$s(n)=\min\{x>1 : x^2\equiv1\pmod n\},$$sau đó$$I(n)=n-s(n).$$--- 

## Bước 4: Tính toán hiệu quả 

Tìm kiếm trực tiếp là không thể lên đến$2\times10^7$. 

Thay vào đó: 

1. Sàng các thừa số nguyên tố nhỏ nhất. 
2. Phân tích từng yếu tố$n$. 
3. Tạo ra tất cả các phép biến đổi CRT từ quá trình phân tách công suất nguyên tố. 
4. Giữ giải pháp nhỏ nhất, không tầm thường$s(n)$. 
5. Thêm$n-s(n)$. 

Số lượng các phép biến đổi rất nhỏ vì số lượng các thừa số nguyên tố phân biệt rất nhỏ. 

Tổng thời gian chạy có thể dễ dàng thực hiện được trong Python/PyPy được tối ưu hóa.

#2. Triển khai Python```python
from math import prod

LIMIT = 20_000_000

# ------------------------------------------------------------
# Smallest prime factor sieve
# ------------------------------------------------------------

spf = list(range(LIMIT + 1))

for i in range(2, int(LIMIT ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, LIMIT + 1, step):
            if spf[j] == j:
                spf[j] = i

# ------------------------------------------------------------
# Extended Euclid modular inverse
# ------------------------------------------------------------

def inv_mod(a, m):
    x0, x1 = 1, 0
    b = m
    while b:
        q = a // b
        a, b = b, a % b
        x0, x1 = x1, x0 - q * x1
    return x0 % m

# ------------------------------------------------------------
# CRT merge:
# x ≡ r1 (mod m1)
# x ≡ r2 (mod m2)
# gcd(m1,m2)=1
# ------------------------------------------------------------

def crt(r1, m1, r2, m2):
    t = ((r2 - r1) * inv_mod(m1, m2)) % m2
    return r1 + m1 * t

# ------------------------------------------------------------
# Generate prime powers
# ------------------------------------------------------------

def factorize(n):
    out = []
    while n > 1:
        p = spf[n]
        e = 0
        pp = 1
        while n % p == 0:
            n //= p
            e += 1
            pp *= p
        out.append((p, e, pp))
    return out

# ------------------------------------------------------------
# Solutions modulo p^k
# ------------------------------------------------------------

def local_roots(p, e, pe):
    if p == 2:
        if e == 1:
            return [1]
        elif e == 2:
            return [1, 3]
        else:
            h = 1 << (e - 1)
            return [1, pe - 1, 1 + h, h - 1]
    else:
        return [1, pe - 1]

# ------------------------------------------------------------
# Main
# ------------------------------------------------------------

answer = 0

for n in range(3, LIMIT + 1):

    fac = factorize(n)

    roots = [(0, 1)]

    # build all CRT combinations
    for p, e, pe in fac:
        local = local_roots(p, e, pe)

        new_roots = []

        for r, mod in roots:
            for t in local:
                nr = crt(r, mod, t, pe)
                new_roots.append((nr, mod * pe))

        roots = new_roots

    best = 1

    for r, _ in roots:
        r %= n
        if r != n - 1:
            best = max(best, r)

    answer += best

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

###Sàng lọc SPF 

Chúng tôi tính toán trước hệ số nguyên tố nhỏ nhất của mọi số lên đến$2\times10^7$. 

Điều này cho phép tính hệ số trong thời gian khấu hao gần như không đổi. 

--- 

###`factorize(n)`sản xuất$$n=\prod p_i^{e_i}$$cùng với các quyền lực chính thực tế$p_i^{e_i}$. 

--- 

###`local_roots`Trả về tất cả giải pháp cho$$x^2\equiv1\pmod{p^e}.$$Đối với số nguyên tố lẻ: chỉ$\pm1$. 

Đối với lũy thừa của hai ($e\ge3$):$$1,\ -1,\ 1+2^{e-1},\ -1+2^{e-1}.$$--- 

###Kết hợp CRT 

Chúng tôi kết hợp đệ quy các giải pháp cục bộ thành các giải pháp toàn cầu theo modulo$n$. 

Bởi vì số lượng các thừa số nguyên tố phân biệt rất nhỏ nên tổng số nghiệm cũng rất nhỏ. 

--- 

### Đang trích xuất$I(n)$Trong số tất cả các rễ,$n-1$luôn luôn có mặt (giải pháp tầm thường$-1$). 

Chúng ta chọn nghiệm lớn nhất nhỏ hơn rất nhiều so với$n-1$. 

--- 

#4. Xác minh trên các ví dụ nhỏ 

##$n=15$Rễ là$$1,4,11,14.$$Lớn nhất bên dưới$14$là$$I(15)=11.$$Chính xác. 

--- 

##$n=100$Rễ là$$1, 49, 51, 99.$$Lớn nhất bên dưới$99$là$$I(100)=51.$$Chính xác. 

--- 

##$n=7$Chỉ có rễ:$$1,6.$$Từ$6=n-1$bị loại trừ:$$I(7)=1.$$Chính xác.

#5. Xác minh cuối cùng 

Tổng số đó theo thứ tự$$\sum_{n\le 2\times10^7} O(n),$$vì vậy một kết quả xung quanh$10^{14}$–$10^{15}$là hợp lý. 

Việc tính toán hoàn toàn mang tính xác định và dựa trên sự phân loại đầy đủ các phép biến đổi theo modulo$n$.
