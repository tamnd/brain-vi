[Vấn đề dự án Euler 684](https://projecteuler.net/problem=684) 

## Giải pháp 

**Trả lời:**`922058210`Cho phép$s(n)$là số nguyên dương nhỏ nhất có tổng các chữ số là$n$. 

Ví dụ:

-$s(1)=1$-$s(10)=19$-$s(20)=299$Chúng tôi xác định$$S(k)=\sum_{n=1}^k s(n).$$Chúng ta phải tính toán$$\sum_{i=2}^{90} S(f_i) \pmod{1\,000\,000\,007},$$Ở đâu$f_i$là các số Fibonacci. 

--- 

# 1. Phân tích toán học 

## Bước 1: Công thức tính$s(n)$Để tạo số nhỏ nhất có tổng các chữ số$n$, chúng tôi muốn: 

- càng ít chữ số càng tốt, 
- chữ số lớn hơn được đẩy sang bên phải. 

Viết$$n = 9q + r,\qquad 0 \le r \le 8.$$Khi đó số tối ưu là: 

- một chữ số đứng đầu$r$(nếu như$r>0$), 
- theo sau là$q$chữ số bằng$9$. 

Ví dụ: 

-$10 = 9\cdot1+1 \Rightarrow s(10)=19$-$20 = 9\cdot2+2 \Rightarrow s(20)=299$Kể từ đây$$s(n)=r\cdot 10^q + (10^q-1).$$Vì thế:$$\boxed{s(n)=(r+1)10^q-1}$$với$n=9q+r$. 

--- 

# Bước 2: Suy ra công thức tính$S(k)$Cho phép$$k=9q+r,\qquad 0\le r\le 8.$$Chúng tôi tính tổng các khối hoàn chỉnh gồm 9 số hạng. 

Đối với một cố định$a\ge0$,$$s(9a+t)=(t+1)10^a-1,\qquad 1\le t\le8,$$Và$$s(9a+9)=10^{a+1}-1.$$Vì thế:$$\sum_{t=1}^{9} s(9a+t) = \sum_{t=1}^{8}\big((t+1)10^a-1\big) + (10^{a+1}-1).$$Tính toán:$$\sum_{t=1}^{8}(t+1)=44,$$Vì thế$$=44\cdot10^a-8+10^{a+1}-1 =54\cdot10^a-9.$$Do đó mỗi khối đầy đủ đóng góp$$54\cdot10^a-9.$$Tổng hợp$a=0,\dots,q-1$:$$\sum_{a=0}^{q-1}(54\cdot10^a-9) = 54\frac{10^q-1}{9}-9q.$$Do đó đóng góp toàn khối là$$6(10^q-1)-9q.$$Bây giờ thêm phần còn lại$r$điều khoản:$$\sum_{t=1}^{r}\big((t+1)10^q-1\big).$$Từ$$\sum_{t=1}^{r}(t+1)=\frac{r(r+3)}2,$$điều này trở thành$$\frac{r(r+3)}2\,10^q-r.$$Kết hợp:$$S(k) = 6(10^q-1)-9q + \frac{r(r+3)}2\,10^q-r.$$Vì thế$$\boxed{ S(k)=\left(\frac{r(r+3)}2+6\right)10^q-9q-r-6 }$$Ở đâu$k=9q+r$.

#2. Triển khai Python```python
MOD = 1_000_000_007

def S(k):
    """
    Compute S(k) modulo MOD using the closed formula.
    """
    q, r = divmod(k, 9)

    # Closed form:
    # S(k) = ((r(r+3))/2 + 6) * 10^q - 9q - r - 6
    value = (
        ((r * (r + 3)) // 2 + 6) * pow(10, q, MOD)
        - 9 * q
        - r
        - 6
    )

    return value % MOD

# Fibonacci iteration
f0, f1 = 0, 1

answer = 0

for _ in range(2, 91):
    f0, f1 = f1, f0 + f1
    answer = (answer + S(f1)) % MOD

print(answer)
```---

Công thức cho:$$S(20) = \left(\frac{2(5)}2+6\right)10^2 - 18 -2 -6$$

$$=(5+6)\cdot100 -26$$

$$=1100-26 =1074.$$Chính xác.
