##Giải pháp 

**Trả lời:**`271197444`Cho phép

-$A(n)$= số lượng hình tam giác đơn vị có độ dày chính xác là một lớp, 
-$B(n)$= số lượng hình tam giác đơn vị có độ dày chính xác là ba lớp, 
-$G(n)=\gcd(A(n),B(n))$. 

Chúng tôi được yêu cầu$$\sum_{n=3}^{10^7} G(n).$$--- 

# 1. Phân tích toán học 

Bước quan trọng là rút ra các biểu mẫu đóng cho$A(n)$Và$B(n)$. 

Bằng cách phân tích hoạt động lớp phủ đệ quy phát triển như thế nào từ thứ tự$n-1$đặt hàng$n$, người ta thu được các phép tái phát tuyến tính$$A(n)=4A(n-1)+2\cdot 3^{n-2},$$

$$B(n)=4B(n-1)+24(n-2)4^{n-3}-6\cdot 3^{n-2},$$với những giá trị ban đầu đến từ những bông tuyết nhỏ. 

Việc giải các phép truy toán này sẽ đưa ra các công thức rõ ràng$$A(n)=3\cdot 4^{n-1}-2\cdot 3^{n-1},$$Và$$B(n)=18(n-2)4^{n-2}+(4n+26)3^{n-1}-138\cdot 4^{n-2}.$$Những điều này đơn giản hóa thành$$B(n)= (18n-138)4^{n-2} + (4n+26)3^{n-1}.$$Bây giờ hãy tính gcd. 

Nhân tố$A(n)$:$$A(n)=3\left(4^{n-1}-2\cdot 3^{n-2}\right).$$Sau khi loại bỏ đại số giữa$A(n)$Và$B(n)$, người ta tìm thấy$$G(n) = 6\cdot \gcd\!\left( 2\cdot 4^{n-2}-3^{n-2}, \, 7n+3 \right).$$Đó là sự đơn giản hóa quan trọng.

## Đơn giản hóa mô-đun hơn nữa 

hãy để$$m=7n+3.$$Nếu như$3\nmid n$, sau đó$\gcd(3,m)=1$, Vì thế$3^{n-2}$là modulo khả nghịch$m$. 

Định nghĩa$$b \equiv 4\cdot 3^{-1} \pmod m.$$Sau đó$$2\cdot 4^{n-2}-3^{n-2} \equiv 3^{n-2}\left(2b^{n-2}-1\right) \pmod m.$$Từ$3^{n-2}$là modulo khả nghịch$m$,$$\gcd\!\left(2\cdot 4^{n-2}-3^{n-2},m\right) = \gcd\!\left(2b^{n-2}-1,m\right).$$Vì vậy, mỗi số hạng có thể được tính chỉ bằng cách sử dụng lũy ​​thừa mô-đun. 

Sự phức tạp về cơ bản là$$O\!\left(N\log N\right),$$dễ dàng đủ nhanh cho$N=10^7$.

#2. Triển khai Python```python
from math import gcd

def A(n):
    return 3 * pow(4, n - 1) - 2 * pow(3, n - 1)

def B(n):
    p4 = pow(4, n - 2)
    p3 = pow(3, n - 1)
    return (18 * n - 138) * p4 + (4 * n + 26) * p3

def G(n):
    m = 7 * n + 3

    # If gcd(3, m) = 1, cancel 3^(n-2) modulo m
    if n % 3 != 0:

        # modular inverse of 3 modulo m
        if m % 3 == 1:
            inv3 = (2 * m + 1) // 3
        else:
            inv3 = (m + 1) // 3

        b = (4 * inv3) % m

        t = pow(b, n - 2, m)

        return 6 * gcd((2 * t - 1) % m, m)

    # Otherwise compute directly
    x = (2 * pow(4, n - 2, m) - pow(3, n - 2, m)) % m

    return 6 * gcd(x, m)

def solve(N):
    total = 0

    for n in range(3, N + 1):
        total += G(n)

    return total

# Verification against the statement
assert A(3) == 30
assert B(3) == 6
assert G(3) == 6

assert A(11) == 3027630
assert B(11) == 19862070
assert G(11) == 30

assert G(500) == 186
assert solve(500) == 5124

print(solve(10_000_000))
```---
