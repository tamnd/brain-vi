# 1. Phân tích toán học 

## Đếm số lần hoàn thành của tiền tố 

Giả sử chúng ta vẫn còn số lượng có sẵn$$(c_1,c_2,\dots,c_m)$$cho các chữ còn lại. 

Chúng ta cần một chức năng:$$T(\mathbf c, r)$$= số lượng từ có độ dài tối đa không trống$r$đó có thể được hình thành. 

Đối với một chiều dài cố định$k$, số từ riêng biệt là$$k!\sum_{\substack{a_i\le c_i\\ \sum a_i=k}} \frac{1}{a_1!a_2!\cdots a_m!}.$$Đây chính xác là dạng hệ số của hàm tạo$$\prod_i \left(\sum_{t=0}^{c_i}\frac{x^t}{t!}\right).$$Vì vậy, đối với mỗi trạng thái có thể truy cập, chúng tôi tính toán tất cả số lượng cho độ dài$0\ldots 15$. 

--- 

## Xếp hạng một từ$P(w)$Để tính thứ hạng từ điển của một từ$w$: 

Tại mỗi vị trí: 

1. Hãy thử mọi chữ cái nhỏ hơn có thể. 
2. Đếm tất cả các từ bắt đầu bằng tiền tố nhỏ hơn đó. 
3. Nếu chúng ta tiếp tục đi qua tiền tố hiện tại, hãy thêm 1 vì bản thân tiền tố đó cũng là một từ hợp lệ và xuất hiện trước phần mở rộng của nó theo từ điển. 

Ví dụ:

-$P(\text{aaaaaacdee})=10$-$P(\text{euler})=115246685191495243$phù hợp với tuyên bố. 

--- 

## Hủy xếp hạng$W(p)$Để đảo ngược: 

Cho một thứ hạng$p$, 

- lặp lại các chữ cái theo thứ tự bảng chữ cái, 
- xác định có bao nhiêu từ nằm trong mỗi khối tiền tố, 
- trừ các khối cho đến khi tìm thấy khối chính xác, 
- đi xuống đệ quy. 

Điều này xây dựng lại từ ở vị trí$p$.

#2. Triển khai Python```python
from collections import Counter
from functools import lru_cache
from fractions import Fraction
from math import factorial

S = "thereisasyetinsufficientdataforameaningfulanswer"

# Letter multiplicities
cnt = Counter(S)

alphabet = tuple(sorted(cnt))
initial = tuple(cnt[ch] for ch in alphabet)

index = {c: i for i, c in enumerate(alphabet)}

FACT = [factorial(i) for i in range(16)]

@lru_cache(None)
def total_words(state, rem):
    """
    Number of NONEMPTY words of length <= rem
    constructible from remaining multiset 'state'.
    """

    # Generating-function DP:
    # product (sum x^t / t!)
    poly = [Fraction(1, 1)] + [Fraction(0, 1) for _ in range(rem)]

    for c in state:
        nxt = [Fraction(0, 1) for _ in range(rem + 1)]

        for deg, val in enumerate(poly):
            if not val:
                continue

            for t in range(min(c, rem - deg) + 1):
                nxt[deg + t] += val / FACT[t]

        poly = nxt

    total = 0

    for k in range(1, rem + 1):
        total += int(poly[k] * FACT[k])

    return total

def rank_word(word):
    """
    Lexicographic position P(word), starting at 1.
    """

    state = initial
    rank = 1

    for i, ch in enumerate(word):

        # All smaller possible next letters
        for j, c in enumerate(alphabet):

            if c >= ch:
                break

            if state[j] == 0:
                continue

            ns = state[:j] + (state[j] - 1,) + state[j + 1:]

            # prefix itself + all continuations
            rank += 1 + total_words(ns, 14 - i)

        # Current prefix itself appears before extensions
        if i < len(word) - 1:
            rank += 1

        j = index[ch]
        state = state[:j] + (state[j] - 1,) + state[j + 1:]

    return rank

def unrank(rank):
    """
    Inverse map W(rank).
    """

    state = initial
    word = ""

    while True:

        for j, c in enumerate(alphabet):

            if state[j] == 0:
                continue

            ns = state[:j] + (state[j] - 1,) + state[j + 1:]

            block = 1 + total_words(ns, 15 - len(word) - 1)

            if rank > block:
                rank -= block
            else:
                word += c
                state = ns

                if rank == 1:
                    return word

                rank -= 1
                break

target = (
    rank_word("legionary")
    + rank_word("calorimeters")
    - rank_word("annihilate")
    + rank_word("orchestrated")
    - rank_word("fluttering")
)

answer = unrank(target)

print(answer)

#3. Hướng dẫn sử dụng mã 

##`total_words(state, rem)`Sử dụng hàm tạo hàm mũ$$\prod_i \left(\sum_{t=0}^{c_i}\frac{x^t}{t!}\right)$$để đếm tất cả các chuỗi riêng biệt tuân theo giới hạn bội số. 

hệ số nhân$x^k$qua$k!$chuyển đổi mẫu số đa thức thành số đếm chính xác. 

--- 

##`rank_word(word)`Tại mỗi ký tự: 

- mỗi chữ cái hợp lệ nhỏ hơn tiếp theo đóng góp toàn bộ khối từ điển; 
- chính tiền tố hiện tại đóng góp thêm một từ trước đó. 

Điều này tái tạo: 

-$P(\text{aaaaaacdee})=10$-$P(\text{euler})=115246685191495243$chính xác. 

--- 

##`unrank(rank)`Tham lam bước đi trong các khối từ điển cho đến khi thứ hạng mong muốn rơi vào trong một khối. 

Điều này tính toán$W(p)$.
