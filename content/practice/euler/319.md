[Vấn đề dự án Euler 319](https://projecteuler.net/problem=319) 

## Giải pháp 

**Trả lời:**`268457129`Cho phép$$x_1,x_2,\dots,x_n$$thỏa mãn

-$x_1=2$, 
-$x_{i-1}<x_i$, 
- và cho tất cả$i,j$,$$x_i^j<(x_j+1)^i.$$Chúng tôi tìm kiếm$t(n)$, số lượng các chuỗi như vậy, cho$n=10^{10}$, modulo$10^9$. 

## 1. Phân tích toán học 

Nhận xét quan trọng là điều kiện$$x_i^j < (x_j+1)^i$$có thể được viết lại như$$x_i^{1/i} < (x_j+1)^{1/j}.$$Như vậy mọi khoảng$$I_i=\left(x_i^{1/i},\,(x_i+1)^{1/i}\right)$$phải có giao điểm khác trống. 

Do đó tồn tại số thực$\lambda\in(2,3)$sao cho với mọi$i$,$$x_i < \lambda^i < x_i+1.$$Vì thế$$x_i=\lfloor \lambda^i\rfloor.$$Vì vậy, mỗi chuỗi hợp lệ tương ứng duy nhất với một khoảng nào đó của$\lambda\in(2,3)$và thứ tự chỉ thay đổi khi$\lambda$vượt qua một ranh giới$$\lambda = k^{1/i}, \qquad 2^i \le k < 3^i.$$Như vậy:$$t(n) = \#\left\{ k^{1/i} : 1\le i\le n,\, 2^i\le k<3^i \right\}.$$(Để ý$\lambda=2$chính nó được bao gồm thông qua$k=2^i$.) 

--- 

### Tính theo chuẩn mực 

Xác định **mẫu số tối thiểu**$d$có giá trị biên$r$là số nguyên dương nhỏ nhất sao cho$r^d\in\mathbb Z$. 

Cho phép$g(d)$là số điểm biên có mẫu số tối thiểu chính xác là$d$. 

Sau đó$$t(n)=\sum_{d\le n} g(d).$$Để cố định$d$, mọi ứng cử viên trông giống như$$r = m^{1/d}, \qquad 2^d\le m<3^d.$$Mẫu số của nó không nhỏ nhất nếu$m$là một$e$- lũy thừa của một số chia$e\mid d$,$e>1$. 

Bằng phép đảo ngược Möbius:$$g(d) = \sum_{e\mid d} \mu(e) \left(3^{d/e}-2^{d/e}\right),$$Ở đâu$\mu$là hàm Mobius. 

Vì thế$$t(n) = \sum_{d\le n} \sum_{e\mid d} \mu(e) \left(3^{d/e}-2^{d/e}\right).$$Hoán đổi phép tính tổng bằng$d=ek$:$$t(n) = \sum_{e\le n} \mu(e) \sum_{k\le n/e} (3^k-2^k).$$Định nghĩa$$F(m) = \sum_{k=1}^{m}(3^k-2^k).$$Sử dụng tổng hình học:$$F(m) = \frac{3^{m+1}-3}{2} - (2^{m+1}-2).$$Vì thế:$$t(n) = \sum_{e\le n} \mu(e)\, F\!\left(\left\lfloor \frac ne \right\rfloor\right).$$Điều này có thể được tính toán trong khoảng$O(\sqrt n)$các giá trị sàn riêng biệt bằng cách sử dụng hàm Möbius tổng hợp (hàm Mertens).

## 2. Triển khai Python```python
from functools import lru_cache

MOD = 10**9
MOD2 = 2 * MOD

def solve(n):
    # Precompute Möbius up to a cutoff
    LIMIT = 2_000_000

    mu = [0] * (LIMIT + 1)
    mu[1] = 1

    primes = []
    composite = [False] * (LIMIT + 1)

    # Linear sieve for Möbius
    for i in range(2, LIMIT + 1):
        if not composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > LIMIT:
                break

            composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break
            else:
                mu[v] = -mu[i]

    # Prefix Mertens values
    mertens_prefix = [0] * (LIMIT + 1)
    for i in range(1, LIMIT + 1):
        mertens_prefix[i] = mertens_prefix[i - 1] + mu[i]

    @lru_cache(None)
    def M(x):
        """Summatory Möbius function."""
        if x <= LIMIT:
            return mertens_prefix[x]

        result = 1
        l = 2

        while l <= x:
            q = x // l
            r = x // q
            result -= (r - l + 1) * M(q)
            l = r + 1

        return result

    def F(m):
        """Sum_{k=1..m} (3^k - 2^k) modulo 1e9."""
        s3 = ((pow(3, m + 1, MOD2) - 3) % MOD2) // 2
        s2 = (pow(2, m + 1, MOD) - 2) % MOD
        return (s3 - s2) % MOD

    ans = 0
    l = 1

    # Group equal floor(n / i)
    while l <= n:
        q = n // l
        r = n // q

        coeff = M(r) - M(l - 1)
        ans = (ans + coeff * F(q)) % MOD

        l = r + 1

    return ans

print(solve(10**10))
```--- 

## 3. Hướng dẫn sử dụng mã 

1. **Sàng tuyến tính** tính toán các giá trị Möbius$\mu(n)$. 
2. **Tổng tiền tố** xây dựng hàm Mertens$$M(x)=\sum_{k\le x}\mu(k).$$1.`M(x)`cho lớn$x$sử dụng danh tính phân chia và chinh phục tiêu chuẩn:$$M(x) = 1-\sum_{l=2}^{x} (r-l+1)M\!\left(\left\lfloor \frac{x}{l}\right\rfloor\right),$$nhóm các thương số bằng nhau. 

1.`F(m)`tính toán$$\sum_{k=1}^{m}(3^k-2^k)$$thông qua tổng hình học modulo$10^9$. 

1. Vòng lặp chính nhóm các giá trị bằng nhau của$$\left\lfloor \frac{n}{i}\right\rfloor$$để đạt được gần$O(\sqrt n)$sự phức tạp.
