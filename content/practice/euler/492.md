## Giải pháp 

**Trả lời:**`242586962923928`Cho phép$$a_{n+1}=6a_n^2+10a_n+3,\qquad a_1=1.$$Chúng ta phải tính toán$$B(10^9,10^7,10^{15}) =\sum_{p\text{ prime}\atop 10^9\le p\le 10^9+10^7}(a_{10^{15}}\bmod p).$$Điều quan trọng là tuyến tính hóa hoàn toàn sự tái phát. 

--- 

# 1. Phân tích toán học 

## Bước 1: Sự thay thế quan trọng 

Xác định$$b_n = 6a_n+5.$$Sau đó$$\begin{aligned} b_{n+1} &=6a_{n+1}+5 \\ &=6(6a_n^2+10a_n+3)+5 \\ &=36a_n^2+60a_n+23. \end{aligned}$$Nhưng$$(6a_n+5)^2-2 =36a_n^2+60a_n+25-2 =36a_n^2+60a_n+23.$$Kể từ đây$$\boxed{b_{n+1}=b_n^2-2}$$với$$b_1=6\cdot1+5=11.$$Vì vậy sự tái phát trở thành$$11,\ 119,\ 14159,\dots$$được tạo ra bằng cách lặp đi lặp lại bình phương trừ hai. 

--- 

## Bước 2: Đóng form 

Hãy xem xét$$\alpha=\frac{11+3\sqrt{13}}2.$$liên hợp của nó là$$\alpha^{-1}=\frac{11-3\sqrt{13}}2$$bởi vì$$\alpha\alpha^{-1} =\frac{121-117}{4}=1.$$Cũng,$$\alpha+\alpha^{-1}=11=b_1.$$Bây giờ xác định$$u_n=\alpha^{2^{n-1}}+\alpha^{-2^{n-1}}.$$Sau đó$$u_{n+1} =(u_n)^2-2$$bởi vì$$(x+x^{-1})^2-2=x^2+x^{-2}.$$Từ$u_1=11=b_1$, tính duy nhất mang lại$$\boxed{b_n=\alpha^{2^{n-1}}+\alpha^{-2^{n-1}}}.$$Vì thế$$\boxed{ a_n=\frac{ \alpha^{2^{n-1}}+\alpha^{-2^{n-1}}-5 }{6}. }$$--- 

## Bước 3: Tính modulo số nguyên tố 

Đối với một số nguyên tố$p\neq 13$, chúng ta làm việc trong trường bậc hai$\mathbb F_p(\sqrt{13})$. 

phần tử$\alpha$có chuẩn mực$1$, do đó thứ tự nhân của nó chia$$p-\left(\frac{13}{p}\right),$$Ở đâu$\left(\frac{13}{p}\right)$là ký hiệu Legendre. 

Như vậy$$\alpha^{2^{n-1}}$$chỉ phụ thuộc vào$$2^{n-1}\bmod \left(p-\left(\frac{13}{p}\right)\right).$$Vì vậy với mỗi số nguyên tố$p$: 

1. Tính toán$$m=p-\left(\frac{13}{p}\right).$$1. Tính toán$$e=2^{n-1}\bmod m.$$1. Tính toán$\alpha^e$trong phần mở rộng bậc hai. 
2. Phục hồi$$a_n=\frac{(\alpha^e+\alpha^{-e})-5}{6}\pmod p.$$Từ$m\sim 10^9$, số mũ rất nhỏ (khoảng 30 bit).

#2. Triển khai Python```python
from sympy import primerange

N = 10**15

def value_mod_p(p, n):
    """
    Compute a_n mod p using the closed form.
    """

    # Legendre symbol (13/p)
    ls = 1 if pow(13, (p - 1) // 2, p) == 1 else -1

    # Order divisor
    m = p - ls

    # exponent = 2^(n-1) mod m
    e = pow(2, n - 1, m)

    inv2 = (p + 1) // 2
    inv6 = pow(6, p - 2, p)

    # alpha = (11 + 3*sqrt(13))/2
    # represented as pair (a,b) meaning a + b*sqrt(13)
    a = 11 * inv2 % p
    b = 3 * inv2 % p

    # Fast exponentiation in F_p(sqrt(13))
    ra, rb = 1, 0
    ba, bb = a, b

    while e:
        if e & 1:
            ra, rb = (
                (ra * ba + 13 * rb * bb) % p,
                (ra * bb + rb * ba) % p
            )

        ba, bb = (
            (ba * ba + 13 * bb * bb) % p,
            (2 * ba * bb) % p
        )

        e >>= 1

    # Since alpha has norm 1:
    # alpha^{-e} = conjugate(alpha^e)
    # so alpha^e + alpha^{-e} = 2 * real_part
    b_n = (2 * ra) % p

    # a_n = (b_n - 5)/6
    return ((b_n - 5) * inv6) % p

def B(x, y, n):
    total = 0

    for p in primerange(x, x + y + 1):
        total += value_mod_p(p, n)

    return total

# Verification examples
print(B(10**9, 10**3, 10**3))
print(B(10**9, 10**3, 10**15))

# Final answer
print(B(10**9, 10**7, 10**15))
```---

một cặp`(u,v)`đại diện cho$$u+v\sqrt{13}.$$Phép nhân:$$(u+v\sqrt{13})(r+s\sqrt{13}) =(ur+13vs)+(us+vr)\sqrt{13}.$$--- 

## Đang phục hồi$a_n$Nếu như$$\alpha^e = r+s\sqrt{13},$$sau đó$$\alpha^{-e}=r-s\sqrt{13},$$Vì thế$$\alpha^e+\alpha^{-e}=2r.$$Kể từ đây```python
