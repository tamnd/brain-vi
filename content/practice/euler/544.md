[Vấn đề dự án Euler 544](https://projecteuler.net/problem=544) 

## Giải pháp 

**Trả lời:**`640432376`Cho phép$$F(r,c,n)$$là số màu thích hợp của$r\times c$biểu đồ lưới sử dụng màu sắc từ$\{1,\dots,n\}$, trong đó liền kề có nghĩa là chia sẻ một cạnh. 

Chúng tôi được yêu cầu$$S(r,c,n)=\sum_{k=1}^{n}F(r,c,k)$$và đặc biệt$$S(9,10,1112131415)\pmod{10^9+7}.$$--- 

# 1. Phân tích toán học 

Quan sát chính là: 

>$F(r,c,n)$chính xác là đa thức sắc độ của$r\times c$biểu đồ lưới được đánh giá tại$n$. 

Đối với đồ thị có$N=rc$đỉnh thì đa thức sắc có bậc$N$. 

Như vậy: 

-$F(9,10,n)$là một đa thức trong$n$mức độ$90$. 
- Vì thế$$S(9,10,n)=\sum_{k=1}^{n}F(9,10,k)$$là một đa thức trong$n$mức độ$91$. 

Vì vậy, chiến lược là: 

1. Tính đa thức sắc độ$P(q)=F(9,10,q)$. 
2. Đánh giá nó ở số nguyên đủ nhỏ. 
3. Sử dụng phép nội suy Lagrange để đánh giá$S(9,10,1112131415)$. 

Phần khó khăn là bước 1. 

--- 

## Biên giới / chuyển-DP 

Chúng tôi xử lý từng ô lưới. 

Tại bất kỳ thời điểm nào, chỉ có “biên giới” hiện tại mới quan trọng. 

Đối với một lưới có$r=9$, biên giới có kích thước 9. 

Thay vì lưu trữ màu sắc thực tế, chúng tôi chỉ lưu trữ cấu trúc đẳng thức. 

Ví dụ:```python
[5,7,5,9]
```được biểu diễn một cách kinh điển như```python
[0,1,0,2]
```bởi vì chỉ có quan hệ bình đẳng mới quan trọng. 

Điều này nén đáng kể không gian trạng thái. 

--- 

## DP đa thức 

Giả sử biên giới hiện tại chứa$m$màu sắc riêng biệt. 

Khi tô màu ô tiếp theo: 

- sử dụng lại hệ số đóng góp màu biên giới hiện có$1$, 
- giới thiệu một màu sắc hoàn toàn mới góp phần tạo nên một yếu tố$$(q-m),$$bởi vì có$q-m$màu sắc hiện không có trên biên giới. 

Do đó mọi giá trị DP đều trở thành đa thức trong$q$. 

Sau khi tất cả các ô được xử lý, chúng ta thu được đa thức màu đầy đủ. 

--- 

## Tại sao phép nội suy lại hoạt động 

Kể từ khi$S(n)$có bằng cấp$91$, biết giá trị của nó tại$$n=0,1,2,\dots,91$$xác định nó một cách duy nhất. 

Chúng tôi tính toán các giá trị đó theo modulo$$M=10^9+7$$rồi tính đa thức tại$$1112131415$$sử dụng phép nội suy Lagrange tiêu chuẩn trên trường hữu hạn.

#2. Triển khai Python```python
MOD = 1_000_000_007
EMPTY = -1

def poly_eval(coeffs, x, mod=MOD):
    """Evaluate polynomial sum coeffs[i] * x^i."""
    x %= mod
    res = 0
    p = 1
    for a in coeffs:
        res = (res + a * p) % mod
        p = (p * x) % mod
    return res

def lagrange_eval(values, x, mod=MOD):
    """
    Given values[i] = f(i) for i=0..n
    where deg(f) <= n,
    evaluate f(x) modulo mod.
    """
    n = len(values) - 1

    if 0 <= x <= n:
        return values[x] % mod

    x %= mod

    fac = [1] * (n + 1)
    for i in range(1, n + 1):
        fac[i] = fac[i - 1] * i % mod

    invfac = [1] * (n + 1)
    invfac[n] = pow(fac[n], mod - 2, mod)

    for i in range(n, 0, -1):
        invfac[i - 1] = invfac[i] * i % mod

    pre = [1] * (n + 2)
    suf = [1] * (n + 2)

    for i in range(n + 1):
        pre[i + 1] = pre[i] * (x - i) % mod

    for i in range(n, -1, -1):
        suf[i] = suf[i + 1] * (x - i) % mod

    ans = 0

    for i in range(n + 1):
        num = pre[i] * suf[i + 1] % mod

        den = invfac[i] * invfac[n - i] % mod
        if (n - i) & 1:
            den = (-den) % mod

        ans = (ans + values[i] * num % mod * den) % mod

    return ans % mod

def chromatic_poly_grid(r, c, mod=MOD):
    """
    Compute chromatic polynomial of an r x c grid graph.
    Returns coefficients in power basis.
    """

    canon_cache = {}

    def canon(state):
        """Canonical relabelling of colours."""
        if state in canon_cache:
            return canon_cache[state]

        mp = {}
        nxt = 0
        out = []

        for x in state:
            if x == EMPTY:
                out.append(EMPTY)
            else:
                if x not in mp:
                    mp[x] = nxt
                    nxt += 1
                out.append(mp[x])

        res = tuple(out)
        canon_cache[state] = res
        return res

    trans_cache = {}

    def trans(st, i):
        """
        Set frontier position i to every possible label.
        """
        key = (st, i)

        if key in trans_cache:
            return trans_cache[key]

        mx = max(st)
        m = 0 if mx == EMPTY else mx + 1

        base = list(st)

        nexts = [None] * (m + 1)

        for lab in range(m + 1):
            base[i] = lab
            nexts[lab] = canon(tuple(base))

        base[i] = st[i]

        res = (m, nexts)
        trans_cache[key] = res
        return res

    forget_cache = {}

    def forget(st, i):
        key = (st, i)

        if key in forget_cache:
            return forget_cache[key]

        base = list(st)
        base[i] = EMPTY

        res = canon(tuple(base))
        forget_cache[key] = res

        return res

    def add_poly(tgt, poly):
        if len(tgt) < len(poly):
            tgt.extend([0] * (len(poly) - len(tgt)))

        for j, v in enumerate(poly):
            tgt[j] = (tgt[j] + v) % mod

    def add_q_minus_m_mul(tgt, poly, m):
        """
        tgt += (q - m) * poly
        """
        need = len(poly) + 1

        if len(tgt) < need:
            tgt.extend([0] * (need - len(tgt)))

        mm = m % mod

        for j, v in enumerate(poly):
            tgt[j] = (tgt[j] - mm * v) % mod
            tgt[j + 1] = (tgt[j + 1] + v) % mod

    start = tuple([EMPTY] * r)

    dp = {start: [1]}

    for col in range(c):
        for row in range(r):

            i = row

            has_up = row > 0
            has_left = col > 0

            ndp = {}

            for st, poly in dp.items():

                m, nexts = trans(st, i)

                up = st[i - 1] if has_up else -2
                left = st[i] if has_left else -2

                # reuse existing frontier colour
                for lab in range(m):

                    if lab == up or lab == left:
                        continue

                    ns = nexts[lab]

                    tgt = ndp.setdefault(ns, [])
                    add_poly(tgt, poly)

                # introduce new colour
                ns = nexts[m]

                tgt = ndp.setdefault(ns, [])
                add_q_minus_m_mul(tgt, poly, m)

            dp = ndp

    # forget remaining frontier
    for i in range(r):

        ndp = {}

        for st, poly in dp.items():

            ns = forget(st, i)

            tgt = ndp.setdefault(ns, [])
            add_poly(tgt, poly)

        dp = ndp

    return dp[start]

def solve():

    # sanity checks from problem statement

    p22 = chromatic_poly_grid(2, 2)

    assert poly_eval(p22, 3) == 18
    assert poly_eval(p22, 20) == 130340

    p34 = chromatic_poly_grid(3, 4)

    assert poly_eval(p34, 6) == 102923670

    p44 = chromatic_poly_grid(4, 4)

    s44 = sum(poly_eval(p44, k) for k in range(1, 16)) % MOD

    assert s44 == 325951319

    # target
    r, c, n = 9, 10, 1112131415

    p = chromatic_poly_grid(r, c)

    # S(n) has degree 91
    prefix = [0] * 92

    acc = 0

    for k in range(1, 92):
        acc = (acc + poly_eval(p, k)) % MOD
        prefix[k] = acc

    ans = lagrange_eval(prefix, n)

    print(ans)

solve()

#3. Hướng dẫn sử dụng mã 

##`canon(state)`Thay thế nhãn màu tùy ý bằng nhãn chuẩn:```python
[7,3,7,9] -> [0,1,0,2]
```Điều này loại bỏ tính đối xứng không liên quan.

##`dp`

`dp[state]`lưu trữ một đa thức trong$q$. 

Danh sách hệ số đại diện cho:$$a_0 + a_1 q + a_2 q^2 + \cdots$$--- 

## Tái sử dụng màu sắc 

Nếu chúng ta sử dụng lại màu đường viền hiện có thì số lượng lựa chọn sẽ cố định nên chúng ta chỉ cần sao chép đa thức. 

--- 

## Màu mới 

Nếu hiện tại có$m$màu sắc hoạt động trên đường biên, sau đó giới thiệu một màu mới góp phần:$$(q-m)$$Kể từ đây:```python
add_q_minus_m_mul(...)
```thực hiện phép nhân với$(q-m)$.

## Nội suy 

Kể từ khi$S(n)$có bằng cấp$91$, giá trị tại$0..91$xác định nó một cách duy nhất.`lagrange_eval()`đánh giá đa thức đó tại$$n = 1112131415$$modulo$10^9+7$.
