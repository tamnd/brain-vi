## Giải pháp 

**Trả lời:**`11429712`Cho phép$$T_m=\frac{m(m+1)}2$$là$m$-số tam giác thứ 

Chúng tôi được yêu cầu tính toán$$G(N),\qquad N=17526\cdot 10^9.$$--- 

# Bước 1 - Chuyển số tam giác thành số vuông 

Một bản sắc cổ điển là$$8T_m+1=(2m+1)^2.$$Giả định$$N=T_a+T_b+T_c.$$Sau đó$$8N+3=(2a+1)^2+(2b+1)^2+(2c+1)^2.$$Ngược lại, mọi biểu diễn của$8N+3$vì tổng của ba ô vuông lẻ tương ứng duy nhất với một biểu diễn của$N$dưới dạng tổng của ba số tam giác. 

Vì việc đổi dấu các số nguyên lẻ không làm thay đổi số tam giác nên mọi biểu diễn tam giác đều tương ứng chính xác với$2^3=8$biểu diễn hình vuông có dấu. 

Kể từ đây:$$G(N)=\frac{r_3(8N+3)}8,$$Ở đâu$r_3(m)$là số nghiệm số nguyên có thứ tự của$$x^2+y^2+z^2=m.$$--- 

# Bước 2 - Sử dụng công thức số lớp ba bình phương của Gauss 

hãy để$$M=8N+3.$$Đối với số nguyên$M\equiv 3\pmod 8$, 

Gauss đã chứng minh:$$r_3(M)=24\,H(M),$$Ở đâu$H(M)$là số lớp Hurwitz. 

Vì thế$$G(N)=3H(M).$$Bây giờ tính toán$M$:$$M=8(17526\cdot 10^9)+3 =140208000000003.$$Nhân tố hóa:$$140208000000003 =3^8\cdot 13\cdot 3527\cdot 466073.$$Cho phép$$D_0=-(13\cdot3527\cdot466073)=-21369913123.$$Đây là một sự phân biệt cơ bản. 

Từ$$M=|D_0|\cdot 3^8,$$số lớp Hurwitz là$$H(M)=\sum_{d^2\mid M} h\!\left(-\frac{M}{d^2}\right),$$và các ước số bình phương là$$1,3^2,3^4,3^6,3^8.$$Do đó, các yếu tố phân biệt có liên quan là$$D_0,\quad D_0\cdot 3^2,\quad D_0\cdot 3^4,\quad D_0\cdot 3^6,\quad D_0\cdot 3^8.$$--- 

# Bước 3 - Số lớp của các đơn đặt hàng không cơ bản 

Đối với lệnh của người chỉ huy$f$trong trường bậc hai của phân biệt$D_0$,$$h(D_0f^2) = h(D_0)\,f\prod_{p\mid f}\left(1-\frac{\chi_{D_0}(p)}p\right).$$Đây$f=3^k$, Và$$\chi_{D_0}(3)=\left(\frac{D_0}{3}\right)=-1.$$Kể từ đây$$h(D_0 3^{2k}) = h(D_0)\cdot 3^k\left(1+\frac13\right) = 4\cdot 3^{k-1}h(D_0) \qquad (k\ge1).$$Vì thế:$$\begin{aligned} H(M) &= h(D_0) +4h(D_0) +12h(D_0) +36h(D_0) +108h(D_0)\\ &=161\,h(D_0). \end{aligned}$$Vì thế$$G(N)=3H(M)=483\,h(D_0).$$--- 

# Bước 4 - Tính số lớp cơ bản 

Sự phân biệt cơ bản là$$D_0=-21369913123.$$Sử dụng dạng bậc hai nhị phân rút gọn (hoặc thuật toán số lớp tương đương), người ta tìm thấy$$h(D_0)=23664.$$Vì thế$$G(N)=483\cdot 23664=11429712.$$--- 

#Triển khai Python```python
from math import gcd, isqrt
from sympy.ntheory import factorint
from sympy.ntheory.residue_ntheory import sqrt_mod

# ------------------------------------------------------------
# Count reduced primitive binary quadratic forms of
# discriminant D < 0.
#
# For a fundamental discriminant D, this equals h(D).
# ------------------------------------------------------------

def class_number_fundamental(D):
    assert D < 0
    assert D % 4 in (0, 1)

    h = 0
    limit = isqrt(abs(D) // 3) + 1

    for a in range(1, limit + 1):

        modulus = 4 * a
        rhs = D % modulus

        # Solve b^2 ≡ D (mod 4a)
        roots = sqrt_mod(rhs, modulus, all_roots=True)

        for r in roots:

            # Convert to representatives in [-a, a]
            candidates = set()

            for b in (r, r - modulus):
                if -a <= b <= a:
                    candidates.add(b)

            for b in candidates:

                if (b * b - D) % (4 * a):
                    continue

                c = (b * b - D) // (4 * a)

                # Reduced form conditions
                if a > c:
                    continue

                if (abs(b) == a or a == c) and b < 0:
                    continue

                # Primitive
                if gcd(gcd(a, b), c) != 1:
                    continue

                h += 1

    return h

# ------------------------------------------------------------
# Main computation
# ------------------------------------------------------------

N = 17526 * 10**9
M = 8 * N + 3

# Factor M
factors = factorint(M)
print("Factorization:", factors)

# Fundamental discriminant
D0 = -(13 * 3527 * 466073)

# Fundamental class number
h0 = class_number_fundamental(D0)

# Hurwitz multiplier:
# H(M) = 161 * h0
# G(N) = 3 * H(M)
answer = 3 * 161 * h0

print("h(D0) =", h0)
print("G(N) =", answer)
```--- 

# Hướng dẫn sử dụng mã 

###`class_number_fundamental(D)`Hàm này đếm giảm các dạng bậc hai nhị phân xác định dương nguyên thủy của phân biệt đối xử$D$. 

Gauss đã chứng minh rằng đối với phép phân biệt cơ bản$D<0$, số dạng rút gọn như vậy bằng số lớp$h(D)$. 

Vòng lặp:```python
for a in range(1, limit + 1):
```liệt kê các hệ số dẫn đầu có thể có của dạng rút gọn. 

Chúng tôi giải quyết:$$b^2 \equiv D \pmod{4a}$$sử dụng`sqrt_mod`. 

Sau đó:$$c=\frac{b^2-D}{4a}$$phải thỏa mãn các bất đẳng thức dạng rút gọn. 

Cuối cùng chúng tôi chỉ đếm các dạng nguyên thủy:$$\gcd(a,b,c)=1.$$Đối với người phân biệt đối xử của chúng tôi, điều này mang lại:$$h(D_0)=23664.$$Số học còn lại là công thức dây dẫn/Hurwitz rút ra ở trên.
