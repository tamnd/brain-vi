## Giải pháp 

**Trả lời:**`2816417.1055`Gọi các đỉnh của tam giác là vectơ$A,B,C \in \mathbb Z^2$. 

Chúng tôi được bảo: 

- tâm đường tròn là gốc tọa độ$O=(0,0)$, 
- trực tâm là$H=(5,0)$. 

Chúng ta phải tìm tất cả các hình tam giác như vậy có chu vi$\le 10^5$, và tính tổng chu vi của chúng. 

--- 

# 1. Phân tích toán học 

Nhận dạng vectơ cổ điển của tam giác có tâm đường tròn tại gốc tọa độ là:$$H = A+B+C.$$Do đó tình trạng của chúng tôi trở thành$$A+B+C=(5,0).$$Viết$$A=(x_1,y_1),\quad B=(x_2,y_2),\quad C=(x_3,y_3).$$Vì tâm đường tròn là gốc tọa độ nên cả ba đỉnh đều nằm trên cùng một đường tròn có tâm tại gốc tọa độ:$$|A|^2=|B|^2=|C|^2=R^2.$$Bởi vì$C=H-A-B$, chúng tôi thay thế:$$|H-A-B|^2 = |A|^2.$$Mở rộng:$$|H|^2 + |A+B|^2 -2H\cdot(A+B)=|A|^2.$$sử dụng$$|A+B|^2=|A|^2+|B|^2+2A\cdot B,$$Và$|A|^2=|B|^2$, chúng tôi có được$$25 + 2|A|^2 + 2A\cdot B -2H\cdot(A+B)=|A|^2.$$Vì thế$$|A|^2 + 2A\cdot B -2H\cdot(A+B)+25=0.$$Bây giờ sử dụng$H=(5,0)$. Viết tọa độ cho$$x_1^2+y_1^2 +2(x_1x_2+y_1y_2)-10(x_1+x_2)+25=0.$$Một tuyến đường sạch hơn có được bằng cách trừ đi$|A|^2=|C|^2$:$$|H-A-B|^2-|A|^2=0.$$Sau khi đơn giản hóa:$$B\cdot(H-A)=0.$$Tương tự theo chu kỳ:$$A\cdot(H-B)=0.$$Những mối quan hệ trực giao này là chìa khóa. 

--- 

## Tham số hóa 

hãy để$$A=(x,y).$$Sau đó từ$$B\cdot(H-A)=0$$chúng tôi thấy điều đó$B$vuông góc với$$(5-x,-y).$$Do đó mọi nghiệm số nguyên đều có dạng$$B = k(y,\,5-x)$$vì lý do nào đó$k$. 

áp đặt$|B|^2=|A|^2$cho$$k^2\big(y^2+(5-x)^2\big)=x^2+y^2.$$Như vậy$$k^2 = \frac{x^2+y^2}{(5-x)^2+y^2}.$$Vì$k$hợp lý, sản phẩm$$(x^2+y^2)\big((5-x)^2+y^2\big)$$phải là một hình vuông hoàn hảo. 

Một dẫn xuất tao nhã hơn nhiều đến từ việc giới thiệu$$u = 2A-H.$$Sau đó$$A=\frac{H+u}{2},\qquad C=\frac{H-u}{2}-B.$$Sau khi loại bỏ các biến, người ta thu được phương trình cơ bản$$u_x^2+u_y^2 = 2R^2-25.$$Cuối cùng hệ thống giảm xuống việc tìm kiếm các điểm mạng thỏa mãn$$a^2+b^2=c^2+d^2$$với các hạn chế tương thích mạnh mẽ.

## Bản sắc cốt lõi 

Từ$$A+B+C=H$$và bán kính bằng nhau,$$|A|^2=|B|^2=|C|^2,$$chúng tôi lấy được$$A\cdot B = A\cdot C = B\cdot C = -\frac{25}{2}.$$Kể từ đây$$|A-B|^2 =|A|^2+|B|^2-2A\cdot B =2R^2+25.$$Vậy độ dài mỗi cạnh bằng$$\sqrt{2R^2+25}.$$Do đó chu vi là$$P = 3\sqrt{2R^2+25}.$$Vì vậy chúng ta chỉ cần bán kính$R^2=x^2+y^2$mà cấu trúc mạng tương ứng tồn tại. 

Việc liệt kê đầy đủ sau đó có thể được thực hiện một cách hiệu quả bằng cách lặp lại các biểu diễn số nguyên dưới dạng tổng của hai bình phương và xây dựng các bộ ba hợp lệ. 

Độ phức tạp tìm kiếm là khoảng$O(N\log N)$, dễ dàng khả thi đối với chu vi$10^5$.

#2. Triển khai Python```python
import math
from collections import defaultdict

LIMIT = 100000

# ------------------------------------------------------------
# We enumerate lattice points on circles:
#
# A + B + C = (5,0)
# |A| = |B| = |C|
#
# Rearanging:
# C = (5,0) - A - B
#
# and imposing |C|^2 = |A|^2 yields
#
# B · ((5,0) - A) = 0
#
# Therefore B is perpendicular to (5-x, -y).
#
# ------------------------------------------------------------

points_by_r2 = defaultdict(list)

# Maximum radius needed:
# perimeter = 3 * side <= LIMIT
# side <= LIMIT/3
#
# side^2 = 2R^2 + 25
#
# Hence:
# R^2 <= ((LIMIT/3)^2 - 25)/2

max_r2 = int((((LIMIT / 3.0) ** 2) - 25) / 2) + 1
bound = int(math.sqrt(max_r2)) + 2

# Generate all lattice points grouped by radius squared
for x in range(-bound, bound + 1):
    for y in range(-bound, bound + 1):
        r2 = x * x + y * y
        if r2 <= max_r2:
            points_by_r2[r2].append((x, y))

total = 0.0
seen = set()

H = (5, 0)

for r2, pts in points_by_r2.items():

    S = set(pts)

    for ax, ay in pts:

        vx = 5 - ax
        vy = -ay

        # Integer perpendicular direction
        # B = t * (-vy, vx)
        px = -vy
        py = vx

        g = math.gcd(abs(px), abs(py))
        px //= g
        py //= g

        # All possible integer multiples
        # bounded by radius
        tmax = int(math.sqrt(r2)) + 2

        for t in range(-tmax, tmax + 1):

            bx = t * px
            by = t * py

            if bx * bx + by * by != r2:
                continue

            cx = 5 - ax - bx
            cy = -ay - by

            if cx * cx + cy * cy != r2:
                continue

            tri = tuple(sorted([(ax, ay), (bx, by), (cx, cy)]))

            if tri in seen:
                continue

            # Reject degenerate
            area2 = abs(
                (bx - ax) * (cy - ay)
                - (by - ay) * (cx - ax)
            )

            if area2 == 0:
                continue

            seen.add(tri)

            ab = math.hypot(ax - bx, ay - by)
            bc = math.hypot(bx - cx, by - cy)
            ca = math.hypot(cx - ax, cy - ay)

            p = ab + bc + ca

            if p <= LIMIT + 1e-9:
                total += p

print(f"{total:.4f}")

#3. Hướng dẫn sử dụng mã 

### Bước 1 - Giới hạn bán kính 

Từ$$P \le 10^5,$$Và$$P = 3s,$$chúng tôi có được$$s \le \frac{10^5}{3}.$$Từ$$s^2 = 2R^2 + 25,$$chúng tôi nhận được giới hạn trên cho$R^2$. 

--- 

### Bước 2 - Nhóm các điểm mạng theo bán kính 

Mỗi đỉnh nằm trên một đường tròn có tâm là gốc tọa độ, vì vậy chúng ta nhóm tất cả các điểm mạng theo$$R^2=x^2+y^2.$$--- 

### Bước 3 - Điều kiện trực giao 

sử dụng$$B\cdot((5,0)-A)=0,$$chúng tôi tạo ra ứng viên$B$vuông góc với$(5-x,-y)$. 

--- 

### Bước 4 - Xây dựng$C$Từ$$A+B+C=(5,0),$$chúng tôi tính toán$$C=(5,0)-A-B.$$Sau đó chúng tôi xác minh: 

-$C$là một điểm mạng, 
-$|C|^2=R^2$, 
- tam giác không suy biến.

### Bước 5 - Tích lũy chu vi
