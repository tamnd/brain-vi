[Vấn đề dự án Euler 563](https://projecteuler.net/problem=563) 

##Giải pháp 

**Trả lời:**`27186308211734760`Cho hình chữ nhật dựng được có độ dài các cạnh$a$Và$b$. 

Mỗi bước hàn mất$k$hình chữ nhật giống nhau ($2 \le k \le 25$) và hàn chúng dọc theo một cạnh, nhân chính xác chiều dài một cạnh với$k$. 

Do đó mọi chiều dài cạnh dựng được đều là tích của các số$\le 25$, tức là một số có các thừa số nguyên tố đều nằm trong số$$2,3,5,7,11,13,17,19,23.$$Vì vậy, độ dài các cạnh dựng được chính xác là **23 số chẵn**. 

--- 

# Phân tích toán học 

Chúng ta phải tính toán cho từng khu vực có thể xây dựng$A$, số lượng các yếu tố$$A = xy$$như vậy 

-$x,y$mịn màng 23, 
-$x \le y$, 
-$y \le 1.1x$. 

Số lượng đó là số lượng "biến thể". 

Chúng tôi xác định:$$M(n)=\text{smallest constructible area with exactly } n \text{ variants}.$$Chúng tôi được cung cấp:$$M(3)=889200.$$Thực vậy,$$889200 =900\cdot 988 =912\cdot 975 =936\cdot 950,$$và chiều dài mỗi cạnh là 23-mượt. 

--- 

## Tạo tất cả các khu vực có thể xây dựng 

Mỗi khu vực thi công cũng có độ phẳng 23, bởi vì$$A = xy$$với cả hai$x$Và$y$23-mịn màng. 

Do đó tất cả các khu vực có liên quan được tạo ra bởi các số nguyên tố$$\{2,3,5,7,11,13,17,19,23\}.$$Thuật toán tạo “số Hamming” dựa trên heap tiêu chuẩn liệt kê tất cả các số như vậy theo thứ tự tăng dần. 

--- 

## Đếm các biến thể cho một khu vực 

Giả sử diện tích hiện tại là$A$. 

Chúng tôi tìm kiếm tất cả các cạnh ngắn hơn có thể$x$thỏa mãn$$x \le \sqrt{A}.$$Sau đó$$y=\frac{A}{x}.$$Điều kiện 10% trở thành$$\frac{y}{x}\le \frac{11}{10}$$hoặc tương đương$$10y \le 11x.$$Vì vậy, với mỗi 23-mịn$x$gần$\sqrt{A}$, chúng tôi kiểm tra: 

1.$x \mid A$, 
2.$10(A/x)\le 11x$. 

Số lần kiểm tra thành công là số lượng biến thể. 

Chúng tôi tiếp tục cho đến khi tất cả$M(2),M(3),\dots,M(100)$được tìm thấy. 

--- 

#Triển khai Python```python
import heapq
import math
from bisect import bisect_right

# Allowed primes (all primes <= 25)
PRIMES = [2, 3, 5, 7, 11, 13, 17, 19, 23]

# Upper bound known to exceed M(100)
LIMIT = 2300000000000000

# solutions[n] = M(n)
solutions = [0] * 101

# Number of distinct M(n) already found
found = 1  # M(1) is irrelevant

# Final sum
answer = 0

# Min-heap generating all 23-smooth numbers
heap = [1]

# All generated smooth numbers that can serve as side lengths
sides = []

while found < 100:

    current = heapq.heappop(heap)

    # Store as a possible side length
    if current * current <= LIMIT:
        sides.append(current)

    # Generate larger smooth numbers
    for p in reversed(PRIMES):
        nxt = current * p

        if nxt <= LIMIT:
            heapq.heappush(heap, nxt)

        # Avoid duplicates
        if current % p == 0:
            break

    # Small optimisations observed experimentally
    if found >= 56:
        if current % 800 != 0:
            continue
    elif found >= 8:
        if current % 80 != 0:
            continue
    else:
        if current % 40 != 0:
            continue

    # Count variants
    count = 0

    # Largest possible short side
    idx = bisect_right(sides, int(math.isqrt(current))) - 1

    while idx > 0:
        short_side = sides[idx]
        idx -= 1

        long_side = current // short_side

        # Ratio exceeded 10%
        if long_side * 10 > short_side * 11:
            break

        # Exact divisor?
        if long_side * short_side == current:
            count += 1

    # We only care about 2..100
    if not (2 <= count <= 100):
        continue

    # First occurrence => minimal area
    if solutions[count] == 0:
        solutions[count] = current
        answer += current
        found += 1

print(answer)
```--- 

# Hướng dẫn sử dụng mã 

## Tạo vùng heap```python
heap = [1]
```Chúng tôi tạo ra tất cả các số 23 trơn theo thứ tự tăng dần. 

Đối với mỗi số được trích xuất`current`, chúng ta nhân với số nguyên tố cho phép. 

điều kiện```python
if current % p == 0:
    break
```đảm bảo mỗi số trơn tru được tạo ra chính xác một lần. 

--- 

## Độ dài cạnh```python
sides.append(current)
```Mọi số chẵn 23 đều có thể là một cạnh hình chữ nhật. 

Chúng tôi tự động duy trì chúng theo thứ tự được sắp xếp vì vùng heap phát ra số lượng ngày càng tăng. 

--- 

## Đếm hình chữ nhật hợp lệ 

Đối với khu vực`current`:```python
short_side <= sqrt(current)
```Và```python
long_side = current // short_side
```Chúng tôi thực thi:```python
long_side * 10 <= short_side * 11
```đó chính xác là điều kiện “trong vòng 10%”. 

Nếu thêm vào```python
long_side * short_side == current
```sau đó chúng tôi tìm thấy một biến thể hợp lệ.
