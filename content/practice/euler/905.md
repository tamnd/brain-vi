[Vấn đề dự án Euler 905](https://projecteuler.net/problem=905) 

## Giải pháp 

**Trả lời:**`70228218`Cho phép

-$F_A(x,y)=F(x+y,x,y)$(A mặc tổng), 
-$F_B(x,y)=F(x,x+y,y)$, 
-$F_C(x,y)=F(x,y,x+y)$. 

Chúng tôi cần$$\sum_{a=1}^7 \sum_{b=1}^{19} F_C(a^b,b^a).$$Quan sát chính là: 

- Nếu người chơi nhìn thấy số$u,v$, số riêng của họ là$|u-v|$hoặc$u+v$. 
- Nếu khả năng nhỏ hơn đã dẫn đến việc khai báo sớm hơn thì người chơi suy ra rằng chúng phải có giá trị lớn hơn. 

Điều này tạo ra sự đệ quy$$F_P(a,b)=1+F_{P-1}(a,b-a)$$(nơi người chơi đạp xe$A\to B\to C\to A$), sau khi sắp xếp như vậy$a\le b$. 

Thay vì trừ từng bước một, chúng ta có thể gộp các bước theo thuật toán Euclide. 

Nếu như$b=qa+r$:

- khi$r>0$, chúng ta có thể thực hiện$q$phép trừ cùng một lúc; 
- khi$r=0$, phép trừ cuối cùng đạt đến đẳng thức, nên chỉ$q-1$các bước được thực hiện trước trường hợp cơ sở. 

Các trường hợp cơ bản là:$$F_A(a,a)=1,\qquad F_B(a,a)=2,\qquad F_C(a,a)=3.$$Đây là mã Python chính xác.```python
from functools import lru_cache

# players: A=0, B=1, C=2
@lru_cache(None)
def F(player, a, b):
    if a > b:
        a, b = b, a

    # base case: equal numbers
    if a == b:
        return player + 1

    q, r = divmod(b, a)

    if r == 0:
        # equality reached after q-1 subtractions
        k = q - 1
        return k + F((player - k) % 3, a, a)
    else:
        # perform q subtractions at once
        k = q
        return k + F((player - k) % 3, min(a, r), max(a, r))

total = 0

for a in range(1, 8):
    for b in range(1, 20):
        x = a ** b
        y = b ** a
        total += F(2, x, y)   # player C has the sum

print(total)
```Xác minh trên các ví dụ: 

-$F(2,1,1)=1$✔ 
-$F(2,7,5)=5$✔
