[Vấn đề dự án Euler 862](https://projecteuler.net/problem=862) 

##Giải pháp 

**Trả lời:**`6111397420935766740`Đặt nhiều tập hợp các chữ số của một$k$-số có chữ số$n$được cố định. Giả sử chữ số$d$xuất hiện$c_d$thời gian, ở đâu$$\sum_{d=0}^9 c_d = k.$$Chúng tôi muốn tính toán sự đóng góp của tất cả các số có nhiều chữ số này cho$S(k)$. 

## 1. Phân tích toán học 

Đối với nhiều tập hợp chữ số nhất định, hãy xác định:$$P(c_0,\dots,c_9)$$là số ** hợp lệ$k$-số nguyên chữ số** có thể được tạo thành (không có số 0 đứng đầu). 

### Bước 1: Đếm các hoán vị hợp lệ 

Bỏ qua giới hạn số 0 đứng đầu, số hoán vị phân biệt là$$\frac{k!}{\prod_{d=0}^9 c_d!}.$$Nếu như$c_0>0$, một số cách sắp xếp bắt đầu bằng số không. Sửa số 0 ở phía trước và hoán vị phần còn lại$k-1$chữ số:$$\frac{(k-1)!}{(c_0-1)!\prod_{d=1}^9 c_d!}.$$Kể từ đây$$P = \frac{k!}{\prod c_d!} - \frac{(k-1)!}{(c_0-1)!\prod_{d=1}^9 c_d!}.$$Nhân tố hóa mang lại$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}.$$--- 

### Bước 2: Tính tổng$T(n)$trên một chữ số 

Liệt kê tất cả các hoán vị hợp lệ theo thứ tự tăng dần:$$a_1 < a_2 < \cdots < a_P.$$Đối với$i$-số thứ,$$T(a_i)=P-i,$$vì chính xác thì những con số sau này lớn hơn. 

Do đó tổng đóng góp của multiset này là$$\sum_{i=1}^{P}(P-i) = 0+1+\cdots+(P-1) = \frac{P(P-1)}{2}.$$Như vậy$$S(k) = \sum_{\substack{c_0+\cdots+c_9=k\\ c_d\ge 0}} \frac{P(P-1)}{2},$$Ở đâu$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}.$$Số lượng vectơ đếm chữ số chỉ là$$\binom{k+9}{9},$$cái nào cho$k=12$là$$\binom{21}{9}=293930,$$đủ nhỏ để liệt kê trực tiếp.

## 2. Triển khai Python```python
from math import factorial

def S(k):
    # Precompute factorials
    fact = [factorial(i) for i in range(k + 1)]

    counts = [0] * 10
    total = 0

    def dfs(digit, remaining):
        nonlocal total

        # Last digit count is forced
        if digit == 9:
            counts[9] = remaining

            # Compute denominator: product(c_i!)
            denom = 1
            for c in counts:
                denom *= fact[c]

            # Number of valid k-digit permutations
            P = (k - counts[0]) * fact[k - 1] // denom

            # Contribution of this multiset
            total += P * (P - 1) // 2
            return

        # Try all counts for this digit
        for c in range(remaining + 1):
            counts[digit] = c
            dfs(digit + 1, remaining - c)

    dfs(0, k)
    return total

# Check given example
print(S(3))   # 1701

# Required answer
print(S(12))
```--- 

## 3. Hướng dẫn sử dụng mã 

-`factorial(i)`các giá trị được tính toán trước để tránh công việc lặp lại. 
- Ta liệt kê đệ quy tất cả các vectơ đếm chữ số$(c_0,\dots,c_9)$với tổng số$k$. 
- Với mỗi vectơ: 

- tính toán$$\prod c_d!$$- đánh giá$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}$$- thêm vào$$\frac{P(P-1)}{2}$$đến tổng số. 

### Xác minh 

Chương trình tái tạo giá trị đã cho:$$S(3)=1701.$$Ví dụ$2302$: 

- đếm chữ số:$c_0=1,c_2=2,c_3=1$- hoán vị hợp lệ:$$P = \frac{(4-1)\cdot 3!}{1!\,2!\,1!} = 9$$Do đó tổng đóng góp của multiset này là$$\frac{9\cdot 8}{2}=36.$$Thật vậy, danh sách được sắp xếp có thứ hạng tạo ra$$8+7+\cdots+0=36.$$Từ$2302$là mục thứ 5,$T(2302)=4$, phù hợp với tuyên bố.
