[Vấn đề dự án Euler 740](https://projecteuler.net/problem=740) 

## Giải pháp 

**Trả lời:**`0.0189581208`Hãy để trạng thái trước một ngã rẽ được mô tả bởi: 

-$c_0$: những người còn lại với 0 bản sao tên của chính họ vẫn còn trên mũ, 
-$c_1$: những người còn lại 1 bản, 
-$c_2$: người còn lại có 2 bản. 

Ban đầu trạng thái là$(0,0,n)$. 

Nếu chỉ còn lại một người, quá trình này sẽ thất bại trừ khi người đó không còn bản sao tên của chính họ:$$q =  \begin{cases} 0 & (c_0,c_1,c_2)=(1,0,0)\\ 1 & \text{otherwise} \end{cases}$$Chúng tôi sử dụng đệ quy được ghi nhớ trên các trạng thái. 

Đối với loại người hiện tại được chọn$t\in\{0,1,2\}$: 

- có$2m-t$phiếu có thể kéo được, 
- ở đâu$m=c_0+c_1+c_2$. 

Chúng tôi liệt kê tất cả các cách mà hai phiếu rút ra có thể ảnh hưởng đến các lần tự trượt và tái diễn còn lại của người chơi trong tương lai. 

Chương trình Python sau đây tính xác suất chính xác:```python
from functools import lru_cache
from math import comb

@lru_cache(None)
def fail(c0, c1, c2):
    m = c0 + c1 + c2

    # Last remaining person
    if m == 1:
        return 0 if c0 == 1 else 1

    ans = 0.0

    for t, ct in [(0, c0), (1, c1), (2, c2)]:
        if ct == 0:
            continue

        pcur = ct / m

        d0, d1, d2 = c0, c1, c2
        if t == 0:
            d0 -= 1
        elif t == 1:
            d1 -= 1
        else:
            d2 -= 1

        D = 2 * m - t
        R = d1 + 2 * d2
        I = D - R

        den = comb(D, 2)

        sub = 0.0

        # draw two irrelevant slips
        sub += comb(I, 2) / den * fail(d0, d1, d2)

        # draw one relevant slip
        if d2:
            sub += (2 * d2 * I) / den * fail(d0, d1 + 1, d2 - 1)

        if d1:
            sub += (d1 * I) / den * fail(d0 + 1, d1 - 1, d2)

        # draw two relevant slips
        if d2:
            sub += d2 / den * fail(d0 + 1, d1, d2 - 1)

        if d2 >= 2:
            sub += 4 * comb(d2, 2) / den * fail(d0, d1 + 2, d2 - 2)

        if d2 and d1:
            sub += 2 * d2 * d1 / den * fail(d0 + 1, d1, d2 - 1)

        if d1 >= 2:
            sub += comb(d1, 2) / den * fail(d0 + 2, d1 - 2, d2)

        ans += pcur * sub

    return ans

print(fail(0, 0, 100))
```Điều này tái tạo các giá trị đã cho:
