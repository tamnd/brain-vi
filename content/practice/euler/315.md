##Giải pháp 

**Trả lời:**`13625242`Đặt mỗi chữ số thập phân được biểu thị bằng mặt nạ bit 7 đoạn. 

Chuỗi gốc kỹ thuật số cho một số$n$là$$n \to s(n) \to s(s(n)) \to \cdots$$Ở đâu$s(n)$là tổng các chữ số thập phân của$n$, cho đến khi đạt được số có một chữ số. 

Ví dụ:$$137 \to 11 \to 2$$Quan sát quan trọng là cả hai đồng hồ chỉ khác nhau ở cách chúng chuyển đổi giữa các màn hình liên tiếp.

# 1. Phân tích toán học 

## Biểu diễn bảy đoạn 

Chúng tôi mã hóa từng chữ số dưới dạng mặt nạ 7 bit. 

Sử dụng đánh số phân đoạn$$\begin{matrix}  &0& \\ 1&&2\\  &3& \\ 4&&5\\  &6& \end{matrix}$$mặt nạ là: 

| Chữ số | Mặt nạ | Phân đoạn sáng | 
| --- | --- | --- | 
| 0 | 0x77 | 6 | 
| 1 | 0x24 | 2 | 
| 2 | 0x5D | 5 | 
| 3 | 0x6D | 5 | 
| 4 | 0x2E | 4 | 
| 5 | 0x6B | 5 | 
| 6 | 0x7B | 6 | 
| 7 | 0x27 | 4 | 
| 8 | 0x7F | 7 | 
| 9 | 0x6F | 6 | 

Số lượng phân đoạn sáng chỉ đơn giản là popcount (số bit được đặt). 

--- 

# Đồng hồ của Sam 

Sam luôn: 

1. bật toàn bộ số, 
2. sau đó tắt toàn bộ số. 

Vì vậy nếu một số được hiển thị$x$công dụng$L(x)$phân đoạn sáng, Sam dành$$2L(x)$$chuyển tiếp trên màn hình đó. 

Do đó đối với chuỗi gốc kỹ thuật số$$x_0,x_1,\dots,x_k$$Sam sử dụng$$S = 2\sum_{i=0}^k L(x_i)$$--- 

# Đồng hồ của Max 

Max chỉ thay đổi các phân đoạn khác nhau giữa các màn hình liên tiếp. 

Nếu như$M(a)$Và$M(b)$là các mặt nạ bit cho hai màn hình thì số lần chuyển đổi cần thiết là$$\operatorname{popcount}(M(a)\oplus M(b))$$vì XOR đánh dấu chính xác các phân đoạn thay đổi trạng thái. 

Do đó tổng số của Max là: 

- bật số đầu tiên, 
- Chuyển tiếp XOR giữa các số liên tiếp, 
- tắt số cuối cùng. 

Vì thế:$$T = L(x_0) + \sum_{i=0}^{k-1} \operatorname{popcount}(M(x_i)\oplus M(x_{i+1})) + L(x_k)$$--- 

# Phạm vi chính 

Chúng ta phải đánh giá điều này cho tất cả các số nguyên tố$$10^7 \le p < 2\cdot 10^7$$Một sàng Eratosthenes dễ dàng đủ nhanh.

#2. Triển khai Python```python
from math import isqrt

# Seven-segment bitmasks
SEG = {
    0: 0x77,
    1: 0x24,
    2: 0x5D,
    3: 0x6D,
    4: 0x2E,
    5: 0x6B,
    6: 0x7B,
    7: 0x27,
    8: 0x7F,
    9: 0x6F,
}

def digit_sum(n):
    """Sum of decimal digits."""
    s = 0
    while n:
        s += n % 10
        n //= 10
    return s

def segments_of_number(n):
    """
    Pack the seven-segment masks of all digits into one integer.
    Each digit gets 8 bits.
    """
    result = 0
    shift = 0

    while n > 0:
        result |= SEG[n % 10] << shift
        n //= 10
        shift += 8

    return result

def sam_cost(n):
    """Transitions used by Sam."""
    segs = segments_of_number(n)
    cost = 2 * segs.bit_count()

    if n > 9:
        cost += sam_cost(digit_sum(n))

    return cost

def max_cost(n, previous=0):
    """Transitions used by Max."""
    segs = segments_of_number(n)

    # Only changed segments toggle
    cost = (segs ^ previous).bit_count()

    if n > 9:
        cost += max_cost(digit_sum(n), segs)
    else:
        # Turn final display off
        cost += segs.bit_count()

    return cost

def sieve(limit):
    """Return list of primes <= limit."""
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    for p in range(2, isqrt(limit) + 1):
        if is_prime[p]:
            step = p
            start = p * p
            for k in range(start, limit + 1, step):
                is_prime[k] = False

    return is_prime

A = 10_000_000
B = 20_000_000

prime = sieve(B)

answer = 0

for p in range(A, B + 1):
    if prime[p]:
        answer += sam_cost(p) - max_cost(p)

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

##`segments_of_number`Mỗi chữ số đóng góp một mặt nạ 7 bit. 

Ví dụ:$$137$$trở thành$$M(7)\ |\ (M(3)\ll 8)\ |\ (M(1)\ll 16)$$Điều này cho phép chúng tôi so sánh toàn bộ màn hình với một XOR. 

--- 

##`sam_cost`Đối với mỗi giá trị được hiển thị:```python
2 * segs.bit_count()
```đếm bật và tắt tất cả các phân đoạn. 

Sau đó, chúng tôi lặp lại trên tổng chữ số. 

Vì$137$: 

-$137$:$2(2+5+4)=22$-$11$:$2(2+2)=8$-$2$:$2(5)=10$Tổng cộng:$$40$$--- 

##`max_cost`Số lần chuyển đổi giữa các màn hình là:```python
(segs ^ previous).bit_count()
```vì XOR phát hiện chính xác các phân đoạn đã thay đổi. 

Vì$137$:

- trống$\to 137$: 11 
-$137 \to 11$: 7 
-$11 \to 2$: 7 
-$2 \to$trống: 5 

Tổng số:$$30$$phù hợp với phát biểu vấn đề.
