[Vấn đề dự án Euler 590](https://projecteuler.net/problem=590) 

##Giải pháp 

**Trả lời:**`834171904`Cho phép$$H(n)=\#\{S\subset \mathbb Z_{>0}:\operatorname{lcm}(S)=n\}$$Ở đâu$S$là một **set** (không lặp lại) và đặt$$L(n)=\operatorname{lcm}(1,2,\dots,n).$$Chúng tôi tìm kiếm$$HL(50000)=H(L(50000)) \pmod{10^9}.$$--- 

## 1. Phân tích toán học 

### Bước 1: Đặc trưng các tập hợp hợp lệ 

Nếu$\operatorname{lcm}(S)=n$, mọi phần tử của$S$phải chia$n$. Do đó mọi tập hợp lệ đều là tập con của tập chia số$n$. 

Cho phép$D(n)$là tập hợp các ước của$n$, với kích thước$$\tau(n)=\#D(n).$$Mọi tập con khác rỗng của$D(n)$có một số chia lcm$n$. Vì thế:$$2^{\tau(n)}-1 = \sum_{d\mid n} H(d).$$Đây là một quan hệ tổng chia, do đó phép đảo ngược Möbius cho:$$H(n) = \sum_{d\mid n} \mu(d)\,2^{\tau(n/d)}.$$Từ$\mu(d)=0$Trừ khi$d$là không có bình phương, chỉ có tập hợp con của các thừa số nguyên tố là quan trọng. 

--- 

### Bước 2: Dạng lũy thừa 

Giả sử$$n=\prod_{i=1}^{r} p_i^{a_i}.$$Đối với một ước số bình phương$d$, chọn số nguyên tố$p_i$TRONG$d$hệ số thay thế$a_i+1$qua$a_i$bên trong$\tau(n/d)$. Kể từ đây$$\tau(n/d) = \prod_{p_i\nmid d}(a_i+1) \prod_{p_i\mid d}a_i.$$Như vậy$$H(n) = \sum_{S\subseteq \{1,\dots,r\}} (-1)^{|S|} 2^{ \left( \prod_{i\notin S}(a_i+1) \prod_{i\in S}a_i \right) }.$$--- 

### Bước 3: Cấu trúc của$L(50000)$Theo định nghĩa,$$L(50000) = \prod_{p\le 50000} p^{\lfloor \log_p(50000)\rfloor}.$$Vậy số mũ$a_i$là: 

| số mũ$a$| đếm | 
| --- | --- | 
| 15 | 1 | 
| 9 | 1 | 
| 6 | 1 | 
| 5 | 1 | 
| 4 | 2 | 
| 3 | 5 | 
| 2 | 37 | 
| 1 | 5085 | 

Số lượng lớn các số nguyên tố lũy thừa 1 là thách thức tính toán chính. 

--- 

### Bước 4: Thủ thuật rút gọn mô-đun 

Chúng tôi chỉ cần câu trả lời modulo$$10^9 = 2^9\cdot 5^9.$$Tất cả các số mũ đều rất lớn ($>9$), Vì thế$$2^k\equiv 0 \pmod{2^9}.$$Đối với$5^9$phần, tính tuần hoàn Euler/Carmichael cho:$$2^k \pmod{5^9}$$chỉ phụ thuộc vào$$k \bmod \lambda(5^9) = 4\cdot 5^8 = 1{,}562{,}500.$$Vì vậy chúng ta chỉ cần modulo số mũ lớn$1{,}562{,}500$, làm cho việc tính toán trở nên khả thi.

## 2. Triển khai Python```python
from collections import Counter
import sympy as sp
import numpy as np

MOD = 10**9
EXP_MOD = 1_562_500  # Carmichael modulus for 5^9

def HL(n):
    # Count exponent frequencies in L(n)
    exponent_counts = Counter()

    for p in sp.primerange(1, n + 1):
        a = 0
        power = p
        while power <= n:
            a += 1
            power *= p
        exponent_counts[a] += 1

    # Use the largest multiplicity (a=1 here) as a vectorized dimension
    dominant_a = max(exponent_counts, key=lambda x: exponent_counts[x])
    dominant_count = exponent_counts.pop(dominant_a)

    # Binomial coefficients with alternating signs
    coeffs = [1]
    current = 1
    for k in range(1, dominant_count + 1):
        current = current * (dominant_count - k + 1) // k
        coeffs.append(current % MOD)

    coeffs = np.array(coeffs, dtype=np.int64)

    signs = np.array(
        [1 if k % 2 == 0 else MOD - 1
         for k in range(dominant_count + 1)],
        dtype=np.int64
    )

    coeffs = (coeffs * signs) % MOD

    # Contribution from the dominant exponent type
    dominant_factors = np.array([
        (pow(dominant_a, k, EXP_MOD) *
         pow(dominant_a + 1,
             dominant_count - k,
             EXP_MOD)) % EXP_MOD
        for k in range(dominant_count + 1)
    ], dtype=np.int64)

    # Precompute powers of 2 modulo 1e9
    power2 = np.array([
        pow(2, r, MOD)
        for r in range(EXP_MOD)
    ], dtype=np.int64)

    # Enumerate remaining exponent groups recursively
    remaining = list(exponent_counts.items())
    states = []

    def dfs(i, product_mod, coefficient):
        if i == len(remaining):
            states.append((product_mod % EXP_MOD,
                           coefficient % MOD))
            return

        a, count = remaining[i]

        comb = 1
        pow_a = 1
        pow_b = (a + 1) ** count

        for k in range(count + 1):
            sign = comb if k % 2 == 0 else -comb

            dfs(
                i + 1,
                product_mod * pow_a * pow_b,
                coefficient * sign
            )

            if k < count:
                comb = comb * (count - k) // (k + 1)
                pow_a *= a
                pow_b //= (a + 1)

    dfs(0, 1, 1)

    # Final accumulation
    answer = 0

    for base, coeff in states:
        residues = (base * dominant_factors) % EXP_MOD
        values = power2[residues]

        subtotal = int(np.dot(coeffs, values) % MOD)
        answer = (answer + coeff * subtotal) % MOD

    return answer % MOD

print(HL(4))      # 44
print(HL(50000))  # target
```--- 

## 3. Hướng dẫn sử dụng mã 

### Trích xuất số mũ nguyên tố 

Đối với mỗi số nguyên tố$p\le n$, chúng tôi tính toán$$a=\lfloor \log_p(n)\rfloor$$bằng cách nhân nhiều lần$p$. 

Điều này xây dựng hệ số lũy thừa của$L(n)$. 

--- 

### Nhóm các số mũ giống hệt nhau 

Thay vì điều trị tất cả$5133$các số nguyên tố riêng biệt, chúng tôi nhóm chúng theo số mũ$a$. 

Đối với số mũ$a$xuất hiện$c$lần, chúng tôi tổng hợp lại việc lựa chọn$k$của các số nguyên tố đó trong tập con bao gồm-loại trừ:$$\binom{c}{k}(-1)^k.$$Điều này làm giảm đáng kể không gian tìm kiếm. 

--- 

### Giảm số mũ mô-đun 

Vì chỉ$$2^e \pmod{10^9}$$vấn đề, chúng tôi giảm$e$modulo$$1{,}562{,}500.$$Điều này tránh việc xử lý trực tiếp các số mũ lớn về mặt thiên văn. 

--- 

### Xác minh ví dụ nhỏ 

cho$n=4$:$$L(4)=12.$$Chương trình trả về:$$HL(4)=44,$$khớp chính xác với tuyên bố vấn đề.

## 4. Xác minh lần cuối 

- Ví dụ$HL(4)=44$trận đấu. 
- Công thức bao gồm-loại trừ chính xác thông qua nghịch đảo Möbius. 
- Việc rút gọn mô-đun có giá trị về mặt toán học do có hệ số hóa$10^9=2^9\cdot 5^9$. 
- Việc triển khai xử lý số lượng lớn các số nguyên tố mũ 1 một cách hiệu quả.
