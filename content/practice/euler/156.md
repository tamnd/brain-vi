## Giải pháp 

**Trả lời:**`21295121502550`Cho phép$$f(n,d)=\text{number of occurrences of digit }d\text{ in }1,2,\dots,n.$$Chúng ta phải tính toán$$\sum_{d=1}^9 s(d), \qquad s(d)=\sum_{n:\,f(n,d)=n} n.$$Khó khăn chính là các giải pháp rất lớn (lên tới khoảng$10^{11}$–$10^{13}$), vì vậy vũ lực là không thể. 

--- 

# 1. Phân tích toán học 

Đối với một chữ số cố định$d$, định nghĩa$$g_d(n)=f(n,d)-n.$$Chúng tôi tìm kiếm tất cả số không của$g_d(n)$. 

--- 

## Đếm số lần xuất hiện của chữ số một cách hiệu quả 

Đối với vị trí thập phân$10^k$, cho phép

-`higher`= chữ số còn lại của vị trí hiện tại, 
-`current`= chữ số ở vị trí hiện tại, 
-`lower`= chữ số bên phải vị trí hiện tại. 

Sau đó sự đóng góp của vị trí này cho$f(n,d)$là:$$\begin{cases} (higher+1)\cdot 10^k, & current>d,\\[4pt] higher\cdot 10^k + lower +1, & current=d,\\[4pt] higher\cdot 10^k, & current<d. \end{cases}$$Tính tổng tất cả các vị trí thập phân cho$f(n,d)$TRONG$O(\log n)$. 

--- 

## Cấu trúc của$g_d(n)$Quan sát:$$g_d(n+1)-g_d(n) = (\text{number of }d\text{'s in }n+1)-1.$$Do đó: 

- chức năng thay đổi chậm, 
- giữa các số nguyên liên tiếp nó có thể giảm nhiều nhất$1$. 

Điều này đưa ra một quy tắc cắt tỉa theo khoảng thời gian quan trọng. 

Giả sử chúng ta kiểm tra một khoảng$[a,b]$. 

Nếu như$$g_d(a) > b-a,$$sau đó thậm chí giảm đến mức tối đa có thể ($-1$mỗi bước), chức năng không thể đạt được$0$bên trong khoảng. 

Tương tự, nếu$$g_d(b) < a-b,$$sau đó chức năng không thể leo trở lại$0$. 

Do đó những khoảng như vậy không chứa nghiệm. 

Điều này cho phép tìm kiếm phân chia và chinh phục trên phạm vi rộng lớn.

#2. Triển khai Python```python
from functools import lru_cache

def count_digit(n, d):
    """Count occurrences of digit d in 1..n."""
    if n <= 0:
        return 0

    count = 0
    factor = 1

    while factor <= n:
        higher = n // (factor * 10)
        current = (n // factor) % 10
        lower = n % factor

        if current > d:
            count += (higher + 1) * factor
        elif current == d:
            count += higher * factor + lower + 1
        else:
            count += higher * factor

        factor *= 10

    return count

@lru_cache(None)
def g(n, d):
    return count_digit(n, d) - n

def solve_digit(d, limit=10**13):
    """
    Find all n such that f(n,d)=n.
    Uses recursive interval pruning.
    """
    solutions = []

    def search(a, b):
        ga = g(a, d)
        gb = g(b, d)

        # Impossible to hit zero inside interval
        if ga > (b - a):
            return

        if gb < (a - b):
            return

        # Small interval: check directly
        if b - a <= 1:
            if ga == 0:
                solutions.append(a)

            if b != a and gb == 0:
                solutions.append(b)

            return

        mid = (a + b) // 2

        search(a, mid)
        search(mid + 1, b)

    search(0, limit)

    return sorted(set(solutions))

total = 0

for d in range(1, 10):
    sols = solve_digit(d)
    sd = sum(sols)

    print(f"d={d}")
    print("solutions:", sols[:10], "...")
    print("s(d) =", sd)
    print()

    total += sd

print("FINAL =", total)
```--- 

#3. Hướng dẫn sử dụng mã 

##`count_digit`Điều này tính toán$f(n,d)$vị trí chữ số theo vị trí chữ số. 

Ví dụ cho$n=12,d=1$: 

Số:$$1,10,11,12$$bao gồm$1+1+2+1=5$những cái đó, vì vậy:$$f(12,1)=5.$$Hàm trả về chính xác điều này. 

---

## Tìm kiếm theo khoảng đệ quy 

Đối với mỗi khoảng thời gian$[a,b]$:

- đánh giá$g(a)$Và$g(b)$, 
- cắt tỉa những khoảng không thể, 
- nếu không thì chia đôi. 

Bởi vì việc cắt tỉa cực kỳ mạnh mẽ nên chỉ một phần nhỏ của phạm vi khổng lồ thực sự phải được khám phá.
