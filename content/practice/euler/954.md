[Vấn đề dự án Euler 954](https://projecteuler.net/problem=954) 

##Giải pháp 

**Trả lời:**`736463823`Hãy để một số$n$có chữ số$d_i$ở vị trí thập phân$i$(chữ số có nghĩa nhỏ nhất = vị trí$0$). Giả sử chúng ta trao đổi chữ số$d_i=a$Và$d_j=b$. Số mới trở thành$$n' = n + (b-a)(10^i - 10^j).$$chúng tôi muốn$n'$**không bao giờ** chia hết cho$7$, trong khi$n$bản thân nó cũng không chia hết cho$7$. 

mô-đun làm việc$7$, từ$10^k \bmod 7$là tuần hoàn với chu kì$6$,$$10^k \equiv (1,3,2,6,4,5,\ldots)\pmod 7.$$Đối với phần còn lại của mục tiêu cố định$r=n\bmod 7\neq 0$, hoán đổi giữa các vị trí có dư lượng$x=10^i\bmod 7$Và$y=10^j\bmod 7$bị cấm nếu$$r + (b-a)(x-y)\equiv 0 \pmod 7,$$tương đương$$b \equiv a - r(y-x)^{-1}\pmod 7.$$Như vậy, với mỗi số dư cuối cùng$r\in\{1,\dots,6\}$, chúng ta có thể xây dựng một chữ số-DP: 

- xử lý các chữ số từ trái sang phải, 
- theo dõi mod còn lại hiện tại$7$, 
- theo dõi mod dư chữ số nào$7$đã xuất hiện trong mỗi lớp trong số sáu lớp dư vị vị trí, 
- từ chối bất kỳ chữ số nào có thể tạo ra sự hoán đổi mang lại khả năng chia hết cho$7$, 
- thực thi quy tắc “không có số 0 đứng đầu sau khi hoán đổi”. 

DP này sao chép các kiểm tra: 

-$C(100)=74$-$C(10^4)=3737$theo yêu cầu. 

Triển khai Python sạch:```python
from functools import lru_cache

mods = [pow(10, i, 7) for i in range(13)]

def count_length(L):
    posmods = list(reversed(mods[:L]))  # MSD -> LSD
    total = 0

    for r in range(1, 7):

        # forbidden digit residues lookup
        block = [[None] * 7 for _ in range(7)]

        for x in range(1, 7):
            for y in range(1, 7):
                arr = [0] * 128

                diff = (y - x) % 7
                single = [0] * 7

                if diff:
                    inv = pow(diff, -1, 7)
                    k = (-r * inv) % 7
                    for m in range(7):
                        single[m] = 1 << ((m + k) % 7)

                for mask in range(128):
                    b = 0
                    mm = mask
                    while mm:
                        lsb = mm & -mm
                        m = lsb.bit_length() - 1
                        b |= single[m]
                        mm ^= lsb
                    arr[mask] = b

                block[x][y] = arr

        x0 = posmods[0]

        @lru_cache(None)
        def dp(i, rem, masks, msd_res):
            if i == L:
                return rem == r

            x = posmods[i]

            forbidden = 0
            tmp = masks

            for y in range(1, 7):
                forbidden |= block[x][y][tmp & 127]
                tmp >>= 7

            msd_forbidden = 0
            if i > 0 and (x0 - x) % 7:
                diff = (x0 - x) % 7
                inv = pow(diff, -1, 7)
                k = (-r * inv) % 7
                msd_forbidden = 1 << ((msd_res + k) % 7)

            ans = 0

            for d in range(10):
                if i == 0 and d == 0:
                    continue

                f = forbidden
                if i > 0 and d != 0:
                    f |= msd_forbidden

                dr = d % 7
                if (f >> dr) & 1:
                    continue

                nmasks = masks
                if i > 0:
                    shift = (x - 1) * 7
                    nmasks |= (1 << dr) << shift

                ans += dp(i + 1, (rem * 10 + d) % 7,
                          nmasks, msd_res)

            return ans

        for first_digit in range(1, 10):
            total += dp(1, first_digit % 7, 0,
                        first_digit % 7)

    return total

answer = sum(count_length(L) for L in range(1, 14))
print(answer)
```Việc tính toán cho:$$C(10^{13}) = 736463823.$$**Trả lời: 736463823**
