## Giải pháp 

**Trả lời:**`2009`Cho phép$$T_1=T_2=T_3=1,\qquad  T_n=T_{n-1}+T_{n-2}+T_{n-3}.$$Đây là dãy Tribonacci:$$1,1,1,3,5,9,17,31,57,105,\dots$$Chúng tôi tìm kiếm$124^\text{th}$số nguyên lẻ$m$sao cho **không có số hạng** nào của dãy chia hết cho$m$. 

--- 

# 1. Phân tích toán học 

Chúng tôi chỉ quan tâm đến dãy modulo$m$. 

Xác định vectơ trạng thái$$S_n=(T_n,T_{n+1},T_{n+2}) \pmod m.$$Bởi vì$$T_{n+3}=T_{n+2}+T_{n+1}+T_n,$$trạng thái tiếp theo được xác định hoàn toàn bởi trạng thái hiện tại:$$(a,b,c)\mapsto (b,c,a+b+c \bmod m).$$Do đó dãy modulo$m$là một quá trình trạng thái hữu hạn xác định. 

Vì chỉ có$m^3$modulo ba lần có thể$m$, trình tự cuối cùng phải lặp lại. Trong thực tế, vì phép biến đổi là phép biến đổi khả nghịch theo modulo$m$, dãy số này hoàn toàn tuần hoàn. 

Vì vậy: 

- hoặc một số thuật ngữ trở thành$0 \pmod m$, 
- hoặc chuỗi tuần hoàn mãi mãi mà không bao giờ chạm vào$0$. 

Vì vậy, để kiểm tra một số nguyên lẻ ứng cử viên$m$, chúng tôi chỉ đơn giản tạo ra các giá trị Tribonacci modulo$m$cho đến khi trạng thái lặp lại. 

Nếu chúng ta gặp số hạng 0 trước khi lặp lại thì$m$chia một số Tribonacci. 

Nếu chu trình kết thúc mà không thấy số 0 thì$m$là một trong những con số mong muốn. 

Tuyên bố vấn đề cho chúng ta biết:$$27$$là số lẻ đầu tiên có tính chất này. 

Chúng ta tiếp tục quá trình này cho đến khi tìm được$124^\text{th}$số lẻ như vậy.

#2. Triển khai Python```python
def tribonacci_has_zero_mod(m):
    """
    Return True if some Tribonacci number is divisible by m.
    Return False otherwise.
    """

    # Initial Tribonacci values modulo m
    a = b = c = 1 % m

    seen = set()

    while (a, b, c) not in seen:

        # If any current term is 0 mod m,
        # then m divides a Tribonacci number
        if a == 0 or b == 0 or c == 0:
            return True

        seen.add((a, b, c))

        # Advance recurrence:
        # T_{n+3} = T_n + T_{n+1} + T_{n+2}
        a, b, c = b, c, (a + b + c) % m

    # Cycle closed without seeing 0
    return False

target = 124
count = 0
n = 1

while True:

    if n % 2 == 1:  # odd numbers only

        if not tribonacci_has_zero_mod(n):
            count += 1

            if count == target:
                print(n)
                break

    n += 2
```--- 

#3. Hướng dẫn sử dụng mã 

## Chức năng`tribonacci_has_zero_mod(m)`Chúng tôi làm việc hoàn toàn theo modulo$m$. 

### Khởi tạo```python
a = b = c = 1 % m
```Chúng đại diện cho các thuật ngữ Tribonacci liên tiếp. 

--- 

### Phát hiện sự lặp lại```python
seen = set()
```Vì có hữu hạn nhiều bộ ba modulo$m$, cuối cùng lặp lại ba lần. 

--- 

### Vòng lặp chính```python
while (a, b, c) not in seen:
```Tiếp tục cho đến khi trạng thái quay vòng. 

--- 

### Kiểm tra tính chia hết```python
if a == 0 or b == 0 or c == 0:
    return True
```Nếu có bất kỳ điều khoản nào$0 \pmod m$, sau đó$m$chia số Tribonacci. 

--- 

### Nâng cao khả năng tái phát```python
a, b, c = b, c, (a + b + c) % m
```Điều này thực hiện$$T_{n+3}=T_n+T_{n+1}+T_{n+2}.$$--- 

### Nếu chu kỳ kết thúc```python

```thì số 0 không bao giờ xuất hiện, vì vậy$m$có thuộc tính mong muốn.
