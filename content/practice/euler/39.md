[Vấn đề dự án Euler 39](https://projecteuler.net/problem=39) 

##Giải pháp 

**Trả lời:**`840`Chúng tôi tìm kiếm chu vi$p \le 1000$mang lại **số lượng nghiệm tam giác vuông nguyên lớn nhất**$(a,b,c)$thỏa mãn$$a^2+b^2=c^2,\qquad a+b+c=p$$Ở đâu$a,b,c$là các số nguyên dương. 

## 1. Phân tích toán học 

Một tam giác vuông có độ dài các cạnh nguyên là **bộ ba Pythagore**:$$a^2+b^2=c^2$$Chúng tôi muốn đếm có bao nhiêu bộ ba cho mỗi chu vi$p\le 1000$. 

Vì thứ tự không quan trọng nên giả sử:$$a \le b < c$$Sau đó:$$a+b+c=p$$Thay thế:$$c = p-a-b$$vào phương trình Pythagore:$$a^2+b^2=(p-a-b)^2$$Mở rộng:$$a^2+b^2 = p^2+a^2+b^2-2pa-2pb+2ab$$Hủy bỏ$a^2+b^2$:$$0=p^2-2p(a+b)+2ab$$Sắp xếp lại:$$2ab = 2p(a+b)-p^2$$Đối với chu vi cố định$p$, chúng ta có thể liệt kê một cách hiệu quả các giá trị nguyên của$a,b$và kiểm tra xem$$c=\sqrt{a^2+b^2}$$là tích phân và liệu$$a+b+c=p.$$### Giới hạn tìm kiếm 

Kể từ khi$a \le b < c$,$$a < \frac{p}{3}$$Và$$b < \frac{p-a}{2}$$làm giảm đáng kể không gian tìm kiếm. 

### Ví dụ:$p=120$Vấn đề nêu ba giải pháp:$$(20,48,52)$$

$$(24,45,51)$$

$$(30,40,50)$$Thực vậy:

-$20^2+48^2=52^2$-$24^2+45^2=51^2$-$30^2+40^2=50^2$Vì thế$p=120$có đúng 3 nghiệm.

## 2. Triển khai Python```python
def count_solutions(p):
    """
    Count the number of integer right-triangle solutions
    with perimeter p.
    """
    count = 0

    # Ensure a <= b < c
    for a in range(1, p // 3 + 1):
        for b in range(a, (p - a) // 2 + 1):
            c = p - a - b

            # Check Pythagorean condition
            if a * a + b * b == c * c:
                count += 1

    return count

max_count = 0
best_p = 0

# Test every perimeter up to 1000
for p in range(1, 1001):
    solutions = count_solutions(p)

    if solutions > max_count:
        max_count = solutions
        best_p = p

print(best_p)
```---

## 4. Xác minh lần cuối 

Chu vi tối đa hóa nên: 

- **chẵn**, vì hầu hết ba chu vi Pythagore đều chẵn; 
- có nhiều tổ hợp yếu tố (có tính phân chia cao); 
- có thể là bội số của một số bộ ba nguyên thủy. 

Việc thực hiện tìm kiếm mang lại:$$p = 840$$có **8 nghiệm tam giác vuông nguyên riêng biệt**, mức tối đa cho$p \le 1000$.
