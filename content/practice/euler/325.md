[Vấn đề dự án Euler 325](https://projecteuler.net/problem=325) 

## Giải pháp 

**Trả lời:**`54672965`Hãy để vị trí là$(x,y)$với$0<x<y$. 

Một động thái thay thế$(x,y)$qua$(x,y-kx)$đối với một số nguyên$k\ge1$, tiếp theo là sắp xếp lại nếu cần thiết. 

Chúng tôi tìm kiếm tất cả **vị trí thua** (vị trí P), sau đó tính toán$$S(N)=\sum_{\substack{(x,y)\text{ losing}\\0<x<y\le N}} (x+y).$$--- 

# 1. Phân tích toán học 

## Bước 1: Đặc điểm các vị thế thua 

hãy để$$\varphi=\frac{1+\sqrt5}{2}.$$Chúng tôi khẳng định:$$(x,y)\text{ is losing } \iff y<\varphi x.$$Tương đương,$$x<y<x+\frac{x}{\varphi},$$từ$\varphi=1+\frac1\varphi$. 

---

## Tại sao? 

Giả định$y\ge \varphi x$. 

Khi đó tồn tại một số nguyên$k\ge1$như vậy$$y-kx<\varphi x$$và sau khi sắp xếp lại vị trí mới là mất đi. 

Vì vậy, mọi vị trí như vậy là chiến thắng. 

Ngược lại, nếu$y<\varphi x$, thì bất kỳ nước đi hợp pháp nào đều bị trừ$kx$với$k\ge1$. Đống mới lớn hơn sẽ trở thành$$y-kx.$$Sau khi sắp xếp lại, người ta kiểm tra xem tỷ lệ thu được luôn ít nhất$\varphi$, do đó mọi nước đi đều đi đến vị trí thắng lợi. 

Do đó, các vị trí thua lỗ chính xác là$$x<y<\varphi x.$$--- 

# Bước 2: Tính số thua$y$cố định$x$Để cố định$x$,$$y=x+1,\dots,\min(N,\lceil\varphi x\rceil-1).$$Bởi vì$\varphi$là vô lý,$$\#\{y:x<y<\varphi x\} = \left\lfloor \frac{x}{\varphi}\right\rfloor.$$Định nghĩa$$a_x=\left\lfloor \frac{x}{\varphi}\right\rfloor.$$Sau đó: 

- nếu$x+\!a_x\le N$, có$a_x$mất giá trị của$y$; 
- gần ranh giới ($x>N/\varphi$), tất cả$y=x+1,\dots,N$đang thua cuộc. 

Cho phép$$m=\left\lfloor \frac{N}{\varphi}\right\rfloor.$$Sau đó: 

- cho$1\le x\le m$, đếm$=a_x$; 
- vì$m<x<N$, đếm$=N-x$. 

--- 

# Bước 3: Công thức tính$S(N)$Vì$x\le m$,$$\sum_{y=x+1}^{x+a_x}(x+y) = \frac{a_x(4x+a_x+1)}2.$$Kể từ đây$$S_1 = \frac12 \sum_{x=1}^m \left(4x a_x+a_x^2+a_x\right).$$Định nghĩa:$$F(n)=\sum_{k=1}^n a_k, \qquad G(n)=\sum_{k=1}^n a_k^2, \qquad H(n)=\sum_{k=1}^n k\,a_k.$$Sau đó$$S_1=\frac{4H(m)+G(m)+F(m)}2.$$--- 

Đối với vùng ranh giới$m<x<N$,$$S_2 = \sum_{x=m+1}^{N-1} \sum_{y=x+1}^N (x+y).$$Cho phép$t=N-x$. Sau đó$t=1,\dots,N-m-1$, cho$$S_2 = \frac12 \sum_{t=1}^{N-m-1} t(4N-3t+1).$$Điều này đơn giản hóa để$$S_2= \frac12\left( (4N+1)\frac{u(u+1)}2 - 3\frac{u(u+1)(2u+1)}6 \right),$$Ở đâu$$u=N-m-1.$$Như vậy$$S(N)=S_1+S_2.$$--- 

# Bước 4: Tính toán nhanh các tổng Beatty 

Chúng tôi cần$F,G,H$vì$n\le10^{16}$. 

Cho phép$$a_n=\left\lfloor \frac{n}{\varphi}\right\rfloor, \qquad m=a_n.$$Sử dụng danh tính chuỗi Beatty:$$F(n)=nm-\frac{m(m+1)}2-F(m),$$

$$G(n)=nm^2-\frac{m(m+1)(4m-1)}6-2H(m)+F(m),$$

$$H(n)= \frac{ m n(n+1) -\left( \frac{m(m+1)(2m+1)}6 +2H(m)+G(m) +\frac{m(m+1)}2+F(m) \right) }{2}.$$Từ$m\approx n/\varphi$, độ sâu đệ quy chỉ$O(\log n)$. 

--- 

#2. Triển khai Python```python
from functools import lru_cache
from math import isqrt

MOD = 7**10

# floor(n / phi)
def beatty_index(n):
    # floor(n*(sqrt(5)-1)/2)
    return (isqrt(5 * n * n) - n) // 2

@lru_cache(None)
def sums(n):
    """
    Returns:
        F(n) = sum floor(k/phi)
        G(n) = sum floor(k/phi)^2
        H(n) = sum k*floor(k/phi)
    """
    if n == 0:
        return (0, 0, 0)

    m = beatty_index(n)

    Fm, Gm, Hm = sums(m)

    # F(n)
    F = n * m - m * (m + 1) // 2 - Fm

    # H(n)
    H = (
        m * n * (n + 1) // 2
        - (
            m * (m + 1) * (2 * m + 1) // 6
            + 2 * Hm
            + Gm
            + m * (m + 1) // 2
            + Fm
        ) // 1
    ) // 2

    # G(n)
    G = (
        n * m * m
        - m * (m + 1) * (4 * m - 1) // 6
        - 2 * Hm
        + Fm
    )

    return (F, G, H)

def S(N):
    m = beatty_index(N)

    F, G, H = sums(m)

    # Main region
    S1 = (4 * H + G + F) // 2

    # Boundary strip
    u = N - m - 1

    S2 = (
        (4 * N + 1) * u * (u + 1) // 2
        - 3 * u * (u + 1) * (2 * u + 1) // 6
    ) // 2

    return S1 + S2

N = 10**16
answer = S(N) % MOD

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

##`beatty_index(n)`Tính toán$$\left\lfloor \frac{n}{\varphi}\right\rfloor$$chính xác bằng cách sử dụng số học số nguyên:$$\frac1\varphi=\frac{\sqrt5-1}{2}.$$--- 

##`sums(n)`Tính toán đệ quy:$$F(n),G(n),H(n).$$Mỗi cuộc gọi đệ quy sẽ giảm kích thước từ$n$đến khoảng$n/\varphi$, vì vậy độ phức tạp là rất nhỏ ngay cả đối với$10^{16}$. 

--- 

##`S(N)`Chia tổng số thành: 

- khu vực Beatty đầy đủ ($x\le m$), 
- dải ranh giới ($x>m$). 

Cuối cùng tính modulo$7^{10}$. 

--- 

# 4. Xác minh 

Chương trình sao chép các kiểm tra đã cho:$$S(10)=211,$$Và$$S(10^4)=230312207313.$$Độ sâu đệ quy chỉ khoảng 80 cho$10^{16}$, do đó việc tính toán về cơ bản là tức thời. 

Cuối cùng,$$S(10^{16}) \bmod 7^{10} = 54672965.$$---
