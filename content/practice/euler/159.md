## Giải pháp 

**Trả lời:**`14489159`Cho phép$drs(n)$biểu thị gốc kỹ thuật số của$n$. 

Một biểu mẫu đóng hữu ích là:$$drs(n)= \begin{cases} 0 & n=0\\ 1+((n-1)\bmod 9) & n>0 \end{cases}$$Vậy với mọi số nguyên dương,$drs(n)\in\{1,\dots,9\}$, Và:

-$drs(24)=2+4=6$-$drs(467)=4+6+7=17\to1+7=8$Chúng tôi xác định:$$mdrs(n)=\max\{\text{digital root sums over all factorizations of } n\}$$bao gồm cả hệ số tầm thường$n$chính nó. 

Ví dụ:$$24 = 3\times 8$$cho$$drs(3)+drs(8)=3+8=11$$và không có hệ số nào tốt hơn, vì vậy:$$mdrs(24)=11$$--- 

# Thông tin chi tiết quan trọng 

Giả sử chúng ta chia tay$n$BẰNG:$$n=d\cdot \frac{n}{d}$$Khi đó bất kỳ hệ số tối ưu nào của$n$có thể được xem là: 

- chọn một ước số$d\ge2$, 
- sau đó phân tích nhân tử một cách tối ưu$n/d$. 

Vì thế:$$mdrs(n)=\max\left(drs(n),\ \max_{d\mid n,\ 2\le d<n}\left(drs(d)+mdrs\left(\frac{n}{d}\right)\right)\right)$$Đây là một sự lặp lại lập trình/sàng động cổ điển. 

Bởi vì mọi thuật ngữ đệ quy đều bao gồm một số nhỏ hơn$n/d < n$, chúng ta có thể tính các giá trị theo thứ tự tăng dần. 

--- 

# Chiến lược sàng hiệu quả 

Chúng tôi cần:$$\sum_{n=2}^{999999} mdrs(n)$$Một nhân tử đơn giản cho mọi$n$sẽ là quá chậm. 

Thay vào đó: 

1. Tính toán trước$drs(n)$cho tất cả$n<10^6$. 
2. Khởi tạo:$$mdrs(n)=drs(n)$$1. Với mọi ước số$d$, truyền bá các bản cập nhật lên bội số: 

Nếu$n=d\cdot q$, sau đó:$$mdrs(n)\ge drs(d)+mdrs(q)$$Vì thế:```python
for d in 2..N:
    for q in 2..N/d:
        n = d*q
        mdrs[n] = max(mdrs[n], drs[d] + mdrs[q])
```Cái này hoạt động giống như một cái sàng chia và chạy đủ nhanh để$10^6$. 

--- 

# Triển khai Python```python
LIMIT = 10**6

# ---------------------------------------------------------
# Compute digital roots
# drs(n) = 1 + ((n - 1) % 9) for n > 0
# ---------------------------------------------------------

drs = [0] * LIMIT

for n in range(1, LIMIT):
    drs[n] = 1 + (n - 1) % 9

# ---------------------------------------------------------
# Initialize mdrs with the trivial factorization: n itself
# ---------------------------------------------------------

mdrs = drs[:]

# ---------------------------------------------------------
# Dynamic programming sieve
#
# If n = d * q, then:
# mdrs[n] >= drs[d] + mdrs[q]
# ---------------------------------------------------------

for d in range(2, LIMIT):
    dd = drs[d]

    max_q = (LIMIT - 1) // d

    for q in range(2, max_q + 1):
        n = d * q

        candidate = dd + mdrs[q]

        if candidate > mdrs[n]:
            mdrs[n] = candidate

# ---------------------------------------------------------
# Sum all mdrs values for 2 <= n < 10^6
# ---------------------------------------------------------

answer = sum(mdrs[2:])

print(answer)
```--- 

# Hướng dẫn về mã 

## Bảng gốc kỹ thuật số```python
drs[n] = 1 + (n - 1) % 9
```Điều này tính toán gốc kỹ thuật số trong thời gian không đổi. 

Ví dụ: 

-$drs(8)=8$-$drs(24)=6$-$drs(999)=9$--- 

## Đang khởi tạo`mdrs`

```python
mdrs = drs[:]
```Mọi số đều có ít nhất hệ số tầm thường:$$n$$vì vậy ban đầu:$$mdrs(n)\ge drs(n)$$--- 

## Số chia DP 

Với mỗi số chia$d$, chúng tôi lặp lại tất cả các bội số:```python
n = d * q
candidate = drs[d] + mdrs[q]
```Điều này tương ứng với việc lấy:$$n=d\times q$$và sử dụng hệ số _best_ của$q$. 

Bởi vì$q<n$, giá trị của nó đã được biết trước.

# Xác minh ví dụ$n=24$Cuối cùng, sàng xem xét: 

-$24=2\times12$-$24=3\times8$-$24=4\times6$Tốt nhất là:$$drs(3)+mdrs(8)=3+8=11$$Vì thế:$$mdrs(24)=11$$phù hợp với phát biểu vấn đề.
