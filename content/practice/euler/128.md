## Giải pháp 

**Trả lời:**`14516824220`Hãy xếp các viên gạch thành các vòng lục giác đồng tâm. 

Nhẫn$r$(với$r\ge 1$) chứa$6r$ô và ô cuối cùng trong vòng$r$là$$1+\sum_{k=1}^{r}6k =1+3r(r+1).$$Chìa khóa để giải quyết vấn đề là hầu hết tất cả các ô đều có quá nhiều điểm khác biệt tổng hợp của các ô lân cận mà không thể đạt được.$\operatorname{PD}(n)=3$. Trên thực tế, có thể chứng minh rằng chỉ có hai viên gạch trên mỗi vòng có thể hoạt động được.

# 1. Phân tích toán học 

Đối với một viên gạch$n$, định nghĩa$\operatorname{PD}(n)$là số giá trị nguyên tố trong số sáu khác biệt tuyệt đối giữa$n$và các nước láng giềng của nó. 

Vấn đề nói rằng giá trị tối đa có thể là$3$. 

Quan sát đáng chú ý là: 

- Nếu$\operatorname{PD}(n)=3$, sau đó$n$phải nằm ở vị trí góc đặc biệt. 
- Cụ thể chỉ có 2 thí sinh sau vào vòng trong$r$có thể làm việc:$$A_r = 3r(r-1)+2$$(viên gạch đầu tiên của chiếc nhẫn$r$)

Và$$B_r = 3r(r+1)+1$$(viên gạch cuối cùng của chiếc nhẫn$r$). 

Bây giờ chúng ta rút ra các điều kiện cơ bản cho những điều này. 

--- 

## Thí sinh 1: viên gạch đầu tiên của vòng tròn 

Hãy xem xét$$A_r = 3r(r-1)+2.$$Sáu điểm khác biệt hàng xóm của nó đơn giản hóa thành$$1,\quad 6r-1,\quad 6r+1,\quad 12r-7,$$cộng với hai giá trị tổng hợp/không phải số nguyên tố rõ ràng. 

Như vậy$$\operatorname{PD}(A_r)=3$$nếu cả ba số$$6r-1,\qquad 6r+1,\qquad 12r-7$$là nguyên tố. 

--- 

## Thí sinh 2: viên gạch cuối cùng của vòng tròn 

Bây giờ hãy xem xét$$B_r = 3r(r+1)+1.$$Sự khác biệt hàng xóm có liên quan của nó giảm xuống$$6r-1,\quad 6r+5,\quad 12r+5.$$Kể từ đây$$\operatorname{PD}(B_r)=3$$nếu$$6r-1,\qquad 6r+5,\qquad 12r+5$$đều là số nguyên tố. 

--- 

## Tạo trình tự 

Do đó, trình tự bao gồm: 

-$1$,
- tất cả$A_r$thỏa mãn bộ ba số nguyên tố đầu tiên, 
- tất cả$B_r$thỏa mãn bộ số nguyên tố thứ hai. 

Thuật ngữ thứ 10 được đưa ra là$271$, cung cấp một kiểm tra hữu ích. 

Bởi vì chúng ta chỉ cần số hạng thứ 2000 nên việc tìm kiếm trực tiếp trên các vành với kiểm tra tính nguyên tố nhanh là đủ dễ dàng.

#2. Triển khai Python```python
from math import isqrt

def is_prime(n):
    """Deterministic primality test for positive integers."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    if n % 3 == 0:
        return n == 3

    limit = isqrt(n)
    f = 5
    step = 2

    while f <= limit:
        if n % f == 0:
            return False
        f += step
        step = 6 - step

    return True

def solve(target):
    # The sequence starts with tile 1
    values = [1]

    r = 1

    while len(values) < target:

        # First tile in ring r
        a = 3 * r * (r - 1) + 2

        if (
            is_prime(6 * r - 1)
            and is_prime(6 * r + 1)
            and is_prime(12 * r - 7)
        ):
            values.append(a)

        # Last tile in ring r
        b = 3 * r * (r + 1) + 1

        if (
            is_prime(6 * r - 1)
            and is_prime(6 * r + 5)
            and is_prime(12 * r + 5)
        ):
            values.append(b)

        r += 1

    values.sort()
    return values[target - 1]

answer = solve(2000)
print(answer)
