## Giải pháp 

**Trả lời:**`209110240768`Chúng tôi tìm kiếm tất cả các chuỗi nhị phân có độ dài tuần hoàn$2^N$sao cho mỗi từ nhị phân có độ dài$N$xuất hiện đúng một lần dưới dạng một dãy con liên tiếp theo chiều kim đồng hồ. 

Đây chính xác là **chu trình de Bruijn** nhị phân của trật tự$N$. 

Vì$N=5$, chúng ta phải tính tổng của tất cả các bảng mã riêng biệt được mô tả trong câu lệnh bài toán. 

--- 

# Phân tích toán học 

Một chu trình bậc nhị phân de Bruijn$N$là một chuỗi nhị phân tuần hoàn trong đó mọi khả năng có thể$N$chuỗi -bit xảy ra đúng một lần. 

có$2^N$các chuỗi con như vậy, do đó độ dài chu trình phải là$2^N$. 

--- 

## 1. Giải thích đồ thị 

Định nghĩa đồ thị có hướng: 

- Đỉnh = tất cả các chuỗi nhị phân có độ dài$N-1$- Các cạnh có hướng = tất cả các chuỗi nhị phân có độ dài$N$Một cạnh$$b_1b_2\dots b_N$$đi từ$$b_1b_2\dots b_{N-1}$$ĐẾN$$b_2b_3\dots b_N$$Mỗi đỉnh có: 

- bằng cấp ngoài$2$- bằng cấp$2$Chu trình de Bruijn tương ứng chính xác với chu trình Euler trong biểu đồ này. 

--- 

## 2. Biểu diễn chuẩn mực 

Sự cố loại bỏ các bản sao luân phiên bằng cách yêu cầu trình tự bắt đầu bằng$$00000$$Vì vậy, chúng ta có thể sửa nút bắt đầu thành tất cả các số 0 và tạo ra tất cả các chu trình Euler bắt đầu từ đó. 

Nếu chuỗi tuần hoàn được tạo ra là$$a_0a_1\dots a_{31}$$thì số nguyên được mã hóa là$$\sum_{i=0}^{31} a_i 2^{31-i}$$--- 

##3. Xây dựng DFS 

Duy trì: 

- hiện tại$(N-1)$hậu tố -bit 
- tập hợp các lượt truy cập$N$-chuỗi bit 

Ban đầu: 

- đã truy cập chứa$00000$- dãy bắt đầu bằng năm số không 

Ở mỗi bước: 

- nối thêm bit$0$hoặc$1$- hình thành tiếp theo$N$-từ bit 
- chỉ tiếp tục nếu từ đó chưa xuất hiện trước đó 

Khi tất cả$2^N$các từ đã được truy cập, chúng tôi có được một chu kỳ hợp lệ. 

Vì$N=5$, việc tìm kiếm này hoàn toàn khả thi. 

--- 

#Triển khai Python```python
from collections import defaultdict

def debruijn_sum(n):
    target = 1 << n                 # total N-bit strings
    mask = (1 << (n - 1)) - 1      # keeps last N-1 bits

    visited = {0}                  # start with 000...0 already used
    seq = [0] * n                  # initial sequence = N zeros

    total = 0

    def dfs(node):
        nonlocal total

        # If every N-bit word has appeared exactly once,
        # we have a complete de Bruijn cycle.
        if len(visited) == target:
            bits = seq[:target]
            value = int("".join(map(str, bits)), 2)
            total += value
            return

        suffix = node & mask

        # Try appending 0 or 1
        for bit in (0, 1):
            nxt = (suffix << 1) | bit

            if nxt not in visited:
                visited.add(nxt)
                seq.append(bit)

                dfs(nxt)

                seq.pop()
                visited.remove(nxt)

    dfs(0)
    return total

# Verify the example
print(debruijn_sum(3))   # should be 52

# Solve the problem
print(debruijn_sum(5))
```---

```Chúng ta bắt đầu với từ hoàn toàn bằng 0 đã được đưa vào.

# bước DFS 

Giả sử hậu tố hiện tại là$(N-1)$-số bit`suffix`. 

Bit bổ sung`bit`tạo ra:```python
nxt = (suffix << 1) | bit
```cái nào tiếp theo$N$-chữ hơi. 

Nếu nó chưa xuất hiện thì chúng ta tiếp tục đệ quy.
