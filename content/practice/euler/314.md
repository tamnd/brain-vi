[Vấn đề dự án Euler 314](https://projecteuler.net/problem=314) 

## Giải pháp 

**Trả lời:**`132.52756426`Đặt hình vuông có tâm ở gốc tọa độ, do đó vùng có sẵn là$$-250 \le x,y \le 250.$$Bởi vì bức tường tối ưu là đối xứng theo cả trục và lồi nên chỉ cần nghiên cứu phép nối cung phần tư thứ nhất là đủ.$$(0,250)\quad\text{to}\quad(250,0).$$Nếu ranh giới một phần tư này có đóng góp diện tích$A_q$và chiều dài$L_q$, thì hình đầy đủ có$$A = 4A_q,\qquad L = 4L_q,$$tối đa hóa$A/L$tương đương với việc tối đa hóa$$\frac{A_q}{L_q}.$$--- 

# 1. Phân tích toán học 

Đối với một chuỗi đa giác đơn điệu$$P_0=(0,250),\,P_1,\dots,P_k=(250,0),$$với sự gia tăng$x$-tọa độ và giảm dần$y$-tọa độ: 

- diện tích một phần tư được lấy từ hình thang,$$A_q = \sum_i \frac{y_i+y_{i+1}}2 (x_{i+1}-x_i),$$- một phần tư chu vi là$$L_q = \sum_i \sqrt{(x_{i+1}-x_i)^2+(y_{i+1}-y_i)^2}.$$Chúng tôi muốn tối đa hóa$$\frac{A_q}{L_q}.$$--- 

## phép biến đổi Dinkelbach 

Một thủ thuật tiêu chuẩn để tối ưu hóa phân đoạn là: 

tối đa hóa$$\frac{A_q}{L_q}$$iff cho giá trị tối ưu$r^{*}$,$$\max (A_q-r^{*}L_q)=0.$$Vì vậy đối với một cố định$r$, xác định trọng số cạnh$$w(P_i,P_{i+1}) = \frac{y_i+y_{i+1}}2 (x_{i+1}-x_i) - r\sqrt{(x_{i+1}-x_i)^2+(y_{i+1}-y_i)^2}.$$Bây giờ bài toán trở thành một chương trình động có đường đi dài nhất trên DAG gồm các điểm mạng trong góc phần tư thứ nhất. 

Tìm kiếm nhị phân bật$r$: 

- nếu giá trị tốt nhất của$A_q-rL_q$là dương thì$r$quá nhỏ, 
- nếu âm tính,$r$là quá lớn. 

Gốc duy nhất là tỷ lệ tối ưu.

#2. Triển khai Python```python
from math import hypot

N = 250

# all lattice points in the first quadrant
pts = [(x, y) for x in range(N + 1)
               for y in range(N + 1)]

# monotone ordering
pts.sort()

# ------------------------------------------------------------
# For a given r, compute:
#
#   best possible value of A_q - r * L_q
#
# using dynamic programming.
# ------------------------------------------------------------
def best_value(r):

    # dp[(x,y)] = best score reaching (x,y)
    dp = {(0, 250): 0.0}

    for x2 in range(N + 1):
        for y2 in range(N + 1):

            if (x2, y2) == (0, 250):
                continue

            best = -1e100

            # previous point must satisfy monotonicity:
            # x1 <= x2 and y1 >= y2
            for x1 in range(x2 + 1):
                for y1 in range(y2, N + 1):

                    if (x1, y1) not in dp:
                        continue

                    if x1 == x2 and y1 == y2:
                        continue

                    dx = x2 - x1
                    dy = y1 - y2

                    if dx < 0 or dy < 0:
                        continue

                    area = (y1 + y2) * dx / 2.0
                    length = hypot(dx, dy)

                    val = dp[(x1, y1)] + area - r * length

                    if val > best:
                        best = val

            if best > -1e90:
                dp[(x2, y2)] = best

    return dp[(250, 0)]

# ------------------------------------------------------------
# Binary search for the optimal ratio
# ------------------------------------------------------------
lo, hi = 100.0, 150.0

for _ in range(60):
    mid = (lo + hi) / 2.0

    if best_value(mid) > 0:
        lo = mid
    else:
        hi = mid

answer = (lo + hi) / 2.0

print("{:.8f}".format(answer))
```--- 

#3. Hướng dẫn sử dụng mã 

### Xây dựng mạng lưới```python
pts = [(x, y) ...]
```tạo ra tất cả các điểm mạng số nguyên trong$251\times251$lưới góc phần tư thứ nhất. 

--- 

### Trạng thái lập trình động```python
dp[(x,y)]
```lưu trữ giá trị tốt nhất có thể của$$A_q-rL_q$$cho một chuỗi đơn điệu kết thúc tại$(x,y)$. 

--- 

### Chuyển tiếp 

Đối với mọi tiền thân hợp lệ$(x_1,y_1)\to(x_2,y_2)$:```python
area = (y1 + y2) * dx / 2.0
length = hypot(dx, dy)
```Điều này tính toán: 

- đóng góp diện tích hình thang, 
- Độ dài cạnh Euclide. 

Sau đó:```python
val = previous + area - r * length
```thực hiện mục tiêu tối ưu hóa được chuyển đổi. 

--- 

### Tìm kiếm nhị phân 

Tỷ lệ tối ưu$r^{*}$thỏa mãn$$\max(A_q-r^{*}L_q)=0.$$Vì vậy, chúng tôi tìm kiếm nhị phân gốc.
