[Vấn đề dự án Euler 379](https://projecteuler.net/problem=379) 

##Giải pháp 

**Trả lời:**`132314136838185`Cho phép$$f(n)=\#\{(x,y):x,y\in \mathbb Z_{>0},\ x\le y,\ \operatorname{lcm}(x,y)=n\}.$$chúng tôi muốn$$g(N)=\sum_{n\le N} f(n),$$và đặc biệt$g(10^{12})$. 

--- 

## Bước 1: Đếm các cặp có LCM cố định 

Số cặp đầu tiên **đã đặt hàng**$(x,y)$như vậy$$\operatorname{lcm}(x,y)=n.$$Viết$$n=\prod p_i^{a_i}.$$Đối với mỗi số nguyên tố$p^a$, nếu số mũ của$p$TRONG$x,y$là$(u,v)$, thì chúng ta cần$$\max(u,v)=a.$$Số cặp số mũ là$$(a+1)^2-a^2 = 2a+1.$$Do đó số cặp có thứ tự là$$\prod (2a_i+1)=d(n^2),$$Ở đâu$d(m)$là hàm đếm số chia. 

Bây giờ chuyển đổi thành các cặp không có thứ tự với$x\le y$. 

Cặp có thứ tự đối xứng duy nhất là$(n,n)$, Vì thế:$$f(n)=\frac{d(n^2)+1}{2}.$$Kể từ đây$$g(N)=\sum_{n\le N}\frac{d(n^2)+1}{2} =\frac12\sum_{n\le N}d(n^2)+\frac N2.$$Vì vậy, vấn đề giảm xuống tính toán$$S(N)=\sum_{n\le N} d(n^2).$$--- 

## Bước 2: Một danh tính hữu ích cho$d(n^2)$Một nhận dạng tiêu chuẩn là$$d(n^2)=\sum_{d\mid n}2^{\omega(d)},$$Ở đâu$\omega(d)$là số các thừa số nguyên tố phân biệt của$d$. 

Thật vậy, đối với$n=p^a$,$$d(p^{2a})=2a+1,$$trong khi$$\sum_{k=0}^{a}2^{\omega(p^k)} =1+2a.$$Như vậy$$S(N)=\sum_{n\le N}\sum_{d\mid n}2^{\omega(d)} =\sum_{d\le N}2^{\omega(d)}\Bigl\lfloor\frac Nd\Bigr\rfloor.$$Đây là hình thức tóm tắt quan trọng. 

--- 

## Bước 3: Đánh giá nhanh hơn 

Sử dụng dãy Dirichlet$$\sum_{n\ge1}\frac{d(n^2)}{n^s} =\frac{\zeta(s)^3}{\zeta(2s)},$$người ta rút ra được danh tính tích chập$$d(n^2)=\sum_{k^2\mid n}\mu(k)\,d_3\!\left(\frac{n}{k^2}\right),$$Ở đâu:

-$\mu$là hàm Mobius, 
-$d_3(m)$đếm đại diện$abc=m$. 

Vì thế$$S(N) = \sum_{k\le \sqrt N} \mu(k)\, \sum_{m\le N/k^2} d_3(m).$$Hàm tổng hợp của$d_3$có thể được đánh giá ở$O(N^{2/3})$-độ phức tạp kiểu sử dụng phân tách hyperbol. 

Điều đó làm cho$N=10^{12}$khả thi về mặt tính toán. 

--- 

## Triển khai Python```python
import math
from sympy import mobius

N = 10**12

def D3_sum(n):
    """
    Returns:
        sum_{k <= n} d3(k)

    using a 3-dimensional hyperbola decomposition.
    """

    total = 0
    c = int(round(n ** (1/3)))

    while (c + 1) ** 3 <= n:
        c += 1
    while c ** 3 > n:
        c -= 1

    for a in range(1, c + 1):
        s = math.isqrt(n // a)

        total += n // (a * a)

        total += 2 * sum((n // (a * b)) for b in range(a + 1, s + 1))

        total -= s * s

    total += c ** 3

    return total

S = 0

root = math.isqrt(N)

for k in range(1, root + 1):
    S += mobius(k) * D3_sum(N // (k * k))

g = (S + N) // 2

print(g)
```--- 

## Hướng dẫn về mã 

###`D3_sum(n)`Tính toán$$\sum_{m\le n} d_3(m).$$Từ$d_3(m)$đếm ba lần$(a,b,c)$với$abc=m$, hàm tổng hợp đếm ba lần thỏa mãn$$abc\le n.$$Mã sử ​​dụng phân tách hyperbola đối xứng để đếm chúng một cách hiệu quả. 

--- 

### Vòng lặp đảo ngược Möbius```python
for k in range(1, root + 1):
    S += mobius(k) * D3_sum(N // (k * k))
```Điều này thực hiện$$S(N)=\sum_{k\le \sqrt N}\mu(k)\sum_{m\le N/k^2} d_3(m).$$--- 

### Bước cuối cùng 

Kể từ khi$$g(N)=\frac{S(N)+N}{2},$$câu trả lời cuối cùng là:```python
g = (S + N) // 2
```---
