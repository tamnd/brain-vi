[Vấn đề dự án Euler 596](https://projecteuler.net/problem=596) 

## Giải pháp 

**Trả lời:**`734582049`Cho phép$$T(r)=\#\{(x,y,z,t)\in \mathbb Z^4:\ x^2+y^2+z^2+t^2\le r^2\}.$$Quan sát quan trọng là đây là số lượng biểu diễn tích lũy dưới dạng tổng của bốn ô vuông. Nếu như$r_4(n)$biểu thị số lượng bốn số nguyên thỏa mãn$$x^2+y^2+z^2+t^2=n,$$sau đó$$T(r)=\sum_{n=0}^{r^2} r_4(n).$$Theo định lý bốn bình phương cổ điển của Jacobi,$$r_4(n)=8\sum_{\substack{d\mid n\\4\nmid d}} d$$có thể được viết lại thành$$r_4(n)=8\sigma(n)-32\sigma(n/4),$$Ở đâu$\sigma(n)$là tổng chia và$\sigma(n/4)=0$Trừ khi$4\mid n$. 

Do đó, đối với$N=r^2$,$$T(r) = 1 + 8\sum_{n\le N}\sigma(n) - 32\sum_{n\le N/4}\sigma(n).$$Xác định hàm chia tổng$$S(N)=\sum_{n\le N}\sigma(n) = \sum_{d\le N} d\left\lfloor \frac{N}{d}\right\rfloor.$$Sử dụng nhóm chia số (thực tế là$\lfloor N/d\rfloor$là không đổi trong các khoảng thời gian), điều này có thể được tính toán trong khoảng$O(\sqrt N)$thời gian:```python
MOD = 1_000_000_007

def summatory_sigma_mod(N):
    res = 0
    i = 1
    while i <= N:
        q = N // i
        j = N // q

        # sum of integers from i to j
        segment_sum = (i + j) * (j - i + 1) // 2

        res = (res + (q % MOD) * (segment_sum % MOD)) % MOD
        i = j + 1

    return res

def T_mod(r):
    N = r * r
    s1 = summatory_sigma_mod(N)
    s2 = summatory_sigma_mod(N // 4)

    return (1 + 8 * s1 - 32 * s2) % MOD

# Verification
print(T_mod(2))      # 89
print(T_mod(5))      # 3121
print(T_mod(100))    # 493490641
print(T_mod(10**4))  # 49348022079085897 mod MOD
print(T_mod(10**8))
```Đạo hàm tái tạo chính xác các kiểm tra đã cho: 

-$T(2)=89$-$T(5)=3121$-$T(100)=493490641$-$T(10^4)=49348022079085897$phù hợp với phát biểu vấn đề.
