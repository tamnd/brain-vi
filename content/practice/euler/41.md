## Giải pháp 

**Trả lời:**`7652413`## 1. Phân tích toán học 

Chúng tôi muốn **số nguyên tố pandigital lớn nhất**, trong đó một$n$-số pandigital sử dụng mỗi chữ số$1$ĐẾN$n$đúng một lần. 

Ví dụ:$$2143$$là$4$-chữ số pandigital và số nguyên tố. 

Ý tưởng ngây thơ là: 

- Tạo tất cả các số pandigit, 
- Kiểm tra tính nguyên sơ, 
- Lấy tối đa. 

Nhưng chúng ta có thể làm tốt hơn nhiều bằng cách sử dụng lý thuyết số. 

### Thông tin quan trọng 1: Chia hết cho 3 

Một số có thể chia hết cho$3$nếu tổng các chữ số của nó chia hết cho$3$. 

Đối với một$n$-số pandigit có tổng các chữ số là:$$1+2+\cdots+n=\frac{n(n+1)}{2}$$Hãy kiểm tra giá trị của$n$:$$n=9:\quad \frac{9\cdot10}{2}=45$$Chia cho$3$, do đó **mọi số pandigit có 9 chữ số đều chia hết cho 3** → không thể là số nguyên tố.$$n=8:\quad \frac{8\cdot9}{2}=36$$Cũng chia hết cho$3$→ **mọi số pandigital có 8 chữ số đều là hợp số**.$$n=7:\quad \frac{7\cdot8}{2}=28$$Không chia hết cho$3$, do đó, số nguyên tố toàn số có 7 chữ số **có thể tồn tại**. 

Do đó, số nguyên tố toàn số lớn nhất phải có **7 chữ số hoặc nhỏ hơn**. 

Ta chỉ cần tìm trong các hoán vị của:$$1,2,3,4,5,6,7$$### Thông tin quan trọng 2: Tìm kiếm theo thứ tự giảm dần 

Chúng tôi muốn số nguyên tố **lớn nhất** như vậy. 

Thay vì tạo ra tất cả các số pandigital và lấy giá trị tối đa, hãy tạo các hoán vị theo **thứ tự từ điển giảm dần** và dừng ở số nguyên tố đầu tiên được tìm thấy. 

Điều này đảm bảo sự tối ưu. 

### Thông tin chuyên sâu chính 3: Kiểm tra tính nguyên thủy nhanh 

Để kiểm tra xem một số$n$là số nguyên tố: 

- Từ chối$n < 2$, 
- Từ chối số chẵn, 
- Chỉ thử các ước số tối đa:$$\sqrt{n}$$bởi vì nếu$n = ab$, tối đa phải có một thừa số$\sqrt{n}$. 

Vì vậy, đối với mỗi ứng cử viên, hãy kiểm tra khả năng chia hết cho các số nguyên lẻ tối đa:$$\lfloor \sqrt{n} \rfloor$$Vì chỉ có:$$7! = 5040$$Hoán vị 7 chữ số, lực lượng vũ phu là rất nhỏ.

## 2. Triển khai Python```python
from itertools import permutations
import math

def is_prime(n):
    """Return True if n is prime, otherwise False."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    limit = int(math.isqrt(n))

    # Check odd divisors only
    for d in range(3, limit + 1, 2):
        if n % d == 0:
            return False

    return True

def largest_pandigital_prime():
    # Try n from largest to smallest
    for n in range(9, 0, -1):

        # Skip digit lengths whose digit sum is divisible by 3
        digit_sum = n * (n + 1) // 2
        if digit_sum % 3 == 0:
            continue

        digits = ''.join(str(i) for i in range(n, 0, -1))

        # Generate permutations in descending order
        for perm in permutations(digits):
            number = int(''.join(perm))

            if is_prime(number):
                return number

answer = largest_pandigital_prime()
print(answer)
```---
