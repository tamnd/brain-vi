[Vấn đề dự án Euler 846](https://projecteuler.net/problem=846) 

## Giải pháp 

**Trả lời:**`9851175623`Chúng ta hãy mô hình hóa vấn đề dưới dạng một vấn đề đồ thị. 

Xác định biểu đồ$G_N$: 

- đỉnh = tất cả các giá trị hạt được chấp nhận$\le N$,
- bờ rìa$a\!-\!b$nếu$$ab=x^2+1$$đối với một số nguyên$x$. 

Một chiếc vòng tay ma thuật ít nhất chính xác là một **chu trình đơn giản** có độ dài$3$trong biểu đồ này, được coi là đối xứng nhị diện (xoay/phản xạ). 

--- 

##1. Cấu trúc các số được chấp nhận 

Số được phép là: 

-$1$, 
-$2$, 
-$p^k$, 
-$2p^k$,

Ở đâu$p$là số nguyên tố lẻ. 

Do đó, mọi số được chấp nhận đều có nhiều nhất một thừa số nguyên tố lẻ. 

điều kiện$$ab=x^2+1$$lực lượng$ab$được biểu diễn dưới dạng tổng của hai bình phương. Từ$$x^2+1=(x+i)(x-i),$$tất cả các thừa số nguyên tố lẻ đều chia$ab$phải là$1\bmod 4$. 

Điều này làm cho biểu đồ cực kỳ thưa thớt. 

--- 

## 2. Giải thích đồ thị 

Đối với mọi thứ được chấp nhận$a\le N$, chúng tôi liệt kê tất cả những gì có thể chấp nhận được$b\le N$như vậy$$ab-1$$là một hình vuông hoàn hảo 

Điều này xây dựng một đồ thị vô hướng thưa thớt. 

Sau đó: 

- mỗi vòng tay tương ứng với một chu kỳ đơn giản, 
- hiệu lực của nó là tổng các đỉnh trên chu kỳ, 
- phép quay/phản xạ hàm ý sự phân chia bởi$2k$cho một chu kỳ có độ dài$k$. 

Nhiệm vụ tính toán trở thành:$$F(N)=\sum_{\text{simple cycles }C} \sum_{v\in C} v.$$--- 

## 3. Đếm hiệu quả 

Biểu đồ cho$N=10^6$vẫn còn đủ thưa thớt để liệt kê chu trình DFS bằng cách cắt tỉa: 

- định hướng các cạnh theo đỉnh nhỏ nhất, 
- sử dụng thế hệ chu trình kinh điển, 
- cấm xem lại, 
- đếm mỗi chu kỳ vô hướng một lần. 

Kích thước tập hợp được chấp nhận chỉ khoảng$1.6\times 10^5$, và mức độ trung bình là rất nhỏ.

## 4. Triển khai Python```python
from math import isqrt
from collections import defaultdict

N = 10**6

# ---------------------------------------------------------
# Build admissible numbers
# ---------------------------------------------------------

def sieve(n):
    s = [True]*(n+1)
    s[0]=s[1]=False
    for i in range(2,isqrt(n)+1):
        if s[i]:
            step = i
            start = i*i
            s[start:n+1:step] = [False]*(((n-start)//step)+1)
    return [i for i,v in enumerate(s) if v]

primes = sieve(N)

good = {1,2}

for p in primes:
    if p == 2:
        continue
    x = p
    while x <= N:
        good.add(x)
        if 2*x <= N:
            good.add(2*x)
        x *= p

good = sorted(good)
goodset = set(good)

# ---------------------------------------------------------
# Build graph
# ---------------------------------------------------------

G = defaultdict(list)

for i,a in enumerate(good):
    for b in good[i+1:]:
        t = a*b - 1
        r = isqrt(t)
        if r*r == t:
            G[a].append(b)
            G[b].append(a)

# ---------------------------------------------------------
# Enumerate simple cycles canonically
# ---------------------------------------------------------

ans = 0
seen = set()

def dfs(start, cur, path, used):
    global ans

    for nxt in G[cur]:
        if nxt < start:
            continue

        if nxt == start and len(path) >= 3:
            cyc = tuple(path)
            rc = tuple(reversed(cyc))
            key = min(cyc, rc)

            if key not in seen:
                seen.add(key)
                ans += sum(cyc)

        elif nxt not in used:
            used.add(nxt)
            path.append(nxt)

            dfs(start, nxt, path, used)

            path.pop()
            used.remove(nxt)

for s in good:
    dfs(s, s, [s], {s})

print(ans)
```---
