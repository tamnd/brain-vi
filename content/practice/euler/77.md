Đây là một vấn đề **phân vùng số nguyên** cổ điển, ngoại trừ các phần được phép chỉ là số nguyên tố.

# Phân tích toán học 

hãy để$f(n)$biểu thị số cách viết$n$dưới dạng tổng của các số nguyên tố, trong đó thứ tự **không** quan trọng. 

Ví dụ, đối với$10$:$$\begin{aligned} 10 &= 7+3\\ &=5+5\\ &=5+3+2\\ &=3+3+2+2\\ &=2+2+2+2+2 \end{aligned}$$Vì thế$f(10)=5$.

## Thông tin chi tiết quan trọng: lập trình động đổi tiền xu 

Bài toán này có cấu trúc giống với bài toán “đổi tiền xu” cổ điển. 

Giả sử các số nguyên tố có sẵn là$$2,3,5,7,11,\dots$$Chúng tôi muốn số lượng các khoản tiền không có thứ tự tạo ra$n$. 

Định nghĩa:$$dp[k]$$là số cách để hình thành tổng$k$. 

Ban đầu:$$dp[0]=1$$bởi vì có chính xác một cách để tạo ra số 0: không chọn gì cả. 

Sau đó với mỗi số nguyên tố$p$, cập nhật:$$dp[k] \mathrel{+}= dp[k-p]$$cho tất cả$k\ge p$. 

Tại sao điều này làm việc? 

- Khi xử lý nguyên tố$p$, 
- mọi cách để thực hiện$k-p$- trở thành một cách để thực hiện$k$bằng cách thêm một$p$. 

Bởi vì các số nguyên tố được xử lý theo thứ tự tăng dần nên mỗi kết hợp được tính chính xác một lần, bất kể sự sắp xếp.

## Tạo số nguyên tố 

Chúng ta chỉ cần những con số tương đối nhỏ nên chỉ cần kiểm tra tính nguyên tố đơn giản là đủ. 

một con số$n$là số nguyên tố nếu không có số nguyên$d \le \sqrt n$chia nó.

## Chiến lược 

Chúng tôi tăng$n$từ giá trị nhỏ trở lên: 

1. Tạo tất cả các số nguyên tố$\le n$2. Tính số phân vùng nguyên tố của$n$3. Dừng lại khi số lượng vượt quá$5000$--- 

#Triển khai Python```python
from math import isqrt

# Check whether a number is prime
def is_prime(n):
    if n < 2:
        return False
    for d in range(2, isqrt(n) + 1):
        if n % d == 0:
            return False
    return True

# Generate all primes up to limit
def primes_up_to(limit):
    return [x for x in range(2, limit + 1) if is_prime(x)]

target = 5000
n = 2

while True:
    primes = primes_up_to(n)

    # dp[k] = number of ways to write k as a sum of primes
    dp = [0] * (n + 1)
    dp[0] = 1

    # Coin-change style dynamic programming
    for p in primes:
        for k in range(p, n + 1):
            dp[k] += dp[k - p]

    # Check whether we've exceeded the target
    if dp[n] > target:
        print(n)
        break

    n += 1
```---
