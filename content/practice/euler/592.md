[Vấn đề dự án Euler 592](https://projecteuler.net/problem=592) 

##Giải pháp 

**Trả lời:**`13415DF2BE9C`Cho phép$$M = 20! = 2432902008176640000.$$Chúng tôi muốn 12 chữ số thập lục phân cuối cùng của$M!$trước các số 0 thập lục phân ở cuối. 

Số 0 thập lục phân ở cuối tương ứng với hệ số$16=2^4$. 

Vậy nếu$$v_2(M!)=\sum_{k\ge1}\left\lfloor \frac{M}{2^k}\right\rfloor,$$thì số số 0 ở cuối thập lục phân là$$\left\lfloor \frac{v_2(M!)}{4}\right\rfloor.$$Vì vậy chúng tôi tính toán$$\frac{M!}{16^{\lfloor v_2(M!)/4\rfloor}} \pmod{16^{12}}.$$Tương tự, làm việc theo modulo$$16^{12}=2^{48},$$chúng tôi loại bỏ tất cả các yếu tố của$2$từ tích giai thừa, giữ phần lẻ còn lại theo modulo$2^{48}$, và cuối cùng khôi phục lại nguồn điện còn sót lại$2^{v_2(M!)\bmod 4}$. 

Cách hiệu quả để làm điều này là lũy thừa modulo của thuật toán giai thừa lẻ đệ quy tiêu chuẩn của hai:$$G(n)=\frac{n!}{2^{v_2(n!)}},$$với đệ quy$$G(n)=G\!\left(\left\lfloor \frac n2\right\rfloor\right)\cdot \prod_{\substack{1\le k\le n\\ k\text{ odd}}}k \pmod{2^{48}}.$$Sử dụng tính tuần hoàn của dư lượng lẻ modulo$2^{48}$, điều này làm giảm$O(\log n)$độ sâu đệ quy. 

Việc triển khai Python sạch là:```python
from functools import cache
from math import factorial

MOD = 1 << 48
N = factorial(20)

def v2_factorial(n):
    s = 0
    while n:
        n //= 2
        s += n
    return s

@cache
def odd_fact(n):
    if n == 0:
        return 1

    # recursive odd-part reduction
    res = odd_fact(n // 2)

    # multiply odd terms
    p = 1
    for k in range(1, n + 1, 2):
        p = (p * k) % MOD

    return (res * p) % MOD

v2 = v2_factorial(N)

# odd part
g = odd_fact(N)

# restore remaining twos after removing hexadecimal zeros
g = (g * pow(2, v2 % 4, MOD)) % MOD

answer = f"{g:012X}"
print(answer)
```Đối với mẫu:```python
20! = 21C3677C82B40000 (hex)
```Việc loại bỏ bốn số 0 thập lục phân ở cuối sẽ cho:```python
21C3677C82B4
```phù hợp với tuyên bố.
