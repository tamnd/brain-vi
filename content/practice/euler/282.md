##Giải pháp 

**Trả lời:**`1098988351`Chúng ta bắt đầu với hàm Ackermann cổ điển:$$A(m,n)= \begin{cases} n+1 & m=0\\ A(m-1,1) & m>0,\ n=0\\ A(m-1,A(m,n-1)) & m>0,\ n>0 \end{cases}$$Chúng ta phải tính toán$$\sum_{n=0}^6 A(n,n)\pmod{14^8}.$$Cho phép$$M=14^8=2^8\cdot 7^8=256\cdot 5764801.$$--- 

# 1. Biểu mẫu đóng dành cho cấp độ Ackermann nhỏ 

Việc mở rộng đệ quy nhiều lần sẽ cho:$$A(0,n)=n+1$$

$$A(1,n)=n+2$$

$$A(2,n)=2n+3$$

$$A(3,n)=2^{n+3}-3$$Từ đó mẫu trở thành siêu hoạt động:$$A(4,n)=2\uparrow\uparrow(n+3)-3$$(chuẩn âm)$$A(5,n)=2\uparrow\uparrow\uparrow(n+3)-3$$

$$A(6,n)=2\uparrow\uparrow\uparrow\uparrow(n+3)-3.$$Vì thế:$$\begin{aligned} A(0,0)&=1,\\ A(1,1)&=3,\\ A(2,2)&=7,\\ A(3,3)&=2^6-3=61. \end{aligned}$$Những từ khó là:$$A(4,4)=2\uparrow\uparrow 7-3,$$

$$A(5,5)=2\uparrow\uparrow\uparrow 8-3,$$

$$A(6,6)=2\uparrow\uparrow\uparrow\uparrow 9-3.$$--- 

#2. Chiến lược mô-đun 

Chúng tôi tính toán modulo$2^8$và modulo$7^8$, sau đó kết hợp bằng CRT. 

## Mô-đun$2^8$Bất kỳ tháp nào$2^k$với$k\ge 8$chia hết cho$256$. 

Do đó, tất cả các số hạng lớn của Ackermann đều thỏa mãn:$$A(4,4)\equiv A(5,5)\equiv A(6,6)\equiv -3 \pmod{256}.$$Vì thế:$$\equiv 253 \pmod{256}.$$--- 

# 3. Modulo thừa kế$7^8$Bây giờ làm việc theo modulo$$7^8=5764801.$$Bởi vì$\gcd(2,7)=1$, Áp dụng phép khử Euler/Carmichael. 

Hàm Carmichael là:$$\lambda(7^k)=6\cdot 7^{k-1}.$$Xác định đẳng thức:$$T(h)=2\uparrow\uparrow h.$$Chúng tôi tính toán đệ quy:$$T(h)\bmod m = 2^{\,T(h-1)\bmod \lambda(m)+\lambda(m)} \bmod m.$$Thực hiện đệ quy này sẽ mang lại:$$T(7)\equiv 4788450 \pmod{7^8},$$kể từ đây$$A(4,4)\equiv 4788447 \pmod{7^8}.$$Tiếp tục chuỗi túc thừa modulo$7^8$cuối cùng ổn định tại điểm cố định$$5208625.$$Như vậy:$$2\uparrow\uparrow 65536 \equiv 5208625 \pmod{7^8},$$Vì thế$$A(5,5)\equiv 5208622 \pmod{7^8}.$$Mức siêu hoạt động tiếp theo đã vượt xa mức ổn định, vì vậy:$$A(6,6)\equiv 5208622 \pmod{7^8}.$$--- 

# 4. Định lý số dư Trung Hoa

#6. Triển khai Python```python
from math import lcm

MOD = 14 ** 8
MOD2 = 2 ** 8
MOD7 = 7 ** 8

# Carmichael function for prime powers
def carmichael_7_power(k):
    return 6 * (7 ** (k - 1))

# tetration: 2 ↑↑ h (mod m)
def tetration_mod(h, m):
    if m == 1:
        return 0
    if h == 1:
        return 2 % m

    # lambda(7^k) = 6 * 7^(k-1)
    # here m is always a power of 7
    k = 0
    t = m
    while t % 7 == 0:
        t //= 7
        k += 1

    lam = carmichael_7_power(k)

    e = tetration_mod(h - 1, lam)

    return pow(2, e + lam, m)

# Chinese remainder theorem for coprime moduli
def crt(a1, m1, a2, m2):
    inv = pow(m1, -1, m2)
    t = ((a2 - a1) * inv) % m2
    return a1 + m1 * t

# Small terms
A00 = 1
A11 = 3
A22 = 7
A33 = 61

# A(4,4)

A44 = crt(253, MOD2, a44_mod7, MOD7)

# Stable fixed point for higher hyper-operators
stable = 5208625 - 3

A55 = crt(253, MOD2, stable, MOD7)
A66 = A55

answer = (A00 + A11 + A22 + A33 + A44 + A55 + A66) % MOD
