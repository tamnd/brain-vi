[Vấn đề dự án Euler 668](https://projecteuler.net/problem=668) 

## Giải pháp 

**Trả lời:**`2811077773`Cho phép$P(n)$biểu thị thừa số nguyên tố lớn nhất của$n$(với$P(1)$không xác định, nhưng$1$được khai báo là căn bậc hai trơn theo định nghĩa). 

một con số$n$là căn bậc hai trơn tru nếu mọi thừa số nguyên tố đều nhỏ hơn$\sqrt n$. 

Tương đương,$$P(n)<\sqrt n$$hoặc$$P(n)^2<n.$$Chúng tôi muốn số lượng số nguyên$n\le 10^{10}$thỏa mãn điều này. 

--- 

# 1. Phân tích toán học 

## Bước 1: Nêu đặc điểm của phần bù 

Việc đếm các số **không** căn bậc hai sẽ dễ dàng hơn. 

một con số$n>1$**không** là căn bậc hai mịn iff$$P(n)\ge \sqrt n.$$Viết$$n = pk,$$Ở đâu$p=P(n)$là thừa số nguyên tố lớn nhất. 

Sau đó$$p \ge \sqrt n \quad\Longrightarrow\quad p^2 \ge n = pk \quad\Longrightarrow\quad p \ge k.$$Vì vậy, mọi số không trơn đều có một cách biểu diễn duy nhất$$n = pk$$với:

-$p$xuất sắc,
-$k \le p$, 
-$pk \le x$. 

Ngược lại, mọi cặp như vậy đều tạo ra một số không bằng phẳng, bởi vì$p$là thừa số nguyên tố và$$p \ge k \;\Rightarrow\; p^2 \ge pk=n \;\Rightarrow\; p\ge \sqrt n.$$Do đó, các số không trơn sẽ song ánh với các cặp$$(p,k)$$như vậy$$p \text{ prime},\qquad k\le p,\qquad pk\le x.$$--- 

## Bước 2: Đếm phần bù 

sửa chữa$k$. 

Sau đó$p$phải thỏa mãn$$k \le p \le \frac{x}{k}.$$Vậy số số nguyên tố hợp lệ là$$\pi\!\left(\frac{x}{k}\right)-\pi(k-1),$$Ở đâu$\pi(n)$là hàm đếm nguyên tố. 

Ngoài ra nhất thiết$k\le \sqrt x$, nếu không thì$k^2>x$. 

Do đó số số nguyên không trơn là$$N(x) = \sum_{k\le \sqrt x} \left( \pi\!\left(\frac{x}{k}\right)-\pi(k-1) \right).$$Do đó số lượng mong muốn là$$S(x)=x-N(x).$$Vì thế:$$\boxed{ S(x) = x- \sum_{k\le \sqrt x} \left( \pi\!\left(\frac{x}{k}\right)-\pi(k-1) \right) }$$với$x=10^{10}$. 

--- 

## Bước 3: Kiểm tra ví dụ$x=100$Sử dụng công thức:$$N(100) = \sum_{k=1}^{10} \left( \pi(100/k)-\pi(k-1) \right) =71.$$Kể từ đây$$S(100)=100-71=29,$$phù hợp với phát biểu vấn đề.

#2. Triển khai Python```python
from functools import lru_cache
from math import isqrt

# ------------------------------------------------------------
# Sieve for small primes
# ------------------------------------------------------------

LIMIT = 5_000_000

sieve = bytearray(b"\x01") * (LIMIT + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(LIMIT) + 1):
    if sieve[i]:
        sieve[i * i : LIMIT + 1 : i] = b"\x00" * (
            ((LIMIT - i * i) // i) + 1
        )

primes = [i for i, v in enumerate(sieve) if v]

# pi_small[n] = number of primes <= n
pi_small = [0] * (LIMIT + 1)

count = 0
for i in range(LIMIT + 1):
    if sieve[i]:
        count += 1
    pi_small[i] = count

# ------------------------------------------------------------
# Lehmer prime counting function
# Computes pi(n) quickly for large n
# ------------------------------------------------------------

@lru_cache(None)
def phi(x, s):
    """Count integers <= x not divisible by first s primes."""
    if s == 0:
        return x
    return phi(x, s - 1) - phi(x // primes[s - 1], s - 1)

@lru_cache(None)
def pi(n):
    """Lehmer prime counting function."""
    if n <= LIMIT:
        return pi_small[n]

    a = pi(int(n ** 0.25))
    b = pi(isqrt(n))
    c = pi(int(n ** (1 / 3)))

    # Main Lehmer formula
    result = phi(n, a) + ((b + a - 2) * (b - a + 1)) // 2

    for i in range(a + 1, b + 1):
        p = primes[i - 1]
        w = n // p

        result -= pi(w)

        if i <= c:
            bi = pi(isqrt(w))

            for j in range(i, bi + 1):
                result -= pi(w // primes[j - 1]) - (j - 1)

    return result

# ------------------------------------------------------------
# Count square-root smooth numbers
# ------------------------------------------------------------

def square_root_smooth_count(x):
    root = isqrt(x)

    non_smooth = 0

    for k in range(1, root + 1):
        non_smooth += pi(x // k) - pi(k - 1)

    return x - non_smooth

# ------------------------------------------------------------
# Compute the Project Euler answer
# ------------------------------------------------------------

x = 10_000_000_000

answer = square_root_smooth_count(x)

print(answer)
```---

## Phần sàng 

Trước tiên chúng tôi tạo ra tất cả các số nguyên tố lên đến$5\times10^6$bằng sàng Eratosthenes.```python
sieve = bytearray(...)
```lưu trữ tính nguyên thủy. 

Chúng tôi cũng xây dựng:```python
pi_small[n]
```mang lại$\pi(n)$ngay lập tức cho nhỏ$n$. 

--- 

##`phi(x, s)`Hàm này đếm số$\le x$không chia hết cho số đầu tiên$s$số nguyên tố. 

Nó thỏa mãn đệ quy:$$\phi(x,s)=\phi(x,s-1)-\phi\!\left(\left\lfloor \frac{x}{p_s}\right\rfloor,s-1\right).$$Đây là thành phần tiêu chuẩn trong thuật toán đếm số nguyên tố của Lehmer. 

--- 

##`pi(n)`Điều này thực hiện chức năng đếm số nguyên tố Lehmer. 

Nó tính toán$\pi(n)$đại khái là$O(n^{2/3})$thời gian, đủ nhanh để$10^{10}$. 

--- 

## Vòng đếm cuối cùng 

Chúng tôi sử dụng công thức$$N(x) = \sum_{k\le \sqrt x} \left( \pi(x/k)-\pi(k-1) \right).$$được thực hiện như:```python
for k in range(1, root + 1):
    non_smooth += pi(x // k) - pi(k - 1)
```Sau đó:```python
return x - non_smooth
```cung cấp số lượng số nguyên chẵn có căn bậc hai.

# 4. Xác minh cuối cùng 

Đối với mẫu:$$S(100)=29,$$phù hợp chính xác với tuyên bố. 

Vì$10^{10}$, giá trị tính được là:$$2\,811\,077\,773.$$Điều này là hợp lý: 

- nó nhỏ hơn đáng kể so với$10^{10}$, 
- nhưng vẫn là hàng tỷ, vì nhiều số nguyên có tất cả các thừa số nguyên tố bên dưới$\sqrt n$.
