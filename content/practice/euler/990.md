# Phân tích toán học 

Chúng ta phải đếm tối đa tất cả các phương trình hợp lệ có tổng chiều dài$50$. 

Một phương trình điển hình trông giống như$$a_1+a_2+\cdots+a_p = b_1+b_2+\cdots+b_q$$với$$a_1+\cdots+a_p=b_1+\cdots+b_q$$và mọi số đều là số nguyên thập phân dương không có số 0 đứng đầu. 

--- 

## 1. Đảo ngược quan điểm: cột chữ số DP 

Thay vì nghĩ về toàn bộ số nguyên, hãy xử lý phương trình **từng cột một từ chữ số có nghĩa nhỏ nhất**. 

Tại cột thập phân bất kỳ: 

- một số số vẫn còn “còn sống” (chúng tiếp tục có chữ số cao hơn), 
- một số số kết thúc ở cột này (chữ số có nghĩa nhất của chúng là ở đây). 

Giả định:

-$p$các số bên trái vẫn hoạt động, 
-$q$số bên phải vẫn còn hoạt động. 

Đối với mỗi số hoạt động: 

- nếu nó tiếp tục đi lên, chữ số này có thể là$0\ldots9$, 
- nếu nó kết thúc ở đây thì chữ số này phải là$1\ldots9$. 

Điều này thực thi chính xác quy tắc “không có số 0 đứng đầu”. 

--- 

## 2. Mang phương trình 

hãy để 

-$S_L$= tổng các chữ số bên trái trong cột này, 
-$S_R$= tổng các chữ số bên phải, 
-$c$= mang theo đến. 

Sau đó chúng ta cần$$S_L - S_R + c = 10c'$$cho một số đồ mang đi$c'$. 

Do đó toàn bộ bài toán trở thành một chương trình động trạng thái hữu hạn trên:$$(p,q,c)$$Ở đâu:

-$p,q$giảm khi số lượng kết thúc, 
-$c$là số thập phân. 

--- 

##3. Tính toán độ dài 

Nếu một số có$d$chữ số, nó góp phần: 

-$d$ký tự chữ số, 
- và một đóng góp tổng thể. 

Đối với một phương trình với$m=p+q$tổng số: 

- có$m-2$dấu cộng, 
- một dấu đẳng thức, 

vì vậy số lượng dấu phân cách là$$m-1.$$Do đó tổng chiều dài là$$(\text{total digits}) + (m-1).$$DP theo dõi các cột chữ số một cách riêng biệt và chúng tôi thêm phần đóng góp dấu phân cách khi khởi tạo. 

--- 

## 4. Đếm chuyển tiếp 

Giả sử trong số$p$số bên trái hoạt động: 

-$p'$Tiếp tục,
-$p-p'$chấm dứt ở đây. 

Tương tự cho bên phải: 

-$q'$Tiếp tục,
-$q-q'$chấm dứt. 

Các bộ tạo chữ số là: 

- số tiếp theo: chữ số$0\ldots9$, 
- số kết thúc: chữ số$1\ldots9$. 

Chúng tôi đếm tất cả các phép gán chữ số tạo ra sự khác biệt về cột nhất định$$S_L-S_R.$$Sau đó, điều kiện mang sẽ xác định duy nhất lần mang tiếp theo. 

Bởi vì tổng chiều dài chỉ$50$, không gian trạng thái đủ nhỏ để ghi nhớ đệ quy.

#Triển khai Python```
from functools import lru_cache
from collections import defaultdict
from math import comb

MOD = 10**9 + 7
N = 50
MAX_TERMS = 25   # worst case: 1-digit numbers separated by symbols

# ------------------------------------------------------------
# dist(p, pp)
#
# p  = active numbers
# pp = numbers that continue upward
#
# Returns:
#   dictionary {digit_sum : count}
#
# Continuing numbers contribute digits 0..9.
# Terminating numbers contribute digits 1..9.
# ------------------------------------------------------------

@lru_cache(None)
def dist(p, pp):

    ways = {0: 1}

    # continuing numbers
    for _ in range(pp):
        nxt = defaultdict(int)
        for s, v in ways.items():
            for d in range(10):
                nxt[s + d] += v
        ways = nxt

    # terminating numbers
    for _ in range(p - pp):
        nxt = defaultdict(int)
        for s, v in ways.items():
            for d in range(1, 10):
                nxt[s + d] += v
        ways = nxt

    # choose which numbers continue
    choose = comb(p, pp)

    return {k: v * choose for k, v in ways.items()}

# ------------------------------------------------------------
# trans(p, q, pp, qq)
#
# Returns all possible values of:
#
#   (left digit sum) - (right digit sum)
#
# together with their multiplicities.
# ------------------------------------------------------------

@lru_cache(None)
def trans(p, q, pp, qq):

    A = dist(p, pp)
    B = dist(q, qq)

    out = defaultdict(int)

    for a, va in A.items():
        for b, vb in B.items():
            out[a - b] += va * vb

    return list(out.items())

# ------------------------------------------------------------
# F(rem, p, q, carry)
#
# rem   = remaining digit-character budget
# p,q   = active numbers on each side
# carry = incoming carry
#
# Returns number of ways.
# ------------------------------------------------------------

@lru_cache(None)
def F(rem, p, q, carry):

    # success state
    if rem == 0:
        return 1 if p == 0 and q == 0 and carry == 0 else 0

    # impossible
    if p == 0 and q == 0:
        return 0

    column_cost = p + q

    if column_cost > rem:
        return 0

    ans = 0

    # choose survivors
    for pp in range(p + 1):
        for qq in range(q + 1):

            for diff, cnt in trans(p, q, pp, qq):

                t = diff + carry

                # must be divisible by 10
                if t % 10 != 0:
                    continue

                next_carry = t // 10

                ans += (
                    cnt *
                    F(rem - column_cost, pp, qq, next_carry)
                )

    return ans % MOD

# ------------------------------------------------------------
# Build A(n)
# ------------------------------------------------------------

exact = [0] * (N + 1)

for total_len in range(N + 1):

    value = 0

    # p left terms, q right terms
    for p in range(1, MAX_TERMS + 1):
        for q in range(1, MAX_TERMS + 1):

            separator_cost = p + q - 1

            if separator_cost > total_len:
                break

            digit_budget = total_len - separator_cost

            value += F(digit_budget, p, q, 0)

    exact[total_len] = value % MOD

# cumulative A(n)
A = [0] * (N + 1)

running = 0
for i in range(N + 1):
    running = (running + exact[i]) % MOD
    A[i] = running

print(A[3])   # 9
print(A[5])   # 171
print(A[7])   # 4878
print(A[50])
```--- 

# Hướng dẫn sử dụng mã 

##`dist(p, pp)`Tính tất cả các tổng chữ số có thể có cho một cạnh trong một cột thập phân. 

Ví dụ:

-$p=3$, 
-$pp=1$, 

có nghĩa là: 

- 1 số tiếp tục, 
- 2 số chấm dứt ở đây. 

Vậy các chữ số là: 

- một chữ số từ$0..9$, 
- hai chữ số từ$1..9$. 

Chúng tôi đếm mọi tổng số có thể có. 

--- 

##`trans(...)`Kết hợp phân phối chữ số bên trái và bên phải. 

Nếu trái đóng góp tổng$a$và quyền đóng góp tổng$b$, cột đóng góp:$$a-b.$$Chúng tôi lưu trữ nhiều thứ. 

--- 

##`F(rem,p,q,carry)`DP được ghi nhớ lõi. 

Ý nghĩa trạng thái: 

-`rem`ngân sách ký tự chữ số còn lại, 
-`p,q`số hoạt động, 
-`carry`mang số thập phân. 

Ở mỗi bước: 

1. chọn số nào tiếp tục, 
2. liệt kê tất cả các khác biệt trong cột, 
3. thực thi phép chia cho$10$, 
4. tái diễn.
