[Vấn đề dự án Euler 462](https://projecteuler.net/problem=462) 

## Giải pháp 

**Trả lời:**`5.5350769703e1512`Hãy để$3$- số trơn được viết dưới dạng$$2^a3^b \qquad (a,b\ge 0).$$Để cố định$N$, định nghĩa$$\mathcal P_N=\{(a,b)\in \mathbb Z_{\ge0}^2 : 2^a3^b\le N\}.$$Quan hệ chia hết trở thành$$2^{a_1}3^{b_1}\mid 2^{a_2}3^{b_2} \iff a_1\le a_2 \text{ and } b_1\le b_2.$$Vì thế$F(N)$chính xác là số phần mở rộng tuyến tính của poset$(\mathcal P_N,\le)$theo thứ tự từng thành phần. 

--- 

#1. Chuyển đổi sang sơ đồ Ferrers 

Đối với mỗi$b$, định nghĩa$$\lambda_b = \left\lfloor \log_2\!\left(\frac{N}{3^b}\right)\right\rfloor + 1.$$Sau đó chèo$b$chứa các tế bào$$(a,b),\qquad 0\le a<\lambda_b.$$Do đó hình dạng là sơ đồ Ferrers$$\lambda=(\lambda_0,\lambda_1,\ldots).$$Ví dụ:$N=20$.$$\lambda=(5,3,2),$$tương ứng với$$1,2,4,8,16;\quad 3,6,12;\quad 9,18.$$Thứ tự poset chính xác là thứ tự sơ đồ Young. 

Vì thế:$$F(N)=f^\lambda,$$số lượng hình dạng tiêu chuẩn của trẻ$\lambda$. 

--- 

#2. Công thức tính chiều dài móc câu 

Đối với hình dạng Ferrers$\lambda$với$n$tế bào,$$f^\lambda=\frac{n!}{\prod_{c\in\lambda} h(c)},$$Ở đâu$h(c)$là chiều dài móc của ô$c$. 

Kể từ đây$$F(N)=\frac{n!}{\prod h(c)}.$$--- 

#3. Kiểm chứng các ví dụ nhỏ 

cho$N=20$,$$\lambda=(5,3,2), \qquad n=10.$$Chiều dài móc là$$\begin{matrix} 7&6&4&2&1\\ 4&3&1\\ 2&1 \end{matrix}$$sản phẩm của ai là$$7\cdot6\cdot4\cdot2\cdot1\cdot4\cdot3\cdot1\cdot2\cdot1=8064.$$Như vậy$$F(20)=\frac{10!}{8064}=450,$$phù hợp với tuyên bố. 

Vì$N=1000$, phép tính cho$$F(1000)\approx 8.8521816557\times 10^{21},$$một lần nữa phù hợp với vấn đề. 

--- 

#4. Triển khai Python```python
from math import log, floor, lgamma

def F_scientific(N):
    # Build the Ferrers shape
    rows = []
    b = 0
    p3 = 1

    while p3 <= N:
        rows.append(int(floor(log(N / p3, 2))) + 1)
        p3 *= 3
        b += 1

    # Total number of cells
    n = sum(rows)

    # Compute log10(product of hook lengths)
    hook_log10 = 0.0

    for r, length in enumerate(rows):
        for c in range(length):

            # cells to the right
            right = length - c - 1

            # cells below
            below = 0
            for rr in range(r + 1, len(rows)):
                if rows[rr] > c:
                    below += 1

            hook = right + below + 1
            hook_log10 += log(hook, 10)

    # log10(n!)
    log10_fact = lgamma(n + 1) / log(10)

    # log10(F)
    log10_F = log10_fact - hook_log10

    exponent = int(floor(log10_F))
    mantissa = 10 ** (log10_F - exponent)

    return mantissa, exponent

m, e = F_scientific(10**18)
print(f"{m:.10f}e{e}")
```--- 

#5. Hướng dẫn sử dụng mã 

### Xây dựng hình dạng```python
rows.append(int(floor(log(N / p3, 2))) + 1)
```Để cố định$b$, điều này tính số mũ hợp lệ$a$như vậy$$2^a3^b \le N.$$Vì vậy, độ dài mỗi hàng chính xác là số lũy thừa cho phép của$2$. 

--- 

### Chiều dài móc 

Đối với mỗi ô:```python
right = length - c - 1
below = number of later rows extending past column c
hook = right + below + 1
```Đây là chiều dài móc Young-tableau tiêu chuẩn. 

--- 

### Độ ổn định về số 

Các con số rất lớn nên chúng tôi tính logarit:$$\log_{10} F = \log_{10}(n!) - \sum \log_{10}(h).$$

`lgamma(n+1)`tính toán$\log(n!)$một cách chính xác.
