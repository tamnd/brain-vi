##Giải pháp 

**Trả lời:**`871198282`Chúng ta phải: 

1. Đọc danh sách tên. 
2. Sắp xếp chúng theo thứ tự bảng chữ cái. 
3. Đối với mỗi tên: 

- Tính giá trị theo thứ tự chữ cái của nó (`A=1, B=2, ..., Z=26`) 
- Nhân với vị trí dựa trên 1 của nó trong danh sách đã sắp xếp. 
4. Tổng hợp tất cả các điểm. 

Ví dụ:

-`COLIN`- Giá trị =`3+15+12+9+14 = 53`- Vị trí =`938`- Điểm =`938 × 53 = 49714`Việc tính toán rất đơn giản khi tệp được phân tích cú pháp chính xác. 

Mã Python:```python
from string import ascii_uppercase

# Build letter values
value = {c: i + 1 for i, c in enumerate(ascii_uppercase)}

# Read and parse names
with open("0022_names.txt") as f:
    names = f.read().replace('"', '').split(',')

# Sort alphabetically
names.sort()

# Compute total score
total = 0

for i, name in enumerate(names, start=1):
    name_value = sum(value[ch] for ch in name)
    total += i * name_value

print(total)
```Theo dõi logic: 

- File chứa 5163 tên. 
- Sắp xếp phù hợp với đặc điểm kỹ thuật của Project Euler. 
- Mỗi điểm được tính đúng một lần. 
- Tổng hợp tất cả các điểm sẽ mang lại kết quả Dự án Euler chính xác đã biết.
