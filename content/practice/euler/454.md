[Vấn đề dự án Euler 454](https://projecteuler.net/problem=454) 

## Giải pháp 

**Trả lời:**`5435004633092`Cho phép$$\frac1x+\frac1y=\frac1n, \qquad x<y\le L,$$với$x,y,n\in \mathbb Z_{>0}$. 

chúng tôi muốn$F(L)$, số cặp như vậy$(x,y)$. 

--- 

# 1. Phân tích toán học 

Bắt đầu từ$$\frac1x+\frac1y=\frac1n.$$Nhân với$xyn$,$$n(x+y)=xy.$$## Bước 1: Giải nén gcd 

hãy để$$x=gu,\qquad y=gv,$$với$$\gcd(u,v)=1,\qquad u<v.$$Thay thế:$$n(g u + g v)=g^2uv.$$Chia cho$g$:$$n(u+v)=g uv.$$Bởi vì$\gcd(u,v)=1$,$$\gcd(u,u+v)=\gcd(v,u+v)=1.$$Kể từ đây$u\mid n$Và$v\mid n$. Từ$u,v$là nguyên tố cùng nhau,$$uv\mid n.$$Vì vậy hãy viết$$n=tuv$$với một số nguyên dương$t$. 

Thay thế trở lại:$$tuv(u+v)=g uv.$$Hủy bỏ$uv$:$$g=t(u+v).$$Do đó mọi nghiệm đều có dạng$$x=t\,u(u+v),$$

$$y=t\,v(u+v),$$với$$u<v,\qquad \gcd(u,v)=1.$$Ngược lại, mọi bộ ba như vậy đều có tác dụng. 

Vì vậy, việc đếm các giải pháp giảm xuống việc đếm$$t\,v(u+v)\le L.$$Đối với coprime cố định$u<v$,$$t \le \frac{L}{v(u+v)}.$$Kể từ đây$$F(L)= \sum_{\substack{u<v\\ \gcd(u,v)=1}} \left\lfloor \frac{L}{v(u+v)} \right\rfloor.$$--- 

#2. Đảo ngược Mobius 

giới thiệu$s=u+v$. Sau đó$v<s<2v$, Và$$\gcd(v,s)=1.$$Vì thế$$F(L) = \sum_{v=1}^{\sqrt L} \sum_{\substack{v<s<2v\\ \gcd(v,s)=1}} \left\lfloor \frac{L}{vs}\right\rfloor.$$Sử dụng danh tính tiêu chuẩn$$[\gcd(v,s)=1] = \sum_{d\mid \gcd(v,s)} \mu(d),$$Ở đâu$\mu$là hàm Mobius. 

Điều này biến đổi điều kiện cùng nguyên tố thành tổng chia và cho phép tính tổng bên trong bằng kỹ thuật chia hài hòa trong khoảng$O(L^{3/4})$, đủ nhanh để$L=10^{12}$.

#3. Triển khai Python```python
import math

# ------------------------------------------------------------
# Mobius sieve
# ------------------------------------------------------------

def mobius_sieve(n):
    mu = [1] * (n + 1)
    prime = []
    is_comp = [False] * (n + 1)

    for i in range(2, n + 1):
        if not is_comp[i]:
            prime.append(i)
            mu[i] = -1

        for p in prime:
            if i * p > n:
                break

            is_comp[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    return mu

# ------------------------------------------------------------
# Fast computation of
#    sum_{k=a}^{b} floor(n / k)
# ------------------------------------------------------------

def floor_sum_range(n, a, b):
    if a > b:
        return 0

    s = 0
    k = a

    while k <= b:
        q = n // k
        r = min(b, n // q)
        s += q * (r - k + 1)
        k = r + 1

    return s

# ------------------------------------------------------------
# Main function
# ------------------------------------------------------------

def F(L):
    root = int(math.isqrt(L))

    mu = mobius_sieve(root)

    ans = 0

    for v in range(2, root + 1):

        # divisors of v
        divisors = []

        d = 1
        while d * d <= v:
            if v % d == 0:
                divisors.append(d)
                if d * d != v:
                    divisors.append(v // d)
            d += 1

        for d in divisors:
            if mu[d] == 0:
                continue

            vv = v // d

            left = vv + 1
            right = (2 * v - 1) // d

            n = L // (v * d)

            contribution = floor_sum_range(n, left, right)

            ans += mu[d] * contribution

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

print(F(15))      # 4
print(F(1000))    # 1069

# Final answer
print(F(10**12))
```--- 

#4. Hướng dẫn code 

##`mobius_sieve`Tính hàm Mobius$\mu(n)$cho tất cả$n\le \sqrt L$. 

Nhớ lại:

-$\mu(n)=0$nếu như$n$chứa một thừa số nguyên tố bình phương, 
- nếu không$\mu(n)=(-1)^k$, Ở đâu$k$là số các thừa số nguyên tố phân biệt. 

Điều này là cần thiết cho việc đảo ngược Möbius. 

--- 

##`floor_sum_range`Tính toán hiệu quả$$\sum_{k=a}^{b} \left\lfloor \frac{n}{k}\right\rfloor.$$Chỉ số thay đổi$O(\sqrt n)$lần, vì vậy chúng tôi nhóm các khoảng có thương số bằng nhau. 

--- 

## Vòng lặp chính 

Đối với mỗi$v$: 

- liệt kê các ước số$d\mid v$, 
- áp dụng đảo ngược Möbius, 
- đánh giá tổng số sàn hài hòa, 
- tích lũy đóng góp. 

Điều này tránh việc lặp lại trực tiếp trên tất cả các cặp nguyên tố cùng nhau.
