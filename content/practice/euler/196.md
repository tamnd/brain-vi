## Giải pháp 

**Trả lời:**`322303240771079935`Để các mục của hàng$n$là$$T(n,k)=\frac{n(n-1)}2+k,\qquad 1\le k\le n.$$Vì vậy, hàng$n$chứa các số nguyên liên tiếp$$\frac{n(n-1)}2+1,\dots,\frac{n(n+1)}2.$$Chúng ta phải tính toán$$S(5678027)+S(7208785),$$Ở đâu$S(n)$là tổng các số nguyên tố trong hàng$n$thuộc về ít nhất một _bộ ba nguyên tố_. 

--- 

# Phân tích toán học 

##1. Cấu trúc hàng xóm 

Đối với một số ở vị trí$(n,k)$, các hàng xóm đều có vị trí hợp lệ trong số$$(n+\delta_n,\;k+\delta_k),$$với$$\delta_n,\delta_k\in\{-1,0,1\},$$loại trừ$(0,0)$. 

Như vậy một phần tử bên trong có tới$8$hàng xóm. 

--- 

## 2. Thuộc bộ ba nguyên tố có nghĩa là gì? 

Bộ ba nguyên tố là một tập hợp gồm ba số nguyên tố sao cho một trong chúng liền kề với hai số còn lại. 

Xác định **bậc nguyên tố** của số nguyên tố$p$là số các số nguyên tố lân cận. 

Sau đó: 

- nếu số nguyên tố có bậc$\ge 2$, bản thân nó là tâm của một bộ ba nguyên tố; 
- nếu số nguyên tố có bậc$1$, nó vẫn có thể thuộc về một bộ ba nếu hàng xóm nguyên tố duy nhất của nó có bậc$\ge 2$. 

Vì vậy: 

> Một số nguyên tố$p$thuộc về một số bộ ba nguyên tố iff 
> 
> 
> 
> 
> -$p$có ít nhất hai hàng xóm chính, hoặc 
> - một trong các số nguyên tố lân cận của nó có ít nhất hai số nguyên tố lân cận. 

Điều này làm giảm vấn đề thành một tính toán thuần túy cục bộ. 

--- 

## 3. Địa phương 

Để xác định xem một số nguyên tố trong hàng$n$thuộc về một bộ ba, chúng ta chỉ cần thông tin từ các hàng$$n-2,\ n-1,\ n,\ n+1,\ n+2.$$Thật vậy: 

- hàng xóm của hàng$n$nằm thành hàng$n-1,n,n+1$; 
- để biết mức độ lân cận của các số nguyên tố đó, chúng ta cần thêm một lớp nữa. 

Do đó việc tính toán là khả thi ngay cả đối với$n\approx 7\times10^6$. 

--- 

##4. Thế hệ Prime 

Những con số liên quan là khoảng$$\frac{n^2}{2}\approx 2.6\times10^{13},$$quá lớn để sàng lọc thông thường trên toàn bộ phạm vi. 

Nhưng chỉ khoảng$5n$cần có các số nguyên liên tiếp, vì vậy **sàng phân đoạn** là lý tưởng. 

--- 

#Triển khai Python```python
from math import isqrt

def row_start(n):
    return n * (n - 1) // 2 + 1

def value(n, k):
    return row_start(n) + k - 1

def neighbours(n, k):
    """
    Generate all neighbouring coordinates of (n,k).
    """
    out = []

    for dn in (-1, 0, 1):
        rn = n + dn
        if rn < 1:
            continue

        for dk in (-1, 0, 1):
            if dn == 0 and dk == 0:
                continue

            kk = k + dk

            if 1 <= kk <= rn:
                out.append((rn, kk))

    return out

def segmented_sieve(lo, hi):
    """
    Return a boolean array is_prime[x - lo]
    for all x in [lo, hi].
    """

    size = hi - lo + 1
    is_prime = [True] * size

    if lo <= 1 <= hi:
        is_prime[1 - lo] = False

    limit = isqrt(hi)

    # ordinary sieve up to sqrt(hi)
    base = [True] * (limit + 1)
    base[0] = base[1] = False

    for p in range(2, isqrt(limit) + 1):
        if base[p]:
            for m in range(p * p, limit + 1, p):
                base[m] = False

    primes = [i for i, v in enumerate(base) if v]

    # segmented marking
    for p in primes:
        start = max(p * p, ((lo + p - 1) // p) * p)

        for m in range(start, hi + 1, p):
            is_prime[m - lo] = False

    return is_prime

def S(n):
    """
    Sum of primes in row n that belong to some prime triplet.
    """

    # enough rows to determine all local structures
    lo = row_start(n - 2)
    hi = row_start(n + 3) - 1

    is_prime_segment = segmented_sieve(lo, hi)

    def is_prime(x):
        return is_prime_segment[x - lo]

    # prime neighbour counts
    degree = {}

    for r in range(n - 1, n + 2):
        for k in range(1, r + 1):

            x = value(r, k)

            if not is_prime(x):
                continue

            cnt = 0

            for rr, kk in neighbours(r, k):
                y = value(rr, kk)

                if is_prime(y):
                    cnt += 1

            degree[(r, k)] = cnt

    total = 0

    for k in range(1, n + 1):

        x = value(n, k)

        if not is_prime(x):
            continue

        ok = False

        # case 1: x itself is centre of a triplet
        if degree.get((n, k), 0) >= 2:
            ok = True

        # case 2: some neighbour is centre
        else:
            for rr, kk in neighbours(n, k):

                y = value(rr, kk)

                if is_prime(y) and degree.get((rr, kk), 0) >= 2:
                    ok = True
                    break

        if ok:
            total += x

    return total

answer = S(5678027) + S(7208785)

print(answer)
```--- 

# Hướng dẫn sử dụng mã 

## Hệ tọa độ```python
row_start(n)
```tính số đầu tiên trong hàng$n$:$$1+\frac{n(n-1)}2.$$Sau đó```python
value(n, k)
```đưa ra số nguyên thực tế tại vị trí$(n,k)$. 

--- 

## Thế hệ hàng xóm```python
neighbours(n, k)
```liệt kê tất cả các ô lân cận bằng cách sử dụng offset$-1,0,+1$theo cả hai hướng hàng và cột. 

Tọa độ không hợp lệ sẽ bị loại bỏ. 

--- 

## Sàng phân đoạn 

Thay vì sàng lọc tất cả các số nguyên lên đến$2.6\times10^{13}$, chúng tôi chỉ sàng lọc trong khoảng thời gian ngắn thực sự cần thiết. 

Điều này làm cho việc tính toán trở nên thiết thực. 

--- 

## Tính toán độ 

Đối với mọi số nguyên tố trong hàng$n-1,n,n+1$, chúng ta đếm xem có bao nhiêu phần tử lân cận là số nguyên tố. 

Số đó được lưu trữ trong:```python
degree[(r, k)]
```--- 

## Kiểm tra tư cách thành viên 

Số nguyên tố thuộc về bộ ba nếu:```python
degree[(n,k)] >= 2
```hoặc một trong các số nguyên tố lân cận của nó có bậc ít nhất$2$.
