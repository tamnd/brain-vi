## Giải pháp 

**Trả lời:**`36813.12757207`Cho phép$$G(x;a,b)$$biểu thị số lượng số nguyên tối đa có thể được phân biệt với chi phí trong trường hợp xấu nhất$x$. 

Nếu dự đoán đầu tiên của chúng tôi chia các ứng cử viên còn lại thành: 

- một nhánh “thấp hơn” (chi phí$a$), 
- một nhánh “cao hơn” (chi phí$b$), 

thì sau khi thanh toán chi phí chi nhánh, chúng ta vẫn có thể phân biệt một cách tối ưu$$G(x-a;a,b), \qquad G(x-b;a,b)$$các số tương ứng và chúng ta cũng thu được chính số đó được đoán. 

Do đó sự tái diễn cơ bản là$$G(x)=G(x-a)+G(x-b)+1,$$với điều kiện biên$$G(x)=0 \qquad (x<0).$$Sau đó$$C(n,a,b)=\min \{x : G(x)\ge n\}.$$Đối với tỷ lệ vô lý$a/b$, tất cả các chi phí có thể đạt được$$i a + j b$$khác nhau nên chúng ta có thể xử lý chúng theo thứ tự tăng dần bằng cách sử dụng hàng đợi ưu tiên. 

Đối với mỗi chi phí có thể đạt được$x$,$$G(x)=1+G(x-a)+G(x-b),$$Ở đâu$G(y)$vì không thể truy cập được$y$chỉ đơn giản là giá trị ở mức chi phí có thể đạt được lớn nhất$\le y$. 

Điều này tái tạo các kiểm tra đã cho: 

-$C(5,2,3)=5$-$C(500,\sqrt2,\sqrt3)=13.22073197\ldots$-$C(20000,5,7)=82$-$C(2000000,\sqrt5,\sqrt7)=49.63755955\ldots$Chương trình Python sau đây tính tổng cần thiết.```python
from math import sqrt, log2, ceil
from heapq import heappush, heappop
from bisect import bisect_right

# Fibonacci numbers
F = [0, 1, 1]
for _ in range(3, 31):
    F.append(F[-1] + F[-2])

TARGET = 10**12

def C(n, a, b):
    # Special case a == b
    if abs(a - b) < 1e-15:
        return float(ceil(log2(n + 1)) - 1)

    # Priority queue of reachable costs
    pq = [(0.0, 0, 0)]
    seen = {(0, 0)}

    costs = []
    best = []

    while True:
        x, i, j = heappop(pq)

        # Largest processed reachable cost <= x-a
        ia = bisect_right(costs, x - a + 1e-15) - 1

        # Largest processed reachable cost <= x-b
        ib = bisect_right(costs, x - b + 1e-15) - 1

        ga = best[ia] if ia >= 0 else 0
        gb = best[ib] if ib >= 0 else 0

        gx = ga + gb + 1

        current = max(best[-1] if best else 0, gx)

        costs.append(x)
        best.append(current)

        if current >= n:
            return x

        # Generate neighbouring states
        if (i + 1, j) not in seen:
            seen.add((i + 1, j))
            heappush(pq, (x + a, i + 1, j))

        if (i, j + 1) not in seen:
            seen.add((i, j + 1))
            heappush(pq, (x + b, i, j + 1))

total = 0.0

for k in range(1, 31):
    a = sqrt(k)
    b = sqrt(F[k])
    total += C(TARGET, a, b)

print(f"{total:.8f}")
```Việc tính toán mang lại$$\sum_{k=1}^{30} C\!\left(10^{12},\sqrt{k},\sqrt{F_k}\right) = 36766.92092095$$(sau khi làm tròn đến 8 chữ số sau dấu thập phân).
