[Vấn đề dự án Euler 538](https://projecteuler.net/problem=538) 

##Giải pháp 

**Trả lời:**`22472871503401097`Gọi độ dài bốn cạnh được chọn là$a \le b \le c \le d$. 

Đối với một tập hợp các cạnh có độ dài cố định, tứ giác có diện tích lớn nhất là hình tròn, do đó theo công thức Brahmagupta$$A^2=(s-a)(s-b)(s-c)(s-d), \qquad s=\frac{a+b+c+d}{2}.$$Tương đương,$$16A^2= (a+b+c-d) (a+b-c+d) (a-b+c+d) (-a+b+c+d).$$Định nghĩa$$F(a,b,c,d)= (a+b+c-d) (a+b-c+d) (a-b+c+d) (-a+b+c+d).$$Tối đa hóa diện tích tương đương với tối đa hóa$F$, và các mối ràng buộc bị phá vỡ bởi chu vi$P=a+b+c+d$. 

--- 

# 1. Quan sát cấu trúc chính 

Giả sử nhiều tập hợp có độ dài sẵn có được sắp xếp. 

Nếu bộ bốn tối ưu bỏ qua một số giá trị khả dụng giữa hai giá trị đã chọn, thì việc thay thế giá trị được chọn nhỏ hơn bằng giá trị lớn hơn bị bỏ qua sẽ làm tăng mọi yếu tố trong$F$, do đó làm tăng diện tích. 

Vì vậy: 

> **Bộ tứ tối ưu luôn là bốn phần tử liên tiếp trong tập hợp nhiều tập hợp được sắp xếp.** 

Vì vậy, sau khi chèn một giá trị mới vào chuỗi đã sắp xếp, chỉ có tối đa bốn cửa sổ liên tiếp chứa giá trị mới đó mới có thể cải thiện mức tối ưu. 

Điều này làm giảm vấn đề từ “tất cả bốn lần” xuống chỉ còn$O(1)$ứng viên cho mỗi lần chèn.

#2. Tạo chuỗi$$u_n = 2^{B(3n)} + 3^{B(2n)} + B(n+1),$$Ở đâu$B(k)$là số lượng nhị phân. 

Vì$n \le 3\,000\,000$, chỉ có 1614 giá trị khác nhau của$u_n$, vì vậy chúng tôi phối hợp nén chúng và duy trì nhiều tập hợp có thứ tự bằng cây Fenwick (Cây chỉ mục nhị phân). 

Cây Fenwick hỗ trợ: 

- chèn, 
- truy vấn xếp hạng, 
-$k$- truy vấn phần tử thứ, 

tất cả trong$O(\log M)$, Ở đâu$M=1614$. 

Vì vậy toàn bộ tính toán về cơ bản là tuyến tính.

#3. Triển khai Python```python
from bisect import bisect_left

N = 3_000_000

# ---------- generate all u_n ----------
pow3 = [3 ** k for k in range(30)]

vals = []
distinct = set()

for n in range(1, N + 1):
    v = (1 << ((3 * n).bit_count())) \
        + pow3[(2 * n).bit_count()] \
        + (n + 1).bit_count()

    vals.append(v)
    distinct.add(v)

# ---------- coordinate compression ----------
coord = sorted(distinct)
idx = {v: i + 1 for i, v in enumerate(coord)}
M = len(coord)

# ---------- Fenwick tree ----------
bit = [0] * (M + 1)

def add(i, delta):
    while i <= M:
        bit[i] += delta
        i += i & -i

def prefix_sum(i):
    s = 0
    while i:
        s += bit[i]
        i -= i & -i
    return s

def kth(k):
    """
    Smallest index i such that prefix_sum(i) >= k
    """
    i = 0
    step = 1 << (M.bit_length() - 1)

    while step:
        ni = i + step
        if ni <= M and bit[ni] < k:
            k -= bit[ni]
            i = ni
        step >>= 1

    return i + 1

def value_at_rank(r):
    return coord[kth(r) - 1]

# ---------- Brahmagupta comparison quantity ----------
def score(q):
    a, b, c, d = q

    x1 = a + b + c - d
    if x1 <= 0:
        return -1

    return (
        x1
        * (a + b - c + d)
        * (a - b + c + d)
        * (-a + b + c + d)
    )

best_F = -1
best_P = 0

answer = 0
total = 0

# ---------- process U_n incrementally ----------
for n, v in enumerate(vals, start=1):

    i = idx[v]

    # rank of inserted element
    rank = prefix_sum(i) + 1

    add(i, 1)
    total += 1

    # only windows containing the new element matter
    start_lo = max(1, rank - 3)
    start_hi = min(rank, total - 3)

    for s in range(start_lo, start_hi + 1):

        q = [
            value_at_rank(s),
            value_at_rank(s + 1),
            value_at_rank(s + 2),
            value_at_rank(s + 3),
        ]

        F = score(q)
        P = sum(q)

        if F > best_F or (F == best_F and P > best_P):
            best_F = F
            best_P = P

    if n >= 4:
        answer += best_P

print(answer)
```--- 

#4. Hướng dẫn code 

### Tạo trình tự```python
v = (1 << ((3 * n).bit_count())) \
    + pow3[(2 * n).bit_count()] \
    + (n + 1).bit_count()
```Trực tiếp thực hiện định nghĩa của$u_n$. 

--- 

###Cây Fenwick 

Chúng tôi duy trì số lượng của từng giá trị nén. 

-`add(i,1)`chèn một lần xuất hiện, 
-`prefix_sum(i)`đếm xem có bao nhiêu phần tử$\le i$, 
-`kth(k)`lấy lại$k$-phần tử nhỏ nhất thứ 

--- 

### Cửa sổ liên tiếp 

Nếu phần tử được chèn có thứ hạng được sắp xếp`rank`, thì chỉ những cửa sổ này mới có thể thay đổi:$$[rank-3, rank],\ [rank-2, rank+1],\ [rank-1, rank+2],\ [rank, rank+3].$$Do đó chỉ có tối đa bốn bộ tứ ứng cử viên được kiểm tra. 

--- 

### So sánh diện tích 

Thay vì diện tích dấu phẩy động, chúng ta so sánh$$F = 16A^2,$$đó là giá trị số nguyên và chính xác. 

Tie-break sử dụng chu vi.
