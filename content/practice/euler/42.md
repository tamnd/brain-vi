[Vấn đề dự án Euler 42](https://projecteuler.net/problem=42) 

##Giải pháp 

**Trả lời:**`162`Nhiệm vụ chính là xác định có bao nhiêu từ trong tệp được cung cấp có **giá trị từ** bằng **số tam giác**. 

Số tam giác được xác định bởi$$t_n = \frac{n(n+1)}{2}$$Một số đầu tiên là:$$1,3,6,10,15,21,28,36,45,55,\dots$$Ví dụ:

-$S=19$-$K=11$-$Y=25$Vì thế$$19+11+25 = 55$$và kể từ đó$$55 = \frac{10\cdot 11}{2}$$SKY là một từ hình tam giác. 

--- 

# Bước 1 - Phân tích toán học 

## Chuyển đổi một từ thành một số 

Mỗi chữ cái ánh xạ tới chỉ mục theo thứ tự chữ cái của nó:$$A=1,\;B=2,\;\dots,\;Z=26$$Nếu một từ có chữ cái$c_1,c_2,\dots,c_k$, giá trị của nó là$$V = \sum_{i=1}^{k} \text{value}(c_i)$$Ví dụ:$$\text{SKY}=19+11+25=55$$--- 

## Xác định một số có phải là hình tam giác hay không 

Chúng ta cần biết liệu một số nguyên$x$thỏa mãn$$x=\frac{n(n+1)}2$$Sắp xếp lại:$$n^2+n-2x=0$$Sử dụng công thức bậc hai:$n=\frac{-1+\sqrt{1+8x}}{2}$Vì thế$x$là hình tam giác chính xác khi$$1+8x$$là một hình vuông hoàn hảo và kết quả$n$là một số nguyên. 

--- 

## Giá trị từ tối đa có thể 

Tệp từ chứa các từ tiếng Anh thông dụng; độ dài từ tối đa là nhỏ. Ngay cả khi một từ có 20 chữ cái đều bằng Z:$$20\cdot 26 = 520$$Vì vậy chỉ cần một bộ số tam giác khiêm tốn. 

Một cách tiếp cận thực tế: 

1. Đọc tất cả các từ 
2. Tính giá trị từng từ 
3. Tính toán trước tất cả các số tam giác đến giá trị lớn nhất 
4. Đếm trận đấu 

Điều này hiệu quả vì việc tra cứu trong một tập hợp là$O(1)$.

# Bước 2 - Triển khai Python```python
from math import sqrt

# Read the words file
with open("0042_words.txt") as f:
    content = f.read()

# The file format is:
# "WORD1","WORD2","WORD3",...
words = [w.strip('"') for w in content.split(",")]

# Function to compute word value
def word_value(word):
    return sum(ord(c) - ord('A') + 1 for c in word)

# Compute all word values
values = [word_value(w) for w in words]

# Find the largest value
max_value = max(values)

# Generate all triangle numbers up to max_value
triangle_numbers = set()

n = 1
while True:
    t = n * (n + 1) // 2
    if t > max_value:
        break
    triangle_numbers.add(t)
    n += 1

# Count triangle words
count = sum(1 for v in values if v in triangle_numbers)

print(count)
```---

## Tính giá trị từ```python
def word_value(word):
    return sum(ord(c) - ord('A') + 1 for c in word)
```

`ord('A')`cung cấp mã ASCII 65. 

Vì vậy: 

- A →$65-65+1=1$- B →$66-65+1=2$- … 
- Z → 26 

Ví dụ:```python
word_value("SKY")
```cho$$19+11+25=55$$phù hợp với tuyên bố vấn đề. 

--- 

## Tạo số tam giác```python
t = n * (n + 1) // 2
```Điều này thực hiện$$t_n = \frac{n(n+1)}2$$Chúng tôi dừng lại khi số tam giác vượt quá giá trị từ lớn nhất. 

Sử dụng một`set`cho phép thử nghiệm thành viên rất nhanh. 

--- 

## Đếm các từ trong hình tam giác```python
count = sum(1 for v in values if v in triangle_numbers)
