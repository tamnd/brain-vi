##Giải pháp 

**Trả lời:**`319.30207833`Cho phép$E(s)$biểu thị giá trị cuối cùng được mong đợi khi chuỗi được viết hiện tại là tiền tố chữ số La Mã$s$. 

Quan sát chính là: 

- Nếu việc thêm một chữ cái giữ cho chuỗi có tiền tố hợp lệ là một chữ số La Mã _minimal_, thì chúng ta chuyển sang trạng thái mới. 
- Nếu không lá thư đó sẽ bị bỏ qua. 
- Khi`#`xuất hiện (xác suất$0.02$), chúng tôi dừng lại ngay lập tức. 

Các chữ số La Mã ở dạng tối thiểu có phân rã chuẩn$$M^a \cdot H \cdot T \cdot O$$Ở đâu:

-$a \ge 0$, 
-$H \in \{ "", C, CC, CCC, CD, D, DC, DCC, DCCC, CM \}$, 
-$T \in \{ "", X, XX, XXX, XL, L, LX, LXX, LXXX, XC \}$, 
-$O \in \{ "", I, II, III, IV, V, VI, VII, VIII, IX \}$. 

Vì vậy, toàn bộ ngôn ngữ của các chữ số hợp lệ là một automaton tiền tố hữu hạn, ngoại trừ phần đầu không giới hạn$M$'S. 

--- 

# 1. Tái phát 

Giả sử một trạng thái$s$có giá trị$v(s)$, Và$k$các chữ cái tiếp theo hợp lệ. 

Sau đó$$E(s) = 0.02\,v(s) + 0.14\sum_{t} E(t) + (0.98-0.14k)E(s)$$trong đó tổng chạy trên tất cả các trạng thái tiếp theo hợp lệ$t$. 

Sắp xếp lại:$$(0.02+0.14k)E(s) = 0.02\,v(s)+0.14\sum_t E(t)$$và chia cho$0.02$,$$(1+7k)E(s) = v(s)+7\sum_t E(t).$$Như vậy$$\boxed{ E(s)=\frac{v(s)+7\sum_t E(t)}{1+7k} }$$cho mọi trạng thái hậu tố không trống. 

--- 

#2. Xử lý vô hạn$M$-chuỗi 

Gọi số hiện tại là$$M^a s$$Ở đâu$s$không chứa$M$. 

Viết$$E(M^a s)=1000a+F(s).$$Thay thế vào phép truy toán cho thấy sự phụ thuộc vào$a$hủy bỏ hoàn toàn, để lại một hệ thống hữu hạn cho các trạng thái hậu tố$s$. 

Đối với trạng thái hậu tố trống:$$F(\varepsilon) = \frac{7000+7\sum F(t)}{43}$$trong đó tổng số trên sáu chữ cái bắt đầu$$I,V,X,L,C,D.$$Tất cả các trạng thái khác đều thỏa mãn phép truy hồi hữu hạn ở trên.

#3. Triển khai Python```python
from functools import lru_cache

# Minimal Roman blocks
ones = ["", "I", "II", "III", "IV",
        "V", "VI", "VII", "VIII", "IX"]

tens = ["", "X", "XX", "XXX", "XL",
        "L", "LX", "LXX", "LXXX", "XC"]

hundreds = ["", "C", "CC", "CCC", "CD",
            "D", "DC", "DCC", "DCCC", "CM"]

# All minimal numerals from 0..999
nums = [
    hundreds[h] + tens[t] + ones[o]
    for h in range(10)
    for t in range(10)
    for o in range(10)
]

# Value of each suffix numeral
value = {}
prefixes = {""}

for n, s in enumerate(nums):
    value[s] = n
    for i in range(len(s) + 1):
        prefixes.add(s[:i])

letters = "IVXLCD"

# Valid transitions
trans = {}

for p in prefixes:
    nxt = []
    for ch in letters:
        q = p + ch
        if q in prefixes:
            nxt.append(q)
    trans[p] = nxt

# Solve backwards by decreasing length
states = sorted(prefixes, key=len, reverse=True)

F = {}

for s in states:
    if s == "":
        continue

    k = len(trans[s])

    F[s] = (
        value[s]
        + 7 * sum(F[t] for t in trans[s])
    ) / (1 + 7 * k)

# Empty state:
# one transition to another M,
# six transitions to I,V,X,L,C,D
F0 = (
    7000
    + 7 * sum(F[t] for t in trans[""])
) / 43

print("{:.8f}".format(F0))
```---
