[Vấn đề dự án Euler 926](https://projecteuler.net/problem=926) 

##Giải pháp 

**Trả lời:**`40410219`Đối với một số$n$, độ tròn ở đáy$b$là lớn nhất$k$như vậy$b^k \mid n$. 

Kể từ đây:$$R(n)=\sum_{b\ge2} v_b(n)$$Ở đâu$v_b(n)$là số mũ của$b$chia$n$. 

Bây giờ hãy quan sát:$$v_b(n)=\sum_{k\ge1} [b^k\mid n]$$Vì thế$$R(n)=\sum_{k\ge1} \#\{b\ge2 : b^k\mid n\}.$$Nếu như$$n=\prod p_i^{a_i},$$sau đó$b^k\mid n$nếu mọi số mũ nguyên tố của$b$nhiều nhất là$\left\lfloor a_i/k\right\rfloor$. 

Vì vậy số lượng như vậy$b$là$$\prod_i \left(\left\lfloor \frac{a_i}{k}\right\rfloor+1\right)-1,$$("$-1$” loại trừ$b=1$). 

Vì thế:$$R(n)=\sum_{k\ge1} \left( \prod_i \left(\left\lfloor \frac{a_i}{k}\right\rfloor+1\right)-1 \right).$$Vì$n=N!$, số mũ là$$a_p=v_p(N!)=\sum_{j\ge1}\left\lfloor \frac{N}{p^j}\right\rfloor.$$Mã Python sau tính toán giá trị một cách hiệu quả.```python
MOD = 10**9 + 7
N = 10_000_000

# exponent of 2 in N! gives the maximum possible k
a2 = 0
t = N
while t:
    t //= 2
    a2 += t

# D[k] = product over primes p of (floor(v_p(N!)/k) + 1)
D = [1] * (a2 + 1)

# sieve of Eratosthenes
sieve = bytearray(b"\x01") * (N + 1)
sieve[0] = sieve[1] = 0

limit = int(N**0.5)
for i in range(2, limit + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:N + 1:step] = b"\x00" * (((N - start) // step) + 1)

primes = [i for i in range(2, N + 1) if sieve[i]]

# process each prime exponent in N!
for p in primes:
    a = 0
    t = N
    while t:
        t //= p
        a += t

    for k in range(1, a + 1):
        D[k] = (D[k] * (a // k + 1)) % MOD

answer = sum(x - 1 for x in D) % MOD
print(answer)
```Xác minh trên mẫu: 

-$R(20)=6$-$R(10!)=312$cả hai đều phù hợp với tuyên bố.
