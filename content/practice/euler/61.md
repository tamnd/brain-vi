[Vấn đề dự án Euler 61](https://projecteuler.net/problem=61) 

##Giải pháp 

**Trả lời:**`28684`Chúng ta tìm kiếm một **bộ tuần hoàn gồm sáu số đa giác có 4 chữ số riêng biệt**, mỗi số một loại: 

- Tam giác$P_{3,n}$- Quảng trường$P_{4,n}$- Ngũ giác$P_{5,n}$- Lục giác$P_{6,n}$- Hình bảy phương$P_{7,n}$- Hình bát giác$P_{8,n}$như vậy: 

1. Mỗi số có **4 chữ số**. 
2. Tập hợp này là **tuần hoàn**:$$\text{last two digits of } a_i = \text{first two digits of } a_{i+1}$$và các liên kết cuối cùng trở lại liên kết đầu tiên. 
3. Mỗi loại đa giác xuất hiện **chính xác một lần**. 

--- 

## 1. Phân tích toán học 

### Bước 1: Tạo số đa giác 

Các công thức là:$$P_{3,n}=\frac{n(n+1)}{2}$$

$$P_{4,n}=n^2$$

$$P_{5,n}=\frac{n(3n-1)}{2}$$

$$P_{6,n}=n(2n-1)$$

$$P_{7,n}=\frac{n(5n-3)}{2}$$

$$P_{8,n}=n(3n-2)$$Chúng tôi chỉ quan tâm đến **giá trị 4 chữ số**, tức là$$1000 \le P_{k,n} \le 9999$$--- 

### Bước 2: Mô hình hóa bài toán dưới dạng đồ thị 

Một con số như$8128$có thể kết nối với một số khác có hai chữ số đầu tiên bằng nhau$28$. 

Ví dụ:$$8128 \to 2882$$bởi vì:$$8128 \mod 100 = 28$$Và$$\left\lfloor \frac{2882}{100} \right\rfloor = 28$$Do đó, mỗi số hoạt động giống như một cạnh có hướng giữa: 

- tiền tố = hai chữ số đầu tiên 
- hậu tố = hai chữ số cuối 

Chúng ta tìm kiếm một **chu trình có độ dài 6** trong đó: 

- mỗi loại đa giác được sử dụng một lần, 
- số có sự khác biệt, 
- giữ nguyên quy tắc kề, 
- chu kỳ đóng lại. 

Điều này được giải quyết một cách tự nhiên bằng **tìm kiếm theo chiều sâu (DFS)** trên các hoán vị của các loại đa giác. 

--- 

### Bước 3: Hạn chế chuyển tiếp không hợp lệ 

Một quan sát hữu ích: 

Nếu hậu tố nhỏ hơn 10 thì đó không thể là hai chữ số đầu tiên của số có 4 chữ số. 

Ví dụ:$$8120$$kết thúc bằng$20$, có hiệu lực. 

Nhưng$$8105$$kết thúc bằng$05$, không thể vì không có số có 4 chữ số nào bắt đầu bằng “05”. 

Vì vậy, chúng tôi chỉ giữ lại những số có hai chữ số cuối ít nhất là 10.

## 2. Triển khai Python```python
from collections import defaultdict

# Polygonal formulas
def polygonal(s, n):
    if s == 3:
        return n * (n + 1) // 2
    elif s == 4:
        return n * n
    elif s == 5:
        return n * (3 * n - 1) // 2
    elif s == 6:
        return n * (2 * n - 1)
    elif s == 7:
        return n * (5 * n - 3) // 2
    elif s == 8:
        return n * (3 * n - 2)

# Generate all valid 4-digit polygonal numbers
poly = {}

for s in range(3, 9):
    nums = []
    n = 1

    while True:
        x = polygonal(s, n)

        if x >= 10000:
            break

        # Keep only valid 4-digit cyclic candidates
        if 1000 <= x <= 9999 and x % 100 >= 10:
            nums.append(x)

        n += 1

    poly[s] = nums

def dfs(path, used_types):
    # If we have 6 numbers, check cyclic closure
    if len(path) == 6:
        return path if path[-1] % 100 == path[0] // 100 else None

    suffix = path[-1] % 100

    # Try unused polygonal types
    for s in range(3, 9):
        if s not in used_types:
            for num in poly[s]:
                if num // 100 == suffix:
                    result = dfs(
                        path + [num],
                        used_types | {s}
                    )
                    if result:
                        return result

    return None

# Start search from octagonal numbers
# (any type works, but this reduces symmetry)
answer_cycle = None

for start in poly[8]:
    result = dfs([start], {8})
    if result:
        answer_cycle = result
        break

print(answer_cycle)
print(sum(answer_cycle))
```--- 

## 3. Hướng dẫn sử dụng mã 

### Tạo số đa giác 

Chúng tôi thực hiện sáu công thức trong`polygonal(s, n)`. 

Đối với mỗi loại:```python
for s in range(3, 9):
```chúng tôi tạo ra các giá trị cho đến khi vượt quá 9999. 

Chúng tôi chỉ giữ lại:```python
1000 <= x <= 9999
```Và```python
x % 100 >= 10
```để đảm bảo hai chữ số cuối cùng tạo thành hai chữ số đầu của số có 4 chữ số khác. 

--- 

### Tìm kiếm DFS 

Hàm đệ quy:```python
dfs(path, used_types)
```duy trì: 

-`path`→ chuỗi số hiện tại 
-`used_types`→ danh mục đa giác đã được chọn 

Ở mỗi bước:```python
suffix = path[-1] % 100
```Chúng tôi thử mọi loại đa giác không sử dụng và tìm kiếm các số có:```python
num // 100 == suffix
```có nghĩa là hai chữ số đầu tiên khớp nhau. 

Khi sáu số được thu thập:```python
len(path) == 6
```chúng tôi xác minh chu trình đóng lại:```python
path[-1] % 100 == path[0] // 100
```--- 

### Xác minh ví dụ 

Ví dụ về vấn đề:$$8128, 2882, 8281$$hoạt động vì: 

-$8128 \to 2882$qua 28 
-$2882 \to 8281$qua 82 
-$8281 \to 8128$qua 81 

và các số lần lượt là hình tam giác, hình ngũ giác, hình vuông. 

Logic DFS tái tạo chính xác hành vi này cho sáu loại.

## 4. Xác minh lần cuối 

Chạy chương trình sẽ tìm thấy tập tuần hoàn duy nhất:$$1281,\ 8128,\ 2882,\ 8256,\ 5625,\ 2512$$(sử dụng một số từ mỗi họ đa giác đúng một lần). 

Tổng của chúng là:$$1281+8128+2882+8256+5625+2512=28684$$Độ lớn là hợp lý (sáu số có 4 chữ số có tổng bằng khoảng$6\times 5000\approx 30000$) và phù hợp với điều kiện duy nhất của bài toán.
