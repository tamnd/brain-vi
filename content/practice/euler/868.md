[Vấn đề dự án Euler 868](https://projecteuler.net/problem=868) 

##Giải pháp 

**Trả lời:**`3832914911887589`Bài toán này là bài toán xếp hạng cho thứ tự hoán vị được tạo ra bởi quy tắc rung chuông. Điều quan trọng là phải nhận ra rằng quy trình chính xác là thứ tự hoán vị **Steinhaus–Johnson–Trotter (SJT)** (còn được gọi là “thay đổi đơn giản”). 

Chúng tôi được yêu cầu về số lần hoán đổi cần thiết để đạt được một hoán vị nhất định so với thứ tự bảng chữ cái ban đầu. Vì mỗi bước thực hiện **chính xác một lần hoán đổi liền kề** nên số lần hoán đổi bằng **chỉ số dựa trên 0** của hoán vị đích theo thứ tự SJT. 

--- 

## 1. Phân tích toán học 

hãy để$R(P)$là số lần hoán đổi cần thiết để đạt được hoán vị$P$. 

Chúng tôi muốn:$$R(\texttt{NOWPICKBELFRYMATHS})$$bắt đầu từ các chữ cái theo thứ tự bảng chữ cái. 

### Cấu trúc đệ quy của trật tự SJT 

Giả sử chúng ta có$n$các chữ cái và đặt chữ cái lớn nhất là$L$. 

Thế hệ SJT dành cho$n$các chữ cái được xây dựng đệ quy từ thứ tự cho$n-1$chữ cái: 

- Lấy từng hoán vị của số nhỏ hơn$n-1$các chữ cái. 
- Chèn$L$vào tất cả các vị trí có thể. 
- Hướng chèn xen kẽ: 

Nếu hoán vị nhỏ hơn có **chỉ số chẵn**, hãy di chuyển$L$từ **phải sang trái**. 

Nếu hoán vị nhỏ hơn có **chỉ số lẻ**, hãy di chuyển$L$từ **trái sang phải**. 

Ví dụ cho$ABC$: 

Từ hoán vị của$AB$: 

-$AB$(chỉ số 0, chẵn): chèn$C$phải → trái$$ABC,\ ACB,\ CAB$$-$BA$(chỉ số 1, số lẻ): chèn$C$trái → phải$$CBA,\ BCA,\ BAC$$Chính xác như trong báo cáo vấn đề. 

--- 

### Phát sinh sự tái phát 

Hãy: 

-$n$= số chữ cái 
-$L$= chữ cái lớn nhất 
-$p$= vị trí của$L$(được lập chỉ mục 0 từ bên trái) 
-$r$= hạng của hoán vị sau khi loại bỏ$L$Sau đó: 

- nếu$r$là **chẵn**,$L$di chuyển sang phải → trái, do đó độ lệch khối là$$(n-1)-p$$- nếu như$r$thật **kỳ quặc**,$L$di chuyển sang trái→phải, do đó độ lệch khối là$$p$$Như vậy:$$R(P)=n\cdot r + b$$Ở đâu$$b= \begin{cases} (n-1)-p & \text{if } r \text{ even}\\[4pt] p & \text{if } r \text{ odd} \end{cases}$$Điều này mang lại một$O(n^2)$thuật toán xếp hạng đệ quy.

## 2. Triển khai Python```python
def sjt_rank(word):
    """
    Return the 0-based index of `word`
    in Steinhaus-Johnson-Trotter order.
    """

    def rank_recursive(letters):
        n = len(letters)

        # Base case
        if n <= 1:
            return 0

        # Largest letter
        largest = max(letters)

        # Position of largest letter
        pos = letters.index(largest)

        # Remove largest letter
        reduced = [x for x in letters if x != largest]

        # Rank of reduced permutation
        r = rank_recursive(reduced)

        # Offset within this block
        if r % 2 == 0:
            offset = (n - 1) - pos
        else:
            offset = pos

        return n * r + offset

    return rank_recursive(list(word))

# Verify examples
print(sjt_rank("CBA"))      # 3
print(sjt_rank("BELFRY"))   # 59

# Compute Project Euler answer
target = "NOWPICKBELFRYMATHS"
print(sjt_rank(target))
```--- 

## 3. Hướng dẫn sử dụng mã 

###Trường hợp cơ sở```python
if n <= 1:
    return 0
```Một chữ cái không yêu cầu hoán đổi. 

--- 

### Tìm chữ cái lớn nhất```python
largest = max(letters)
pos = letters.index(largest)
```Đệ quy SJT phụ thuộc vào vị trí của chữ cái lớn nhất hiện tại. 

--- 

### Giảm thiểu vấn đề```python
reduced = [x for x in letters if x != largest]
r = rank_recursive(reduced)
```Loại bỏ chữ cái lớn nhất và tính toán đệ quy thứ hạng của hoán vị còn lại. 

--- 

### Xác định hướng chuyển động```python
if r % 2 == 0:
    offset = (n - 1) - pos
else:
    offset = pos
```Xếp hạng phụ chẵn → chữ cái lớn nhất quét sang phải → trái. 

Thứ hạng phụ lẻ → chữ cái lớn nhất quét sang trái→phải. 

--- 

### Kết hợp số khối và offset```python
return n * r + offset
```Mỗi khối đệ quy chứa chính xác$n$hoán vị.
