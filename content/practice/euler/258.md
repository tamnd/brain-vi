[Vấn đề dự án Euler 258](https://projecteuler.net/problem=258) 

## Giải pháp 

**Trả lời:**`12747994`Cho phép$$g_k = \begin{cases} 1,&0\le k\le 1999,\\[4pt] g_{k-2000}+g_{k-1999},&k\ge 2000. \end{cases}$$Chúng ta phải tính toán$$g_{10^{18}} \pmod{20092010}.$$--- 

# 1. Phân tích toán học 

Đây là sự tái diễn tuyến tính của trật tự$2000$. 

Xác định quan hệ đặc trưng:$$g_n-g_{n-1999}-g_{n-2000}=0.$$Do đó đa thức đặc trưng là$$P(x)=x^{2000}-x-1.$$Thực tế quan trọng cho các phép truy toán tuyến tính là: 

> Mỗi học kỳ$g_n$có thể được biểu diễn dưới dạng tổ hợp tuyến tính của biểu thức đầu tiên$2000$điều khoản. 

Vì tất cả các giá trị ban đầu đều$$g_0=g_1=\cdots=g_{1999}=1,$$nếu chúng ta có thể tính được các hệ số của$x^n$modulo đa thức đặc trưng$P(x)$, thì câu trả lời chỉ đơn giản là tổng của các hệ số đó. 

--- 

## Quan điểm đa thức 

Bên trong vòng thương$$\mathbb Z_m[x]/(x^{2000}-x-1),$$chúng ta có quy tắc rút gọn$$x^{2000}\equiv x+1.$$Vì thế bất kỳ quyền lực nào$x^n$có thể giảm xuống một đa thức bậc$<2000$:$$x^n \equiv \sum_{i=0}^{1999} c_i x^i.$$Sau đó$$g_n=\sum_{i=0}^{1999} c_i g_i.$$Nhưng mỗi$g_i=1$, Vì thế$$g_n=\sum_{i=0}^{1999} c_i.$$Do đó nhiệm vụ giảm xuống còn: 

1. Tính toán$x^{10^{18}} \bmod (x^{2000}-x-1)$. 
2. Tính tổng các hệ số của nó theo modulo$20092010$. 

--- 

#2. Thuật toán hiệu quả 

Chúng tôi sử dụng lũy thừa nhị phân trên đa thức. 

Khi nhân hai đa thức, độ có thể lên tới$3998$. 

Bất cứ khi nào một thuật ngữ$x^d$với$d\ge 2000$xuất hiện, giảm sử dụng$$x^{2000}\equiv x+1.$$Như vậy$$x^d = x^{d-2000}x^{2000} \equiv x^{d-1999}+x^{d-2000}.$$Điều này mang lại một$O(K^2\log n)$thuật toán với$K=2000$, dễ dàng đủ nhanh. 

--- 

#3. Triển khai Python```python
MOD = 20092010
K = 2000
N = 10**18

def combine(a, b):
    """
    Multiply two polynomials modulo:
        x^2000 - x - 1
    Result has degree < 2000.
    """
    tmp = [0] * (2 * K - 1)

    # Ordinary polynomial multiplication
    for i, ai in enumerate(a):
        if ai:
            for j, bj in enumerate(b):
                if bj:
                    tmp[i + j] = (tmp[i + j] + ai * bj) % MOD

    # Reduce high-degree terms using:
    # x^2000 = x + 1
    for d in range(2 * K - 2, K - 1, -1):
        v = tmp[d]
        if v:
            tmp[d - K] = (tmp[d - K] + v) % MOD
            tmp[d - K + 1] = (tmp[d - K + 1] + v) % MOD

    return tmp[:K]

def power_x(n):
    """
    Compute x^n modulo the characteristic polynomial.
    Return coefficients of degree < 2000 polynomial.
    """

    # res = 1
    res = [1] + [0] * (K - 1)

    # base = x
    base = [0, 1] + [0] * (K - 2)

    while n > 0:
        if n & 1:
            res = combine(res, base)

        base = combine(base, base)
        n >>= 1

    return res

# coefficients for x^N
coeffs = power_x(N)

# since g_0 ... g_1999 are all 1,
# g_N is the sum of coefficients
answer = sum(coeffs) % MOD

print(answer)
```--- 

#4. Hướng dẫn code 

##`combine(a, b)`Hàm này nhân hai đa thức rút gọn. 

Đầu tiên:```python
tmp[i + j] += ai * bj
```thực hiện phép nhân đa thức thông thường. 

Sau đó, chúng tôi giảm các điều khoản của mức độ$\ge 2000$. 

Từ$$x^{2000} \equiv x+1,$$chúng tôi thay thế$$x^d \equiv x^{d-1999}+x^{d-2000}.$$Vậy hệ số`v`của$x^d$được phân phối tới:```python
tmp[d - K]
tmp[d - K + 1]
```tương ứng với$$x^{d-2000},\quad x^{d-1999}.$$--- 

##`power_x(n)`Điều này tính toán$$x^n \bmod (x^{2000}-x-1)$$sử dụng lũy ​​thừa nhị phân. 

-`res`bắt đầu như$1$-`base`bắt đầu như$x$Bất cứ khi nào một bit nhị phân của$n$được thiết lập:```python
res = combine(res, base)
```Sau đó bình phương cơ sở theo từng bước.
