# Bước 1 - Biến đổi phương trình 

Bắt đầu từ$$2b(b-1)=n(n-1).$$Mở rộng:$$2b^2-2b=n^2-n.$$Nhân với$4$:$$8b^2-8b=4n^2-4n.$$Bây giờ hoàn thành các hình vuông:$$8b^2-8b+2=4n^2-4n+1.$$Như vậy$$2(2b-1)^2=(2n-1)^2+1.$$Sắp xếp lại:$$(2n-1)^2-2(2b-1)^2=-1.$$Định nghĩa$$x=2n-1,\qquad y=2b-1.$$Sau đó chúng ta thu được phương trình Pell$$x^2-2y^2=-1.$$--- 

# Bước 2 - Phép lặp phương trình Pell 

Phương trình Pell âm$$x^2-2y^2=-1$$có vô số giải pháp được tạo ra một cách đệ quy. 

Một số đầu tiên là:$$(1,1),\ (7,5),\ (41,29),\ (239,169),\dots$$Những điều này tương ứng với:$$n=\frac{x+1}{2},\qquad b=\frac{y+1}{2}.$$Ví dụ:

-$x=239,\ y=169$cho$$n=120,\qquad b=85,$$phù hợp với tuyên bố vấn đề. 

Phép truy toán chuẩn của nghiệm là$$x_{k+1}=3x_k+4y_k,$$

$$y_{k+1}=2x_k+3y_k.$$Chuyển đổi trở lại$(n,b)$, chúng tôi nhận được:$$n_{k+1}=3n_k+4b_k-3,$$

$$b_{k+1}=2n_k+3b_k-2.$$Bắt đầu từ giải pháp đã biết$$(n,b)=(21,15),$$chúng tôi liên tục tạo ra các giải pháp lớn hơn cho đến khi$n>10^{12}$. 

--- 

# Bước 3 - Triển khai Python```python
# Project Euler Problem 100

LIMIT = 10**12

# Initial known solution:
# total discs = 21
# blue discs  = 15
n = 21
b = 15

# Generate larger solutions using the Pell recurrence
while n <= LIMIT:
    n, b = (
        3 * n + 4 * b - 3,
        2 * n + 3 * b - 2
    )

print(b)
```---
