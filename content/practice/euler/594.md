## Giải pháp 

**Trả lời:**`47067598`Cho phép$$O_{a,b}$$là hình bát giác lồi có các góc bằng nhau có độ dài các cạnh xen kẽ giữa$a$Và$b$. 

Chúng ta phải tính toán$$t(O_{4,2}),$$số lượng các ô xếp theo hình vuông đơn vị và hình thoi đơn vị (với các góc$45^\circ/135^\circ$). 

Một cách tiêu chuẩn để giải quyết các vấn đề xếp lớp này là chuyển chúng thành các họ đường mạng không giao nhau và sau đó áp dụng định lý xác định Lindström–Gessel–Viennot (LGV).

# 1. Phân tích toán học 

Hình bát giác$$(a,b,c,d,a,b,c,d)$$với các góc bằng nhau$135^\circ$thừa nhận một biểu diễn đường de Bruijn: mỗi lát gạch tương ứng duy nhất với một tập hợp các đường dẫn đơn điệu. 

Đối với họ này, công thức liệt kê định thức của Elnitsky cho:$$T_{a,b,c,d} = \sum_{X,Y} \left( \prod_{u=1}^{d+1}\det M^{(u)} \right) \left( \prod_{v=1}^{b+1}\det P^{(v)} \right),$$Ở đâu:

-$X=(x_{k,\ell})$là một sự đơn điệu$b\times d$ma trận với các mục trong$[0,a]$, 
-$Y=(y_{k,\ell})$là một đơn điệu đảo ngược$b\times d$ma trận với các mục trong$[0,c]$, 
- các yếu tố quyết định tính các họ đường dẫn không giao nhau thông qua LGV. 

Đối với đa giác Project Euler,$$O_{a,b}=(a,b,a,b,a,b,a,b),$$vì vậy chúng tôi thiết lập$$(a,b,c,d)=(a,b,a,b).$$Các ma trận là:$$M^{(u)}_{ij} = \binom{ (x_{j,u}-x_{i,u-1})+(y_{j,u}-y_{i,u-1}) }{ (x_{j,u}-x_{i,u-1})+(j-i) },$$Và$$P^{(v)}_{ij} = \binom{ (x_{v,j}-x_{v-1,i})+(y_{v-1,i}-y_{v,j}) }{ (x_{v,j}-x_{v-1,i})+(j-i) }.$$Tổng số ô có được bằng cách tính tổng các tích của các định thức này trên tất cả các mảng đơn điệu được chấp nhận$X,Y$.

#2. Triển khai Python```python
from math import comb

def gen_monotone_matrices(rows, cols, max_value):
    """
    Generate all matrices M such that:
        M[i][j] >= M[i-1][j]
        M[i][j] >= M[i][j-1]
    with entries in [0, max_value].
    """
    m = [[0] * cols for _ in range(rows)]

    def rec(pos):
        if pos == rows * cols:
            yield tuple(tuple(r) for r in m)
            return

        i, j = divmod(pos, cols)

        lo = 0
        if i > 0:
            lo = max(lo, m[i - 1][j])
        if j > 0:
            lo = max(lo, m[i][j - 1])

        for v in range(lo, max_value + 1):
            m[i][j] = v
            yield from rec(pos + 1)

    yield from rec(0)

def det_bareiss(mat):
    """
    Exact determinant using the Bareiss algorithm.
    """
    n = len(mat)

    if n == 0:
        return 1

    a = [row[:] for row in mat]
    sign = 1
    prev = 1

    for k in range(n - 1):

        if a[k][k] == 0:
            for i in range(k + 1, n):
                if a[i][k]:
                    a[k], a[i] = a[i], a[k]
                    sign = -sign
                    break
            else:
                return 0

        pivot = a[k][k]

        for i in range(k + 1, n):
            for j in range(k + 1, n):
                a[i][j] = (
                    a[i][j] * pivot
                    - a[i][k] * a[k][j]
                ) // prev

        prev = pivot

    return sign * a[-1][-1]

def count_tilings_octagon(a, b, c, d):

    X = list(gen_monotone_matrices(b, d, a))

    Y = []
    for y_rev in gen_monotone_matrices(b, d, c):
        y = tuple(
            tuple(y_rev[b - 1 - i][j] for j in range(d))
            for i in range(b)
        )
        Y.append(y)

    total = 0

    for x in X:

        x_full = [[0] * (d + 2) for _ in range(b + 2)]

        for k in range(1, b + 1):
            for l in range(1, d + 1):
                x_full[k][l] = x[k - 1][l - 1]

        for k in range(1, b + 1):
            x_full[k][d + 1] = a

        for l in range(d + 2):
            x_full[b + 1][l] = a

        for y in Y:

            y_full = [[0] * (d + 2) for _ in range(b + 2)]

            for k in range(1, b + 1):
                for l in range(1, d + 1):
                    y_full[k][l] = y[k - 1][l - 1]

            for k in range(1, b + 1):
                y_full[k][d + 1] = c

            for l in range(d + 2):
                y_full[0][l] = c

            prod = 1

            # Product of det(M^(u))
            for u in range(1, d + 2):

                M = []

                for i in range(1, b + 1):

                    row = []

                    for j in range(1, b + 1):

                        A = (
                            x_full[j][u] - x_full[i][u - 1]
                            + y_full[j][u] - y_full[i][u - 1]
                        )

                        B = (
                            x_full[j][u] - x_full[i][u - 1]
                            + (j - i)
                        )

                        row.append(comb(A, B) if 0 <= B <= A else 0)

                    M.append(row)

                prod *= det_bareiss(M)

                if prod == 0:
                    break

            if prod == 0:
                continue

            # Product of det(P^(v))
            for v in range(1, b + 2):

                P = []

                for i in range(1, d + 1):

                    row = []

                    for j in range(1, d + 1):

                        A = (
                            x_full[v][j] - x_full[v - 1][i]
                            + y_full[v - 1][i] - y_full[v][j]
                        )

                        B = (
                            x_full[v][j] - x_full[v - 1][i]
                            + (j - i)
                        )

                        row.append(comb(A, B) if 0 <= B <= A else 0)

                    P.append(row)

                prod *= det_bareiss(P)

                if prod == 0:
                    break

            total += prod

    return total

def t_O_ab(a, b):
    return count_tilings_octagon(a, b, a, b)

# Verify given examples
print(t_O_ab(1, 1))  # 8
print(t_O_ab(2, 1))  # 76
print(t_O_ab(3, 2))  # 456572

# Required value
print(t_O_ab(4, 2))

#3. Hướng dẫn sử dụng mã 

-`gen_monotone_matrices(...)`tạo ra tất cả các mảng đơn điệu$X$Và$Y$. 
-`det_bareiss(...)`tính toán chính xác các định thức bằng thuật toán Bareiss không có phân số. 
-`count_tilings_octagon(...)`thực hiện trực tiếp công thức định thức. 
-`t_O_ab(a,b)`chuyên hóa hình bát giác chung thành hình Project Euler. 

Các đầu ra xác minh là:$$t(O_{1,1})=8, \qquad t(O_{2,1})=76, \qquad t(O_{3,2})=456572,$$khớp chính xác với tuyên bố vấn đề. 

Cuối cùng, tính toán cho:$$t(O_{4,2}) = 47067598.$$---
