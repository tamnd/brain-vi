[Vấn đề dự án Euler 309](https://projecteuler.net/problem=309) 

##Giải pháp 

**Trả lời:**`210139`Gọi chiều rộng của đường là$w$. Giả sử các thang có chiều dài$x<y$, chạm vào các bức tường đối diện ở độ cao$a$Và$b$, tương ứng. 

Theo định lý Pythagore:$$a^2+w^2=x^2,\qquad b^2+w^2=y^2$$Vì thế$a,b$phải là số nguyên. Chiều cao vượt qua$h$thỏa mãn quan hệ bậc thang chéo tiêu chuẩn:$$\frac1h=\frac1a+\frac1b$$sắp xếp lại để$$h=\frac{ab}{a+b}$$Vì vậy, đối với số nguyên$h$, chúng ta cần:$$a+b \mid ab$$Vì vậy, vấn đề trở thành: 

1. Tìm tất cả các tam giác vuông nguyên có cạnh chung$w$:$$x^2=w^2+a^2,\qquad y^2=w^2+b^2$$2. Đối với mỗi cặp chia sẻ giống nhau$w$, đếm những người có$$\frac{ab}{a+b}\in \mathbb Z$$Một quan sát quan trọng là mọi giá trị hợp lệ$(w,a,x)$là bộ ba Pythagore. Chúng ta có thể tạo ra tất cả các bộ ba như vậy một cách hiệu quả bằng công thức Euclid:$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2$$với$\gcd(m,n)=1$và tính chẵn lẻ ngược lại, sau đó chia tỷ lệ theo$k$. 

Đối với mỗi chiều rộng$w$, thu thập tất cả các cấu hình bậc thang có thể$(a,x)$, sau đó kiểm tra từng cặp:$$h=\frac{ab}{a+b}$$Nếu như$h$là tích phân, đếm bộ ba$(x,y,h)$.

### Triển khai Python```python
from math import gcd, isqrt
from collections import defaultdict

LIMIT = 1_000_000

# width -> list of (height, ladder_length)
by_width = defaultdict(list)

# Generate all Pythagorean triples
m_max = isqrt(LIMIT) + 2

for m in range(2, m_max):
    for n in range(1, m):
        # Primitive triple conditions
        if gcd(m, n) != 1 or (m - n) % 2 == 0:
            continue

        a = m * m - n * n
        b = 2 * m * n
        c = m * m + n * n

        k = 1
        while k * c < LIMIT:
            aa = k * a
            bb = k * b
            cc = k * c

            # Either leg can be the street width
            if aa < LIMIT:
                by_width[aa].append((bb, cc))
            if bb < LIMIT:
                by_width[bb].append((aa, cc))

            k += 1

count = 0

# For each common width, test pairs
for w, configs in by_width.items():
    L = len(configs)

    for i in range(L):
        a, x = configs[i]

        for j in range(i + 1, L):
            b, y = configs[j]

            # Need x < y (avoid duplicates)
            if x == y:
                continue

            # h = ab / (a + b) must be integer
            if (a * b) % (a + b) == 0:
                count += 1

print(count)
```--- 

### Hướng dẫn sử dụng mã 

- **Tạo bộ ba Pythagore** 

- Công thức Euclid sinh ra mọi tam giác vuông nguyên thủy. 
- Nhân với$k$để có được tất cả những cái không nguyên thủy. 
- Lưu trữ mọi khả năng được khóa theo chiều rộng chung$w$. 
- **Ghép cặp thang có cùng chiều rộng** 

- Với mỗi chiều rộng, mỗi mục được lưu trữ đều có thể là một bậc thang. 
- So sánh từng cặp. 
- **Kiểm tra chiều cao vượt qua số nguyên** 

- Sử dụng$$h=\frac{ab}{a+b}$$- Chỉ đếm khi chia hết.
