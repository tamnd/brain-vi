[Vấn đề dự án Euler 391](https://projecteuler.net/problem=391) 

##Giải pháp 

**Trả lời:**`61029882288`Cho phép$$s_k=\sum_{i=0}^k \operatorname{popcount}(i),$$Ở đâu$\operatorname{popcount}(i)$là số bit 1 trong khai triển nhị phân của$i$. 

Các vị trí trò chơi hợp pháp chính xác là các giá trị$$S=\{s_0,s_1,s_2,\dots\}.$$Sự khác biệt giữa các phần tử liên tiếp là$$s_{k+1}-s_k=\operatorname{popcount}(k+1).$$Vì vậy việc chuyển từ$s_a$ĐẾN$s_b$là hợp pháp nếu$$s_b-s_a\le n.$$--- 

# 1. Phân tích toán học 

## Cấu trúc trò chơi khách quan 

Đây là một trò chơi bình thường, công bằng nên các vị trí được phân thành: 

- **Vị trí P** (người chơi trước thắng / thua vị trí), 
- **N-vị trí** (người chơi tiếp theo thắng / vị trí chiến thắng). 

Một vị trí sẽ thua nếu mọi nước đi hợp pháp đều dẫn đến vị trí thắng. 

Vì biểu đồ trò chơi hoàn toàn có thứ tự nên các vị thế thua có thể được tạo ra một cách tham lam. 

--- 

## Quan sát chính 

Giả sử các vị trí thua lỗ là$$p_0 < p_1 < p_2 < \cdots.$$Sau đó: 

- mọi vị trí trong$S$trong khoảng cách$\le n$của một vị trí thua là thắng, 
- do đó vị trí thua tiếp theo chỉ đơn giản là yếu tố đầu tiên của$S$đó là nhiều hơn$n$thoát khỏi vị trí thua cuộc trước đó. 

Vì thế:$$p_{k+1}=\min\{x\in S : x-p_k>n\}.$$Sự tái diễn này hoàn toàn quyết định trò chơi. 

Nước đi đầu tiên sẽ thắng nếu rơi vào thế thua, do đó$$M(n)=\max\{p_k : p_k\le n\}.$$--- 

## Tạo hiệu quả$S$Chúng tôi không chuyển đổi rõ ràng mọi số nguyên thành nhị phân. 

Sử dụng:$$s_{k+1}=s_k+\operatorname{popcount}(k+1).$$Tính toán popcount cực kỳ nhanh trong Python bằng cách sử dụng`bit_count()`. 

--- 

## Tính toán hiệu quả của$M(n)$Đối với một cố định$n$: 

1. Tạo đủ giá trị của$S$. 
2. Tạo các vị thế thua lỗ một cách tham lam: 

- bắt đầu với vị trí thua đầu tiên, 
- liên tục nhảy tới phần tử đầu tiên của$S$xa hơn$n$. 
3. Vị thế thua lỗ lớn nhất$\le n$là$M(n)$. 

Làm điều này cho$1\le n\le1000$rất nhanh. 

Báo cáo vấn đề đưa ra kiểm tra:$$\sum_{n=1}^{20} M(n)^3 = 8150.$$Chương trình của chúng tôi tái tạo chính xác điều này. 

--- 

#2. Triển khai Python```python
from bisect import bisect_right

# ---------------------------------------------------------
# Generate the sequence S = {s_k}
# s_k = total number of 1-bits appearing in 0..k
# ---------------------------------------------------------

LIMIT = 300000

S = [0]
cur = 0

for k in range(1, LIMIT + 1):
    cur += k.bit_count()
    S.append(cur)

# ---------------------------------------------------------
# Compute M(n)
# ---------------------------------------------------------

def M(n):
    # Generate losing positions greedily.
    losing = []

    # First losing position:
    # the first element of S having no predecessor within distance <= n
    p = next(x for x in S if x > n)
    losing.append(p)

    # Generate more losing positions
    idx = bisect_right(S, p + n)

    while idx < len(S):
        p = S[idx]
        losing.append(p)
        idx = bisect_right(S, p + n)

        # We only care about losing positions <= n
        if p > n:
            break

    # Largest losing position <= n
    ans = 0
    for x in losing:
        if x <= n:
            ans = x

    return ans

# ---------------------------------------------------------
# Verify the sample
# ---------------------------------------------------------

check = sum(M(n) ** 3 for n in range(1, 21))
print(check)   # 8150

# ---------------------------------------------------------
# Final computation
# ---------------------------------------------------------

answer = sum(M(n) ** 3 for n in range(1, 1001))
print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

## Đang tạo$S$

```python
cur += k.bit_count()
S.append(cur)
```Từ$$s_k=s_{k-1}+\operatorname{popcount}(k),$$chúng tôi xây dựng trình tự tăng dần. 

--- 

## Xây dựng vị thế thua lỗ 

Dòng quan trọng là:```python
idx = bisect_right(S, p + n)
```Mọi động thái hợp pháp từ$p$đất ở$$[p+1,\;p+n].$$Tất cả những vị trí đó đều đang chiến thắng. 

Vì vậy vị trí thua tiếp theo là yếu tố đầu tiên của$S$thực sự lớn hơn$p+n$. 

Tìm kiếm nhị phân thực hiện điều này$O(\log |S|)$.
