##Giải pháp 

**Trả lời:**`4037526`Cho phép$$p=\frac{x^4-y^4}{x^3+y^3}$$với$x,y\in \mathbb Z_{>0}$, và giả sử$p$là nguyên tố. 

Chúng ta phải đếm tất cả các số nguyên tố như vậy dưới đây$5\times 10^{15}$. 

--- 

# 1. Phân tích toán học 

Chúng ta bắt đầu bằng cách đơn giản hóa biểu thức.$$x^4-y^4=(x-y)(x+y)(x^2+y^2)$$Và$$x^3+y^3=(x+y)(x^2-xy+y^2).$$Vì thế$$p=\frac{(x-y)(x+y)(x^2+y^2)}          {(x+y)(x^2-xy+y^2)}$$Vì thế$$p=\frac{(x-y)(x^2+y^2)}{x^2-xy+y^2}.$$--- 

## Bước 1: Loại bỏ các thừa số chung 

hãy để$$x=da,\qquad y=db,$$với$\gcd(a,b)=1$. 

Sau đó$$p=d\cdot \frac{(a-b)(a^2+b^2)}{a^2-ab+b^2}.$$Bây giờ hãy kiểm tra gcds. 

Bởi vì$\gcd(a,b)=1$,$$\gcd(a^2+b^2,\ a^2-ab+b^2)=1.$$Thực vậy,$$(a^2+b^2)-(a^2-ab+b^2)=ab,$$và bất kỳ ước số chung nào cũng sẽ chia cả hai$ab$Và$a^2+b^2$, buộc nó phải như vậy$1$. 

Do đó mẫu số phải chia$d(a-b)$. 

Vì vậy hãy viết$$d=k(a^2-ab+b^2).$$Thay thế trở lại:$$p=k(a-b)(a^2+b^2).$$Từ$p$là số nguyên tố và mọi đại lượng đều là số nguyên dương nên ta phải có$$k=1,\qquad a-b=1.$$Như vậy$$a=b+1.$$Cho phép$b=n$. Sau đó$$a=n+1.$$Do đó mọi số nguyên tố Panaitopol đều có dạng$$p=n^2+(n+1)^2.$$Mở rộng:$$p=2n^2+2n+1.$$Ngược lại, mọi số nguyên tố có dạng này đều là số nguyên tố Panaitopol (lấy$x=(n+1)(n^2+n+1)$,$y=n(n^2+n+1)$). 

Vì vậy, vấn đề trở thành: 

> Đếm số nguyên tố có dạng 
> 
> 
> 
> 
>$$2n^2+2n+1 < 5\times 10^{15}.$$--- 

# 2. Giới hạn$n$Chúng tôi cần$$2n^2+2n+1 < 5\times 10^{15}.$$Giải quyết:$$n \le 49\,999\,999.$$Vì vậy chúng tôi kiểm tra$n=0,1,\dots,49\,999\,999$. 

--- 

#3. Sàng nguyên tố hiệu quả 

Xác định$$f(n)=2n^2+2n+1.$$Một số nguyên tố$q\neq 2$chia rẽ$f(n)$nếu$$2n^2+2n+1 \equiv 0 \pmod q.$$Nhân với$2$:$$(2n+1)^2 \equiv -1 \pmod q.$$Vì vậy, giải pháp tồn tại nếu$-1$là mod thặng dư bậc hai$q$, tức là$$q\equiv 1 \pmod 4.$$Với mỗi số nguyên tố như vậy$q$, có đúng hai lớp thặng dư modulo$q$điều đó làm$f(n)$chia hết cho$q$. Chúng tôi sàng lọc các lớp cặn đó. 

Bất kỳ giá trị tổng hợp nào dưới đây$5\times10^{15}$có thừa số nguyên tố dưới đây$$\sqrt{5\times10^{15}} \approx 7.1\times10^7.$$Do đó sàng lọc theo mọi số nguyên tố$q\le \sqrt{5\times10^{15}}$với$q\equiv1\pmod4$hoàn toàn xác định tính nguyên thủy.

#4. Triển khai Python```python
import math

LIMIT = 5 * 10**15

# Largest n with 2n^2 + 2n + 1 < LIMIT
NMAX = (math.isqrt(2 * LIMIT - 1) - 1) // 2

# We only need prime divisors up to sqrt(LIMIT)
PMAX = math.isqrt(LIMIT) + 1

# ---------------------------------------------------------
# Standard sieve of Eratosthenes
# ---------------------------------------------------------
sieve = bytearray(b"\x01") * (PMAX + 1)
sieve[0:2] = b"\x00\x00"

primes = []

for p in range(2, PMAX + 1):
    if sieve[p]:
        primes.append(p)

        step = p
        start = p * p

        if start <= PMAX:
            sieve[start:PMAX + 1:step] = b"\x00" * (
                (PMAX - start) // step + 1
            )

# ---------------------------------------------------------
# Tonelli-Shanks algorithm:
# Computes sqrt(n) mod p for odd prime p
# ---------------------------------------------------------
def mod_pow(a, e, mod):
    result = 1
    while e:
        if e & 1:
            result = (result * a) % mod
        a = (a * a) % mod
        e >>= 1
    return result

def tonelli(n, p):
    """
    Solve x^2 = n (mod p), p odd prime.
    Returns one square root.
    """

    if p == 2:
        return 1

    # Euler criterion
    if mod_pow(n, (p - 1) // 2, p) != 1:
        return None

    if p % 4 == 3:
        return mod_pow(n, (p + 1) // 4, p)

    # Factor p-1 = q * 2^s with q odd
    q = p - 1
    s = 0

    while q % 2 == 0:
        s += 1
        q //= 2

    # Find quadratic non-residue z
    z = 2
    while mod_pow(z, (p - 1) // 2, p) != p - 1:
        z += 1

    c = mod_pow(z, q, p)
    x = mod_pow(n, (q + 1) // 2, p)
    t = mod_pow(n, q, p)
    m = s

    while t != 1:
        i = 1
        tt = (t * t) % p

        while tt != 1:
            tt = (tt * tt) % p
            i += 1

        b = mod_pow(c, 1 << (m - i - 1), p)

        x = (x * b) % p
        t = (t * b * b) % p
        c = (b * b) % p
        m = i

    return x

# ---------------------------------------------------------
# Precompute residue classes for each p == 1 mod 4
# ---------------------------------------------------------
roots = []

for p in primes:
    if p % 4 != 1:
        continue

    # Need sqrt(-1) mod p
    r = tonelli(p - 1, p)

    inv2 = (p + 1) // 2

    # Solutions of 2n^2 + 2n + 1 == 0 (mod p)
    n1 = ((r - 1) * inv2) % p
    n2 = ((-r - 1) * inv2) % p

    roots.append((p, n1, n2))

# ---------------------------------------------------------
# Segmented sieve over n
# ---------------------------------------------------------
BLOCK = 5_000_000

count = 0

for low in range(0, NMAX + 1, BLOCK):

    high = min(low + BLOCK - 1, NMAX)
    size = high - low + 1

    is_prime_value = bytearray(b"\x01") * size

    for p, r1, r2 in roots:

        # Mark first residue class
        start = r1
        if start < low:
            start += ((low - start + p - 1) // p) * p

        for n in range(start, high + 1, p):
            value = 2 * n * n + 2 * n + 1

            # Do not mark the prime itself
            if value != p:
                is_prime_value[n - low] = 0

        # Mark second residue class
        if r2 != r1:

            start = r2
            if start < low:
                start += ((low - start + p - 1) // p) * p

            for n in range(start, high + 1, p):
                value = 2 * n * n + 2 * n + 1

                if value != p:
                    is_prime_value[n - low] = 0

    count += sum(is_prime_value)

print(count)

### Thế hệ Prime 

Đầu tiên chúng ta tạo ra tất cả các số nguyên tố lên đến$$\sqrt{5\times10^{15}}.$$Đây là những yếu tố nhỏ duy nhất có thể có của bất kỳ ứng cử viên tổng hợp nào. 

--- 

### Tonelli–Shanks 

Đối với mỗi số nguyên tố$p\equiv1\pmod4$, chúng tôi giải quyết$$x^2\equiv -1 \pmod p.$$Điều này cung cấp cho các lớp dư lượng nơi$$2n^2+2n+1\equiv0\pmod p.$$--- 

### Sàng phân đoạn

Đối với mỗi số nguyên tố$p\equiv1\pmod4$, chúng tôi đánh dấu tất cả$n$trong các lớp dư lượng tương ứng modulo$p$. 

Sau khi đánh dấu xong, các mục còn lại tương ứng chính xác với các giá trị nguyên tố của$$2n^2+2n+1.$$---
