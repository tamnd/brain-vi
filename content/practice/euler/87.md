[Vấn đề dự án Euler 87](https://projecteuler.net/problem=87) 

##Giải pháp 

**Trả lời:**`1097343`Chúng tôi muốn số số nguyên dưới đây$50{,}000{,}000$có thể được viết là$$n = p_2^2 + p_3^3 + p_4^4$$Ở đâu$p_2,p_3,p_4$là số nguyên tố. 

Thử thách chính là **đếm các giá trị riêng biệt**, vì nhiều bộ ba nguyên tố có thể tạo ra cùng một tổng. 

## 1. Phân tích toán học 

Hãy để giới hạn là$$L = 50{,}000{,}000.$$Chúng tôi cần tất cả các số$$p^2 + q^3 + r^4 < L$$với$p,q,r$xuất sắc. 

### Bước 1: Giới hạn tìm kiếm 

Vì tất cả các số hạng đều dương nên mỗi số nguyên tố chỉ cần được tạo ra ở một mức tối đa nhất định. 

Đối với quyền hạn thứ tư:$$r^4 < L \Rightarrow r < L^{1/4}.$$Từ$$50{,}000{,}000^{1/4} \approx 84,$$chúng ta chỉ cần số nguyên tố lên tới 83. 

Đối với hình khối:$$q^3 < L \Rightarrow q < L^{1/3}.$$Từ$$50{,}000{,}000^{1/3} \approx 368,$$chúng ta chỉ cần số nguyên tố lên tới 367. 

Đối với hình vuông:$$p^2 < L \Rightarrow p < \sqrt{L}.$$Từ$$\sqrt{50{,}000{,}000}\approx 7071,$$chúng ta chỉ cần số nguyên tố lên tới 7071. 

Vì vậy, không gian tìm kiếm thực sự rất nhỏ: 

- số nguyên tố: khoảng 900 số nguyên tố, 
- khối nguyên tố: khoảng 70 số nguyên tố, 
- lũy thừa thứ tư: khoảng 20 số nguyên tố. 

Tổng số kết hợp là khoảng$$900 \times 70 \times 20 \approx 1.26\times10^6,$$đó là tầm thường về mặt tính toán. 

### Bước 2: Tránh trùng lặp 

Các bộ ba khác nhau có thể tạo ra cùng một số tiền. 

Ví dụ:$$p_1^2 + q_1^3 + r_1^4 = p_2^2 + q_2^3 + r_2^4.$$Chúng tôi chỉ đếm số một lần. 

Cách tiếp cận rõ ràng nhất là lưu trữ mọi tổng hợp lệ trong một **bộ**, vì các bộ tự động loại bỏ các bản sao. 

### Bước 3: Tạo hiệu quả 

Tính toán trước: 

- tất cả các ô vuông nguyên tố bên dưới$L$, 
- tất cả các hình khối bên dưới$L$, 
- tất cả các lũy thừa thứ tư dưới đây$L$. 

Sau đó lặp lại:$$s = a+b+c$$và chèn vào một bộ bất cứ khi nào$$s < L.$$Chúng ta có thể cắt tỉa sớm vì danh sách đã được sắp xếp: 

- nếu$a+b \ge L$, dừng các vòng lặp bên trong, 
- nếu$a+b+c \ge L$, dừng vòng lặp sâu nhất.

## 2. Triển khai Python```python
from math import isqrt

LIMIT = 50_000_000

def sieve(n):
    """Return list of primes <= n using Sieve of Eratosthenes."""
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for p in range(2, isqrt(n) + 1):
        if is_prime[p]:
            for multiple in range(p * p, n + 1, p):
                is_prime[multiple] = False

    return [i for i, prime in enumerate(is_prime) if prime]

# Generate primes only up to the needed maximum
max_prime = isqrt(LIMIT)
primes = sieve(max_prime)

# Precompute prime powers under LIMIT
prime_squares = [p**2 for p in primes if p**2 < LIMIT]
prime_cubes = [p**3 for p in primes if p**3 < LIMIT]
prime_fourths = [p**4 for p in primes if p**4 < LIMIT]

# Store distinct representable numbers
values = set()

for square in prime_squares:
    for cube in prime_cubes:
        partial = square + cube

        if partial >= LIMIT:
            break

        for fourth in prime_fourths:
            total = partial + fourth

            if total >= LIMIT:
                break

            values.add(total)

print(len(values))
```---
