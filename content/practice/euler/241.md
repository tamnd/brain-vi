##Giải pháp 

**Trả lời:**`482316491800641154`Cho phép$$p(n)=\frac{\sigma(n)}{n}, \qquad \sigma(n)=\sum_{d\mid n} d.$$Chúng tôi muốn tất cả$n\le 10^{18}$như vậy$$p(n)=k+\frac12$$đối với một số nguyên$k$. Tương đương,$$\frac{\sigma(n)}{n}=\frac{2k+1}{2},$$vậy mẫu số rút gọn của$p(n)$phải chính xác$2$. 

--- 

# 1. Phân tích toán học 

Viết$$n=\prod p_i^{a_i}.$$Sử dụng phép nhân của$\sigma$,$$\frac{\sigma(n)}{n} = \prod_i \frac{p_i^{a_i+1}-1}{p_i^{a_i}(p_i-1)}.$$Định nghĩa$$R(n)=\frac{\sigma(n)}{n}.$$Chúng ta cần dạng rút gọn của$R(n)$có mẫu số$2$. 

--- 

## Ý tưởng đệ quy chính 

Giả sử ở một giai đoạn nào đó chúng ta có$$\frac{\sigma(n)}{n}=\frac{A}{B}$$trong điều kiện thấp nhất. 

Chúng tôi muốn cuối cùng$B=2$. 

Thay vì xây dựng$R(n)$trực tiếp, chúng tôi theo dõi đệ quy “yếu tố còn thiếu” cần thiết để đạt được nửa số nguyên. 

Cho phép$$\frac{rn}{rs}$$là phân số rút gọn sao cho$$R(n)\cdot \frac{rn}{rs}$$vẫn là một nửa số nguyên ứng cử viên. 

Ban đầu, nếu nửa số nguyên đích là$$\frac{x}{2} \qquad (x \text{ odd}),$$sau đó chúng ta bắt đầu với$$(rn,rs)=(x,2).$$Bây giờ giả sử chúng ta nhân$n$qua$p^e$. Sau đó$$R(np^e) = R(n)\cdot \frac{p^{e+1}-1}{p^e(p-1)}.$$Vì vậy chúng tôi cập nhật$$rn \leftarrow rn\cdot p^e,$$

$$rs \leftarrow rs\cdot \frac{p^{e+1}-1}{p-1},$$và giảm đi gcd. 

Nếu cuối cùng$$rn=rs=1,$$thì yếu tố còn lại cần thiết là$1$, vậy là chúng ta đã đạt được thương số hoàn hảo nửa số nguyên hợp lệ. 

--- 

## Tại sao đệ quy là hữu hạn 

Ở mỗi bước: 

- ta chọn ước số nguyên tố nhỏ nhất của$rs$, 
- buộc số nguyên tố đó vào hệ số của$n$, 
- và cấu trúc mẫu số nhanh chóng sụp đổ. 

Điều này tạo ra một cây tìm kiếm rất nhỏ. Trên thực tế, chỉ có **22** số hợp lệ bên dưới$10^{18}$. 

Tổng của họ là câu trả lời cần thiết.

#2. Triển khai Python```python
from math import gcd

LIMIT = 10**18

def smallest_prime_factor(n):
    """Return the smallest prime factor of n."""
    if n % 2 == 0:
        return 2

    d = 3
    while d * d <= n:
        if n % d == 0:
            return d
        d += 2

    return n

solutions = []

def dfs(n, rn, rs):
    """
    Recursive search.

    n  = current integer being built
    rn/rs = remaining correction factor
    """

    # Prune: even the minimal remaining multiplier is too large
    if n * rs > LIMIT:
        return

    # Success condition
    if rn == 1 and rs == 1:
        solutions.append(n)

    # Nothing more to do
    if rs == 1:
        return

    # Force the smallest prime dividing rs
    p = smallest_prime_factor(rs)

    # p must not already divide n
    if gcd(p, n) != 1:
        return

    # exponent of p inside rs
    e = 1
    while rs % (p ** (e + 1)) == 0:
        e += 1

    power = p ** e

    # Try larger exponents as well
    for exp in range(e, 60):

        new_n = n * power

        if new_n > LIMIT:
            break

        # Multiply correction fraction appropriately
        new_rn = rn * power

        sigma_part = (power * p - 1) // (p - 1)

        new_rs = rs * sigma_part

        g = gcd(new_rn, new_rs)

        dfs(new_n, new_rn // g, new_rs // g)

        power *= p

# The target numerator must be odd.
# Small odd starting values are sufficient.
for odd in range(3, 13, 2):
    dfs(1, odd, 2)

answer = sum(solutions)

print(sorted(solutions))
print(answer)
```---

# 4. Xác minh ví dụ nhỏ 

cho$n=24$,$$24=2^3\cdot 3.$$Sau đó$$\sigma(24)=1+2+3+4+6+8+12+24=60.$$Vì thế$$\frac{\sigma(24)}{24} = \frac{60}{24} = \frac52 = 2+\frac12.$$Vì thế$24$là hợp lệ. 

Chương trình bao gồm nó một cách chính xác.
