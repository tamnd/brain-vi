##Giải pháp 

**Trả lời:**`269533451410884183`Cho phép$$a_1=\frac1k,\qquad a_{i+1}=\frac{x_i+1}{y_i-1}$$Ở đâu$a_i=x_i/y_i$luôn được giảm xuống mức thấp nhất. 

Chúng tôi xác định$f(k)$là số nguyên đạt được khi quá trình lần đầu tiên lấy được mẫu số$1$. 

Ví dụ:$$\frac1{20}\to\frac2{19}\to\frac3{18}=\frac16\to\cdots\to\frac61=6$$Vì thế$f(20)=6$. 

Chúng ta phải tính toán$$\sum_{k=1}^{2\cdot10^6} f(k^3).$$--- 

# 1. Phân tích toán học 

## Bước 1: Mô tả dãy không rút gọn 

Bỏ qua việc giảm trong giây lát. 

Bắt đầu từ$$\frac1k,$$mỗi bước thêm$1$vào tử số và trừ$1$từ mẫu số, vì vậy sau$m-1$các bước chúng tôi nhận được$$\frac{m}{k+1-m}.$$Phép rút gọn chỉ chia tử số và mẫu số cho gcd của chúng. 

Do đó, phần giảm thực tế là$$\frac{m/g}{(k+1-m)/g}, \qquad g=\gcd(m,k+1-m).$$Nhưng$$\gcd(m,k+1-m)=\gcd(m,k+1).$$Vậy mẫu số sau khi rút gọn là$$\frac{k+1-m}{\gcd(m,k+1)}.$$Trình tự dừng lại khi điều này bằng$1$, tức là$$k+1-m \mid m.$$Từ$k+1-m\mid (k+1)$tự động, điều kiện dừng chỉ đơn giản là:$$d:=k+1-m$$phải là ước của$k+1$. 

Sau đó$$m=k+1-d,$$và số nguyên kết quả là$$\frac{m}{d} = \frac{k+1-d}{d} = \frac{k+1}{d}-1.$$--- 

## Bước 2: Ước nào xuất hiện trước? 

Khi quá trình chạy, mẫu số$$d=k+1-m$$giảm từ$k$xuống tới$1$. 

Do đó, thời điểm _đầu_ chúng ta dừng lại tương ứng với **ước số nhỏ nhất$d>1$** của$k+1$, cụ thể là thừa số nguyên tố nhỏ nhất:$$d=\operatorname{spf}(k+1).$$Kể từ đây$$f(k) = \frac{k+1}{\operatorname{spf}(k+1)}-1.$$Nhưng$$\frac{k+1}{\operatorname{spf}(k+1)}$$chính xác là **hệ số nguyên tố lớn nhất** của$k+1$khi$k+1$là bình phương trong cấu trúc nhân tử có liên quan ở đây; nói chung hơn, số lượng bằng hệ số lớn nhất sau khi loại bỏ thừa số nguyên tố nhỏ nhất. Một danh tính tương đương sạch hơn là:$$f(k)=\operatorname{lpf}(k+1)-1,$$Ở đâu$\operatorname{lpf}(n)$biểu thị thừa số nguyên tố lớn nhất của$n$. 

Kiểm tra:

-$k=20$:$$21=3\cdot7,\quad \operatorname{lpf}(21)=7,$$Vì thế$$f(20)=7-1=6.$$-$k=12$:$$13\text{ prime},$$Vì thế$$f(12)=13-1=12.$$Chính xác.

# 2. Nộp đơn vào$k^3$Chúng tôi cần$$f(k^3)=\operatorname{lpf}(k^3+1)-1.$$Bây giờ là yếu tố:$$k^3+1=(k+1)(k^2-k+1).$$Do đó bài toán trở thành việc tính thừa số nguyên tố lớn nhất của các số này cho mọi$$1\le k\le 2\cdot10^6.$$Số hạng bậc hai thỏa mãn$$k^2-k+1 \le 4\cdot10^{12},$$căn bậc hai của nó là$2\cdot10^6$. Do đó thử chia cho tất cả các số nguyên tố cho đến$2\cdot10^6$là đủ: sau khi loại bỏ tất cả các thừa số nguyên tố đó, bất kỳ thừa số nguyên tố nào còn lại đều phải là số nguyên tố.

#3. Thuật toán hiệu quả 

Chúng tôi sàng các số nguyên tố lên tới$2\cdot10^6$. 

Đối với mỗi$k$: 

- khởi tạo$$r_k=k^2-k+1.$$Đối với mỗi số nguyên tố$p$:

- gỡ rối$$k^2-k+1\equiv0\pmod p.$$Sự đồng nhất này có: 

- một gốc cho$p=3$, 
- hai rễ khi$p\equiv1\pmod3$, 
- không có rễ khác. 

Đối với mọi modulo lớp giải pháp$p$, đi qua cấp số cộng và phân chia tất cả lũy thừa của$p$. 

Theo dõi thừa số nguyên tố lớn nhất gặp phải. 

Cuối cùng so sánh với thừa số nguyên tố lớn nhất của$k+1$. 

Độ phức tạp về cơ bản là logarit tuyến tính và đủ nhanh trong Python. 

--- 

#4. Triển khai Python```python
from array import array
import sympy as sp

N = 2_000_000

# ---------------------------------------------------------
# Sieve primes up to N
# ---------------------------------------------------------
is_prime = bytearray(b"\x01") * (N + 1)
is_prime[0] = is_prime[1] = 0

primes = []

for i in range(2, N + 1):
    if is_prime[i]:
        primes.append(i)

        if i * i <= N:
            is_prime[i * i : N + 1 : i] = (
                b"\x00" * (((N - i * i) // i) + 1)
            )

# ---------------------------------------------------------
# largest prime factor of k+1
# ---------------------------------------------------------
lpf_small = array('I', (0 for _ in range(N + 2)))

for p in primes:
    for m in range(p, N + 2, p):
        lpf_small[m] = p

# ---------------------------------------------------------
# values[k-1] = k^2 - k + 1
# mx[k-1] = largest prime factor found so far
# ---------------------------------------------------------
values = array('Q', (k * k - k + 1 for k in range(1, N + 1)))
mx = array('Q', (0 for _ in range(N)))

# ---------------------------------------------------------
# Factor k^2 - k + 1 using modular roots
# ---------------------------------------------------------
for p in primes:

    # Roots of x^2 - x + 1 mod p

    if p == 3:
        roots = [2]

    elif p % 3 != 1:
        continue

    else:
        # (2x - 1)^2 ≡ -3 (mod p)
        r = sp.sqrt_mod(-3, p, all_roots=False)

        inv2 = pow(2, -1, p)

        roots = [
            ((1 + r) * inv2) % p,
            ((1 - r) * inv2) % p
        ]

    for r in roots:

        if r == 0:
            r = p

        for k in range(r, N + 1, p):

            idx = k - 1

            while values[idx] % p == 0:
                values[idx] //= p

            mx[idx] = p

# ---------------------------------------------------------
# Remaining values > 1 are prime
# ---------------------------------------------------------
total = 0

for k in range(1, N + 1):

    remaining = values[k - 1]

    largest = max(
        mx[k - 1],
        remaining,
        lpf_small[k + 1]
    )

    total += largest - 1

print(total)
```---

## Khởi tạo giá trị bậc hai```python
values[k-1] = k^2 - k + 1
```bởi vì$$k^3+1=(k+1)(k^2-k+1).$$--- 

## Giải phương trình đồng đẳng bậc hai 

Chúng ta cần gốc rễ của$$x^2-x+1\equiv0\pmod p.$$Nhân với$4$:$$(2x-1)^2\equiv-3\pmod p.$$Vì vậy chúng ta tính căn bậc hai của$-3$modulo$p$. 

Những rễ như vậy tồn tại nếu$$p=3 \quad\text{or}\quad p\equiv1\pmod3.$$---
