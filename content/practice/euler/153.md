## Giải pháp 

**Trả lời:**`17971254122360635`Cho phép$$S(N)=\sum_{n=1}^N s(n),$$Ở đâu$s(n)$là tổng của tất cả các ước số nguyên Gaussian của$n$phần thực của nó là dương. 

Chúng tôi được cung cấp:$$S(10^5)=17924657155.$$Chúng tôi tìm kiếm:$$S(10^8).$$--- 

# Phân tích toán học 

Một số nguyên Gaussian là$$a+bi,\qquad a,b\in\mathbb Z.$$Chuẩn mực của nó là$$N(a+bi)=a^2+b^2.$$Một số nguyên Gaussian$a+bi$chia số nguyên hợp lý$n$nếu$$\frac{n}{a+bi}$$lại là số nguyên Gaussian. 

--- 

## 1. Ước số hữu tỉ ($b=0$) 

Đây chỉ là những ước số dương thông thường của$n$. 

Tổng đóng góp của họ là$$\sum_{n\le N}\sigma(n),$$Ở đâu$\sigma(n)$là hàm tổng chia thông thường. 

Sử dụng danh tính chuyển đổi số chia tiêu chuẩn:$$\sum_{n\le N}\sigma(n) = \sum_{d\le N} d\left\lfloor \frac Nd\right\rfloor.$$--- 

## 2. Ước số Gaussian không thực 

Giả sử$$z=a+bi,\qquad b\neq 0.$$Sau đó$$\frac{n}{a+bi} = \frac{n(a-bi)}{a^2+b^2}.$$Để đây là tích phân Gaussian, cả hai$$\frac{na}{a^2+b^2}, \qquad \frac{nb}{a^2+b^2}$$phải là số nguyên. 

Viết$$a=ga',\qquad b=gb', \qquad \gcd(a',b')=1.$$Sau đó$$a^2+b^2=g^2(a'^2+b'^2).$$Từ$$\gcd(a',a'^2+b'^2)=1, \qquad \gcd(b',a'^2+b'^2)=1,$$điều kiện chia hết trở thành$$g(a'^2+b'^2)\mid n.$$Vì vậy, mọi ước số Gaussian đều xuất phát từ: 

- một cặp nguyên thủy$(a',b')$với$\gcd(a',b')=1$, 
- được chia tỷ lệ bởi$g$. 

--- 

## 3. Đóng góp của các cặp liên hợp 

Nếu$a+bi$chia rẽ$n$, thì cũng vậy$a-bi$. 

Tổng của họ là$$(a+bi)+(a-bi)=2a.$$Vì vậy phần ảo triệt tiêu hoàn toàn. 

Do đó, mọi cặp nguyên thủy chỉ đóng góp các giá trị thực. 

Cho phép$$m=a'^2+b'^2.$$Đối với mỗi quy mô$g$, cặp số chia đóng góp$$2ga'$$tới mọi bội số của$gm$. 

Do đó tổng đóng góp là$$\sum_{\substack{a',b'>0\\ \gcd(a',b')=1}} 2a' \sum_{g\le N/m} g\left\lfloor\frac{N}{gm}\right\rfloor.$$Nhưng$$\sum_{g\le M} g\left\lfloor\frac{M}{g}\right\rfloor = \sum_{k\le M}\sigma(k).$$Vì thế:$$S(N) = \sum_{d\le N} d\left\lfloor\frac Nd\right\rfloor + 2\sum_{\substack{a,b>0\\ \gcd(a,b)=1}} a\, \Sigma\!\left(\left\lfloor\frac{N}{a^2+b^2}\right\rfloor\right),$$Ở đâu$$\Sigma(x)=\sum_{n\le x}\sigma(n).$$Đây là công thức then chốt. 

--- 

# Thuật toán hiệu quả 

Chúng tôi cần: 

1. Tính toán nhanh$$\Sigma(x)=\sum_{n\le x}\sigma(n).$$Sử dụng nhóm chia:$$\Sigma(x) = \sum_{d\le x} d\left\lfloor\frac xd\right\rfloor.$$Điều này có thể được đánh giá ở$O(\sqrt x)$. 

1. Liệt kê các điểm mạng nguyên thủy$$a^2+b^2\le N.$$Chỉ có các cặp nguyên tố cùng nhau mới quan trọng. 

Thuật toán kết quả chạy nhanh thoải mái trong PyPy cho$N=10^8$. 

--- 

#Triển khai Python```python
from math import gcd, isqrt

N = 10**8

# Summatory sigma:
#   S(n) = sum_{k<=n} sigma(k)
#
# Using:
#   sum sigma(k) = sum d * floor(n/d)
#
# Computed in O(sqrt(n)) using divisor grouping.
def sigma_sum(n):
    total = 0
    d = 1

    while d <= n:
        q = n // d
        r = n // q

        # sum of integers d..r
        block = (d + r) * (r - d + 1) // 2

        total += q * block
        d = r + 1

    return total

# Memoize sigma_sum values because many repeats occur.
memo = {}

def Sigma(n):
    if n not in memo:
        memo[n] = sigma_sum(n)
    return memo[n]

# ----------------------------------------------------
# Rational integer divisors contribution
# ----------------------------------------------------

answer = Sigma(N)

# ----------------------------------------------------
# Non-real Gaussian divisors
# ----------------------------------------------------

limit = isqrt(N)

for a in range(1, limit + 1):

    max_b = isqrt(N - a * a)

    for b in range(1, max_b + 1):

        if gcd(a, b) != 1:
            continue

        m = a * a + b * b

        answer += 2 * a * Sigma(N // m)

print(answer)
```--- 

# Hướng dẫn sử dụng mã 

##`sigma_sum(n)`Tính toán$$\sum_{k\le n}\sigma(k).$$sử dụng$$\sum_{k\le n}\sigma(k) = \sum_{d\le n} d\left\lfloor\frac nd\right\rfloor.$$Giá trị của$\lfloor n/d\rfloor$không đổi trong các khoảng thời gian, vì vậy chúng tôi nhóm chúng lại thành$O(\sqrt n)$. 

--- 

## Đóng góp của số chia hợp lý```python
answer = Sigma(N)
```Điều này giải thích cho tất cả các ước số dương thông thường. 

--- 

## Ước số Gauss nguyên thủy 

Chúng tôi lặp lại các cặp nguyên tố cùng nhau:```python
if gcd(a, b) != 1:
    continue
```với```python
m = a*a + b*b
```Mỗi ước số Gaussian nguyên thủy như vậy đều đóng góp$$2a\cdot \Sigma\!\left(\left\lfloor\frac{N}{m}\right\rfloor\right).$$Vì thế:```python
answer += 2 * a * Sigma(N // m)
```---
