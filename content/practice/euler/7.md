## Giải pháp 

Để tìm$10{,}001^\text{st}$prime, chúng ta tạo ra các số nguyên tố một cách tuần tự và đếm chúng cho đến khi đạt được chỉ số mục tiêu. 

Một cách tiếp cận tiêu chuẩn là: 

- Bắt đầu từ$2$- Kiểm tra từng ứng cử viên về tính nguyên tố bằng cách sử dụng phép chia thử lên đến$\sqrt{n}$- Đếm số nguyên tố được tìm thấy 
- Dừng khi đếm đủ$10{,}001$Đây là mã Python sạch:```python
def is_prime(n):
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    d = 3
    while d * d <= n:
        if n % d == 0:
            return False
        d += 2

    return True

count = 0
num = 1

while count < 10001:
    num += 1
    if is_prime(num):
        count += 1

print(num)
```Theo dõi logic: 

- Các số nguyên tố bắt đầu:$2,3,5,7,11,13,\dots$- Bộ đếm chỉ tăng khi tìm thấy số nguyên tố.
