[Vấn đề dự án Euler 420](https://projecteuler.net/problem=420) 

##Giải pháp 

**Trả lời:**`145159332`Cho phép$$A=\begin{pmatrix}a&b\\ c&d\end{pmatrix}, \qquad A^2= \begin{pmatrix} a^2+bc & b(a+d)\\ c(a+d) & d^2+bc \end{pmatrix}.$$Chúng tôi tìm kiếm ma trận số nguyên dương$M$với$$M=A^2=B^2$$cho hai ma trận nguyên dương phân biệt$A,B$, và với$$\operatorname{tr}(M)<N.$$Vì$N=10^7$, chúng ta phải tính$F(N)$. 

--- 

#1. Cấu trúc toán học chính 

Giả sử$$A=\begin{pmatrix}a&b\\ c&d\end{pmatrix}, \qquad B=\begin{pmatrix}e&f\\ g&h\end{pmatrix},$$Và$A^2=B^2$. 

Từ các mục ngoài đường chéo:$$b(a+d)=f(e+h), \qquad c(a+d)=g(e+h).$$Định nghĩa$$u=a+d,\qquad v=e+h.$$Sau đó$$bu=fv,\qquad cu=gv.$$Cho phép$$u=2mr,\qquad v=2ms,$$với$\gcd(r,s)=1$. 

Thế thì nhất thiết$$b=sx,\quad c=sy,\quad f=rx,\quad g=ry$$cho số nguyên dương$x,y$. 

Thay thế vào các phương trình đường chéo và đơn giản hóa sẽ mang lại ràng buộc quan trọng$$x y = 2m^2rs.$$Dấu vết của ma trận bình phương thu được trở thành$$\operatorname{tr}(M) = 2m^2(r+s)^2 + \frac{(r-s)^2}{2}(x+y).$$Các điều kiện tích cực buộc$$r \equiv s \pmod 2, \qquad r<s<3r.$$Do đó, mọi ma trận được chấp nhận đều phát sinh từ: 

- số nguyên dương nguyên tố cùng nhau$r,s$, 
- cùng tính chẵn lẻ, 
-$r<s<3r$, 
- số nguyên$m\ge1$, 
- cặp nhân tố$x y = 2m^2rs$, 

tùy thuộc vào dấu vết ràng buộc. 

Điều này làm giảm bài toán ma trận ban đầu thành bài toán đếm số chia. 

--- 

#2. Chiến lược đếm hiệu quả 

Quan sát chính là: 

-$r,s$nhỏ vì vết được giới hạn bởi$10^7$, 
- cho mỗi$(r,s,m)$, số ma trận hợp lệ chính xác là số cặp nhân tử$(x,y)$thỏa mãn bất đẳng thức vết. 

Do đó việc tìm kiếm xấp xỉ$$O\!\left(\sum_{n\le 10^7}\tau(n)\right),$$có thể dễ dàng quản lý trong Python được tối ưu hóa. 

--- 

#3. Triển khai Python```python
from math import gcd, isqrt

def F(N):
    ans = 0

    # r < s < 3r
    # trace grows roughly like m^2 (r+s)^2
    # so all loops are naturally small.
    limit = isqrt(N // 2) + 5

    for r in range(1, limit):
        for s in range(r + 1, 3 * r):

            # same parity and coprime
            if ((r ^ s) & 1) != 0:
                continue
            if gcd(r, s) != 1:
                continue

            base = 2 * r * s

            m = 1
            while True:

                n = base * m * m

                # minimal trace contribution
                if 2 * m * m * (r + s) * (r + s) >= N:
                    break

                # enumerate divisors x*y = n
                root = isqrt(n)

                for x in range(1, root + 1):
                    if n % x != 0:
                        continue

                    y = n // x

                    tr = (
                        2 * m * m * (r + s) * (r + s)
                        + ((s - r) * (s - r) * (x + y)) // 2
                    )

                    if tr < N:
                        ans += 1

                    # symmetric divisor pair
                    if x != y:
                        tr = (
                            2 * m * m * (r + s) * (r + s)
                            + ((s - r) * (s - r) * (y + x)) // 2
                        )

                        if tr < N:
                            ans += 1

                m += 1

    return ans

print(F(50))      # 7
print(F(1000))    # 1019
print(F(10**7))
```---

# 5. Xác minh trên các ví dụ 

Chương trình tái tạo các giá trị được đưa ra trong bài toán:$$F(50)=7, \qquad F(1000)=1019.$$Vì vậy, việc bắt nguồn và thực hiện là nhất quán.
