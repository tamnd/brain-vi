[Vấn đề dự án Euler 655](https://projecteuler.net/problem=655) 

## Giải pháp 

**Trả lời:**`2000008332`Cho phép$M=10{,}000{,}019$. 

Chúng ta phải đếm palindromes$<10^{32}$chia hết cho$M$. 

--- 

# Phân tích toán học 

Một palindrome có chiều dài$L$hoàn toàn được xác định bởi lần đầu tiên$$h=\left\lceil \frac L2 \right\rceil$$chữ số. 

Hãy để những chữ số đó là$$d_0,d_1,\dots,d_{h-1}$$Ở đâu$d_0\neq 0$. 

--- 

## 1. Viết modulo palindrome$M$chữ số$d_j$xuất hiện ở hai vị trí đối xứng: 

- vị trí$j$- chức vụ$L-1-j$ngoại trừ chữ số ở giữa khi$L$thật kỳ quặc. 

Kể từ đây$$P \equiv \sum_{j=0}^{h-1} d_j c_j \pmod M$$Ở đâu$$c_j = \begin{cases} 10^j + 10^{L-1-j} \pmod M, & \text{normally}\\[4pt] 10^j \pmod M, & \text{middle digit of odd }L \end{cases}$$Vì vậy, vấn đề trở thành: 

> Đếm các bài tập chữ số sao cho 
> 
> 
> 
> 
>$$\sum d_j c_j \equiv 0 \pmod M$$với$d_0\in\{1,\dots,9\}$và tất cả các chữ số khác trong$\{0,\dots,9\}$. 

--- 

## 2. Lập trình động trên dư lượng 

Xác định:$$dp[r] = \text{number of ways to obtain residue } r$$Ban đầu:$$dp[0]=1$$Đối với mỗi vị trí chữ số$j$, chuyển đổi bằng cách thử tất cả các chữ số được phép. 

Nếu chúng ta đặt chữ số$d$,$$r \to (r+d\,c_j)\bmod M$$Cuối cùng, câu trả lời về độ dài$L$là$dp[0]$. 

Chúng tôi lặp lại điều này trong suốt thời gian dài$1\le L\le 32$. 

--- 

## 3. Độ phức tạp 

-$M=10{,}000{,}019$- nửa chiều dài lớn nhất là$16$Vì vậy, DP khả thi trong mã cấp thấp được tối ưu hóa (hoặc PyPy có mảng). 

Tổng số thu được là:$$\boxed{2{,}000{,}008{,}332}$$--- 

#Triển khai Python```python
from array import array

MOD = 10_000_019

# Precompute powers of 10 modulo MOD
pow10 = [1] * 40
for i in range(1, 40):
    pow10[i] = (pow10[i - 1] * 10) % MOD

def count_length(L):
    """
    Count palindromes of exact length L divisible by MOD.
    """
    h = (L + 1) // 2

    # coefficients c_j
    coeff = []

    for j in range(h):
        # middle digit in odd length
        if (L % 2 == 1) and (j == h - 1):
            c = pow10[j]
        else:
            c = (pow10[j] + pow10[L - 1 - j]) % MOD

        coeff.append(c)

    # DP over residues
    dp = array('I', [0]) * MOD
    dp[0] = 1

    for j, c in enumerate(coeff):

        ndp = array('I', [0]) * MOD

        # leading digit cannot be zero
        digits = range(1, 10) if j == 0 else range(10)

        for r in range(MOD):
            cur = dp[r]
            if cur == 0:
                continue

            for d in digits:
                nr = (r + d * c) % MOD
                ndp[nr] += cur

        dp = ndp

    return dp[0]

answer = 0

for L in range(1, 33):
    answer += count_length(L)

print(answer)
```--- 

# Hướng dẫn sử dụng mã 

## Quyền lực tính toán trước```python
pow10[i] = 10^i mod MOD
```Những điều này là cần thiết để xác định vị trí mỗi chữ số đóng góp bên trong bảng màu. 

--- 

## Xây dựng hệ số 

Đối với mỗi cặp chữ số được nhân đôi:```python
10^j + 10^(L-1-j)
```vì chữ số xuất hiện ở cả hai vị trí. 

Đối với độ dài lẻ, chữ số ở giữa chỉ xuất hiện một lần. 

--- 

## Trạng thái DP```python
dp[r]
```lưu trữ bao nhiêu palindromes một phần tạo ra dư lượng`r`. 

--- 

## Chuyển tiếp 

Đang thử chữ số`d`cập nhật:```python
nr = (r + d * c) % MOD
```--- 

## Số cuối cùng 

Sau khi tất cả các vị trí được xử lý:```python
dp[0]
```là số lượng palindromes có thể chia được có độ dài đó.

# Xác minh ví dụ nhỏ 

Tuyên bố vấn đề nói: 

-$545$-$5995$-$15151$là ba palindromes đầu tiên chia hết cho$109$. 

Chạy cùng một thuật toán với mô-đun$109$và giới hạn trên$100000$tạo ra chính xác:$$9$$phù hợp với tuyên bố. 

Vì vậy, phương pháp được xác nhận.
