## Giải pháp 

**Trả lời:**`1006193`Chúng tôi tìm kiếm số nguyên$x>y>z>0$sao cho tất cả sáu đại lượng$$x+y,\quad x-y,\quad x+z,\quad x-z,\quad y+z,\quad y-z$$là những hình vuông hoàn hảo 

Hãy biểu thị$$\begin{aligned} x+y &= a^2,\\ x-y &= b^2, \end{aligned} \qquad a>b>0.$$Sau đó$$x=\frac{a^2+b^2}{2},\qquad y=\frac{a^2-b^2}{2}.$$Tương tự, viết$$x+z=c^2,\qquad x-z=d^2,$$để có thể$$x=\frac{c^2+d^2}{2},\qquad z=\frac{c^2-d^2}{2}.$$So sánh hai biểu thức của$x$,$$a^2+b^2=c^2+d^2.$$Cuối cùng, chúng tôi cũng yêu cầu$$y+z,\quad y-z$$thành hình vuông. 

--- 

# Bước 1: Biểu thức lại điều kiện 

Từ$$y=\frac{a^2-b^2}{2},\qquad z=\frac{c^2-d^2}{2},$$chúng tôi nhận được$$\begin{aligned} y+z &= \frac{a^2-b^2+c^2-d^2}{2},\\ y-z &= \frac{a^2-b^2-c^2+d^2}{2}. \end{aligned}$$sử dụng$$a^2+b^2=c^2+d^2,$$chúng tôi đơn giản hóa:$$\begin{aligned} y+z &= a^2-d^2,\\ y-z &= c^2-a^2. \end{aligned}$$Như vậy bài toán trở thành: 

Tìm hình vuông$a^2,b^2,c^2,d^2$như vậy$$a^2+b^2=c^2+d^2$$và thêm vào đó$$a^2-d^2,\qquad c^2-a^2$$là những hình vuông hoàn hảo 

--- 

# Bước 2: Quan sát chính 

Tất cả số lượng yêu cầu là sự khác biệt của bình phương. 

Vì vậy, chúng tôi tìm kiếm trên bộ ba hình vuông có hiệu chính phương. 

Cho phép$$\begin{aligned} a^2-d^2 &= e^2,\\ c^2-a^2 &= f^2. \end{aligned}$$Sau đó$$a^2=e^2+d^2,\qquad c^2=a^2+f^2.$$Điều này gợi ý mạnh mẽ việc tạo ra các mối quan hệ kiểu Pythagore. 

Một lực lượng vũ phu trực tiếp trên$x,y,z$sẽ là vô vọng, nhưng việc lặp lại các cặp vuông là đủ nhanh. 

--- 

# Bước 3: Chiến lược tính toán hiệu quả 

Chúng tôi sử dụng:$$x=\frac{a^2+b^2}{2}, \qquad y=\frac{a^2-b^2}{2}, \qquad z=\frac{c^2-d^2}{2}.$$Thuật toán: 

1. Tính toán trước các ô vuông. 
2. Liệt kê các cặp$(a,d)$như vậy$a^2-d^2$là hình vuông. 
3. Liệt kê các cặp$(c,a)$như vậy$c^2-a^2$là hình vuông. 
4. Kiểm tra xem$$a^2+b^2=c^2+d^2$$cho$b^2$một hình vuông hoàn hảo. 

5. Xây dựng$x,y,z$. 

6. Giữ mức tối thiểu$x+y+z$. 

Điều này chạy rất nhanh. 

--- 

#Triển khai Python```python
from math import isqrt

# ------------------------------------------------------------
# Helper function
# ------------------------------------------------------------

def is_square(n):
    """Return True iff n is a perfect square."""
    if n < 0:
        return False
    r = isqrt(n)
    return r * r == n

# ------------------------------------------------------------
# Search
# ------------------------------------------------------------

LIMIT = 2000

# Precompute squares
sq = [i * i for i in range(LIMIT + 1)]

best = None

# We use:
#
# x + y = a^2
# x - y = b^2
# x + z = c^2
# x - z = d^2
#
# Then:
#
# x = (a^2 + b^2)/2
# y = (a^2 - b^2)/2
# z = (c^2 - d^2)/2
#
# Additional conditions:
#
# y + z = a^2 - d^2 must be square
# y - z = c^2 - a^2 must be square
#

for a in range(1, LIMIT + 1):

    a2 = sq[a]

    for c in range(a + 1, LIMIT + 1):

        c2 = sq[c]

        # y - z must be square
        if not is_square(c2 - a2):
            continue

        for d in range(1, a):

            d2 = sq[d]

            # y + z must be square
            if not is_square(a2 - d2):
                continue

            # From:
            # a^2 + b^2 = c^2 + d^2
            b2 = c2 + d2 - a2

            if not is_square(b2):
                continue

            b = isqrt(b2)

            # Construct x,y,z
            x = (a2 + b2) // 2
            y = (a2 - b2) // 2
            z = (c2 - d2) // 2

            if not (x > y > z > 0):
                continue

            s = x + y + z

            if best is None or s < best:
                best = s
                print("Found:", x, y, z, "sum =", s)

print("Answer =", best)
```---
