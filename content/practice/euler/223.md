## Giải pháp 

**Trả lời:**`61614848`Cho phép$$a^2+b^2=c^2+1, \qquad a\le b\le c$$với chu vi$$a+b+c\le 25{,}000{,}000.$$Chúng ta muốn đếm tất cả các tam giác “hầu như không nhọn” có cạnh nguyên. 

## 1. Phân tích toán học 

Sắp xếp lại phương trình xác định:$$a^2+b^2=c^2+1$$BẰNG$$a^2-1=c^2-b^2=(c-b)(c+b).$$Định nghĩa$$x=c-b,\qquad y=c+b.$$Sau đó$$xy=a^2-1.$$Từ$$b=\frac{y-x}{2},\qquad c=\frac{y+x}{2},$$chúng tôi yêu cầu: 

1.$x,y$có cùng tính chẵn lẻ (vì vậy$b,c$là số nguyên), 
2.$x>0$, 
3.$a\le b$, tức là$$a \le \frac{y-x}{2}$$trở thành$$y-x\ge 2a.$$Điều kiện chu vi cũng trở thành$$a+b+c=a+y\le N,$$Ở đâu$N=25{,}000{,}000$. 

Vì vậy với mỗi cố định$a$, chúng ta đang đếm các ước số$x\mid(a^2-1)$như vậy$$x\le y=\frac{a^2-1}{x},$$

$$\frac{a^2-1}{x}-x\ge 2a,$$Và$$a+\frac{a^2-1}{x}\le N.$$Bởi vì$y=(a^2-1)/x$, các ràng buộc trở thành: 

### Giới hạn trên của$x$Từ$y-x\ge 2a$:$$\frac{a^2-1}{x}-x\ge 2a.$$Nhân với$x$:$$a^2-1\ge x^2+2ax.$$Sắp xếp lại:$$(x+a)^2\le 2a^2-1.$$Kể từ đây$$x\le \sqrt{2a^2-1}-a.$$### Giới hạn dưới trên$x$Từ chu vi:$$a+\frac{a^2-1}{x}\le N$$Vì thế$$x\ge \frac{a^2-1}{N-a}.$$Như vậy, đối với mỗi$a$, chúng ta đếm các ước số$x$của$a^2-1$nằm trong khoảng$$\left\lceil \frac{a^2-1}{N-a} \right\rceil \le x\le \left\lfloor \sqrt{2a^2-1}-a \right\rfloor,$$với điều kiện chẵn lẻ$x+y$thậm chí. 

###Trường hợp đặc biệt$a=1$Nếu như$a=1$,$$1+b^2=c^2+1 \Rightarrow b=c.$$Vậy mọi tam giác$(1,b,b)$tác phẩm được cung cấp$$1+2b\le N.$$Điều đó góp phần$$\left\lfloor\frac{N-1}{2}\right\rfloor$$giải pháp.

## 2. Triển khai Python```python
from math import isqrt

N = 25_000_000
A_MAX = N // 3 + 1

def build_spf(limit):
    """Smallest prime factor sieve."""
    spf = list(range(limit + 1))

    for i in range(2, isqrt(limit) + 1):
        if spf[i] == i:  # i is prime
            for j in range(i * i, limit + 1, i):
                if spf[j] == j:
                    spf[j] = i

    return spf

spf = build_spf(A_MAX + 1)

# Special case a = 1
count = (N - 1) // 2

for a in range(2, A_MAX + 1):
    n = a * a - 1

    # Bounds on divisor x
    lower = (n + (N - a) - 1) // (N - a)
    upper = isqrt(2 * a * a - 1) - a

    # Factorise (a-1)(a+1)
    factors = {}

    for z in (a - 1, a + 1):
        while z > 1:
            p = spf[z]
            e = 0

            while z % p == 0:
                z //= p
                e += 1

            factors[p] = factors.get(p, 0) + e

    factor_items = list(factors.items())

    # Enumerate divisors <= upper
    stack = [(0, 1)]

    while stack:
        idx, cur = stack.pop()

        if idx == len(factor_items):
            if cur >= lower:
                y = n // cur

                # Same parity condition
                if ((cur + y) & 1) == 0:
                    count += 1
        else:
            p, e = factor_items[idx]
            value = 1

            for _ in range(e + 1):
                nxt = cur * value

                if nxt <= upper:
                    stack.append((idx + 1, nxt))
                else:
                    break

                value *= p

print(count)

## 3. Hướng dẫn sử dụng mã 

###Sàng lọc SPF 

Chúng tôi tính toán trước **hệ số nguyên tố nhỏ nhất** cho mọi số nguyên lên đến$$\frac{N}{3}$$từ$a \le N/3$. 

Điều này cho phép nhân tố hóa rất nhanh$a-1$Và$a+1$. 

### Lặp lại$a$Đối với mỗi$a$: 

- tính toán$$n=a^2-1$$- lấy được khoảng chia hợp lệ$[L,U]$,
- nhân tố$$n=(a-1)(a+1),$$- tạo ước số$x$của$n$lên đến$U$, 
- kiểm tra các ràng buộc về tính chẵn lẻ và chu vi. 

Mỗi ước số hợp lệ tương ứng với chính xác một tam giác. 

### Kiểm tra độ tỉnh táo nhỏ 

Đối với chu vi$\le 100$, phương pháp tìm được 72 hình tam giác, bao gồm:$$(4,7,8), \quad (5,5,7), \quad (8,9,12), \quad (29,29,41),$$và gia đình vô tận$$(1,b,b).$$Điều này phù hợp với việc liệt kê lực lượng vũ phu.
