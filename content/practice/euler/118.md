[Vấn đề dự án Euler 118](https://projecteuler.net/problem=118) 

## Giải pháp 

**Trả lời:**`44680`Chúng ta phải đếm số _bộ_ số nguyên tố được hình thành bằng cách sử dụng từng chữ số$1,\dots,9$đúng một lần. 

Ví dụ,$$\{2,5,47,89,631\}$$là hợp lệ vì: 

- mọi phần tử đều là số nguyên tố, 
- các chữ số$1$bởi vì$9$được sử dụng chính xác một lần tổng thể, 
- thứ tự không thành vấn đề vì đây là **bộ**. 

Thách thức là đếm tất cả các tập hợp riêng biệt như vậy. 

--- 

# Phân tích toán học 

## 1. Quan sát về số nguyên tố 

Chúng ta ghép các chữ số để tạo thành số nguyên. 

Một số được tạo thành từ các chữ số khác nhau chỉ có thể là số nguyên tố nếu: 

- nó **không** kết thúc bằng chữ số chẵn, 
- nó **không** kết thúc bằng$5$, 
- nó không chia hết cho$3$. 

Việc quan sát chia hết cho 3 là đặc biệt quan trọng. 

Với mọi số nguyên, chia hết cho$3$phụ thuộc vào tổng các chữ số. 

Các chữ số$1$bởi vì$9$tổng hợp thành$$1+2+\cdots+9 = 45.$$Từ$45\equiv 0 \pmod 3$, _ toàn bộ phép nối _ chia hết cho$3$. 

Vì vậy chúng ta không thể đặt tất cả các chữ số vào một số nguyên tố. 

Tổng quát hơn: 

- bất kỳ tập hợp con các chữ số nào có tổng các chữ số chia hết cho$3$không thể tạo thành số nguyên tố (trừ số$3$chính nó). 

Điều này làm giảm đáng kể không gian tìm kiếm. 

--- 

#2. Chiến lược 

Chúng tôi sẽ: 

1. Tạo mọi số nguyên tố: 

- sử dụng các chữ số riêng biệt từ$1$–$9$, 
- không sử dụng chữ số hai lần, 
- không chứa số không. 
2. Biểu thị mỗi số nguyên tố bằng một bitmask gồm các chữ số được sử dụng. 
3. Sử dụng tìm kiếm đệ quy/quay ngược để kết hợp các mặt nạ rời rạc cho đến khi sử dụng hết chín chữ số. 
4. Thực thi điều kiện đặt hàng để tránh đếm cùng một bộ nhiều lần. 

--- 

#3. Thế hệ Prime 

chỉ có$$\sum_{k=1}^9 P(9,k)$$cách sắp xếp chữ số có thể, ở đâu$$P(9,k)=\frac{9!}{(9-k)!}.$$Tổng số này có thể quản lý được. 

Với mỗi hoán vị độ dài$k$: 

- chuyển đổi thành số nguyên, 
- kiểm tra tính nguyên thủy, 
- lưu trữ nếu nguyên tố. 

--- 

#4. Tránh các bộ trùng lặp 

Giả sử chúng ta chọn đệ quy các số nguyên tố. 

Nếu chúng ta cho phép thứ tự tùy ý thì$$\{2,5,47\}$$sẽ được tính là: 

-$2,5,47$-$2,47,5$-$5,2,47$- v.v. 

Để ngăn chặn điều này, chúng tôi yêu cầu các số nguyên tố phải được chọn theo thứ tự tăng dần. 

Do đó, mỗi bộ được tạo chính xác một lần.

#Triển khai Python```python
from itertools import permutations
from math import isqrt

# ------------------------------------------------------------
# Primality test
# ------------------------------------------------------------

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    if n % 3 == 0:
        return n == 3

    r = isqrt(n)
    f = 5
    while f <= r:
        if n % f == 0 or n % (f + 2) == 0:
            return False
        f += 6
    return True

# ------------------------------------------------------------
# Generate all usable primes
# ------------------------------------------------------------

digits = '123456789'

# primes_by_mask[mask] = list of primes using exactly those digits
primes = []

for length in range(1, 10):
    for perm in permutations(digits, length):

        # quick divisibility-by-3 pruning
        digit_sum = sum(ord(c) - ord('0') for c in perm)
        if digit_sum % 3 == 0:
            # only possible prime is 3 itself
            if not (length == 1 and perm[0] == '3'):
                continue

        # last digit cannot be even or 5
        if perm[-1] in '24568':
            if not (length == 1 and perm[0] in '25'):
                continue

        n = int(''.join(perm))

        if is_prime(n):

            # build bitmask
            mask = 0
            for ch in perm:
                mask |= 1 << (ord(ch) - ord('1'))

            primes.append((n, mask))

# ------------------------------------------------------------
# Sort primes so recursive generation is canonical
# ------------------------------------------------------------

primes.sort()

FULL_MASK = (1 << 9) - 1

answer = 0

# ------------------------------------------------------------
# Backtracking search
# ------------------------------------------------------------

def search(start_index, used_mask):
    """
    Choose increasing primes whose digit masks are disjoint
    until all digits are used.
    """
    global answer

    if used_mask == FULL_MASK:
        answer += 1
        return

    for i in range(start_index, len(primes)):
        p, mask = primes[i]

        # disjoint digit sets only
        if used_mask & mask:
            continue

        search(i + 1, used_mask | mask)

search(0, 0)

print(answer)
```---
