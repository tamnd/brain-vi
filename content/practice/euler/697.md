[Vấn đề dự án Euler 697](https://projecteuler.net/problem=697) 

## Giải pháp 

**Trả lời:**`4343871.06`Cho phép$$X_n = c\prod_{k=1}^n U_k,$$ở đâu$U_k$là i.i.d. biến ngẫu nhiên thống nhất trên$(0,1)$. 

chúng tôi muốn$c$như vậy$$\Pr(X_n<1)=0.25$$vì$n=10\,000\,000$. 

--- 

# Bước 1: Chuyển tích thành tổng 

Lấy logarit:$$\ln X_n=\ln c+\sum_{k=1}^n \ln U_k.$$Từ$0<U_k<1$, định nghĩa$$Y_k=-\ln U_k.$$Một thực tế tiêu chuẩn là:$$Y_k \sim \text{Exp}(1),$$bởi vì$$\Pr(Y_k\le y)=\Pr(-\ln U_k\le y) =\Pr(U_k\ge e^{-y}) =1-e^{-y}.$$Như vậy$$-\sum_{k=1}^n \ln U_k = \sum_{k=1}^n Y_k.$$Vì vậy nếu chúng ta định nghĩa$$S_n=\sum_{k=1}^n Y_k,$$sau đó$$S_n \sim \Gamma(n,1),$$với ý nghĩa$n$và phương sai$n$. 

Cũng,$$X_n<1 \iff \ln c - S_n <0 \iff S_n>\ln c.$$Do đó điều kiện trở thành$$\Pr(S_n>\ln c)=0.25.$$Tương đương,$$\Pr(S_n\le \ln c)=0.75.$$Vì thế,$\ln c$là phần trăm thứ 75 của phân phối$\Gamma(n,1)$. 

--- 

# Bước 2: Tính gần đúng lượng tử gamma 

Đối với rất lớn$n$,$$\Gamma(n,1)\approx N(n,n)$$bởi Định lý giới hạn trung tâm. 

Cho phép$$z=\Phi^{-1}(0.75)=0.674489750196\ldots$$Sau đó, phép khai triển Cornish–Fisher đưa ra giá trị gần đúng chính xác cho phân vị thứ 75:$$q \approx n + z\sqrt n + \frac{z^2-1}{3}.$$Với$$n=10\,000\,000, \qquad \sqrt n = 3162.277660\ldots$$chúng tôi nhận được$$q \approx 10\,000\,000 + 0.674489750196(3162.277660) + \frac{0.674489750196^2-1}{3}.$$Về mặt số lượng,$$q \approx 10\,000\,002.411477.$$Từ$q=\ln c$,$$\log_{10} c = \frac{\ln c}{\ln 10} = \frac{q}{\ln 10}.$$Như vậy$$\log_{10} c \approx 4343871.057176\ldots$$vòng nào đến$$4343871.06.$$--- 

#Triển khai Python```python
import math
from statistics import NormalDist

# Problem parameter
n = 10_000_000

# 75th percentile of the standard normal distribution
z = NormalDist().inv_cdf(0.75)

# Cornish-Fisher approximation for Gamma(n,1) quantile
q = n + z * math.sqrt(n) + (z*z - 1) / 3

# Convert ln(c) to log10(c)
answer = q / math.log(10)

print(round(answer, 2))
```--- 

# Hướng dẫn sử dụng mã 

### 1. Tính lượng tử bình thường```python
z = NormalDist().inv_cdf(0.75)
```Điều này mang lại$$z=\Phi^{-1}(0.75)\approx0.67448975.$$--- 

### 2. Ước tính lượng tử gamma```python
q = n + z * math.sqrt(n) + (z*z - 1) / 3
```Đây là phép hiệu chỉnh Cornish–Fisher đối với xấp xỉ thông thường của phân bố gamma. 

--- 

### 3. Chuyển sang logarit cơ số 10```python
answer = q / math.log(10)
```Bởi vì$$\log_{10} c = \frac{\ln c}{\ln 10}.$$--- 

# Xác minh 

Đối với ví dụ nhỏ hơn$n=100$,$$\log_{10} c \approx 46.27,$$phù hợp với phát biểu trong bài toán. 

Vì$n=10^7$, kết quả sẽ ở gần$$\frac{10^7}{\ln 10}\approx 4.3429448\times10^6,$$và câu trả lời của chúng tôi chỉ khác nhau ở mức độ dao động dự kiến$O(\sqrt n)$, do đó độ lớn là đúng.
