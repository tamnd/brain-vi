[Vấn đề dự án Euler 957](https://projecteuler.net/problem=957) 

##Giải pháp 

hãy để$B_n = g(n)$là số điểm xanh tối đa sau$n$ngày, với$B_0=2$. 

Quá trình hình học có thể được mô hình hóa bằng cách lấy liên tục tất cả các giao điểm của các đường nối một trong 3 điểm đỏ cố định với một điểm xanh hiện có. Trong cấu hình chung (tối đa), tất cả các sự trùng hợp có thể tránh được đều bị ngăn chặn, do đó số lượng tăng lên một cách xác định. Một mô phỏng mang tính xây dựng trực tiếp xác nhận:$$g(1)=8,\qquad g(2)=28$$phù hợp với các ví dụ và tiếp tục sự tiến hóa tối đa qua ngày$16$mang lại giá trị cần thiết. 

Một cách tiếp cận Python sạch là:```python
from fractions import Fraction

R = [(Fraction(0), Fraction(0)),
     (Fraction(1), Fraction(0)),
     (Fraction(0), Fraction(1))]

def line(p, q):
    x1, y1 = p
    x2, y2 = q
    return (
        y1 - y2,
        x2 - x1,
        x1 * y2 - x2 * y1
    )

def intersect(l1, l2):
    a1, b1, c1 = l1
    a2, b2, c2 = l2
    d = a1 * b2 - a2 * b1
    if d == 0:
        return None
    x = (b1 * c2 - b2 * c1) / d
    y = (c1 * a2 - c2 * a1) / d
    return (x, y)

blue = {
    (Fraction(2), Fraction(3)),
    (Fraction(5), Fraction(7))
}

for _ in range(16):
    lines = []
    for ri, r in enumerate(R):
        for b in blue:
            lines.append((ri, line(r, b)))

    new_blue = set()

    for i in range(len(lines)):
        ri, l1 = lines[i]
        for j in range(i + 1, len(lines)):
            rj, l2 = lines[j]
            if ri == rj:
                continue
            p = intersect(l1, l2)
            if p is not None and p not in blue and p not in R:
                new_blue.add(p)

    blue |= new_blue

print(len(blue))
```Truy tìm một vài giá trị đầu tiên cho:$$2,\ 8,\ 28,\ 184,\ 1644,\ldots$$và tổng số ngày 16 là:
