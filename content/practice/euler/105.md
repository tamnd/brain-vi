[Dự án Euler Vấn đề 105](https://projecteuler.net/problem=105) 

##Giải pháp 

**Trả lời:**`73702`Hãy để một bộ$A$được sắp xếp ngày càng nhiều:$$a_1 < a_2 < \cdots < a_n$$Chúng ta phải kiểm tra xem đó có phải là **tập hợp tổng đặc biệt** hay không, nghĩa là: 

1. Không có hai tập con khác biệt nào có tổng bằng nhau. 
2. Nếu một tập hợp con có nhiều phần tử hơn tập hợp con khác thì tổng của nó phải lớn hơn. 

Tệp đầu vào chứa 100 bộ ứng viên, mỗi bộ có$7$–$12$các phần tử. Chúng ta phải xác định tất cả các tập hợp tổng đặc biệt hợp lệ và tính tổng tổng của chúng.

# Phân tích toán học 

## Thuộc tính 2: kiểm tra cần và đủ nhanh 

Giả sử tập hợp đã được sắp xếp. 

Nếu nhỏ nhất$k$các phần tử **không** vượt quá giá trị lớn nhất$k-1$phần tử thì ta có thể tạo thành: 

- một$k$-tập hợp phần tử có tổng nhỏ, 
- một$(k-1)$-tập hợp phần tử có tổng lớn, 

vi phạm điều kiện (2). 

Vì vậy chúng tôi yêu cầu:$$a_1 + a_2 + \cdots + a_k > a_n + a_{n-1} + \cdots + a_{n-k+2}$$cho mọi$k = 2,3,\dots,\lfloor n/2 \rfloor +1$. 

Điều này là đủ vì: 

- nhỏ nhất có thể$k$-tập hợp con là tập hợp đầu tiên$k$các yếu tố, 
- lớn nhất có thể$(k-1)$-subset là tập cuối cùng$k-1$các phần tử. 

Vì vậy, nếu ngay cả tập con lớn nhất nhỏ nhất cũng đánh bại tập con nhỏ lớn nhất thì điều kiện (2) luôn đúng. 

--- 

## Thuộc tính 1: tính duy nhất của tổng tập hợp con 

Chúng ta phải đảm bảo:$$S(B) \ne S(C)$$cho tất cả các tập hợp con không trống riêng biệt$B,C$. 

Cách tiếp cận vũ phu hoạt động vì các bộ rất nhỏ ($n \le 12$). 

Có nhiều nhất là:$$2^{12}=4096$$tập hợp con. 

Đối với mỗi tập hợp con: 

- tính tổng của nó, 
- lưu trữ nó trong một bộ, 
- nếu tổng đã xuất hiện, thuộc tính (1) không thành công. 

Điều này là tầm thường về mặt tính toán.

#Triển khai Python```python
from itertools import combinations
import urllib.request

URL = "https://projecteuler.net/resources/documents/0105_sets.txt"

# Download the file
data = urllib.request.urlopen(URL).read().decode()

sets_list = [
    list(map(int, line.split(",")))
    for line in data.strip().splitlines()
]

def satisfies_rule_2(nums):
    """
    Check:
    if |B| > |C| then S(B) > S(C)

    For a sorted list, it is sufficient to verify:
    sum(k smallest) > sum(k-1 largest)
    """
    nums = sorted(nums)
    n = len(nums)

    for k in range(2, n // 2 + 2):
        if sum(nums[:k]) <= sum(nums[-(k - 1):]):
            return False

    return True

def satisfies_rule_1(nums):
    """
    Check that all subset sums are unique.
    """
    n = len(nums)
    seen = set()

    # Enumerate all non-empty subsets
    for mask in range(1, 1 << n):
        subset_sum = 0

        for i in range(n):
            if mask & (1 << i):
                subset_sum += nums[i]

        if subset_sum in seen:
            return False

        seen.add(subset_sum)

    return True

def is_special_sum_set(nums):
    return satisfies_rule_2(nums) and satisfies_rule_1(nums)

answer = 0

for s in sets_list:
    if is_special_sum_set(s):
        answer += sum(s)

print(answer)
```---
