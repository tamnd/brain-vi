## Giải pháp 

**Trả lời:**`104924.0`Hãy để các điểm được tạo ra$P_0,P_1,\dots,P_{499}$, Ở đâu$$S_0=290797,\qquad S_{n+1}=S_n^2 \bmod 50515093,$$

$$T_n=(S_n\bmod 2000)-1000,$$Và$$P_k=(T_{2k+1},T_{2k+2}).$$Chúng ta tìm kiếm diện tích tối đa **đa giác lồi trống** (lỗ lồi) có các đỉnh nằm trong số 500 điểm này. 

--- 

# 1. Phân tích toán học 

## 1.1 Hình tam giác trống 

Cho ba điểm$A,B,C$theo thứ tự ngược chiều kim đồng hồ, xác định tam giác$\triangle ABC$**trống** nếu không có điểm sinh ra nào khác nằm hoàn toàn bên trong nó. 

Một quan sát quan trọng là: 

> Nếu một đa giác lồi là một lỗ lồi trống thì mọi tam giác trong bất kỳ tam giác nào của đa giác cũng trống. 

Vì vậy, nếu chúng ta tam giác một đa giác lồi từ một đỉnh cố định thì mọi tam giác hình quạt phải trống. 

--- 

## 1.2 Chọn gốc chính tắc 

Mỗi đa giác lồi có một đỉnh thấp nhất duy nhất (phá vỡ các mối liên hệ bằng cách$x$-điều phối). 

Gọi đỉnh này$P_i$. 

Bây giờ sắp xếp tất cả các điểm ở trên$P_i$bởi góc cực xung quanh$P_i$:$$Q_0,Q_1,\dots,Q_{m-1}.$$Mọi đa giác lồi đều có$P_i$khi đỉnh thấp nhất xuất hiện dưới dạng một chuỗi góc tăng dần. 

--- 

##1.3 Lập trình động 

Giả sử chúng ta đã xây dựng một chuỗi lồi kết thúc bằng các đỉnh$$P_i,\dots,Q_a,Q_b.$$Nếu chúng ta nối thêm$Q_c$, thì: 

1. Góc quay phải lồi:$$\operatorname{cross}(Q_a,Q_b,Q_c)>0.$$2. Tam giác quạt mới$$\triangle(P_i,Q_b,Q_c)$$phải trống rỗng. 

Diện tích đa giác phân hủy thành các hình tam giác hình quạt:$$\text{Area} = \sum \text{Area}\bigl(\triangle(P_i,Q_j,Q_{j+1})\bigr).$$Vì vậy chúng tôi xác định$$dp[b][c]$$là diện tích nhân đôi tối đa của chuỗi hợp lệ kết thúc bằng cạnh$(Q_b,Q_c)$. 

Chuyển tiếp:$$dp[b][c] = \max\Bigl( \text{area}(i,b,c), \; dp[a][b]+\text{area}(i,b,c) \Bigr)$$trên tất cả những người tiền nhiệm hợp lệ$a$. 

--- 

##1.4 Kiểm tra độ rỗng nhanh 

Đối với mỗi cặp đặt hàng$(u,v)$, tính toán trước bitset$$L[u][v]$$chứa tất cả các điểm nằm ngay bên trái của cạnh có hướng$u\to v$. 

Sau đó cho một tam giác ngược chiều kim đồng hồ$(a,b,c)$,$$\triangle abc$$chứa chính xác các điểm trong$$L[a][b]\cap L[b][c]\cap L[c][a].$$Do đó tam giác trống nếu giao điểm này trống. 

Sử dụng số nguyên Python làm bitset làm cho việc này cực kỳ nhanh.

#2. Triển khai Python```python
from math import atan2

# ------------------------------------------------------------
# Generate the 500 points
# ------------------------------------------------------------

N = 500

S = 290797
pts = []

for _ in range(N):
    S = (S * S) % 50515093
    x = (S % 2000) - 1000

    S = (S * S) % 50515093
    y = (S % 2000) - 1000

    pts.append((x, y))

xs = [p[0] for p in pts]
ys = [p[1] for p in pts]

# ------------------------------------------------------------
# Geometry helpers
# ------------------------------------------------------------

def cross(a, b, c):
    return (
        (xs[b] - xs[a]) * (ys[c] - ys[a])
        - (ys[b] - ys[a]) * (xs[c] - xs[a])
    )

# ------------------------------------------------------------
# Precompute left-of-edge bitsets
# ------------------------------------------------------------

left = [[0] * N for _ in range(N)]

for i in range(N):
    xi, yi = xs[i], ys[i]

    for j in range(N):
        if i == j:
            continue

        xj, yj = xs[j], ys[j]
        dx = xj - xi
        dy = yj - yi

        bits = 0

        for k in range(N):
            if dx * (ys[k] - yi) - dy * (xs[k] - xi) > 0:
                bits |= (1 << k)

        left[i][j] = bits

# ------------------------------------------------------------
# Dynamic programming over convex chains
# ------------------------------------------------------------

best = 0  # doubled area

for i in range(N):

    # only points above the root can appear
    V = [
        j for j in range(N)
        if ys[j] > ys[i]
        or (ys[j] == ys[i] and xs[j] > xs[i])
    ]

    # angular order around root i
    V.sort(key=lambda j: atan2(ys[j] - ys[i], xs[j] - xs[i]))

    m = len(V)

    # incoming[b] = list of (a, value) for dp[a][b]
    incoming = [[] for _ in range(m)]

    xi, yi = xs[i], ys[i]

    for b in range(m):

        j = V[b]
        xj, yj = xs[j], ys[j]

        left_ij = left[i][j]

        for c in range(b + 1, m):

            k = V[c]

            # triangle (i,j,k) empty?
            if left_ij & left[j][k] & left[k][i]:
                continue

            area = (
                (xj - xi) * (ys[k] - yi)
                - (yj - yi) * (xs[k] - xi)
            )

            best_here = area

            xk, yk = xs[k], ys[k]

            # extend previous chains
            for a, prev in incoming[b]:

                h = V[a]

                # convex turn?
                if (
                    (xk - xj) * (ys[h] - yj)
                    - (yk - yj) * (xs[h] - xj)
                ) < 0:

                    best_here = max(best_here, prev + area)

            incoming[c].append((b, best_here))

            best = max(best, best_here)

print(best / 2)
```---

## Tạo điểm

--- 

## Tiền xử lý bitset 

Đối với mỗi cạnh có hướng$i\to j$, chúng ta tính toán tất cả các điểm ở bên trái của cạnh đó. 

Điều này cho phép kiểm tra khoảng trống tam giác theo thời gian không đổi thông qua giao điểm bitset. 

--- 

## Cấu trúc DP 

Đối với mỗi đỉnh gốc$P_i$: 

1. Sắp xếp tất cả các đỉnh ứng cử viên theo góc. 
2. Xây dựng chuỗi lồi theo thứ tự góc cạnh. 
3. Chỉ thêm các hình tam giác trống. 
4. Tích lũy tổng diện tích bằng tam giác quạt. 

Tất cả các khu vực được lưu trữ gấp đôi để vẫn tách rời.
