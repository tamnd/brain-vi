[Vấn đề dự án Euler 416](https://projecteuler.net/problem=416) 

##Giải pháp 

**Trả lời:**`898082747`Cho phép$L=n-1$. 

Một chuyến đi ra ngoài hoặc về nhà hoàn chỉnh chỉ là sự kết hợp của$L$thành nhiều phần$1,2,3$. 

Vì$m$có những chuyến đi khứ hồi$$p=2m$$đường đi đơn điệu độc lập từ$0$ĐẾN$L$. 

Quan sát quan trọng là chúng ta có thể quét bảng từ trái sang phải và chỉ cần biết, đối với mỗi đường đi, điểm hạ cánh tiếp theo của nó cách đó bao xa. 

Đối với một đường dẫn duy nhất tại vị trí$t$:

- tình trạng$0$: con đường đi tới$t$,
- tình trạng$1$: lần hạ cánh tiếp theo là lúc$t+1$,
- tình trạng$2$: lần hạ cánh tiếp theo là lúc$t+2$. 

Nếu một đường dẫn hiện đang ở trạng thái$0$, sau khi hạ cánh nó chọn bước nhảy có độ dài$1,2,3$, tạo ra các trạng thái mới$0,1,2$tương ứng. 

Cho tất cả$p$các đường dẫn với nhau, toàn bộ hệ thống chỉ được mô tả bằng số lượng$$(a,b,c),$$Ở đâu

-$a$đường dẫn đang ở trạng thái$0$, 
-$b$đường dẫn đang ở trạng thái$1$, 
-$c$đường dẫn đang ở trạng thái$2$,

với$$a+b+c=p.$$Do đó số trạng thái tự động hóa là$$\binom{p+2}{2}.$$Vì$p=20$, đây chỉ là$231$. 

--- 

Tại một quảng trường bên trong$t$, hình vuông được viếng thăm nếu$a>0$. 

Do đó, chúng tôi tăng cường trạng thái bằng cách cho biết liệu chúng tôi đã nhìn thấy một ô vuông chưa được ghé thăm hay chưa. 

Vì vậy tổng số trạng thái chỉ là$$231 \times 2 = 462.$$Điều này đưa ra một hệ thống chuyển tiếp tuyến tính hữu hạn, vì vậy$F(m,n)$có thể được tính bằng phép lũy thừa ma trận nhanh trong$O(\log n)$. 

Bởi vì mô đun yêu cầu là$$10^9 = 2^9\cdot 5^9,$$chúng tôi tính toán riêng modulo$512$và modulo$1953125$, trong đó phép nhân ma trận 64 bit là an toàn thì kết hợp với CRT. 

Quy tắc chuyển tiếp là: 

Nếu trạng thái hiện tại là$(a,b,c)$, thì trong số$a$chọn đường hạ cánh 

-$x$nhảy chiều dài$1$, 
-$y$nhảy chiều dài$2$, 
-$z$nhảy chiều dài$3$,

với$x+y+z=a$. 

Trạng thái tiếp theo là$$(b+x,\; c+y,\; z),$$với sự đa dạng$$\binom{a}{x,y,z}.$$--- 

Triển khai Python:```python
import numpy as np
from math import comb

MOD1 = 512
MOD2 = 1953125

def solve_mod(mod):
    m = 10
    p = 2 * m
    L = 10**12 - 1

    # Enumerate all (a,b,c), a+b+c=p
    states = []
    idx = {}

    for a in range(p + 1):
        for b in range(p + 1 - a):
            c = p - a - b
            idx[(a, b, c)] = len(states)
            states.append((a, b, c))

    S = len(states) * 2   # extra bit = already used one unvisited square

    A = np.zeros((S, S), dtype=np.int64)
    B = np.zeros((S, S), dtype=np.int64)

    # Build transition matrices
    for si, (a, b, c) in enumerate(states):

        trans = []

        for x in range(a + 1):
            for y in range(a - x + 1):
                z = a - x - y

                mult = comb(a, x) * comb(a - x, y)
                mult %= mod

                nxt = (b + x, c + y, z)
                ni = idx[nxt]

                trans.append((ni, mult))

        for used in range(2):

            row = si * 2 + used

            for ni, mult in trans:

                # First step: no interior-square check
                A[row, ni * 2 + used] += mult
                A[row, ni * 2 + used] %= mod

                # Interior steps
                nused = used + (1 if a == 0 else 0)

                if nused <= 1:
                    B[row, ni * 2 + nused] += mult
                    B[row, ni * 2 + nused] %= mod

    start = idx[(p, 0, 0)] * 2

    vec = np.zeros(S, dtype=np.int64)
    vec[start] = 1

    # First step (position 0 is not interior)
    vec = (vec @ A) % mod

    # Remaining steps
    e = L - 1
    P = B.copy()

    while e:
        if e & 1:
            vec = (vec @ P) % mod

        e >>= 1

        if e:
            P = (P @ P) % mod

    ans = (vec[start] + vec[start + 1]) % mod
    return int(ans)

a1 = solve_mod(MOD1)
a2 = solve_mod(MOD2)

# CRT
inv = pow(MOD1, -1, MOD2)

answer = (
    a1
    + MOD1 * (((a2 - a1) * inv) % MOD2)
) % (10**9)

print(answer)
