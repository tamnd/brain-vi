[Vấn đề dự án Euler 374](https://projecteuler.net/problem=374) 

##Giải pháp 

**Trả lời:**`334420941`Cho phép$$F(n)=f(n)\cdot m(n)$$Ở đâu$f(n)$là sản phẩm tối đa có thể thu được từ một phân vùng của$n$thành các số nguyên dương phân biệt và$m(n)$là số phần trong một phân vùng tối ưu như vậy. 

Quan sát quan trọng là phân vùng tối ưu luôn luôn “gần như liên tiếp”. 

Nếu như$$T_k=\frac{k(k+1)}2$$Và$$n=T_k+r,\qquad 0\le r\le k,$$sau đó: 

- Vì$r=0$:$$n=1+2+\cdots+k$$Phân vùng tối ưu là$$2+3+\cdots+(k-1)+(k+1)$$(sản phẩm tăng lên khi thay thế$1$Và$k$với$k+1$). 

Như vậy$$f(n)=\frac{(k+1)!}{2},\qquad m(n)=k-1.$$Vì thế$$F(n)=\frac{(k-1)(k+1)!}{2}.$$- Vì$1\le r\le k$: 

Bắt đầu từ$1,2,\dots,k$, di dời$k-r$, và thêm$k+1$. 

Kể từ đây$$f(n)=\frac{(k+1)!}{k-r}, \qquad m(n)=k,$$với trường hợp đặc biệt$r=k$cho đi$f(n)=(k+1)!$. 

Điều này mang lại một tổng có thể được tính toán trong$O(\sqrt N)$.

## Mã Python```
import math
from array import array

MOD = 982451653
N = 10**14

# Largest k with T_k <= N
kmax = (math.isqrt(1 + 8 * N) - 1) // 2
r = N - kmax * (kmax + 1) // 2

# Modular inverses up to kmax
inv = array('I', [0]) * (kmax + 1)
inv[1] = 1

for i in range(2, kmax + 1):
    inv[i] = (MOD - (MOD // i) * inv[MOD % i] % MOD) % MOD

inv2 = (MOD + 1) // 2

ans = 0

# H = sum_{j=1}^{k-1} 1/j mod MOD
H = 0

# A = (k+1)! mod MOD
A = 2  # for k = 1

# Complete blocks
for k in range(1, kmax):

    # contribution for n = T_k
    # plus contributions for T_k + 1 ... T_k + k
    block = A * (((k - 1) * inv2 + k * (1 + H)) % MOD)

    ans = (ans + block) % MOD

    H = (H + inv[k]) % MOD
    A = (A * (k + 2)) % MOD

# Final partial block
k = kmax

# n = T_k
ans = (ans + A * ((k - 1) * inv2)) % MOD

# n = T_k + 1 ... T_k + r
for j in range(k - r, k):
    ans = (ans + k * A * inv[j]) % MOD

ans %= MOD

print(ans)
```--- 

## Hướng dẫn 

### 1. Phân tách tam giác 

Mỗi số nguyên$n$có thể được viết duy nhất là$$n=T_k+r,\qquad 0\le r\le k.$$Điều này xác định cấu trúc phân vùng tối ưu. 

--- 

### 2. Nghịch đảo mô đun 

Chúng ta cần nhiều giá trị của$1/j \pmod{MOD}$. 

Sử dụng sự tái phát$$\text{inv}[i] = MOD-\left\lfloor \frac{MOD}{i}\right\rfloor \cdot \text{inv}[MOD\bmod i] \pmod{MOD},$$tất cả các nghịch đảo được tính toán trong thời gian tuyến tính. 

--- 

### 3. Giai thừa 

Biến$$A=(k+1)! \pmod{MOD}$$được cập nhật tăng dần sau mỗi lần lặp. 

--- 

### 4. Tổng hài 

Chúng tôi duy trì$$H=\sum_{j=1}^{k-1}\frac1j \pmod{MOD}.$$Điều này cho phép mỗi đóng góp khối được tính toán trong$O(1)$.
