[Vấn đề dự án Euler 698](https://projecteuler.net/problem=698) 

## Giải pháp 

**Trả lời:**`57808202`Cho phép$S$là tập hợp tất cả 123 số. 

Số thập phân thuộc về$S$nếu: 

1. mọi chữ số đều ở$\{1,2,3\}$và 
2. ứng với mỗi chữ số xuất hiện thì tần số của nó cũng thuộc về$S$. 

Ví dụ:

-$33\in S$bởi vì chữ số$3$xuất hiện$2$lần và$2\in S$. 
-$1112\in S$vì số lượng là: 

- chữ số$1$:$3$lần, 
- chữ số$2$:$1$thời gian, 

và cả hai$1,3\in S$. 

Chúng tôi tìm kiếm$$F(111111111111222333),$$cái$111111111111222333$-số thứ 123 theo thứ tự tăng dần. 

--- 

# 1. Phân tích toán học 

## Một quan sát đệ quy quan trọng 

Nếu một số có: 

-$a$bản sao của chữ số$1$, 
-$b$bản sao của chữ số$2$, 
-$c$bản sao của chữ số$3$, 

thì số đó hợp lệ nếu$$a,b,c \in \{0\}\cup S.$$Đối với một bộ ba cố định$(a,b,c)$, số chuỗi hợp lệ chỉ đơn giản là số đa thức$$\binom{a+b+c}{a,b,c} = \frac{(a+b+c)!}{a!b!c!}.$$Vì vậy, toàn bộ vấn đề giảm xuống: 

1. liệt kê các bộ ba có thể chấp nhận được, 
2. đếm xem có bao nhiêu chuỗi hợp lệ cho mỗi chiều dài tổng cộng, 
3. không xếp hạng theo từ điển. 

--- 

## Giá trị đếm nào có thể quan trọng? 

Chỉ số mục tiêu là khoảng$10^{17}$, vì vậy độ dài câu trả lời không lớn. 

Tính toán số lượng tích lũy theo chiều dài cho thấy: 

- tất cả các số có độ dài hợp lệ$\le 37$tổng cộng$$85\,645\,659\,280\,376\,850,$$trong khi bao gồm cả chiều dài$38$vượt chỉ tiêu. 

Vì vậy câu trả lời có độ dài$38$. 

Bây giờ hãy quan sát: 

- bất kỳ số đếm được chấp nhận nào cũng phải là số 123$\le 38$, 
- những giá trị duy nhất như vậy là$$1,2,3,11,12,13,21,22,23,31,32,33.$$Vì vậy chúng ta chỉ cần 12 giá trị này (cộng 0). 

--- 

## Đếm tất cả các số có độ dài-38 hợp lệ 

Chúng tôi xem xét tất cả các bộ ba$$(a,b,c)$$với$$a+b+c=38$$và mỗi thành phần trong$$\{0,1,2,3,11,12,13,21,22,23,31,32,33\}.$$Đối với mỗi bộ ba, thêm$$\frac{38!}{a!b!c!}.$$Điều này mang lại$$84\,604\,808\,105\,550\,180$$123 số có độ dài hợp lệ$38$. 

Chỉ số mong muốn bên trong chiều dài$38$do đó là$$111111111111222333 - 85645659280376850 = 25465451830845483.$$--- 

## Bỏ xếp hạng từ điển 

Các số có độ dài cố định được sắp xếp theo từ điển. 

Chúng tôi xây dựng chữ số câu trả lời theo chữ số. 

Tại mỗi vị trí: 

- thử đặt$1$, 
- đếm xem có bao nhiêu lần hoàn thành, 
- nếu chỉ số mục tiêu vượt quá số lượng đó, hãy trừ đi và thử$2$, 
- nếu không thì giữ lại$1$và tiếp tục. 

Số lần hoàn thành sau khi chọn tiền tố lại là số đa thức sử dụng tần số chữ số còn lại. 

Điều này mang lại kết quả duy nhất:$$13312122322122222113311233331213131323.$$Cuối cùng tính modulo$123123123$:$$13312122322122222113311233331213131323 \equiv 57808202 \pmod{123123123}.$$--- 

#2. Triển khai Python```python
from math import comb
from functools import lru_cache

TARGET = 111_111_111_111_222_333
MOD = 123_123_123

# All 123-numbers <= 38
VALID = [0, 1, 2, 3, 11, 12, 13, 21, 22, 23, 31, 32, 33]

@lru_cache(None)
def multinomial(a, b, c):
    """
    Number of strings containing:
        a copies of '1'
        b copies of '2'
        c copies of '3'
    """
    n = a + b + c
    return comb(n, a) * comb(n - a, b)

def count_length(L):
    """
    Count all 123-numbers of total length L.
    """
    total = 0

    for a in VALID:
        for b in VALID:
            c = L - a - b

            if c in VALID:
                total += multinomial(a, b, c)

    return total

# ------------------------------------------------------------
# Step 1: determine the answer length
# ------------------------------------------------------------

cumulative = 0
length = 0

while True:
    length += 1
    cnt = count_length(length)

    if cumulative + cnt >= TARGET:
        break

    cumulative += cnt

# Index inside this length block
k = TARGET - cumulative

# ------------------------------------------------------------
# Step 2: enumerate all admissible count triples
# ------------------------------------------------------------

triples = []

for a in VALID:
    for b in VALID:
        c = length - a - b

        if c in VALID:
            triples.append((a, b, c))

# ------------------------------------------------------------
# Step 3: lexicographic unranking
# ------------------------------------------------------------

answer_digits = []

for _ in range(length):

    for digit in "123":

        total = 0
        next_triples = []

        for a, b, c in triples:

            aa, bb, cc = a, b, c

            if digit == "1":
                if aa == 0:
                    continue
                aa -= 1

            elif digit == "2":
                if bb == 0:
                    continue
                bb -= 1

            else:
                if cc == 0:
                    continue
                cc -= 1

            total += multinomial(aa, bb, cc)
            next_triples.append((aa, bb, cc))

        if k > total:
            k -= total
        else:
            answer_digits.append(digit)
            triples = next_triples
            break

answer = int("".join(answer_digits))

print("F(n) =", answer)
print("Modulo =", answer % MOD)
```--- 

#3. Hướng dẫn sử dụng mã 

##`multinomial(a,b,c)`Tính toán$$\frac{(a+b+c)!}{a!b!c!}$$sử dụng hệ số nhị thức:```python
comb(n, a) * comb(n - a, b)
```--- 

##`count_length(L)`Liệt kê mọi bộ ba được chấp nhận:```python
(a,b,c)
```với tổng chiều dài$L$, sau đó tính tổng các số đa thức.

## Xây dựng từ điển 

Đối với mỗi vị trí chữ số:
