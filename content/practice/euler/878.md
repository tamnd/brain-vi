[Vấn đề dự án Euler 878](https://projecteuler.net/problem=878) 

## Giải pháp 

**Trả lời:**`23707109`Cho phép$$Q(a,b)=(a\otimes a)\oplus(2\otimes a\otimes b)\oplus(b\otimes b).$$Tích XOR chính xác là phép nhân đa thức trên$\mathbb F_2$:

nếu như$$a=\sum a_i2^i,\qquad b=\sum b_i2^i,$$xác định chúng bằng đa thức$$A(x)=\sum a_ix^i,\qquad B(x)=\sum b_ix^i.$$Khi đó tích XOR tương ứng với phép nhân trong$\mathbb F_2[x]$, với$x$được biểu thị bằng số nguyên$2$. 

Kể từ đây$$Q(a,b)\leftrightarrow A^2+xAB+B^2.$$Bây giờ xác định sự chuyển đổi$$T(a,b)=(b,\ a\oplus (2b)).$$Ở dạng đa thức:$$(A,B)\mapsto (B,\ A+xB).$$Tính toán trực tiếp trong$\mathbb F_2[x]$cho$$B^2+xB(A+xB)+(A+xB)^2 = A^2+xAB+B^2,$$bởi vì quá đặc trưng$2$,$$x^2B^2+x^2B^2=0.$$Vì thế$Q(a,b)$là bất biến dưới$T$. 

Hơn nữa, mọi nghiệm khác 0 đều thuộc về đúng một quỹ đạo vô hạn được tạo ra bằng cách áp dụng nhiều lần$T$và mỗi quỹ đạo có một đại diện **nguyên thủy** duy nhất thỏa mãn$$b\oplus (2a) > a.$$Đối với một cặp nguyên thủy với$Q(a,b)\le 10^6<2^{20}$, những cân nhắc về mức độ ngụ ý$b<2^{11}=2048$. 

Vì vậy chúng ta chỉ cần liệt kê các cặp nguyên thủy với$0\le a\le b<2048$. 

Đối với mỗi cặp nguyên thủy, áp dụng nhiều lần$T$cho đến khi$b>10^{17}$, đếm tất cả các phần tử quỹ đạo. 

Mã Python sau đây thực hiện chính xác điều đó.```python
def clmul(a, b):
    """Carryless (XOR) multiplication."""
    r = 0
    while b:
        if b & 1:
            r ^= a
        a <<= 1
        b >>= 1
    return r

def Q(a, b):
    return clmul(a, a) ^ (clmul(a, b) << 1) ^ clmul(b, b)

def primitive(a, b):
    return (a, b) == (0, 0) or ((b ^ (2 * a)) > a)

N = 10**17
M = 1_000_000

ans = 1   # (0,0) gives k=0

for a in range(2048):
    for b in range(max(a, 1), 2048):

        if not primitive(a, b):
            continue

        if Q(a, b) > M:
            continue

        x, y = a, b

        while y <= N:
            ans += 1
            x, y = y, x ^ (2 * y)

print(ans)
```Kiểm tra mẫu:```python

```phù hợp với tuyên bố.
