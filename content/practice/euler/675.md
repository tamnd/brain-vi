## Giải pháp 

**Trả lời:**`416146418`Cho phép$$S(n)=\sum_{d\mid n}2^{\omega(d)}$$Ở đâu$\omega(d)$là số các ước nguyên tố phân biệt của$d$. 

Chúng tôi cần$$F(n)=\sum_{i=2}^n S(i!)$$vì$n=10^7$, modulo$$M=1\,000\,000\,087.$$--- 

# Bước 1 - Rút ra biểu mẫu đóng cho$S(n)$Viết$$n=\prod_{p} p^{e_p}.$$Mỗi số chia$d\mid n$có hình thức$$d=\prod_p p^{a_p}, \qquad 0\le a_p\le e_p.$$Đối với số nguyên tố cố định$p$:

- nếu như$a_p=0$, nó không đóng góp gì cho$\omega(d)$,
- nếu như$a_p>0$, nó góp phần$1$. 

Vì vậy sự đóng góp từ Prime$p$là:

-$1$sự lựa chọn với trọng lượng$2^0=1$, 
-$e_p$lựa chọn với trọng lượng$2^1=2$. 

Do đó yếu tố địa phương là$$1+2e_p.$$Vì thế$$S(n)=\prod_p (2e_p+1).$$Vì vậy, ví dụ:$$6=2^1\cdot 3^1$$cho$$S(6)=(2\cdot1+1)(2\cdot1+1)=3\cdot3=9,$$phù hợp với tuyên bố. 

--- 

# Bước 2 - Áp dụng điều này cho giai thừa 

hãy để$$i! = \prod_p p^{E_p(i)}.$$Sau đó$$S(i!)=\prod_p (2E_p(i)+1).$$Giả sử chúng ta đã biết$S((i-1)!)$. 

Khi nhân với$i$,$$i=\prod_p p^{c_p},$$số mũ của mỗi số nguyên tố liên quan tăng thêm$c_p$:$$E_p \to E_p+c_p.$$Vậy hệ số thay đổi từ$$2E_p+1$$ĐẾN$$2(E_p+c_p)+1.$$Vì thế$$S(i!) = S((i-1)!) \prod_{p^ {c_p}\parallel i} \frac{2(E_p+c_p)+1}{2E_p+1}.$$Điều này cho phép cập nhật gia tăng về cơ bản$O(\omega(i))$.

# Bước 3 - Phân tích nhân tố hiệu quả 

Chúng tôi xử lý trước hệ số nguyên tố nhỏ nhất (SPF) cho mọi số lên tới$10^7$sử dụng sàng tuyến tính. 

Sau đó mỗi$i$có thể được nhân tố hóa một cách nhanh chóng. 

Chúng tôi cũng duy trì: 

-`exp[p] = E_p(i!)`- giá trị hiện tại$$cur = S(i!)$$modulo$M$. 

Kể từ khi chia modulo$M$có nghĩa là nhân với nghịch đảo môđun, chúng ta tính trước nghịch đảo của tất cả các số lẻ:$$(2k+1)^{-1}\pmod M.$$--- 

#Triển khai Python```python
from array import array

MOD = 1_000_000_087
N = 10_000_000

# ------------------------------------------------------------
# Linear sieve for smallest prime factor
# ------------------------------------------------------------

spf = array('I', [0]) * (N + 1)
primes = []

for i in range(2, N + 1):
    if spf[i] == 0:
        spf[i] = i
        primes.append(i)

    for p in primes:
        v = p * i
        if v > N:
            break
        spf[v] = p
        if p == spf[i]:
            break

# ------------------------------------------------------------
# Precompute inverses of all odd numbers:
# inv[k] = inverse of (2k+1) modulo MOD
# ------------------------------------------------------------

inv = array('I', [0]) * (N + 1)

# inverse of 1
inv[0] = 1

for k in range(1, N + 1):
    a = 2 * k + 1
    inv[k] = MOD - (MOD // a) * inv[(MOD % a) // 2] % MOD

# ------------------------------------------------------------
# exp[p] = exponent of prime p in current factorial
# cur    = S(i!)
# ans    = running sum of S(i!)
# ------------------------------------------------------------

exp = array('I', [0]) * (N + 1)

cur = 1
ans = 0

for n in range(2, N + 1):

    x = n

    # factorize n using SPF
    while x > 1:

        p = spf[x]
        c = 0

        while x % p == 0:
            x //= p
            c += 1

        old_e = exp[p]
        new_e = old_e + c
        exp[p] = new_e

        # multiply by (2*new_e+1)/(2*old_e+1)
        cur = (
            cur
            * (2 * new_e + 1)
            % MOD
            * inv[old_e]
            % MOD
        )

    ans += cur
    ans %= MOD

print(ans)
```--- 

# Hướng dẫn sử dụng mã 

### 1. Sàng tuyến tính```python
spf[i]
```lưu trữ thừa số nguyên tố nhỏ nhất của`i`. 

Điều này cho phép chúng ta phân tích mọi số một cách nhanh chóng. 

--- 

### 2. Bảng nghịch đảo 

Chúng ta cần nghịch đảo mô-đun của các số có dạng$$2e+1.$$Sự tái diễn$$a^{-1}\equiv -\left\lfloor \frac{M}{a}\right\rfloor (M\bmod a)^{-1} \pmod M$$tính toán nghịch đảo trong thời gian tuyến tính. 

--- 

### 3. Đang cập nhật$S(i!)$Giả sử số nguyên tố$p$có số mũ$e$, và sau khi nhân với$i$nó trở thành$e+c$. 

Sau đó```python
cur *= (2*new_e+1) / (2*old_e+1)
```modulo$M$. 

Vì vậy, chúng tôi cập nhật theo thời gian liên tục cho mỗi hệ số nguyên tố.
