[Vấn đề dự án Euler 843](https://projecteuler.net/problem=843) 

##Giải pháp 

**Trả lời:**`2816775424692`Gọi các số trên hình tròn là$a_0,a_1,\dots,a_{n-1}$, modulo được lập chỉ mục$n$. 

Một bước của quy trình thay thế$$a_i \longmapsto |a_{i-1}-a_{i+1}|.$$Vấn đề mấu chốt là tập hợp các giai đoạn cuối cùng có thể xảy ra được xác định hoàn toàn theo modulo$2$. 

Modulo$2$,$$|x-y|\equiv x+y \pmod 2,$$thế là xong$\mathbb F_2$bản đồ trở thành phép biến đổi tuyến tính$$T(a_i)=a_{i-1}+a_{i+1}.$$Đây là máy tự động di động Rule-90 cổ điển. 

--- 

# 1. Công thức đại số 

Biểu diễn một trạng thái bằng đa thức$$A(x)=\sum_{i=0}^{n-1} a_i x^i$$trong vòng$$R_n=\mathbb F_2[x]/(x^n-1).$$Sau đó, một lần lặp chỉ đơn giản là$$A(x)\mapsto (x+x^{-1})A(x).$$Từ$x^{-1}=x^{n-1}$trong vòng thương,$$T(A)=(x+x^{n-1})A.$$Như vậy động năng là phép nhân với một phần tử cố định của vành hữu hạn$R_n$. 

--- 

#2. Cấu trúc các thời kỳ 

Viết$$n=2^s m,\qquad m\ \text{odd}.$$Qua$\mathbb F_2$,$$x^n-1=(x^m-1)^{2^s}.$$Nhân tố$x^m-1$thành bất khả quy:$$x^m-1=\prod_i f_i(x).$$Mỗi yếu tố đưa ra một thành phần độc lập của động lực. 

Đối với một yếu tố không thể giảm được$f$, cho phép$\alpha$là gốc rễ của$f$. 

Trên thành phần đó, bản đồ hoạt động bằng cách nhân với$$\beta=\alpha+\alpha^{-1}.$$Khoảng thời gian đóng góp của thành phần đó là cấp số nhân của$\beta$trong trường hữu hạn được tạo bởi$\alpha$. 

Nếu như$n$có một yếu tố$2^s$, các thừa số lặp lại sẽ tạo ra một hệ số nhân lũy thừa hai$2^b$với$0\le b\le s$. 

Vì vậy: 

- mỗi thừa số bất khả quy đóng góp một chu kỳ lẻ cơ bản$o$, 
- các khoảng thời gian có thể thu được bằng cách lấy LCM của các khoảng thời gian thành phần, 
- và nhân với lũy thừa của hai đến từ các thừa số lặp lại. 

Đưa công đoàn lên trên tất cả$3\le n\le N$đưa ra tập hợp có tổng là$S(N)$. 

--- 

# 3. Xác minh trên các ví dụ 

cho$3\le n\le 6$: 

-$n=3$: dấu chấm$\{1\}$-$n=4$: dấu chấm$\{1\}$-$n=5$: dấu chấm$\{1,3\}$-$n=6$: dấu chấm$\{1,2\}$Liên minh:$$\{1,2,3\}$$Vì thế$$S(6)=1+2+3=6,$$phù hợp với tuyên bố. 

Vì$N=30$, phép tính cho kết quả chính xác$$S(30)=20381,$$một lần nữa phù hợp với tuyên bố vấn đề.

#4. Triển khai Python```python
import math
import sympy as sp

x = sp.symbols('x')

# convert a GF(2) polynomial to bit representation
def poly_to_int(poly):
    v = 0
    for (e,), c in poly.terms():
        if int(c) & 1:
            v |= (1 << e)
    return v

# multiplication in GF(2)[x]/(modpoly)
def mul(a, b, modpoly, deg):
    r = 0
    while b:
        if b & 1:
            r ^= a
        b >>= 1
        a <<= 1
        if a >> deg:
            a ^= modpoly
    return r

def powmod(a, e, modpoly, deg):
    r = 1
    while e:
        if e & 1:
            r = mul(r, a, modpoly, deg)
        a = mul(a, a, modpoly, deg)
        e >>= 1
    return r

# multiplicative order in the finite field
def order(a, modpoly, deg):
    group_order = (1 << deg) - 1
    ans = group_order

    for p, e in sp.factorint(group_order).items():
        for _ in range(e):
            if powmod(a, ans // p, modpoly, deg) == 1:
                ans //= p
            else:
                break

    return ans

def periods_for_n(n):
    # n = 2^s * m  with m odd
    s = 0
    m = n
    while m % 2 == 0:
        s += 1
        m //= 2

    poly = sp.Poly(x**m - 1, x, modulus=2)
    factors = sp.factor_list(poly, modulus=2)[1]

    component_choices = []

    for f, _ in factors:

        # ignore x+1 (gives only the trivial fixed point)
        if f.degree() == 1:
            continue

        deg = f.degree()
        modpoly = poly_to_int(f)

        alpha = 2                      # polynomial x
        alpha_inv = powmod(alpha, m - 1, modpoly, deg)

        beta = alpha ^ alpha_inv       # alpha + alpha^{-1} over GF(2)

        odd_period = order(beta, modpoly, deg)

        choices = [1]
        for b in range(s + 1):
            choices.append(odd_period * (1 << b))

        component_choices.append(choices)

    periods = {1}

    for choices in component_choices:
        new_periods = set()
        for a in periods:
            for b in choices:
                new_periods.add(math.lcm(a, b))
        periods = new_periods

    return periods

def S(N):
    all_periods = set()

    for n in range(3, N + 1):
        all_periods |= periods_for_n(n)

    return sum(all_periods)

print(S(30))   # 20381
print(S(100))
