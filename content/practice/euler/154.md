## Giải pháp 

**Trả lời:**`479742450`Đối với hệ số của$x^i y^j z^k$TRONG$$(x+y+z)^{200000}, \qquad i+j+k=200000,$$hệ số đa thức là$$\binom{200000}{i,j,k} = \frac{200000!}{i!\,j!\,k!}.$$Chúng ta phải đếm xem có bao nhiêu hệ số chia hết cho$10^{12}=2^{12}5^{12}$. 

Vì vậy chúng ta cần$$v_2\!\left(\binom{200000}{i,j,k}\right)\ge 12 \quad\text{and}\quad v_5\!\left(\binom{200000}{i,j,k}\right)\ge 12.$$Nội tuyến, hệ số đa thức là:$\binom{n}{i,j,k}=\frac{n!}{i!j!k!}$--- 

# 1. Phân tích toán học 

Đối với bất kỳ số nguyên tố nào$p$,$$v_p(n!) = \sum_{m\ge1}\left\lfloor \frac{n}{p^m}\right\rfloor.$$Kể từ đây$$v_p\!\left(\binom{n}{i,j,k}\right) = v_p(n!) - v_p(i!) - v_p(j!) - v_p(k!).$$Đối với vấn đề này:$$n=200000.$$Vì vậy hãy xác định:$$A_p(t)=v_p(t!).$$Sau đó$$v_p\!\left(\binom{200000}{i,j,k}\right) = A_p(200000)-A_p(i)-A_p(j)-A_p(k).$$Chúng tôi yêu cầu:$$A_2(i)+A_2(j)+A_2(k)\le A_2(200000)-12,$$Và$$A_5(i)+A_5(j)+A_5(k)\le A_5(200000)-12.$$--- 

## Tính toán hiệu quả 

Một vòng ba trực tiếp trên tất cả$$(i,j,k), \quad i+j+k=200000$$sẽ là không thể. 

Thay vào đó: 

- tính toán trước tất cả các giá trị giai thừa$A_2(t)$Và$A_5(t)$, 
- lặp đi lặp lại$i$,
- bộ$k=200000-i-j$, 
- Kiểm tra hai bất đẳng thức. 

Sự tối ưu hóa quan trọng là tính đối xứng: 

- hầu hết các bộ ba xảy ra trong hoán vị kích thước$6$, 
- chỉ những trường hợp có chỉ số bằng nhau mới có ít hoán vị hơn. 

Điều này làm giảm thời gian chạy rất nhiều.

#2. Triển khai Python```python
N = 200000
MIN_V = 12

# ---------------------------------------------------------
# Compute v_p(n!) for all n <= N
# ---------------------------------------------------------
def cumval(p):
    v = [0] * (N + 1)

    pk = p
    while pk <= N:
        for x in range(pk, N + 1, pk):
            v[x] += 1
        pk *= p

    # Prefix sums => v[n] = v_p(n!)
    for n in range(1, N + 1):
        v[n] += v[n - 1]

    return v

v2 = cumval(2)
v5 = cumval(5)

vN2 = v2[N]
vN5 = v5[N]

# ---------------------------------------------------------
# Count valid multinomial coefficients
# using symmetry i <= j <= k
# ---------------------------------------------------------
count = 0

for i in range(N + 1):

    t2 = vN2 - v2[i] - MIN_V
    t5 = vN5 - v5[i] - MIN_V

    if t2 < 0 or t5 < 0:
        continue

    # j ranges from i to k
    # because we enforce i <= j <= k
    maxj = (N - i) // 2

    for j in range(i, maxj + 1):

        k = N - i - j

        if v2[j] + v2[k] <= t2 and \
           v5[j] + v5[k] <= t5:

            # multiplicity from permutations
            if i == j == k:
                count += 1
            elif i == j or j == k or i == k:
                count += 3
            else:
                count += 6

print(count)
```--- 

#3. Hướng dẫn sử dụng mã 

## Bước 1 - định giá giai thừa nguyên tố 

Chức năng:```python
cumval(p)
```tính toán$$v_p(n!)$$cho mọi$0\le n\le 200000$. 

Nó thực hiện điều này bằng cách: 

- thêm sự đóng góp từ quyền hạn$p,p^2,p^3,\dots$, 
- sau đó lấy tổng tiền tố. 

--- 

## Bước 2 - chuyển phép chia thành bất đẳng thức 

Đối với mỗi$i$,```python
t2 = vN2 - v2[i] - 12
t5 = vN5 - v5[i] - 12
```đại diện cho sự đóng góp tối đa được phép từ$j!$Và$k!$. 

Sau đó chúng tôi kiểm tra:```python
v2[j] + v2[k] <= t2
v5[j] + v5[k] <= t5
```điều này hoàn toàn tương đương với việc yêu cầu chia hết cho$2^{12}$Và$5^{12}$. 

--- 

## Bước 3 - tính đối xứng 

Thay vì lặp lại tất cả các bộ ba có thứ tự:$$(i,j,k),$$chúng tôi chỉ lặp lại:$$i \le j \le k.$$Sau đó: 

- tất cả các chỉ số riêng biệt đều đóng góp$6$hoán vị, 
- hai chỉ số bằng nhau đóng góp$3$, 
- mọi người đều đóng góp như nhau$1$. 

Điều này làm giảm không gian tìm kiếm khoảng một hệ số$6$.
