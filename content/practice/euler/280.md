[Vấn đề dự án Euler 280](https://projecteuler.net/problem=280) 

##Giải pháp 

**Trả lời:**`430.088247`Hãy để một trạng thái mã hóa: 

- vị trí hiện tại của con kiến$(x,y)$, 
- liệu nó có mang hạt giống hay không, 
- hạt nào vẫn ở hàng dưới cùng, 
- ô vuông nào ở hàng trên cùng đã được điền. 

Bởi vì chỉ có$5$các hạt giống, mỗi cấu hình hàng dưới và hàng trên có thể được biểu diễn bằng một$5$-bit mặt nạ. 

Một trạng thái chuẩn hóa thuận tiện là:$$(x,y,c,S,T)$$Ở đâu

-$c\in\{0,1\}$cho biết liệu con kiến có mang hạt giống hay không, 
-$S$là tập hợp các hạt ở hàng dưới cùng vẫn còn tồn tại, 
-$T$là tập hợp các ô vuông ở hàng trên cùng bị chiếm. 

Quá trình này là Markovian. 

--- 

#1. Quy tắc chuyển tiếp 

Bất cứ khi nào kiến đi vào: 

- ô ở hàng dưới chứa một hạt giống, không mang hạt nào thì nó nhặt ngay lên; 
- một ô trống ở hàng trên khi đang mang một hạt giống, nó sẽ làm rơi nó ngay lập tức. 

Do đó, trạng thái chuẩn hóa sẽ tự động áp dụng những hành động này. 

Các trạng thái đầu cuối chính xác là những trạng thái có:$$S=\varnothing,\qquad T=\{0,1,2,3,4\},\qquad c=0.$$--- 

# 2. Phương trình tuyến tính 

hãy để$E(s)$là số bước còn lại dự kiến ​​từ trạng thái$s$. 

Đối với mọi trạng thái không kết thúc:$$E(s) = 1+\frac1{d(s)} \sum_{s'} E(s'),$$Ở đâu$d(s)\in\{2,3,4\}$là số ô vuông lân cận hợp lệ. 

Tương đương,$$E(s)-\frac1{d(s)}\sum_{s'}E(s')=1.$$Trạng thái đầu cuối thỏa mãn$$E(s)=0.$$Điều này mang lại một hệ thống tuyến tính thưa thớt. 

Không gian trạng thái có thể truy cập có kích thước$10270$, đủ nhỏ cho đại số tuyến tính thưa thớt.

#3. Triển khai Python```python
from collections import deque
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla

# ------------------------------------------------------------
# Grid neighbors
# ------------------------------------------------------------

moves = {}

for x in range(5):
    for y in range(5):
        nbrs = []

        for dx, dy in [(1,0), (-1,0), (0,1), (0,-1)]:
            nx, ny = x + dx, y + dy

            if 0 <= nx < 5 and 0 <= ny < 5:
                nbrs.append((nx, ny))

        moves[(x, y)] = nbrs

# ------------------------------------------------------------
# Normalize a state:
#   pick up seed automatically
#   drop seed automatically
# ------------------------------------------------------------

def normalize(x, y, carry, seeds, top):

    # pick up
    if carry == 0 and y == 0 and ((seeds >> x) & 1):
        carry = 1
        seeds ^= (1 << x)

    # drop
    if carry == 1 and y == 4 and not ((top >> x) & 1):
        carry = 0
        top |= (1 << x)

    return (x, y, carry, seeds, top)

# ------------------------------------------------------------
# Initial state
# ------------------------------------------------------------

start = normalize(2, 2, 0, 31, 0)

# ------------------------------------------------------------
# Enumerate all reachable states
# ------------------------------------------------------------

q = deque([start])
visited = {start}

while q:

    s = q.popleft()

    x, y, carry, seeds, top = s

    # terminal state
    if carry == 0 and seeds == 0 and top == 31:
        continue

    for nx, ny in moves[(x, y)]:

        ns = normalize(nx, ny, carry, seeds, top)

        if ns not in visited:
            visited.add(ns)
            q.append(ns)

states = list(visited)
index = {s:i for i,s in enumerate(states)}

n = len(states)

# ------------------------------------------------------------
# Build sparse linear system
# ------------------------------------------------------------

rows = []
cols = []
vals = []

b = np.ones(n)

for s in states:

    i = index[s]

    x, y, carry, seeds, top = s

    # diagonal
    rows.append(i)
    cols.append(i)
    vals.append(1.0)

    # terminal
    if carry == 0 and seeds == 0 and top == 31:
        b[i] = 0.0
        continue

    deg = len(moves[(x, y)])

    for nx, ny in moves[(x, y)]:

        ns = normalize(nx, ny, carry, seeds, top)

        rows.append(i)
        cols.append(index[ns])
        vals.append(-1.0 / deg)

A = sp.csr_matrix((vals, (rows, cols)), shape=(n, n))

# ------------------------------------------------------------
# Solve
# ------------------------------------------------------------

solution, info = spla.bicgstab(A, b, rtol=1e-12)

answer = solution[index[start]]

print(answer)
```--- 

#4. Hướng dẫn code 

-`normalize(...)`thực thi các quy tắc đón/thả tự động. 
- BFS chỉ tạo ra các trạng thái có thể truy cập được. 
- Mỗi phương trình thực hiện:$$E(s)=1+\text{average of neighbors}.$$- Ma trận thưa thớt vì mỗi trạng thái có nhiều nhất$4$chuyển tiếp đi. 
-`bicgstab`giải quyết hiệu quả các$10270\times10270$hệ thống thưa thớt. 

Giá trị tính toán là:$$430.088246716666\ldots$$Làm tròn đến$6$số thập phân:$$430.088247$$---
