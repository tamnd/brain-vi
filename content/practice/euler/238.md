# 1. Cấu trúc của chuỗi Blum–Blum–Shub 

Máy phát điện là$$s_{n+1}=s_n^2 \pmod{20300713},\qquad s_0=14025256.$$Trình tự hoàn toàn là định kỳ. Tính toán chu trình cho: 

- thời kỳ của$s_n$:$$T=2\,534\,198$$Ghép tất cả các số trong một khoảng thời gian đầy đủ sẽ tạo ra một khối chữ số có độ dài$$L=18\,886\,117$$có tổng các chữ số là$$S=80\,846\,691.$$Vì thế từ vô hạn$w$là tuần hoàn với chu kì$L$và mỗi khoảng thời gian đầy đủ đều đóng góp chính xác$S$đến tổng chữ số.

# 2. Nhận dạng tính chu kỳ chính 

Giả sử một chuỗi con bắt đầu tại vị trí$z$có tổng chữ số$k$. 

Chuyển chuỗi con theo một dấu chấm đầy đủ chữ số$L$giữ tất cả các chữ số giống hệt nhau nhưng cộng tổng các chữ số của một dấu chấm$S$. Kể từ đây:$$p(k+S)=p(k)+L.$$Đây là mức giảm quan trọng. 

Vì vậy, đối với bất kỳ$$k=qS+r,\qquad 1\le r\le S,$$chúng tôi nhận được$$p(k)=qL+p(r).$$Vì vậy toàn bộ vấn đề quy về tính toán$p(r)$chỉ dành cho$$1\le r\le S.$$--- 

#3. Tính toán tất cả$p(r)$vì$1\le r\le S$Một sự ngây thơ$O(L^2)$quét là không thể. 

Quan sát quan trọng là: 

- tổng các chữ số không âm và tăng đơn điệu khi chuỗi con được mở rộng, 
- đối với mỗi vị trí bắt đầu, tổng tích lũy tạo thành một chuỗi tăng dần, 
- mỗi giá trị của$r$chỉ cần sự xuất hiện _first_ của nó. 

Sử dụng cách tiếp cận cửa sổ trượt/tổng ​​tích lũy trên một khoảng thời gian chữ số là đủ. 

Sau khi tính toán hết$p(r)$, định nghĩa$$A=\sum_{r=1}^{S} p(r).$$Việc tính toán cho:$$A=745\,314\,242\,834\,532.$$--- 

#4. Tổng kết lại$2\times10^{15}$Cho phép$$N=2\times10^{15}.$$Viết$$N=qS+t,$$Ở đâu$$q=\left\lfloor \frac{N}{S}\right\rfloor, \qquad t=N\bmod S.$$sử dụng$$p(qS+r)=qL+p(r),$$chúng tôi có được$$\sum_{k=1}^{N} p(k) = qA + L S \cdot \frac{q(q-1)}2 + q\sum_{r=1}^{t}1 + \sum_{r=1}^{t} p(r).$$Đánh giá điều này với các bảng tính toán mang lại:$$9922545104535660.$$--- 

#5. Triển khai Python```python
MOD = 20300713
s = 14025256

# ------------------------------------------------------------
# Build one full period of the BBS sequence
# ------------------------------------------------------------

seen = set()
vals = []

while s not in seen:
    seen.add(s)
    vals.append(s)
    s = (s * s) % MOD

# Concatenate digits
digits = ''.join(map(str, vals))
d = [int(c) for c in digits]

L = len(d)
S = sum(d)

# ------------------------------------------------------------
# Compute p(k) for 1 <= k <= S
# ------------------------------------------------------------

p = [0] * (S + 1)

# Duplicate digits so windows can wrap cyclically
dd = d + d

for start in range(L):

    s = 0

    # Extend substring
    for end in range(start, start + L):

        s += dd[end]

        if s > S:
            break

        if p[s] == 0:
            p[s] = start + 1

# Base sum
A = sum(p[1:])

# ------------------------------------------------------------
# Use periodicity:
# p(k + S) = p(k) + L
# ------------------------------------------------------------

N = 2 * 10**15

q, t = divmod(N, S)

answer = (
    q * A
    + L * S * (q * (q - 1) // 2)
    + q * sum(p[1:t + 1])
)

print(answer)
```---
