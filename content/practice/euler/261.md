[Vấn đề dự án Euler 261](https://projecteuler.net/problem=261) 

## Giải pháp 

**Trả lời:**`238890850232021`Cho phép$$S(a,b)=a^2+(a+1)^2+\cdots+b^2$$và giả sử$k$là một trục xoay vuông. Khi đó tồn tại số nguyên$m>0$Và$n\ge k$như vậy$$(k-m)^2+\cdots+k^2=(n+1)^2+\cdots+(n+m)^2.$$Chúng ta phải tìm tổng của tất cả các phân biệt như vậy$k\le 10^{10}$. 

--- 

# 1. Phân tích toán học 

Công thức tổng bình phương là$$\sum_{i=1}^{t} i^2=\frac{t(t+1)(2t+1)}6.$$Vì thế$$S(k-m,k)=S(n+1,n+m).$$Viết cái này với tổng tiền tố và đơn giản hóa sẽ cho$$k^2(m+1)-km(m+1)-mn(m+n+1)=0.$$Chia cho$m(m+1)$cho hình dạng đối xứng hơn$$\frac{k^2}{m}-k-n-\frac{n^2}{m+1}=0. \tag{1}$$--- 

## Giới hạn$m$Từ$n\ge k$,$$\frac{k^2}{m}-2k-\frac{k^2}{m+1}\ge0.$$Sau khi đơn giản hóa:$$k\ge 2m(m+1).$$Do đó đối với$k\le N=10^{10}$,$$2m(m+1)\le N.$$Vì thế$$m \le \frac{-1+\sqrt{1+2N}}2 \approx 70710.$$Như vậy chỉ khoảng$7\times 10^4$giá trị của$m$cần phải được kiểm tra. 

--- 

# 2. Chuyển sang phương trình Pell 

Giới thiệu số nguyên$x,t$qua$$\begin{cases} 2k = m(x+1)+t,\\ 2n = (m+1)(x-1)+t. \end{cases}$$Thay thế vào (1) và rút gọn kết quả$$m(m+1)(x^2-1)=t^2. \tag{2}$$Bây giờ hãy viết$$m=r p^2,\qquad m+1=s q^2,$$Ở đâu$r,s$là hình vuông. 

Vì các số nguyên liên tiếp là nguyên tố cùng nhau nên$r,s$cũng là nguyên tố cùng nhau. 

Phương trình (2) trở thành$$r s p^2 q^2 (x^2-1)=t^2.$$Kể từ đây$rpsq\mid t$. Cho phép$$t=rpsq\,y.$$Sau đó$$x^2-rs\,y^2=1. \tag{3}$$Đây là phương trình Pell. 

Vì vậy đối với mỗi$m$, chúng tôi: 

1. Tính phần hình vuông$r,s$của$m,m+1$. 
2. Giải phương trình Pell$$x^2-Dy^2=1, \qquad D=rs.$$3. Tạo tất cả các giải pháp Pell. 
4. Phục hồi$$k=\frac{m(x+1)+t}{2}, \qquad t=rpsq\,y.$$5. Giữ tất cả sự khác biệt$k\le 10^{10}$. 

--- 

#3. Triển khai Python```python
from math import isqrt

N = 10**10

# ---------------------------------------------------------
# Compute squarefree part and square part of every integer
# n = sf[n] * sq[n]^2
# ---------------------------------------------------------

M = (-1 + isqrt(1 + 2 * N)) // 2

sf = [0] * (M + 3)   # squarefree part
sq = [0] * (M + 3)   # square root of square part

for n in range(1, M + 3):

    x = 1
    y = 1
    t = n

    d = 2
    while d * d <= t:

        if t % d == 0:

            e = 0
            while t % d == 0:
                t //= d
                e += 1

            # odd exponent contributes to squarefree part
            if e & 1:
                x *= d

            # floor(e/2) contributes to square part
            y *= d ** (e >> 1)

        d += 1 if d == 2 else 2

    if t > 1:
        x *= t

    sf[n] = x
    sq[n] = y

# ---------------------------------------------------------
# Fundamental Pell solution x^2 - D y^2 = 1
# via continued fractions
# ---------------------------------------------------------

def pell_fundamental(D):

    a0 = isqrt(D)

    if a0 * a0 == D:
        return None

    m = 0
    d = 1
    a = a0

    num_prev, num = 1, a
    den_prev, den = 0, 1

    while num * num - D * den * den != 1:

        m = d * a - m
        d = (D - m * m) // d
        a = (a0 + m) // d

        num_prev, num = num, num_prev + a * num
        den_prev, den = den, den_prev + a * den

    return num, den

# ---------------------------------------------------------
# Enumerate all square-pivots
# ---------------------------------------------------------

ans_set = set()

for m in range(1, M + 1):

    D = sf[m] * sf[m + 1]

    x1, y1 = pell_fundamental(D)

    # Generate all Pell solutions
    x, y = x1, y1

    # t = sf[m]*sf[m+1]*sq[m]*sq[m+1]*y
    mult = sf[m] * sf[m + 1] * sq[m] * sq[m + 1]

    while True:

        t = mult * y

        kk = m * (x + 1) + t

        if kk > 2 * N:
            break

        nn = (m + 1) * (x - 1) + t

        # parity checks + n >= k
        if kk % 2 == 0 and nn % 2 == 0 and nn >= kk:
            ans_set.add(kk // 2)

        # Next Pell solution
        x, y = (
            x1 * x + D * y1 * y,
            x1 * y + y1 * x
        )

answer = sum(ans_set)

print(answer)
```--- 

#4. Hướng dẫn code 

## Bước 1 - Giới hạn tìm kiếm```python
M = (-1 + isqrt(1 + 2 * N)) // 2
```Từ$$2m(m+1)\le N,$$điều này mang lại mức tối đa có thể$m$. 

--- 

## Bước 2 - Phân tách số nguyên 

Với mọi số nguyên$n$,$$n = \text{squarefree}(n)\times (\text{square part})^2.$$Chúng tôi lưu trữ: 

-`sf[n]`= phần tự do 
-`sq[n]`= căn bậc hai của phần hình vuông 

Những điều này là cần thiết để hình thành nên sự phân biệt đối xử Pell. 

--- 

## Bước 3 - Giải phương trình Pell 

Đối với mỗi$m$,$$D = \operatorname{sf}(m)\operatorname{sf}(m+1).$$Chúng tôi giải quyết$$x^2 - D y^2 = 1.$$chức năng`pell_fundamental`tính toán giải pháp cơ bản bằng cách sử dụng các phân số tiếp tục. 

--- 

## Bước 4 - Tạo tất cả các giải pháp 

Tất cả các giải pháp Pell đều đến từ sức mạnh của đơn vị cơ bản:$$x+y\sqrt D=(x_1+y_1\sqrt D)^n.$$Sự tái diễn```python
x, y = (
    x1 * x + D * y1 * y,
    x1 * y + y1 * x
)
```lần lượt tạo ra chúng. 

--- 

## Bước 5 - Khôi phục$k$sử dụng$$k=\frac{m(x+1)+t}{2},$$với$$t=\operatorname{sf}(m)\operatorname{sf}(m+1)    \operatorname{sq}(m)\operatorname{sq}(m+1)\,y.$$Chúng tôi xác minh tính chẵn lẻ và$n\ge k$, sau đó lưu trữ riêng biệt$k$.
