[Vấn đề dự án Euler 710](https://projecteuler.net/problem=710) 

##Giải pháp 

**Trả lời:**`1275000`Cho phép

-$P(n)$= số bộ giá trị palindromic tổng hợp thành$n$, 
-$a(n)$= số bộ giá trị palindromic tổng hợp thành$n$**không** chứa một$2$, 
-$t(n)$= số lượng hai người bạn. 

Sau đó$$t(n)=P(n)-a(n).$$Đối với các tổ hợp palindromic, nửa bên trái xác định toàn bộ bộ dữ liệu, do đó$$P(n)=2^{\lfloor n/2 \rfloor}.$$Trình tự$a(n)$thỏa mãn sự tái phát$$a(n)=a(n-2)+a(n-3),$$với các giá trị ban đầu$$a(1)=1,\quad a(2)=1,\quad a(3)=2.$$Vì thế,$$t(n)=2^{\lfloor n/2 \rfloor}-a(n).$$Bây giờ chúng tôi tính toán$t(n)\bmod 10^6$cho đến khi nó trở thành$0$lần đầu tiên với$n>42$.```python
MOD = 10**6

# a[n] = number of palindromic sums of n with no element equal to 2
a = [0, 1, 1, 2]   # indices 0..3

n = 3

while True:
    n += 1

    # recurrence: a(n) = a(n-2) + a(n-3)
    a.append((a[n - 2] + a[n - 3]) % MOD)

    # total palindromic sums = 2^(floor(n/2))
    total = pow(2, n // 2, MOD)

    # twopals
    t = (total - a[n]) % MOD

    if n > 42 and t == 0:
        print(n)
        break
```### Hướng dẫn 

-`a[n]`lưu trữ số lượng tổng palindromic tránh số 2. 
- Chúng tôi chỉ giữ giá trị modulo$10^6$, bởi vì việc chia hết cho một triệu mới là điều quan trọng. 
-`pow(2, n // 2, MOD)`tính toán$2^{\lfloor n/2\rfloor}\bmod 10^6$. 
- Chúng tôi kiểm tra từng$n>42$cho đến khi$t(n)\equiv 0 \pmod{10^6}$.
