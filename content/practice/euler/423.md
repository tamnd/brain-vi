[Vấn đề dự án Euler 423](https://projecteuler.net/problem=423) 

## Giải pháp 

**Trả lời:**`653972374`Cho phép$$C(n)=\#\{\text{length-}n\text{ die sequences with }c\le \pi(n)\},$$Ở đâu$c$là số cặp bằng nhau liền kề. 

Chúng ta phải tính toán$$S(50\,000\,000)=\sum_{n=1}^{50\,000\,000} C(n) \pmod{1\,000\,000\,007}.$$--- 

# 1. Phân tích toán học 

## Đếm chính xác các dãy$k$sự kề cận bằng nhau 

Một chuỗi độ dài$n$có$n-1$những khoảng trống liền kề. 

Giả sử chính xác$k$khoảng cách đó bằng nhau. 

- Chọn$k$khoảng trống bằng nhau:$$\binom{n-1}{k}.$$- Chọn giá trị xúc xắc đầu tiên:$$6.$$- Mọi khoảng cách không bằng nhau đều buộc phải thay đổi, tạo ra$5$mỗi lựa chọn. 

có$n-1-k$những khoảng trống như vậy. 

Kể từ đây:$$\boxed{ N(n,k)=6\binom{n-1}{k}5^{\,n-1-k} }$$Vì thế$$\boxed{ C(n)=6\sum_{k=0}^{\pi(n)} \binom{n-1}{k}5^{\,n-1-k} }$$Điều này ngay lập tức xác minh:$$C(4)=6\left(5^3+3\cdot 5^2+3\cdot 5\right)=1290.$$--- 

#2. Tái phát nhanh 

Xác định$$D(n)=\frac{C(n)}{6} = \sum_{k=0}^{\pi(n)} \binom{n-1}{k}5^{\,n-1-k}.$$Đồng thời xác định$$p=\pi(n), \qquad B_n=\binom{n-1}{p}5^{\,n-1-p}.$$--- 

## Chuyển tiếp tổng hợp 

Nếu$n+1$là hợp số thì$\pi(n+1)=p$. 

Sử dụng Pascal:$$\binom{n}{k}=\binom{n-1}{k}+\binom{n-1}{k-1}.$$Sau đó$$D(n+1) = 6D(n)-B_n.$$Như vậy$$\boxed{ C(n+1)=6C(n)-6B_n }$$--- 

## Quá trình chuyển đổi chính 

Nếu$n+1$là số nguyên tố thì$\pi(n+1)=p+1$. 

Giới hạn tổng trên mới đóng góp thêm một số hạng:$$D(n+1) = 6D(n) + \binom{n-1}{p+1}5^{\,n-1-p}.$$sử dụng$$\binom{n-1}{p+1} = \binom{n-1}{p}\frac{n-1-p}{p+1},$$chúng tôi có được$$\boxed{ C(n+1) = 6C(n) + 6B_n\frac{n-1-p}{p+1} }$$--- 

# 3. Đang cập nhật$B_n$Chúng tôi cũng cần một sự tái diễn cho$B_n$. 

---

## Nếu như$n+1$là tổng hợp 

Sau đó$p$vẫn cố định:$$B_{n+1} = \binom{n}{p}5^{n-p} = B_n\cdot \frac{5n}{n-p}.$$Vì thế$$\boxed{ B_{n+1}=B_n\frac{5n}{n-p} }$$---

## Nếu như$n+1$là số nguyên tố 

Sau đó$p\to p+1$:$$B_{n+1} = \binom{n}{p+1}5^{\,n-1-p} = B_n\frac{n}{p+1}.$$Kể từ đây$$\boxed{ B_{n+1}=B_n\frac{n}{p+1} }$$--- 

# 4. Độ phức tạp 

Mọi thứ trở thành một$O(L)$vòng lặp chỉ với công việc không đổi trên mỗi bước. 

Chúng tôi sàng các số nguyên tố lên đến$50\,000\,000$, tính toán trước các nghịch đảo mô-đun và lặp lại một lần. 

Điều này dễ dàng chạy trong vòng vài giây trong C++ được tối ưu hóa. 

--- 

#5. Triển khai Python```python
MOD = 1_000_000_007
L = 50_000_000

# ---------- sieve ----------
is_prime = bytearray(b"\x01") * (L + 1)
is_prime[0] = is_prime[1] = 0

p = 2
while p * p <= L:
    if is_prime[p]:
        step = p
        start = p * p
        is_prime[start:L + 1:step] = b"\x00" * (((L - start) // step) + 1)
    p += 1

# ---------- modular inverses ----------
inv = [0] * (L + 1)
inv[1] = 1

for i in range(2, L + 1):
    inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

# ---------- recurrence ----------
# C(1) = 6
C = 6

# B_1 = binom(0,0) * 5^0 = 1
B = 1

S = 6
pi_n = 0

for n in range(1, L):

    if is_prime[n + 1]:
        # prime transition

        extra = (
            6
            * B
            % MOD
            * (n - 1 - pi_n)
            % MOD
            * inv[pi_n + 1]
        ) % MOD

        C = (6 * C + extra) % MOD

        pi_n += 1

        B = B * n % MOD * inv[pi_n] % MOD

    else:
        # composite transition

        C = (6 * C - 6 * B) % MOD

        B = (
            B
            * 5
            % MOD
            * n
            % MOD
            * inv[n - pi_n]
        ) % MOD

    S += C
    S %= MOD

print(S)
```--- 

#6. Hướng dẫn sử dụng code 

###Sàng lọc chính 

Chúng tôi tính toán tính nguyên tố cho tất cả các số nguyên lên đến$50\,000\,000$. 

Điều này cho chúng tôi biết liệu$\pi(n)$tăng ở mỗi bước. 

--- 

### Nghịch đảo mô-đun 

Sự tái phát chia cho các số như$p+1$Và$n-p$. 

Sử dụng:$$\text{inv}[i] = -(M//i)\cdot \text{inv}[M\bmod i] \pmod M$$chúng tôi tính toán trước tất cả các nghịch đảo trong thời gian tuyến tính. 

--- 

### Vòng lặp chính 

Chúng tôi duy trì: 

-`C = C(n)`-`B = B_n`-`pi_n = π(n)`Ở mỗi bước: 

- nếu$n+1$là số nguyên tố: 

sử dụng phép tái phát nguyên tố, 
- mặt khác: 

sử dụng phép truy hồi tổng hợp. 

Chúng tôi tích lũy thành`S`.
