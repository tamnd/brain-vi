[Vấn đề dự án Euler 506](https://projecteuler.net/problem=506) 

##Giải pháp 

**Trả lời:**`18934502`Đặt luồng chữ số vô hạn là$$123432123432123432\cdots$$Chúng tôi phân chia nó thành các số nguyên liên tiếp$v_n$sao cho tổng các chữ số của$v_n$bằng$n$. 

Các điều khoản đầu tiên là:$$1,2,3,4,32,123,43,2123,432,1234,32123,\dots$$chúng tôi muốn$$S(n)=\sum_{k=1}^{n} v_k$$và đặc biệt$$S(10^{14}) \bmod 123454321.$$--- 

## 1. Phân tích toán học 

### Bước 1: Quan sát cấu trúc tuần hoàn 

Khối lặp lại là$$123432$$tổng các chữ số của nó là$$1+2+3+4+3+2 = 15.$$Đây là cái nhìn sâu sắc quan trọng. 

Vì tổng khối lặp lại là 15 nên việc tăng tổng chữ số mục tiêu lên 15 chỉ cần thêm toàn bộ chu kỳ chữ số. 

Ví dụ: 

|$n$|$v_n$| 
| --- | --- | 
| 1 | 1 | 
| 16 | 1234321 | 
| 31 | 1234321234321 | 

Tương tự: 

|$n$|$v_n$| 
| --- | --- | 
| 5 | 32 | 
| 20 | 32123432 | 
| 35 | 32123432123432 | 

Vì vậy đối với dư lượng cố định$r=n\bmod 15$,$$n=15q+r$$số$v_n$có dạng:$$v_{15q+r} = \underbrace{C_rC_r\cdots C_r}_{q\text{ copies}}\,B_r$$Ở đâu:

-$B_r=v_r$(mẫu cơ bản), 
-$C_r$là khối tuần hoàn có 6 chữ số. 

Ví dụ:$$B_5=32,\qquad C_5=321234$$Vì thế$$v_{20}=32123432.$$--- 

### Bước 2: Công thức giá trị thập phân 

Nếu$L_r$là độ dài chữ số của$B_r$, sau đó$$v_{15q+r} = \left( C_r\sum_{i=0}^{q-1}10^{6i} \right)10^{L_r} + B_r.$$Phần hình học là$$R_q = \sum_{i=0}^{q-1}10^{6i} = \frac{10^{6q}-1}{10^6-1}.$$Như vậy$$v_{15q+r} = C_r\,10^{L_r}R_q+B_r.$$--- 

### Bước 3: Tổng hợp tất cả$q$Đối với dư lượng cố định$r$, cho phép$$m_r = \left\lfloor\frac{N-r}{15}\right\rfloor+1$$là số lượng các điều khoản. 

Sau đó$$S_r = \sum_{q=0}^{m_r-1} v_{15q+r}.$$Thay thế công thức:$$S_r = m_rB_r + C_r10^{L_r} \sum_{q=0}^{m_r-1}R_q.$$Hiện nay$$\sum_{q=0}^{m-1}R_q = \frac{ \sum_{q=0}^{m-1}10^{6q}-m }{ 10^6-1 }$$Và$$\sum_{q=0}^{m-1}10^{6q} = \frac{10^{6m}-1}{10^6-1}.$$Mọi thứ đều có thể được tính toán theo modulo$$M=123454321$$sử dụng nghịch đảo mô-đun. 

Bởi vì$$\gcd(999999,M)=1,$$modulo chia$M$là hợp lệ.

## 2. Triển khai Python```python
MOD = 123454321
BASE = 10**6
D = BASE - 1  # 999999

# First 15 base values v_r
B = [
    None,
    "1", "2", "3", "4", "32",
    "123", "43", "2123", "432",
    "1234", "32123", "43212",
    "34321", "23432", "123432"
]

# Corresponding repeating 6-digit blocks
C = [
    None,
    "123432", "234321", "343212", "432123",
    "321234", "123432", "432123", "212343",
    "432123", "123432", "321234", "432123",
    "343212", "234321", "123432"
]

def solve(N):
    inv_D = pow(D, -1, MOD)
    inv_geom = pow(BASE - 1, -1, MOD)

    total = 0

    for r in range(1, 16):
        if r > N:
            break

        # number of q-values
        m = (N - r) // 15 + 1

        b = int(B[r])
        c = int(C[r])
        L = len(B[r])

        # geometric sum:
        # sum_{q=0}^{m-1} 10^(6q)
        geom = (
            (pow(BASE, m, MOD) - 1)
            * inv_geom
        ) % MOD

        # sum of R_q
        sum_R = ((geom - m) % MOD) * inv_D % MOD

        contribution = (
            (m % MOD) * (b % MOD)
            + c * pow(10, L, MOD) * sum_R
        ) % MOD

        total = (total + contribution) % MOD

    return total

# Checks
print(solve(11))    # 36120
print(solve(1000))  # 18232686

# Final answer
print(solve(10**14))
```--- 

## 3. Hướng dẫn sử dụng mã 

-`B[r]`lưu trữ mẫu cơ sở$v_r$. 
-`C[r]`lưu trữ chu kỳ 6 chữ số lặp lại cho phần dư$r$. 
- Đối với từng loại dư lượng$r=1,\dots,15$: 

- đếm xem có bao nhiêu thuật ngữ xuất hiện$N$, 
- tính chuỗi hình học modulo$M$, 
- tính toán tổng đóng góp của lớp dư lượng đó, 
- thêm nó vào câu trả lời. 

### Xác minh 

Chương trình tái tạo các ví dụ:$$S(11)=36120$$Và$$S(1000)\bmod 123454321=18232686.$$Cả hai đều khớp chính xác với tuyên bố vấn đề.
