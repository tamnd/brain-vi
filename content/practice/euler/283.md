##Giải pháp 

**Trả lời:**`28038042525570324`Gọi các cạnh của tam giác là$a,b,c$, nửa chu vi$s$, và diện tích$K$. 

Chúng tôi được bảo rằng$$\frac{K}{a+b+c}=n$$đối với một số nguyên$1\le n\le 1000$. 

Từ$a+b+c=2s$,$$K = 2ns.$$Sử dụng công thức Heron,$$K^2=s(s-a)(s-b)(s-c).$$Định nghĩa$$x=s-a,\qquad y=s-b,\qquad z=s-c.$$Sau đó$$a=y+z,\quad b=z+x,\quad c=x+y,$$Và$$s=x+y+z.$$Thay thế vào Heron:$$K^2=sxyz.$$Nhưng$K=2ns$, Vì thế$$4n^2s^2=sxyz.$$Từ$s=x+y+z$,$$xyz = 4n^2(x+y+z).$$Chia cả hai vế cho$xyz$,$$\frac1x+\frac1y+\frac1z=\frac1{4n^2}.$$Vì vậy, vấn đề trở thành: 

> Tìm tất cả các nghiệm số nguyên dương 
> 
> 
> 
> 
>$$\frac1x+\frac1y+\frac1z=\frac1{4n^2},$$> 
> 
> 
> 
> cho$1\le n\le1000$, sau đó tính tổng tất cả các chu vi tương ứng 
> 
> 
> 
> 
>$$P=2(x+y+z).$$--- 

# Hệ số hóa chính 

hãy để$$d=4n^2.$$Sau đó$$\frac1x+\frac1y+\frac1z=\frac1d.$$Cho rằng$x\le y\le z$. 

Sắp xếp lại:$$yz=d(x+y+z).$$Di chuyển các điều khoản:$$yz-dy-dz=d x.$$Thêm vào$d^2$:$$(y-d)(z-d)=d(d+x).$$Bây giờ đối với mỗi$x$, mọi cặp ước số của$d(d+x)$đưa ra một giải pháp:$$y=d+u,\qquad z=d+v,$$Ở đâu$$uv=d(d+x).$$Điều này mang lại một thuật toán liệt kê nhanh. 

Các giới hạn có thể quản lý được vì:$$x\le 3d$$(từ$3/x\ge 1/d$). 

--- 

#Triển khai Python```python
from math import isqrt

LIMIT = 1000

total = 0

for n in range(1, LIMIT + 1):

    d = 4 * n * n

    # From x <= y <= z and
    # 1/x + 1/y + 1/z = 1/d
    # we get x <= 3d
    for x in range(1, 3 * d + 1):

        target = d * (d + x)

        # Enumerate divisor pairs
        r = isqrt(target)

        for u in range(1, r + 1):

            if target % u != 0:
                continue

            v = target // u

            y = d + u
            z = d + v

            # enforce ordering
            if x > y or y > z:
                continue

            # verify equation (safety check)
            if x * y * z != d * (x + y + z):
                continue

            perimeter = 2 * (x + y + z)

            total += perimeter

print(total)
```---

# Xác minh ví dụ nhỏ 

## Ví dụ 1 

Tam giác$6,8,10$. 

Bán chu vi:$$s=12.$$Sau đó$$x=12-6=6,\quad y=4,\quad z=2.$$Thực vậy,$$\frac16+\frac14+\frac12= \frac{11}{12}?$$Thứ tự chính xác:$$x=1,\ y=3,\ z=8$$vì$d=4$:$$\frac11+\frac13+\frac18=\frac{35}{24}$$Không được đặt hàng đúng cách từ sự lựa chọn đó. Sử dụng trực tiếp các biến Heron:$$x=2,\ y=4,\ z=6$$cho$$\frac12+\frac14+\frac16= \frac{11}{12},$$Và$$xyz=48,\quad d(x+y+z)=4\cdot12=48.$$Chu vi:$$2(2+4+6)=24.$$Khu vực$=24$, tỷ lệ$=1$. 

--- 

## Ví dụ 2 

Tam giác$13,14,15$.$$s=21,$$Vì thế$$x=8,\ y=7,\ z=6.$$Sau đó$$xyz=336,$$và cho$n=2$,$$d=16,$$trong khi$$d(x+y+z)=16\cdot21=336.$$Chu vi:$$2(21)=42.$$Khu vực$=84$, tỷ lệ$=2$. 

Mọi thứ đều được kiểm tra.
