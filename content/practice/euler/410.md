## Giải pháp 

**Trả lời:**`799999783589946560`Hãy để dòng thông qua$P(a,b)$Và$Q(-a,c)$tiếp tuyến với$$x^2+y^2=r^2.$$Chúng tôi muốn đếm tất cả các bộ bốn số nguyên$(r,a,b,c)$với$$0<r\le R,\qquad 0<a\le X.$$Giá trị yêu cầu cuối cùng là$$F(10^8,10^9)+F(10^9,10^8).$$--- 

# 1. Phân tích hình học và lý thuyết số 

Đường đi qua$P(a,b)$Và$Q(-a,c)$có phương trình$$(c-b)x+2ay-a(b+c)=0.$$một dòng$Ax+By+C=0$tiếp tuyến với đường tròn$x^2+y^2=r^2$nếu khoảng cách từ điểm gốc bằng$r$:$$\frac{|C|}{\sqrt{A^2+B^2}}=r.$$Thay thế:$$\frac{|a(b+c)|}{\sqrt{(c-b)^2+4a^2}}=r.$$Bình phương:$$a^2(b+c)^2=r^2\big((c-b)^2+4a^2\big).$$Giới thiệu$$u=b+c,\qquad v=c-b.$$Sau đó:$$a^2u^2=r^2(v^2+4a^2).$$Cho phép$$g=\gcd(a,r),\qquad a=gA,\quad r=gR,\quad \gcd(A,R)=1.$$Sau khi chia cho$g^2$,$$A^2u^2=R^2(v^2+4g^2A^2).$$Bởi vì$\gcd(A,R)=1$, chúng ta phải có$R\mid u$. Viết$$u=Rk.$$Sau đó$$A^2k^2=v^2+4g^2A^2.$$Lại$\gcd(A,R)=1$ngụ ý$A\mid v$. Viết$$v=A\ell.$$Hiện nay:$$k^2-\ell^2=4g^2.$$Nhân tố:$$(k-\ell)(k+\ell)=4g^2.$$Cho phép$$k-\ell=2s,\qquad k+\ell=2t,$$để có thể$$st=g^2.$$Mọi phân tích theo thứ tự$g^2=st$tạo ra một giải pháp. 

Các ràng buộc chẵn lẻ làm giảm số lượng một chút khi$a$Và$r$có các giá trị 2-adic khác nhau. 

Sau khi giải quyết các trường hợp chẵn lẻ, số nghiệm của một cặp cố định$(r,a)$là$$N(r,a)= \begin{cases} 2\,\tau(g^2), & v_2(r)=v_2(a),\\[1ex] 2\,\tau\!\left(\left(\dfrac g2\right)^2\right), & v_2(r)\ne v_2(a),\ g\text{ even},\\[2ex] 2\,\tau(g^2), & g\text{ odd}, \end{cases}$$Ở đâu$g=\gcd(r,a)$,$\tau(n)$là hàm đếm số chia và$v_2$là số mũ của 2. 

Điều này đơn giản hóa thành dạng tóm tắt nhỏ gọn đáng chú ý$$F(R,X) = 2\sum_{n\le \min(R,X)} 2^{\omega(n)} \left\lfloor \frac{R}{n}\right\rfloor \left\lfloor \frac{X}{n}\right\rfloor,$$Ở đâu$\omega(n)$là số các thừa số nguyên tố phân biệt của$n$. 

Hàm số học$$f(n)=2^{\omega(n)}$$có tính nhân lên và dễ sàng lọc. 

--- 

# 2. Thuật toán hiệu quả 

Chúng ta phải tính toán$$\sum_{n\le N} 2^{\omega(n)} \left\lfloor \frac{R}{n}\right\rfloor \left\lfloor \frac{X}{n}\right\rfloor$$vì$N=\min(R,X)$. 

Sử dụng thủ thuật chia tổng-tổng tiêu chuẩn: 

- giá trị của$\lfloor R/n\rfloor$Và$\lfloor X/n\rfloor$không đổi trong các khoảng thời gian, 
- tính toán trước tổng tiền tố của$2^{\omega(n)}$, 
- khoảng thời gian xử lý trong$O(\sqrt N)$. 

--- 

#3. Triển khai Python```python
from math import isqrt

def solve(R, X):
    N = min(R, X)

    # sieve for omega(n)
    omega = [0] * (N + 1)

    for p in range(2, N + 1):
        if omega[p] == 0:          # prime
            for k in range(p, N + 1, p):
                omega[k] += 1

    # f(n) = 2^omega(n)
    f = [1] * (N + 1)
    for n in range(1, N + 1):
        f[n] = 1 << omega[n]

    # prefix sums
    pref = [0] * (N + 1)
    for i in range(1, N + 1):
        pref[i] = pref[i - 1] + f[i]

    ans = 0
    i = 1

    while i <= N:
        vr = R // i
        vx = X // i

        j = min(R // vr, X // vx, N)

        block = pref[j] - pref[i - 1]

        ans += block * vr * vx

        i = j + 1

    return 2 * ans

answer = solve(10**8, 10**9) + solve(10**9, 10**8)

print(answer)
```--- 

# 4. Hướng dẫn viết mã 

### Phần sàng```python
omega = [0] * (N + 1)
```Lưu trữ số lượng các thừa số nguyên tố riêng biệt của mỗi số nguyên. 

Đối với mỗi số nguyên tố$p$, tăng tất cả các bội số:```python
for k in range(p, N + 1, p):
    omega[k] += 1
```Sau đó:```python
f[n] = 1 << omega[n]
```tính toán$$f(n)=2^{\omega(n)}.$$--- 

### Tổng tiền tố```python
pref[i] = pref[i - 1] + f[i]
```cho phép tổng phạm vi nhanh của$f(n)$. 

--- 

### Phương pháp hyperbol 

Các giá trị$$\left\lfloor \frac{R}{n}\right\rfloor, \qquad \left\lfloor \frac{X}{n}\right\rfloor$$duy trì không đổi trong khoảng thời gian dài. 

Vì vậy, thay vì lặp đi lặp lại mỗi$n$, chúng tôi xử lý các khối:```python
j = min(R // vr, X // vx, N)
```và thêm sự đóng góp của toàn bộ khối cùng một lúc.

# 5. Xác minh trên các ví dụ đã cho 

Chương trình tái hiện:$$F(1,5)=10,$$

$$F(2,10)=52,$$

$$F(10,100)=3384.$$phù hợp chính xác với tuyên bố. 

Kết quả cuối cùng có kích thước khoảng$$O(RX\log N),$$vì vậy một giá trị xung quanh$10^{17}$–$10^{18}$là hoàn toàn hợp lý.
