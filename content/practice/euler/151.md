[Dự án Euler Vấn đề 151](https://projecteuler.net/problem=151) 

## Giải pháp 

**Trả lời:**`0.464399`Đặt trạng thái của phong bì là$$(a_2,a_3,a_4,a_5)$$Ở đâu$a_k$là số lượng tờ giấy có kích thước$A_k$hiện ở trong phong bì. 

Sau đợt đầu tiên (sáng thứ Hai), đợt đầu tiên$A1$tờ đã được cắt xuống nhiều lần để có được một$A5$tờ để in. Những tờ giấy chưa sử dụng được trả lại vào phong bì là:$$\{A2,A3,A4\}$$vậy trạng thái ban đầu là$$(1,1,1,0).$$Chúng ta phải tính toán số lần dự kiến, ngoại trừ đợt đầu tiên và đợt cuối cùng, để phong bì chứa đúng một tờ trước khi đợt bắt đầu. 

--- 

# 1. Chuyển đổi trạng thái 

Giả sử trạng thái hiện tại là$$(a_2,a_3,a_4,a_5).$$Tổng số tờ là$$N=a_2+a_3+a_4+a_5.$$Một tờ được chọn ngẫu nhiên thống nhất. 

--- 

## Nếu một$A5$được chọn 

Xác suất:$$\frac{a_5}{N}.$$Nó được sử dụng đơn giản, vì vậy:$$(a_2,a_3,a_4,a_5)\to(a_2,a_3,a_4,a_5-1).$$--- 

## Nếu một$A4$được chọn 

Xác suất:$$\frac{a_4}{N}.$$MỘT$A4$được cắt thành hai$A5$tờ; một$A5$được sử dụng, cái còn lại được trả lại. 

Hiệu ứng ròng: 

- loại bỏ một$A4$- thêm một$A5$Vì thế:$$(a_2,a_3,a_4,a_5)\to(a_2,a_3,a_4-1,a_5+1).$$--- 

## Nếu một$A3$được chọn 

Xác suất:$$\frac{a_3}{N}.$$Quá trình cắt:$$A3 \to 2A4,\quad A4 \to 2A5,$$một$A5$được sử dụng. 

Các tờ được trả lại: 

- một$A4$- một$A5$Như vậy:$$(a_2,a_3,a_4,a_5)\to(a_2,a_3-1,a_4+1,a_5+1).$$--- 

## Nếu một$A2$được chọn 

Xác suất:$$\frac{a_2}{N}.$$Tương tự: 

Các tờ được trả lại: 

- một$A3$- một$A4$- một$A5$Như vậy:$$(a_2,a_3,a_4,a_5)\to(a_2-1,a_3+1,a_4+1,a_5+1).$$--- 

# 2. Những tiểu bang nào được tính? 

Chúng tôi đếm những buổi sáng mà phong bì chỉ chứa đúng một tờ giấy. 

Các trạng thái trang đơn có thể có là:$$(1,0,0,0),\quad (0,1,0,0),\quad (0,0,1,0),\quad (0,0,0,1).$$Tuy nhiên: 

- lô đầu tiên bị loại trừ, 
- lô cuối cùng được loại trừ. 

Trạng thái cuối cùng$(0,0,0,1)$tương ứng với lô cuối cùng nên nó phải **không** được tính. 

Do đó, các trạng thái đơn lẻ duy nhất được tính là:$$(1,0,0,0),\quad (0,1,0,0),\quad (0,0,1,0).$$Do đó, giá trị kỳ vọng là$$E = P(1,0,0,0) + P(0,1,0,0) + P(0,0,1,0),$$trong đó các xác suất này là xác suất đạt được các trạng thái đó trước khi một đợt bắt đầu.

#3. Tính toán xác suất chính xác 

Chúng tôi tuyên truyền xác suất thông qua tất cả các trạng thái có thể tiếp cận. 

Trạng thái bắt đầu:$$(1,1,1,0)$$với xác suất$1$. 

Vì tổng số tờ giấy mỗi đợt giảm đi đúng một tờ nên quá trình này hữu hạn và đủ nhỏ để tính toán hợp lý chính xác. 

--- 

#4. Triển khai Python```python
from fractions import Fraction
from collections import defaultdict

# ------------------------------------------------------------
# Transition function
# ------------------------------------------------------------

def transitions(state):
    a2, a3, a4, a5 = state
    total = a2 + a3 + a4 + a5

    result = []

    # choose A2
    if a2:
        p = Fraction(a2, total)
        nxt = (a2 - 1, a3 + 1, a4 + 1, a5 + 1)
        result.append((p, nxt))

    # choose A3
    if a3:
        p = Fraction(a3, total)
        nxt = (a2, a3 - 1, a4 + 1, a5 + 1)
        result.append((p, nxt))

    # choose A4
    if a4:
        p = Fraction(a4, total)
        nxt = (a2, a3, a4 - 1, a5 + 1)
        result.append((p, nxt))

    # choose A5
    if a5:
        p = Fraction(a5, total)
        nxt = (a2, a3, a4, a5 - 1)
        result.append((p, nxt))

    return result

# ------------------------------------------------------------
# Dynamic probability propagation
# ------------------------------------------------------------

start = (1, 1, 1, 0)

dist = defaultdict(Fraction)
dist[start] = Fraction(1, 1)

expected = Fraction(0, 1)

while dist:
    new_dist = defaultdict(Fraction)

    for state, prob in dist.items():

        total_sheets = sum(state)

        # Count singleton states excluding final A5 state
        if total_sheets == 1 and state != (0, 0, 0, 1):
            expected += prob

        # Continue transitions unless terminal
        if state == (0, 0, 0, 0):
            continue

        for p, nxt in transitions(state):
            new_dist[nxt] += prob * p

    dist = new_dist

# ------------------------------------------------------------
# Output
# ------------------------------------------------------------

value = float(expected)

print(expected)
print(f"{value:.6f}")
```--- 

#5. Hướng dẫn code 

## Trình tạo chuyển tiếp 

Chức năng:```python
transitions(state)
```liệt kê mọi lựa chọn trang ngẫu nhiên có thể và trả về:```python
(probability, next_state)
```cặp. 

Ví dụ:```python
(a2,a3,a4,a5)
```chọn một$A3$mang lại:```python
(a2, a3-1, a4+1, a5+1)
```bởi vì cắt một$A3$tạo ra một phần còn lại$A4$và một cái còn sót lại$A5$. 

--- 

## Lan truyền xác suất 

Chúng tôi duy trì phân phối xác suất trên tất cả các trạng thái có thể truy cập:```python
dist[state] = probability
```Ở mỗi bước chúng tôi: 

1. thêm xác suất trạng thái đơn vào kỳ vọng, 
2. truyền khối lượng xác suất tới các trạng thái kế tiếp. 

Bởi vì mỗi đợt loại bỏ chính xác một$A5$, quá trình này kết thúc một cách tự nhiên.
