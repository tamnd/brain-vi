## Giải pháp 

**Trả lời:**`3857447`Cho mỗi tụ điện có điện dung$C$. 

Vì mọi điện dung thu được đều là bội số hữu tỉ của$C$, chúng tôi chuẩn hóa bằng cách thiết lập$C=1$. 

Do đó, mọi điện dung có thể đạt được là một số hữu tỉ chính xác. 

Chúng tôi xác định:$$S_n = \{\text{all capacitances achievable using exactly } n \text{ capacitors}\}$$Và$$D(n)=\left|\bigcup_{k=1}^n S_k\right|$$Vấn đề yêu cầu$D(18)$. 

--- 

# Phân tích toán học 

Nếu hai mạch con có điện dung$x$Và$y$, thì: 

## Kết nối song song 

Điện dung thêm trực tiếp:$$C_{\text{parallel}} = x+y$$## Kết nối hàng loạt$$\frac1{C_{\text{series}}}=\frac1x+\frac1y$$Vì thế$$C_{\text{series}}=\frac{xy}{x+y}$$Vì vậy mỗi mạch được xây dựng từ$n$tụ điện có thể được hình thành bằng cách chia các tụ điện thành hai nhóm kích thước khác nhau$k$Và$n-k$, xây dựng một mạch con từ mỗi nhóm và kết hợp chúng nối tiếp hoặc song song. 

Vì thế:$$S_n = \bigcup_{k=1}^{n-1} \left\{ x+y,\ \frac{xy}{x+y} \;\middle|\; x\in S_k,\ y\in S_{n-k} \right\}$$Trường hợp cơ sở:$$S_1=\{1\}$$Bởi vì tất cả các giá trị đều là số hữu tỉ nên chúng ta biểu diễn chúng một cách chính xác bằng cách sử dụng phân số rút gọn. 

--- 

# Chiến lược lập trình động 

Chúng tôi tính toán$S_1,S_2,\dots,S_{18}$. 

Đối với mỗi$n$: 

- lặp lại tất cả các phần tách$k$Và$n-k$, 
- kết hợp từng cặp$x\in S_k$,$y\in S_{n-k}$,
- chèn:

-$x+y$-$\dfrac{xy}{x+y}$thành một bộ (để tự động loại bỏ trùng lặp). 

Một tối ưu hóa hữu ích: 

Bởi vì kết hợp$S_k$với$S_{n-k}$đối xứng nên ta chỉ cần:$$k \le \frac n2$$Điều này cắt giảm công việc khoảng một nửa. 

--- 

#Triển khai Python```python
from math import gcd

N = 18

# S[n] = set of capacitances using exactly n capacitors
# Each capacitance stored as a reduced fraction (num, den)
S = [set() for _ in range(N + 1)]

# Base case: one capacitor => capacitance 1
S[1] = {(1, 1)}

# Global set of all distinct capacitances
all_values = {(1, 1)}

for n in range(2, N + 1):

    current = set()

    # Only need k <= n//2 because of symmetry
    for k in range(1, n // 2 + 1):

        other = n - k

        for a, b in S[k]:
            for c, d in S[other]:

                # -------------------------
                # Parallel:
                # a/b + c/d
                # -------------------------
                num = a * d + b * c
                den = b * d

                g = gcd(num, den)
                current.add((num // g, den // g))

                # -------------------------
                # Series:
                # (a/b * c/d) / (a/b + c/d)
                # = ac / (ad + bc)
                # -------------------------
                num = a * c
                den = a * d + b * c

                g = gcd(num, den)
                current.add((num // g, den // g))

    S[n] = current
    all_values |= current

print(len(all_values))
```---
