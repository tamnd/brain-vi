## Giải pháp 

**Trả lời:**`328968937309`Hãy hiểu các hình khối là **hộp nửa mở**$$[x_0,x_0+dx)\times [y_0,y_0+dy)\times [z_0,z_0+dz)$$có cùng âm lượng với phiên bản đóng trong câu lệnh, nhưng tránh được sự mơ hồ về ranh giới chồng chéo. 

Nhiệm vụ là tính khối lượng của sự kết hợp của$50{,}000$hình hộp chữ nhật thẳng hàng với trục.

# Phân tích toán học 

Cách tiếp cận bao gồm-loại trừ trực tiếp là không thể: có quá nhiều hình khối. 

Cách tiêu chuẩn để tính toán khối lượng hợp của các hộp thẳng hàng theo trục là **thuật toán đường quét**. 

--- 

## 1. Quét vào$x$-hướng 

Mỗi hình khối đóng góp: 

- một **sự kiện tham gia** tại$x=x_0$- một **sự kiện rời khỏi** tại$x=x_0+dx$Giữa hai lần liên tiếp$x$-tọa độ, tập hợp các hình khối hoạt động không thay đổi. 

Vì vậy, nếu diện tích hợp của các hình chữ nhật hoạt động trong$yz$-máy bay là$A(x)$, sau đó$$V = \sum (\Delta x)\cdot A(x)$$Trong bài toán này mọi tọa độ đều là số nguyên và$$0 \le x < 10400$$bởi vì:

-$x_0 < 10000$-$dx \le 399$Vì vậy chúng ta chỉ cần xử lý$10400$tấm số nguyên. 

--- 

## 2. Khu vực liên kết máy tính trong$yz$-máy bay 

Đối với các hình khối hiện đang hoạt động, hãy chiếu chúng lên$yz$-máy bay. 

Mỗi cái trở thành một hình chữ nhật$$[y_1,y_2)\times[z_1,z_2)$$Chúng tôi lại sử dụng đường quét: 

- quét vào$y$- duy trì chiều dài được bao phủ trong$z$Đối với mỗi hình chữ nhật: 

- thêm sự kiện$(y_1, z_1,z_2,+1)$- thêm sự kiện$(y_2, z_1,z_2,-1)$Một cây phân đoạn trên$z$-trục cửa hàng: 

- số lượng bảo hiểm 
- tổng chiều dài được bao phủ 

Nếu số lượng nút là dương thì toàn bộ khoảng thời gian của nút đó sẽ được bao phủ. 

Do đó diện tích hợp được tích lũy là:$$\text{area} += (y_i-y_{i-1}) \times (\text{covered z-length})$$--- 

#Triển khai Python```python
from collections import defaultdict

# ------------------------------------------------------------
# Lagged Fibonacci Generator
# ------------------------------------------------------------

S = [0] * 300001

for k in range(1, 56):
    S[k] = (100003 - 200003 * k + 300007 * k * k * k) % 1000000

for k in range(56, 300001):
    S[k] = (S[k - 24] + S[k - 55]) % 1000000

# ------------------------------------------------------------
# Build cuboids and x-events
# ------------------------------------------------------------

ADD = defaultdict(list)
REMOVE = defaultdict(list)

for n in range(1, 50001):

    x0 = S[6 * n - 5] % 10000
    y0 = S[6 * n - 4] % 10000
    z0 = S[6 * n - 3] % 10000

    dx = 1 + (S[6 * n - 2] % 399)
    dy = 1 + (S[6 * n - 1] % 399)
    dz = 1 + (S[6 * n] % 399)

    cuboid = (y0, y0 + dy, z0, z0 + dz)

    ADD[x0].append(cuboid)
    REMOVE[x0 + dx].append(cuboid)

# ------------------------------------------------------------
# Segment tree for union length on z-axis
# ------------------------------------------------------------

ZMAX = 10400

class SegmentTree:

    def __init__(self, n):
        self.n = n
        self.count = [0] * (4 * n)
        self.length = [0] * (4 * n)

    def update(self, node, left, right, ql, qr, val):

        if qr <= left or right <= ql:
            return

        if ql <= left and right <= qr:
            self.count[node] += val
        else:
            mid = (left + right) // 2

            self.update(node * 2, left, mid, ql, qr, val)
            self.update(node * 2 + 1, mid, right, ql, qr, val)

        if self.count[node] > 0:
            self.length[node] = right - left
        else:
            if right - left == 1:
                self.length[node] = 0
            else:
                self.length[node] = (
                    self.length[node * 2]
                    + self.length[node * 2 + 1]
                )

# ------------------------------------------------------------
# Main sweep in x
# ------------------------------------------------------------

active = []
volume = 0

for x in range(10400):

    # add cuboids starting here
    active.extend(ADD[x])

    # remove cuboids ending here
    for r in REMOVE[x]:
        active.remove(r)

    # build y-events
    events = []

    for y1, y2, z1, z2 in active:
        events.append((y1, z1, z2, +1))
        events.append((y2, z1, z2, -1))

    events.sort()

    # sweep in y
    seg = SegmentTree(ZMAX)

    area = 0
    prev_y = 0
    i = 0

    while i < len(events):

        y = events[i][0]

        area += (y - prev_y) * seg.length[1]

        while i < len(events) and events[i][0] == y:
            _, z1, z2, typ = events[i]
            seg.update(1, 0, ZMAX, z1, z2, typ)
            i += 1

        prev_y = y

    volume += area

print(volume)

# Hướng dẫn sử dụng mã 

## Tạo hình khối 

Trình tạo Fibonacci trễ tạo ra$300000$những con số. 

Cứ sáu số xác định một hình khối:$$(x_0,y_0,z_0,dx,dy,dz)$$phù hợp chính xác với tuyên bố. 

--- 

##Thi công sự kiện 

Đối với mỗi hình lập phương: 

- thêm nó vào$x_0$- loại bỏ nó tại$x_0+dx$Điều này cho phép chúng ta duy trì tập hoạt động trong khi quét$x$. 

--- 

## Cây phân đoạn 

Cây phân đoạn duy trì độ dài hợp trên$z$-trục. 

Mỗi nút lưu trữ: 

-`count[node]`= có bao nhiêu khoảng bao phủ hoàn toàn nút đó 
-`length[node]`= tổng chiều dài được bao phủ 

Nếu số lượng bảo hiểm là dương thì khoảng thời gian đó được bao phủ hoàn toàn. 

Nếu không, bảo hiểm đến từ trẻ em. 

--- 

## Quét bên trong$y$Đối với hình chữ nhật hoạt động: 

- tham gia sự kiện tại$y_1$- rời khỏi sự kiện lúc$y_2$Giữa liên tiếp$y$-giá trị, được bảo hiểm$z$-độ dài không đổi. 

Vì thế:$$\Delta \text{area} = (\Delta y)\times(\text{covered z length})$$---
