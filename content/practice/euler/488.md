[Vấn đề dự án Euler 488](https://projecteuler.net/problem=488) 

## Giải pháp 

**Trả lời:**`216737278`Cho phép$$(a,b,c),\qquad 0<a<b<c$$là một vị trí của trò chơi Nim đã được sửa đổi, trong đó các động tác tạo ra hai đống bằng nhau đều bị cấm. 

Chúng ta phải tính toán$$F(N)=\sum (a+b+c)$$trên tất cả các vị trí thua (vị trí P) với$0<a<b<c<N$, và cuối cùng xuất ra cái cuối cùng$9$chữ số của$F(10^{18})$. 

--- 

# Phân tích toán học 

## 1. Đặc điểm các vị thế thua 

Nhận xét quan trọng là trò chơi trở thành Nim bình thường sau một sự thay đổi đơn giản. 

Định nghĩa$$x=a+1,\qquad y=b+1,\qquad z=c+1.$$Khi đó, quy tắc “bạn không được phép tạo hai đống bằng nhau” chuyển thành thực tế là các vị trí cuối cùng chính xác là những vị trí có một tọa độ bằng nhau$1$và những cái khác bằng$2,3$ở dạng đã dịch chuyển. 

Thử nghiệm với các trạng thái nhỏ (và chứng minh bằng phương pháp quy nạp sử dụng phép truy toán Sprague–Grundy) đưa ra tiêu chí chính xác:$$(a,b,c)\text{ is losing} \iff (a+1)\oplus(b+1)\oplus(c+1)=0,$$Ở đâu$\oplus$biểu thị XOR theo bit. 

Vì vậy nếu chúng ta thiết lập$$x=a+1,\ y=b+1,\ z=c+1,$$thì vị trí thua chính xác là bộ ba dương khác nhau thỏa mãn$$x\oplus y\oplus z=0.$$Bởi vì$z=x\oplus y$, một lần$x,y$được chọn,$z$được xác định. 

--- 

## 2. Chuyển đổi tổng 

Chúng tôi cần$$0<a<b<c<N.$$Sau khi dịch chuyển:$$2\le x<y<z\le N.$$Số lượng được tính tổng là$$a+b+c=(x-1)+(y-1)+(z-1)=x+y+z-3.$$Vì vậy nhiệm vụ giảm xuống còn tổng hợp$x+y+z-3$trên tất cả các bộ ba phân biệt không có thứ tự với$$x\oplus y\oplus z=0.$$--- 

## 3. Bộ ba có thứ tự thay vì bộ ba không có thứ tự 

Việc đếm các bộ ba theo thứ tự sẽ dễ dàng hơn. 

Đối với bộ ba XOR-zero, đẳng thức không thể xảy ra trừ khi cả ba đều bằng nhau và trong phạm vi của chúng tôi ($\ge2$) điều đó là không thể. Do đó mọi bộ ba không có thứ tự đều tương ứng chính xác$6$đặt hàng gấp ba lần. 

Vì thế:$$F(N) = \frac{ \sum_{\text{ordered}} (x+y+z)-3\cdot(\#\text{ordered}) }{6}.$$--- 

## 4. Chữ số DP trên bit nhị phân 

Chúng ta cần đếm các bộ ba theo thứ tự thỏa mãn$$x\oplus y=z,$$với giới hạn trên. 

Đây là một chữ số nhị phân tiêu chuẩn-DP: 

- xử lý các bit từ quan trọng nhất đến ít quan trọng nhất, 
- duy trì cờ “chặt chẽ” để biết liệu chúng tôi có còn bằng giới hạn trên hay không, 
- tại mỗi bit chọn các bit của$x$Và$y$, 
- một chút$z$bị buộc phải:$$z_i=x_i\oplus y_i.$$DP đồng thời tích lũy: 

- số bộ ba hợp lệ, 
- tổng số tiền của tất cả$x$, 
- tổng số tiền của tất cả$y$, 
- tổng số tiền của tất cả$z$. 

Cuối cùng chúng tôi áp dụng bao gồm-loại trừ để thực thi$$x,y,z\ge2.$$Sự phức tạp chỉ có$O(\log N)$.

#Triển khai Python```python
MOD = 10**9

def dp_count_sum(A: int, B: int, C: int):
    """
    Count triples (x,y,z) such that:
        0 <= x <= A
        0 <= y <= B
        z = x XOR y
        0 <= z <= C

    Returns:
        (count, total_sum_xyz)
    """

    if A < 0 or B < 0 or C < 0:
        return 0, 0

    bits = max(A, B, C).bit_length()
    if bits == 0:
        bits = 1

    # state = (tightA, tightB, tightC)
    count = [0] * 8
    sx = [0] * 8
    sy = [0] * 8
    sz = [0] * 8

    count[7] = 1  # initially all tight

    for p in range(bits - 1, -1, -1):

        bitA = (A >> p) & 1
        bitB = (B >> p) & 1
        bitC = (C >> p) & 1

        value = 1 << p

        ncount = [0] * 8
        nsx = [0] * 8
        nsy = [0] * 8
        nsz = [0] * 8

        for state in range(8):

            cnt = count[state]
            if cnt == 0:
                continue

            tightA = (state >> 2) & 1
            tightB = (state >> 1) & 1
            tightC = state & 1

            for xb in (0, 1):

                if tightA and xb > bitA:
                    continue

                ntA = 1 if (tightA and xb == bitA) else 0

                for yb in (0, 1):

                    if tightB and yb > bitB:
                        continue

                    ntB = 1 if (tightB and yb == bitB) else 0

                    zb = xb ^ yb

                    if tightC and zb > bitC:
                        continue

                    ntC = 1 if (tightC and zb == bitC) else 0

                    ns = (ntA << 2) | (ntB << 1) | ntC

                    ncount[ns] += cnt

                    nsx[ns] += sx[state] + cnt * xb * value
                    nsy[ns] += sy[state] + cnt * yb * value
                    nsz[ns] += sz[state] + cnt * zb * value

        count = ncount
        sx = nsx
        sy = nsy
        sz = nsz

    total_count = sum(count)
    total_sum = sum(sx) + sum(sy) + sum(sz)

    return total_count, total_sum

def F(N: int) -> int:
    """
    Sum of a+b+c over all losing positions:
        0 < a < b < c < N
    """

    L = N

    ordered_count = 0
    ordered_sum = 0

    # Inclusion-exclusion to enforce x,y,z >= 2
    for mask in range(8):

        A = 1 if (mask & 1) else L
        B = 1 if (mask & 2) else L
        C = 1 if (mask & 4) else L

        cnt, sm = dp_count_sum(A, B, C)

        if mask.bit_count() % 2 == 0:
            ordered_count += cnt
            ordered_sum += sm
        else:
            ordered_count -= cnt
            ordered_sum -= sm

    # Convert back from x,y,z to a,b,c:
    # a+b+c = x+y+z - 3

    return (ordered_sum - 3 * ordered_count) // 6

# Verification
assert F(8) == 42
assert F(128) == 496062

answer = F(10**18) % MOD
print(answer)

# Hướng dẫn sử dụng mã 

###`dp_count_sum(A,B,C)`Điều này thực hiện DP chữ số theo bit. 

Tại mỗi bit: 

- chọn một chút cho$x$, 
- chọn một chút cho$y$, 
- tính toán một chút$z$dưới dạng XOR, 
- duy trì điều kiện độ kín. 

Các cửa hàng DP: 

- có bao nhiêu bộ ba tồn tại, 
- số tiền tích lũy của$x$,$y$, Và$z$. 

--- 

### Bao gồm-loại trừ 

Đầu tiên chúng ta đếm bộ ba với tọa độ được phép$0$hoặc$1$, sau đó loại bỏ những người vi phạm$x,y,z\ge2$. 

Điều này được thực hiện bởi 8 mặt nạ:$$\{x\le1\},\{y\le1\},\{z\le1\}.$$--- 

### Chia cho 6 

Chúng tôi đếm bộ ba theo thứ tự. 

Mỗi bộ ba không có thứ tự xuất hiện chính xác$6$lần vì tọa độ khác nhau. 

Vì vậy chúng tôi chia cho$6$.
