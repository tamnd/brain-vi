[Vấn đề dự án Euler 832](https://projecteuler.net/problem=832) 

##Giải pháp 

**Trả lời:**`552839586`Để các vòng bên trong một khối được lập chỉ mục từ$0$. 

Định nghĩa$$T_k=\frac{4^k-1}{3}.$$Sau đó$T_k$làm tròn, tờ giấy chứa chính xác các số nguyên$$1,2,\dots,4^k-1.$$Điều này có thể nhìn thấy từ các ví dụ: 

-$T_1=1$: con số$1..3$, 
-$T_2=5$: con số$1..15$, 
-$T_3=21$: con số$1..63$. 

Do đó quá trình tiến hành theo khối có kích thước$4^k$. 

Đối với khối bắt đầu tại$4^k$, viết chỉ số tròn là$r\in[0,4^k)$, trong căn cứ$4$:$$r = \sum d_i 4^i.$$Việc xây dựng đệ quy tạo ra ánh xạ chữ số$$0\mapsto(0,0),\quad 1\mapsto(2,3),\quad 2\mapsto(3,1),\quad 3\mapsto(1,2).$$Nếu như$x_r,y_r$là phần thấp của tương ứng$b,c$, sau đó$$x_r+y_r = \sum t(d_i)4^i,$$Ở đâu$$t(0)=0,\quad t(1)=5,\quad t(2)=4,\quad t(3)=3.$$Vì thế$$r + (x_r+y_r) = 6\sum_{d_i\neq 0}4^i.$$Vì vậy sự đóng góp của vòng$r$trong khối$k$là$$6\cdot 4^k + 6\sum_{d_i\neq 0}4^i.$$Định nghĩa$$\operatorname{supp}(r)=\sum_{d_i\neq 0}4^i.$$Sau đó cho$n=T_k+m$với$0\le m<4^k$,$$M(n) = \frac{4^k(4^k-1)}2 + 6m4^k + 6\sum_{r=0}^{m-1}\operatorname{supp}(r).$$Số tiền còn lại được tính toán đệ quy. 

Việc triển khai Python được sử dụng:```python
MOD = 10**9 + 7

from functools import lru_cache

@lru_cache(None)
def fullS(k):
    # Sum of supp(r) for 0 <= r < 4^k
    if k == 0:
        return 0
    p = 4 ** (k - 1)
    return 4 * fullS(k - 1) + 3 * p * p

def S(k, m):
    # Sum of supp(r) for 0 <= r < m, with r < 4^k
    if k == 0 or m == 0:
        return 0

    p = 4 ** (k - 1)
    a, b = divmod(m, p)

    return (
        a * fullS(k - 1)
        + max(0, a - 1) * p * p
        + (p * b if a else 0)
        + S(k - 1, b)
    )

def M(n):
    k = 0
    while (4 ** (k + 1) - 1) // 3 <= n:
        k += 1

    T = (4 ** k - 1) // 3
    m = n - T

    base = 4 ** k * (4 ** k - 1) // 2

    return base + 6 * m * 4 ** k + 6 * S(k, m)

ans = M(10**18) % MOD
print(ans)
```Kiểm tra: 

-$M(10)=642$-$M(1000)=5432148$cả hai đều phù hợp với tuyên bố.
