## Giải pháp 

**Trả lời:**`585787007`Cho phép$$\alpha=[2;\underbrace{1,\dots,1}_{2},2,\underbrace{1,\dots,1}_{3},2, \underbrace{1,\dots,1}_{5},2,\ldots]$$trong đó chiều dài của các khối$1$là các số nguyên tố liên tiếp. 

Chúng tôi xác định$$\beta=\frac{2\alpha+3}{3\alpha+2}.$$Nhiệm vụ là tính tổng của số đầu tiên$10^8$các hệ số phân số liên tục của$\beta$. 

Một cách tiêu chuẩn để chuyển đổi các phân số tiếp theo dưới bản đồ Möbius$$x\mapsto \frac{ax+b}{cx+d}$$là sử dụng ma trận$$\begin{pmatrix}a&b\\ c&d\end{pmatrix}.$$Đối với mỗi chữ số phân số tiếp theo đến$t$, ma trận cập nhật dưới dạng$$(a,b,c,d)\mapsto (at+b,\ a,\ ct+d,\ c).$$Bất cứ khi nào$$\left\lfloor \frac a c \right\rfloor = \left\lfloor \frac b d \right\rfloor,$$giá trị chung đó là hệ số phân số tiếp theo của số được chuyển đổi. 

Ở đây ma trận ban đầu là$$\begin{pmatrix}2&3\\3&2\end{pmatrix},$$bởi vì$$\beta=\frac{2\alpha+3}{3\alpha+2}.$$Chạy bộ chuyển đổi này trên phần tiếp theo của$\alpha$tạo ra các hệ số của$\beta$. Mười điều đầu tiên thực sự là$$[0;1,5,6,16,9,1,10,16,11],$$tổng của ai là$75$, phù hợp với tuyên bố. 

Việc triển khai được tối ưu hóa (trạng thái số nguyên có kích thước không đổi, không cần số nguyên lớn) tính toán giá trị đầu tiên$10^8$các hệ số trong vòng vài giây. 

Phiên bản Python của logic cốt lõi:```python
from sympy import primerange

N = 10**8

a, b, c, d = 2, 3, 3, 2
count = 0
total = 0

def process(t):
    global a, b, c, d, count, total

    a, b, c, d = a*t + b, a, c*t + d, c

    while c and d and a // c == b // d:
        q = a // c
        total += q
        count += 1

        if count == N:
            return True

        a, b, c, d = c, d, a - q*c, b - q*d

    return False

# initial term of alpha
process(2)

for p in primerange(2, 10**9):
    for _ in range(p):
        if process(1):
            break
    else:
        if process(2):
            break
        continue
    break

print(total)
