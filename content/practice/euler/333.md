[Vấn đề dự án Euler 333](https://projecteuler.net/problem=333) 

## Giải pháp 

**Trả lời:**`3053105`Hãy để một số hạng được biểu diễn bằng cặp số mũ của nó$$(i,j)\quad\leftrightarrow\quad 2^i3^j.$$Một phân vùng hợp lệ nếu không có thuật ngữ nào chia cho thuật ngữ khác. 

Đối với hai điều khoản$$2^a3^b,\qquad 2^c3^d,$$chúng tôi có$$2^a3^b \mid 2^c3^d \iff a\le c \text{ and } b\le d.$$Do đó, một phân vùng hợp lệ tương ứng chính xác với một tập hợp các cặp số mũ trong đó không có cặp nào có tọa độ$\le$khác. 

Tương đương: 

- nếu$i$-số mũ tăng, 
- sau đó$j$- số mũ phải giảm nghiêm ngặt. 

Vì vậy, mọi phân vùng hợp lệ đều có thể được viết dưới dạng một chuỗi$$(i_1,j_1),(i_2,j_2),\dots,(i_k,j_k)$$với$$i_1<i_2<\cdots<i_k,\qquad j_1>j_2>\cdots>j_k.$$Điều này chuyển đổi vấn đề thành một tìm kiếm tổ hợp có cấu trúc. 

--- 

# 1. Phân tích toán học 

Chúng tôi cần:$$\sum_{\substack{q<10^6\\ q\text{ prime}\\ P(q)=1}} q.$$--- 

## Giới hạn số mũ 

Kể từ khi$2^i3^j<10^6$, 

-$i\le 19$bởi vì$2^{20}>10^6$, 
-$j\le 12$bởi vì$3^{13}>10^6$. 

Vì vậy có rất ít thuật ngữ cơ bản có thể có. 

--- 

## Ý tưởng lập trình động 

Xử lý quyền hạn của$3$từ lớn$j$xuống còn nhỏ$j$. 

Tại mỗi$j$, chúng tôi có thể: 

- bỏ qua chuyện đó$j$hoặc 
- chọn chính xác một$i$lớn hơn mọi lựa chọn trước đó$i$. 

Điều này tự động thực thi:$$i_1<i_2<\cdots,\qquad j_1>j_2>\cdots,$$do đó tính hợp lệ. 

Chúng tôi duy trì trạng thái:$$(\text{largest chosen } i,\ \text{sum})$$và đếm xem mỗi tổng có thể xảy ra bao nhiêu cách. 

Cuối cùng: 

- tính toán$P(n)$, 
- sàng số nguyên tố, 
- tính tổng tất cả các số nguyên tố với$P(q)=1$.

#2. Triển khai Python```python
from collections import defaultdict

LIMIT = 10**6

# ------------------------------------------------------------
# Generate powers of 2 and 3
# ------------------------------------------------------------

pow2 = [1]
while pow2[-1] * 2 < LIMIT:
    pow2.append(pow2[-1] * 2)

pow3 = [1]
while pow3[-1] * 3 < LIMIT:
    pow3.append(pow3[-1] * 3)

I = len(pow2)
J = len(pow3)

# ------------------------------------------------------------
# DP states:
#
# states[k] is a dictionary:
#   sum -> number of valid partitions
#
# where the largest chosen i-exponent equals (k-1).
#
# k = 0 represents "no exponent chosen yet", i.e. last_i = -1.
# ------------------------------------------------------------

states = [defaultdict(int) for _ in range(I + 1)]
states[0][0] = 1

# Process j from large to small
for j in range(J - 1, -1, -1):

    new_states = [defaultdict(int) for _ in range(I + 1)]

    for idx, d in enumerate(states):

        last_i = idx - 1

        for current_sum, ways in d.items():

            # Option 1: skip this j
            new_states[idx][current_sum] += ways

            # Option 2: choose an i > last_i
            for new_i in range(last_i + 1, I):

                value = pow2[new_i] * pow3[j]
                new_sum = current_sum + value

                if new_sum < LIMIT:
                    new_states[new_i + 1][new_sum] += ways

    states = new_states

# ------------------------------------------------------------
# Collect P(n)
# ------------------------------------------------------------

P = [0] * LIMIT

for d in states:
    for s, cnt in d.items():
        P[s] += cnt

# Remove empty partition
P[0] -= 1

# ------------------------------------------------------------
# Prime sieve
# ------------------------------------------------------------

is_prime = bytearray(b"\x01") * LIMIT
is_prime[0:2] = b"\x00\x00"

for p in range(2, int(LIMIT**0.5) + 1):
    if is_prime[p]:
        is_prime[p*p:LIMIT:p] = b"\x00" * (
            ((LIMIT - 1 - p*p) // p) + 1
        )

# ------------------------------------------------------------
# Compute answer
# ------------------------------------------------------------

answer = sum(
    n for n in range(LIMIT)
    if is_prime[n] and P[n] == 1
)

print(answer)
```--- 

# 3. Hướng dẫn viết mã 

## Tạo ra sức mạnh```python
pow2 = [1]
while pow2[-1] * 2 < LIMIT:
    pow2.append(pow2[-1] * 2)
```Tạo ra mọi quyền lực$2^i<10^6$. 

Tương tự đối với quyền hạn của$3$. 

--- 

## Cấu trúc DP```python
states[k][s]
```có nghĩa là: 

- chúng ta đã hình thành tổng$s$, 
- số mũ được sử dụng lớn nhất$i$bằng$k-1$. 

Xử lý$j$theo thứ tự giảm dần đảm bảo lựa chọn trong tương lai$j$của nhỏ hơn. 

Chỉ lựa chọn$i > \text{last}_i$đảm bảo ngày càng tăng$i$'S. 

Do đó không thể xảy ra sự phân chia. 

--- 

## Chuyển tiếp```python
# skip this j
new_states[idx][current_sum] += ways
```hoặc```python
value = pow2[new_i] * pow3[j]
new_sum = current_sum + value
```để bao gồm một thuật ngữ. 

---

## Xây dựng$P(n)$Rốt cuộc$j$được xử lý:```python
P[s] += cnt
```đếm số lượng phân vùng hợp lệ của$s$.
