[Vấn đề dự án Euler 342](https://projecteuler.net/problem=342) 

##Giải pháp 

**Trả lời:**`5943040885644`Cho phép$$n=\prod_{p} p^{a_p}.$$Chúng tôi muốn tất cả$1<n<10^{10}$như vậy$\phi(n^2)$là một khối lập phương hoàn hảo. 

Điều quan trọng là phải hiểu số mũ nguyên tố trong$\phi(n^2)$. 

--- 

# 1. Phân tích toán học 

Chúng tôi sử dụng$$\phi(p^k)=p^{k-1}(p-1),$$Vì thế$$\phi(n^2) =\prod_p \phi\!\left(p^{2a_p}\right) =\prod_p p^{2a_p-1}(p-1).$$Tương đương,$$\phi(n^2)=n\phi(n).$$Điều kiện là: 

> mọi số mũ nguyên tố trong$\phi(n^2)$phải chia hết cho$3$. 

--- 

## Phương trình số mũ nguyên tố 

hãy để$$R=\operatorname{rad}(n)=\prod_{p\mid n} p$$(hạt nhân bình phương của$n$). 

Định nghĩa$$d_q = v_q(\phi(R))      = v_q\!\left(\prod_{p\mid R}(p-1)\right).$$Bây giờ hãy kiểm tra số mũ của một số nguyên tố$q$bên trong$\phi(n^2)$. 

--- 

### Trường hợp 1:$q\mid n$Giả định$q^{a_q}\parallel n$. Sau đó:

-$q^{2a_q-1}$đến từ$\phi(q^{2a_q})$, 
- quyền hạn bổ sung của$q$đến từ yếu tố$(p-1)$cho các số nguyên tố khác$p\mid n$. 

Kể từ đây$$v_q(\phi(n^2)) = 2a_q-1+d_q.$$Chúng tôi yêu cầu điều này phải được chia cho$3$:$$2a_q-1+d_q \equiv 0 \pmod 3.$$Từ$2^{-1}\equiv 2 \pmod 3$,$$a_q \equiv 2+d_q \pmod 3.$$Vì thế một lần$R$là cố định, số mũ của mọi phép chia nguyên tố$n$được xác định modulo$3$. 

Do đó số mũ dương nhỏ nhất là$$r_q= \begin{cases} 1,& d_q\equiv 2 \pmod 3,\\ 2,& d_q\equiv 0 \pmod 3,\\ 3,& d_q\equiv 1 \pmod 3. \end{cases}$$--- 

### Trường hợp 2:$q\nmid n$Sau đó, sự đóng góp duy nhất đến từ$\phi(R)$, vì vậy chúng ta cần$$d_q \equiv 0 \pmod 3.$$Do đó mọi số nguyên tố “ngoài” xuất hiện trong$\prod(p-1)$phải xảy ra với số mũ chia hết cho$3$. 

--- 

#2. Cấu trúc của mọi giải pháp 

Một khi là người cấp tiến$R$đã được sửa: 

- mỗi số nguyên tố$p\mid R$có số mũ tối thiểu$r_p\in\{1,2,3\}$, 
- cộng bội số của$3$đến số mũ bảo toàn điều kiện khối. 

Vậy mọi nghiệm đều có dạng$$n=n_0\prod_{p\mid R} p^{3k_p},$$Ở đâu$$n_0=\prod_{p\mid R} p^{r_p}.$$Do đó vấn đề giảm xuống: 

1. liệt kê tất cả các gốc được chấp nhận$R$, 
2. tính cơ số tối thiểu$n_0$, 
3. nhân với các khối số nguyên tố tùy ý đã có trong$R$, 
4. giữ giá trị bên dưới$10^{10}$. 

--- 

#3. Chiến lược tìm kiếm hiệu quả 

Chúng tôi xây dựng đệ quy các gốc$R$. 

Khi thêm một số nguyên tố mới$q$: 

- cập nhật hệ số hóa của$\phi(R)$sử dụng hệ số hóa của$q-1$, 
- tính toán lại mức tối thiểu có thể$n_0$, 
- tỉa nếu$n_0>10^{10}$. 

Một ràng buộc quan trọng: 

- số nguyên tố lớn nhất trong$R$luôn có số mũ$2$, 
- do đó mọi số nguyên tố trong$R$nhiều nhất là$10^5$. 

Vì vậy không gian tìm kiếm là rất nhỏ.

#4. Triển khai Python```python
from sympy import primerange, factorint

LIMIT = 10**10

# All primes that could possibly appear.
# The largest prime must appear with exponent at least 2,
# so p^2 < LIMIT => p < 1e5.
primes = list(primerange(2, 100000))

# Precompute factorizations of p - 1
fac = {p: factorint(p - 1) for p in primes}

solutions = set()

def minimal_base(R, d):
    """
    Given:
        R = set of primes dividing n
        d[q] = exponent of q in phi(R) modulo 3

    compute the smallest possible n having radical R.
    """
    n0 = 1

    for p in R:
        r = (2 + d.get(p, 0)) % 3

        # residue 0 means exponent 3
        if r == 0:
            r = 3

        n0 *= p ** r

        if n0 > LIMIT:
            return n0

    return n0

def generate_all_from_base(base, prime_list, idx=0):
    """
    From the minimal solution, multiply by arbitrary cubes
    of existing primes.
    """
    if base > LIMIT:
        return

    if idx == len(prime_list):
        solutions.add(base)
        return

    p = prime_list[idx]

    value = base
    while value <= LIMIT:
        generate_all_from_base(value, prime_list, idx + 1)
        value *= p ** 3

def dfs(start, R, d):
    """
    Recursive generation of admissible radicals.
    """
    n0 = minimal_base(R, d)

    if n0 > LIMIT:
        return

    # Check external-prime condition:
    # every prime not in R must have exponent 0 mod 3.
    ok = True
    for q, v in d.items():
        if q not in R and v % 3 != 0:
            ok = False
            break

    # If valid, generate all solutions from this radical
    if ok and R:
        generate_all_from_base(
            n0,
            sorted(R)
        )

    # Try adding larger primes
    for i in range(start, len(primes)):
        q = primes[i]

        # Safe pruning:
        # any new prime contributes at least q^2 overall.
        if n0 * q * q > LIMIT:
            break

        R2 = set(R)
        R2.add(q)

        d2 = dict(d)

        # Update d using factorization of q-1
        for p, e in fac[q].items():
            d2[p] = (d2.get(p, 0) + e) % 3

        dfs(i + 1, R2, d2)

dfs(0, set(), {})

answer = sum(solutions)

print(answer)
```---

## Từ điển`d`

`d[q]`cửa hàng$$v_q(\phi(R)) \pmod 3.$$Khi thêm một số nguyên tố$p$đến căn bản, chúng ta nhân lên$\phi(R)$qua$p-1$, vì vậy chúng ta chỉ cần thêm hệ số của$p-1$modulo$3$. 

---

r = (2 + d.get(p, 0)) % 3
```Điều này thực hiện$$a_p \equiv 2+d_p \pmod 3.$$Nếu phần dư là$0$, số mũ dương nhỏ nhất là$3$.

## Nhân số khối

# 6. Kiểm tra độ tỉnh táo nhỏ 

Ví dụ từ tuyên bố:$$50 = 2^1 \cdot 5^2.$$Sau đó$$\phi(50^2)=\phi(2500)=1000=10^3.$$Chính xác. 

Một ví dụ khác:$$225=3^2\cdot 5^2.$$Sau đó$$\phi(225^2) = 2^3\cdot 3^3\cdot 5^3 = 30^3.$$Cũng đúng.
