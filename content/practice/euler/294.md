[Vấn đề dự án Euler 294](https://projecteuler.net/problem=294) 

##Giải pháp 

**Trả lời:**`789184709`Cho khai triển thập phân của$k$là$$k=\sum_{i=0}^{n-1} a_i 10^i, \qquad 0\le a_i\le 9.$$Chúng tôi muốn đếm số$k<10^n$như vậy 

1.$k\equiv 0 \pmod{23}$, 
2.$\sum a_i = 23$. 

Biểu thị số đếm này bằng$S(n)$. 

--- 

# 1. Phân tích toán học 

## 1.1 Mã hóa điều kiện 

Điều kiện tổng chữ số là$$\sum_{i=0}^{n-1} a_i = 23.$$Điều kiện chia hết là$$\sum_{i=0}^{n-1} a_i 10^i \equiv 0 \pmod{23}.$$Vì vậy, mọi chữ số đều đóng góp đồng thời: 

-$+a_i$đến tổng chữ số, 
-$+a_i 10^i$modulo$23$. 

Điều này gợi ý mạnh mẽ một cách tiếp cận hàm tạo. 

--- 

## 1.2 Hàm sinh hai biến 

Đối với một vị trí cố định$i$, chữ số$d\in\{0,\dots,9\}$đóng góp$$x^d y^{d10^i}.$$Như vậy vị trí$i$đóng góp đa thức$$P_i(x,y)=\sum_{d=0}^9 x^d y^{d10^i}.$$Nhân trên tất cả các vị trí:$$F_n(x,y)=\prod_{i=0}^{n-1} P_i(x,y).$$Sau đó: 

- số mũ của$x$ghi lại tổng chữ số, 
- số mũ của$y$hồ sơ dư lượng modulo$23$. 

Vì thế,$$S(n)= [x^{23}y^0]\,F_n(x,y),$$trong đó số mũ của$y$được giải thích modulo$23$. 

--- 

## 1.3 Tính tuần hoàn modulo 23 

Một quan sát quan trọng:$$10^{22}\equiv 1 \pmod{23},$$bởi vì$23$là số nguyên tố và$10$là phần tử nguyên thủy modulo$23$. 

Do đó trình tự$10^i \pmod{23}$có thời gian$22$. 

Do đó các yếu tố lặp lại mỗi$22$các vị trí. 

Cho phép$$n = 22q + r,\qquad 0\le r<22.$$Sau đó, mỗi vị trí lớp dư lượng sẽ xuất hiện: 

-$q$lần, hoặc 
-$q+1$lần. 

Cụ thể, đối với$j=0,\dots,21$,$$P_j(x,y)=\sum_{d=0}^9 x^d y^{d10^j},$$Và$$F_n(x,y) = \prod_{j=0}^{21} P_j(x,y)^{\,q+\mathbf 1_{j<r}}.$$--- 

## 1.4 Phép lạ cắt ngắn 

Chúng tôi chỉ quan tâm đến hệ số$x^{23}$. 

Vì vậy, trong tất cả các phép nhân, chúng ta có thể loại bỏ mọi số hạng bậc$>23$. 

Vì vậy, toàn bộ tính toán nằm trong một đại số hữu hạn nhỏ: 

-$x$-bằng cấp:$0\ldots 23$, 
- modulo dư lượng$23$:$0\ldots 22$. 

Tổng số tiểu bang:$$24\times 23 = 552.$$Sự lũy thừa trở nên cực kỳ nhanh chóng.

#2. Triển khai Python```python
MOD = 10**9

# --------------------------------------------------------------------
# Polynomial representation:
# dictionary mapping (digit_sum, residue_mod_23) -> coefficient
# --------------------------------------------------------------------

def multiply(A, B):
    """
    Multiply two truncated polynomials.

    State:
        (s, r)
    means:
        x^s y^r

    We truncate all terms with s > 23.
    """
    C = {}

    for (s1, r1), v1 in A.items():
        for (s2, r2), v2 in B.items():

            s = s1 + s2

            # We only need digit sum <= 23
            if s <= 23:
                r = (r1 + r2) % 23

                key = (s, r)

                C[key] = (C.get(key, 0) + v1 * v2) % MOD

    return C

def power(P, e):
    """
    Fast exponentiation of a polynomial.
    """
    R = {(0, 0): 1}

    while e > 0:

        if e & 1:
            R = multiply(R, P)

        P = multiply(P, P)

        e >>= 1

    return R

def S(n):
    """
    Compute S(n) mod 1e9.
    """

    q, r = divmod(n, 22)

    # Start with multiplicative identity
    ans = {(0, 0): 1}

    # Build the 22 periodic factors
    for j in range(22):

        w = pow(10, j, 23)

        # P_j(x,y)
        P = {}

        for d in range(10):
            key = (d, (d * w) % 23)
            P[key] = P.get(key, 0) + 1

        exponent = q + (1 if j < r else 0)

        ans = multiply(ans, power(P, exponent))

    return ans.get((23, 0), 0)

# --------------------------------------------------------------------
# Verification on given examples
# --------------------------------------------------------------------

print(S(9))      # 263626
print(S(42))     # 878570056  (matches the last 9 digits)

# Final computation
N = 11**12

print(S(N))
```--- 

#3. Hướng dẫn sử dụng mã 

##`multiply(A, B)`Mỗi đa thức được lưu trữ thưa thớt. 

Một thuật ngữ```python
(s, r): value
```có nghĩa:$$\text{value}\cdot x^s y^r.$$Khi nhân:$$x^{s_1}y^{r_1}\cdot x^{s_2}y^{r_2} = x^{s_1+s_2}y^{r_1+r_2}.$$Phần dư được giảm modulo$23$. 

Chúng tôi loại bỏ tất cả các số hạng có tổng chữ số$>23$. 

--- 

##`power(P, e)`Mũ nhị phân tiêu chuẩn. 

Điều này tính toán:$$P^e$$TRONG$O(\log e)$phép nhân. 

Từ$11^{12}\approx 3.1\times 10^{12}$, chỉ về$42$bước bình phương là cần thiết. 

--- 

##`S(n)`Chúng tôi sử dụng tính tuần hoàn:$$10^{22}\equiv 1 \pmod{23}.$$Như vậy chỉ có$22$loại vị trí riêng biệt. 

Nếu như$$n=22q+r,$$sau đó nhân tố$P_j$xuất hiện:$$q+\mathbf 1_{j<r}$$lần. 

Cuối cùng chúng tôi trích xuất hệ số:```python
ans[(23, 0)]
```tương ứng chính xác với: 

- tổng chữ số$23$, 
- dư lượng$0\pmod{23}$.
