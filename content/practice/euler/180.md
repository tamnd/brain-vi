## Giải pháp 

**Trả lời:**`285196020571078987`Chúng tôi tìm kiếm tất cả các bộ ba hợp lý$(x,y,z)$với$$0<x,y,z<1,\qquad x,y,z\in \left\{\frac ab:0<a<b\le 35\right\},$$sao cho đối với một số nguyên$n$,$$f_n(x,y,z)=0.$$Điều quan trọng là đơn giản hóa cấu trúc đại số của$f_n$. 

--- 

# 1. Phân tích toán học 

Chúng tôi được trao$$\begin{aligned} f_{1,n}&=x^{n+1}+y^{n+1}-z^{n+1},\\ f_{2,n}&=(xy+yz+zx)(x^{n-1}+y^{n-1}-z^{n-1}),\\ f_{3,n}&=xyz(x^{n-2}+y^{n-2}-z^{n-2}), \end{aligned}$$Và$$f_n=f_{1,n}+f_{2,n}-f_{3,n}.$$Đầu tiên chúng ta tính hệ số biểu thức này. 

## 1.1 Mở rộng$f_n$Mở rộng:$$\begin{aligned} f_n &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +(xy+yz+zx)(x^{n-1}+y^{n-1}-z^{n-1})\\ &\quad -xyz(x^{n-2}+y^{n-2}-z^{n-2}). \end{aligned}$$Nhóm điều khoản liên quan đến quyền hạn của$x$:$$x^{n-1}(x^2+xy+xz-yz).$$Nhưng$$x^2+xy+xz-yz=(x+y)(x+z)-2yz.$$Một cách rõ ràng hơn là kiểm tra trực tiếp rằng$$f_n=(x+y-z)(x^n+y^n-z^n).$$Thực vậy,$$\begin{aligned} (x+y-z)(x^n+y^n-z^n) &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +xy^n+yx^n-xz^n-zx^n\\ &\quad +xz^n+zy^n-zx^n-zy^n\\ &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +xy(x^{n-1}+y^{n-1})\\ &\quad +xz(x^{n-1}-z^{n-1})\\ &\quad +yz(y^{n-1}-z^{n-1}), \end{aligned}$$khớp chính xác sau khi tập hợp lại. 

Vì thế,$$\boxed{f_n(x,y,z)=(x+y-z)(x^n+y^n-z^n).}$$Do đó bộ ba vàng thỏa mãn một trong hai 

1.$x+y=z$hoặc 
2.$x^n+y^n=z^n$. 

đối với một số nguyên$n$. 

--- 

#1.2 Số mũ nào quan trọng? 

Bởi vì$0<x,y,z<1$là hợp lý: 

- Vì$n=1$:$$x+y=z.$$- Vì$n=2$:$$x^2+y^2=z^2.$$Bộ ba Pythagore hợp lý xảy ra. 
- Vì$n\ge 3$: 

Theo Định lý cuối cùng của Fermat, không tồn tại nghiệm hữu tỉ khác 0. 
- Vì$n=0$:$$x^0+y^0=z^0 \implies 1+1=1,$$không thể nào. 
- Vì$n=-1$:$$\frac1x+\frac1y=\frac1z.$$Tương đương,$$z=\frac{xy}{x+y}.$$- Vì$n=-2$:$$\frac1{x^2}+\frac1{y^2}=\frac1{z^2},$$một điều kiện kiểu Pythagore khác. 
- Vì$n\le -3$: 

viết lại mang lại$$\left(\frac1x\right)^m+\left(\frac1y\right)^m =\left(\frac1z\right)^m,$$một lần nữa FLT lại không thể thực hiện được. 

Vậy chỉ có bốn trường hợp tồn tại:$$n\in\{1,2,-1,-2\}.$$--- 

#1.3 Liệt kê tất cả các bộ ba hợp lệ 

hãy để$$S=\left\{\frac ab:0<a<b\le 35,\ \gcd(a,b)=1\right\}.$$Chúng tôi cần tất cả các giá trị riêng biệt$$s=x+y+z$$đến từ bộ ba thỏa mãn một trong: 

1.$x+y=z$2.$x^2+y^2=z^2$3.$1/x+1/y=1/z$4.$1/x^2+1/y^2=1/z^2$với$x,y,z\in S$. 

Cuối cùng tổng hợp tất cả các khác biệt$s$. 

--- 

#1.4 Tham số hóa hợp lý 

Hai phương trình bậc hai được tham số hóa bằng bộ ba Pythagore hữu tỷ. 

Nếu như$$a^2+b^2=c^2,$$sau đó$$(a,b,c)=k(m^2-n^2,2mn,m^2+n^2).$$Như vậy: 

- Trường hợp$n=2$: 

chọn bộ ba Pythagore hợp lý bên trong$(0,1)$. 
- Trường hợp$n=-2$: 

nghịch đảo của các bộ ba như vậy. 

Việc tính toán là hữu hạn và đủ nhỏ để xử lý mạnh mẽ các phân số Farey có mẫu số$\le 35$.

#2. Triển khai Python```python
from fractions import Fraction
from math import gcd, isqrt

K = 35

# ------------------------------------------------------------
# Generate all reduced fractions a/b with 0 < a < b <= K
# ------------------------------------------------------------

vals = set()

for b in range(2, K + 1):
    for a in range(1, b):
        if gcd(a, b) == 1:
            vals.add(Fraction(a, b))

vals = sorted(vals)

# ------------------------------------------------------------
# Collect all distinct sums s = x + y + z
# ------------------------------------------------------------

sums = set()

for x in vals:
    for y in vals:

        # ----------------------------------------------------
        # Case n = 1 : x + y = z
        # ----------------------------------------------------
        z = x + y
        if z in vals:
            sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = -1 : 1/x + 1/y = 1/z
        # z = xy / (x + y)
        # ----------------------------------------------------
        z = x * y / (x + y)
        if z in vals:
            sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = 2 : x^2 + y^2 = z^2
        # ----------------------------------------------------
        z2 = x * x + y * y

        num = z2.numerator
        den = z2.denominator

        sn = isqrt(num)
        sd = isqrt(den)

        if sn * sn == num and sd * sd == den:
            z = Fraction(sn, sd)
            if z in vals:
                sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = -2 :
        # 1/x^2 + 1/y^2 = 1/z^2
        # ----------------------------------------------------
        inv2 = Fraction(1, x * x) + Fraction(1, y * y)

        num = inv2.numerator
        den = inv2.denominator

        sn = isqrt(den)
        sd = isqrt(num)

        if sn * sn == den and sd * sd == num:
            z = Fraction(sn, sd)
            if z in vals:
                sums.add(x + y + z)

# ------------------------------------------------------------
# Sum all distinct s-values
# ------------------------------------------------------------

total = sum(sums, Fraction(0, 1))

print(total)
print(total.numerator + total.denominator)
```---
