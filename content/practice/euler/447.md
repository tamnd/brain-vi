## Giải pháp 

**Trả lời:**`530553372`### Bước 1 - Mô tả đặc điểm rút lại$f(f(x)) = a(ax+b)+b = a^2x + ab + b$. 

điều kiện$f(f(x)) \equiv f(x) \pmod{n}$cho tất cả$x$yêu cầu:$$n \mid a(a-1) \quad \text{and} \quad n \mid ab.$$**Điều kiện 1** —$a$phải bình thường trong$\mathbb{Z}/n\mathbb{Z}$:$a^2 \equiv a$. 

Bởi vì$\gcd(a,a-1)=1$, với mỗi lũy thừa nguyên tố$p^k \| n$chúng tôi cần$p^k \mid a$hoặc$p^k \mid (a-1)$. Với CRT, đẳng thức của$\mathbb{Z}/n\mathbb{Z}$chính xác là các phần tử thu được bằng cách chọn, độc lập cho từng thành phần lũy thừa nguyên tố$p_i^{k_i}$, liệu$a \equiv 0$hoặc$a \equiv 1 \pmod{p_i^{k_i}}$. có$2^{\omega(n)}$bình thường (bao gồm cả$0$), kể từ đây$2^{\omega(n)}-1$đẳng thức khác không trong$0 < a < n$. 

**Điều kiện 2** — hợp lệ$a$, đếm$b$.$n \mid ab$nếu$b \equiv 0 \pmod{n/\gcd(a,n)}$. Có chính xác$\gcd(a,n)$như là$b$TRONG$[0,n)$. 

Đối với bình thường$a$được xây dựng từ tập hợp con$S$của các thành phần năng lượng chính (những nơi mà$a \equiv 0$):$$\gcd(a,n) = \prod_{p^k \in S} p^k.$$### Bước 2 - Biểu mẫu đóng cho R(n)$$R(n) = \sum_{\substack{S \subsetneq \{p_1^{k_1},\ldots,p_m^{k_m}\}}} \prod_{p^k \in S} p^k = \prod_{i=1}^{m}(1 + p_i^{k_i}) - \prod_{i=1}^{m} p_i^{k_i} = \sigma^*(n) - n$$Ở đâu$\sigma^*(n) = \prod_{p^k \| n}(1+p^k)$là **tổng ước số đơn nhất** (một hàm nhân). 

Xác minh:$n=6=2\cdot3$,$\sigma^*(6)=(1+2)(1+3)=12$,$R(6)=6$. Tính trực tiếp:$a\in\{1,3,4\}$,$b$-đếm$1,3,2$tổng hợp thành$6$. ✓ 

### Bước 3 - Giảm F(N)$$F(N) = \sum_{n=2}^{N}(\sigma^*(n) - n) = G(N) - \frac{N(N+1)}{2}$$Ở đâu$G(N) = \sum_{n=1}^{N}\sigma^*(n)$. 

### Bước 4 - Tính G(N) thông qua nghịch đảo Möbius 

Một số chia đơn nhất$d$của$n$thỏa mãn$d \mid n$Và$\gcd(d, n/d)=1$. Vì thế:$$G(N) = \sum_{d=1}^{N} d \cdot \#\{n \le N : d \| n\} = \sum_{d=1}^{N} d \cdot \#\{m \le N/d : \gcd(m,d)=1\}.$$Ứng dụng nghịch đảo và viết Möbius$d = ek$:$$G(N) = \sum_{e=1}^{\lfloor\sqrt{N}\rfloor} \mu(e)\cdot e \cdot S\!\left(\left\lfloor\frac{N}{e^2}\right\rfloor\right)$$Ở đâu$S(M) = \sum_{k=1}^{M} k\left\lfloor\frac{M}{k}\right\rfloor = \sum_{m=1}^{M}\sigma(m)$. 

### Bước 5 — Tính S(M) theo O(√M) 

Nhóm$k$bởi các giá trị bằng nhau của$q = \lfloor M/k\rfloor$. Mỗi nhóm là một phạm vi liền kề$[k_0, k_1)$với$k_1 = \lfloor M/q\rfloor + 1$, đóng góp$q \cdot (k_0+k_1-1)(k_1-k_0)/2$. Vòng lặp while chạy$O(\sqrt{M})$lần lặp lại. 

### Triển khai Python```python
from math import isqrt

MOD = 10**9 + 7

def solve(N):
    sqN = isqrt(N)

    # Linear sieve: Mobius function up to sqrt(N)
    mu = [0] * (sqN + 1)
    mu[1] = 1
    primes = []
    is_comp = bytearray(sqN + 1)
    for i in range(2, sqN + 1):
        if not is_comp[i]:
            primes.append(i)
            mu[i] = -1
        for p in primes:
            ip = i * p
            if ip > sqN:
                break
            is_comp[ip] = 1
            if i % p == 0:
                mu[ip] = 0
                break
            mu[ip] = -mu[i]

    def S(M):
        total = 0
        k = 1
        while k <= M:
            q = M // k
            nk = M // q + 1
            cnt = nk - k
            s = (k + nk - 1) * cnt // 2 % MOD
            total = (total + q * s) % MOD
            k = nk
        return total

    G = 0
    for e in range(1, sqN + 1):
        if mu[e] == 0:
            continue
        M = N // (e * e)
        if M == 0:
            break
        G = (G + mu[e] * e % MOD * S(M)) % MOD

    tri = N % MOD * ((N + 1) % MOD) % MOD * pow(2, MOD - 2, MOD) % MOD
    return (G - tri) % MOD

assert solve(10**7) == 638042271
print(solve(10**14))  # → 530553372
```**Độ phức tạp:**$O(\sqrt{N}\log N)$- sàng$O(\sqrt{N})$; vòng lặp chính$\sum_{e \le \sqrt{N}} O(\sqrt{N/e^2}) = O(\sqrt{N}\log\sqrt{N})$.
