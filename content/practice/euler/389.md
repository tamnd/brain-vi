##Giải pháp 

**Trả lời:**`2406376.3623`Cho phép

-$T$= kết quả của một con súc sắc 4 mặt, 
-$C$= tổng của$T$xúc xắc 6 mặt độc lập, 
-$O$= tổng của$C$xúc xắc 8 mặt độc lập, 
-$D$= tổng của$O$xúc xắc 12 mặt độc lập, 
-$I$= tổng của$D$xúc xắc 20 mặt độc lập. 

Chúng tôi được yêu cầu$\mathrm{Var}(I)$. 

Công cụ chính là **quy luật tổng kỳ vọng** và **luật phương sai tổng**. 

Cho một hội chợ$n$các giá trị lấy khuôn mặt$1,\dots,n$,$$\mathbb E[X] = \frac{n+1}{2}, \qquad \mathrm{Var}(X)=\frac{n^2-1}{12}.$$Chúng tôi sẽ liên tục sử dụng thực tế sau đây. 

Nếu như$S_N$là tổng của$N$iid biến ngẫu nhiên$X_i$, Ở đâu$N$bản thân nó là ngẫu nhiên và độc lập với$X_i$, sau đó$$\mathbb E[S_N] = \mathbb E[N]\mathbb E[X],$$Và$$\mathrm{Var}(S_N) = \mathbb E[N]\mathrm{Var}(X) + \mathrm{Var}(N)\bigl(\mathbb E[X]\bigr)^2.$$Bản sắc đó xuất phát trực tiếp từ$$\mathrm{Var}(S_N) = \mathbb E[\mathrm{Var}(S_N\mid N)] + \mathrm{Var}(\mathbb E[S_N\mid N]).$$--- 

# Bước 1: Phân bổ thông số cho từng khuôn 

Đối với một$k$khuôn mặt:$$\mu_k = \frac{k+1}{2}, \qquad \sigma_k^2 = \frac{k^2-1}{12}.$$Như vậy: 

| Chết | Ý nghĩa | Phương sai | 
| --- | --- | --- | 
| d4 |$5/2$|$5/4$| 
| d6 |$7/2$|$35/12$| 
| d8 |$9/2$|$21/4$| 
| d12 |$13/2$|$143/12$| 
| d20 |$21/2$|$133/4$| 

--- 

# Bước 2: Tính toán$C$có điều kiện$T=t$,$$C = \sum_{i=1}^t X_i,$$Ở đâu$X_i$là iid d6 cuộn. 

Kể từ đây$$\mathbb E[C] = \mathbb E[T]\mu_6 = \frac52\cdot\frac72 = \frac{35}{4}.$$Sử dụng tổng phương sai:$$\mathrm{Var}(C) = \mathbb E[T]\sigma_6^2 + \mathrm{Var}(T)\mu_6^2.$$Vì thế$$\mathrm{Var}(C) = \frac52\cdot\frac{35}{12} + \frac54\cdot\left(\frac72\right)^2.$$Tính toán:$$= \frac{175}{24} + \frac{245}{16} = \frac{595}{24}.$$--- 

# Bước 3: Tính toán$O$

$O$là tổng của$C$iid d8 cuộn. 

Nghĩa là:$$\mathbb E[O] = \mathbb E[C]\mu_8 = \frac{35}{4}\cdot\frac92 = \frac{315}{8}.$$Phương sai:$$\mathrm{Var}(O) = \mathbb E[C]\sigma_8^2 + \mathrm{Var}(C)\mu_8^2.$$Như vậy$$= \frac{35}{4}\cdot\frac{21}{4} + \frac{595}{24}\cdot\left(\frac92\right)^2.$$

$$= \frac{735}{16} + \frac{16065}{96} = \frac{20475}{96} = \frac{6825}{32}.$$--- 

# Bước 4: Tính toán$D$

$D$là tổng của$O$iid d12 cuộn. 

Nghĩa là:$$\mathbb E[D] = \frac{315}{8}\cdot\frac{13}{2} = \frac{4095}{16}.$$Phương sai:$$\mathrm{Var}(D) = \mathbb E[O]\sigma_{12}^2 + \mathrm{Var}(O)\mu_{12}^2.$$Vì thế$$= \frac{315}{8}\cdot\frac{143}{12} + \frac{6825}{32}\cdot\left(\frac{13}{2}\right)^2.$$

$$= \frac{45045}{96} + \frac{1153425}{128}.$$mẫu số chung$384$:$$= \frac{180180 + 3460275}{384} = \frac{3640455}{384}.$$--- 

# Bước 5: Tính toán$I$

$I$là tổng của$D$iid d20 cuộn. 

Chúng ta chỉ cần phương sai:$$\mathrm{Var}(I) = \mathbb E[D]\sigma_{20}^2 + \mathrm{Var}(D)\mu_{20}^2.$$Các giá trị thay thế:$$= \frac{4095}{16}\cdot\frac{133}{4} + \frac{3640455}{384}\cdot\left(\frac{21}{2}\right)^2.$$Học kỳ đầu tiên:$$\frac{4095\cdot133}{64} = \frac{544635}{64}.$$Học kỳ thứ hai:$$\frac{3640455}{384}\cdot\frac{441}{4} = \frac{1603440655}{1536}.$$Chuyển số hạng đầu tiên thành mẫu số$1536$:$$\frac{544635}{64} = \frac{13071240}{1536}.$$Kể từ đây$$\mathrm{Var}(I) = \frac{1616511895}{1536}.$$Giá trị thập phân:$$\mathrm{Var}(I) = 1052416.5983072916\ldots$$Làm tròn đến 4 chữ số thập phân:$$1052416.5983$$--- 

#Triển khai Python```python
from fractions import Fraction

def die_stats(sides):
    """
    Return (mean, variance) for a fair die with values 1..sides.
    """
    mean = Fraction(sides + 1, 2)
    var = Fraction(sides * sides - 1, 12)
    return mean, var

def compound_sum(mean_n, var_n, mean_x, var_x):
    """
    If S is the sum of N iid X variables:

        S = X1 + X2 + ... + XN

    where N is random and independent of the Xi, then

        E[S]   = E[N] E[X]
        Var[S] = E[N] Var[X] + Var[N] (E[X])^2

    Returns (mean_S, var_S).
    """
    mean_s = mean_n * mean_x
    var_s = mean_n * var_x + var_n * mean_x * mean_x
    return mean_s, var_s

# Start with T: one d4
mean_T, var_T = die_stats(4)

# C: sum of T d6
mean_d6, var_d6 = die_stats(6)
mean_C, var_C = compound_sum(mean_T, var_T, mean_d6, var_d6)

# O: sum of C d8
mean_d8, var_d8 = die_stats(8)
mean_O, var_O = compound_sum(mean_C, var_C, mean_d8, var_d8)

# D: sum of O d12
mean_d12, var_d12 = die_stats(12)
mean_D, var_D = compound_sum(mean_O, var_O, mean_d12, var_d12)

# I: sum of D d20
mean_d20, var_d20 = die_stats(20)
mean_I, var_I = compound_sum(mean_D, var_D, mean_d20, var_d20)

print("Exact variance:", var_I)
print("Decimal:", float(var_I))
print("Rounded:", round(float(var_I), 4))
```--- 

# Hướng dẫn sử dụng mã 

###`die_stats`Tính giá trị trung bình và phương sai của một con súc sắc đẹp:$$\mu=\frac{n+1}{2},\qquad \sigma^2=\frac{n^2-1}{12}.$$sử dụng`Fraction`giữ mọi thứ chính xác. 

--- 

###`compound_sum`Thực hiện các công thức cơ bản:$$E[S]=E[N]E[X]$$Và$$\mathrm{Var}(S) = E[N]\mathrm{Var}(X) + \mathrm{Var}(N)(E[X])^2.$$Điều này được áp dụng nhiều lần thông qua chuỗi:$$T \to C \to O \to D \to I.$$--- 

### Tính toán đệ quy 

Mỗi giai đoạn trở thành số lượng xúc xắc ngẫu nhiên được tung ra ở giai đoạn tiếp theo. 

Ví dụ:```python
mean_C, var_C = compound_sum(mean_T, var_T, mean_d6, var_d6)
```tính toán thống kê tổng của$T$xúc xắc sáu mặt.
