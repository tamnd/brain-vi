[Dự án Euler Vấn đề 755](https://projecteuler.net/problem=755) 

##Giải pháp 

**Trả lời:**`2877071595975576960`Cho phép$$F=\{1,2,3,5,8,\dots\}$$và để$f(n)$là số tập con của$F$các phần tử của nó có tổng bằng$n$. 

Sau đó$$S(N)=\sum_{k=0}^N f(k)$$đếm **tất cả các tập con của các số Fibonacci có tổng tổng lớn nhất$N$**. 

Vì vậy, nhiệm vụ là: 

> Đếm các tập con của các số Fibonacci riêng biệt có tổng$\le 10^{13}$. 

Một đệ quy rất hiệu quả hoạt động. 

Nếu các số Fibonacci có sẵn là$F_0,\dots,F_i$, thì: 

- hoặc là chúng tôi **không** sử dụng$F_i$, 
- hoặc chúng tôi **có** sử dụng$F_i$. 

Kể từ đây:$$C(i,x)=C(i-1,x)+C(i-1,x-F_i).$$Chúng tôi cũng sử dụng một phím tắt quan trọng: 

Nếu$$x \ge \sum_{k=0}^i F_k,$$thì mọi tập hợp con đều được phép, vì vậy$$C(i,x)=2^{i+1}.$$Điều này làm giảm đáng kể số lượng trạng thái. 

Mã Python:```python
from functools import lru_cache

N = 10**13

# Build Fibonacci numbers: 1,2,3,5,...
fibs = [1, 2]
while fibs[-1] + fibs[-2] <= N:
    fibs.append(fibs[-1] + fibs[-2])

# Prefix sums
prefix = []
s = 0
for x in fibs:
    s += x
    prefix.append(s)

@lru_cache(None)
def count_subsets(i, limit):
    # Number of subsets using fibs[0..i] with sum <= limit

    if limit < 0:
        return 0

    if i < 0:
        return 1  # empty subset

    # If limit already exceeds total possible sum,
    # every subset is valid.
    if limit >= prefix[i]:
        return 1 << (i + 1)

    # Can't use fibs[i]
    if fibs[i] > limit:
        return count_subsets(i - 1, limit)

    # Exclude or include fibs[i]
    return (
        count_subsets(i - 1, limit)
        + count_subsets(i - 1, limit - fibs[i])
    )

answer = count_subsets(len(fibs) - 1, N)

print(answer)
```Xác minh trên các ví dụ đã cho:
