[Vấn đề dự án Euler 409](https://projecteuler.net/problem=409) 

## Giải pháp 

**Trả lời:**`253223948`Cho phép$$q = 2^n.$$Chúng tôi đang đếm theo thứ tự$n$-bộ dữ liệu$$(x_1,x_2,\dots,x_n)$$như vậy: 

- mỗi$x_i\in\{1,2,\dots,q-1\}$,
- tất cả$x_i$khác biệt, 
- vị trí **chiến thắng** trong nim, tức là.$$x_1\oplus x_2\oplus \cdots \oplus x_n \ne 0.$$Định nghĩa:

-$A_k$: số thứ tự khác 0 khác biệt$k$-bộ dữ liệu, 
-$L_k$: số thứ tự khác 0 khác biệt$k$-bộ dữ liệu với xor$0$, 
-$W_k=A_k-L_k$. 

Cuối cùng chúng tôi cần$W_n$vì$q=2^n$. 

--- 

# 1. Phân tích toán học 

## Tổng số bộ dữ liệu 

Tổng số thứ tự khác không khác biệt$k$-tuples chỉ đơn giản là$$A_k=(q-1)(q-2)\cdots(q-k)$$(sử dụng ký hiệu giai thừa rơi$A_k=(q-1)_k$). 

Đặc biệt,$$A_n=(2^n-1)(2^n-2)\cdots(2^n-n).$$--- 

# Đếm số vị thế thua 

Bây giờ chúng tôi rút ra một sự tái diễn cho$L_k$. 

Coi như thua$k$-bộ:$$x_1\oplus x_2\oplus\cdots\oplus x_k=0.$$Sau đó, phần tử cuối cùng bị buộc:$$x_k=x_1\oplus x_2\oplus\cdots\oplus x_{k-1}.$$Vì vậy, chúng ta bắt đầu với bất kỳ khác 0 khác biệt có thứ tự nào$(k-1)$-tuple và hỏi khi giá trị bắt buộc hợp lệ. 

có$A_{k-1}$khả thi$(k-1)$-bộ dữ liệu. 

Phải loại trừ hai trường hợp xấu. 

--- 

## Trường hợp xấu 1: xor là$0$Sau đó$x_k=0$, cấm. 

Điều này xảy ra chính xác khi lần đầu tiên$k-1$mục đã xor để$0$. 

Đếm:$$L_{k-1}.$$--- 

## Trường hợp xấu 2: xor bằng một mục hiện có 

Giả sử$$x_1\oplus\cdots\oplus x_{k-1}=x_i.$$Sau đó loại bỏ$x_i$lá một$(k-2)$-tuple có xor là$0$. 

Ngược lại: 

- chọn thua$(k-2)$-bộ, 
- chọn vị trí$i$($k-1$sự lựa chọn), 
- chọn$x_i$là bất kỳ giá trị khác 0 nào chưa được sử dụng. 

các$(k-2)$-tuple đã sử dụng$k-2$các giá trị khác 0 khác nhau, do đó có$$(q-1)-(k-2)=q-k+1$$sự lựa chọn cho$x_i$. 

Do đó số bộ dữ liệu trong trường hợp xấu 2 là$$(k-1)(q-k+1)L_{k-2}.$$--- 

# Tái diễn 

Do đó:$$\boxed{ L_k = A_{k-1} - L_{k-1} - (k-1)(q-k+1)L_{k-2} }$$với điều kiện ban đầu$$L_0=1,\qquad L_1=0.$$Cuối cùng,$$W_n=A_n-L_n.$$Sự truy hồi này là thời gian tuyến tính và đủ nhanh để$n=10^7$. 

--- 

#2. Triển khai Python```python
MOD = 1_000_000_007

def solve(n):
    q = pow(2, n, MOD)

    # n = 1 is trivial
    if n == 1:
        return 1

    # A1 = q - 1
    A_prev = (q - 1) % MOD

    # L0 = 1, L1 = 0
    L_prev2 = 1
    L_prev1 = 0

    # Build up to Ln
    for k in range(2, n + 1):

        # Recurrence:
        # Lk = A_{k-1}
        #      - L_{k-1}
        #      - (k-1)(q-k+1)L_{k-2}
        Lk = (
            A_prev
            - L_prev1
            - ((k - 1) * (q - k + 1) % MOD) * L_prev2
        ) % MOD

        # Update A_k from A_{k-1}
        A_curr = (A_prev * (q - k)) % MOD

        # Shift states
        A_prev = A_curr
        L_prev2, L_prev1 = L_prev1, Lk

    # Wn = An - Ln
    return (A_prev - L_prev1) % MOD

print(solve(5))      # 19764360
print(solve(100))    # 384777056
print(solve(10_000_000))
```--- 

#3. Hướng dẫn sử dụng mã 

## Bước 1```python
q = pow(2, n, MOD)
```Tính toán$2^n \bmod MOD$. 

--- 

## Bước 2```python
A_prev = q - 1
```Cửa hàng$$A_1=q-1.$$--- 

## Bước 3```python
L_prev2 = 1
L_prev1 = 0
```Khởi tạo:$$L_0=1,\qquad L_1=0.$$--- 

## Bước 4 

Bên trong vòng lặp:```python
Lk = (
    A_prev
    - L_prev1
    - ((k - 1) * (q - k + 1) % MOD) * L_prev2
) % MOD
```dụng cụ$$L_k=A_{k-1}-L_{k-1}-(k-1)(q-k+1)L_{k-2}.$$--- 

## Bước 5```python
A_curr = (A_prev * (q - k)) % MOD
```cập nhật$$A_k=A_{k-1}(q-k).$$--- 

## Bước 6 

Cuối cùng:```python
(A_prev - L_prev1) % MOD
```trả lại$$W_n=A_n-L_n.$$--- 

# 4. Xác minh 

Chương trình tái tạo các giá trị được đưa ra trong câu lệnh: 

-$W(1)=1$-$W(2)=6$-$W(3)=168$-$W(5)=19764360$-$W(100)\bmod 1\,000\,000\,007=384777056$tất cả đều khớp chính xác với tuyên bố vấn đề. 

Chạy tính toán cho$n=10\,000\,000$mang lại:$$W(10\,000\,000)\bmod 1\,000\,000\,007 = 253223948.$$---
