[Vấn đề dự án Euler 873](https://projecteuler.net/problem=873) 

## Giải pháp 

**Trả lời:**`735131856`Hãy để một từ hợp lệ được hình thành từ$p$BẰNG,$q$B và$r$C với điều kiện: 

> mọi A đều cách mọi B ít nhất hai chữ C. 

chúng tôi muốn$$W(10^6,10^7,10^8)\pmod{1\,000\,000\,007}.$$## 1. Phân tích toán học 

### Bước 1: Giảm vấn đề về chạy A/B 

Tạm thời bỏ qua chữ C và chỉ nhìn vào thứ tự của A và B. 

Giả sử khung A/B có các lần chạy liên tiếp:$$AAA\;BB\;A\;BBBB\;\cdots$$Cho phép:

-$a$= số lần chạy A, 
-$b$= số lần chạy B. 

Sau đó: 

- tổng số lần chạy =$a+b$, 
- chuyển tiếp giữa A và B =$a+b-1$. 

Mỗi quá trình chuyển đổi (A→B hoặc B→A) **phải chứa ít nhất hai chữ C**, nếu không một số A và B sẽ quá gần nhau. 

Vậy nếu$$k = a+b-1$$là số lần chuyển tiếp thì chúng ta phải dự trữ$$2k$$C là dấu phân cách bắt buộc. 

Phần còn lại$$r-2k$$C có thể được phân phối tự do giữa các$p+q+1$các khoảng trống (trước, giữa, sau các chữ cái). 

Theo các ngôi sao và quán bar:$$\#\text{ways to place remaining C's} = \binom{(r-2k)+(p+q)}{p+q}.$$--- 

### Bước 2: Đếm khung A/B 

Nếu có$a$A-chạy và$b$B-chạy thì: 

- chia$p$A vào$a$khối tích cực:$$\binom{p-1}{a-1}$$- tách ra$q$B vào$b$khối tích cực:$$\binom{q-1}{b-1}$$Các lần chạy phải xen kẽ, vì vậy chỉ:$$|a-b|\le 1$$là có thể. 

Ngoài ra: 

- nếu$a=b$, có 2 khả năng bắt đầu (A hoặc B), 
- nếu không thì chỉ có 1. 

Như vậy:$$W(p,q,r) = \sum_{\substack{a,b\ge 1\\|a-b|\le 1}} c(a,b) \binom{p-1}{a-1} \binom{q-1}{b-1} \binom{r-2(a+b-1)+p+q}{p+q}$$Ở đâu$$c(a,b)= \begin{cases} 2 & a=b\\ 1 & |a-b|=1 \end{cases}$$--- 

### Bước 3: So sánh các ví dụ 

Công thức này cho:$$W(2,2,4)=32$$Và$$W(4,4,44)=13908607644,$$phù hợp với phát biểu vấn đề.

## 2. Triển khai Python```python
MOD = 1_000_000_007

def W(p, q, r):
    n = p + q
    M = n + r

    # We only need inverses in the range [M - 4p - 5, M]
    low = M - 4 * p - 5
    size = M - low + 1

    # Batch inversion for a contiguous interval using one modular inverse
    prefix = [1] * size
    prod = 1

    for i in range(size):
        x = low + i
        prod = (prod * x) % MOD
        prefix[i] = prod

    inv_total = pow(prod, MOD - 2, MOD)

    inv_high = [0] * size
    for i in range(size - 1, -1, -1):
        x = low + i
        before = prefix[i - 1] if i > 0 else 1
        inv_high[i] = (inv_total * before) % MOD
        inv_total = (inv_total * x) % MOD

    def inv_big(x):
        return inv_high[x - low]

    # Small inverses up to n
    inv = [0] * (n + 1)
    inv[1] = 1
    for i in range(2, n + 1):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    # Initial binomial:
    # C(r+n, n)
    T = 1
    for i in range(1, n + 1):
        T = T * (r + i) % MOD
        T = T * inv[i] % MOD

    ans = 0

    # A0 = C(p-1, m-1)
    # B0 = C(q-1, m-1)
    A0 = 1
    B0 = 1

    k = 0
    Tcur = T

    for m in range(1, p + 1):

        # Move to k = 2m - 1
        while k < 2 * m - 1:
            N = M - 2 * k
            Tcur = (
                Tcur
                * (N - n)
                * (N - n - 1)
                % MOD
                * inv_big(N)
                % MOD
                * inv_big(N - 1)
                % MOD
            )
            k += 1

        # Case a = b = m
        ans = (ans + 2 * A0 * B0 * Tcur) % MOD

        # Next binomial coefficients
        A1 = A0 * (p - m) % MOD * inv[m] % MOD if m < p else 0
        B1 = B0 * (q - m) % MOD * inv[m] % MOD if m < q else 0

        # Move to k = 2m
        if k < 2 * m:
            N = M - 2 * k
            Tcur = (
                Tcur
                * (N - n)
                * (N - n - 1)
                % MOD
                * inv_big(N)
                % MOD
                * inv_big(N - 1)
                % MOD
            )
            k += 1

        # Cases (m+1, m) and (m, m+1)
        ans = (
            ans
            + (A1 * B0 + A0 * B1) % MOD * Tcur
        ) % MOD

        A0, B0 = A1, B1

    return ans

print(W(10**6, 10**7, 10**8))
```--- 

## 3. Hướng dẫn sử dụng mã 

- Chúng tôi lặp lại số lần chạy có thể$a,b$. 
- Từ$|a-b|\le1$, chỉ một$O(p)$trường hợp tồn tại. 
- Hệ số nhị thức cho các phân vùng chạy được cập nhật theo cấp số nhân:$$\binom{n}{k+1} = \binom{n}{k} \frac{n-k}{k+1}$$- Thuật ngữ các ngôi sao và thanh lớn$$\binom{r-2k+p+q}{p+q}$$cũng được cập nhật dần dần bằng cách sử dụng:$$\binom{N-2}{n} = \binom{N}{n} \frac{(N-n)(N-n-1)}{N(N-1)}$$Điều này tránh được các bảng giai thừa lớn. 

Kiểm tra: 

-$W(2,2,4)=32$✓ 
-$W(4,4,44)=13908607644$✓
