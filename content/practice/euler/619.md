[Vấn đề dự án Euler 619](https://projecteuler.net/problem=619) 

##Giải pháp 

**Trả lời:**`857810883`Cho phép$$S=\{a,a+1,\dots,b\}$$và với mỗi số nguyên$n$, viết hệ số nguyên tố của nó thành$$n=\prod p_i^{e_i}.$$Tích của các số là một bình phương hoàn hảo nếu mọi số mũ nguyên tố trong tổng số đó đều là số chẵn. 

Xác định **vectơ chẵn lẻ không vuông** của$n$qua$\mathbb F_2$:$$v(n)=(e_i \bmod 2).$$Sau đó cho một tập hợp con$T\subseteq S$,$$\prod_{x\in T} x \text{ is a square} \iff \sum_{x\in T} v(x)=0 \quad (\text{over }\mathbb F_2).$$Vì vậy, vấn đề trở thành: 

> Đếm các tập con khác rỗng có tổng vectơ bằng 0. 

--- 

#1. Công thức đại số tuyến tính 

Giả sử có$$N=b-a+1$$tổng số và các vectơ$v(x)$trải rộng trên một không gian vectơ xếp hạng$r$. 

Bản đồ$$\phi:\mathbb F_2^N \to \mathbb F_2^m$$gửi vectơ chỉ báo tập hợp con tới tổng chẵn lẻ có kích thước hạt nhân$$2^{N-r}.$$Đây chính xác là các tập con có tích là hình vuông, bao gồm cả tập con rỗng. 

Vì thế$$C(a,b)=2^{N-r}-1.$$Vì vậy, toàn bộ vấn đề được quy về việc tính toán thứ hạng$r$qua$\mathbb F_2$. 

--- 

# 2. Tính toán các vectơ 

Đối với mỗi số$n$: 

- tính đến nó, 
- chỉ giữ lại các số nguyên tố có số mũ lẻ, 
- tập hợp các số nguyên tố đó là vectơ chẵn lẻ. 

Ví dụ:$$72=2^3\cdot 3^2$$có vectơ chẵn lẻ$$\{2\}$$vì chỉ có số mũ của$2$thật kỳ quặc. 

--- 

# 3. Loại bỏ Gaussian thưa thớt$\mathbb F_2$Mỗi vectơ thưa thớt (một vài thừa số nguyên tố lẻ), vì vậy chúng tôi lưu trữ nó dưới dạng một tập hợp các số nguyên tố. 

Loại bỏ Gaussian: 

- chọn số nguyên tố lớn nhất trong vectơ làm trục, 
- loại bỏ các vectơ cơ sở hiện có, 
- nếu vẫn còn khác 0 thì chèn vào cơ sở. 

Điều này tính toán thứ hạng một cách hiệu quả. 

--- 

#4. Triển khai Python```python
from math import isqrt

MOD = 1_000_000_007

def compute_C(a, b):
    N = b - a + 1

    # ------------------------------------------------------------
    # Smallest prime factor sieve
    # ------------------------------------------------------------
    spf = list(range(b + 1))

    for p in range(2, isqrt(b) + 1):
        if spf[p] == p:  # p is prime
            for x in range(p * p, b + 1, p):
                if spf[x] == x:
                    spf[x] = p

    # ------------------------------------------------------------
    # Sparse Gaussian elimination over F2
    # basis[pivot_prime] = set representing basis vector
    # ------------------------------------------------------------
    basis = {}
    rank = 0

    for value in range(a, b + 1):

        n = value
        vec = set()

        # Build squarefree parity vector
        while n > 1:
            p = spf[n]
            parity = 0

            while n % p == 0:
                n //= p
                parity ^= 1

            if parity:
                vec.symmetric_difference_update({p})

        # Eliminate using existing basis
        while vec:
            pivot = max(vec)

            if pivot in basis:
                vec ^= basis[pivot]
            else:
                basis[pivot] = vec
                rank += 1
                break

    # Number of square-product subsets
    return (pow(2, N - rank, MOD) - 1) % MOD

# ------------------------------------------------------------
# Checks from the problem statement
# ------------------------------------------------------------
print(compute_C(40, 55))       # 15
print(compute_C(1000, 1234))   # 975523611

# ------------------------------------------------------------
# Required answer
# ------------------------------------------------------------
print(compute_C(1_000_000, 1_234_567))
```--- 

#5. Hướng dẫn sử dụng mã 

###Sàng lọc SPF```python
spf = list(range(b + 1))
```Ban đầu giả sử mọi số đều là số nguyên tố. 

Sau đó:```python
if spf[x] == x:
    spf[x] = p
```lưu trữ hệ số nguyên tố nhỏ nhất của mọi số tổng hợp. 

Điều này cho phép nhân tố hóa nhanh chóng. 

--- 

### Xây dựng vectơ chẵn lẻ 

Đối với mỗi số:```python
while n % p == 0:
    n //= p
    parity ^= 1
```chỉ theo dõi tính chẵn lẻ của số mũ. 

Nếu chẵn lẻ là số lẻ thì số nguyên tố thuộc vectơ. 

--- 

### Loại bỏ Gaussian 

Mỗi vectơ được giảm bớt so với các trục hiện có:```python
vec ^= basis[pivot]
```bởi vì phép cộng kết thúc$\mathbb F_2$là XOR/sự khác biệt đối xứng. 

Nếu vẫn còn một vectơ khác 0 thì nó sẽ đóng góp một chiều độc lập mới.

# 6. Xác minh trên các ví dụ đã cho

- tổng số:$$N = 1234567 - 1000000 + 1 = 234568$$- Xếp hạng tính toán:$$r = 58242$$do đó$$C = 2^{234568-58242}-1 =2^{176326}-1 \pmod{10^9+7}.$$Đánh giá mang lại:$$857810883.$$---
