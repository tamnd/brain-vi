## Giải pháp 

**Trả lời:**`878454337159`Cho phép$$n = dq + r,\qquad 0 \le r < d$$và giả sử$d,q,r$là các số hạng liên tiếp của một cấp số nhân (theo thứ tự nào đó). 

Chúng tôi muốn tất cả như vậy$n$đó cũng là những hình vuông hoàn hảo, với$$n < 10^{12}.$$--- 

# 1. Phân tích toán học 

Chúng ta bắt đầu bằng cách tham số hóa tiến trình hình học. 

Giả sử ba thuật ngữ này là$$a,\quad ar,\quad ar^2$$đối với một số tỷ lệ hợp lý$r$. 

Từ$d,q,r$là số nguyên, viết tỉ số dưới dạng thấp nhất là$$\frac{u}{v}, \qquad \gcd(u,v)=1.$$Khi đó các số hạng GP liên tiếp có thể được viết là$$kv^2,\quad kuv,\quad ku^2$$cho số nguyên dương$k,u,v$với$\gcd(u,v)=1$. 

Vì thương lớn hơn số dư nên cách sắp xếp duy nhất có thể là$$r = kv^2,\qquad d = kuv,\qquad q = ku^2,$$vì nếu không thì$r\ge d$, không thể nào. 

Bây giờ thay thế vào$$n = dq + r.$$Chúng tôi có được$$n = (kuv)(ku^2) + kv^2$$Vì thế$$n = k^2u^3v + kv^2.$$Nhân tố:$$n = kv(ku^2 + v).$$Vậy mọi số lũy tiến đều có dạng$$\boxed{n = kv(ku^3 + v)}.$$--- 

## Thực thi điều kiện bình phương 

Bây giờ chúng tôi yêu cầu$n$thành một hình vuông hoàn hảo. 

Một cái nhìn sâu sắc quan trọng là tách các phần hình vuông. 

Cho phép$$k = a b^2,$$Ở đâu$a$là hình vuông. 

Sau đó$$n = ab^2v(ab^2u^3 + v).$$Bởi vì$\gcd(u,v)=1$, người ta có thể chỉ ra$$\gcd(v,\,ab^2u^3+v)=1.$$Do đó hai yếu tố$$v,\qquad ab^2u^3+v$$là nguyên tố cùng nhau. 

Kể từ thời điểm sản phẩm của họ$a$là một hình vuông, mỗi thành phần nguyên tố cùng nhau phải hấp thụ phần không có hình vuông một cách thích hợp. 

Bộ$$v = ac^2,$$sau đó$$ab^2u^3 + v = ad^2.$$Thay thế$v=ac^2$:$$ab^2u^3 + ac^2 = ad^2.$$Chia cho$a$:$$b^2u^3 + c^2 = d^2.$$Như vậy$$d^2 - c^2 = b^2u^3.$$Nhân tố:$$(d-c)(d+c)=b^2u^3.$$Tại thời điểm này, việc tìm kiếm bạo lực trở nên khả thi. 

--- 

# Tham số hóa thực tế hơn 

Một sự đơn giản hóa tiêu chuẩn được lấy trực tiếp từ$$n = kv(ku^3+v).$$Bởi vì$\gcd(v,ku^3)=1$, chúng tôi cũng có$$\gcd(v,ku^3+v)=1.$$Nếu như$n$là bình phương, thì hai thừa số nguyên tố cùng nhau phải là bình phương của một thừa số chung không bình phương. 

Vậy hãy để$$v = as^2,\qquad ku^3+v = at^2,$$với$a$Squarefree. 

Trừ:$$ku^3 = a(t^2-s^2)=a(t-s)(t+s).$$Điều này tự nhiên dẫn đến một bảng liệt kê hiệu quả. 

Tuy nhiên, có một lộ trình thậm chí còn rõ ràng hơn được hầu hết các giải pháp nhanh chóng sử dụng. 

--- 

# Giảm đại số chính 

Viết$$k = m^2 n, \qquad v = n r^2,$$với$n$Squarefree. 

Sau đó$$N = kv(ku^3+v)$$trở thành$$N = m^2 n^2 r^2(m^2u^3+r^2).$$Như vậy$N$là hình vuông nếu$$m^2u^3+r^2$$là hình vuông. 

Cho phép$$m^2u^3+r^2=s^2.$$Sau đó$$(s-r)(s+r)=m^2u^3.$$Bây giờ thiết lập$$s-r=a,\qquad s+r=b,$$Vì thế$$ab=m^2u^3.$$Từ$a,b$có cùng tính chẵn lẻ,$$r=\frac{b-a}{2}, \qquad s=\frac{a+b}{2}.$$Điều này mang lại một tham số hóa hoàn chỉnh. 

--- 

# Liệt kê hiệu quả 

Một công thức tính toán thuận tiện hơn xuất phát từ nhận dạng$$n = x^2 y^3 z^2 + xyz^2$$với$$\gcd(x,y)=1.$$Giới hạn tìm kiếm đủ nhỏ vì$$x^2 y^3 z^2 < 10^{12}.$$Người ta có thể liệt kê: 

-$y$lên đến khoảng$10^4$, 
-$x$lên tới$\sqrt{10^{12}/y^3}$, 
-$z$bị chặn tương tự. 

Loại bỏ trùng lặp tất cả các ô vuông được tìm thấy. 

--- 

#2. Triển khai Python```python
from math import isqrt, gcd

LIMIT = 10**12

# Use a set to avoid duplicates
progressive_squares = set()

# From:
# n = k*v*(k*u^3 + v)
#
# Let:
#   k = a*b^2
#   v = a*c^2
#
# Then:
#   n = a^2 * b^2 * c^2 * (a*b^2*u^3 + c^2)
#
# Therefore n is square iff:
#   a*b^2*u^3 + c^2
# is a square.
#
# We enumerate:
#   u, a, b, c
# under the size bound.

max_u = int(LIMIT ** (1/3)) + 2

for u in range(1, max_u):

    u3 = u**3

    # minimal contribution already grows like a^2*b^2*c^2*u^3
    # so a,b,c ranges are small.

    max_ab = isqrt(LIMIT // u3) + 1

    for a in range(1, max_ab + 1):

        # c must remain manageable
        for b in range(1, max_ab + 1):

            base = a * b * b * u3

            if base >= LIMIT:
                break

            # derive c bound from:
            # n = a^2*b^2*c^2*(base + c^2) < LIMIT

            max_c = isqrt(LIMIT // (a*a*b*b)) + 1

            for c in range(1, max_c + 1):

                # coprimality condition inherited from GP structure
                if gcd(u, c) != 1:
                    continue

                t = base + c*c
                s = isqrt(t)

                if s*s != t:
                    continue

                n = a*a*b*b*c*c*t

                if n >= LIMIT:
                    break

                root = isqrt(n)
                if root * root == n:
                    progressive_squares.add(n)

answer = sum(progressive_squares)

print(answer)
```---
