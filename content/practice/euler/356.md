[Vấn đề dự án Euler 356](https://projecteuler.net/problem=356) 

## Giải pháp 

**Trả lời:**`28010159`Hãy để rễ của$$g_n(x)=x^3-2^n x^2+n$$là$a_n,b_n,c_n$, Ở đâu$a_n$là nghiệm thực lớn nhất. 

Chúng tôi tìm kiếm$$\sum_{n=1}^{30}\left\lfloor a_n^{987654321}\right\rfloor$$modulo$10^8$. 

## 1. Phân tích toán học 

### Bước 1: Liên hệ sàn với tổng công suất 

Theo công thức Viète,$$a_n+b_n+c_n = 2^n,$$

$$a_nb_n+a_nc_n+b_nc_n=0,$$

$$a_nb_nc_n=-n.$$Vì$n\ge 2$, đa thức có một nghiệm dương lớn$a_n$, một nghiệm dương nhỏ$b_n\in(0,1)$và một nghiệm âm$c_n\in(-1,0)$. Vì$n=1$, rễ là$$\phi,\quad 1,\quad -\frac1\phi.$$Như vậy trong mọi trường hợp:$$0<b_n\le 1,\qquad -1<c_n<0,$$và vì số mũ$$m=987654321$$thật kỳ lạ,$$0<b_n^m+c_n^m<1.$$Xác định tổng lũy ​​thừa nguyên$$S_k = a_n^k+b_n^k+c_n^k.$$Sau đó$$a_n^m=S_m-(b_n^m+c_n^m),$$với$0<b_n^m+c_n^m<1$. Vì thế:$$\boxed{\lfloor a_n^m\rfloor = S_m-1.}$$Vì vậy chúng ta chỉ cần$S_m$. 

--- 

### Bước 2: Tìm phép truy toán cho$S_k$Mỗi gốc$r$thỏa mãn$$r^3=2^n r^2-n.$$nhân với$r^{k-3}$,$$r^k = 2^n r^{k-1} - n r^{k-3}.$$Tổng hợp cả ba gốc:$$\boxed{ S_k = 2^n S_{k-1} - n S_{k-3} } \qquad (k\ge 3).$$Giá trị ban đầu:$$S_0=3,$$

$$S_1=a_n+b_n+c_n=2^n,$$

$$S_2=(a_n+b_n+c_n)^2 -2(a_nb_n+a_nc_n+b_nc_n) =2^{2n}.$$Kể từ đây:$$S_0=3,\qquad S_1=2^n,\qquad S_2=2^{2n}.$$Vì chúng tôi chỉ cần **tám chữ số cuối** nên chúng tôi tính toán modulo truy hồi$$10^8.$$Sử dụng lũy ​​thừa ma trận:$$\begin{pmatrix} S_k\\ S_{k-1}\\ S_{k-2} \end{pmatrix} = \begin{pmatrix} 2^n & 0 & -n\\ 1&0&0\\ 0&1&0 \end{pmatrix} \begin{pmatrix} S_{k-1}\\ S_{k-2}\\ S_{k-3} \end{pmatrix}.$$lũy thừa điều này$3\times3$ma trận để cấp nguồn$m-2$cho$S_m$TRONG$O(\log m)$.

## 2. Triển khai Python```python
MOD = 10**8
M = 987654321

def mat_mul(A, B):
    """Multiply two 3x3 matrices modulo MOD."""
    return [
        [
            (
                A[i][0] * B[0][j]
                + A[i][1] * B[1][j]
                + A[i][2] * B[2][j]
            ) % MOD
            for j in range(3)
        ]
        for i in range(3)
    ]

def mat_pow(A, exponent):
    """Fast matrix exponentiation."""
    result = [
        [1, 0, 0],
        [0, 1, 0],
        [0, 0, 1]
    ]

    while exponent:
        if exponent & 1:
            result = mat_mul(result, A)

        A = mat_mul(A, A)
        exponent >>= 1

    return result

answer = 0

for n in range(1, 31):

    two_n = pow(2, n, MOD)

    # Transition matrix for:
    # S_k = 2^n * S_{k-1} - n * S_{k-3}
    transition = [
        [two_n, 0, (-n) % MOD],
        [1, 0, 0],
        [0, 1, 0]
    ]

    # Initial vector [S_2, S_1, S_0]
    initial = [
        pow(2, 2 * n, MOD),
        two_n,
        3
    ]

    # Compute S_M
    power_matrix = mat_pow(transition, M - 2)

    S_M = (
        power_matrix[0][0] * initial[0]
        + power_matrix[0][1] * initial[1]
        + power_matrix[0][2] * initial[2]
    ) % MOD

    # floor(a_n^M) = S_M - 1
    answer = (answer + S_M - 1) % MOD

print(answer)
```--- 

## 3. Hướng dẫn sử dụng mã 

-`mat_mul`nhân hai$3\times3$ma trận modulo$10^8$. 
-`mat_pow`tính toán lũy thừa ma trận bằng cách sử dụng lũy ​​thừa nhị phân trong$O(\log M)$. 
- Đối với mỗi$n=1,\dots,30$: 

- Xây dựng ma trận truy hồi$$\begin{pmatrix} 2^n & 0 & -n\\ 1&0&0\\ 0&1&0 \end{pmatrix}.$$- Sử dụng giá trị ban đầu:$$(S_2,S_1,S_0)=(2^{2n},2^n,3).$$- Tính toán$S_M$. 
- Thêm vào$S_M-1$, bởi vì$$\lfloor a_n^M\rfloor=S_M-1.$$### Kiểm tra ví dụ nhỏ 

cho$n=2$:$$a_2 = 3.86619826\ldots$$Sự lặp lại cho các giá trị số nguyên$S_k$, và thực sự$$\lfloor a_2^{11}\rfloor = S_{11}-1,$$phù hợp với tính toán số trực tiếp.
