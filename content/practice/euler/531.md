[Vấn đề dự án Euler 531](https://projecteuler.net/problem=531) 

##Giải pháp 

**Trả lời:**`4515432351156203105`Chúng ta cần tính toán$$\sum_{1000000 \le n < m < 1005000} f(n,m)$$Ở đâu$$f(n,m)=g(\phi(n),n,\phi(m),m),$$Và$g(a,n,b,m)$là nghiệm không âm nhỏ nhất của$$x\equiv a \pmod n,\qquad x\equiv b \pmod m,$$hoặc$0$nếu không có giải pháp tồn tại. 

Cách tiếp cận tự nhiên là: 

1. Tính trước hàm tổng Euler$\phi(n)$cho tất cả$n\in[10^6,1004999]$dùng sàng. 
2. Đối với mỗi cặp$(n,m)$, giải hệ thống CRT:$$x\equiv \phi(n)\pmod n,\qquad x\equiv \phi(m)\pmod m.$$3. Nếu các đồng dư không tương thích modulo$\gcd(n,m)$, đóng góp$0$. 
4. Mặt khác hãy tính nghiệm tối thiểu bằng cách sử dụng Định lý số dư Trung Hoa tổng quát. 

Mã Python chính xác được sử dụng:```python
from math import gcd

L = 1000000
R = 1005000

# Compute Euler phi values by sieve
phi = list(range(R + 1))

for i in range(2, R + 1):
    if phi[i] == i:  # prime
        for j in range(i, R + 1, i):
            phi[j] -= phi[j] // i

def crt(a, n, b, m):
    g = gcd(n, m)

    # No solution
    if (b - a) % g:
        return 0

    ng = n // g
    mg = m // g
    rhs = (b - a) // g

    # Solve ng * t ≡ rhs (mod mg)
    inv = pow(ng, -1, mg)
    t = (rhs * inv) % mg

    lcm = ng * m
    x = (a + n * t) % lcm
    return x

# Verify examples
print(crt(2,4,4,6))  # 10
print(crt(3,4,4,6))  # 0

total = 0

for n in range(L, R):
    an = phi[n]
    for m in range(n + 1, R):
        total += crt(an, n, phi[m], m)

print(total)
```Các ví dụ xác minh phù hợp với tuyên bố:
