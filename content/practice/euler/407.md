[Vấn đề dự án Euler 407](https://projecteuler.net/problem=407) 

## Giải pháp 

**Trả lời:**`39782849136421`Đối với một số nguyên$a$, sự phù hợp$$a^2 \equiv a \pmod n$$có nghĩa$$a(a-1)\equiv 0 \pmod n.$$Quan sát quan trọng là$a$Và$a-1$là nguyên tố cùng nhau nên mọi ước số nguyên tố của$n$phải chia **chính xác một** trong số chúng. 

--- 

# 1. Phân tích toán học 

Chúng tôi tìm kiếm$$M(n)=\max\{a<n : a^2\equiv a \pmod n\}.$$Chúng ta phải tính toán$$\sum_{n=1}^{10^7} M(n).$$--- 

## Bước 1 - Cấu trúc của tất cả các giải pháp 

hãy để$$n=\prod_{i=1}^k p_i^{e_i}.$$Bởi vì$$a(a-1)\equiv 0 \pmod{p_i^{e_i}},$$Và$\gcd(a,a-1)=1$, với mỗi lũy thừa nguyên tố ta phải có:$$a\equiv 0 \pmod{p_i^{e_i}} \quad\text{or}\quad a\equiv 1 \pmod{p_i^{e_i}}.$$Do đó, mọi giải pháp đều tương ứng với việc lựa chọn, độc lập cho từng hệ số công suất cơ bản, hoặc$0$hoặc$1$. 

Theo Định lý số dư Trung Hoa, có chính xác$$2^{\omega(n)}$$giải pháp, ở đâu$\omega(n)$là số các thừa số nguyên tố phân biệt. 

--- 

## Bước 2 - Viết lại với thừa số nguyên tố cùng nhau 

Phân chia quyền hạn chính của$n$thành hai phần nguyên tố cùng nhau:$$n = uv,\qquad \gcd(u,v)=1.$$Khi đó đẳng thức tương ứng thỏa mãn$$a\equiv 0\pmod u, \qquad a\equiv 1\pmod v.$$Viết$a=uk$. Sau đó$$uk\equiv 1\pmod v.$$Vì thế$$k\equiv u^{-1}\pmod v.$$Do đó giải pháp duy nhất modulo$n$là$$a=u\cdot u^{-1}\pmod v.$$Mọi người bình thường đều phát sinh theo cách này. 

Vì thế$$M(n)=\max_{uv=n,\ \gcd(u,v)=1} \left(u\cdot u^{-1}\pmod v\right).$$--- 

## Bước 3 - Tính toán hiệu quả 

Một yếu tố vũ phu cho mọi$n\le10^7$quá chậm. 

Thay vào đó: 

1. Xây dựng sàng có hệ số nguyên tố nhỏ nhất. 
2. Khôi phục các thừa số nguyên tố riêng biệt cho từng$n$. 
3. Tạo tất cả các tập hợp con của lũy thừa nguyên tố riêng biệt. 
4. For each coprime split$n=uv$: 

- tính toán nghịch đảo mô-đun$u^{-1}\pmod v$, 
- xây dựng bình thường, 
- tối đa hóa. 

Bởi vì$10^7$có nhiều nhất 8 thừa số nguyên tố riêng biệt nên số lượng tập hợp con rất nhỏ. 

Tổng độ phức tạp về cơ bản là thang đo tuyến tính.

#2. Triển khai Python```python
from math import prod

LIMIT = 10_000_000

# ---------------------------------------------------------
# Smallest prime factor sieve
# ---------------------------------------------------------
spf = list(range(LIMIT + 1))

for i in range(2, int(LIMIT ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, LIMIT + 1, step):
            if spf[j] == j:
                spf[j] = i

# ---------------------------------------------------------
# Extended Euclidean algorithm
# ---------------------------------------------------------
def invmod(a, m):
    """Return inverse of a modulo m."""
    x0, x1 = 1, 0
    b = m

    while b:
        q = a // b
        a, b = b, a % b
        x0, x1 = x1, x0 - q * x1

    return x0 % m

# ---------------------------------------------------------
# Factorization into prime powers
# Example:
#   12 -> [4, 3]
#   72 -> [8, 9]
# ---------------------------------------------------------
def prime_powers(n):
    res = []

    while n > 1:
        p = spf[n]
        pp = 1

        while n % p == 0:
            n //= p
            pp *= p

        res.append(pp)

    return res

# ---------------------------------------------------------
# Compute M(n)
# ---------------------------------------------------------
def M(n):
    if n == 1:
        return 0

    pp = prime_powers(n)
    k = len(pp)

    best = 1

    # Enumerate all subset products u
    for mask in range(1 << k):
        u = 1

        for i in range(k):
            if mask & (1 << i):
                u *= pp[i]

        v = n // u

        # trivial solutions 0 and 1
        if v == 1 or u == 1:
            continue

        # Solve:
        #   a ≡ 0 (mod u)
        #   a ≡ 1 (mod v)
        inv = invmod(u % v, v)

        a = u * inv

        if a > best:
            best = a

    return best

# ---------------------------------------------------------
# Main summation
# ---------------------------------------------------------
ans = 0

for n in range(1, LIMIT + 1):
    ans += M(n)

print(ans)
```---

## Liệt kê các lựa chọn CRT 

Mỗi lũy thừa có thể thuộc về: 

- hệ số chia$a$, 
- hoặc nhân tử chia$a-1$. 

Vì vậy, chúng tôi liệt kê tất cả các sản phẩm tập hợp con$u$. 

Sau đó:$$v = n/u.$$Từ$u$Và$v$là nguyên tố cùng nhau, chúng tôi giải quyết$$a \equiv 0 \pmod u, \qquad a \equiv 1 \pmod v.$$Viết$a=uk$:$$uk \equiv 1 \pmod v$$Vì thế$$k = u^{-1}\pmod v.$$Như vậy```python
a = u * invmod(u % v, v)
```đó là giải pháp CRT.

| 1 | 1 | 1 |

lớn nhất là:$$M(6)=4.$$phù hợp với tuyên bố.
