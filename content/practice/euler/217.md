[Vấn đề dự án Euler 217](https://projecteuler.net/problem=217) 

##Giải pháp 

**Trả lời:**`6273134`Cho phép$$t(n)=2n^2-1$$Rất tiếc - bối cảnh vấn đề sai. 

Thay vào đó chúng ta cần số lượng Project Euler 217:$$T(n)=\sum_{\substack{0\le x<10^n\\ x\text{ balanced}}} x$$trong đó một số được **cân bằng** nếu tổng của số đầu tiên của nó$\lceil k/2\rceil$các chữ số bằng tổng số cuối cùng của nó$\lceil k/2\rceil$chữ số. 

Chúng tôi tìm kiếm$$T(47)\bmod 3^{15}.$$--- 

# 1. Phân tích toán học 

##1.1 Tìm hiểu điều kiện cân bằng 

Giả sử một số có$k$chữ số. 

--- 

### Độ dài chẵn:$k=2m$Viết số đó dưới dạng$$N = L\cdot 10^m + R$$Ở đâu:

-$L$là người đầu tiên$m$chữ số, 
-$R$là cuối cùng$m$chữ số. 

Điều kiện cân bằng là:$$\text{digitSum}(L)=\text{digitSum}(R).$$--- 

### Độ dài lẻ:$k=2m+1$Viết số đó dưới dạng$$N = L\cdot 10^{m+1} + c\cdot 10^m + R$$Ở đâu$c$là chữ số ở giữa 

Định nghĩa so sánh đầu tiên$m+1$chữ số và cuối cùng$m+1$chữ số:$$\text{digitSum}(L)+c = c+\text{digitSum}(R).$$Chữ số ở giữa bị hủy, vì vậy một lần nữa:$$\text{digitSum}(L)=\text{digitSum}(R).$$Do đó, cả độ dài chẵn và lẻ đều giảm về cùng một điều kiện cốt lõi. 

--- 

# 1,2 DP cho tổng chữ số 

Xác định:$$A(m,s)=\#\{\text{length-}m\text{ digit strings with digit sum }s\}$$cho phép số 0 đứng đầu. 

Đồng thời xác định:$$B(m,s)=\sum (\text{all such }m\text{-digit numbers}).$$Những điều này thỏa mãn sự chuyển đổi:$$A(m+1,s+d) += A(m,s)$$Và$$B(m+1,s+d) += 10B(m,s)+dA(m,s).$$Tại sao? 

Chữ số nối thêm$d$biến đổi mọi số cũ$x$vào trong$$10x+d.$$Tổng hợp tất cả như vậy$x$:$$\sum (10x+d) = 10\sum x + d\cdot(\#\text{numbers}).$$--- 

# 1.3 Đóng góp có độ dài chẵn 

cho$2m$-Số cân bằng có chữ số: 

- nửa bên trái$L$phải không có số 0 đứng đầu, 
- nửa bên phải$R$có thể có số 0 đứng đầu, 
- cả hai phải có tổng chữ số bằng nhau$s$. 

Cho phép:

-$C_L(s)$= số nửa bên trái hợp lệ, 
-$S_L(s)$= tổng các nửa bên trái hợp lệ. 

Khi đó tổng số tiền đóng góp là$$\sum_s \left( S_L(s)\cdot 10^m \cdot A(m,s) + C_L(s)\cdot B(m,s) \right).$$Số hạng đầu tiên dành cho nửa bên trái được đặt ở chữ số cao; tài khoản thứ hai cho nửa bên phải. 

--- 

# 1.4 Đóng góp độ dài lẻ 

cho$2m+1$-Số cân bằng có chữ số:$$N=L\cdot10^{m+1}+c\cdot10^m+R.$$Để cố định$(L,R)$, tổng hợp lại$c=0,\dots,9$:$$\sum_c N = 10(L\cdot10^{m+1}+R) + 45\cdot10^m.$$Vì thế:$$\sum_s \left[ 10\left( S_L(s)\cdot10^{m+1}\cdot A(m,s) + C_L(s)\cdot B(m,s) \right) + 45\cdot10^m\cdot C_L(s)\cdot A(m,s) \right].$$--- 

#2. Triển khai Python```python
MOD = 3**15
N = 47

# Maximum half-length needed:
# floor(47/2) = 23, but we use 24 safely.
MAXM = 24
MAXS = 9 * MAXM

# A[m][s] = count of m-digit strings with digit sum s
# B[m][s] = sum of all such m-digit numbers
A = [[0] * (MAXS + 1) for _ in range(MAXM + 1)]
B = [[0] * (MAXS + 1) for _ in range(MAXM + 1)]

A[0][0] = 1

# Precompute powers of 10
pow10 = [1]
for _ in range(60):
    pow10.append(pow10[-1] * 10)

# Build DP tables
for m in range(MAXM):
    for s in range(9 * m + 1):

        count = A[m][s]
        total = B[m][s]

        if count == 0 and total == 0:
            continue

        for d in range(10):

            A[m + 1][s + d] += count

            # Appending digit d:
            # new_number = old_number * 10 + d
            B[m + 1][s + d] += total * 10 + count * d

def left_tables(m, s):
    """
    Count/sum of m-digit numbers with no leading zero
    and digit sum s.
    """

    count = 0
    total = 0

    for first in range(1, 10):

        if s - first < 0 or s - first > 9 * (m - 1):
            continue

        cnt = A[m - 1][s - first]

        # Numbers formed as:
        # first * 10^(m-1) + tail
        sm = B[m - 1][s - first] + cnt * first * pow10[m - 1]

        count += cnt
        total += sm

    return count, total

def balanced_sum_length(length):

    # One-digit case
    if length == 1:
        return 45

    # -------------------------------------------------
    # EVEN LENGTH = 2m
    # -------------------------------------------------
    if length % 2 == 0:

        m = length // 2
        ans = 0

        for s in range(9 * m + 1):

            left_count, left_sum = left_tables(m, s)

            ans += (
                left_sum * pow10[m] * A[m][s]
                + left_count * B[m][s]
            )

        return ans

    # -------------------------------------------------
    # ODD LENGTH = 2m+1
    # -------------------------------------------------
    else:

        m = length // 2
        ans = 0

        for s in range(9 * m + 1):

            left_count, left_sum = left_tables(m, s)

            pair_count = left_count * A[m][s]

            ans += (
                10 * (
                    left_sum * pow10[m + 1] * A[m][s]
                    + left_count * B[m][s]
                )
                + 45 * pow10[m] * pair_count
            )

        return ans

# Compute T(47)
answer = sum(
    balanced_sum_length(k)
    for k in range(1, N + 1)
) % MOD

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

##Xây dựng DP 

Chúng tôi xây dựng tất cả các chuỗi chữ số bằng cách nối thêm các chữ số$0\ldots9$.`A[m][s]`lưu trữ bao nhiêu chuỗi dài`m`có tổng chữ số`s`.`B[m][s]`lưu trữ tổng của tất cả các chuỗi như vậy được hiểu là số nguyên. 

--- 

##`left_tables(m, s)`Điều này tính toán: 

- số nửa bên trái hợp lệ, 
- tổng các nửa bên trái hợp lệ, 

với hạn chế là chữ số đầu tiên khác 0. 

Chúng tôi chọn rõ ràng chữ số hàng đầu$1\ldots9$. 

--- 

##`balanced_sum_length(length)`Tay cầm riêng biệt: 

- độ dài chẵn, 
- độ dài lẻ. 

Sử dụng các công thức rút ra ở trên.
