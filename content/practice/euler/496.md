##Giải pháp 

**Trả lời:**`2042473533769142717`Cho phép

-$a = BC$, 
-$b = CA$, 
-$c = AB$,

với$a,b,c\in \mathbb Z_{>0}$. 

Chúng tôi tìm kiếm tất cả các tam giác nguyên thỏa mãn$$b = DI,$$Ở đâu$I$là trung tâm và$D$là giao điểm thứ hai của đường phân giác của góc$AI$với đường tròn ngoại tiếp. 

--- 

## 1. Phân tích toán học 

### Bước 1: Thể hiện$DI$về mặt hình học 

Kể từ khi$A,I,D$là thẳng hàng và$D$nằm trên đường tròn ngoại tiếp, hãy sử dụng sức mạnh của một điểm tại$I$. 

Sức mạnh của tâm đối với đường tròn ngoại tiếp là$$IA\cdot ID = 2Rr,$$Ở đâu$R$là bán kính đường tròn và$r$là bán kính nội bộ. 

Cũng,$$IA = \frac{r}{\sin(A/2)}.$$Kể từ đây$$ID = \frac{2Rr}{IA} = 2R\sin(A/2).$$điều kiện$AC = DI$trở thành$$b = 2R\sin(A/2).$$Nhưng từ định luật sin,$$b = 2R\sin B.$$Như vậy$$\sin B = \sin(A/2).$$Vì các góc của tam giác nằm trong$(0,\pi)$, khả năng hợp lệ duy nhất là$$B = \frac A2.$$Vậy điều kiện tương đương với:$$A = 2B.$$--- 

### Bước 2: Chuyển điều kiện góc sang phương trình Diophantine 

Theo định luật sin,$$\frac{a}{\sin A} = \frac{b}{\sin B}.$$Từ$A=2B$,$$a = b\frac{\sin(2B)}{\sin B} = 2b\cos B.$$Vì thế$$\cos B = \frac{a}{2b}.$$Hiện nay$$c = b\frac{\sin(3B)}{\sin B} = b(4\cos^2B-1).$$Thay thế$\cos B = a/(2b)$:$$c = b\left(\frac{a^2}{b^2}-1\right) = \frac{a^2-b^2}{b}.$$Sắp xếp lại sẽ cho phương trình chính:$$a^2 = b(b+c).$$Đây là đặc tính chính xác. 

--- 

### Bước 3: Tham số hóa 

hãy để$$g = \gcd(b,b+c).$$Viết$$b = g u,\qquad b+c = gv,$$với$\gcd(u,v)=1$. 

Sau đó$$a^2 = g^2 uv.$$Từ$u$Và$v$là nguyên tố cùng nhau và tích của chúng là hình vuông, cả hai đều phải là hình vuông:$$u=m^2,\qquad v=n^2,$$với$\gcd(m,n)=1$. 

Do đó mọi giải pháp đều$$\boxed{ a = gmn,\quad b = gm^2,\quad c = g(n^2-m^2) }$$với$$m<n<2m, \qquad \gcd(m,n)=1.$$(Sự bất bình đẳng$n<2m$xuất phát từ bất đẳng thức tam giác/góc dương.) 

Ví dụ: 

-$m=2,n=3,g=1$cho$$(a,b,c)=(6,4,5),$$phù hợp với ví dụ. 

--- 

### Bước 4: Công thức tính tổng 

Đối với coprime cố định$(m,n)$,$$a = gmn.$$Tất cả các bội số với$$gmn \le L$$được phép. 

Cho phép$$K=\left\lfloor \frac{L}{mn}\right\rfloor.$$Đóng góp của cặp nguyên thủy này:$$\sum_{g=1}^{K} gmn = mn\cdot \frac{K(K+1)}2.$$Như vậy$$F(L) = \sum_{\substack{m<n<2m\\ \gcd(m,n)=1}} mn\cdot \frac{K(K+1)}2, \quad K=\left\lfloor\frac{L}{mn}\right\rfloor.$$Để đánh giá một cách hiệu quả cho$L=10^9$, chúng tôi tránh lặp lại tất cả$n$trực tiếp và sử dụng phép đảo ngược Möbius để tính tổng các số nguyên nguyên tố cùng nhau trong phạm vi:$$\sum_{\substack{x\le n\le y\\(n,m)=1}} n.$$Điều này làm giảm thời gian chạy xuống còn vài giây.

## 2. Triển khai Python```python
from math import isqrt

def F(L):
    M = isqrt(L)

    # Möbius function up to sqrt(L)
    mu = [0] * (M + 1)
    mu[1] = 1
    primes = []
    composite = [False] * (M + 1)

    for i in range(2, M + 1):
        if not composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > M:
                break

            composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break

            mu[v] = -mu[i]

    # divisors with nonzero Möbius values
    divisors = [[] for _ in range(M + 1)]

    for d in range(1, M + 1):
        if mu[d] == 0:
            continue

        coeff = mu[d] * d

        for m in range(d, M + 1, d):
            divisors[m].append((d, coeff))

    def triangular(k):
        return k * (k + 1) // 2

    total = 0

    for m in range(1, M + 1):

        limit = min(2 * m - 1, L // m)
        if limit <= m:
            continue

        divs = divisors[m]

        # Sum of integers <= N coprime to m
        def coprime_sum(N):
            s = 0
            for d, coeff in divs:
                t = N // d
                s += coeff * (t * (t + 1) // 2)
            return s

        n = m + 1

        # Group intervals where floor(L/(m*n)) is constant
        while n <= limit:
            k = L // (m * n)
            r = min(limit, L // (m * k))

            sum_n = coprime_sum(r) - coprime_sum(n - 1)

            total += m * triangular(k) * sum_n

            n = r + 1

    return total

print(F(15))      # 45
print(F(10**9))
```--- 

## 3. Hướng dẫn sử dụng mã 

### Tính toán trước Möbius 

Chúng tôi sàng lọc hàm Möbius lên đến$\sqrt L$. 

Điều này cho phép chúng tôi đánh giá:$$\sum_{\gcd(n,m)=1} n$$sử dụng bao gồm-loại trừ:$$\sum_{d\mid m} \mu(d)d \cdot \frac{\lfloor N/d\rfloor(\lfloor N/d\rfloor+1)}2.$$--- 

### Đếm các hình tam giác nguyên thủy 

Chúng tôi lặp đi lặp lại$m$và với mỗi:$$m<n<2m.$$Từ$$mn\le L,$$chúng tôi giới hạn$n$Tại$$\min(2m-1,\lfloor L/m\rfloor).$$Thay vì kiểm tra mọi$n$, chúng tôi nhóm các khoảng trong đó$$\left\lfloor \frac{L}{mn}\right\rfloor$$là hằng số, làm cho thuật toán nhanh. 

--- 

### Ví dụ xác minh 

cho$L=15$, chương trình tìm thấy chính xác:$$(6,4,5), (12,8,10), (12,9,7), (15,9,16),$$tổng của ai$BC$giá trị là:$$6+12+12+15=45.$$Chính xác.
