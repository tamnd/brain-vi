# Phân tích toán học 

Nhận xét quan trọng là trò chơi hoàn toàn sụp đổ theo kiểu phân loại chẵn lẻ. 

Cho phép$$N=10^7,\qquad N_o=\frac N2,\qquad N_a=\frac N4.$$Từ$N\equiv 0\pmod 4$, công thức tính đầy đủ trở thành:$$\boxed{ \text{Ans} = E_{\text{tot}} - E_{\text{lost}} + O_{\text{win}} \pmod M }$$Ở đâu$M=1234567891$. 

Ba mảnh đó là:$$E_{\text{tot}} = \sum_{m=0}^{N_o} \binom{N+2m-1}{2m},$$

$$E_{\text{lost}} = \frac12 \sum_{r=0}^{N_a} \binom{N_o}{2r} \binom{3N_o-r}{N_o-r} + \frac12 \binom{5N_a}{N_o},$$

$$O_{\text{win}} = \frac12 \sum_{r=0}^{N_a-1} \binom{N_o}{2r+1} \binom{3N_o-1-r}{N_o-1-r}.$$Như vậy$$\boxed{ \text{Ans} = \sum_{m=0}^{N_o}\binom{N+2m-1}{2m} -\frac12\sum_{r=0}^{N_a}\binom{N_o}{2r}\binom{3N_o-r}{N_o-r} -\frac12\binom{5N_a}{N_o} +\frac12\sum_{r=0}^{N_a-1}\binom{N_o}{2r+1}\binom{3N_o-1-r}{N_o-1-r} }$$modulo$M$.

# Tính toán hiệu quả 

Bảng giai thừa trực tiếp lên tới$2\times 10^7$có thể nhưng nặng về bộ nhớ. 

Thay vào đó, hãy tính toán từng số hạng tổng theo cách đệ quy. 

Ví dụ:$$T_m=\binom{N+2m-1}{2m}$$thỏa mãn$$T_{m+1} = T_m \cdot \frac{(N+2m)(N+2m+1)}{(2m+1)(2m+2)}.$$Tương tự:$$A_r = \binom{N_o}{2r} \binom{3N_o-r}{N_o-r}$$thỏa mãn$$A_{r+1} = A_r \cdot \frac{(N_o-2r)(N_o-2r-1)} {(2r+1)(2r+2)} \cdot \frac{N_o-r}{3N_o-r}.$$Và$$B_r = \binom{N_o}{2r+1} \binom{3N_o-1-r}{N_o-1-r}$$thỏa mãn$$B_{r+1} = B_r \cdot \frac{(N_o-2r-1)(N_o-2r-2)} {(2r+2)(2r+3)} \cdot \frac{N_o-1-r}{3N_o-1-r}.$$Bởi vì mô đun là số nguyên tố nên tất cả các phép chia đều là nghịch đảo mô đun.

#Triển khai Python```python
MOD = 1234567891

N = 10_000_000
No = N // 2
Na = N // 4

# modular inverses up to 20,000,000
LIMIT = 20_000_001
inv = [0] * LIMIT
inv[1] = 1

for i in range(2, LIMIT):
    inv[i] = (MOD - MOD // i) * inv[MOD % i] % MOD

inv2 = (MOD + 1) // 2

# ---------------------------------------------------
# S1 = sum C(N+2m-1, 2m)
# ---------------------------------------------------

t = 1
S1 = 1

for m in range(No):
    t = t * (N + 2*m) % MOD
    t = t * (N + 2*m + 1) % MOD
    t = t * inv[2*m + 1] % MOD
    t = t * inv[2*m + 2] % MOD

    S1 += t
    S1 %= MOD

# ---------------------------------------------------
# Compute C(3No, No)
# ---------------------------------------------------

C3 = 1
for k in range(1, No + 1):
    C3 = C3 * (2*No + k) % MOD
    C3 = C3 * inv[k] % MOD

# ---------------------------------------------------
# L1 terms
# ---------------------------------------------------

A = C3
sumA = A

for r in range(Na):
    A = A * (No - 2*r) % MOD
    A = A * (No - 2*r - 1) % MOD
    A = A * inv[2*r + 1] % MOD
    A = A * inv[2*r + 2] % MOD
    A = A * (No - r) % MOD
    A = A * inv[3*No - r] % MOD

    sumA += A
    sumA %= MOD

# ---------------------------------------------------
# L2 = C(5Na, No)
# ---------------------------------------------------

L2 = 1
for k in range(1, No + 1):
    L2 = L2 * (5*Na - No + k) % MOD
    L2 = L2 * inv[k] % MOD

# ---------------------------------------------------
# Odd winning terms
# ---------------------------------------------------

inv3 = pow(3, MOD - 2, MOD)

B = C3 * inv3 % MOD
sumB = B

for r in range(Na - 1):
    B = B * (No - 2*r - 1) % MOD
    B = B * (No - 2*r - 2) % MOD
    B = B * inv[2*r + 2] % MOD
    B = B * inv[2*r + 3] % MOD
    B = B * (No - 1 - r) % MOD
    B = B * inv[3*No - 1 - r] % MOD

    sumB += B
    sumB %= MOD

# ---------------------------------------------------
# Final answer
# ---------------------------------------------------

ans = (
    S1
    - (sumA + L2) * inv2
    + sumB * inv2
) % MOD

print(ans)
```---

$$E_{\text{lost}}=10+5=15,$$
