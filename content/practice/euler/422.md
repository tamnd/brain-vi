[Vấn đề dự án Euler 422](https://projecteuler.net/problem=422) 

## Giải pháp 

**Trả lời:**`92060460`Cho phép$$Q(x,y)=12x^2+7xy-12y^2.$$Hyperbol là$$H:\quad Q(x,y)=625,$$Và$X=(7,1)\in H$. 

Chúng tôi xác định$P_n$đệ quy theo điều kiện hình học: 

-$P_1=(13,\tfrac{61}{4})$, 
-$P_2=(-\tfrac{43}{6},-4)$,
- vì$n>2$,$P_n$là giao điểm thứ hai của$H$với đường đi qua$P_{n-1}$song song với$XP_{n-2}$. 

Chúng ta phải tính toán$P_n$vì$$n=11^{14}$$và trở về$$(a+b+c+d)\bmod 1{,}000{,}000{,}007$$Ở đâu$$P_n=\left(\frac ab,\frac cd\right)$$trong điều kiện thấp nhất. 

--- 

## 1. Phân tích toán học 

### Bước 1: Tham số hóa hyperbol thông qua$X$Đi một dòng qua$X=(7,1)$có độ dốc$u$:$$(x,y)=(7+t,1+ut).$$Thay thế vào$Q(x,y)=625$:$$12(7+t)^2+7(7+t)(1+ut)-12(1+ut)^2=625.$$Bao thanh toán mang lại:$$t\left(12tu^2-7tu-12t-25u-175\right)=0.$$Một gốc là$t=0$(điểm$X$); giao lộ thứ hai là$$t=\frac{25u+175}{12u^2-7u-12}.$$Như vậy mọi điểm trên$H$(trừ hướng tiệm cận) tương ứng với một tham số$u$. 

Các hệ số mẫu số bậc hai:$$12u^2-7u-12 = 12\left(u-\frac43\right)\left(u+\frac34\right).$$Điều này gợi ý sự thay thế$$z = \frac{u-\frac43}{u+\frac34}.$$Giải quyết cho$u$,$$u=\frac{\frac43+\frac34 z}{1-z}.$$Việc thay thế vào tọa độ điểm sẽ đơn giản hóa rất tốt:$$x=3z+\frac4z, \qquad y=\frac{16}{3z}-\frac94 z.$$--- 

### Bước 2: Tìm phép truy toán trong$z_n$Cho phép$z_n$tương ứng với$P_n$. 

Điều kiện “$P_nP_{n-1}$song song với$XP_{n-2}$” có thể được dịch theo đại số. 

Sau khi thay thế và đơn giản hóa, phép truy toán trở thành:$$z_n=\frac{4z_{n-2}}{3z_{n-1}}.$$Giá trị ban đầu:$$z_1=\frac13, \qquad z_2=-\frac89.$$Kiểm tra:$$z_3 = \frac{4(1/3)}{3(-8/9)} = -\frac12,$$

$$z_4 = \frac{4(-8/9)}{3(-1/2)} = \frac{64}{27},$$phù hợp với dữ liệu vấn đề. 

--- 

### Bước 3: Dạng số mũ nguyên tố 

Vì mọi thứ bắt đầu như sức mạnh của$2$Và$3$, viết$$z_n=\pm 2^{A_n}3^{B_n}.$$Sự tái phát mang lại:$$A_n=A_{n-2}-A_{n-1}+2,$$

$$B_n=B_{n-2}-B_{n-1}-1,$$với$$A_1=0,\ A_2=3,$$

$$B_1=-1,\ B_2=-2.$$Vì$n=11^{14}$: 

-$n$thật kỳ lạ, 
-$n\equiv 1\pmod 3$,

Vì thế$z_n>0$, và với số lẻ lớn$n$,$$A_n<0,\qquad B_n>0.$$Như vậy$$z_n=\frac{3^{B_n}}{2^{-A_n}}.$$Cho phép$$p=3^{B_n}, \qquad q=2^{-A_n}.$$Sau đó$$z_n=\frac pq.$$Tọa độ trở thành:$$x=\frac{3p^2+4q^2}{pq},$$

$$y=\frac{64q^2-27p^2}{12pq}.$$Đối với số lẻ$n$ở đây, cả hai phân số đều đã được giảm. 

--- 

### Bước 4: Tính lũy thừa mô đun 

Chúng tôi chỉ cần modulo tổng cuối cùng$$M=1{,}000{,}000{,}007.$$Từ$M$là số nguyên tố, số mũ được giảm modulo$M-1$. 

Phép lũy thừa ma trận nhanh trên các phép truy toán affine cho:$$A_n \equiv 852174610 \pmod{M-1},$$

$$B_n \equiv 218412851 \pmod{M-1}.$$Từ$A_n<0$,$$-A_n \equiv 147825396 \pmod{M-1}.$$Kể từ đây$$p\equiv 3^{218412851}\pmod M,$$

$$q\equiv 2^{147825396}\pmod M.$$Sau đó:$$a=3p^2+4q^2,$$

$$b=pq,$$

$$c=64q^2-27p^2,$$

$$d=12pq.$$Cuối cùng:$$(a+b+c+d)\bmod M = 92060460.$$--- 

## 2. Triển khai Python```python
MOD = 1_000_000_007
PHI = MOD - 1

n = 11**14

def matrix_mul(A, B, mod):
    """Multiply two 3x3 matrices modulo mod."""
    return [
        [
            sum(A[i][k] * B[k][j] for k in range(3)) % mod
            for j in range(3)
        ]
        for i in range(3)
    ]

def recurrence_mod(n, x1, x2, c):
    """
    Solve:
        x_n = x_{n-2} - x_{n-1} + c
    modulo PHI.
    """
    if n == 1:
        return x1 % PHI
    if n == 2:
        return x2 % PHI

    # State vector:
    # [x_n, x_{n-1}, 1]
    M = [
        [-1 % PHI, 1, c % PHI],
        [1, 0, 0],
        [0, 0, 1]
    ]

    # Fast exponentiation
    power = n - 2
    result = [
        [1, 0, 0],
        [0, 1, 0],
        [0, 0, 1]
    ]

    while power:
        if power & 1:
            result = matrix_mul(result, M, PHI)
        M = matrix_mul(M, M, PHI)
        power >>= 1

    vec = [x2 % PHI, x1 % PHI, 1]

    xn = sum(result[0][i] * vec[i] for i in range(3)) % PHI
    return xn

# Compute exponent residues
A_mod = recurrence_mod(n, 0, 3, 2)
B_mod = recurrence_mod(n, -1, -2, -1)

# Since A_n is negative for this n
exp2 = (-A_mod) % PHI
exp3 = B_mod

p = pow(3, exp3, MOD)
q = pow(2, exp2, MOD)

# Coordinates modulo MOD
a = (3 * p * p + 4 * q * q) % MOD
b = (p * q) % MOD

c = (64 * q * q - 27 * p * p) % MOD
d = (12 * p * q) % MOD

answer = (a + b + c + d) % MOD

print(answer)
```---
