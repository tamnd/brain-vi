[Vấn đề dự án Euler 341](https://projecteuler.net/problem=341) 

##Giải pháp 

**Trả lời:**`56098610614277014`Cho phép$G(n)=1+G\bigl(n-G(G(n-1))\bigr)$là phép truy toán tiêu chuẩn cho dãy Golomb (có giá trị đối với$n>1$), với$G(1)=1$. 

Chúng tôi muốn tính toán$$\sum_{1 \le n < 10^6} G(n^3).$$Thử thách đó chính là$n^3$đạt gần như$10^{18}$, do đó việc tạo trực tiếp chuỗi theo chỉ mục đó là không thể. 

## 1. Phân tích toán học 

### Bước 1: Tìm hiểu trình tự Golomb 

Thuộc tính xác định cho biết: 

> số nguyên$k$xuất hiện chính xác$G(k)$lần. 

Vậy nếu$G(k)=4$, thì giá trị$k$xảy ra bốn lần trong chuỗi. 

Xác định hàm điểm cuối tích lũy$$S(k)=\sum_{i=1}^{k} G(i).$$Sau đó:

-$k$chiếm vị trí$$S(k-1)+1,\dots,S(k),$$- Vì vậy$$G(n)=k \quad\Longleftrightarrow\quad S(k-1)<n\le S(k).$$Vì vậy tính toán$G(n^3)$giảm xuống việc tìm kiếm đầu tiên$k$với$$S(k)\ge n^3.$$--- 

### Bước 2: Tránh tạo tối đa$10^{18}$Một cách tiếp cận ngây thơ sẽ tính toán tất cả$S(k)$cho đến khi$10^{18}$, nhưng điều đó sẽ đòi hỏi khoảng$10^{11}$giá trị - không thể. 

Quan sát chính là: 

Nếu$G(r)=L$, thì giá trị$r$xảy ra chính xác$L$lần giữa các chỉ số$k$. 

Điều đó có nghĩa là có cả một **khối**$L$liên tiếp$k$-giá trị mà$$G(k)=r.$$Bên trong khối đó: 

-$S(k)$tăng chính xác$r$mỗi bước, 
- do đó các giá trị tích lũy tạo thành một cấp số cộng. 

Do đó chúng ta có thể xử lý toàn bộ khối cùng một lúc thay vì một khối$k$tại một thời điểm. 

Từ$G(r)$chỉ tăng lên khoảng vài triệu, tạo ra$G(r)$đến kích thước cần thiết là hoàn toàn khả thi. 

--- 

### Bước 3: Xử lý khối hiệu quả 

Giả sử chúng ta đang ở trong một khối có: 

-$G(k)=r$, 
- chiều dài khối là$L=G(r)$. 

Sau đó:$$S(k)$$tiến bộ theo từng bước$r$. 

Nếu chúng ta đã biết tổng tích lũy trước khối, giả sử$S_0$, thì điểm cuối của khối là$$S_0 + Lr.$$Đối với một khối lập phương$c=n^3$trong phạm vi này, chỉ số chính xác là$$k = k_0 + \left\lceil \frac{c-S_0}{r} \right\rceil,$$Ở đâu$k_0$là chỉ mục trước khi khối bắt đầu. 

Vì chỉ có$999{,}999$hình khối, chúng ta có thể quét qua chúng một lần.

## 2. Triển khai Python```python
def solve(limit=10**6):
    """
    Compute:
        sum(G(n^3)) for 1 <= n < limit
    where G is Golomb's self-describing sequence.
    """

    # Golomb values, 1-indexed
    G = [0, 1]  # G(1) = 1

    total = 0

    # Current cube pointer: n^3
    n = 1
    cube = 1

    # We have already processed k = 1
    # S(1) = 1
    current_k = 1
    current_S = 1

    # Handle cubes <= S(1)
    while n < limit and cube <= 1:
        total += 1
        n += 1
        cube = n**3

    r = 2

    while n < limit:
        # Generate G(r)
        g_r = 1 + G[r - G[G[r - 1]]]
        G.append(g_r)

        # This block has length G(r)
        block_length = g_r

        # End of cumulative range for this block
        block_end_S = current_S + block_length * r

        # Process all cubes that fall in this block
        while n < limit and cube <= block_end_S:
            # Ceiling division:
            # j = ceil((cube - current_S) / r)
            j = (cube - current_S + r - 1) // r

            # Corresponding k-value
            total += current_k + j

            n += 1
            cube = n**3

        # Move to next block
        current_k += block_length
        current_S = block_end_S
        r += 1

    return total

# Verification checks
print(solve(1000))     # should be 153506976
print(solve(10**6))
```--- 

## 3. Hướng dẫn sử dụng mã 

### Xây dựng giá trị Golomb```python
g_r = 1 + G[r - G[G[r - 1]]]
```Đây là sự tái diễn Golomb cổ điển:$$G(r) = 1 + G(r - G(G(r-1))).$$Chúng tôi chỉ tạo ra nhiều thuật ngữ nếu cần. 

--- 

### Khối xử lý 

Nếu$G(r)=L$, thì giá trị$r$lặp lại$L$lần giữa các chỉ số liên tiếp$k$. 

Thay vì lặp đi lặp lại mỗi$k$, chúng tôi xử lý toàn bộ khối:```python
block_end_S = current_S + block_length * r
```bởi vì mỗi bước tăng lên$S(k)$chính xác$r$. 

--- 

### Tìm vị trí của khối lập phương 

Nếu$c=n^3$nằm trong khối hiện tại:```python
j = (cube - current_S + r - 1) // r
```tính toán$$\left\lceil \frac{c-S_0}{r} \right\rceil,$$phần bù bên trong khối. 

Sau đó:```python
total += current_k + j
```thêm giá trị Golomb chính xác.
