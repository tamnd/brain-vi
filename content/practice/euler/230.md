-$F_0=A$-$F_1=B$-$F_n=F_{n-1}F_{n-2}$vì$n\ge2$trong đó vị trí kề nhau có nghĩa là nối. 

Chúng ta được yêu cầu tính các chữ số bên trong hệ thống từ giống Fibonacci này.

# 1. Phân tích toán học 

## Độ dài từ Fibonacci 

hãy để$L_n=|F_n|$, chiều dài của$n$-từ thứ. 

Vì phép nối thêm độ dài,$$L_n=L_{n-1}+L_{n-2}$$với$$L_0=L_1=100$$Như vậy$$L_n=100F_{n+1}$$Ở đâu$F_k$là các số Fibonacci thông thường. 

Vì vậy chiều dài tăng lên nhanh chóng. 

--- 

## Định vị một chữ số theo cách đệ quy 

Giả sử chúng ta muốn$m$-chữ số thứ. 

Chọn cái nhỏ nhất$k$như vậy$$L_k \ge m.$$Bởi vì$$F_k = F_{k-1}F_{k-2},$$cái đầu tiên$L_{k-1}$chữ số đến từ$F_{k-1}$, và các chữ số còn lại đến từ$F_{k-2}$. 

Vì vậy: 

- nếu$m \le L_{k-1}$, chữ số nằm bên trong$F_{k-1}$; 
- nếu không thì nó nằm bên trong$F_{k-2}$ở vị trí$$m-L_{k-1}.$$Điều này mang lại sự giảm đệ quy:$$(k,m)\to \begin{cases} (k-1,m), & m\le L_{k-1}\\[4pt] (k-2,m-L_{k-1}), & m>L_{k-1} \end{cases}$$Cuối cùng chúng tôi đạt được: 

-$k=0$: chữ số ở trong$A$, 
-$k=1$: chữ số ở trong$B$. 

Điều này tránh việc xây dựng các chuỗi khổng lồ.

#2. Triển khai Python```python
A = (
    "14159265358979323846264338327950288419716939937510"
    "58209749445923078164062862089986280348253421170679"
)

B = (
    "82148086513282306647093844609550582231725359408128"
    "48111745028410270193852110555964462294895493038196"
)

# ---------------------------------------------------------
# Precompute Fibonacci-word lengths
# ---------------------------------------------------------

lengths = [100, 100]

while lengths[-1] < 10**18:
    lengths.append(lengths[-1] + lengths[-2])

# ---------------------------------------------------------
# Compute D_A,B(n)
# ---------------------------------------------------------

def D(n):
    """
    Return the nth digit (1-indexed) in the first Fibonacci
    word whose length is at least n.
    """

    # Find smallest k with lengths[k] >= n
    k = 0
    while lengths[k] < n:
        k += 1

    # Reduce recursively without building strings
    while k > 1:

        # F_k = F_{k-1} + F_{k-2}

        if n <= lengths[k - 2]:
            k -= 2
        else:
            n -= lengths[k - 2]
            k -= 1

    # Base cases
    if k == 0:
        return int(A[n - 1])
    else:
        return int(B[n - 1])

# ---------------------------------------------------------
# Evaluate the required sum
# ---------------------------------------------------------

answer = 0

for n in range(18):
    N = (127 + 19 * n) * (7 ** n)
    answer += (10 ** n) * D(N)

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

## Tính toán trước độ dài```python
lengths = [100, 100]
```Vì cả hai$A$Và$B$có chiều dài$100$.```python
lengths.append(lengths[-1] + lengths[-2])
```thực hiện phép lặp Fibonacci cho độ dài nối. 

---

## Chức năng`D(n)`Đầu tiên:```python
while lengths[k] < n:
    k += 1
```tìm từ Fibonacci đầu tiên đủ lớn để chứa vị trí mong muốn. 

Sau đó:```python
if n <= lengths[k - 2]:
    k -= 2
else:
    n -= lengths[k - 2]
    k -= 1
```sử dụng sự phân hủy$$F_k = F_{k-1}F_{k-2}$$đi xuống đệ quy cho đến khi chỉ$A$hoặc$B$vẫn còn. 

Cuối cùng:```python
A[n - 1]
```hoặc```python
B[n - 1]
```trả về chữ số (Python sử dụng chỉ mục 0).
