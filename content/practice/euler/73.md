**Trả lời:**`7295372`## 1. Phân tích toán học 

Chúng tôi muốn số **phân số thích hợp giảm**$$\frac{n}{d}$$như vậy$$\frac13 < \frac nd < \frac12 \quad\text{and}\quad \gcd(n,d)=1,$$cho tất cả các mẫu số$$d \le 12000.$$### Bước 1: Tìm phạm vi tử số cho mỗi mẫu số 

Sửa mẫu số$d$. Chúng tôi cần:$$\frac13 < \frac nd < \frac12.$$Nhân với$d$:$$\frac d3 < n < \frac d2.$$Vậy tử số hợp lệ là số nguyên trong$$\left(\left\lfloor \frac d3 \right\rfloor + 1\right) \le n \le \left\lceil \frac d2 \right\rceil - 1.$$Nhưng chúng ta cũng phải yêu cầu:$$\gcd(n,d)=1.$$Do đó với mỗi mẫu số$d$, chúng tôi đếm số nguyên$n$trong khoảng này nguyên tố cùng nhau$d$. 

--- 

### Bước 2: Phương pháp đếm trực tiếp 

Một thuật toán đơn giản là: 

Đối với mỗi mẫu số$d=2,3,\dots,12000$: 

1. Tính tử số nhỏ nhất có thể:$$n_{\min}=\left\lfloor \frac d3 \right\rfloor +1$$2. Tính tử số lớn nhất có thể:$$n_{\max}=\left\lfloor \frac{d-1}{2}\right\rfloor$$3. Với mọi số nguyên$n\in[n_{\min},n_{\max}]$: 

- Kiểm tra xem$$\gcd(n,d)=1.$$- Nếu có thì tính đi. 

Không gian tìm kiếm có thể quản lý được vì: 

-$d \le 12000$- Độ dài khoảng trung bình khoảng$d/6$Tổng công việc là khoảng vài chục triệu lần kiểm tra gcd mà Python có thể xử lý một cách thoải mái. 

Một giải pháp lý thuyết số phức tạp hơn sử dụng **chuỗi Farey** hoặc số lượng đảo ngược Möbius, nhưng cách tiếp cận gcd bạo lực đã đủ nhanh.

## 2. Triển khai Python```python
from math import gcd

def count_fractions(limit):
    total = 0

    # Check every denominator
    for d in range(2, limit + 1):

        # Numerators strictly between 1/3 and 1/2
        n_min = d // 3 + 1
        n_max = (d - 1) // 2

        # Count reduced fractions
        for n in range(n_min, n_max + 1):
            if gcd(n, d) == 1:
                total += 1

    return total

# Problem answer
result = count_fractions(12000)
print(result)
```---
