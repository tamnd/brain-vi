##Giải pháp 

**Trả lời:**`20444710234716473`Cho phép$s(n)$biểu thị tổng các chữ số thập phân của$n$. 

Chúng tôi tìm kiếm số nguyên$$0 \le n < 10^{18}$$như vậy$$s(n)=s(137n).$$--- 

# Phân tích toán học 

hãy để$$n=\sum_{i=0}^{17} d_i 10^i, \qquad 0\le d_i\le 9.$$Chúng tôi xử lý phép nhân bằng$137$từng chữ số từ ít quan trọng nhất đến quan trọng nhất. 

--- 

## 1. Hành vi tổng các chữ số được mang theo 

Giả sử ở một bước nào đó chúng ta tính toán$$137d_i + c_i,$$Ở đâu$c_i$là vật mang đến. 

Viết$$137d_i+c_i = 10c_{i+1}+e_i,$$với$e_i$chữ số đầu ra của$137n$. 

Sau đó:$$e_i = (137d_i+c_i)\bmod 10, \qquad c_{i+1}=\left\lfloor \frac{137d_i+c_i}{10}\right\rfloor.$$Phần đóng góp vào chênh lệch tổng chữ số là$$d_i-e_i.$$Sau khi tất cả 18 chữ số được xử lý, một số chữ số vẫn còn. Các chữ số thập phân của nó cũng đóng góp vào tổng các chữ số của$137n$. 

Kể từ đây$$s(n)-s(137n) = \sum_{i=0}^{17}(d_i-e_i) - s(c_{18}),$$Ở đâu$s(c_{18})$là tổng chữ số của lần mang cuối cùng. 

Vì thế chúng ta cần$$\sum_{i=0}^{17}(d_i-e_i)=s(c_{18}).$$Điều này lý tưởng cho chữ số DP. 

--- 

## 2. Nén trạng thái 

Tại mỗi vị trí chúng ta chỉ cần: 

- mang theo hiện tại, 
- chênh lệch lũy kế$$\Delta=\sum(d_i-e_i).$$Vì vậy hãy xác định:$$\text{DP}(pos, carry, \Delta)$$= số cách điền chữ số vào vị trí`pos`trở đi. 

Cuối cùng (`pos = 18`), chúng tôi chấp nhận nếu$$\Delta = s(carry).$$Việc mang theo vẫn còn nhỏ:$$137\cdot 9 + \text{carry} < 1400,$$nên không gian trạng thái rất nhỏ. 

--- 

#Triển khai Python```python
from functools import lru_cache

LENGTH = 18
MULTIPLIER = 137

@lru_cache(None)
def dp(pos, carry, diff):
    """
    pos   : current digit position (0 = least significant)
    carry : carry entering this position
    diff  : accumulated value of sum(d_i - e_i)
    """

    # All 18 digits processed
    if pos == LENGTH:

        # Remaining carry contributes digits to 137n
        carry_digit_sum = 0
        c = carry

        while c > 0:
            carry_digit_sum += c % 10
            c //= 10

        # Need total digit sums to match
        return 1 if diff == carry_digit_sum else 0

    total = 0

    # Choose next digit of n
    for d in range(10):

        value = MULTIPLIER * d + carry

        # Output digit of 137n
        out_digit = value % 10

        # Next carry
        next_carry = value // 10

        # Update digit-sum difference
        next_diff = diff + d - out_digit

        total += dp(pos + 1, next_carry, next_diff)

    return total

answer = dp(0, 0, 0)

print(answer)
```---

# Kiểm tra sự tỉnh táo nhỏ
