##Giải pháp 

**Trả lời:**`581468882`Cho phép$a>1$không hợp lý (điều này đúng với$a=\sqrt p$khi$p$là số nguyên tố). 

Chúng tôi được trao$$g_a(x)= \begin{cases} 1,&x<a,\\ g_a(x-1)+g_a(x-a),&x\ge a. \end{cases}$$Chúng ta phải tính toán$$G(n)=g_{\sqrt n}(n),$$và cuối cùng$$\sum_{\substack{p\text{ prime}\\10^7<p<10010000}} G(p)\pmod{10^9+7}.$$--- 

# 1. Phân tích toán học 

## 1.1 Giải thích tổ hợp 

Sự tái diễn$$g(x)=g(x-1)+g(x-a)$$tương tự như việc đếm đường đi bằng cách sử dụng các bước có độ dài$1$Và$a$. 

Bởi vì$a$là vô tỉ, mọi số có dạng$$m+na$$có một đại diện duy nhất. Điều này loại bỏ tất cả sự mơ hồ trong cây đệ quy. 

Định nghĩa:

-$k$= số lượng$a$-bước, 
-$j$= số lượng$1$-bước. 

Khi đó tổng chiều dài là$$j+ka.$$Để cố định$k$, điều kiện$$j+ka\le x$$trở thành$$j\le \lfloor x-ka\rfloor.$$Đối với mỗi chấp nhận được$j$, số dãy chứa: 

-$k$bản sao của$a$, 
-$j$bản sao của$1$,

là$$\binom{j+k}{k}.$$Vì thế$$g_a(x)= \sum_{k\ge0}\sum_{j=0}^{\lfloor x-ka\rfloor}\binom{j+k}{k}.$$Bây giờ hãy sử dụng danh tính gậy khúc côn cầu:$$\sum_{j=0}^{m}\binom{j+k}{k} = \binom{m+k+1}{k+1}.$$Kể từ đây$$g_a(x) = \sum_{k\ge0} \binom{\lfloor x-ka\rfloor+k+1}{k+1}.$$Lập chỉ mục lại với$k\mapsto k-1$:$$\boxed{ g_a(x)= \sum_{k\ge0} \binom{\lfloor x-ka\rfloor+k}{k} }.$$--- 

##1.2 Công thức tính$G(n)$Bộ$a=\sqrt n$,$x=n$:$$\boxed{ G(n)= \sum_{k=0}^{\lfloor\sqrt n\rfloor} \binom{\lfloor n-k\sqrt n\rfloor+k}{k} }.$$Vấn đề mang lại$$G(90)=7564511.$$Kiểm tra:$$G(90) = \sum_{k=0}^{9} \binom{\lfloor 90-k\sqrt{90}\rfloor+k}{k} = 7564511,$$vậy công thức đúng.

#2. Tính toán mô-đun hiệu quả 

Chúng ta cần tất cả các số nguyên tố$$10^7<p<10010000.$$Chỉ có vài trăm số đó, và với mỗi số nguyên tố$p$,$$k\le \lfloor\sqrt p\rfloor \approx 3162.$$Như vậy tổng số đánh giá nhị thức chỉ vào khoảng$2\times10^6$. 

Chúng tôi tính toán tất cả các hệ số nhị thức modulo$$M=10^9+7$$sử dụng giai thừa và giai thừa nghịch đảo.

#3. Triển khai Python```python
import math

MOD = 1_000_000_007

LOW = 10_000_000
HIGH = 10_010_000

# ------------------------------------------------------------
# Segmented sieve for primes in (LOW, HIGH)
# ------------------------------------------------------------

limit = int(math.isqrt(HIGH)) + 1

base = [True] * (limit + 1)
base[0] = base[1] = False

for i in range(2, int(limit ** 0.5) + 1):
    if base[i]:
        step = i
        start = i * i
        for j in range(start, limit + 1, step):
            base[j] = False

small_primes = [i for i, v in enumerate(base) if v]

seg = [True] * (HIGH - LOW)

for p in small_primes:
    start = max(p * p, ((LOW + p - 1) // p) * p)
    for x in range(start, HIGH, p):
        seg[x - LOW] = False

primes = [LOW + i for i, v in enumerate(seg) if v and LOW + i > LOW]

# ------------------------------------------------------------
# Precompute factorials modulo MOD
# ------------------------------------------------------------

N = HIGH + 5000

fact = [1] * (N + 1)

for i in range(1, N + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact = [1] * (N + 1)

invfact[N] = pow(fact[N], MOD - 2, MOD)

for i in range(N, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    """Compute nCr modulo MOD."""
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

# ------------------------------------------------------------
# Compute G(p)
# ------------------------------------------------------------

def G(p):
    a = math.sqrt(p)

    total = 0

    for k in range(int(a) + 1):
        n = math.floor(p - k * a) + k
        total = (total + C(n, k)) % MOD

    return total

answer = 0

for p in primes:
    answer = (answer + G(p)) % MOD

print(answer)
```---

## Giai thừa 

Chúng tôi tính toán trước:$$n!,\quad (n!)^{-1}\pmod M$$để có thể$$\binom{n}{r} = \frac{n!}{r!(n-r)!} \pmod M$$có thể được đánh giá trong thời gian không đổi.
