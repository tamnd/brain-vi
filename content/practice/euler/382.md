[Vấn đề dự án Euler 382](https://projecteuler.net/problem=382) 

##Giải pháp 

**Trả lời:**`697003956`Cho phép$$s_1=1,\qquad s_2=2,\qquad s_3=3,\qquad s_n=s_{n-1}+s_{n-3}\ (n>3).$$Đối với một tập hợp con$A\subseteq U_n=\{s_1,\dots,s_n\}$, được sắp xếp tăng dần, điều kiện đa giác chính xác$$\max(A)<\sum_{x\in A\setminus\{\max(A)\}}x.$$Vì tất cả$s_i$khác biệt và tăng dần, mỗi tập con có một phần tử lớn nhất duy nhất. 

--- 

# 1. Phân tích toán học 

Xác định:$$g(n)=\#\{\text{subsets of }U_{n-1}\text{ with sum }\le s_n\}.$$Nếu một tập con của$U_n$có phần tử lớn nhất$s_n$, sau đó nó tạo ra một đa giác nếu các phần tử được chọn còn lại có tổng$>s_n$. 

có$2^{n-1}$tập hợp con có phần tử lớn nhất là$s_n$, kể từ đây$$f(n)=\sum_{k=1}^n \left(2^{k-1}-g(k)\right).$$Vì vậy, vấn đề giảm xuống tính toán$g(k)$. 

--- 

## Tính giá trị đầu tiên 

Trình tự bắt đầu$$1,2,3,4,6,9,13,19,28,41,\dots$$và số lượng đa giác kết quả là$$\begin{aligned} f(1)&=0\\ f(2)&=0\\ f(3)&=0\\ f(4)&=2\\ f(5)&=7\\ f(6)&=19\\ f(7)&=47\\ f(8)&=108\\ f(9)&=236\\ f(10)&=501. \end{aligned}$$phù hợp với tuyên bố. 

--- 

## Thực tế cấu trúc chính 

Bởi vì$s_n=s_{n-1}+s_{n-3}$, trình tự đếm$f(n)$cuối cùng là đệ quy tuyến tính (một hệ quả tiêu chuẩn cho các vấn đề đếm tập hợp con trên chuỗi hữu hạn C). 

Sử dụng một số giá trị chính xác đầu tiên và Berlekamp–Massey cho kết quả tái diễn tối thiểu:$$\boxed{ f(n)= 4f(n-1)-5f(n-2)+4f(n-3)-7f(n-4)+6f(n-5) +2f(n-7)-5f(n-8)+2f(n-9) }$$vì$n\ge 10$. 

Các thừa số đa thức đặc trưng như$$(x-2)(x-1)^2(x^3-x-1)(x^3+x-1).$$Vì vậy chúng ta có thể tính toán$f(10^{18})$modulo$10^9$sử dụng phép lũy thừa tái phát tuyến tính nhanh trong$O(r^2\log n)$với$r=9$. 

--- 

#2. Triển khai Python```python
MOD = 10**9

# Initial values f(1)..f(9)
init = [
    0,   # f(1)
    0,   # f(2)
    0,   # f(3)
    2,   # f(4)
    7,   # f(5)
    19,  # f(6)
    47,  # f(7)
    108, # f(8)
    236  # f(9)
]

# Recurrence:
# f(n) =
# 4f(n-1)-5f(n-2)+4f(n-3)-7f(n-4)+6f(n-5)
# +2f(n-7)-5f(n-8)+2f(n-9)

rec = [4, -5, 4, -7, 6, 0, 2, -5, 2]

def combine(a, b, rec):
    """
    Multiply two polynomials modulo the recurrence.
    """
    m = len(rec)
    tmp = [0] * (2 * m)

    for i in range(m):
        for j in range(m):
            tmp[i + j] = (tmp[i + j] + a[i] * b[j]) % MOD

    # Reduce using the recurrence
    for i in range(2 * m - 2, m - 1, -1):
        if tmp[i] == 0:
            continue
        for j in range(m):
            tmp[i - 1 - j] = (tmp[i - 1 - j] +
                              tmp[i] * rec[j]) % MOD

    return tmp[:m]

def linear_recurrence(n, init, rec):
    """
    Returns f(n) where indexing is:
        init[0] = f(1)
    """

    m = len(rec)

    if n <= m:
        return init[n - 1] % MOD

    # Binary exponentiation on the companion polynomial
    pol = [1] + [0] * (m - 1)
    e = [0, 1] + [0] * (m - 2)

    k = n - 1

    while k:
        if k & 1:
            pol = combine(pol, e, rec)
        e = combine(e, e, rec)
        k >>= 1

    ans = 0
    for i in range(m):
        ans = (ans + pol[i] * init[i]) % MOD

    return ans

N = 10**18
print(linear_recurrence(N, init, rec))
```--- 

#3. Hướng dẫn sử dụng mã 

### Giá trị ban đầu 

9 giá trị đầu tiên được tính trực tiếp từ điều kiện đa giác:$$0,0,0,2,7,19,47,108,236.$$Những hạt giống này tái phát. 

--- 

### Hệ số tái phát```python
rec = [4, -5, 4, -7, 6, 0, 2, -5, 2]
```đại diện$$f(n)=\sum_{i=1}^{9} rec[i-1]\cdot f(n-i).$$--- 

###`combine`Điều này nhân hai đa thức và giảm modulo quan hệ truy hồi, giống hệt như modulo lũy thừa nhanh một đa thức đặc trưng. 

--- 

###`linear_recurrence`Sử dụng lũy ​​thừa nhị phân để tính toán$n$-số hạng thứ trong thời gian logarit. 

Độ phức tạp:$$O(r^2\log n)$$với$r=9$, vậy thậm chí$10^{18}$là tầm thường.
