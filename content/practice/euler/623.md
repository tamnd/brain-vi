[Vấn đề dự án Euler 623](https://projecteuler.net/problem=623) 

## Giải pháp 

**Trả lời:**`3679796`Cho phép$T_m(n)$là số lượng$\alpha$-các lớp tương đương của thuật ngữ lambda có kích thước **chính xác**$n$có các biến tự do nằm trong số$m$chất kết dính có sẵn. 

Khi đó số lượng cần tìm là$$\Lambda(n)=\sum_{k\le n} T_0(k).$$Quan sát quan trọng là việc đếm modulo$\alpha$-sự tương đương chính xác là những gì **lập chỉ mục de Bruijn** thực hiện: chỉ _cấu trúc liên kết_ quan trọng, không phải tên biến thực tế. 

--- 

# 1. Phân tích toán học 

##Mô hình kích thước 

Từ các ví dụ: 

- Biến$x$có kích thước$1$. 
- Ứng dụng$(MN)$đóng góp hai dấu ngoặc đơn:$$|(MN)| = |M|+|N|+2.$$- Trừu tượng$(\lambda x.M)$đóng góp: 
- dấu ngoặc trái 
-$\lambda$- biến 
- dấu chấm 
- dấu ngoặc đơn bên phải 

vậy$$|(\lambda x.M)| = |M|+5.$$Kiểm tra:$$|(\lambda x.x)| = 5+1 = 6,$$phù hợp với tuyên bố. 

--- 

## Phân tách đệ quy 

Một thuật ngữ được tính bằng$T_m(n)$là một trong: 

### 1. Biến 

Có chính xác$m$các biến tự do có thể có. 

Vì thế:$$T_m(1)=m.$$--- 

### 2. Ứng dụng 

Một thuật ngữ$(AB)$có kích thước$$|A|+|B|+2=n.$$Kể từ đây:$$\sum_{i=1}^{n-3} T_m(i)\,T_m(n-2-i).$$--- 

### 3. Trừu tượng hóa 

Một thuật ngữ$(\lambda x.M)$có kích thước$$|M|+5=n.$$Bên trong phần trừu tượng, chúng ta có thêm một biến có sẵn, vì vậy:$$T_{m+1}(n-5).$$--- 

Kết hợp mọi thứ:$$\boxed{ T_m(n)= \begin{cases} m,& n=1,\\[1ex] T_{m+1}(n-5)+ \displaystyle\sum_{i=1}^{n-3}T_m(i)T_m(n-2-i), & n\ge2. \end{cases} }$$Cuối cùng,$$\boxed{ \Lambda(N)=\sum_{n=0}^{N} T_0(n). }$$--- 

#2. Triển khai Python```python
MOD = 1_000_000_007
N = 2000

# Maximum possible abstraction depth.
# Every abstraction costs 5 symbols.
MAX_M = N // 5 + 5

# dp[m][n] = number of alpha-equivalence classes
# of exact size n with free variables among m binders
dp = [[0] * (N + 1) for _ in range(MAX_M + 2)]

# Compute from large m downward because dp[m]
# depends on dp[m+1]
for m in range(MAX_M, -1, -1):

    # Variable terms
    dp[m][1] = m

    # Larger sizes
    for n in range(2, N + 1):

        total = 0

        # Abstraction contribution
        if n >= 5:
            total += dp[m + 1][n - 5]

        # Application contribution
        # (A B) has size |A| + |B| + 2
        for left_size in range(1, n - 2):
            right_size = n - 2 - left_size
            total += dp[m][left_size] * dp[m][right_size]

        dp[m][n] = total % MOD

# Lambda(N) = cumulative count of closed terms
answer = sum(dp[0][:N + 1]) % MOD

print(answer)
```---

dp[m][n]
```lưu trữ số lượng thuật ngữ có kích thước chính xác$n$với nhiều nhất$m$chất kết dính có thể tiếp cận được. 

--- 

## Trường hợp biến```python
dp[m][1] = m
```Một biến có thể là bất kỳ$m$các biến bị ràng buộc.

total += dp[m + 1][n - 5]
```Một sự trừu tượng hóa sử dụng 5 ký hiệu và giới thiệu một chất kết dính bổ sung.

# 4. Xác minh tuyên bố

$$\Lambda(9)=2,$$

$$\Lambda(15)=20,$$
