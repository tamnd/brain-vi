## Giải pháp 

**Trả lời:**`48861552`Chúng tôi tìm kiếm$$\sum_{N=5}^{10000} D(N),$$Ở đâu$D(N)=N$nếu sản phẩm tối đa hóa$M(N)$là số thập phân vô tận và$D(N)=-N$nếu không thì. 

Điều quan trọng là phải xác định, đối với mỗi$N$, liệu sản phẩm có tối ưu hay không$$M(N)=\left(\frac Nk\right)^k$$có chấm dứt hay không. 

# 1. Phân tích toán học 

Để cố định$N$, định nghĩa$$f(k)=\left(\frac Nk\right)^k.$$Chúng tôi tối đa hóa điều này trên các số nguyên dương$k$. 

Lấy nhật ký:$$\log f(k)=k(\log N-\log k).$$Đối xử$k$như thật và khác biệt:$$\frac{d}{dk}\bigl(k(\log N-\log k)\bigr) =\log N-\log k-1.$$Đặt giá trị này bằng 0:$$\log\frac Nk=1 \quad\Longrightarrow\quad \frac Nk=e \quad\Longrightarrow\quad k=\frac Ne.$$Do đó số nguyên tối đa hóa$k$là số nguyên gần nhất với$N/e$. 

Chính xác hơn: 

- để$$k_1=\left\lfloor \frac Ne \right\rfloor,$$- sau đó so sánh$f(k_1)$Và$f(k_1+1)$. 

Một thực tế tiêu chuẩn cho vấn đề này là số nguyên tối đa luôn luôn là$$\left\lfloor \frac Ne \right\rfloor \quad\text{or}\quad \left\lfloor \frac Ne \right\rfloor+1.$$--- 

## Khi nào$M(N)$chấm dứt? 

Giả sử tối đa hóa$k$được chọn. 

Sau đó$$M(N)=\left(\frac Nk\right)^k.$$Giảm phân số:$$\frac Nk=\frac ab$$trong điều kiện thấp nhất. 

Sau đó$$M(N)=\left(\frac ab\right)^k.$$Một số hữu tỉ có một số thập phân tận cùng nếu mẫu số rút gọn của nó không có thừa số nguyên tố nào khác ngoài$2$Và$5$. 

Vì vậy chúng ta chỉ cần biết liệu mẫu số rút gọn$b$chứa các số nguyên tố bên cạnh$2,5$. 

Nhưng$$b=\frac{k}{\gcd(N,k)}.$$Vì vậy: 

- tính toán$$d=\frac{k}{\gcd(N,k)};$$- liên tục phân chia các yếu tố của$2$Và$5$; 
- nếu kết quả là$1$, sau đó$M(N)$chấm dứt; 
- nếu không thì không. 

Như vậy:$$D(N)= \begin{cases} -N & \text{if } d \text{ has only factors }2,5,\\ +N & \text{otherwise.} \end{cases}$$--- 

#2. Xác định mức tối ưu$k$Chúng tôi so sánh$$\left(\frac N{k}\right)^k$$cho các số nguyên liên tiếp. 

Thay vì lũy thừa rất lớn, hãy so sánh logarit:$$k\log\frac Nk.$$Định nghĩa$$g(k)=k\log\frac Nk.$$Khi đó số nguyên tối đa là:```python
k = floor(N/e)
if g(k+1) > g(k):
    k += 1
```--- 

#3. Triển khai Python```python
import math
from math import gcd

def optimal_k(N):
    """
    Return the integer k maximizing (N/k)^k.
    """
    k = int(N / math.e)

    # Compare logarithms to avoid huge numbers
    g1 = k * math.log(N / k)
    g2 = (k + 1) * math.log(N / (k + 1))

    if g2 > g1:
        k += 1

    return k

def terminating_decimal(N):
    """
    Return True iff M(N) is a terminating decimal.
    """
    k = optimal_k(N)

    # Reduced denominator of N/k
    d = k // gcd(N, k)

    # Remove all factors of 2
    while d % 2 == 0:
        d //= 2

    # Remove all factors of 5
    while d % 5 == 0:
        d //= 5

    return d == 1

def compute(limit):
    total = 0

    for N in range(5, limit + 1):
        if terminating_decimal(N):
            total -= N
        else:
            total += N

    return total

# Verify the example
print(compute(100))      # should be 2438

# Final answer
print(compute(10000))
```--- 

#4. Hướng dẫn code 

##`optimal_k(N)`

```python
k = int(N / math.e)
```Sự tối ưu liên tục xảy ra tại$N/e$, vì vậy số nguyên tốt nhất là gần giá trị này. 

---```python
g1 = k * math.log(N / k)
g2 = (k + 1) * math.log(N / (k + 1))
```Chúng tôi so sánh logarit thay vì bản thân sản phẩm. 

Vì logarit ngày càng tăng nên$$f(k+1)>f(k) \iff \log f(k+1)>\log f(k).$$---```python
if g2 > g1:
    k += 1
```Chọn số nguyên nào cho tích lớn hơn.

##`terminating_decimal(N)`

```python
d = k // gcd(N, k)
```Đây chính xác là mẫu số của$N/k$trong điều kiện thấp nhất. 

---```python
while d % 2 == 0:
    d //= 2

while d % 5 == 0:
    d //= 5
```Số thập phân tận cùng chỉ có thể có mẫu số$2$Và$5$. 

---```python
return d == 1
```Nếu không còn gì thì số thập phân chấm dứt.

## Kiểm tra ví dụ 

###$N=11$Tối ưu$k=4$.$$M(11)=\left(\frac{11}{4}\right)^4.$$Mẫu số rút gọn là$4=2^2$, thế là chấm dứt. 

Kể từ đây$$D(11)=-11.$$--- 

###$N=8$Tối ưu$k=3$.$$M(8)=\left(\frac83\right)^3=\frac{512}{27}.$$Mẫu số chứa hệ số$3$, do đó không kết thúc. 

Kể từ đây$$D(8)=+8.$$--- 

Chương trình cũng sao chép séc đã cho:$$\sum_{N=5}^{100} D(N)=2438.$$---
