## Giải pháp 

**Trả lời:**`23.386029052`Cho silo có bán kính$R$, và để hạt được đổ từ điểm$(x,0)$trên đỉnh xi lanh. 

Nếu góc nghỉ ngơi là$\alpha$, thì bề mặt tự do của hạt tạo thành độ dốc$$\tan\alpha$$với chiều ngang. 

Đối với bất kỳ điểm nào$(u,v)$Do đó, trong mặt cắt ngang hình tròn, chiều cao trống thẳng đứng phía trên hạt là$$h(u,v)=\tan\alpha\;\sqrt{(u-x)^2+v^2}.$$Do đó khối lượng lãng phí là$$V(x)=\tan\alpha\iint_D \sqrt{(u-x)^2+v^2}\,dA,$$Ở đâu$D$là cái đĩa$u^2+v^2\le R^2$. 

--- 

#1. Chuyển đổi tích phân 

Sử dụng tọa độ cực có tâm tại điểm rót:$$u=x+r\cos\theta,\qquad v=r\sin\theta.$$Dọc theo hướng$\theta$, tia thoát khỏi silo khi$$(x+r\cos\theta)^2+(r\sin\theta)^2=R^2.$$Giải quyết cho$r$,$$r_{\max}(\theta) = -x\cos\theta+\sqrt{R^2-x^2\sin^2\theta}.$$Vì tích phân chỉ đơn giản là$r$,$$V(x) = \tan\alpha \int_0^{2\pi}\int_0^{r_{\max}(\theta)} r\cdot r\,dr\,d\theta.$$Vì thế$$\boxed{ V(x)= \frac{\tan\alpha}{3} \int_0^{2\pi} \left( -x\cos\theta+\sqrt{R^2-x^2\sin^2\theta} \right)^3 d\theta }.$$--- 

#2. Kiểm tra ví dụ 

Ví dụ đầu tiên của câu lệnh sử dụng: 

- đường kính$6\Rightarrow R=3$, 
-$\alpha=30^\circ$, 
-$x=0$. 

Sau đó$$V(0) = \frac{\tan30^\circ}{3} \int_0^{2\pi} 3^3\,d\theta = 18\pi\tan30^\circ = 6\pi\sqrt3 \approx 32.648388556,$$phù hợp chính xác với tuyên bố vấn đề. 

Vậy công thức là đúng.

#3. Dữ liệu vấn đề thực tế 

Bây giờ sử dụng:$$R=6,\qquad \alpha=40^\circ.$$Chúng tôi tìm kiếm tất cả$x\in[0,6]$như vậy$V(x)$là một hình vuông hoàn hảo 

Từ$V(x)$đang tăng mạnh với$x$, có nhiều nhất một nghiệm cho mỗi ô vuông. 

Tính khoảng:$$V(0)\approx 379.60, \qquad V(6)\approx 644.43.$$Do đó, số hình vuông hoàn hảo duy nhất có thể là$$20^2,21^2,22^2,23^2,24^2,25^2.$$Giải số$V(x)=n^2$cho mỗi$n=20,\dots,25$mang lại:$$\begin{aligned} x_{20}&\approx1.6097585009208716,\\ x_{21}&\approx2.8060119465435142,\\ x_{22}&\approx3.6783279154320040,\\ x_{23}&\approx4.4264032917821366,\\ x_{24}&\approx5.1094202074447333,\\ x_{25}&\approx5.7561071894994169. \end{aligned}$$Tóm tắt:$$\sum x = 23.386029051622676\ldots$$Làm tròn thành$9$số thập phân:$$\boxed{23.386029052}$$--- 

#4. Triển khai Python```python
import mpmath as mp

mp.mp.dps = 50

R = mp.mpf(6)
alpha = mp.radians(40)
T = mp.tan(alpha)

# Volume function
def V(x):
    def integrand(theta):
        return (
            -x * mp.cos(theta)
            + mp.sqrt(R*R - x*x * mp.sin(theta)**2)
        ) ** 3

    return (T / 3) * mp.quad(integrand, [0, 2 * mp.pi])

# Solve V(x) = n^2 by bisection
def solve_for_square(n):
    target = n * n

    lo = mp.mpf(0)
    hi = R

    for _ in range(100):
        mid = (lo + hi) / 2

        if V(mid) < target:
            lo = mid
        else:
            hi = mid

    return (lo + hi) / 2

roots = []

for n in range(20, 26):
    x = solve_for_square(n)
    roots.append(x)
    print(n, x)

answer = mp.fsum(roots)

print("Sum =", answer)
print("Rounded =", mp.nstr(answer, 12))
```--- 

#5. Hướng dẫn sử dụng mã 

-`V(x)`thực hiện công thức tích phân chính xác được dẫn xuất ở trên. 
- Đối với mỗi góc`theta`, độ dài tia sáng bên trong đĩa là```python
-x*cos(theta) + sqrt(R^2 - x^2*sin(theta)^2)
```- Tích phân hướng tâm trong đóng góp một hệ số$r^3/3$. 
- Chúng tôi tích hợp số trên$[0,2\pi]$. 
- Từ$V(x)$là đơn điệu, chia đôi giải quyết một cách an toàn$$V(x)=n^2.$$- Chỉ hình vuông từ$20^2$ĐẾN$25^2$nằm trong phạm vi có thể đạt được.
