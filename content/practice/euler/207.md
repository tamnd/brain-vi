## Giải pháp 

**Trả lời:**`44043947822`Cho phép$$4^t = 2^t + k.$$Chúng ta được hỏi về số nguyên dương$k$mà một phân vùng như vậy tồn tại, và trong số đó, những nơi$t\in\mathbb Z$phân vùng ("hoàn hảo"). 

Chúng tôi muốn cái nhỏ nhất$m$như vậy$$P(m) < \frac1{12345},$$Ở đâu$P(m)$là tỷ lệ của các phân vùng có$k\le m$đó là hoàn hảo. 

--- 

# Bước 1: Viết lại phương trình 

Đặt$$x = 2^t.$$Sau đó$$4^t = (2^t)^2 = x^2,$$nên phương trình xác định trở thành$$x^2 = x + k.$$Kể từ đây$$k = x^2 - x = x(x-1).$$Từ$k$phải là số nguyên,$x$cũng phải là số nguyên (vì$x$thỏa mãn đa thức monic$x^2-x-k=0$; một điều kiện nghiệm số nguyên cho$x\in\mathbb Z$). 

Do đó mỗi phân vùng tương ứng chính xác với một số nguyên$$x=n\ge2,$$với$$k=n(n-1).$$Vì vậy có thể chấp nhận được$k$chính xác là$$2,6,12,20,30,\dots$$phù hợp với các ví dụ. 

--- 

# Bước 2: Mô tả các phân vùng hoàn hảo 

Một phân vùng hoàn hảo khi$t$là một số nguyên. 

Nhưng$x=2^t$. Vì thế:

-$t\in\mathbb Z$- nếu$x$là sức mạnh của hai. 

Vì vậy, phân vùng hoàn hảo tương ứng với$$x=2^a \quad (a\ge1),$$cho đi$$k = 2^a(2^a-1).$$--- 

# Bước 3: Đếm số phân vùng tối đa$m$Tất cả các phân vùng được lập chỉ mục theo số nguyên$n\ge2$với$$k=n(n-1)\le m.$$Giả sử lớn nhất như vậy$n$là$N$. Sau đó$$N(N-1)\le m < (N+1)N.$$Do đó tổng số phân vùng lên tới$m$là$$N-1$$(từ$n=2,3,\dots,N$). 

Bây giờ hãy đếm các phân vùng hoàn hảo. 

Phân vùng hoàn hảo xảy ra khi$n$là lũy thừa của hai:$$n=2,4,8,\dots,2^A\le N.$$Vậy số phân vùng hoàn hảo là$$A,$$Ở đâu$$A=\lfloor \log_2 N\rfloor.$$Vì thế$$P(m)=\frac{\lfloor \log_2 N\rfloor}{N-1}.$$--- 

# Bước 4: Giải bất phương trình 

Chúng tôi cần$$\frac{\lfloor \log_2 N\rfloor}{N-1}<\frac1{12345}.$$Cho phép$$a=\lfloor \log_2 N\rfloor.$$Sau đó$$2^a \le N < 2^{a+1}.$$Bất đẳng thức trở thành$$12345a < N-1,$$hoặc$$N > 12345a+1.$$Để giảm thiểu$m$, chúng tôi giảm thiểu$N$. Vì vậy đối với mỗi$a$, ứng cử viên nhỏ nhất là$$N = 12345a+2.$$Nhưng điều này$N$phải thỏa mãn$$\lfloor \log_2 N\rfloor = a,$$tức là$$2^a \le 12345a+2 < 2^{a+1}.$$Chúng tôi kiểm tra các giá trị của$a$. 

-$a=16$:$$12345\cdot16+2=197522,$$Nhưng$$2^{16}=65536,\qquad 2^{17}=131072.$$Quá lớn. 

-$a=17$:$$12345\cdot17+2=209867,$$Và$$2^{17}=131072,\qquad 2^{18}=262144.$$Điều này hoạt động. 

Do đó giá trị tối thiểu hợp lệ$N$là$$N=209867.$$Khi đó giá trị nhỏ nhất tương ứng$m$là giá trị nhỏ nhất với chính xác điều này$N$, cụ thể là$$m=N(N-1).$$Vì thế$$m=209867\cdot209866.$$Tính toán:$$209867^2 = 44\,044\,151\,689,$$kể từ đây$$m=209867^2-209867 =44\,044\,151\,689-209\,867 =44\,043\,941\,822.$$--- 

#Triển khai Python```python
import math

TARGET = 12345

a = 1

while True:
    # smallest N satisfying:
    # a / (N - 1) < 1 / TARGET
    N = TARGET * a + 2

    # check whether floor(log2(N)) == a
    if (1 << a) <= N < (1 << (a + 1)):
        m = N * (N - 1)
        print(m)
        break

    a += 1
```---

# Xác minh cuối cùng
