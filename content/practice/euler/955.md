[Bài toán Euler dự án 955](https://projecteuler.net/problem=955) 

##Giải pháp 

**Trả lời:**`6795261671274`Gọi số tam giác là$$T_m=\frac{m(m+1)}2.$$Giả định$a_r=T_m$là số tam giác xuất hiện trong dãy và số tam giác tiếp theo xuất hiện là$a_{r+k}=T_n$. 

Giữa hai số tam giác, phép truy hồi là$$a_{j+1}-a_j=(a_j-a_{j-1})+1,$$và ngay sau số tam giác, hiệu sẽ được đặt lại thành$1$. 

Do đó các lần tăng liên tiếp là$$1,2,3,\dots,k,$$Vì thế$$T_n-T_m = 1+2+\cdots+k = T_k.$$Vì thế$$T_n=T_m+T_k.$$sử dụng$T_x=\frac{x(x+1)}2$,$$n(n+1)=m(m+1)+k(k+1).$$Sắp xếp lại:$$(2n+1)^2=(2m+1)^2+(2k+1)^2-1.$$Một thủ thuật phân tích nhân tử tiêu chuẩn mang lại$$m(m+1)=uv,$$với$$u=\frac{2n+1-(2k+1)}2,\qquad v=\frac{2n+1+(2k+1)}2.$$Sau đó$$2k+1=v-u,\qquad 2n+1=u+v.$$Vì vậy, đối với một nhất định$m$, để có được số tam giác _next_ trong dãy chúng ta phải chọn cặp thừa số$$uv=m(m+1)$$với sự khác biệt lẻ nhỏ nhất$v-u>1$. Sau đó$$k=\frac{v-u-1}{2},\qquad n=\frac{u+v-1}{2}.$$Bắt đầu từ$m=2$(từ$a_0=3=T_2$), chúng tôi lặp lại quy tắc này 69 lần và tích lũy tương ứng$k$-giá trị (chỉ số nhảy). 

Việc triển khai Python sạch là:```python
from math import isqrt
from sympy import divisors

def next_triangle(m):
    N = m * (m + 1)

    best = None
    for u in divisors(N):
        if u * u > N:
            break
        v = N // u
        d = v - u

        # need smallest odd difference > 1
        if d > 1 and d % 2 == 1:
            best = (u, v)

    u, v = best

    k = (v - u - 1) // 2
    n = (u + v - 1) // 2

    return n, k

m = 2          # T_2 = 3
index = 0      # a_0

for _ in range(69):   # move to the 70th triangle number
    m, jump = next_triangle(m)
    index += jump

print(index)
```Điều này mang lại$$6795261671274.$$**Trả lời: 6795261671274**
