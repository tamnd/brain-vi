## Giải pháp 

**Trả lời:**`921107572`Cho phép$$S_k(n)=\sum_{i=1}^n i^k$$là đa thức Faulhaber. Chúng ta quan tâm đến hệ số$n$, mẫu số của nó là$D(k)$. 

### 1. Kết nối số Bernoulli 

Công thức Faulhaber là$$\sum_{i=1}^n i^k = \frac{1}{k+1} \sum_{j=0}^{k} (-1)^j \binom{k+1}{j} B_j n^{k+1-j},$$Ở đâu$B_j$là các số Bernoulli. 

Hệ số của$n$xuất phát từ thuật ngữ$j=k$, Vì thế:$$a_1 = B_k.$$Kể từ đây:$$D(k)=\text{denominator}(B_k).$$Ví dụ,$$B_4=-\frac{1}{30},$$Vì thế$D(4)=30$, phù hợp với phát biểu vấn đề. 

--- 

### 2. Áp dụng định lý von Staudt–Clausen 

Định lý nói:$$\operatorname{den}(B_k) = \prod_{p-1\mid k} p \qquad (k \text{ even}),$$nơi sản phẩm chạy trên số nguyên tố$p$như vậy$p-1\mid k$. 

Chúng tôi muốn:$$D(k)=20010.$$Nhân tố:$$20010 = 2\cdot 3\cdot 5\cdot 23\cdot 29.$$Do đó, các số nguyên tố **duy nhất**$p$với$p-1\mid k$phải là$$p\in\{2,3,5,23,29\}.$$Tương đương,$$1,2,4,22,28 \mid k,$$nhưng **không có gì khác**$p-1$có thể chia$k$. 

bội số chung nhỏ nhất là$$\mathrm{lcm}(1,2,4,22,28)=308.$$Vì vậy mọi giá trị hợp lệ$k$có hình thức$$k=308t.$$Bây giờ điều kiện trở thành: 

Với mỗi ước số$d\mid 308$,$$dt+1$$phải là hợp số (nếu không thì một số nguyên tố mới$q=dt+1$sẽ thỏa mãn$q-1\mid k$, thêm một yếu tố không mong muốn vào mẫu số). 

Điều này đưa ra một bài kiểm tra nhân đệ quy: 

-$t=1$là hợp lệ ($k=308$, cho$F(1)=308$). 
- Một số$t$là hợp lệ nếu: 

1. tất cả$dt+1$vì$d\mid 308$là hợp chất và 
2. mỗi$t/p$(đối với ước số nguyên tố$p\mid t$) là hợp lệ. 

Điều này tái tạo:$$F(10)=96404,$$phù hợp với tuyên bố.

### 3. Triển khai Python```python
import sympy as sp

DIVS = sp.divisors(308)

def find_F(target):
    N = 200000

    while True:
        # Smallest prime factor sieve
        spf = list(range(N + 1))
        for i in range(2, int(N**0.5) + 1):
            if spf[i] == i:
                for j in range(i * i, N + 1, i):
                    if spf[j] == j:
                        spf[j] = i

        good = [False] * (N + 1)
        good[1] = True

        count = 1  # t = 1 corresponds to F(1)=308

        for t in range(2, N + 1):

            # Local primality condition:
            # d*t + 1 must be composite for all d | 308
            local_ok = True
            for d in DIVS:
                if sp.isprime(d * t + 1):
                    local_ok = False
                    break

            if not local_ok:
                continue

            # Recursive divisor condition
            n = t
            ok = True
            used = set()

            while n > 1:
                p = spf[n]
                if p not in used:
                    used.add(p)
                    if not good[t // p]:
                        ok = False
                        break
                n //= p

            if ok:
                good[t] = True
                count += 1

                if count == target:
                    return 308 * t

        N *= 2

print(find_F(10))      # 96404
print(find_F(100000))  # final answer
```--- 

### 4. Hướng dẫn sử dụng mã 

-`DIVS = divisors(308)`tính tất cả các ước của$308$. 
- Chúng tôi tìm kiếm số$t$như vậy$k=308t$. 
- Đối với mỗi$t$, chúng tôi kiểm tra xem mọi$dt+1$là tổng hợp. 
- Chúng ta cũng thực thi thuộc tính ước số đệ quy bằng cách kiểm tra tất cả$t/p$, Ở đâu$p$chạy trên các ước nguyên tố của$t$. 
- Chúng tôi tính hợp lệ$t$theo thứ tự tăng dần cho đến khi$100000$-thứ 1 

Xác minh: 

-$F(1)=308$✔ 
-$F(10)=96404$✔ 

Việc tính toán cho:$$t_{100000}=2,\!990,\!609$$và do đó$$F(10^5)=308\times 2,\!990,\!609 =921,\!107,\!572.$$**Trả lời: 921107572**
