**Trả lời:**`303963552391`## 1. Phân tích toán học 

Chúng tôi muốn số **phân số thích hợp giảm**$$\frac{n}{d}$$như vậy: 

-$n < d$, 
-$\gcd(n,d)=1$, 
-$d \le 1{,}000{,}000$. 

--- 

### Bước 1: Đếm phân số rút gọn có mẫu số cố định 

Sửa mẫu số$d$. 

Các tử số hợp lệ$n$là số nguyên:$$1 \le n < d$$đó là nguyên tố cùng nhau$d$. 

Số các số nguyên như vậy chính xác là hàm tổng Euler:$$\varphi(d)$$bởi vì$\varphi(d)$đếm số nguyên dương nhỏ hơn$d$đó là nguyên tố cùng nhau$d$. 

Ví dụ:

-$d=8$: các tử số nguyên tố cùng nhau là$1,3,5,7$, Vì thế$\varphi(8)=4$. 
-$d=7$: tất cả$1,2,3,4,5,6$làm việc, vậy$\varphi(7)=6$. 

Do đó tổng số các phân số thích hợp rút gọn cho$d \le N$là:$$\sum_{d=2}^{N} \varphi(d)$$Đối với vấn đề này:$$\sum_{d=2}^{1{,}000{,}000} \varphi(d)$$--- 

### Bước 2: Tính toán totient hiệu quả 

Kiểm tra gcd trực tiếp cho mỗi cặp$(n,d)$sẽ không thể chậm được:$$O(N^2)$$Thay vào đó, hãy tính toán tất cả các tổng số đến$N$sử dụng một cái rây (tương tự như Sàng Eratosthenes). 

Thực tế chính: 

Nếu$p$là số nguyên tố thì với bội số của$p$,$$\varphi(n) = n\left(1-\frac1p\right)$$Chúng tôi khởi tạo:$$\varphi(n)=n$$Sau đó với mỗi số nguyên tố$p$, cập nhật tất cả bội số:$$\varphi(k) \leftarrow \varphi(k)-\frac{\varphi(k)}{p}$$Điều này tính toán tất cả các totents lên đến$10^6$đại khái là:$$O(N\log\log N)$$đó là đủ nhanh chóng.

## 2. Triển khai Python```python
def count_reduced_proper_fractions(limit):
    # Initialize phi[n] = n
    phi = list(range(limit + 1))

    # Sieve to compute Euler's totient for every number
    for p in range(2, limit + 1):
        # If phi[p] == p, then p is prime
        if phi[p] == p:
            # Update all multiples of p
            for multiple in range(p, limit + 1, p):
                phi[multiple] -= phi[multiple] // p

    # Sum φ(d) for d >= 2
    return sum(phi[2:])

# Problem limit
N = 1_000_000

answer = count_reduced_proper_fractions(N)
print(answer)
```--- 

## 3. Hướng dẫn sử dụng mã 

### Khởi tạo totient```python
phi = list(range(limit + 1))
```Chúng tôi bắt đầu với:$$\phi(n)=n$$cho mọi$n$. 

Ví dụ:```python
phi = [0,1,2,3,4,5,6,7,8]
```vì$N=8$. 

--- 

### Phát hiện số nguyên tố```python
if phi[p] == p:
```Chỉ có số nguyên tố vẫn thỏa mãn:$$\phi(p)=p$$ở giai đoạn này. 

Vì vậy, điều này hoạt động như một bài kiểm tra tính nguyên thủy trong quá trình sàng lọc. 

--- 

### Áp dụng cập nhật toàn bộ```python
phi[multiple] -= phi[multiple] // p
```Thực hiện:$$\phi(n) = \phi(n)\left(1-\frac1p\right)$$với mọi bội số nguyên tố$p$. 

Ví dụ cho$N=8$: 

Sau khi xử lý số nguyên tố:$$\phi = [0,1,1,2,2,4,2,6,4]$$nghĩa:$$\phi(2)=1,\; \phi(3)=2,\; \phi(4)=2,\; \phi(5)=4,\; \phi(6)=2,\; \phi(7)=6,\; \phi(8)=4$$--- 

### Tính tổng tất cả các số đếm```python
sum(phi[2:])
```Đối với mẫu$d \le 8$:$$1+2+2+4+2+6+4 = 21$$phù hợp chính xác với tuyên bố vấn đề.

## 4. Xác minh lần cuối 

Ước tính tiệm cận là:$$\sum_{n\le N}\varphi(n) \approx \frac{3}{\pi^2}N^2$$Vì$N=10^6$:$$\frac{3}{\pi^2}(10^{12}) \approx 3.04\times10^{11}$$Vì vậy, chúng tôi mong đợi câu trả lời vào khoảng vài trăm tỷ, mức độ phù hợp.
