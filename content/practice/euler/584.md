[Vấn đề dự án Euler 584](https://projecteuler.net/problem=584) 

##Giải pháp 

**Trả lời:**`32.83822408`Cho phép$T$là số người trong phòng khi lần đầu tiên chúng ta có **4 ngày sinh nhật cách nhau 7 ngày** trên lịch tròn 365 ngày. 

Quan sát chính là: 

- “Cách nhau 7 ngày” nghĩa là cả 4 ngày sinh nhật đều nằm trong một dãy nhà nào đó$8$ngày dương lịch liên tiếp. 
- Vì sinh nhật rơi vào khoảng cuối năm nên lịch có tính tuần hoàn. 

Định nghĩa$$S_n=\Pr(T>n),$$xác suất sau đó$n$mọi người, **không** chặn$8$ngày liên tiếp chứa$4$hoặc nhiều ngày sinh nhật. 

Sau đó$$\mathbb E[T]=\sum_{n\ge0} S_n.$$Vì vậy, vấn đề giảm xuống việc đếm các cấu hình sinh nhật để tránh mẫu bị cấm. 

--- 

#1. Đếm cấu hình hợp lệ 

hãy để$c_i$là số ngày sinh nhật trong ngày$i$, Ở đâu$i=1,\dots,365$. 

Điều kiện “không có 4 ngày sinh nhật trong vòng 7 ngày” là chính xác$$c_i+c_{i+1}+\cdots+c_{i+7}\le 3$$cho mỗi khối tuần hoàn trong 8 ngày liên tiếp. 

Đối với vector công suất cố định$(c_1,\dots,c_{365})$với tổng số$n$,$$\sum_i c_i=n,$$số lượng bài tập sinh nhật được gắn nhãn nhận ra nó là$$\frac{n!}{\prod_i c_i!}.$$Kể từ đây$$S_n = \frac{n!}{365^n} \sum_{\substack{(c_i)\\ \text{all 8-block sums }\le3\\ \sum c_i=n}} \frac1{\prod_i c_i!}.$$--- 

#2. Lập trình động chuyển trạng thái 

Để thực thi giới hạn 8 ngày, hãy quét lịch từng ngày. 

Một tiểu bang lưu trữ số lượng phòng trống của 7 ngày trước đó:$$(c_{i-6},\dots,c_i).$$Khi thêm một ngày mới với công suất phòng$x$, chúng tôi yêu cầu$$x+c_{i-6}+\cdots+c_i \le 3.$$Do đó tổng số trạng thái là nhỏ:$$\binom{7+3}{7}=120.$$Chúng tôi xây dựng một biểu đồ chuyển giao giữa các trạng thái, được tính trọng số bởi$$\frac{z^x}{x!}.$$Bởi vì lịch có tính tuần hoàn nên các cấu hình hợp lệ hàng năm tương ứng với các bước đi khép kín có độ dài$365$. 

Trích xuất hệ số của$z^n$đưa ra số lượng có trọng số cho$S_n$. 

Cuối cùng,$$\mathbb E[T] = \sum_{n\ge0} S_n.$$--- 

#3. Triển khai Python```python
from math import factorial
import numpy as np

DAYS = 365
GROUP = 4
WINDOW = 7
MAX_N = 100   # far beyond where probabilities become negligible

def generate_states(length, limit):
    """
    Generate all tuples of given length whose entries are
    nonnegative integers with total sum < limit.
    """
    states = []

    def dfs(pos, remaining, cur):
        if pos == length:
            states.append(tuple(cur))
            return

        for x in range(remaining):
            cur.append(x)
            dfs(pos + 1, remaining - x, cur)
            cur.pop()

    dfs(0, limit, [])
    return states

# State length = WINDOW = 7 previous days
states = generate_states(WINDOW, GROUP)

index = {s: i for i, s in enumerate(states)}
S = len(states)

# Build transitions
transitions = [[] for _ in range(S)]

for s in states:
    i = index[s]
    current_sum = sum(s)

    # occupancy on next day
    for x in range(GROUP - current_sum):

        next_state = s[1:] + (x,)
        j = index[next_state]

        weight = 1.0 / factorial(x)

        transitions[i].append((j, x, weight))

# dp[start_state, current_state, n]
dp = np.zeros((S, S, MAX_N + 1), dtype=np.float64)

for i in range(S):
    dp[i, i, 0] = 1.0

# advance through all 365 days
for _ in range(DAYS):

    ndp = np.zeros_like(dp)

    for s in range(S):

        arr = dp[:, s, :]

        for ns, x, w in transitions[s]:

            ndp[:, ns, x:] += arr[:, :MAX_N + 1 - x] * w

    dp = ndp

# closed walks give cyclic configurations
A = np.zeros(MAX_N + 1)

for i in range(S):
    A += dp[i, i, :]

# survival probabilities
survival = np.zeros(MAX_N + 1)

for n in range(MAX_N + 1):
    survival[n] = factorial(n) * A[n] / (DAYS ** n)

expected_value = survival.sum()

print(expected_value)
print(round(expected_value, 8))
