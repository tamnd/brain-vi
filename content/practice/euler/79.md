# Bước 3 - Thứ tự tôpô 

Bây giờ chúng tôi liên tục chọn một chữ số không có chữ số đứng trước chưa gặp. 

Thứ tự xuất hiện duy nhất: 

1.`7`phải đến trước. 
2. Sau đó`3`. 
3. Sau đó`1`. 
4. Sau đó`6`. 
5. Sau đó`2`. 
6. Sau đó`8`. 
7. Sau đó`9`. 
8. Cuối cùng`0`. 

Do đó mật mã ngắn nhất là:$$73162890$$--- 

#Triển khai Python```python
from collections import defaultdict, deque

# Login attempts from the problem file
attempts = [
    "319","680","180","690","129","620","762","689","762","318",
    "368","710","720","710","629","168","160","689","716","731",
    "736","729","316","729","729","710","769","290","719","680",
    "318","389","162","289","162","718","729","319","790","680",
    "890","362","319","760","316","729","380","319","728","716"
]

# Directed graph
graph = defaultdict(set)

# In-degree count for topological sort
indegree = defaultdict(int)

# All digits appearing in the file
digits = set()

# Build precedence graph
for attempt in attempts:
    a, b, c = attempt
    digits.update([a, b, c])

    # Add edge a -> b
    if b not in graph[a]:
        graph[a].add(b)
        indegree[b] += 1

    # Add edge b -> c
    if c not in graph[b]:
        graph[b].add(c)
        indegree[c] += 1

# Ensure every digit exists in indegree dictionary
for d in digits:
    indegree[d] += 0

# Queue all nodes with indegree 0
queue = deque(sorted([d for d in digits if indegree[d] == 0]))

# Topological ordering
result = []

while queue:
    node = queue.popleft()
    result.append(node)

    for nxt in sorted(graph[node]):
        indegree[nxt] -= 1
        if indegree[nxt] == 0:
            queue.append(nxt)

# Construct passcode
passcode = "".join(result)

print(passcode)
```--- 

# Hướng dẫn sử dụng mã 

## Xây dựng biểu đồ```python
graph = defaultdict(set)
indegree = defaultdict(int)
```-`graph[a]`lưu trữ tất cả các chữ số phải theo sau`a`. 
-`indegree[x]`đếm có bao nhiêu chữ số điều kiện tiên quyết`x`có. 

--- 

## Xử lý mỗi lần đăng nhập```python
a, b, c = attempt
```Đối với một chuỗi như`"319"`: 

-`a = '3'`-`b = '1'`-`c = '9'`Chúng tôi thêm các cạnh:```python
a -> b
b -> c
```Điều này mã hóa thứ tự cần thiết. 

--- 

## Sắp xếp cấu trúc liên kết 

chữ số với`indegree = 0`không có điều kiện tiên quyết còn lại.```python
queue = deque(sorted([...]))
```Chúng tôi liên tục: 

1. xóa một chữ số hợp lệ, 
2. thêm nó vào câu trả lời, 
3. giảm độ của các chữ số phụ thuộc. 

Điều này xây dựng một thứ tự ngắn nhất hợp lệ đáp ứng tất cả các ràng buộc.
