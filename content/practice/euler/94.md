[Vấn đề dự án Euler 94](https://projecteuler.net/problem=94) 

## Giải pháp 

**Trả lời:**`518408346`Cho tam giác gần đều có các cạnh: 

-$(a,a,a+1)$, hoặc
-$(a,a,a-1)$,

Ở đâu$a$là một số nguyên. Chúng tôi muốn: 

1. độ dài cạnh nguyên, 
2. diện tích nguyên, 
3. chu vi$\le 10^9$. 

Điều quan trọng là chuyển đổi điều kiện diện tích thành phương trình Pell. 

--- 

# 1. Phân tích toán học 

Đối với tam giác cân có các cạnh bằng nhau$a$và căn cứ$b$, chiều cao là$$h=\sqrt{a^2-\left(\frac b2\right)^2}.$$Diện tích là$$A=\frac12 bh.$$Chúng tôi cần$A$là một số nguyên. 

Từ$b=a\pm1$, viết:$$A=\frac b2\sqrt{a^2-\frac{b^2}{4}} =\frac b4\sqrt{4a^2-b^2}.$$Vì vậy chúng tôi yêu cầu$$4a^2-b^2$$thành một hình vuông hoàn hảo. 

Cho phép$$b=a\pm1.$$Sau đó$$4a^2-(a\pm1)^2 =3a^2\mp2a-1.$$Vì vậy chúng ta cần$$3a^2\mp2a-1 = k^2.$$--- 

## Trường hợp 1:$(a,a,a+1)$chúng tôi nhận được$$k^2=3a^2-2a-1.$$Nhân với 3:$$3k^2 = 9a^2-6a-3.$$Thêm 1:$$3k^2+1 = (3a-1)^2.$$Kể từ đây$$(3a-1)^2-3k^2=1.$$Cho phép$$x=3a-1,\qquad y=k.$$Sau đó$$x^2-3y^2=1.$$Đây là phương trình Pell. 

Cũng:$$a=\frac{x+1}{3}.$$Chúng tôi cần$x\equiv2\pmod3$. 

Chu vi là$$P=3a+1=x+2.$$--- 

## Trường hợp 2:$(a,a,a-1)$Tương tự,$$k^2=3a^2+2a-1.$$Nhân với 3 và cộng 1:$$(3a+1)^2-3k^2=1.$$Cho phép$$x=3a+1.$$Lại:$$x^2-3y^2=1.$$Hiện nay$$a=\frac{x-1}{3},$$và chu vi:$$P=3a-1=x-2.$$--- 

## Cấu trúc phương trình Pell 

Chúng ta phải liệt kê các giải pháp$x^2-3y^2=1$Giải pháp cơ bản là$$(2,1),$$và mọi giải pháp đều đến từ$$x_n+y_n\sqrt3=(2+\sqrt3)^n.$$Chúng tôi chỉ giữ lại những người tạo ra các hình tam giác hợp lệ và với$$P\le10^9.$$Sự lặp lại của giải pháp Pell là:$$x_{n+1}=2x_n+3y_n,$$

$$y_{n+1}=x_n+2y_n.$$Kiểm tra vài cái đầu tiên: 

|$a$| Tam giác | Chu vi | 
| --- | --- | --- | 
| 5 | 5-5-6 | 16 | 
| 17 | 17-17-16 | 50 | 
| 65 | 65-65-66 | 196 | 
| 241 | 241-241-240 | 722 | 

Chúng khớp với các ví dụ đã biết và tiếp tục xen kẽ. 

Chúng tôi tổng hợp tất cả các chu vi hợp lệ dưới$10^9$. 

--- 

#2. Triển khai Python```python
LIMIT = 1_000_000_000

total = 0

# Fundamental Pell solution
x, y = 2, 1

while True:
    added = False

    # Case: (a, a, a+1)
    if (x + 1) % 3 == 0:
        a = (x + 1) // 3
        p = 3 * a + 1

        # Check triangle validity
        if p <= LIMIT and 2 * a > a + 1:
            total += p
            added = True

    # Case: (a, a, a-1)
    if (x - 1) % 3 == 0:
        a = (x - 1) // 3
        p = 3 * a - 1

        # Check triangle validity
        if p <= LIMIT and a > 1:
            total += p
            added = True

    # Generate next Pell solution
    x, y = 2 * x + 3 * y, x + 2 * y

    # Stop once both possible perimeters exceed limit
    if x - 2 > LIMIT and x + 2 > LIMIT:
        break

print(total)
```--- 

#3. Hướng dẫn sử dụng mã 

### Khởi tạo```python
LIMIT = 1_000_000_000
total = 0
x, y = 2, 1
```Chúng tôi bắt đầu từ giải pháp Pell cơ bản$$(2,1).$$--- 

### Kiểm tra cả hai dạng tam giác 

Đối với mỗi giải pháp Pell:```python
if (x + 1) % 3 == 0:
```Điều này tương ứng với$$x=3a-1$$cho hình tam giác$(a,a,a+1)$. 

Chúng tôi phục hồi:$$a=\frac{x+1}{3}$$và chu vi$$P=3a+1.$$Tương tự:```python
if (x - 1) % 3 == 0:
```tay cầm$$x=3a+1$$cho hình tam giác$(a,a,a-1)$. 

--- 

### Pell tái phát```python
x, y = 2 * x + 3 * y, x + 2 * y
```Điều này tạo ra tất cả các giải pháp để$$x^2-3y^2=1.$$Trình tự này tăng nhanh theo cấp số nhân nên chỉ cần vài chục lần lặp. 

--- 

### Kiểm tra ví dụ nhỏ 

Mã tạo ra: 

-$5\!-\!5\!-\!6$, chu vi$16$, 
-$17\!-\!17\!-\!16$, chu vi$50$, 
-$65\!-\!65\!-\!66$, chu vi$196$, 

tất cả đều thực sự có diện tích nguyên. 

Ví dụ:$$5\!-\!5\!-\!6: \quad h=\sqrt{25-9}=4,$$

$$A=\frac12(6)(4)=12.$$Chính xác.
