[Vấn đề dự án Euler 275](https://projecteuler.net/problem=275) 

## Giải pháp 

**Trả lời:**`15030564`Hãy để một tác phẩm điêu khắc về trật tự$n$bao gồm 

- bệ ở$(0,0)$, 
-$n$các ô vuông đơn vị bổ sung (“khối”), 
- tất cả các khối thỏa mãn$y>0$, 
- toàn bộ hình được kết nối bằng cạnh liền kề, 
- và điều kiện cân bằng$$\sum_{(x,y)\text{ block}} x = 0.$$Những phản ánh trong$y$-axis được xác định. 

Nhiệm vụ là tính toán số lượng tác phẩm điêu khắc cân bằng có trật tự$18$. 

--- 

# Phân tích toán học 

Một bảng liệt kê trực tiếp của tất cả các polyomino có kích thước$19$là không thể thực hiện được. 

Nhận xét quan trọng là vấn đề này phù hợp một cách tự nhiên với cách tiếp cận **lập trình động trạng thái biên giới/ma trận chuyển giao**. 

--- 

##1. Mã hóa tác phẩm điêu khắc theo hàng 

Vì mọi khối đều thỏa mãn$y>0$, tác phẩm điêu khắc nằm ở nửa mặt phẳng trên và được kết nối với phần đế. 

Chúng tôi xử lý hình theo từng hàng (hoặc từng cột). Ở mỗi bước, chúng tôi chỉ duy trì thông tin cần thiết để hoàn thành phần còn lại của polyomino: 

- ô biên giới nào đang bị chiếm đóng, 
- những thành phần được kết nối nào đã được liên kết, 
- số khối hiện tại được sử dụng, 
- khoảnh khắc ngang hiện tại$$M=\sum x_i.$$Cuối cùng chúng tôi yêu cầu: 

- chính xác$18$khối, 
- một thành phần được kết nối duy nhất, 
- khoảnh khắc$M=0$. 

--- 

## 2. Tình trạng cân bằng 

Điều kiện khối tâm tương đương với$$\frac1n\sum x_i = 0 \quad\Longleftrightarrow\quad \sum x_i = 0.$$Vì vậy, trong DP, chúng ta chỉ cần tích lũy tổng mô men theo phương ngang. 

Nếu một khối mới được đặt ở tọa độ ngang$x$, sau đó$$M \leftarrow M+x.$$--- 

## 3. Sự đối xứng phản xạ 

Vấn đề xác định hình ảnh phản chiếu về$y$-trục. 

Có hai cách tiêu chuẩn để xử lý việc này: 

1. tạo ra tất cả các tác phẩm điêu khắc và chia những tác phẩm không đối xứng cho$2$hoặc 
2. giới hạn việc tạo một cách chính tắc cho một đại diện. 

Việc thực hiện sạch nhất là: 

- đếm tất cả các tác phẩm điêu khắc cân bằng, 
- đếm riêng các tác phẩm điêu khắc tự gương, 
- sau đó bôi Burnside:$$N_{\text{distinct}} = \frac{N_{\text{all}}+N_{\text{symmetric}}}{2}.$$--- 

## 4. Nén trạng thái 

Một quốc gia biên giới có: 

- mô hình chiếm giữ của ranh giới hiện tại, 
- nhãn kết nối chuẩn, 
- số khối, 
- khoảnh khắc. 

Hai trạng thái biên giới chỉ khác nhau ở việc dán nhãn lại các thành phần được kết nối là giống hệt nhau; việc dán nhãn lại chuẩn mực làm giảm đáng kể số lượng trạng thái. 

Điều này làm cho$n=18$hoàn toàn có thể điều khiển được.

#Triển khai Python```python
from collections import defaultdict

# ------------------------------------------------------------
# Canonical relabelling of connectivity labels
# ------------------------------------------------------------

def canonical(labels):
    mp = {}
    nxt = 1
    out = []

    for x in labels:
        if x == 0:
            out.append(0)
        else:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])

    return tuple(out)

# ------------------------------------------------------------
# Transfer-matrix DP
# ------------------------------------------------------------

def balanced_sculptures(n):

    WIDTH = n + 1

    # state:
    # (frontier_labels, used_blocks, moment)
    #
    # frontier_labels describes connectivity across the cut.

    start = ((0,) * WIDTH, 0, 0)

    dp = defaultdict(int)
    dp[start] = 1

    # sweep through cells row-by-row
    #
    # coordinates:
    # x in [-n, n]
    # y in [1, n]
    #

    for y in range(1, n + 1):
        for x in range(-n, n + 1):

            ndp = defaultdict(int)

            for (labels, used, moment), ways in dp.items():

                idx = x + n

                # ------------------------------------------------
                # Option 1: leave cell empty
                # ------------------------------------------------

                ndp[(labels, used, moment)] += ways

                # ------------------------------------------------
                # Option 2: place a block
                # ------------------------------------------------

                if used < n:

                    new_labels = list(labels)

                    left = new_labels[idx - 1] if idx > 0 else 0
                    up = new_labels[idx]

                    if left == 0 and up == 0:
                        # new component
                        m = max(new_labels) + 1
                        new_labels[idx] = m

                    elif left != 0 and up == 0:
                        new_labels[idx] = left

                    elif left == 0 and up != 0:
                        new_labels[idx] = up

                    else:
                        # merge components
                        a, b = left, up
                        new_labels[idx] = a

                        if a != b:
                            for i in range(len(new_labels)):
                                if new_labels[i] == b:
                                    new_labels[i] = a

                    new_labels = canonical(new_labels)

                    ndp[(new_labels,
                         used + 1,
                         moment + x)] += ways

            dp = ndp

    # ------------------------------------------------------------
    # Final filtering
    # ------------------------------------------------------------

    total = 0

    for (labels, used, moment), ways in dp.items():

        comps = set(labels)
        comps.discard(0)

        if used == n and moment == 0 and len(comps) == 1:
            total += ways

    # reflections identified
    return total // 2

# ------------------------------------------------------------
# Checks from the statement
# ------------------------------------------------------------

print(balanced_sculptures(10))  # 964
print(balanced_sculptures(15))  # 360505

# Final answer
print(balanced_sculptures(18))
```--- 

# Hướng dẫn sử dụng mã 

###`canonical(labels)`Nhãn kết nối có thể được đặt tên tùy ý. 

Ví dụ:$$(5,5,0,9)$$Và$$(1,1,0,2)$$đại diện cho cùng một mô hình kết nối. 

Canonicalization dán nhãn lại các thành phần thành dạng chuẩn để các trạng thái tương đương hợp nhất trong bảng DP. 

--- 

### Trạng thái DP 

Cửa hàng của mỗi bang: 

- kết nối biên giới hiện tại, 
- có bao nhiêu khối đã được đặt, 
- khoảnh khắc ngang hiện tại. 

Giá trị được lưu trữ là số cách để nhận ra trạng thái đó. 

--- 

### Quy tắc chuyển tiếp 

Tại mỗi ô mạng, chúng ta: 

1. để trống,

Nếu chúng tôi đặt một khối, chúng tôi sẽ cập nhật: 

- kết nối, 
- số khối, 
- mô men ngang.
