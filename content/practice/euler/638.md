[Vấn đề dự án Euler 638](https://projecteuler.net/problem=638) 

## Giải pháp 

**Trả lời:**`18423394`Hãy để con đường bao gồm$a$bước đi đúng đắn và$b$bước lên. 

Nếu chúng ta mã hóa một đường dẫn theo độ cao tại đó xảy ra các bước bên phải thì diện tích bên dưới đường dẫn chính xác là tổng của các độ cao đó. 

Quan sát quan trọng là đây là một **$q$-hệ số nhị thức** (nhị thức Gaussian). 

Đối với một con đường$P_{a,b}$,$$C(a,b,k) = \sum_{P_{a,b}} k^{A(P)}$$là hàm tạo cho các đường mạng có trọng số theo diện tích. Đây là bản sắc cổ điển:$$C(a,b,k) = \binom{a+b}{a}_k = \prod_{i=1}^{a} \frac{k^{b+i}-1}{k^i-1}.$$Điều này xảy ra do thống kê diện tích trên các đường mạng đơn điệu tương ứng với khu vực biểu đồ đếm ngược/Ferrers, có hàm sinh là nhị thức Gaussian. 

Vì$k=1$, biểu thức trở thành hệ số nhị thức thông thường:$$C(a,b,1)=\binom{a+b}{a},$$phù hợp với ví dụ đã cho:$$C(10,10,1)=\binom{20}{10}=184756.$$Chúng tôi có thể xác minh một mẫu khác:$$C(15,10,3) = \prod_{i=1}^{15} \frac{3^{10+i}-1}{3^i-1} \equiv 880419838 \pmod{10^9+7},$$phù hợp với tuyên bố. 

### Thuật toán hiệu quả 

Chúng tôi cần$$\sum_{k=1}^{7} C(10^k+k,10^k+k,k) \pmod{10^9+7}.$$Từ$$C(n,n,k) = \prod_{i=1}^{n} \frac{k^{n+i}-1}{k^i-1},$$chúng tôi đánh giá sản phẩm theo modulo lặp đi lặp lại$$M=1\,000\,000\,007.$$Bởi vì$M$là số nguyên tố, việc chia được thực hiện bằng cách sử dụng nghịch đảo mô đun:$$x^{-1}\equiv x^{M-2}\pmod M.$$Triển khai Python:```python
MOD = 1_000_000_007

def C(a, b, k):
    # Special case q = 1:
    # ordinary binomial coefficient C(a+b, a)
    if k == 1:
        res = 1
        for i in range(1, a + 1):
            res = res * (b + i) % MOD
            res = res * pow(i, MOD - 2, MOD) % MOD
        return res

    q = k % MOD
    q_to_b = pow(k, b, MOD)

    res = 1
    q_pow_i = 1

    # Product:
    # ∏_{i=1}^{a} (k^(b+i)-1)/(k^i-1)
    for i in range(1, a + 1):
        q_pow_i = q_pow_i * q % MOD

        numerator = (q_to_b * q_pow_i - 1) % MOD
        denominator = (q_pow_i - 1) % MOD

        res = (
            res
            * numerator
            % MOD
            * pow(denominator, MOD - 2, MOD)
            % MOD
        )

    return res

answer = 0

for k in range(1, 8):
    n = 10**k + k
    answer = (answer + C(n, n, k)) % MOD

print(answer)
```### Hướng dẫn sử dụng mã 

-`C(a, b, k)`tính tổng đường dẫn mạng có trọng số. 
- Nếu như`k == 1`, chúng tôi tính hệ số nhị thức thông thường$\binom{a+b}{a}$. 
- Ngược lại ta sử dụng công thức tích nhị thức Gaussian. 
-`q_pow_i`cửa hàng$k^i$tăng dần. 
- Mỗi yếu tố$$\frac{k^{b+i}-1}{k^i-1}$$được nhân theo modulo$10^9+7$, sử dụng nghịch đảo Fermat. 

Kiểm tra vệ sinh: 

-`C(2,2,1) = 6`-`C(2,2,2) = 35`-`C(10,10,1) = 184756`-`C(15,10,3) ≡ 880419838 (mod 10^9+7)`-`C(10000,10000,4) ≡ 395913804 (mod 10^9+7)`Tất cả đều phù hợp với tuyên bố vấn đề. 

Các giá trị tính toán cho$k=1,\dots,7$tổng hợp thành:$$18\,423\,394 \pmod{1\,000\,000\,007}.$$**Trả lời: 18423394**
