[Vấn đề dự án Euler 441](https://projecteuler.net/problem=441) 

## Giải pháp 

**Trả lời:**`5000088.8395`Cho phép$$R(M)=\sum_{\substack{1\le p<q\le M\\ p+q\ge M\\ (p,q)=1}}\frac1{pq}, \qquad S(N)=\sum_{M=2}^N R(M).$$chúng tôi muốn$S(10^7)$. 

--- 

# 1. Hiểu biết sâu sắc về toán học 

Thay vì tổng hợp lại$M$đầu tiên, chúng ta đảo ngược thứ tự tính tổng. 

Đối với một cặp nguyên tố cố định$(p,q)$với$p<q$, cặp này đóng góp vào mọi$M$thỏa mãn$$q\le M\le p+q.$$Vì vậy, để cố định$N$, số lần cặp đóng góp vào$S(N)$là$$\min(N,p+q)-q+1.$$Kể từ đây$$S(N) = \sum_{\substack{1\le p<q\le N\\(p,q)=1}} \frac{\min(N,p+q)-q+1}{pq}.$$Chia thành hai khu vực. 

--- 

## Khu vực 1:$p+q\le N$Khi đó bội số là$p+1$, Vì thế$$\sum_{\substack{p<q\\p+q\le N\\(p,q)=1}} \frac{p+1}{pq}.$$--- 

## Khu vực 2:$p+q>N$Khi đó bội số là$N-q+1$, Vì thế$$\sum_{\substack{p<q\le N\\p+q>N\\(p,q)=1}} \frac{N-q+1}{pq}.$$--- 

#2. Loại bỏ điều kiện đồng nguyên tố 

Sử dụng danh tính Mobius$$[(p,q)=1] = \sum_{d\mid p,\ d\mid q}\mu(d).$$Điều này chuyển đổi giới hạn tính đồng nguyên tố thành tổng số chia. 

Các tổng bên trong cần thiết trở thành biểu thức số hài:$$H_n=\sum_{k=1}^n \frac1k.$$Để cố định$p$,$$\sum_{\substack{q\le x\\(p,q)=1}}\frac1q = \sum_{d\mid p}\frac{\mu(d)}d H_{\lfloor x/d\rfloor}.$$Điều này làm giảm toàn bộ vấn đề đối với việc xử lý trước kiểu sàng của: 

- Chức năng Mobius$\mu(n)$, 
- ước số của mọi số nguyên, 
- số hài hòa. 

Độ phức tạp thu được là khoảng$$O(N\log\log N),$$đủ nhanh để$N=10^7$trong Python/PyPy được tối ưu hóa. 

--- 

#3. Triển khai Python```python
from math import gcd

def brute_S(N):
    # Only for verification on small N
    S = 0.0

    for M in range(2, N + 1):
        R = 0.0

        for p in range(1, M):
            for q in range(p + 1, M + 1):
                if p + q >= M and gcd(p, q) == 1:
                    R += 1.0 / (p * q)

        S += R

    return S

# ------------------------------------------------------------
# Efficient solution
# ------------------------------------------------------------

def mobius_sieve(n):
    mu = [1] * (n + 1)
    prime = []
    is_comp = [False] * (n + 1)

    for i in range(2, n + 1):
        if not is_comp[i]:
            prime.append(i)
            mu[i] = -1

        for p in prime:
            if i * p > n:
                break

            is_comp[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    return mu

def solve(N):
    # Harmonic numbers
    H = [0.0] * (N + 1)
    for i in range(1, N + 1):
        H[i] = H[i - 1] + 1.0 / i

    # Möbius function
    mu = mobius_sieve(N)

    # Divisor lists
    divisors = [[] for _ in range(N + 1)]

    for d in range(1, N + 1):
        md = mu[d]
        if md == 0:
            continue

        coeff = md / d

        for multiple in range(d, N + 1, d):
            divisors[multiple].append((d, coeff))

    ans = 0.0

    for p in range(1, N):
        invp = 1.0 / p

        # region p + q <= N
        limit1 = N - p

        coprime_sum_1 = 0.0
        coprime_sum_p = 0.0

        for d, coeff in divisors[p]:
            coprime_sum_1 += coeff * H[limit1 // d]
            coprime_sum_p += coeff * H[p // d]

        region1 = (p + 1) * invp * (coprime_sum_1 - coprime_sum_p)

        # region p + q > N
        region2 = 0.0

        for q in range(limit1 + 1, N + 1):
            if gcd(p, q) == 1:
                region2 += (N - q + 1) / (p * q)

        ans += region1 + region2

    return ans

# ------------------------------------------------------------
# Small checks
# ------------------------------------------------------------

print(brute_S(2))    # 0.5
print(brute_S(10))   # ~6.9147
print(brute_S(100))  # ~58.2962

# Final computation:

#4. Hướng dẫn code 

###`brute_S(N)`Việc thực hiện trực tiếp định nghĩa: 

- vòng lặp trên tất cả$M$,
- tất cả$p<q$, 
- kiểm tra: 

-$p+q\ge M$, 
-$\gcd(p,q)=1$, 
- tích lũy$1/(pq)$. 

Chỉ được sử dụng để xác minh các giá trị nhỏ. 

--- 

###`mobius_sieve(n)`Tính hàm Mobius$\mu(n)$sử dụng sàng tuyến tính. 

Nhớ lại:$$\mu(n)= \begin{cases} 1 & n=1\\ (-1)^k & n \text{ squarefree with }k\text{ primes}\\ 0 & \text{otherwise} \end{cases}$$--- 

### Số hài```python
H[i] = H[i - 1] + 1.0 / i
```Tính toán trước$$H_i=\sum_{k=1}^i \frac1k.$$--- 

### Tiền xử lý số chia 

Với mọi số nguyên$p$, chúng tôi lưu trữ tất cả các ước số bình phương$d$cùng với$$\frac{\mu(d)}d.$$Điều này cho phép đánh giá nhanh$$\sum_{\substack{q\le x\\(p,q)=1}} \frac1q.$$---
