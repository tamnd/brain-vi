##Giải pháp 

**Trả lời:**`4075`Chúng ta phải đếm xem có bao nhiêu hệ số nhị thức$$\binom{n}{r}$$với$1 \le n \le 100$lớn hơn$1{,}000{,}000$. 

--- 

# Phân tích toán học 

Hệ số nhị thức là$$\binom{n}{r}=\frac{n!}{r!(n-r)!}.$$Có thể tính toán trực tiếp bằng cách sử dụng giai thừa, nhưng có một quan sát cấu trúc quan trọng hơn. 

##1. Tính đối xứng của hệ số nhị thức 

Chúng tôi có danh tính$$\binom{n}{r}=\binom{n}{n-r}.$$Vì vậy, các giá trị đối xứng xung quanh$r=n/2$. 

Ví dụ,$$\binom{23}{10}=\binom{23}{13}.$$Sự đối xứng này giúp giảm bớt công việc. 

--- 

## 2. Hành vi tăng trưởng 

Để cố định$n$, trình tự$$\binom{n}{0}, \binom{n}{1}, \dots, \binom{n}{n}$$tăng dần đến giữa rồi giảm dần đối xứng. 

Vì vậy, một khi hệ số vượt quá một triệu, tất cả các hệ số ở gần giữa cũng sẽ vượt quá một triệu. 

Vì vậy đối với mỗi$n$: 

1. Tìm cái đầu tiên$r$như vậy$$\binom{n}{r} > 1{,}000{,}000.$$1. Khi đó tất cả các giá trị từ$r$bởi vì$n-r$vượt quá một triệu. 

Do đó số lượng đóng góp bởi hàng đó là$$(n-r) - r + 1 = n - 2r + 1.$$--- 

## 3. Tái phát hiệu quả 

Thay vì tính giai thừa, hãy tính các hệ số lặp đi lặp lại bằng cách sử dụng$$\binom{n}{r} = \binom{n}{r-1}\cdot\frac{n-r+1}{r}.$$Điều này tránh được các tính toán giai thừa lớn. 

Bắt đầu với$$\binom{n}{0}=1.$$Sau đó liên tục tạo ra hệ số tiếp theo. 

--- 

#Triển khai Python```python
# Count binomial coefficients greater than one million

LIMIT = 1_000_000
count = 0

# Loop through all n from 1 to 100
for n in range(1, 101):

    # Start with C(n,0) = 1
    c = 1

    # Compute coefficients iteratively
    for r in range(1, n + 1):

        # Recurrence relation:
        # C(n,r) = C(n,r-1) * (n-r+1) / r
        c = c * (n - r + 1) // r

        # Once we exceed the limit,
        # all coefficients up to C(n,n-r) also exceed it
        if c > LIMIT:
            count += (n - 2 * r + 1)
            break

print(count)
```---

# Xác minh ví dụ nhỏ 

Vấn đề nêu rõ:$$\binom{23}{10} = 1144066 > 1{,}000{,}000.$$Thật vậy, đối với$n=23$, hệ số vượt quá đầu tiên xảy ra tại$r=10$. 

Theo tính đối xứng:$$\binom{23}{10}, \binom{23}{11}, \binom{23}{12}, \binom{23}{13}$$tất cả đều vượt quá một triệu. 

Đếm:$$23 - 2(10) + 1 = 4,$$cái nào phù hợp.
