[Vấn đề dự án Euler 603](https://projecteuler.net/problem=603) 

##Giải pháp 

**Trả lời:**`879476477`Đặt các chữ số thập phân của một số/chuỗi là$d_1,d_2,\dots,d_N$. 

Chúng ta phải tính toán$$S(n)=\sum_{\text{all contiguous substrings}} \text{(substring value)}.$$Đối với vấn đề: 

-$P(n)$= nối của cái đầu tiên$n$số nguyên tố, 
-$C(n,k)$=$P(n)$lặp đi lặp lại$k$lần, 
- bắt buộc:$$S(C(10^6,10^{12})) \pmod{10^9+7}.$$--- 

# 1. Phân tích toán học 

## 1.1 Đóng góp của một chữ số 

Sửa một chữ số$d_i$ở vị trí$i$(1-lập chỉ mục từ bên trái). 

Giả sử một chuỗi con bắt đầu ở một vị trí nào đó$\le i$và kết thúc tại$j\ge i$. 

Bên trong chuỗi con đó,$d_i$đóng góp$$d_i \cdot 10^{j-i}.$$Có bao nhiêu lựa chọn về điểm xuất phát? 

Chính xác$i$sự lựa chọn. 

Vì vậy tổng đóng góp của$d_i$là$$d_i \cdot i \sum_{j=i}^{N} 10^{j-i}.$$Cho phép$t=j-i$. Sau đó$$\sum_{t=0}^{N-i}10^t = \frac{10^{N-i+1}-1}{9}.$$Vì thế$$S = \sum_{i=1}^{N} d_i\, i \,\frac{10^{N-i+1}-1}{9}.$$Vì thế$$S = \frac1{9} \left( 10^{N+1}\sum_{i=1}^{N} d_i i 10^{-i} - \sum_{i=1}^{N} d_i i \right).$$Bây giờ mọi thứ được giảm xuống thành tổng chữ số có trọng số. 

--- 

#1.2 Các khối lặp đi lặp lại 

Cho chuỗi chữ số của$P(n)$có chiều dài$L$, với các chữ số$$a_1,a_2,\dots,a_L.$$Chúng tôi lặp lại khối này$k$lần. 

Một chữ số trong bản sao$r$(Ở đâu$0\le r<k$) và vị trí bên trong$i$có vị trí toàn cầu$$rL+i.$$Định nghĩa$$q=10^{-1}\pmod M, \qquad M=10^9+7.$$Sau đó$$10^{- (rL+i)} = q^{rL+i}.$$Chúng tôi cần$$T = \sum_{r=0}^{k-1}\sum_{i=1}^{L} a_i(rL+i)q^{rL+i}.$$Nhân tố:$$T = \sum_{r=0}^{k-1} q^{rL} \left( rL \sum_i a_i q^i + \sum_i a_i i q^i \right).$$Định nghĩa$$B=\sum_i a_i q^i, \qquad C=\sum_i a_i i q^i.$$Sau đó$$T = BL\sum_{r=0}^{k-1} r x^r + C\sum_{r=0}^{k-1} x^r,$$Ở đâu$$x=q^L.$$Chúng tôi cũng cần$$U=\sum d_i i = kE + DL\frac{k(k-1)}2,$$Ở đâu$$D=\sum_i a_i, \qquad E=\sum_i a_i i.$$Như vậy$$S = \frac{ 10^{N+1}T-U }{9}, \qquad N=Lk.$$--- 

# 1.3 Tổng hình học 

Chúng tôi sử dụng$$G_0=\sum_{r=0}^{k-1}x^r = \frac{1-x^k}{1-x},$$Và$$G_1=\sum_{r=0}^{k-1} r x^r = \frac{x(1-kx^{k-1}+(k-1)x^k)}{(1-x)^2}.$$Vì thế$$T = BLG_1 + CG_0.$$Mọi thứ bây giờ có thể được tính toán theo modulo$M$.

#2. Triển khai Python```python
MOD = 10**9 + 7

INV9 = pow(9, MOD - 2, MOD)
INV10 = pow(10, MOD - 2, MOD)
INV2 = pow(2, MOD - 2, MOD)

N_PRIMES = 10**6
K = 10**12

# ------------------------------------------------------------
# Sieve for first 1,000,000 primes
# ------------------------------------------------------------

import math

# Standard upper bound for nth prime
LIMIT = int(
    N_PRIMES * (
        math.log(N_PRIMES) +
        math.log(math.log(N_PRIMES))
    )
) + 100

sieve = bytearray(b"\x01") * (LIMIT + 1)
sieve[0] = sieve[1] = 0

for p in range(2, int(math.isqrt(LIMIT)) + 1):
    if sieve[p]:
        start = p * p
        sieve[start:LIMIT + 1:p] = b"\x00" * (
            ((LIMIT - start) // p) + 1
        )

# ------------------------------------------------------------
# Build digit statistics for P(10^6)
# ------------------------------------------------------------

L = 0

B = 0
C = 0
D = 0
E = 0

qpow = 1
count = 0

for p in range(2, LIMIT + 1):
    if sieve[p]:
        count += 1

        for ch in str(p):
            d = ord(ch) - 48

            L += 1

            # q^L
            qpow = (qpow * INV10) % MOD

            B = (B + d * qpow) % MOD
            C = (C + d * L * qpow) % MOD

            D = (D + d) % MOD
            E = (E + d * L) % MOD

        if count == N_PRIMES:
            break

# ------------------------------------------------------------
# Geometric sums
# ------------------------------------------------------------

x = pow(INV10, L, MOD)

den = (1 - x) % MOD
den_inv = pow(den, MOD - 2, MOD)

G0 = (1 - pow(x, K, MOD)) * den_inv
G0 %= MOD

G1 = (
    x *
    (1 - K * pow(x, K - 1, MOD) + (K - 1) * pow(x, K, MOD))
)

G1 %= MOD

G1 = (G1 * den_inv * den_inv) % MOD

# ------------------------------------------------------------
# Assemble formula
# ------------------------------------------------------------

T = (B * L % MOD) * G1
T += C * G0
T %= MOD

U = (
    (K % MOD) * E
    + D * (L % MOD) % MOD
      * ((K - 1) % MOD) % MOD
      * (K % MOD) % MOD
      * INV2
)
U %= MOD

# exponent reduced modulo MOD-1 by Fermat
N_mod = (L % (MOD - 1)) * (K % (MOD - 1))
N_mod %= (MOD - 1)

answer = (
    (pow(10, N_mod + 1, MOD) * T - U)
    * INV9
) % MOD

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

##Phần sàng 

Chúng tôi tạo ra một triệu số nguyên tố đầu tiên bằng cách sử dụng sàng bytearray tiêu chuẩn. 

Số nguyên tố thứ một triệu là$15{,}485{,}863$, do đó giới hạn trên gần$1.65\times10^7$là đủ. 

--- 

## Xây dựng số liệu thống kê chữ số 

Khi chúng tôi ghép các số nguyên tố theo từng chữ số, chúng tôi duy trì: 

-$L$: tổng số chữ số, 
-$B=\sum a_i q^i$, 
-$C=\sum a_i i q^i$, 
-$D=\sum a_i$, 
-$E=\sum a_i i$. 

Chúng ta không bao giờ tự mình xây dựng nên con số khổng lồ. 

--- 

## Tổng hình học 

Bởi vì$C(n,k)$là một khối lặp lại, tất cả các hiệu ứng sao chép lặp lại sẽ thu gọn thành:$$G_0=\sum x^r, \qquad G_1=\sum r x^r.$$Cả hai đều được tính toán trong$O(\log k)$thời gian bằng cách sử dụng lũy ​​thừa mô-đun. 

--- 

## Lắp ráp cuối cùng 

Chúng tôi tính toán$$S=\frac{10^{N+1}T-U}{9}\pmod M.$$Từ$N=Lk$là rất lớn, chúng ta giảm modulo số mũ$M-1$sử dụng định lý Fermat.
