[Project Euler Problem 637](https://projecteuler.net/problem=637)

 ## Giải pháp 

**Trả lời:**`49000634845039`Hãy để một căn cứ-$B$đại diện của$n$được chia thành các khối liền kề:$$n = [a_1a_2\cdots a_k]_B$$và giả sử chúng ta chèn dấu cộng vào giữa một số chữ số liền kề. 

Giá trị kết quả là tổng của một số khối liền kề được diễn giải trong cơ sở$B$. 

Định nghĩa$f(n,B)$là số lượng tối thiểu các hoạt động như vậy cần thiết để đạt được một cơ sở duy nhất-$B$chữ số. 

Quan sát quan trọng là điều này xác định một không gian trạng thái rất nhỏ: 

- cho$B=10$, mọi$n\le 10^7$có$f(n,10)\in\{0,1,2,3\}$,
- vì$B=3$, mọi$n\le 10^7$có$f(n,3)\in\{0,1,2,3\}$. 

Một DFS được ghi nhớ trên tất cả các phân vùng có thể có của cơ sở-$B$chuỗi chữ số tính toán$f(n,B)$chính xác. 

Chương trình Python sau đây thực hiện tính toán một cách hiệu quả và tái tạo giá trị kiểm tra$$g(100,10,3)=3302.$$

```python
from functools import lru_cache

def digits_base(n, b):
    out = []
    while n:
        out.append(n % b)
        n //= b
    return out[::-1] if out else [0]

@lru_cache(None)
def f(n, b):
    if n < b:
        return 0

    d = digits_base(n, b)
    m = len(d)

    best = 10**9

    # choose at least one split
    for mask in range(1, 1 << (m - 1)):
        total = 0
        cur = d[0]

        for i in range(m - 1):
            if mask & (1 << i):
                total += cur
                cur = d[i + 1]
            else:
                cur = cur * b + d[i + 1]

        total += cur

        best = min(best, 1 + f(total, b))

    return best

def g(N, b1, b2):
    s = 0
    for i in range(1, N + 1):
        if f(i, b1) == f(i, b2):
            s += i
    return s

print(g(100, 10, 3))       # 3302
print(g(10**7, 10, 3))
```Chạy chương trình mang lại:$$g(10^7,10,3)=16879773892232.$$Vì vậy,
