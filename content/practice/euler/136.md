## Giải pháp 

**Trả lời:**`2544559`Cho phép$$x,\ y,\ z$$là số hạng liên tiếp của một cấp số cộng. Viết chúng như$$x = y+d,\qquad z = y-d$$với một số nguyên dương nào đó$d$. 

Chúng tôi được yêu cầu học$$x^2-y^2-z^2=n.$$Chúng tôi muốn đếm xem có bao nhiêu$n<50\,000\,000$có **chính xác một** nghiệm là số nguyên dương. 

--- 

# 1. Phân tích toán học 

Thay thế$$x=y+d,\qquad z=y-d.$$Sau đó$$n=(y+d)^2-y^2-(y-d)^2.$$Mở rộng:$$(y+d)^2 = y^2+2yd+d^2,$$

$$(y-d)^2 = y^2-2yd+d^2.$$Vì thế$$n = (y^2+2yd+d^2)-y^2-(y^2-2yd+d^2).$$Đơn giản hóa:$$n = 4yd-y^2-d^2.$$Hệ số hóa rõ ràng hơn sẽ xuất hiện nếu chúng ta chuyển đổi các biến. 

Cho phép$$a = y-d = z.$$Sau đó$$y=a+d,\qquad x=a+2d.$$Thay thế:$$n=(a+2d)^2-(a+d)^2-a^2.$$Mở rộng:$$(a+2d)^2=a^2+4ad+4d^2,$$

$$(a+d)^2=a^2+2ad+d^2.$$Kể từ đây$$n=a^2+4ad+4d^2-a^2-2ad-d^2-a^2.$$Vì thế$$n=2ad+3d^2-a^2.$$Nhân tố:$$n=(3d-a)(a+d).$$Bây giờ xác định$$u=3d-a,\qquad v=a+d.$$Sau đó$$n=uv.$$Cũng,$$u+v=4d,$$Vì thế$u\equiv -v\pmod 4$, tương đương$$u+v\equiv0\pmod4.$$Và kể từ đó$$a=\frac{3v-u}{4}>0,$$chúng ta phải có$$u<3v.$$--- 

## Tham số hóa đơn giản hơn nhiều 

Có một sự đơn giản hóa tiêu chuẩn. 

Bắt đầu từ$$n=(3d-a)(a+d),$$bộ$$p=a+d,\qquad q=3d-a.$$Sau đó$$n=pq,$$Và$$p+q=4d.$$Do đó, mọi giải pháp đều tương ứng chính xác với việc phân tích nhân tử$$n=pq$$như vậy$$p+q\equiv0\pmod4.$$Hơn nữa tính tích cực của$a$cho$$3p>q.$$--- 

# Đếm những giải pháp độc đáo 

Chúng tôi cần số lượng$n<50\,000\,000$với đúng một cặp$(p,q)$thỏa mãn: 

1.$$pq=n$$1.$$p+q\equiv0\pmod4$$1.$$q<3p$$Phương pháp đếm số chia trực tiếp vẫn còn lớn. 

Điểm mấu chốt của Dự án Euler là những con số có đúng một nghiệm sẽ có ba dạng rời rạc. 

--- 

#2. Phân loại qua cấu trúc số chia 

Từ$$n=(3d-a)(a+d),$$cho phép$$u=3d-a,\qquad v=a+d.$$Sau đó$$u+v=4d.$$Vì thế$u,v$có cùng tính chẵn lẻ và trên thực tế cả hai đều bằng nhau theo modulo$2$. 

Phân tích các điều kiện chia một cách cẩn thận mang lại: 

một con số$n$có chính xác một giải pháp nếu đó là một trong: 

1. A prime$p$với$$p\equiv3\pmod4$$1. Bốn lần một số nguyên tố:$$n=4p$$Ở đâu$p$là số nguyên tố 

1. Mười sáu lần một số nguyên tố:$$n=16p$$Ở đâu$p$là số nguyên tố và$$p\equiv3\pmod4.$$Sự phân loại này là bước đột phá quan trọng. 

Vì vậy câu trả lời là:$$\pi_{3\bmod4}(50\,000\,000) + \pi\!\left(\frac{50\,000\,000}{4}\right) + \pi_{3\bmod4}\!\left(\frac{50\,000\,000}{16}\right)$$Ở đâu:

-$\pi(x)$= số số nguyên tố$\le x$-$\pi_{3\bmod4}(x)$= số số nguyên tố$\le x$phù hợp với$3 \pmod 4$--- 

#3. Triển khai Python```python
from math import isqrt

LIMIT = 50_000_000

def sieve(n):
    """Return list of primes up to n using sieve of Eratosthenes."""
    is_prime = bytearray(b"\x01") * (n + 1)
    is_prime[0:2] = b"\x00\x00"

    for p in range(2, isqrt(n) + 1):
        if is_prime[p]:
            step = p
            start = p * p
            is_prime[start:n + 1:step] = b"\x00" * ((n - start) // step + 1)

    return is_prime

# We need primes up to 50,000,000
prime = sieve(LIMIT)

count = 0

# Case 1: n = p where p ≡ 3 (mod 4)
for p in range(3, LIMIT):
    if prime[p] and p % 4 == 3:
        count += 1

# Case 2: n = 4p
for p in range(2, LIMIT // 4):
    if prime[p]:
        count += 1

# Case 3: n = 16p where p ≡ 3 (mod 4)
for p in range(3, LIMIT // 16):
    if prime[p] and p % 4 == 3:
        count += 1

print(count)
```---
