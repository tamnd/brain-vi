# 1. Phân tích toán học 

Chúng ta đặt đường tiếp tuyến$L$như$x$-trục. 

Sau đó: 

- vòng tròn$A$có trung tâm$(0,a)$,
- vòng tròn$B$có trung tâm$(2\sqrt{ab},\,b)$, 

Vì hai đường tròn tiếp xúc cùng một đường thẳng và với nhau thỏa mãn:$$(\Delta x)^2=(a+b)^2-(a-b)^2=4ab.$$Bây giờ đặt vòng tròn$C$với trung tâm$(x,c)$. 

Từ$C$tiếp tuyến với$A$,$$x^2=(a+c)^2-(a-c)^2=4ac,$$kể từ đây$$x=2\sqrt{ac}.$$Tương tự, tiếp tuyến với$B$cho$$(2\sqrt{ab}-x)^2=4bc.$$Thay thế$x=2\sqrt{ac}$:$$(2\sqrt{ab}-2\sqrt{ac})^2=4bc.$$Chia cho$4$:$$(\sqrt{ab}-\sqrt{ac})^2=bc.$$Lấy căn bậc hai trong cấu hình hình học mang lại$$\sqrt{ab}=\sqrt{ac}+\sqrt{bc}.$$Yếu tố ra$\sqrt c$:$$\sqrt{ab}=\sqrt c(\sqrt a+\sqrt b).$$Vì thế$$\boxed{\sqrt c=\frac{\sqrt{ab}}{\sqrt a+\sqrt b}}$$Và$$\boxed{c=\frac{ab}{(\sqrt a+\sqrt b)^2}}.$$--- 

## Tham số số nguyên 

cho$c$là tích phân, viết$$a=dx^2,\qquad b=dy^2,$$Ở đâu$x,y$là nguyên tố cùng nhau. 

Sau đó$$c=\frac{d^2x^2y^2}{d(x+y)^2} =\frac{dx^2y^2}{(x+y)^2}.$$Từ$$\gcd(x+y,xy)=1$$cho coprime$x,y$, chúng ta phải có$$(x+y)^2\mid d.$$Vậy hãy để$$d=k(x+y)^2.$$Khi đó mọi giải pháp đều$$\boxed{ \begin{aligned} a&=k\,x^2(x+y)^2,\\ b&=k\,y^2(x+y)^2,\\ c&=k\,x^2y^2, \end{aligned}}$$với$$\gcd(x,y)=1,\qquad x\le y,\qquad k\ge1.$$--- 

## Đóng góp cho$S(n)$Từ$b\le n$,$$k\,y^2(x+y)^2\le n.$$Định nghĩa$$M=\left\lfloor \frac{n}{y^2(x+y)^2}\right\rfloor.$$Đối với coprime cố định$x,y$, các giá trị hợp lệ là$k=1,\dots,M$. 

Hiện nay$$a+b+c = k\Big((x+y)^2(x^2+y^2)+x^2y^2\Big).$$Do đó tổng số tiền đóng góp là$$\Big((x+y)^2(x^2+y^2)+x^2y^2\Big) \sum_{k=1}^{M}k.$$sử dụng$$\sum_{k=1}^{M}k=\frac{M(M+1)}2,$$chúng tôi có được$$\boxed{ S(n)= \sum_{\substack{x\le y\\ \gcd(x,y)=1}} \left((x+y)^2(x^2+y^2)+x^2y^2\right) \frac{M(M+1)}2 }$$Ở đâu$$M=\left\lfloor \frac{n}{y^2(x+y)^2}\right\rfloor.$$Điều này hiệu quả vì$$y^2(x+y)^2\le n$$chỉ ngụ ý về$O(\sqrt n)$các cặp có liên quan.

#2. Triển khai Python```python
from math import gcd, isqrt

def S(n):
    total = 0

    # y^2 (x+y)^2 <= n
    # so y is at most sqrt(n)
    limit = isqrt(n)

    for y in range(1, limit + 1):
        for x in range(1, y + 1):

            # primitive pairs only
            if gcd(x, y) != 1:
                continue

            denom = y * y * (x + y) * (x + y)

            if denom > n:
                break

            M = n // denom

            base = (x + y) * (x + y) * (x * x + y * y)
            base += x * x * y * y

            total += base * M * (M + 1) // 2

    return total

print(S(5))       # 9
print(S(100))     # 3072
print(S(10**9))
```---
