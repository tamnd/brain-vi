## Giải pháp 

**Trả lời:**`33626723890930`Cho phép$$p=5k-4 \qquad\Longrightarrow\qquad k=\frac{p+4}{5},$$Vì thế$$k-1=\frac{p-1}{5}.$$Định nghĩa$$d=\frac{p-1}{5}.$$Đối với khác không$x\in\mathbb F_p$,$$f_p(x)=x^k+x=x\left(x^{k-1}+1\right)=x\left(x^d+1\right).$$Hiện nay$x^d$luôn là gốc rễ thứ 5 của sự thống nhất trong$\mathbb F_p$, từ$$(x^d)^5=x^{p-1}=1.$$Do đó, các phần tử khác 0 được chia thành 5 lớp lân cận được xác định bởi giá trị của$x^d$. 

Đối với gốc thứ 5 cố định$r$,$$x^d=r$$ngụ ý$$f_p(x)=x(1+r).$$Do đó, tác động cảm ứng lên năm lớp lân cận hoàn toàn được xác định bởi bản đồ$$r \mapsto r(1+r)^d.$$Mọi phần tử trong một lớp lân cận đều tuần hoàn và mọi phần tử trong một lớp lân cận không tuần hoàn cuối cùng sẽ rời khỏi nó mãi mãi. Vì vậy: 

- mỗi coset định kỳ đóng góp chính xác$d=(p-1)/5$điểm, 
-$x=0$luôn luôn cố định. 

Vậy nếu$c$là số lớp lân cận tuần hoàn trong số năm lớp lân cận khác 0,$$C(p)=1+c\cdot \frac{p-1}{5}.$$Chương trình Python sau đây tính toán điều này một cách hiệu quả.```python
import math

def S(N):
    # odd-only sieve
    sieve = bytearray(b'\x01') * (N // 2)

    limit = int(math.isqrt(N))
    for i in range(3, limit + 1, 2):
        if sieve[i // 2]:
            start = i * i // 2
            sieve[start::i] = b'\x00' * (((N // 2 - 1 - start) // i) + 1)

    total = 0

    # only primes p == 1 (mod 5) matter
    for p in range(11, N + 1, 10):
        if not sieve[p // 2]:
            continue

        d = (p - 1) // 5

        # find a primitive 5th root of unity
        a = 2
        while True:
            t = pow(a, d, p)
            if t != 1:
                break
            a += 1

        t2 = (t * t) % p
        t3 = (t2 * t) % p
        t4 = (t2 * t2) % p

        roots = (1, t, t2, t3, t4)
        idx = {roots[i]: i for i in range(5)}

        # induced map on the 5 cosets
        T = [0] * 5
        for i, r in enumerate(roots):
            nxt = (r * pow(1 + r, d, p)) % p
            T[i] = idx[nxt]

        # count periodic states in the 5-state graph
        periodic = 0
        for i in range(5):
            j = i
            seen = 0
            while not ((seen >> j) & 1):
                seen |= 1 << j
                j = T[j]
            if j == i:
                periodic += 1

        total += 1 + periodic * d

    return total

print(S(100))      # 127
print(S(10**8))
```Chương trình tái hiện lại ví dụ:$$S(100)=127.$$Chạy nó cho$10^8$mang lại:$$S(10^8)=33626723890930.$$**Trả lời: 33626723890930**
