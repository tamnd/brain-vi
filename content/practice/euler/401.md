##Giải pháp 

**Trả lời:**`281632621`Chúng tôi muốn tính toán$$\operatorname{SIGMA}_2(n)=\sum_{k=1}^n \sigma_2(k),$$Ở đâu$$\sigma_2(k)=\sum_{d\mid k} d^2.$$Mục tiêu là$$\operatorname{SIGMA}_2(10^{15}) \pmod{10^9}.$$--- 

# Phân tích toán học 

Quan sát quan trọng là đảo ngược thứ tự tính tổng. 

Theo định nghĩa,$$\operatorname{SIGMA}_2(n) =\sum_{k=1}^n \sum_{d\mid k} d^2.$$Thay vì tính tổng các số$k$, tổng các ước$d$. 

Nếu như$d$chia rẽ$k$, sau đó$k=dm$. 

Đối với số chia cố định$d$, bội số của$d$lên tới$n$là$$d,2d,3d,\dots,\left\lfloor \frac nd \right\rfloor d.$$Vì thế$d^2$đóng góp chính xác$$\left\lfloor \frac nd \right\rfloor$$lần. 

Kể từ đây$$\boxed{ \operatorname{SIGMA}_2(n) = \sum_{d=1}^n d^2\left\lfloor \frac nd \right\rfloor }$$Đây là sự chuyển đổi quan trọng. 

--- 

## Tại sao phương pháp ngây thơ lại không thể 

cho$n=10^{15}$, lặp tới$10^{15}$là không thể. 

Chúng ta cần khai thác thực tế rằng$$\left\lfloor \frac nd \right\rfloor$$chỉ mất khoảng$2\sqrt n$những giá trị riêng biệt. 

--- 

# Nhóm các thương số bằng nhau 

Giả sử$$q=\left\lfloor \frac nd \right\rfloor.$$Sau đó tất cả$d$trong khoảng thời gian$$\left[ \left\lfloor \frac n{q+1}\right\rfloor+1, \left\lfloor \frac nq\right\rfloor \right]$$chia sẻ cùng một thương số$q$. 

Vì vậy, chúng tôi có thể xử lý toàn bộ phạm vi cùng một lúc. 

Chúng ta cần công thức$$\sum_{k=1}^m k^2 = \frac{m(m+1)(2m+1)}6.$$Định nghĩa$$S(m)=\frac{m(m+1)(2m+1)}6.$$Sau đó$$\sum_{k=a}^b k^2 = S(b)-S(a-1).$$--- 

# Giảm độ phức tạp 

hãy để$$r=\lfloor \sqrt n \rfloor.$$Chúng tôi chia tính toán thành hai phần: 

1. Xử lý trực tiếp ước số nhỏ$d\le r$2. Xử lý các ước số lớn trong phạm vi được nhóm theo thương 

Điều này mang lại một$O(\sqrt n)$thuật toán. 

Vì$n=10^{15}$,$$\sqrt n \approx 3.16\times 10^7,$$điều này khả thi trong Python được tối ưu hóa. 

--- 

#Triển khai Python```python
from math import isqrt

MOD = 10**9
N = 10**15

def sum_squares(m):
    """Return 1^2 + 2^2 + ... + m^2."""
    return m * (m + 1) * (2 * m + 1) // 6

def sigma2_summatory(n):
    r = isqrt(n)
    ans = 0

    # Part 1:
    # Directly sum d^2 * floor(n/d) for d <= sqrt(n)
    for d in range(1, r + 1):
        ans += d * d * (n // d)
        ans %= MOD

    # Part 2:
    # Group all large d by equal quotient q = floor(n/d)
    for q in range(1, r + 1):

        # d values satisfying floor(n/d) = q
        lo = n // (q + 1) + 1
        hi = n // q

        # We only want d > sqrt(n),
        # since smaller ones were already counted.
        lo = max(lo, r + 1)

        if lo <= hi:
            block_sum = sum_squares(hi) - sum_squares(lo - 1)
            ans += q * block_sum
            ans %= MOD

    return ans % MOD

print(sigma2_summatory(N))
```--- 

# Hướng dẫn sử dụng mã 

##`sum_squares(m)`Sử dụng công thức đóng$$1^2+2^2+\cdots+m^2 = \frac{m(m+1)(2m+1)}6.$$Điều này cho phép tính tổng khoảng thời gian không đổi. 

--- 

## Vòng lặp đầu tiên```python
for d in range(1, r + 1):
    ans += d * d * (n // d)
```Tính toán$$\sum_{d=1}^{\sqrt n} d^2\left\lfloor \frac nd\right\rfloor.$$--- 

## Vòng lặp thứ hai 

Với mỗi thương số$q$, chúng tôi xác định khoảng thời gian đầy đủ của$d$như vậy$$\left\lfloor \frac nd \right\rfloor=q.$$Các khoảng đó là:```python
lo = n // (q + 1) + 1
hi = n // q
```Sau đó, chúng tôi tính tổng tất cả các ô vuông trong khoảng đó cùng một lúc:```python
block_sum = sum_squares(hi) - sum_squares(lo - 1)
```và thêm$$q \times \sum d^2.$$--- 

# Xác minh trên các giá trị nhỏ 

cho$n=6$:$$\sigma_2(1)=1$$

$$\sigma_2(2)=1+4=5$$

$$\sigma_2(3)=1+9=10$$

$$\sigma_2(4)=1+4+16=21$$

$$\sigma_2(5)=1+25=26$$

$$\sigma_2(6)=1+4+9+36=50$$Tóm tắt:$$1+5+10+21+26+50=113,$$phù hợp với phát biểu vấn đề.
