## Giải pháp 

**Trả lời:**`173`Chúng tôi tìm kiếm số nguyên tố$p$sao cho tồn tại một số nguyên dương$n$với$$n^3+n^2p$$là một khối lập phương hoàn hảo. 

Chúng tôi được bảo rằng đối với$p=19$,$$8^3+8^2\cdot 19=12^3.$$Chúng ta phải đếm xem có bao nhiêu số nguyên tố như vậy$p<10^6$. 

--- 

# Bước 1 - Phân tích đại số 

Chúng tôi muốn số nguyên$n,m>0$thỏa mãn$$n^3+n^2p=m^3.$$Thừa số vế trái:$$n^2(n+p)=m^3.$$Vì thế$$m^3=n^2(n+p).$$Bây giờ chúng ta phân tích cấu trúc của phương trình này. 

--- 

## Thay thế khóa 

hãy để$$m = nk$$vì lý do nào đó$k$. Thay thế:$$n^3k^3=n^2(n+p).$$Hủy bỏ$n^2$:$$nk^3=n+p.$$Kể từ đây$$p=n(k^3-1).$$Từ$p$là số nguyên tố, điều này cực kỳ hạn chế. 

Nhân tố:$$k^3-1=(k-1)(k^2+k+1).$$Như vậy$$p=n(k-1)(k^2+k+1).$$Bởi vì$p$là số nguyên tố và$n\ge1$, tất cả các yếu tố ngoại trừ một yếu tố phải bằng nhau$1$. 

Vì vậy nhất thiết:$$n=k-1=1.$$Nhưng sẽ dễ dàng hơn nếu rút ra bằng cách sử dụng tính nguyên thủy cùng nhau. 

--- 

# Bước 2 - Đạo hàm chuẩn 

Viết$$m^3-n^3=n^2p.$$Yếu tố sự khác biệt của hình khối:$$(m-n)(m^2+mn+n^2)=n^2p.$$Bây giờ hãy$$m-n=d.$$Sau đó$m=n+d$. Thay vào thừa số thứ hai:$$m^2+mn+n^2 =(n+d)^2+n(n+d)+n^2.$$Mở rộng:$$=3n^2+3nd+d^2.$$Vì thế$$d(3n^2+3nd+d^2)=n^2p.$$Một quan sát quan trọng:$$\gcd(d,n)=1.$$Thật vậy, nếu một số chia cả hai$d=m-n$Và$n$, nó chia$m$quá, do đó chia cả hai bên của$$m^3-n^3=n^2p,$$buộc mâu thuẫn trừ khi gcd là$1$. 

Từ$d\mid n^2p$Và$\gcd(d,n)=1$, chúng ta phải có$$d\mid p.$$Bởi vì$p$là số nguyên tố và$d>0$,$$d=1 \quad \text{or} \quad d=p.$$Nếu như$d=p$, sau đó$$p(3n^2+3np+p^2)=n^2p,$$ngụ ý$$3n^2+3np+p^2=n^2,$$không thể nào. 

Kể từ đây$$d=1.$$Vì thế$$m=n+1.$$Thay thế trở lại:$$(n+1)^3-n^3=n^2p.$$Mở rộng:$$3n^2+3n+1=n^2p.$$Nhưng việc sắp xếp lại dự định sẽ dễ dàng hơn trực tiếp từ phương trình ban đầu:$$n^3+n^2p=(n+1)^3.$$Như vậy$$n^2p=(n+1)^3-n^3.$$Tính sự khác biệt:$$(n+1)^3-n^3=3n^2+3n+1.$$Vì thế$$p=\frac{3n^2+3n+1}{n^2}.$$Điều này nhìn chung có vẻ không tích hợp, vì vậy chúng ta cần một tham số hóa rõ ràng hơn.

# Bước 3 - Tham số hóa chính xác 

hãy để$$m=n+k.$$Sau đó$$m^3-n^3 =3n^2k+3nk^2+k^3.$$Vì điều này bằng$n^2p$,$$n^2p = k(3n^2+3nk+k^2).$$Lại$\gcd(n,k)=1$, Vì thế$k\mid p$. Từ$p$là số nguyên tố,$$k=p.$$Sau đó$$n^2 = 3n^2+3np+p^2,$$không thể trừ khi thay vào đó chúng ta có$$k=1.$$Như vậy$$m=n+1.$$Bây giờ thay thế một cách cẩn thận:$$(n+1)^3=n^3+n^2p.$$Mở rộng:$$n^3+3n^2+3n+1=n^3+n^2p.$$Kể từ đây$$p=\frac{3n^2+3n+1}{n^2}.$$Điều này một lần nữa có vẻ sai bởi vì$p=19$làm việc với$n=8$. Hãy kiểm tra:$$\frac{3(64)+24+1}{64}=\frac{217}{64}.$$Vì vậy giả định của chúng tôi$m=n+1$là sai. 

Hãy khởi động lại sạch sẽ.

# Bước 4 - Phân tích nhân tử một cách tinh tế 

Từ$$n^3+n^2p=m^3,$$chia cho$n^3$:$$1+\frac{p}{n}=\left(\frac{m}{n}\right)^3.$$Cho phép$$\frac{m}{n}=\frac{a}{b}$$trong điều kiện thấp nhất. Sau đó$$1+\frac{p}{n}=\frac{a^3}{b^3}.$$Sắp xếp lại:$$\frac{p}{n}=\frac{a^3-b^3}{b^3}.$$Như vậy$$pb^3=n(a^3-b^3).$$Từ$a,b$là nguyên tố cùng nhau,$$a^3-b^3=(a-b)(a^2+ab+b^2).$$Vì$p$là số nguyên tố, khả năng duy nhất là$$a-b=1.$$Bộ$$a=b+1.$$Sau đó$$a^3-b^3 =(b+1)^3-b^3 =3b^2+3b+1.$$Vì thế$$p=3b^2+3b+1.$$Đây là kết quả then chốt. 

Thật vậy, với$b=2$:$$p=3(4)+6+1=19.$$Và ví dụ đưa ra$$n=b^3=8,\qquad m=a^3=27 \Rightarrow m=12,$$phù hợp hoàn hảo kể từ đó$$8^3+8^2\cdot19=12^3.$$Vì vậy, vấn đề giảm xuống:

from math import isqrt

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    
    limit = isqrt(n)
    d = 3
    
    while d <= limit:
        if n % d == 0:
            return False
        d += 2
    
    return True

count = 0
values = []

b = 1

while True:
    p = 3*b*b + 3*b + 1
    
    if p >= 1_000_000:
        break
    
    if is_prime(p):
        count += 1
        values.append(p)
    
    b += 1

print(count)
```---
