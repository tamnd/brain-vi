## Giải pháp 

**Trả lời:**`21035`Cho phép$$r_n = (p_n-1)^n + (p_n+1)^n \pmod{p_n^2},$$Ở đâu$p_n$là$n$-thứ nguyên tố. 

Chúng tôi tìm kiếm ít nhất$n$như vậy$$r_n > 10^{10}.$$--- 

# Phân tích toán học 

Quan sát quan trọng là biểu thức có thể được đơn giản hóa đáng kể bằng cách sử dụng định lý nhị thức. 

Cho phép$p=p_n$. 

Chúng tôi mở rộng:$$(p+1)^n = \sum_{k=0}^{n} \binom{n}{k} p^k$$Và$$(p-1)^n = \sum_{k=0}^{n} \binom{n}{k} p^k(-1)^{n-k}.$$Chúng tôi chỉ quan tâm modulo$p^2$, do đó mọi số hạng chứa$p^2$hoặc cao hơn biến mất. 

Như vậy modulo$p^2$,$$(p+1)^n \equiv 1 + np$$Và$$(p-1)^n \equiv (-1)^n + n(-1)^{n-1}p.$$Thêm:$$r_n \equiv (1+(-1)^n) + np\left(1+(-1)^{n-1}\right)\pmod{p^2}.$$Bây giờ chia thành các trường hợp chẵn lẻ. 

## Trường hợp 1:$n$thậm chí 

Sau đó$$(-1)^n=1,\qquad (-1)^{n-1}=-1.$$Vì thế$$r_n \equiv 2 + np(1-1)=2 \pmod{p^2}.$$Do đó thậm chí đối với$n$,$$r_n = 2.$$Điều này không bao giờ có thể vượt quá$10^{10}$. 

--- 

## Trường hợp 2:$n$kỳ quặc 

Sau đó$$(-1)^n=-1,\qquad (-1)^{n-1}=1.$$Vì thế$$r_n \equiv 0 + np(1+1)=2np \pmod{p^2}.$$Vì vậy, đối với số lẻ$n$,$$r_n = 2p_n n$$(miễn là$2np_n < p_n^2$, điều này đúng trong phạm vi có liên quan). 

Vậy bài toán quy về việc tìm số lẻ nhỏ nhất$n$như vậy$$2n p_n > 10^{10}.$$--- 

## Ước tính phạm vi 

Sử dụng Định lý số nguyên tố,$$p_n \sim n\log n.$$Như vậy$$2n p_n \sim 2n^2\log n.$$Chúng tôi giải quyết khoảng:$$2n^2\log n \approx 10^{10}.$$Điều này gợi ý$n$ở xung quanh$2\times 10^4$. 

Bây giờ chúng tôi tính toán chính xác. 

--- 

#Triển khai Python```python
from math import isqrt

LIMIT = 10**10

def generate_primes(limit_count):
    """
    Generate the first 'limit_count' primes using
    a standard incremental primality test.
    """
    primes = [2]
    candidate = 3

    while len(primes) < limit_count:
        is_prime = True
        root = isqrt(candidate)

        for p in primes:
            if p > root:
                break
            if candidate % p == 0:
                is_prime = False
                break

        if is_prime:
            primes.append(candidate)

        candidate += 2

    return primes

# We know the answer is around 2e4, so 30000 primes is plenty.
primes = generate_primes(30000)

answer = None

for n in range(1, len(primes) + 1, 2):   # only odd n matter
    p = primes[n - 1]                    # p_n (1-indexed)

    remainder = 2 * n * p

    if remainder > LIMIT:
        answer = n
        break

print(answer)
```---

# Xác minh trên ví dụ 

cho$n=3$: 

-$p_3 = 5$- Công thức cho$$r = 2 \cdot 3 \cdot 5 = 30.$$Modulo$25$,$$30 \equiv 5 \pmod{25},$$phù hợp với tuyên bố vấn đề:$$4^3 + 6^3 = 280 \equiv 5 \pmod{25}.$$Chính xác. 

Ngoài ra, vấn đề ít nhất nói lên$n$vì$10^9$là$7037$. Cắm vào công thức:$$2 \cdot 7037 \cdot p_{7037}$$thực sự lần đầu tiên vượt quá$10^9$, khẳng định tính nhất quán.
