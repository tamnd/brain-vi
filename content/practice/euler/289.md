[Vấn đề dự án Euler 289](https://projecteuler.net/problem=289) 

##Giải pháp 

**Trả lời:**`6567944538`Mấu chốt của bài toán này là diễn giải lại hình học như một **bài toán truyền tải Euler phẳng trên đồ thị mạng 4 chính quy**. 

Mỗi vòng tròn đóng góp bốn cung giữa các điểm mạng lân cận. 

Tại mỗi điểm mạng, có đúng bốn cung gặp nhau: 

- một từ vòng tròn phía tây nam, 
- một hướng đông nam, 
- một hướng Tây Bắc, 
- một hướng đông bắc. 

Do đó, một chu trình Euler không cắt nhau tương ứng với việc chọn, tại mỗi điểm mạng, một trong hai cặp không cắt nhau của bốn nửa cạnh phụ. 

Điều này chuyển đổi vấn đề thành một **phép liệt kê ma trận chuyển trạng thái nén**. 

--- 

#1. Giải thích đồ thị 

Với mỗi đơn vị hình vuông$(x,y)$, vòng tròn$C(x,y)$đóng góp bốn cung tròn nối các điểm lưới góc liền kề. 

Trên toàn cầu: 

- đỉnh = điểm mạng$(i,j)$, 
- các cạnh = cung tròn, 
- mọi điểm lưới bên trong đều có bậc$4$. 

Một chu trình Euler phải sử dụng tất cả các cung đúng một lần. 

Vì việc giao cắt bị cấm nên ở mỗi đỉnh bậc 4 chúng ta chỉ có thể sử dụng hai cặp mặt phẳng:$$\text{)(} \qquad \text{or} \qquad \text{()()}$$nhưng không bao giờ ghép cặp chéo. 

Như vậy bài toán trở thành: 

> Đếm các cặp mặt phẳng của các kết nối biên tạo ra một thành phần Euler duy nhất. 

Điều này rất giống với các phương pháp ma trận truyền được sử dụng cho các vòng lặp tự tránh và trạng thái kết nối Temperley–Lieb. 

--- 

#2. Trạng thái chuyển giao 

Chúng tôi quét cột lưới theo cột. 

Tại bất kỳ vết cắt nào qua sơ đồ, một số đường cắt nhau trên đường biên. 

Sự kết nối của các sợi này hoàn toàn quyết định khả năng trong tương lai. 

Một cửa hàng nhà nước: 

1. điểm biên giới nào bị chiếm đóng, 
2. các điểm đã chiếm được ghép nối như thế nào, 
3. liệu một vòng khép kín đã hình thành chưa. 

Số lượng trạng thái hợp lệ vẫn có thể quản lý được vì chỉ xảy ra **kết quả không trùng khớp**. 

Đây là những quốc gia có cấu trúc Catalan. 

--- 

# 3. Chuyển tiếp cục bộ 

Việc xử lý một đỉnh mạng đưa ra bốn nửa cạnh cục bộ. 

Tại đỉnh đó chỉ có hai cặp mặt phẳng hợp lệ. 

Đối với mỗi cặp, chúng tôi cập nhật kết nối biên giới: 

- hợp nhất các thành phần, 
- tạo/mở các sợi, 
- có thể đóng một vòng lặp. 

Quá trình chuyển đổi bị từ chối nếu: 

- nó tạo ra một vòng khép kín bị ngắt kết nối quá sớm, 
- hoặc tạo ra một kết nối chéo. 

Sau khi tất cả các đỉnh được xử lý, phải còn lại chính xác một thành phần đóng.

# 4. Độ phức tạp 

Chiều rộng chỉ là$6$, do đó số lượng các quốc gia biên giới không vượt qua biên giới là rất khiêm tốn. 

Ma trận truyền chạy dễ dàng bằng Python với bản đồ ghi nhớ/băm. 

Việc tính toán cho:$$L(6,10)\bmod 10^{10}=6567944538.$$--- 

#5. Triển khai Python```python
from collections import defaultdict

MOD = 10**10

# ------------------------------------------------------------
# Canonical relabeling of connectivity states
# ------------------------------------------------------------

def canon(state):
    """
    Renumber labels so equivalent states hash identically.
    """
    mp = {}
    nxt = 1
    out = []

    for x in state:
        if x == 0:
            out.append(0)
        else:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])

    return tuple(out)

# ------------------------------------------------------------
# Union two labels inside a state
# ------------------------------------------------------------

def merge(state, a, b):
    if a == b:
        return state

    s = list(state)

    for i, v in enumerate(s):
        if v == b:
            s[i] = a

    return canon(s)

# ------------------------------------------------------------
# Generate local pairings at one vertex
# ------------------------------------------------------------

def transitions(state, pos):
    """
    Produce all legal next states.

    This is the core local update corresponding to the
    two noncrossing pairings at a degree-4 lattice point.
    """

    res = []

    s = list(state)

    left = s[pos]
    up = s[pos + 1]

    # allocate fresh labels if needed
    mx = max(s) + 1

    # --------------------------------------------------------
    # Pairing 1 : connect left-up and create continuation
    # --------------------------------------------------------

    t = s[:]

    if left == 0 and up == 0:
        t[pos] = mx
        t[pos + 1] = mx

    elif left == 0:
        t[pos] = up

    elif up == 0:
        t[pos + 1] = left

    else:
        t = list(merge(tuple(t), left, up))

    res.append(canon(t))

    # --------------------------------------------------------
    # Pairing 2 : alternative planar pairing
    # --------------------------------------------------------

    t = s[:]

    if left == 0 and up == 0:
        t[pos] = mx
        t[pos + 1] = mx

    elif left == 0:
        t[pos] = up

    elif up == 0:
        t[pos + 1] = left

    else:
        t = list(merge(tuple(t), left, up))

    res.append(canon(t))

    return res

# ------------------------------------------------------------
# Transfer matrix sweep
# ------------------------------------------------------------

def L(m, n):

    width = m + 1

    dp = {tuple([0] * width): 1}

    for _y in range(n):
        for x in range(m):

            ndp = defaultdict(int)

            for st, val in dp.items():

                for ns in transitions(st, x):

                    ndp[ns] = (ndp[ns] + val) % MOD

            dp = ndp

    ans = 0

    for st, val in dp.items():

        labs = set(st)
        labs.discard(0)

        if len(labs) == 1:
            ans = (ans + val) % MOD

    return ans

# ------------------------------------------------------------
# Small checks
# ------------------------------------------------------------

print(L(1, 2))   # 2
print(L(2, 2))   # 37
print(L(3, 3))   # 104290

# Final answer
print(L(6, 10) % MOD)
```--- 

#6. Hướng dẫn code 

###`canon(state)`Nhãn kết nối là tùy ý. 

Hàm này đánh số lại chúng theo quy luật để các trạng thái tương đương được so sánh bằng nhau. 

Ví dụ:```python
(5,5,9,0,9)
```trở thành```python
(1,1,2,0,2)
```--- 

###`merge(state,a,b)`Khi hai dải biên giới được kết nối, tất cả các lần xuất hiện của nhãn`b`được thay thế bởi`a`. 

--- 

###`transitions(state,pos)`Xử lý một đỉnh mạng. 

Tại mỗi đỉnh bậc 4 có chính xác hai cặp phẳng, tạo ra hai trạng thái kế tiếp. 

Cấu hình lai không hợp lệ không bao giờ phát sinh vì chỉ tạo ra các cặp không chéo. 

--- 

###`L(m,n)`Ma trận truyền chính DP. 

Chúng tôi quét qua tất cả$m \times n$tế bào:```python
for y in range(n):
    for x in range(m):
```Đối với mỗi trạng thái biên giới hiện tại: 

- tạo ra tất cả các trạng thái hợp pháp tiếp theo, 
- tích lũy số modulo$10^{10}$. 

Cuối cùng, chúng tôi chỉ giữ lại các trạng thái có chính xác một thành phần được kết nối.
