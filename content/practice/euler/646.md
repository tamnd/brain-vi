[Vấn đề dự án Euler 646](https://projecteuler.net/problem=646) 

## Giải pháp 

**Trả lời:**`845218467`Cho phép$$n=\prod_{i=1}^k p_i^{\alpha_i}, \qquad \lambda(n)=(-1)^{\sum \alpha_i}.$$chúng tôi muốn$$S(n,L,H)=\sum_{\substack{d\mid n\\L\le d\le H}}\lambda(d)\,d.$$Đối với vấn đề này:$$S(70!,10^{20},10^{60}) \pmod{1\,000\,000\,007}.$$## 1. Phân tích toán học 

Nếu$$d=\prod_i p_i^{\beta_i}, \qquad 0\le \beta_i\le \alpha_i,$$sau đó$$\lambda(d) = (-1)^{\sum_i \beta_i}.$$Vì thế$$\lambda(d)d = \prod_i (-p_i)^{\beta_i}.$$Vì vậy, mỗi ước số đóng góp một trọng số có dấu nhân. 

Thử thách đó chính là$70!$có số lượng ước rất lớn:$$\tau(70!) = \prod_i (\alpha_i+1) = 3\,543\,845\,437\,440,$$nên vũ lực là không thể. 

### Gặp nhau giữa chừng 

Chia các số nguyên tố của$70!$thành hai nhóm$A,B$. 

Đối với mỗi ước số một phần trong nhóm$A$, tính: 

- giá trị của nó$a$, 
- đóng góp đã ký của nó$t_A=\lambda(a)a$. 

Tương tự như vậy đối với nhóm$B$: 

- số chia$b$, 
- đóng góp đã ký$t_B=\lambda(b)b$. 

Khi đó mọi ước của$70!$là duy nhất:$$d=a\cdot b,$$và đóng góp$$\lambda(d)d = t_A t_B.$$Đối với một cố định$a$, có hiệu lực$b$thỏa mãn$$\frac{L}{a}\le b\le \frac{H}{a}.$$Nếu tất cả$b$-các giá trị được sắp xếp, chúng ta có thể tìm kiếm nhị phân trong khoảng và sử dụng tổng tiền tố của$t_B$để có được:$$\sum_{\frac{L}{a}\le b\le \frac{H}{a}} t_B$$TRONG$O(\log N)$. 

Do đó tổng độ phức tạp trở nên gần như:$$O(N\log N),$$trong đó mỗi nửa chỉ có khoảng$1.88\times 10^6$trạng thái - hoàn toàn khả thi. 

## 2. Triển khai Python```python
from math import factorial
from bisect import bisect_left, bisect_right
from sympy import factorint

MOD = 1_000_000_007

def generate_divisors(items):
    """
    Generate all partial divisors and their signed values.

    Returns list of tuples:
        (d, lambda(d) * d)
    """
    arr = [(1, 1)]

    for p, a in items:
        powers = []

        value = 1
        sign = 1

        for _ in range(a + 1):
            powers.append((value, sign * value))
            value *= p
            sign *= -1

        new_arr = []

        for d, t in arr:
            for v, tv in powers:
                new_arr.append((d * v, t * tv))

        arr = new_arr

    return arr

def S(n, L, H):
    # Prime factorization of n!
    fac = factorint(factorial(n))
    items = list(fac.items())

    # Find balanced split minimizing max(side size)
    divisor_counts = [a + 1 for _, a in items]

    total_divisors = 1
    for c in divisor_counts:
        total_divisors *= c

    best_mask = None
    best_size = float("inf")

    m = len(items)

    for mask in range(1 << m):
        left_size = 1

        for i in range(m):
            if (mask >> i) & 1:
                left_size *= divisor_counts[i]

        right_size = total_divisors // left_size
        worst = max(left_size, right_size)

        if worst < best_size:
            best_size = worst
            best_mask = mask

    A = [items[i] for i in range(m)
         if (best_mask >> i) & 1]

    B = [items[i] for i in range(m)
         if not ((best_mask >> i) & 1)]

    # Generate both halves
    left = generate_divisors(A)
    right = generate_divisors(B)

    # Sort right side by divisor value
    right.sort(key=lambda x: x[0])

    right_divs = [d for d, _ in right]

    # Prefix sums of signed contributions
    prefix = [0]
    running = 0

    for _, t in right:
        running += t
        prefix.append(running)

    total = 0

    for a, ta in left:
        lo = (L + a - 1) // a
        hi = H // a

        i = bisect_left(right_divs, lo)
        j = bisect_right(right_divs, hi)

        total += ta * (prefix[j] - prefix[i])

    return total

# Verification against examples
print(S(10, 100, 1000))           # 1457
print(S(15, 10**3, 10**5))        # -107974
print(S(30, 10**8, 10**12))       # 9766732243224

# Final computation
ans = S(70, 10**20, 10**60)
print(ans % MOD)
```## 3. Hướng dẫn sử dụng mã 

-`factorint(factorial(n))`tính số mũ nguyên tố của$n!$. 
-`generate_divisors()`liệt kê đệ quy tất cả các ước số và cửa hàng một phần:$$(d,\lambda(d)d).$$- Ta chia các số nguyên tố thành hai nhóm cân bằng sao cho mỗi bên có khoảng$1.88$triệu tiểu bang. 
- Nửa bên phải được sắp xếp theo kích thước của số chia. 
- Tổng tiền tố cho phép tính tổng khoảng thời gian không đổi sau khi tìm kiếm nhị phân. 
- Đối với mỗi ước số bên trái$a$, chúng tôi thấy tất cả đều tương thích$b$thỏa mãn:$$L \le ab \le H.$$- Tổng hợp tất cả các đóng góp đã ký.

## 4. Xác minh lần cuối 

Tổng không giới hạn trên tất cả các ước của$70!$sẽ nhân hệ số nhân lên như sau:$$\sum_{d\mid 70!}\lambda(d)d = \prod_p (1-p+p^2-\cdots),$$vì vậy dự kiến ​​sẽ có sự hủy bỏ lớn. Một kết quả modulo$10^9+7$ở giữa phạm vi dư lượng là hoàn toàn hợp lý.
