[Vấn đề dự án Euler 938](https://projecteuler.net/problem=938) 

## Giải pháp 

**Trả lời:**`0.2928967987`Cho phép$P(R,B)$biểu thị xác suất để màu cuối cùng còn lại là màu đen. 

Tại một tiểu bang$(R,B)$, hai lá bài được rút ra: 

- RR với xác suất$\dfrac{R(R-1)}{(R+B)(R+B-1)}$, dẫn đến$(R-2,B)$- BB có xác suất$\dfrac{B(B-1)}{(R+B)(R+B-1)}$, trở về trạng thái tương tự 
- RB có xác suất$\dfrac{2RB}{(R+B)(R+B-1)}$, dẫn đến$(R,B-1)$Vì thế,$$P(R,B)= \frac{R(R-1)}{N(N-1)}P(R-2,B) +\frac{B(B-1)}{N(N-1)}P(R,B) +\frac{2RB}{N(N-1)}P(R,B-1),$$Ở đâu$N=R+B$. 

Sắp xếp lại,$$P(R,B)= \frac{R-1}{R+2B-1}P(R-2,B) + \frac{2B}{R+2B-1}P(R,B-1).$$Điều kiện biên:$$P(0,B)=1,\qquad P(R,0)=0 \text{ for } R>0.$$Từ$R=24690=2\cdot12345$, định nghĩa$$f(k,b)=P(2k,b).$$Sau đó$$f(k,b)= \frac{2k-1}{2k+2b-1}f(k-1,b) + \frac{2b}{2k+2b-1}f(k,b-1).$$Một cách đơn giản$O(KB)$chương trình động tính toán câu trả lời. 

Mã Python:```python
K = 12345
B = 12345

# dp[b] = current row values
dp = [1.0] * (B + 1)   # k = 0 => P(0,b)=1

for k in range(1, K + 1):
    dp[0] = 0.0        # P(2k,0)=0

    for b in range(1, B + 1):
        dp[b] = (
            (2*k - 1) * dp[b]
            + 2*b * dp[b - 1]
        ) / (2*k + 2*b - 1)

print(f"{dp[B]:.10f}")
```Điều này tái tạo các kiểm tra đã cho: 

-$P(2,2)=0.4666666667$-$P(10,9)=0.4118903397$-$P(34,25)=0.3665688069$và sản lượng$$P(24690,12345)=0.2928967987\ldots$$**Đáp án: 0,2928967987**
