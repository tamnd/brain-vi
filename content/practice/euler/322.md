[Vấn đề dự án Euler 322](https://projecteuler.net/problem=322) 

## Giải pháp 

**Trả lời:**`999998760323313995`Cho phép$$T(m,n)=\#\left\{\, i \mid n\le i<m,\ 10\mid \binom{i}{n}\right\}.$$Chúng tôi được trao$$T(10^9,10^7-10)=989697000$$và chúng ta phải tính toán$$T(10^{18},10^{12}-10).$$--- 

# 1. Phân tích toán học 

Ta cần tính khi hệ số nhị thức chia hết cho$10$, tức là bởi cả hai$2$Và$5$. 

Vì vậy hãy xác định: 

-$A_2$: số lượng$i$như vậy$\binom{i}{n}$**không chia hết cho$2$**. 
-$A_5$: số lượng$i$như vậy$\binom{i}{n}$**không chia hết cho$5$**. 
-$A_{10}$: số lượng$i$như vậy$\binom{i}{n}$không chia hết cho cả hai$2$cũng không$5$. 

Sau đó bằng cách bao gồm-loại trừ,$$T(m,n) = (m-n)-A_2-A_5+A_{10}.$$Vì vậy, vấn đề giảm xuống việc tính toán ba đại lượng này. 

--- 

## Định lý Lucas/Kummer 

Đối với một số nguyên tố$p$,$$\binom{i}{n}\not\equiv 0 \pmod p$$nếu mọi cơ sở-$p$chữ số của$n$nhiều nhất là chữ số tương ứng của$i$. 

Tương đương, nếu$i=n+x$, sau đó thêm$n$Và$x$trong căn cứ$p$tạo ra **không mang theo**. 

--- 

# Máy tính$A_2$Cho phép$$n=10^{12}-10.$$Ở dạng nhị phân,$\binom{i}{n}$là số lẻ nếu mỗi 1 bit nhị phân của$n$cũng là 1-bit của$i$. 

Một chữ số-DP trong cơ số 2 cho:$$A_2 = 238418395136.$$--- 

# Máy tính$A_5$Trong cơ sở 5, Lucas đưa ra điều kiện tương tự. 

DP có 5 chữ số cơ bản mang lại:$$A_5 = 1258291200.$$--- 

# Máy tính$A_{10}$Bây giờ chúng ta cần những số thỏa mãn cả hai điều kiện cùng một lúc. 

Viết$$i=n+x.$$Sau đó: 

- không mang theo cơ sở 2$\iff x\& n =0$, 
- không mang theo cơ sở 5$\iff$mỗi chữ số cơ số 5 của$x$được giới hạn bởi$4-d_k(n)$. 

Sự mở rộng cơ sở-5 của$n=10^{12}-10$là$$(1,1,2,3,4,0,4,4,4,4,4,4,4,4,4,4,3,0)_5$$(đọc từ cao xuống thấp). 

Hầu hết các chữ số đều$4$, buộc chữ số tương ứng của$x$được$0$. 

Chỉ một$4800$khả năng phần thấp vẫn còn. 

Cho phép$$5^{18}=3814697265625.$$Mọi thứ được chấp nhận$x$có thể được viết duy nhất là$$x=y\cdot 5^{18}+z,$$Ở đâu:

-$0\le y<262144$, 
-$z$là một trong số đó$4800$phần thấp chấp nhận được. 

Kiểm tra điều kiện nhị phân$(x\& n)=0$trên tất cả các cặp như vậy mang lại$$A_{10}=321.$$--- 

# Tính toán cuối cùng 

Bây giờ áp dụng bao gồm-loại trừ:$$\begin{aligned} T &=(10^{18}-(10^{12}-10))  -238418395136  -1258291200  +321 \\ &=999999000000000010  -238418395136  -1258291200  +321 \\ &=999998760323313995. \end{aligned}$$--- 

#2. Triển khai Python```python
from functools import lru_cache
from itertools import product
import numpy as np

def count_not_divisible(m, n, p):
    """
    Count i in [n, m) such that C(i,n) is NOT divisible by p.
    Lucas theorem:
    every base-p digit of n must be <= corresponding digit of i.
    """

    # digits of n
    nd = []
    x = n
    while x:
        nd.append(x % p)
        x //= p

    # digits of m-1
    md = []
    x = m - 1
    while x:
        md.append(x % p)
        x //= p

    L = max(len(nd), len(md))
    nd += [0] * (L - len(nd))
    md += [0] * (L - len(md))

    @lru_cache(None)
    def dp(pos, tight):
        if pos < 0:
            return 1

        limit = md[pos] if tight else (p - 1)

        total = 0
        for d in range(nd[pos], limit + 1):
            total += dp(pos - 1, tight and d == limit)

        return total

    return dp(L - 1, True)

def count_not_divisible_by_10(m, n):
    """
    Count i such that C(i,n) is divisible by neither 2 nor 5.
    """

    L = m - n

    # base-5 digits of n
    digits = []
    x = n
    while x:
        digits.append(x % 5)
        x //= 5

    # admissible low-part digits
    positions = [i for i, d in enumerate(digits) if d < 4]
    choices = [range(5 - digits[i]) for i in positions]

    zs = []

    for tup in product(*choices):
        z = 0
        for v, k in zip(tup, positions):
            z += v * (5 ** k)
        zs.append(z)

    zs = np.array(zs, dtype=np.uint64)

    p5 = 5 ** len(digits)

    Y = (L - 1) // p5 + 1

    ys = np.arange(Y, dtype=np.uint64) * np.uint64(p5)

    total = 0

    for z in zs:
        total += np.count_nonzero(((ys + z) & np.uint64(n)) == 0)

    return int(total)

def solve():
    m = 10 ** 18
    n = 10 ** 12 - 10

    A2 = count_not_divisible(m, n, 2)
    A5 = count_not_divisible(m, n, 5)
    A10 = count_not_divisible_by_10(m, n)

    T = (m - n) - A2 - A5 + A10

    return T

print(solve())

#3. Hướng dẫn sử dụng mã 

##`count_not_divisible`Đây là chữ số Lucas-DP tiêu chuẩn. 

Đối với mỗi cơ sở-$p$vị trí chữ số: 

- chữ số của$i$ít nhất phải là chữ số của$n$, 
- và không được vượt quá chữ số của$m-1$. 

DP đếm tất cả hợp lệ$i<m$. 

--- 

##`count_not_divisible_by_10`Điều này xử lý đồng thời$2$- Và$5$-điều kiện. 

Điều kiện cơ số 5 hạn chế đáng kể các chữ số thấp của$x=i-n$, chỉ để lại$4800$khả năng. 

Sau đó chúng tôi liệt kê hệ số khối cao hơn$y$và kiểm tra điều kiện không mang nhị phân bằng cách sử dụng:```python
((ys + z) & n) == 0
```mã hóa chính xác "không có 1 bit chồng chéo".
