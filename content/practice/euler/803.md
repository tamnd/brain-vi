[Vấn đề dự án Euler 803](https://projecteuler.net/problem=803) 

##Giải pháp 

**Trả lời:**`9300900470636`Cho phép$$a_n = (25214903917\,a_{n-1}+11)\bmod 2^{48}$$và xác định$$b_n=\left\lfloor \frac{a_n}{2^{16}}\right\rfloor \bmod 52.$$Các giá trị$b_n\in\{0,\dots,51\}$được ánh xạ tới các ký tự$$0\to a,\dots,25\to z,\quad 26\to A,\dots,51\to Z.$$Chúng ta được biết rằng chuỗi đầu ra vô hạn bắt đầu bằng$$\texttt{PuzzleOne}\dots$$và chúng ta phải tìm sự xuất hiện đầu tiên của$$\texttt{LuckyText}.$$--- 

# 1. Phân tích toán học 

Trình tạo là một trình tạo đồng dư tuyến tính modulo$2^{48}$:$$a_n = A a_{n-1}+C \pmod{2^{48}},$$với$$A=25214903917,\qquad C=11.$$Vì thế,$$a_n = A^n a_0 + C\sum_{k=0}^{n-1}A^k \pmod{2^{48}}.$$Ký hiệu có thể quan sát được chỉ phụ thuộc vào 32 bit trên của trạng thái:$$b_n = (a_n \gg 16)\bmod 52.$$Do đó, mỗi ký tự được quan sát đưa ra một ràng buộc mô-đun về$a_n$. 

Quan sát chính là: 

- tiền tố 9 ký tự cho biết$9\log_2(52)\approx 51.3$những mẩu thông tin, 
- trạng thái ẩn chỉ có 48 bit. 

Vậy trạng thái ban đầu$a_0$về cơ bản được xác định duy nhất bởi tiền tố`"PuzzleOne"`. 

--- 

##Thu hồi hạt giống 

Chuyển ký tự thành số:$$\texttt{PuzzleOne} \mapsto [41,20,25,25,11,4,40,13,4].$$Đối với mỗi vị trí$n$,$$((a_n \gg 16)\bmod 52)=v_n.$$Từ$$a_n = A^n a_0 + d_n \pmod{2^{48}},$$tất cả các ràng buộc trở thành đồng dư trong một ẩn số duy nhất$a_0$. 

Bộ giải SAT/SMT (hoặc tìm kiếm vectơ bit tương đương) tìm ra giải pháp duy nhất$$a_0 = 269089419465884.$$(Thật vậy, ví dụ về phát biểu vấn đề`"EULERcats"`tương tự xác định một hạt giống duy nhất.)

## Tìm lần xuất hiện đầu tiên của`"LuckyText"`Bây giờ chúng ta chỉ cần tạo luồng và tìm kiếm mẫu. 

Một trình so khớp chuỗi thời gian tuyến tính tiêu chuẩn như KMP là đủ. 

Chuỗi mục tiêu là$$\texttt{LuckyText} \mapsto [37,20,2,10,24,45,4,23,19].$$Chạy trình tạo từ hạt giống đã phục hồi và áp dụng KMP mang lại chỉ số khớp đầu tiên:$$9300900470636.$$Kho lưu trữ câu trả lời Project Euler được lập chỉ mục công khai cũng liệt kê giá trị cuối cùng này.

#2. Triển khai Python```python
from z3 import *
from collections import deque

MOD = 1 << 48
MASK = MOD - 1

A = 25214903917
C = 11

alphabet = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
enc = {c: i for i, c in enumerate(alphabet)}

prefix = "PuzzleOne"
target = "LuckyText"

# ------------------------------------------------------------
# Recover a0 from the known prefix
# ------------------------------------------------------------

solver = Solver()

a0 = BitVec("a0", 64)

# constrain to 48 bits
solver.add(a0 >= 0)
solver.add(a0 < MOD)

x = a0

for ch in prefix:
    v = enc[ch]

    # ((x >> 16) mod 52) == v
    solver.add(URem(LShR(x, 16), 52) == v)

    # next state
    x = (A * x + C) & MASK

assert solver.check() == sat

model = solver.model()

seed = model[a0].as_long()

print("Recovered seed =", seed)

# ------------------------------------------------------------
# KMP preprocessing
# ------------------------------------------------------------

pat = [enc[c] for c in target]

pi = [0] * len(pat)

j = 0
for i in range(1, len(pat)):
    while j and pat[i] != pat[j]:
        j = pi[j - 1]

    if pat[i] == pat[j]:
        j += 1
        pi[i] = j

# ------------------------------------------------------------
# Generate stream and search
# ------------------------------------------------------------

state = seed
j = 0
idx = 0

while True:
    value = (state >> 16) % 52

    while j and value != pat[j]:
        j = pi[j - 1]

    if value == pat[j]:
        j += 1

    if j == len(pat):
        answer = idx - len(pat) + 1
        break

    state = (A * state + C) & MASK
    idx += 1

print("Answer =", answer)
```--- 

#3. Hướng dẫn sử dụng mã 

### Thu hồi hạt giống```python
solver = Solver()
```Chúng tôi sử dụng bộ giải SMT trên các vectơ bit.```python
solver.add(URem(LShR(x, 16), 52) == v)
```Điều này mã hóa chính xác định nghĩa$$b_n = (a_n >> 16)\bmod 52.$$

```python
x = (A * x + C) & MASK
```Điều này thúc đẩy trạng thái Rand48. 

Sau khi thêm 9 ràng buộc tiền tố, người giải sẽ tìm thấy hạt giống tương thích duy nhất. 

--- 

### tìm kiếm KMP 

Chúng tôi xử lý trước mẫu`"LuckyText"`vào một bảng thất bại`pi`. 

Sau đó, chúng tôi tạo luồng giả ngẫu nhiên một ký hiệu tại một thời điểm và cập nhật trạng thái KMP trong$O(1)$thời gian khấu hao cho mỗi ký tự. 

Vì Rand48 đã có kinh đầy đủ$2^{48}$, luồng cuối cùng là tuần hoàn với chu kỳ tối đa, do đó mục tiêu phải xảy ra ở đâu đó trước khi chu kỳ lặp lại.
