[Vấn đề dự án Euler 201](https://projecteuler.net/problem=201) 

## Giải pháp 

**Trả lời:**`115039000`Cho phép$$S=\{1^2,2^2,\dots,100^2\}.$$Chúng ta phải tìm tổng của tất cả các số nguyên xuất hiện dưới dạng tổng của **chính xác một**$50$-tập hợp phần tử của$S$. 

--- 

# Phân tích toán học 

Chúng ta đang xử lý các tập hợp con theo điều kiện duy nhất. 

Đối với một bộ$A$, định nghĩa$$U(A,k)=\left\{x : x \text{ is the sum of exactly one } k\text{-element subset of }A\right\}.$$Chúng tôi cần$$\sum U(S,50).$$--- 

## 1. Quan điểm lập trình động 

Mỗi phần tử của$S$có thể: 

- bị loại khỏi một tập hợp con, hoặc 
- được bao gồm. 

Chúng tôi muốn đếm mọi thứ có thể: 

- kích thước tập hợp con$j$, 
- tổng tập hợp con$t$, 

có bao nhiêu tập con đạt được cặp đó$(j,t)$. 

--- 

## 2. Quan sát quan trọng 

Chúng tôi **không** cần số lượng tập hợp con chính xác khi nó vượt quá$1$. 

Tại sao? 

Vì bài toán chỉ hỏi tổng có phải là: 

- đạt được$0$lần, 
- đạt được chính xác$1$thời gian, 
- hoặc đạt được nhiều hơn một lần. 

Vì vậy, chúng tôi có thể giới hạn tất cả số lượng tại$2$. 

Điều đó làm giảm đáng kể sự phức tạp. 

--- 

## 3. Định nghĩa DP 

Xác định:$$dp[j][t]$$có nghĩa là: 

-$0$: không thể nào,
-$1$: đúng một chiều, 
-$2$: ít nhất hai cách. 

Ban đầu:$$dp[0][0]=1$$vì tập con trống có kích thước$0$và tổng hợp$0$. 

Đối với mỗi hình vuông$a=i^2$, cập nhật ngược:$$dp[j+1][t+a] = \min\left(2,\; dp[j+1][t+a]+dp[j][t]\right).$$Việc lặp lại ngăn chặn việc sử dụng lại cùng một hình vuông nhiều lần. 

--- 

## 4. Số tiền tối đa có thể 

lớn nhất$50$-tổng tập hợp con là$$51^2+52^2+\cdots+100^2.$$sử dụng$$\sum_{i=1}^{100} i^2 = \frac{100\cdot101\cdot201}{6}=338350,$$Và$$\sum_{i=1}^{50} i^2 = 42925,$$chúng tôi nhận được$$338350-42925=295425.$$Vì vậy bảng DP chỉ cần tổng tới$295425$. 

--- 

#Triển khai Python```python
import numpy as np

# We need 50-element subset sums of squares 1^2 ... 100^2
N = 100
K = 50

squares = [i * i for i in range(1, N + 1)]

# Maximum possible 50-element sum
MAX_SUM = sum(i * i for i in range(51, 101))

# dp[j][s]:
#   0 = impossible
#   1 = exactly one way
#   2 = two or more ways
dp = np.zeros((K + 1, MAX_SUM + 1), dtype=np.uint8)

# Empty subset
dp[0][0] = 1

# Process each square
for a in squares:

    # Go backwards so each value is used once
    for j in range(K - 1, -1, -1):

        # Existing states for size j
        src = dp[j, :MAX_SUM + 1 - a]

        # Destination states for size j+1
        dst = dp[j + 1, a:]

        # Add counts, capped at 2
        total = dst.astype(np.uint16) + src.astype(np.uint16)
        total[total > 2] = 2

        dp[j + 1, a:] = total.astype(np.uint8)

# Sum all uniquely representable sums
answer = np.where(dp[K] == 1)[0].sum()

print(answer)
```--- 

# Hướng dẫn sử dụng mã 

## Bước 1: Xây dựng số bình phương```python
squares = [i * i for i in range(1, N + 1)]
```Điều này tạo ra:$$1,4,9,16,\dots,10000.$$--- 

## Bước 2: Bảng DP```python
dp = np.zeros((K + 1, MAX_SUM + 1), dtype=np.uint8)
```Các hàng tương ứng với kích thước tập hợp con$j$, các cột thành tập hợp con tổng$s$. 

Mỗi ô chỉ lưu trữ: 

-$0$, 
-$1$, 
-$2$(có nghĩa là “ít nhất hai”). 

--- 

## Bước 3: Khởi tạo```python
dp[0][0] = 1
```Có chính xác một tập con trống có tổng$0$. 

--- 

## Bước 4: Chuyển tiếp 

Đối với mỗi hình vuông$a$:```python
for j in range(K - 1, -1, -1):
```chúng tôi cập nhật ngược để tránh sử dụng lại$a$. 

Sau đó:```python
total = dst + src
total[total > 2] = 2
```thực hiện việc đếm giới hạn. 

--- 

## Bước 5: Trích xuất số tiền duy nhất```python
np.where(dp[K] == 1)[0]
```tìm tất cả số tiền đạt được bởi đúng một$50$-tập hợp con. 

Chúng tôi thêm tất cả chúng.
