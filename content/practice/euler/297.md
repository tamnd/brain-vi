[Vấn đề dự án Euler 297](https://projecteuler.net/problem=297) 

##Giải pháp 

**Trả lời:**`2252639041804718029`Cho phép$$F_1=1,\quad F_2=2,\quad F_n=F_{n-1}+F_{n-2}$$vậy dãy Fibonacci là$$1,2,3,5,8,13,\dots$$Mỗi số nguyên dương có một biểu diễn duy nhất dưới dạng tổng của các số Fibonacci **không liên tiếp** từ dãy này (định lý Zeckendorf). 

Định nghĩa$z(n)$là số số hạng Fibonacci trong biểu diễn Zeckendorf của$n$. 

Chúng ta phải tính toán$$\sum_{0<n<10^{17}} z(n).$$--- 

# Phân tích toán học 

Xác định$$S(N)=\sum_{0<n<N} z(n).$$Chúng tôi tìm kiếm$S(10^{17})$. 

--- 

## 1. Cấu trúc biểu diễn Zeckendorf 

Xét mọi số nhỏ hơn$F_k$. 

Mỗi số$n<F_k$rơi vào một trong hai nhóm: 

1.$0\le n<F_{k-1}$2.$F_{k-1}\le n<F_k$Đối với nhóm thứ hai, hãy viết$$n=F_{k-1}+m,$$nhất thiết phải ở đâu$$0\le m<F_{k-2},$$vì biểu diễn Zeckendorf không thể sử dụng các số Fibonacci liên tiếp. 

Như vậy$$z(n)=1+z(m).$$Vì vậy khoảng thời gian$[F_{k-1},F_k)$đóng góp: 

- thêm một thuật ngữ Fibonacci cho mỗi số, 
- cộng với sự đóng góp từ tất cả$m<F_{k-2}$. 

Kể từ đây:$$S(F_k)=S(F_{k-1})+S(F_{k-2})+F_{k-2}.$$(Thuật ngữ$F_{k-2}$đếm chính xác số “+1” bổ sung$F_{k-2}$giá trị.) 

--- 

## 2. Sự lặp lại cho các ranh giới Fibonacci chính xác 

Xác định$$A_k=S(F_k).$$Sau đó:$$A_k=A_{k-1}+A_{k-2}+F_{k-2}.$$Các trường hợp cơ bản:$$A_1=S(1)=0,$$

$$A_2=S(2)=z(1)=1.$$Điều này cho phép chúng ta tính toán tất cả$A_k$rất nhanh chóng. 

--- 

##3. Đệ quy tổng quát tùy ý$N$Cho phép$F_k$là số Fibonacci lớn nhất với$$F_k\le N.$$Chia phạm vi$0<n<N$vào trong:

-$0<n<F_k$-$F_k\le n<N$Việc đầu tiên đóng góp:$$A_k.$$Đối với số thứ hai, mọi số đều có dạng$$F_k+m,\qquad 0\le m<N-F_k,$$và do đó$$z(F_k+m)=1+z(m).$$Vì thế:$$S(N)=A_k+(N-F_k)+S(N-F_k).$$Sự đệ quy này làm giảm$N$bằng hàm triệu Fibonacci lớn nhất ở mỗi bước, phản ánh chính xác quá trình phân rã Zeckendorf. 

--- 

#Triển khai Python```python
from functools import lru_cache

LIMIT = 10**17

# ------------------------------------------------------------
# Build Fibonacci numbers:
# F1 = 1, F2 = 2
# ------------------------------------------------------------

fib = [1, 2]

while fib[-1] < LIMIT:
    fib.append(fib[-1] + fib[-2])

# ------------------------------------------------------------
# A[k] = S(F_k)
# where S(N) = sum_{0 < n < N} z(n)
#
# Recurrence:
# A[k] = A[k-1] + A[k-2] + F[k-2]
# ------------------------------------------------------------

A = [0] * len(fib)

A[0] = 0          # S(1)
A[1] = 1          # S(2)

for k in range(2, len(fib)):
    A[k] = A[k-1] + A[k-2] + fib[k-2]

# ------------------------------------------------------------
# Recursive computation of S(N)
# ------------------------------------------------------------

@lru_cache(None)
def S(N):
    if N <= 1:
        return 0

    # largest Fibonacci number <= N
    k = 0
    while k + 1 < len(fib) and fib[k + 1] <= N:
        k += 1

    # exact boundary
    if fib[k] == N:
        return A[k]

    # recursive decomposition
    return A[k] + (N - fib[k]) + S(N - fib[k])

# ------------------------------------------------------------
# Compute answer
# ------------------------------------------------------------

answer = S(10**17)

print(answer)
```--- 

# Hướng dẫn sử dụng mã 

## Xây dựng số Fibonacci```python
fib = [1, 2]
while fib[-1] < LIMIT:
    fib.append(fib[-1] + fib[-2])
```Tạo:$$1,2,3,5,8,13,\dots$$đến hơn thế nữa$10^{17}$. 

--- 

## Tính toán trước$A_k=S(F_k)$

```python
A[k] = A[k-1] + A[k-2] + fib[k-2]
```Điều này thực hiện sự tái phát có nguồn gốc trước đó. 

Ví dụ:$$S(8)=10$$bởi vì:$$\begin{aligned} z(1)&=1\\ z(2)&=1\\ z(3)&=1\\ z(4)&=2\\ z(5)&=1\\ z(6)&=2\\ z(7)&=2 \end{aligned}$$Và$$1+1+1+2+1+2+2=10.$$--- 

## Tính toán đệ quy```python
return A[k] + (N - fib[k]) + S(N - fib[k])
```Điều này tương ứng chính xác với:$$S(N)=S(F_k)+(N-F_k)+S(N-F_k).$$Độ sâu đệ quy rất nhỏ vì quá trình phân tách Zeckendorf rất ngắn.
