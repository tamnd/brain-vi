[Vấn đề dự án Euler 187](https://projecteuler.net/problem=187) 

## Giải pháp 

**Trả lời:**`17427258`Chúng tôi đang đếm các số nguyên$$n < 10^8$$có **chính xác hai thừa số nguyên tố**, được tính theo bội số. 

Những con số như vậy được gọi là **bán nguyên**. 

Ví dụ: 

-$15 = 3\cdot 5$-$9 = 3^2$-$12 = 2^2\cdot 3$→ không được phép (ba thừa số nguyên tố tính bội số) 

Vì vậy, chúng tôi muốn tất cả các số có dạng$$n = pq$$Ở đâu$p,q$là số nguyên tố và$p \le q$. 

--- 

# Phân tích toán học 

Chúng ta cần đếm các cặp số nguyên tố$(p,q)$như vậy$$pq < 10^8.$$Để tránh tính hai lần, hãy thực thi$$p \le q.$$Như vậy với mỗi số nguyên tố$p$, chúng tôi đếm số nguyên tố$q$thỏa mãn$$q \ge p,\qquad q < \frac{10^8}{p}.$$--- 

## Quan sát chính 

Nếu$p > \sqrt{10^8} = 10^4$, sau đó$$p^2 > 10^8,$$vì vậy không có giá trị$q \ge p$tồn tại. 

Vì vậy chúng ta chỉ cần số nguyên tố$$p \le 10^4.$$Với mỗi số nguyên tố như vậy$p$: 

1. Hãy để$$M = \left\lfloor \frac{10^8-1}{p} \right\rfloor.$$2. Đếm số nguyên tố$q$với$$p \le q \le M.$$Nếu như$\pi(x)$biểu thị số lượng số nguyên tố$\le x$, và nếu$p$là$i$-số nguyên tố thứ (0-lập chỉ mục), sau đó là số lượng được chấp nhận$q$là$$\pi(M) - i.$$Tổng hợp tất cả hợp lệ$p$đưa ra câu trả lời. 

--- 

# Thuật toán hiệu quả 

Chúng tôi cần: 

1. Tất cả các số nguyên tố đến$10^8 / 2 = 5\times10^7$. 
2. Đếm số nguyên tố nhanh$\pi(x)$. 

Một sàng Eratosthenes lên đến$5\times10^7$là khả thi trong Python/PyPy được tối ưu hóa, nhưng về mặt khái niệm, phương pháp này rất đơn giản. 

Quá trình giả: 

- Tạo tất cả các số nguyên tố lên đến$5\times10^7$. 
- Đối với mỗi số nguyên tố$p \le 10^4$: 

- Tìm có bao nhiêu số nguyên tố$\le (10^8-1)/p$. 
- Trừ chỉ số của$p$để thực thi$q \ge p$. 

Sự phức tạp bị chi phối bởi sàng. 

--- 

#Triển khai Python```python
from bisect import bisect_right
from math import isqrt

LIMIT = 10**8

# We only need primes up to LIMIT // 2
MAXP = LIMIT // 2

# Sieve of Eratosthenes
sieve = bytearray(b"\x01") * (MAXP + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(MAXP) + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:MAXP + 1:step] = b"\x00" * (((MAXP - start) // step) + 1)

# Extract primes
primes = [i for i in range(2, MAXP + 1) if sieve[i]]

answer = 0

# Only need p <= sqrt(LIMIT)
root = isqrt(LIMIT)

for i, p in enumerate(primes):
    if p > root:
        break

    max_q = (LIMIT - 1) // p

    # Number of primes <= max_q
    count = bisect_right(primes, max_q)

    # Enforce q >= p
    answer += count - i

print(answer)
```---
