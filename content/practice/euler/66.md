[Bài toán Euler dự án 66](https://projecteuler.net/problem=66) 

##Giải pháp 

**Trả lời:**`661`Đối với phương trình Pell$$x^2 - Dy^2 = 1,$$với$D$một số nguyên dương không phải bình phương, chúng ta tìm kiếm giá trị của$D \le 1000$giải pháp _tối thiểu_ của ai$x$là càng lớn càng tốt. 

Thực tế quan trọng là nghiệm tối thiểu của phương trình Pell được tạo ra từ việc khai triển phân số liên tục của$\sqrt D$. 

--- 

# Phân tích toán học 

Chúng tôi muốn các giải pháp số nguyên để$$x^2 - Dy^2 = 1.$$Đây là phương trình Pell. 

Đối với hình vuông$D$, chúng ta không có nghiệm số nguyên không tầm thường vì$$x^2 - Dy^2=(x-\sqrt D\,y)(x+\sqrt D\,y),$$Và$\sqrt D$là hợp lý. Vì vậy, chúng tôi chỉ xem xét các hình vuông. 

--- 

## Phân số tiếp tục và phương trình Pell 

Một định lý cổ điển phát biểu: 

> Giải pháp tối thiểu$(x,y)$của 
> 
> 
> 
> 
>$$x^2-Dy^2=1$$> 
> 
> 
> 
> thu được từ sự hội tụ của khai triển phân số liên tục định kỳ của$\sqrt D$. 

Phần tiếp tục của$\sqrt D$có hình thức$$\sqrt D = [a_0;\overline{a_1,a_2,\dots,a_k}],$$nơi khối lặp lại định kỳ. 

Các hội tụ là phân số$$\frac{p_n}{q_n},$$được tạo đệ quy bởi$$p_n = a_n p_{n-1} + p_{n-2},$$

$$q_n = a_n q_{n-1} + q_{n-2}.$$Một điểm hội tụ thỏa mãn phương trình Pell một cách chính xác khi$$p_n^2 - D q_n^2 = 1.$$Sự hội tụ đầu tiên như vậy cho nghiệm tối thiểu. 

--- 

## Tính phần tiếp theo của$\sqrt D$Đối với không vuông$D$, định nghĩa$$a_0 = \lfloor \sqrt D \rfloor.$$Sau đó lặp lại$$m_{n+1} = d_n a_n - m_n,$$

$$d_{n+1} = \frac{D - m_{n+1}^2}{d_n},$$

$$a_{n+1} = \left\lfloor \frac{a_0 + m_{n+1}}{d_{n+1}} \right\rfloor.$$bắt đầu bằng$$m_0=0,\quad d_0=1,\quad a_0=\lfloor\sqrt D\rfloor.$$Ở mỗi bước chúng ta xây dựng các điểm hội tụ cho đến khi phương trình Pell được thỏa mãn. 

--- 

#Triển khai Python```python
import math

def minimal_pell_solution_x(D):
    """
    Return the minimal x satisfying:
        x^2 - D*y^2 = 1
    for a non-square D.
    """

    a0 = int(math.isqrt(D))

    # Ignore perfect squares
    if a0 * a0 == D:
        return None

    # Continued fraction variables
    m = 0
    d = 1
    a = a0

    # Convergent recurrence:
    # p/q are convergents
    p_minus2, p_minus1 = 0, 1
    q_minus2, q_minus1 = 1, 0

    while True:
        # Current convergent
        p = a * p_minus1 + p_minus2
        q = a * q_minus1 + q_minus2

        # Check Pell equation
        if p * p - D * q * q == 1:
            return p

        # Advance continued fraction
        m = d * a - m
        d = (D - m * m) // d
        a = (a0 + m) // d

        # Shift recurrence variables
        p_minus2, p_minus1 = p_minus1, p
        q_minus2, q_minus1 = q_minus1, q

max_x = 0
answer_D = 0

for D in range(2, 1001):
    x = minimal_pell_solution_x(D)

    if x is not None and x > max_x:
        max_x = x
        answer_D = D

print(answer_D)
```---

## Phát hiện các hình vuông hoàn hảo```python
a0 = int(math.isqrt(D))

if a0 * a0 == D:
    return None
```Bình phương hoàn hảo bị loại trừ vì phương trình Pell không có nghiệm dương không tầm thường ở đó. 

--- 

## Khởi tạo các biến phân số tiếp theo```python
m = 0
d = 1
a = a0
```Những điều này tạo ra sự mở rộng phân đoạn liên tục của$\sqrt D$. 

--- 

## Khởi tạo tái phát hội tụ```python
p_minus2, p_minus1 = 0, 1
q_minus2, q_minus1 = 1, 0
```Đây là những giá trị bắt đầu tiêu chuẩn cho sự hội tụ. 

--- 

## Xây dựng điểm hội tụ```python
p = a * p_minus1 + p_minus2
q = a * q_minus1 + q_minus2
```Điều này tính toán sự hội tụ tiếp theo$p/q$. 

--- 

## Kiểm tra phương trình Pell```python
if p * p - D * q * q == 1:
    return p
```Hội tụ đầu tiên thỏa mãn phương trình cho nghiệm tối thiểu. 

--- 

## Phân số tiếp theo nâng cao```python
m = d * a - m
d = (D - m * m) // d
a = (a0 + m) // d
```Đây là các công thức truy hồi tiêu chuẩn cho các phân số liên tục của số vô tỉ bậc hai.

# Xác minh ví dụ nhỏ 

cho$D=13$, mã tìm thấy:$$649^2 - 13 \cdot 180^2 = 1.$$Thực vậy,$$649^2 = 421201,$$

$$13 \cdot 180^2 = 13 \cdot 32400 = 421200,$$sự khác biệt$=1$. 

Điều này phù hợp với tuyên bố vấn đề. 

Vì$D \le 7$, tối thiểu$x$-giá trị là: 

|$D$| tối thiểu$x$| 
| --- | --- | 
| 2 | 3 | 
| 3 | 2 | 
| 5 | 9 | 
| 6 | 5 | 
| 7 | 8 | 

Lớn nhất là$9$Tại$D=5$, một lần nữa khớp với lời nhắc.
