[Dự án Euler Vấn đề 815](https://projecteuler.net/problem=815) 

##Giải pháp 

**Trả lời:**`54.12691621`Hãy để trạng thái của quá trình được mô tả bởi 

-$u$: số giá trị chưa thấy, 
-$a$: số lượng cọc$1$, 
-$b$: số lượng cọc$2$, 
-$c$: số lượng cọc$3$. 

Khi đó số cọc không trống hiện tại là$$s=a+b+c.$$Ban đầu trạng thái là$$(u,a,b,c)=(n,0,0,0).$$Một đống biến mất khi nó đạt đến kích thước$4$. 

--- 

# 1. Phân tích toán học 

Ở trạng thái$(u,a,b,c)$, số thẻ còn lại là$$4u+3a+2b+c.$$Thật vậy: 

- mỗi giá trị vô hình đều đóng góp$4$thẻ, 
- mỗi cọc cỡ 1 đóng góp$3$thẻ còn lại, 
- mỗi cọc cỡ 2 góp phần$2$, 
- mỗi cọc cỡ 3 đóng góp$1$. 

Các chuyển tiếp là: 

### Vẽ một giá trị mới 

Xác suất$$\frac{4u}{4u+3a+2b+c}.$$Thay đổi trạng thái:$$(u,a,b,c)\to(u-1,a+1,b,c).$$Số lượng cọc tăng thêm$1$. 

--- 

### Mở rộng cọc cỡ 1 

Xác suất$$\frac{3a}{4u+3a+2b+c}.$$Chuyển tiếp:$$(u,a,b,c)\to(u,a-1,b+1,c).$$Số cọc không thay đổi. 

--- 

### Mở rộng cọc cỡ 2 

Xác suất$$\frac{2b}{4u+3a+2b+c}.$$Chuyển tiếp:$$(u,a,b,c)\to(u,a,b-1,c+1).$$Số cọc không thay đổi. 

--- 

### Hoàn thành cọc cỡ 3 

Xác suất$$\frac{c}{4u+3a+2b+c}.$$Chuyển tiếp:$$(u,a,b,c)\to(u,a,b,c-1).$$Số lượng cọc giảm đi$1$. 

--- 

Chúng ta phải tính toán số lượng cọc đồng thời tối đa dự kiến trong toàn bộ quá trình. 

Cách tiếp cận rõ ràng nhất là lập trình động trên:$$(u,a,b,c,m),$$Ở đâu$m$là số lượng cọc tối đa được nhìn thấy cho đến nay. 

Chúng tôi tuyên truyền xác suất thông qua tất cả$4n$rút thẻ. 

Cuối cùng, tất cả các trạng thái đều$(0,0,0,0,m)$, Vì thế$$E(n)=\sum_m m\Pr(M=m).$$--- 

#2. Triển khai Python```python
from collections import defaultdict

def expected_max_piles(n):
    # state = (u, a, b, c, m)
    # u = unseen values
    # a = piles of size 1
    # b = piles of size 2
    # c = piles of size 3
    # m = maximum number of piles seen so far

    dp = {(n, 0, 0, 0, 0): 1.0}

    # There are exactly 4n card draws
    for _ in range(4 * n):

        nxt = defaultdict(float)

        for (u, a, b, c, m), prob in dp.items():

            remaining = 4*u + 3*a + 2*b + c
            piles = a + b + c

            # Draw a new value
            if u:
                new_piles = piles + 1
                nxt[(u-1, a+1, b, c,
                     max(m, new_piles))] += prob * (4*u / remaining)

            # Extend a size-1 pile
            if a:
                nxt[(u, a-1, b+1, c, m)] += prob * (3*a / remaining)

            # Extend a size-2 pile
            if b:
                nxt[(u, a, b-1, c+1, m)] += prob * (2*b / remaining)

            # Complete a size-3 pile
            if c:
                nxt[(u, a, b, c-1, m)] += prob * (c / remaining)

        dp = nxt

    # Expected value of the maximum
    ans = 0.0

    for (u, a, b, c, m), prob in dp.items():
        ans += m * prob

    return ans

# Check the example
print(f"{expected_max_piles(2):.8f}")

# Compute E(60)
print(f"{expected_max_piles(60):.8f}")
```--- 

#3. Hướng dẫn sử dụng mã 

## Khởi tạo```python
dp = {(n, 0, 0, 0, 0): 1.0}
```Ban đầu: 

- tất cả$n$các giá trị không được nhìn thấy, 
- không có cọc tồn tại, 
- số lượng cọc tối đa cho đến nay là$0$. 

--- 

## Chuyển đổi trạng thái 

Đối với mỗi trạng thái, chúng tôi tính toán:```python
remaining = 4*u + 3*a + 2*b + c
```đó là số lá bài còn lại trong bộ bài. 

Sau đó, chúng tôi phân phối khối lượng xác suất theo bốn loại thẻ có thể có. 

--- 

## Theo dõi tối đa 

Khi một đống mới được tạo:```python
new_piles = piles + 1
max(m, new_piles)
```cập nhật mức chạy tối đa. 

--- 

## Kỳ vọng cuối cùng 

Rốt cuộc$4n$thẻ được xử lý, mọi con đường đã kết thúc. 

Chúng tôi tính toán:```python
ans += m * prob
```đó chính xác là$$E(M)=\sum_m m\,P(M=m).$$--- 

# 4. Xác minh 

cho$n=2$, chương trình đưa ra$$E(2)=1.97142857,$$phù hợp với giá trị được đưa ra trong báo cáo vấn đề. 

Vì$n=60$, quá trình tính toán ổn định và tạo ra giá trị thấp hơn một chút$60$, như mong đợi.
