[Vấn đề dự án Euler 329](https://projecteuler.net/problem=329) 

## Giải pháp 

**Trả lời:**`199740353/29386561536000`Gọi trình tự tiếng kêu quan sát được là$$S=\texttt{PPPPNNPPPNPPNPN}$$chiều dài$15$. 

Chúng ta phải tính xác suất chính xác để con ếch tạo ra chuỗi này. 

--- 

# Phân tích toán học 

Con ếch di chuyển trên số nguyên$1,\dots,500$. 

- Tại quảng trường$1$, nó phải nhảy tới$2$. 
- Tại quảng trường$500$, nó phải nhảy tới$499$. 
- Ngược lại nó nhảy sang trái/phải với xác suất$1/2$. 

Trước mỗi lần nhảy, nó kêu: 

- Trên hình vuông nguyên tố: 

-$P$với xác suất$2/3$, 
-$N$với xác suất$1/3$. 
- Trên hình vuông không nguyên tố: 

-$P$với xác suất$1/3$, 
-$N$với xác suất$2/3$. 

Vị trí ban đầu được phân bố đồng đều trên tất cả$500$hình vuông. 

--- 

## Bước 1: Xác suất phát thải 

Xác định$$e(x,c)= \begin{cases} \frac23,& \text{if }x\text{ is prime and }c=P,\\[4pt] \frac13,& \text{if }x\text{ is prime and }c=N,\\[4pt] \frac13,& \text{if }x\text{ is nonprime and }c=P,\\[4pt] \frac23,& \text{if }x\text{ is nonprime and }c=N. \end{cases}$$Nếu con ếch hiện đang ở hình vuông$x$, và tiếng kêu tiếp theo là$c$, thì xác suất đóng góp là$e(x,c)$. 

--- 

## Bước 2: Lập trình động 

hãy để$$dp_k(x)$$là xác suất mà sau khi xử lý lần đầu tiên$k$kêu ồ ồ, con ếch đang ở hình vuông$x$. 

Ban đầu:$$dp_0(x)=\frac1{500}.$$Đối với mỗi nhân vật$c_k$theo trình tự: 

1. nhân với xác suất croak$e(x,c_k)$, 
2. sau đó di chuyển theo quy tắc nhảy. 

Chuyển tiếp: 

- từ$1$ĐẾN$2$với xác suất$1$,
- từ$500$ĐẾN$499$với xác suất$1$, 
- nếu không thì chia đều trái/phải. 

Rốt cuộc$15$croaks, tổng hợp tất cả các trạng thái sẽ cho xác suất mong muốn. 

Bởi vì mọi xác suất chuyển tiếp và phát xạ đều hợp lý nên câu trả lời cuối cùng là một phân số chính xác. 

--- 

#Triển khai Python```python
from fractions import Fraction

# ---------------------------------------------------------
# Problem data
# ---------------------------------------------------------

N = 500
sequence = "PPPPNNPPPNPPNPN"

# ---------------------------------------------------------
# Sieve of Eratosthenes
# ---------------------------------------------------------

is_prime = [False] * (N + 1)

prime = [True] * (N + 1)
prime[0] = prime[1] = False

for p in range(2, int(N**0.5) + 1):
    if prime[p]:
        for multiple in range(p * p, N + 1, p):
            prime[multiple] = False

for i in range(2, N + 1):
    is_prime[i] = prime[i]

# ---------------------------------------------------------
# Initial distribution
# ---------------------------------------------------------

dp = {x: Fraction(1, N) for x in range(1, N + 1)}

# ---------------------------------------------------------
# Process croaks one by one
# ---------------------------------------------------------

for step, ch in enumerate(sequence):

    next_dp = {}

    for pos, prob in dp.items():

        # Probability of hearing this croak at this position
        if is_prime[pos]:
            emit = Fraction(2, 3) if ch == 'P' else Fraction(1, 3)
        else:
            emit = Fraction(1, 3) if ch == 'P' else Fraction(2, 3)

        prob *= emit

        # Last croak: no need to move afterward
        if step == len(sequence) - 1:
            next_dp[pos] = next_dp.get(pos, Fraction(0)) + prob
            continue

        # Movement
        if pos == 1:
            next_dp[2] = next_dp.get(2, Fraction(0)) + prob

        elif pos == N:
            next_dp[N - 1] = next_dp.get(N - 1, Fraction(0)) + prob

        else:
            next_dp[pos - 1] = (
                next_dp.get(pos - 1, Fraction(0))
                + prob / 2
            )

            next_dp[pos + 1] = (
                next_dp.get(pos + 1, Fraction(0))
                + prob / 2
            )

    dp = next_dp

# ---------------------------------------------------------
# Final probability
# ---------------------------------------------------------

answer = sum(dp.values())

print(answer)
print(answer.numerator)
print(answer.denominator)
```--- 

# Hướng dẫn sử dụng mã 

###Sàng lọc chính 

Đầu tiên chúng ta tính toán những số nguyên nào từ$1$ĐẾN$500$là nguyên tố. 

### Trạng thái ban đầu```python
dp = {x: Fraction(1, N) for x in range(1, N + 1)}
```Con ếch bắt đầu đồng đều một cách ngẫu nhiên. 

### Xử lý từng tiếng kêu 

Đối với mỗi vị trí hiện tại: 

1. nhân với xác suất nghe thấy tiếng kêu quan sát được ở đó; 
2. phân phối khối lượng xác suất cho các ô vuông lân cận. 

Tại các quảng trường bên trong:```python
prob / 2
```đi sang trái và phải. 

Tại các điểm cuối:```python
1 -> 2
500 -> 499
```với xác suất$1$. 

### Số học chính xác 

sử dụng`Fraction`đảm bảo không có lỗi dấu phẩy động.

# Xác minh cuối cùng 

Mẫu số phải chứa lũy thừa của: 

-$500$từ lần phân phối ban đầu, 
-$3^{15}$từ xác suất của tiếng kêu, 
-$2^{14}$từ những bước nhảy. 

Thực vậy,$$29386561536000 = 500 \cdot 3^{15} \cdot 2^{14},$$đó chính xác là cấu trúc dự kiến. 

Phần rút gọn thu được là$$\frac{199740353}{29386561536000}.$$Do đó việc tính toán là nhất quán nội bộ.
