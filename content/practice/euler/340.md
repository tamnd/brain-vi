[Vấn đề dự án Euler 340](https://projecteuler.net/problem=340) 

##Giải pháp 

**Trả lời:**`291504964`Cho phép$$F(n)= \begin{cases} n-c & n>b\\[4pt] F(a+F(a+F(a+F(a+n)))) & n\le b \end{cases}$$Và$$S(a,b,c)=\sum_{n=0}^{b}F(n).$$Chúng tôi cần:$$S(21^7,7^{21},12^7)$$modulo$10^9$. 

## 1. Phân tích toán học 

Xác định$$d=a-c.$$Từ$a>c$, chúng tôi có$d>0$. 

Vì$n>b$,$$F(n)=n-c=n-d-a+a.$$Điều quan trọng là phải hiểu điều gì xảy ra với$n\le b$. 

### Bước 1: Phân vùng$n$thành khối 

hãy để$$k=\left\lfloor \frac{b-n}{a}\right\rfloor.$$Điều này có nghĩa$n$nằm trong$k$-khối thứ từ trên xuống:$$b-(k+1)a < n \le b-ka.$$Chúng tôi khẳng định:$$F(n)=n+D_k$$cho hằng số phụ thuộc khối$D_k$. 

--- 

### Bước 2: Trường hợp cơ sở ($k=0$)

Nếu như$b-a<n\le b$, sau đó$a+n>b$, Vì thế:$$F(a+n)=a+n-c=n+d.$$Sau đó, mọi đối số lồng nhau còn lại đã$>b$, vì vậy mỗi ứng dụng bên ngoài sẽ trừ đi một ứng dụng khác$c$:$$F(n) = n+d+d+d+d = n+4(a-c).$$Như vậy$$D_0=4a-4c.$$--- 

### Bước 3: Lặp lại cho$D_k$Giả định$n$đang ở trong khối$k\ge1$. Sau đó$a+n$nằm trong khối$k-1$, do đó bằng quy nạp:$$F(a+n) = (a+n)+D_{k-1}.$$Sau đó, ba ứng dụng bên ngoài còn lại đều nằm trong$>b$chế độ, mỗi người đóng góp$+d$. Kể từ đây:$$D_k = a+D_{k-1}+3d.$$Từ$d=a-c$,$$D_k = D_{k-1}+4a-3c.$$Với$$D_0=4a-4c,$$điều này giải quyết:$$D_k = (k+1)(4a-3c)-c.$$Vì thế:$$\boxed{ F(n) = n+(k+1)(4a-3c)-c }$$Ở đâu$$k=\left\lfloor \frac{b-n}{a}\right\rfloor.$$--- 

### Bước 4: Tính tổng 

hãy để$$b=qa+r, \qquad 0\le r<a.$$Sau đó: 

- khối$k=0,\dots,q-1$mỗi cái chứa chính xác$a$giá trị, 
- khối$k=q$chứa$r+1$các giá trị. 

Cũng,$$\sum_{n=0}^{b} n = \frac{b(b+1)}{2}.$$Cho phép$$T=4a-3c.$$Từ$$D_k=(k+1)T-c,$$tổng số tiền bù đắp là$$a\sum_{k=0}^{q-1}\big((k+1)T-c\big) + (r+1)\big((q+1)T-c\big).$$sử dụng$$\sum_{j=1}^{q}j=\frac{q(q+1)}{2},$$chúng tôi nhận được$$S(a,b,c) = \frac{b(b+1)}{2} + a\left( T\frac{q(q+1)}{2} -cq \right) + (r+1)\big((q+1)T-c\big).$$--- 

## 2. Triển khai Python```python
def crazy_sum(a, b, c):
    # Divide b into full blocks of size a
    q, r = divmod(b, a)

    # Constant increment per block
    T = 4 * a - 3 * c

    # Sum of n from 0 to b
    total = b * (b + 1) // 2

    # Contribution from full blocks
    full_blocks = a * (
        T * q * (q + 1) // 2 - c * q
    )

    # Contribution from the final partial block
    final_block = (r + 1) * (
        (q + 1) * T - c
    )

    return total + full_blocks + final_block

# Example check
print(crazy_sum(50, 2000, 40))
# 5204240

# Required problem
a = 21 ** 7
b = 7 ** 21
c = 12 ** 7

answer = crazy_sum(a, b, c) % (10 ** 9)
print(answer)
```--- 

## 3. Hướng dẫn sử dụng mã 

###`divmod(b, a)`Chia tách$b$vào trong:$$b=qa+r$$nên chúng ta biết có bao nhiêu khối chiều rộng hoàn chỉnh$a$hiện hữu. 

###`T = 4*a - 3*c`Đây là kích thước bước trong tiến trình số học của độ lệch khối:$$D_k=(k+1)T-c.$$###`total`Thêm đóng góp cơ bản$$\sum n=\frac{b(b+1)}{2}.$$###`full_blocks`Tổng số bù cho tất cả các khối đầy đủ:$$a\sum_{k=0}^{q-1}D_k.$$###`final_block`Thêm khối kích thước một phần còn sót lại$r+1$. 

---

cho$$(a,b,c)=(50,2000,40)$$mã trả về:$$5204240$$phù hợp chính xác với tuyên bố vấn đề.
