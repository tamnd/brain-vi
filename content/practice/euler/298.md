[Vấn đề dự án Euler 298](https://projecteuler.net/problem=298) 

## Giải pháp 

**Trả lời:**`1.76882294`Cho phép

-$L$= Điểm của Larry, 
-$R$= Điểm của Robin. 

Chúng ta phải tính toán$$\mathbb E(|L-R|)$$sau 50 lượt. 

Điểm quan trọng là trò chơi ở **trạng thái hữu hạn**. 

--- 

# 1. Phân tích toán học 

Ở mỗi lượt: 

- một số ngẫu nhiên từ$1,\dots,10$được vẽ đồng đều, 
- mỗi người chơi: 

- ghi điểm nếu số đó đã được ghi nhớ, hoặc 
- chèn số và có thể xóa một số cũ. 

Thông tin duy nhất cần thiết để tiếp tục quá trình là: 

1. Trạng thái trí nhớ của Larry, 
2. Trạng thái trí nhớ của Robin, 
3. sự khác biệt về điểm số hiện tại$d=L-R$, 
4. số lượt. 

--- 

## Chiến lược của Larry (LRU) 

Larry xóa số ít được sử dụng gần đây nhất. 

Vì vậy, bộ nhớ của Larry có thể được biểu diễn bằng một bộ dữ liệu có thứ tự$$(a_1,a_2,\dots,a_k)$$từ ít gần đây nhất đến gần đây nhất. 

Nếu một số đã tồn tại thì nó sẽ được chuyển xuống cuối. 

--- 

## Chiến lược của Robin (FIFO) 

Robin xóa số tồn tại lâu nhất trong bộ nhớ. 

Vì vậy, trí nhớ của Robin chỉ đơn giản là một hàng đợi được sắp xếp từ cũ nhất đến mới nhất. 

Lượt truy cập **không** thay đổi thứ tự. 

--- 

# nén trạng thái 

Các nhãn thực tế$1,\dots,10$không liên quan. 

Chỉ có cấu trúc bình đẳng mới quan trọng. 

Ví dụ: các trạng thái chứa số$$(3,7,9)$$Và$$(1,4,6)$$là tương đương. 

Vì vậy, sau mỗi lần chuyển đổi, chúng tôi gắn nhãn lại các ký hiệu một cách chuẩn mực: 

- biểu tượng xuất hiện đầu tiên$\to 0$- biểu tượng mới tiếp theo$\to 1$- v.v. 

Điều này làm giảm không gian trạng thái rất nhiều. 

--- 

# Lập trình động lặp lại 

Xác định$$F(t,S_L,S_R,d)$$là giá trị cuối cùng dự kiến ​​của$|L-R|$sau lượt thứ 50, cho trước: 

- rẽ$t$, 
- Bang Larry$S_L$, 
- Bang Robin$S_R$, 
- chênh lệch điểm hiện tại$d$. 

Trường hợp cơ sở:$$F(50,\cdot,\cdot,d)=|d|.$$Chuyển tiếp: 

Đối với mỗi số tiếp theo có thể$x\in\{1,\dots,10\}$, 

- cập nhật bộ nhớ Larry, 
- cập nhật bộ nhớ Robin, 
- cập nhật chênh lệch điểm số theo$$d' = d + (\text{Larry hit}) - (\text{Robin hit}),$$sau đó tính trung bình trên 10 lần rút thăm có khả năng như nhau. 

Như vậy,$$F=\frac1{10}\sum_x F(\text{next state}).$$Ghi nhớ tính toán chính xác tất cả các trạng thái có thể truy cập. 

--- 

#2. Triển khai Python```python
from functools import cache

N = 50          # number of turns
NUMS = 10       # numbers 1..10
CAP = 5         # memory size

def canonicalize(lru, fifo):
    """
    Renumber symbols canonically so equivalent states merge.
    """
    mp = {}
    nxt = 0

    def conv(seq):
        nonlocal nxt
        out = []
        for x in seq:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])
        return tuple(out)

    return conv(lru), conv(fifo)

@cache
def dp(turn, lru, fifo, diff):
    """
    Expected final |L-R| from this state.
    """

    # after 50 turns
    if turn == N:
        return abs(diff)

    lru = list(lru)
    fifo = list(fifo)

    # currently used canonical symbols
    used = max([-1] + lru + fifo) + 1

    total = 0.0

    # existing symbols each represent one actual number
    choices = [(i, 1) for i in range(used)]

    # all unseen numbers are equivalent
    unseen = NUMS - used
    if unseen > 0:
        choices.append(("new", unseen))

    for x, weight in choices:

        value = used if x == "new" else x

        # ----- Larry (LRU) -----
        nlru = lru.copy()

        if value in nlru:
            l_hit = 1
            nlru.remove(value)
            nlru.append(value)
        else:
            l_hit = 0
            if len(nlru) == CAP:
                nlru.pop(0)
            nlru.append(value)

        # ----- Robin (FIFO) -----
        nfifo = fifo.copy()

        if value in nfifo:
            r_hit = 1
        else:
            r_hit = 0
            if len(nfifo) == CAP:
                nfifo.pop(0)
            nfifo.append(value)

        ndiff = diff + l_hit - r_hit

        clru, cfifo = canonicalize(tuple(nlru), tuple(nfifo))

        total += weight * dp(turn + 1, clru, cfifo, ndiff)

    return total / NUMS

answer = dp(0, (), (), 0)

print(f"{answer:.8f}")
```--- 

#3. Hướng dẫn sử dụng mã 

## Chuẩn hóa```python
canonicalize(lru, fifo)
```đánh số lại các ký hiệu một cách nhất quán: 

- biểu tượng nhìn thấy đầu tiên trở thành 0, 
- tiếp theo trở thành 1, 
- v.v. 

Điều này hợp nhất các trạng thái tương đương và làm cho DP khả thi. 

--- 

## Trạng thái DP```python
dp(turn, lru, fifo, diff)
```lưu trữ giá trị tương lai dự kiến. 

Thông số: 

-`turn`= vòng hiện tại, 
-`lru`= Thứ tự bộ nhớ của Larry, 
-`fifo`= Thứ tự bộ nhớ Robin, 
-`diff = L - R`. 

--- 

## Số hiện có và số chưa thấy 

Giả sử hiện tại chỉ có 4 nhãn riêng biệt xuất hiện. 

Sau đó: 

- mỗi nhãn hiện có tương ứng với chính xác một số thực, 
- tất cả các số chưa nhìn thấy đều hoạt động giống hệt nhau. 

Vì vậy, thay vì phân nhánh tất cả 10 số riêng lẻ, chúng tôi tổng hợp các số không nhìn thấy thành một chuyển đổi với bội số. 

Điều này làm giảm đáng kể tính toán. 

--- 

## Đang cập nhật Larry 

Trên một hit:```python
nlru.remove(value)
nlru.append(value)
```vì số này được sử dụng gần đây nhất. 

Bị bỏ lỡ: 

- loại bỏ ít được sử dụng gần đây nhất nếu đầy, 
- thêm số mới. 

--- 

## Cập nhật Robin 

Hành vi FIFO: 

- lượt truy cập không làm gì cả, 
- nhớ nối thêm, 
- nếu đầy thì đuổi cái cũ đi.

# 4. Xác minh 

Kỳ vọng phải thỏa mãn:$$0 \le \mathbb E(|L-R|) \le 50.$$Vì cả hai chiến lược đều khá giống nhau nên sự khác biệt kỳ vọng sẽ nhỏ. 

Giá trị tính toán:$$1.76882294$$là hoàn toàn hợp lý. 

Việc triển khai độc lập DP này sẽ tạo ra kết quả tương tự.
