## Giải pháp 

**Trả lời:**`15964587728784`Cho phép$$T(a,b,c,d,e,f)=(b,c,d,e,f,a\oplus (b\land c)).$$Điều kiện trong bài toán là$$\tau(x)\land \tau(T(x))=0$$cho mọi$6$trạng thái -bit$x$. 

Chúng ta phải đếm tất cả các hàm Boolean$$\tau:\{0,1\}^6\to\{0,1\}$$sao cho không có trạng thái và hình ảnh của nó dưới$T$cả hai đều được giao$1$. 

Điều quan trọng là phải hiểu cấu trúc của hoán vị$T$trên$64$tiểu bang.

# Bước 1 - Giải thích biểu đồ điều kiện về mặt lý thuyết 

Xác định đồ thị có hướng trên 64 trạng thái bằng cách$$x\to T(x).$$Từ$T$là khả nghịch (nó là một phép biến đổi kiểu thanh ghi dịch chuyển phản hồi tuyến tính), mọi nút đều có mức độ$1$và bằng cấp cao hơn$1$. Do đó đồ thị phân hủy thành các chu trình có hướng rời rạc. 

Đối với mỗi cạnh$x\to T(x)$, điều kiện nói:$$(\tau(x),\tau(T(x)))\neq (1,1).$$Vì vậy ở mỗi chu kỳ, chúng ta phải gán$0/1$nhãn sao cho không có đỉnh liền kề nào cùng$1$. 

Như vậy: 

- mỗi chu kỳ đóng góp độc lập, 
- và cho một chu kỳ dài$n$, số phép gán hợp lệ là số chuỗi nhị phân tròn có độ dài$n$không có liền kề$1$'S. 

Đại lượng đó đã được biết rõ:$$N(n)=F_{n-1}+F_{n+1},$$Ở đâu$F_n$là các số Fibonacci. 

(Tương đương, đây là số Lucas$L_n$.) 

Vì vậy, vấn đề giảm xuống: 

1. Tìm phân tích chu trình của$T$, 
2. Nhân các số Lucas tương ứng.

# Bước 2 - Phân tích sự chuyển đổi 

Bản đồ là$$(a,b,c,d,e,f)\mapsto (b,c,d,e,f,a\oplus (b\land c)).$$Bây giờ chúng tôi xác định cấu trúc chu trình trên 64 trạng thái. 

Một tính toán trực tiếp (hiển thị bên dưới trong mã) cho: 

- độ dài một chu kỳ$1$, 
- độ dài một chu kỳ$2$, 
- độ dài một chu kỳ$3$, 
- hai chu kỳ dài$6$, 
- độ dài một chu kỳ$46$. 

Kiểm tra:$$1+2+3+6+6+46=64.$$Do đó tổng số bảng chân lý hợp lệ là$$L_1L_2L_3L_6^2L_{46}.$$Sử dụng số Lucas:$$L_1=1,\quad L_2=3,\quad L_3=4,\quad L_6=18.$$Cũng,$$L_{46}=4106118243.$$Kể từ đây$$1\cdot 3\cdot 4\cdot 18^2\cdot 4106118243.$$Tính toán:$$3\cdot 4=12,$$

$$18^2=324,$$

$$12\cdot 324=3888,$$

$$3888\cdot 4106118243=15964587728784.$$--- 

# Bước 3 - Tại sao công thức tính chu kỳ lại đúng 

Đối với một chu kỳ có độ dài$n$, đặt nhãn nhị phân là$$x_1,x_2,\dots,x_n,$$với các chỉ số modulo tuần hoàn$n$. 

Hạn chế là$$x_i x_{i+1}=0.$$Số chuỗi nhị phân tuần hoàn tránh liên tiếp$1$bằng nhau$$F_{n-1}+F_{n+1}.$$Một dẫn xuất nhanh chóng: 

- chuỗi tuyến tính có độ dài$m$không có liền kề$1$được tính bằng$F_{m+2}$, 
- đối với chuỗi tuần hoàn: 

- bit đầu tiên là$0$:$F_{n+1}$, 
- hoặc bit đầu tiên là$1$: hàng xóm ép buộc$0$, rời đi$F_{n-1}$, 
- cho đi$$F_{n+1}+F_{n-1}.$$--- 

# Bước 4 - Triển khai Python```python
from collections import defaultdict

# ---------------------------------------------------------
# Transformation T on 6-bit states
# ---------------------------------------------------------

def T(x):
    """
    x is an integer from 0..63 representing bits abcdef.
    Returns T(x).
    """

    # Extract bits
    a = (x >> 5) & 1
    b = (x >> 4) & 1
    c = (x >> 3) & 1
    d = (x >> 2) & 1
    e = (x >> 1) & 1
    f = x & 1

    # New last bit
    g = a ^ (b & c)

    # Shift left
    y = (b << 5) | (c << 4) | (d << 3) | (e << 2) | (f << 1) | g

    return y

# ---------------------------------------------------------
# Find cycle decomposition
# ---------------------------------------------------------

visited = [False] * 64
cycle_lengths = []

for start in range(64):

    if visited[start]:
        continue

    cur = start
    cycle = []

    while not visited[cur]:
        visited[cur] = True
        cycle.append(cur)
        cur = T(cur)

    cycle_lengths.append(len(cycle))

print(sorted(cycle_lengths))

# ---------------------------------------------------------
# Fibonacci / Lucas
# ---------------------------------------------------------

def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

def lucas(n):
    return fibonacci(n - 1) + fibonacci(n + 1)

# ---------------------------------------------------------
# Compute total count
# ---------------------------------------------------------

answer = 1

for n in cycle_lengths:
    answer *= lucas(n)

print(answer)
```---
