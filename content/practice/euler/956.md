[Vấn đề dự án Euler 956](https://projecteuler.net/problem=956) 

##Giải pháp 

**Trả lời:**`882086212`Cho phép$$F(n,m)=D(n,m)=\sum_{\substack{d\mid n\\ m\mid \Omega(d)}} d.$$Vì$$n=\prod p_i^{e_i},$$hàm tạo$$\prod_i (1+p_i x+p_i^2x^2+\cdots+p_i^{e_i}x^{e_i})$$có hệ số$x^k$bằng tổng các ước$d\mid n$với$\Omega(d)=k$. 

Kể từ đây$D(n,m)$là tổng các hệ số có chỉ số chia hết cho$m$. 

Sử dụng bộ lọc gốc của sự thống nhất,$$D(n,m)=\frac1m\sum_{j=0}^{m-1} \prod_i\left(\sum_{k=0}^{e_i}(p_i\omega^j)^k\right),$$Ở đâu$\omega$là nguyên thủy$m$- căn bậc 1 của modulo đơn vị$999999001$. 

--- 

Đối với siêu nhân:$$n\bigstar=\prod_{t=1}^n t^{\binom{n-t+2}{2}},$$vậy số mũ của số nguyên tố$p$là$$e_p=\sum_{a\ge1}\sum_{\substack{t\le n\\ p^a\mid t}} \binom{n-t+2}{2}.$$Vì$n=1000$, chúng tôi tính toán tất cả$e_p$, sau đó đánh giá công thức nghiệm đơn vị theo modulo$$999999001.$$Triển khai Python:```python
from sympy import primerange, primitive_root

MOD = 999_999_001
m = 1000
n = 1000

# prime exponents in n★
E = {}
for p in primerange(1, n + 1):
    e = 0
    pk = p
    while pk <= n:
        for t in range(pk, n + 1, pk):
            e += (n - t + 1) * (n - t + 2) // 2
        pk *= p
    E[p] = e

g = primitive_root(MOD)
w = pow(g, (MOD - 1) // m, MOD)
inv_m = pow(m, MOD - 2, MOD)

ans = 0

for j in range(m):
    omega = pow(w, j, MOD)
    prod = 1

    for p, e in E.items():
        r = p * omega % MOD

        if r == 1:
            s = e + 1
        else:
            s = (pow(r, e + 1, MOD) - 1) * pow(r - 1, MOD - 2, MOD)

        prod = (prod * s) % MOD

    ans = (ans + prod) % MOD

ans = (ans * inv_m) % MOD
print(ans)
```Điều này đánh giá để:
