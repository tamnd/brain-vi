[Bài toán Euler dự án 86](https://projecteuler.net/problem=86) 

##Giải pháp 

**Trả lời:**`1818`Cho hình lập phương có độ dài các cạnh nguyên$$a \le b \le c.$$Chúng ta muốn đường đi ngắn nhất dọc theo các bề mặt từ góc này đến góc đối diện có độ dài nguyên. 

Quan sát quan trọng là khi chúng ta mở hình hộp chữ nhật ra, ba đường đi ngắn nhất có thể là:$$\sqrt{(a+b)^2+c^2},\qquad \sqrt{(a+c)^2+b^2},\qquad \sqrt{(b+c)^2+a^2}.$$Từ$a \le b \le c$, chúng tôi có$$a+b \le a+c \le b+c,$$vì vậy ứng cử viên thấp nhất luôn là$$\sqrt{(a+b)^2+c^2}.$$Vì vậy, chúng ta cần nghiệm số nguyên của$$(a+b)^2 + c^2 = k^2$$đối với một số nguyên$k$. 

--- 

# 1. Phân tích toán học 

Xác định$$s = a+b.$$Sau đó chúng ta tìm bộ ba Pythagore$$s^2 + c^2 = k^2,$$với những hạn chế$$1 \le a \le b \le c.$$Đối với chiều dài cạnh tối đa cố định$M$, chúng ta đếm tất cả các hình khối với$$c \le M.$$Vì vậy đối với mỗi$c$, chúng tôi đếm tất cả các giá trị$s$như vậy$$s^2 + c^2$$là một hình vuông hoàn hảo 

Rồi đếm xem có bao nhiêu cặp$(a,b)$thỏa mãn$$a+b=s,\qquad 1\le a\le b\le c.$$--- 

## Đếm$(a,b)$cặp 

Để cố định$s$Và$c$:$$a+b=s,\qquad a\le b,\qquad b\le c.$$Bởi vì$b=s-a$,$$a \le s-a \quad\Rightarrow\quad a \le \frac{s}{2}.$$Cũng,$$s-a \le c \quad\Rightarrow\quad a \ge s-c.$$Kể từ đây$$\max(1,s-c)\le a \le \left\lfloor \frac{s}{2}\right\rfloor.$$Vậy số cặp hợp lệ là$$\left\lfloor \frac{s}{2}\right\rfloor-\max(1,s-c)+1.$$Điều này đơn giản hóa thành dạng thu gọn tiêu chuẩn: 

- Nếu$s\le c$:$$\#=\left\lfloor \frac{s}{2}\right\rfloor.$$- Nếu như$s>c$:$$\#=\left\lfloor \frac{s}{2}\right\rfloor-(s-c)+1.$$--- 

# 2. Thuật toán hiệu quả 

Chúng tôi tăng$M=c$từng cái một. 

Đối với mỗi cái mới$c$: 

1. Lặp lại$$s=2,3,\dots,2c$$bởi vì$a,b\le c$. 
2. Kiểm tra xem$$s^2+c^2$$là một hình vuông hoàn hảo 
3. Nếu có, hãy thêm số hợp lệ$(a,b)$cặp. 

Dừng khi tổng tích lũy vượt quá$1,000,000$. 

Độ phức tạp đại khái là$$O(M^2),$$thế là đủ nhanh vì câu trả lời chỉ xoay quanh$1800$. 

--- 

#3. Triển khai Python```python
from math import isqrt

TARGET = 1_000_000

count = 0
M = 0

while count <= TARGET:
    M += 1

    # s = a + b
    for s in range(2, 2 * M + 1):

        # Check whether s^2 + M^2 is a perfect square
        n = s * s + M * M
        r = isqrt(n)

        if r * r == n:

            # Count valid (a,b) pairs
            if s <= M:
                count += s // 2
            else:
                count += (s // 2) - (s - M) + 1

print(M)
```---

```Điều này kiểm tra xem$$s^2 + M^2$$là một hình vuông hoàn hảo

## Đếm các phân tách hợp lệ 

### Trường hợp 1:$s \le M$

```python
count += s // 2
```Ví dụ:$$s=6$$Các cặp hợp lệ:$$(1,5),(2,4),(3,3)$$Chính xác$6//2=3$. 

--- 

### Trường hợp 2:$s > M$

```python
count += (s // 2) - (s - M) + 1
```Điều này thực thi$b \le M$. 

Ví dụ:$$M=5,\quad s=8$$Các cặp có thể có:$$(3,5),(4,4)$$Đếm$=2$. 

Công thức cho:$$8//2-(8-5)+1 =4-3+1 =2.$$---
