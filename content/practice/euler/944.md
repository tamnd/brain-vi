[Vấn đề dự án Euler 944](https://projecteuler.net/problem=944) 

## Giải pháp 

**Trả lời:**`1228599511`Cho phép$E \subseteq \{1,2,\dots,n\}$. Một phần tử$x\in E$góp phần vào$\operatorname{sev}(E)$nếu **một phần tử** khác của$E$chia hết cho$x$. 

Để cố định$x$, cho phép$$m=\left\lfloor \frac{n}{x}\right\rfloor$$vậy có$m-1$bội số khác của$x$TRONG$\{1,\dots,n\}$. 

Số lượng tập hợp con$E$Ở đâu$x$là một chiếc thang máy là: 

- bao gồm$x$, 
- bao gồm ít nhất một trong các$m-1$bội số khác, 
- tất cả các phần tử còn lại tùy ý. 

Kể từ đây:$$N_x = 2^{\,n-m}\left(2^{m-1}-1\right) = 2^{n-1}-2^{n-m}$$Vì thế$$S(n) = \sum_{x=1}^{n} x\left(2^{n-1}-2^{n-\lfloor n/x\rfloor}\right)$$Sắp xếp lại cho phép tính tổng nhanh hơn nhiều:$$S(n) = \sum_{d=2}^{n} 2^{n-d}\cdot \frac{\lfloor n/d\rfloor(\lfloor n/d\rfloor+1)}{2}$$Điều này có thể được đánh giá ở$O(\sqrt n)$sử dụng thủ thuật khoảng cách chia tầng tiêu chuẩn: 

giá trị của$\lfloor n/d\rfloor$là hằng số trong các khoảng. 

Triển khai Python sạch:```python
import math

MOD = 1234567891
INV2 = (MOD + 1) // 2

def solve(n):
    D = math.isqrt(n)
    res = 0

    # Small d: direct
    p = pow(2, (n - 2) % (MOD - 1), MOD)

    for d in range(2, D + 1):
        q = n // d
        tri = (q * (q + 1) // 2) % MOD
        res += p * tri
        p = (p * INV2) % MOD

    res %= MOD

    # Large d grouped by equal floor(n/d)
    cache = {1: INV2}

    cur = D + 1
    pcur = pow(2, (n - cur) % (MOD - 1), MOD)

    for q in range(D - 1, 0, -1):
        R = n // q
        if R < cur:
            continue

        length = R - cur + 1

        if length not in cache:
            cache[length] = pow(INV2, length, MOD)

        ip = cache[length]

        tri = (q * (q + 1) // 2) % MOD
        interval_sum = (2 * pcur * (1 - ip)) % MOD

        res += interval_sum * tri
        pcur = (pcur * ip) % MOD
        cur = R + 1

    return res % MOD

print(solve(10**14))
```Kiểm tra mẫu:$$S(10)=4927$$phù hợp với tuyên bố vấn đề.
