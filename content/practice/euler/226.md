[Vấn đề dự án Euler 226](https://projecteuler.net/problem=226) 

## Giải pháp 

**Trả lời:**`0.11316017`Cho phép$$B(x)=\sum_{n=0}^{\infty}\frac{s(2^n x)}{2^n}, \qquad s(x)=\text{distance from }x\text{ to the nearest integer}.$$Đây là **hàm blancmange** (hoặc hàm Takagi). 

Chúng tôi tìm kiếm khu vực được bao quanh đồng thời: 

- dưới đường cong blancmange$y=B(x)$, 
- và bên trong vòng tròn$$\left(x-\frac14\right)^2+\left(y-\frac12\right)^2=\left(\frac14\right)^2.$$Vùng được yêu cầu là “cái muỗng” nhỏ được giới hạn bởi hình bán nguyệt phía dưới và đường cong blancmange. 

--- 

# 1. Phân tích toán học 

## Bước 1 - Phương trình đường tròn 

Nửa dưới của hình tròn là$$y_c(x)=\frac12-\sqrt{\frac1{16}-\left(x-\frac14\right)^2}.$$Chúng ta cần điểm giao nhau$x_0$thỏa mãn$$B(x_0)=y_c(x_0).$$Bằng tính đối xứng của đường cong blancmange,$$B(x)=B(1-x),$$và vùng kèm theo có liên quan chạy từ$x_0$ĐẾN$1/2$. 

Do đó diện tích mong muốn là$$A=\int_{x_0}^{1/2}\left(B(x)-y_c(x)\right)\,dx.$$--- 

## Bước 2 - Đánh giá hiệu quả$B(x)$Định nghĩa hội tụ rất nhanh vì mỗi số hạng được chia cho$2^n$. 

Đối với tính toán số:$$B(x)\approx \sum_{n=0}^{N-1}\frac{s(2^n x)}{2^n},$$với$N=50$đã cho độ chính xác cực cao. 

Đối với bất kỳ thực tế$t$,$$s(t)=|t-\operatorname{round}(t)|.$$--- 

## Bước 3 - Tìm giao điểm 

Xác định$$f(x)=B(x)-y_c(x).$$Sử dụng phép chia trong khoảng$(0,0.5)$, chúng tôi có được$$x_0 \approx 0.07890778796534.$$--- 

## Bước 4 - Tích hợp số 

Chúng tôi tính toán$$A=\int_{x_0}^{1/2}(B(x)-y_c(x))\,dx$$sử dụng quy tắc Simpson với phép chia nhỏ. 

Giá trị số hội tụ đến$$A \approx 0.11316016345\ldots$$làm tròn đến tám chữ số thập phân là$$0.11316017.$$--- 

#2. Triển khai Python```python
from math import sqrt

# Distance to nearest integer
def s(x):
    return abs(x - round(x))

# Blancmange function
def B(x, terms=60):
    total = 0.0
    scale = 1.0

    for n in range(terms):
        total += s(scale * x) / scale
        scale *= 2.0

    return total

# Lower semicircle
def circle_lower(x):
    return 0.5 - sqrt(0.0625 - (x - 0.25) ** 2)

# Difference between curves
def f(x):
    return B(x) - circle_lower(x)

# Bisection to find intersection point
a, b = 0.0, 0.5

for _ in range(100):
    m = (a + b) / 2

    if f(m) > 0:
        b = m
    else:
        a = m

x0 = (a + b) / 2

# Simpson integration
def simpson(g, a, b, n=20000):
    if n % 2 == 1:
        n += 1

    h = (b - a) / n
    total = g(a) + g(b)

    for i in range(1, n):
        coeff = 4 if i % 2 == 1 else 2
        total += coeff * g(a + i * h)

    return total * h / 3

area = simpson(
    lambda x: B(x) - circle_lower(x),
    x0,
    0.5,
    20000
)

print(f"{area:.8f}")
```---
