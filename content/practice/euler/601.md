##Giải pháp 

**Trả lời:**`1617243`Cho phép$$\operatorname{streak}(n)=k$$có nghĩa là: 

- cho mọi$1\le j\le k$,$$n+j-1 \text{ is divisible by } j,$$- Nhưng$$n+k \text{ is NOT divisible by } k+1.$$Tương đương:$$\begin{aligned} n+1 &\equiv 0 \pmod 2\\ n+2 &\equiv 0 \pmod 3\\ &\vdots\\ n+(k-1) &\equiv 0 \pmod k \end{aligned}$$Mỗi sự đồng đẳng trở thành$$n \equiv 1 \pmod j.$$Vì vậy đối với tất cả$2\le j\le k$,$$n\equiv 1 \pmod j.$$Vì thế:$$n\equiv 1 \pmod{\operatorname{lcm}(1,2,\dots,k)}.$$Định nghĩa$$L_k=\operatorname{lcm}(1,2,\dots,k).$$Sau đó:

-$\operatorname{streak}(n)\ge k$nếu$$n\equiv 1 \pmod{L_k}.$$Để có **chính xác** vệt$k$, chúng tôi cũng yêu cầu thất bại ở bước$k+1$, tức là$$n\not\equiv 1 \pmod{L_{k+1}}.$$Kể từ đây$$P(k,N) = \left\lfloor \frac{N-1}{L_k}\right\rfloor - \left\lfloor \frac{N-1}{L_{k+1}}\right\rfloor.$$--- 

Kiểm tra ví dụ$P(3,14)$:$$L_3=\operatorname{lcm}(1,2,3)=6,\qquad L_4=12.$$Vì thế$$P(3,14) = \left\lfloor\frac{13}{6}\right\rfloor - \left\lfloor\frac{13}{12}\right\rfloor = 2-1=1.$$Chính xác. 

--- 

Bây giờ tính toán$$\sum_{i=1}^{31} P(i,4^i).$$#Triển khai Python```python
from math import gcd

def lcm(a, b):
    return a * b // gcd(a, b)

total = 0
L = 1  # L_i = lcm(1..i)

for i in range(1, 32):
    # Compute L_i
    L = lcm(L, i)

    # Compute L_{i+1}
    L_next = lcm(L, i + 1)

    N = 4 ** i

    # P(i, N)
    p = (N - 1) // L - (N - 1) // L_next

    total += p

print(total)
```--- 

# Hướng dẫn sử dụng mã 

###`lcm(a, b)`Tính bội số chung nhỏ nhất bằng cách sử dụng$$\operatorname{lcm}(a,b)=\frac{ab}{\gcd(a,b)}.$$--- 

###`L = 1`Cửa hàng$$L_i=\operatorname{lcm}(1,2,\dots,i).$$Chúng tôi cập nhật nó dần dần. 

--- 

### Lặp lại`i = 1..31`Đối với mỗi$i$: 

1. Tính toán$L_i$. 
2. Tính toán$L_{i+1}$. 
3. Đặt$N=4^i$. 
4. Sử dụng công thức$$P(i,N) = \left\lfloor \frac{N-1}{L_i}\right\rfloor - \left\lfloor \frac{N-1}{L_{i+1}}\right\rfloor.$$1. Thêm vào tổng số đang chạy.
