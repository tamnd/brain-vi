[Vấn đề dự án Euler 455](https://projecteuler.net/problem=455) 

## Giải pháp 

**Trả lời:**`450186511399999`Chúng tôi tìm kiếm chức năng$$f(n)=\max\{x<10^9 : n^x \equiv x \pmod{10^9}\},$$với$f(n)=0$nếu không như vậy$x$tồn tại. 

Chúng ta phải tính toán$$\sum_{n=2}^{10^6} f(n).$$--- 

# 1. Phân tích toán học 

Chúng tôi đang giải quyết sự phù hợp$$n^x \equiv x \pmod{10^9}.$$Từ$10^9 = 2^9 5^9$, đây là bài toán điểm cố định theo mô đun tổng hợp. 

Điều quan trọng nhất là bản đồ$$T(x)=n^x \pmod{10^9}$$hội tụ rất nhanh đến một điểm cố định khi lặp. 

--- 

## Lặp lại điểm cố định 

Giả sử chúng ta định nghĩa$$x_{k+1}=n^{x_k}\pmod{10^9}, \qquad x_0=1.$$Theo kinh nghiệm (và có thể giải thích thông qua$2$-adic và$5$-adic nâng), trình tự này ổn định cực kỳ nhanh chóng:$$x_{k+1}=x_k.$$Sau khi ổn định, chúng ta có$$x=n^x \pmod{10^9},$$Vì thế$x$chính xác là một giải pháp hợp lệ. 

Hơn nữa, đối với mô đun này, phép lặp hội tụ đến điểm cố định _lớn nhất_ bên dưới$10^9$. 

--- 

## Tại sao số chia hết cho 10 lại bằng 0 

Nếu$10\mid n$, thì với số mũ đủ lớn,$$n^x \equiv 0 \pmod{2^9} \quad\text{and}\quad n^x \equiv 0 \pmod{5^9}.$$Kể từ đây$$n^x \equiv 0 \pmod{10^9}.$$Một điểm cố định sẽ yêu cầu$$x\equiv 0 \pmod{10^9},$$Nhưng$0\le x<10^9$, vậy khả năng duy nhất là$x=0$, bị loại trừ vì bài toán yêu cầu số nguyên dương. Vì thế:$$f(n)=0 \qquad (10\mid n).$$--- 

## Xác minh trên các ví dụ 

### Ví dụ 1:$n=4$Lặp lại:$$1 \to 4 \to 256 \to 719156736 \to \cdots \to 411728896.$$Sau cùng:$$4^{411728896}\equiv 411728896 \pmod{10^9}.$$Như vậy$$f(4)=411728896.$$--- 

### Ví dụ 2:$n=157$Phép lặp hội tụ đến$$743757,$$và thực sự$$157^{743757}\equiv 743757 \pmod{10^9}.$$Vì thế$$f(157)=743757.$$--- 

#2. Triển khai Python```python
MOD = 10**9

def f(n):
    """
    Compute the largest x < 10^9 such that
        n^x ≡ x (mod 10^9)
    using fixed-point iteration.
    """

    # Numbers divisible by 10 have no positive solution
    if n % 10 == 0:
        return 0

    x = 1

    while True:
        nx = pow(n, x, MOD)

        if nx == x:
            return x

        x = nx

def solve(limit=10**6):
    total = 0

    for n in range(2, limit + 1):
        total += f(n)

    return total

# Verification against the example in the statement
check = sum(f(n) for n in range(2, 1001))
print(check)   # 442530011399

# Final answer
print(solve())
```---

```Nếu như$n$chia hết cho$10$, không tồn tại điểm cố định dương.

```Bắt đầu từ$x_0=1$. 

Sau đó áp dụng nhiều lần```python

```tính toán nào$$n^x \bmod 10^9$$sử dụng hiệu quả phép lũy thừa mô-đun.

```Khi vòng lặp ngừng thay đổi, chúng ta đã tìm được điểm cố định:$$x=n^x \pmod{10^9}.$$---
