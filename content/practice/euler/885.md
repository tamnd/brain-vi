[Vấn đề dự án Euler 885](https://projecteuler.net/problem=885) 

## Giải pháp 

**Trả lời:**`827850196`Cho các chữ số khác 0 của một số$d$là$$1^{c_1}2^{c_2}\cdots 9^{c_9},$$Ở đâu$c_i\ge 0$, và để$$k=c_1+\cdots+c_9$$là số các chữ số khác 0. 

Sau đó$$f(d)=\underbrace{11\ldots1}_{c_1} \underbrace{22\ldots2}_{c_2} \cdots \underbrace{99\ldots9}_{c_9},$$tức là các chữ số được sắp xếp ngày càng nhiều và loại bỏ tất cả các số 0. 

Chúng ta phải tính toán$$S(18)=\sum_{\substack{d\ge1\\ \text{at most 18 digits}}} f(d) \pmod{1123455689}.$$--- 

# 1. Phân tích toán học 

## Bước 1 - Sửa các chữ số khác 0 

Giả sử nhiều tập hợp các chữ số khác 0 được cố định:$$(c_1,c_2,\dots,c_9).$$Sau đó giá trị của$f(d)$đã được sửa. 

Sự tự do duy nhất còn lại là: 

- có bao nhiêu số 0, 
- cách sắp xếp tất cả các chữ số. 

Cho số đó chứa$c_0$số không, vì vậy tổng chiều dài là$$n=k+c_0.$$Vì chúng ta chỉ xét số nguyên dương nên chữ số đứng đầu không thể bằng 0. 

--- 

## Bước 2 - Đếm số hợp lệ 

Tổng số hoán vị của multiset là$$\frac{n!}{c_0!c_1!\cdots c_9!}.$$Trong đó, phân số có chữ số đầu tiên khác 0 là$$\frac{k}{n},$$bởi vì chính xác$k$của$n$vị trí chứa các chữ số khác 0. 

Do đó số lượng hợp lệ$n$số nguyên -chữ số là$$\frac{k}{n}\cdot \frac{n!}{c_0!c_1!\cdots c_9!} = \frac{k(n-1)!}{c_0!c_1!\cdots c_9!}.$$Bây giờ viết lại:$$\frac{k(n-1)!}{c_0!} = \frac{k!}{1}\binom{n-1}{c_0}.$$Thực vậy,$$k\frac{(k+c_0-1)!}{c_0!} = k!\binom{k+c_0-1}{c_0}.$$Do đó số đếm trở thành$$\frac{k!}{c_1!\cdots c_9!} \binom{k+c_0-1}{c_0}.$$--- 

## Bước 3 - Tính tổng tất cả số 0 có thể có 

Đối với số lượng cố định khác 0$(c_1,\dots,c_9)$, số 0 có thể là$$0\le c_0\le 18-k.$$Do đó tổng bội số là$$\frac{k!}{c_1!\cdots c_9!} \sum_{c_0=0}^{18-k} \binom{k+c_0-1}{c_0}.$$Sử dụng danh tính gậy khúc côn cầu,$$\sum_{t=0}^{m}\binom{k+t-1}{t} = \binom{k+m}{m}.$$Với$m=18-k$,$$\sum_{c_0=0}^{18-k} \binom{k+c_0-1}{c_0} = \binom{18}{k}.$$Vì vậy mỗi multiset đều đóng góp$$f \cdot \frac{k!}{c_1!\cdots c_9!} \binom{18}{k}.$$Kể từ đây$$S(18) = \sum_{k=1}^{18} \binom{18}{k} \sum_{c_1+\cdots+c_9=k} f(c_1,\dots,c_9) \frac{k!}{c_1!\cdots c_9!}.$$Điều này bây giờ là hữu hạn và nhỏ. 

Số lượng 9 bộ với tổng số$k\le18$là$$\binom{18+9}{9}\approx 4.7\times10^4,$$cái đó nhỏ xíu

#2. Triển khai Python```python
from math import factorial, comb

MOD = 1123455689
N = 18

# Precompute factorials
fact = [factorial(i) for i in range(N + 1)]

answer = 0

def dfs(digit, remaining, counts):
    """
    Recursively generate all count vectors:
        c1 + c2 + ... + c9 <= N
    """
    global answer

    if digit == 10:
        k = sum(counts)

        # Ignore the empty multiset
        if k == 0:
            return

        # Build f(d):
        # digits sorted increasingly with repetitions
        s = []
        for d, c in enumerate(counts, start=1):
            s.extend(str(d) * c)

        f_value = int("".join(s))

        # multinomial factor = k! / (c1! c2! ... c9!)
        mult = fact[k]
        for c in counts:
            mult //= fact[c]

        # Contribution
        contribution = f_value * mult * comb(N, k)

        answer += contribution
        return

    # Choose count for current digit
    for c in range(remaining + 1):
        dfs(digit + 1, remaining - c, counts + [c])

dfs(1, N, [])

print(answer % MOD)
```---
