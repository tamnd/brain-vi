[Vấn đề dự án Euler 21](https://projecteuler.net/problem=21) 

## Giải pháp 

**Trả lời:**`31626`Chúng tôi cần tất cả các số thân thiện bên dưới$10000$. 

Định nghĩa$d(n)$bằng tổng các ước thực sự của$n$. 

Hai số$a,b$tạo thành một cặp thân thiện nếu:$$d(a)=b,\qquad d(b)=a,\qquad a\ne b$$Ví dụ:$$d(220)=284,\qquad d(284)=220$$Vì vậy, cả 220 và 284 đều được bao gồm. 

Cách tiếp cận trực tiếp: 

1. Tính toán$d(n)$cho mọi$n<10000$. 
2. Đối với mỗi$a$:

- cho phép$b=d(a)$- nếu như$b\neq a$Và$d(b)=a$, sau đó$a$là thân thiện. 
3. Tính tổng tất cả như vậy$a$. 

Phép tính tổng số chia hiệu quả có thể được thực hiện bằng cách lặp lại các số chia lên đến$\sqrt n$. 

Mã Python:```python
def divisor_sum(n):
    if n == 1:
        return 0

    total = 1
    p = 2

    while p * p <= n:
        if n % p == 0:
            total += p
            q = n // p
            if q != p:
                total += q
        p += 1

    return total

LIMIT = 10000

d = [0] * LIMIT
for i in range(1, LIMIT):
    d[i] = divisor_sum(i)

answer = 0

for a in range(1, LIMIT):
    b = d[a]

    if b != a and b > 0:
        if b < LIMIT:
            if d[b] == a:
                answer += a
        else:
            if divisor_sum(b) == a:
                answer += a

print(answer)
```Được biết đến là cặp đôi thân thiện dưới$10000$:$$(220,284),\ (1184,1210),\ (2620,2924),\ (5020,5564),\ (6232,6368)$$Tổng hợp tất cả các số:$$220+284+1184+1210+2620+2924+5020+5564+6232+6368 = 31626$$**Đáp án: 31626**
