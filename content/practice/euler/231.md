##Giải pháp 

**Trả lời:**`7526965179680`Chúng tôi muốn tổng của các thừa số nguyên tố (có bội số) của$$\binom{20\,000\,000}{15\,000\,000}.$$Tương đương, nếu$$\binom{n}{k}=\prod_p p^{e_p},$$chúng tôi tìm kiếm$$\sum_p p\,e_p.$$Đối với ví dụ nhỏ,$$\binom{10}{3}=120=2^3\cdot3\cdot5,$$vậy số tiền cần tìm là$$2\cdot3+3\cdot1+5\cdot1=14.$$--- 

# 1. Phân tích toán học 

Ý tưởng chính là tính số mũ của mỗi số nguyên tố trong giai thừa bằng công thức Legendre. 

Đối với một số nguyên tố$p$,$$v_p(n!)=\sum_{i\ge1}\left\lfloor \frac{n}{p^i}\right\rfloor.$$Vì thế,$$v_p\!\left(\binom{n}{k}\right) = v_p(n!) - v_p(k!) - v_p((n-k)!).$$Đối với vấn đề này:$$n=20\,000\,000,\qquad k=15\,000\,000,\qquad n-k=5\,000\,000.$$Kể từ đây$$e_p = \sum_{i\ge1} \left( \left\lfloor \frac{20\,000\,000}{p^i}\right\rfloor - \left\lfloor \frac{15\,000\,000}{p^i}\right\rfloor - \left\lfloor \frac{5\,000\,000}{p^i}\right\rfloor \right).$$Câu trả lời mong muốn là$$\sum_{p\le 20\,000\,000} p\,e_p.$$Vì vậy, thuật toán là: 

1. Tạo tất cả các số nguyên tố lên đến$20\,000\,000$dùng sàng. 
2. Đối với mỗi số nguyên tố$p$: 

- Tính toán$e_p$với công thức Legendre. 
- Thêm vào$p\cdot e_p$đến tổng số. 

Điều này hiệu quả vì: 

- chỉ có khoảng$1.27$triệu số nguyên tố lên đến$20$triệu, 
- và mỗi số nguyên tố chỉ đóng góp$O(\log_p n)$điều khoản.

#2. Triển khai Python```python
from math import isqrt

N = 20_000_000
K = 15_000_000

# ---------------------------------------------------------
# Sieve of Eratosthenes
# ---------------------------------------------------------
# Generate all primes <= N
sieve = bytearray(b"\x01") * (N + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(N) + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:N + 1:step] = b"\x00" * (((N - start) // step) + 1)

primes = [i for i in range(2, N + 1) if sieve[i]]

# ---------------------------------------------------------
# Legendre exponent for p in n!
# ---------------------------------------------------------
def vp_factorial(n, p):
    total = 0
    while n:
        n //= p
        total += n
    return total

# ---------------------------------------------------------
# Compute the required sum
# ---------------------------------------------------------
answer = 0

for p in primes:
    exponent = (
        vp_factorial(N, p)
        - vp_factorial(K, p)
        - vp_factorial(N - K, p)
    )

    answer += p * exponent

print(answer)
```---

# 4. Xác minh ví dụ nhỏ 

lấy$$\binom{10}{3}=120.$$Số mũ nguyên tố: 

-$v_2(10!)=5+2+1=8$-$v_2(3!)=1$-$v_2(7!)=3+1=4$Vậy số mũ của 2 là$$8-1-4=3.$$Tương tự: 

- số mũ của 3 là$1$, 
- số mũ của 5 là$1$. 

Như vậy$$2\cdot3 + 3\cdot1 + 5\cdot1 = 6+3+5 = 14,$$phù hợp với tuyên bố.
