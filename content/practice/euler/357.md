[Vấn đề dự án Euler 357](https://projecteuler.net/problem=357) 

## Giải pháp 

**Trả lời:**`1739023853137`Chúng tôi tìm kiếm tất cả các số nguyên dương$n \le 10^8$như vậy$$d + \frac{n}{d}$$là số nguyên tố với **mọi ước số**$d$của$n$. 

Chúng ta phải tính toán$$\sum n.$$## 1. Phân tích toán học 

Chúng ta hãy rút ra những ràng buộc mạnh mẽ. 

### Điều kiện chính 

Với mỗi ước số$d \mid n$,$$d + \frac{n}{d}$$phải là số nguyên tố. 

Vì các ước số có cặp bù nhau nên chúng ta chỉ cần kiểm tra các ước số tối đa$\sqrt n$. 

--- 

### Quan sát đầu tiên:$d = n$Lấy$d=n$,$$n + \frac{n}{n} = n+1$$phải là số nguyên tố. 

Vì thế:

-$n+1$là số nguyên tố, 
- do đó$n$thậm chí là dành cho tất cả$n>1$. 

--- 

### Quan sát thứ hai:$d=1$Lấy$d=1$,$$1+n$$cũng phải là số nguyên tố - cùng điều kiện. 

Như vậy mọi giá trị hợp lệ$n>1$thỏa mãn:$$n+1 \text{ is prime}.$$Đây đã là một mức giảm rất lớn. 

--- 

### Nhận xét thứ ba:$d=p$cho các ước số nguyên tố 

Giả sử$p\mid n$. 

Sau đó$$p + \frac{n}{p}$$phải là số nguyên tố. 

Bây giờ hãy xem xét khả năng rằng$p^2 \mid n$. 

Cho phép$$n = p^2m.$$Chọn số chia$$d = pm.$$Sau đó$$d+\frac{n}{d} = pm+p = p(m+1).$$Từ$n>1$, đây là hợp số trừ khi nó bằng$p$, không thể nào. 

Do đó: 

### Hậu quả quan trọng$$\boxed{n \text{ must be squarefree}}$$(ngoại trừ$n=1$). 

--- 

### Nhận xét thứ tư:$d = p$Nếu như$p\mid n$,$$p+\frac{n}{p}$$phải là số nguyên tố. 

Đặc biệt đối với$p=2$,$$2+\frac n2$$phải là số nguyên tố. 

Điều này trở thành một bộ lọc sớm rất hiệu quả. 

--- 

### Chiến lược 

Một thử nghiệm chia lực lượng vũ phu lên đến$10^8$là không thể. 

Chúng tôi khai thác các quan sát: 

1.$n+1$phải là số nguyên tố 

⇒ số ứng cử viên là$n=p-1$Ở đâu$p$là nguyên tố. 
2.$n$phải là hình vuông. 
3. Với mọi ước số$d$, 

kiểm tra xem$$d+\frac nd$$là nguyên tố. 

Từ$n$không có hình vuông và hầu như thưa thớt sau khi lọc, điều này trở nên khả thi. 

--- 

### Tra cứu nguyên tố hiệu quả 

Chúng tôi sàng lọc các số nguyên tố lên đến:$$10^8+1$$bởi vì giá trị lớn nhất được kiểm tra là$$d+\frac nd \le n+1.$$Một cái sàng boolean cho$O(1)$kiểm tra tính nguyên thủy. 

--- 

## 2. Triển khai Python```python
from math import isqrt

LIMIT = 100_000_000

def prime_sieve(n):
    """Boolean sieve: is_prime[x] tells whether x is prime."""
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[0:2] = b"\x00\x00"

    for p in range(2, isqrt(n) + 1):
        if sieve[p]:
            start = p * p
            sieve[start:n + 1:p] = b"\x00" * ((n - start) // p + 1)

    return sieve

# Build primality table up to LIMIT + 1
is_prime = prime_sieve(LIMIT + 1)

total = 0

# n = 1 works:
# divisors = {1}, and 1 + 1 = 2 is prime
total += 1

# Since n + 1 must be prime, candidates are p - 1
for p in range(3, LIMIT + 2, 2):
    if not is_prime[p]:
        continue

    n = p - 1

    # n must be squarefree and satisfy condition
    valid = True

    # Check every divisor d <= sqrt(n)
    root = isqrt(n)

    for d in range(2, root + 1):
        if n % d == 0:
            q = n // d

            # d + n/d must be prime
            if not is_prime[d + q]:
                valid = False
                break

            # squarefree test:
            if q % d == 0:
                valid = False
                break

    if valid:
        total += n

print(total)
```---
