##Giải pháp 

**Trả lời:**`278157919195482643`Cho phép$$K = 1234567890.$$Chúng tôi muốn cái nhỏ nhất$n$như vậy$$(i!)^K \mid n!.$$Đối với mỗi số nguyên tố$p\le i$, định nghĩa$v_p(m!)$như số mũ của$p$TRONG$m!$. 

Theo công thức Legendre,$$v_p(m!)=\sum_{t\ge1}\left\lfloor \frac{m}{p^t}\right\rfloor.$$Như vậy$n$phải thỏa mãn$$v_p(n!) \ge K\,v_p(i!) \qquad\text{for every prime }p\le i.$$Vì thế$$N(i)=\max_{p\le i} F_p\!\bigl(K\,v_p(i!)\bigr),$$Ở đâu$F_p(a)$là ít nhất$n$như vậy$v_p(n!)\ge a$. 

--- 

# Hiểu biết sâu sắc về toán học 

Sử dụng Legendre một lần nữa,$$v_p(n!)=\frac{n-s_p(n)}{p-1},$$Ở đâu$s_p(n)$là tổng của cơ sở-$p$chữ số của$n$. 

Kể từ đây$F_p(a)$là nhỏ nhất$n$thỏa mãn$$n-s_p(n)\ge (p-1)a.$$Từ$s_p(n)$là rất nhỏ so với$n$, chúng tôi nhận được$$F_p(a)=(p-1)a+O(\log a).$$Hiện nay$$(p-1)v_p(i!) = i-s_p(i),$$Vì thế$$F_p\!\bigl(Kv_p(i!)\bigr) = K(i-s_p(i,p))+O(\log i).$$Do đó, các số nguyên tố trội chính xác là các số cực tiểu hóa tổng các chữ số$s_p(i,p)$. 

Việc tính toán sau đó có thể được thực hiện một cách hiệu quả bằng cách: 

1. sàng các thừa số nguyên tố nhỏ nhất lên đến$10^6$, 
2. duy trì tất cả số mũ$v_p(i!)$tăng dần, 
3. chỉ cập nhật các số nguyên tố chia mới$i$, 
4. tính toán$F_p(a)$tìm kiếm nhị phân theo công thức Legendre. 

Độ phức tạp tổng thể đủ nhanh trong Python/PyPy được tối ưu hóa.

#Triển khai Python```python
from collections import defaultdict
from math import log

K = 1234567890
MOD = 10**18
U = 10**6

# ------------------------------------------------------------
# smallest prime factor sieve
# ------------------------------------------------------------

spf = list(range(U + 1))

for i in range(2, int(U**0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, U + 1, step):
            if spf[j] == j:
                spf[j] = i

# ------------------------------------------------------------
# Legendre valuation
# ------------------------------------------------------------

def vp_fact(n, p):
    s = 0
    while n:
        n //= p
        s += n
    return s

# ------------------------------------------------------------
# inverse Legendre:
# least n with vp_fact(n,p) >= target
# ------------------------------------------------------------

def inverse_legendre(p, target):
    lo = 0
    hi = (p - 1) * target + 1000

    while lo < hi:
        mid = (lo + hi) // 2
        if vp_fact(mid, p) >= target:
            hi = mid
        else:
            lo = mid + 1

    return lo

# ------------------------------------------------------------
# main accumulation
# ------------------------------------------------------------

exp_p = defaultdict(int)
need_p = defaultdict(int)

current_max = 0
answer = 0

for i in range(2, U + 1):

    x = i
    factors = defaultdict(int)

    while x > 1:
        p = spf[x]
        factors[p] += 1
        x //= p

    # update prime exponents in i!
    for p, e in factors.items():
        exp_p[p] += e

        target = K * exp_p[p]
        val = inverse_legendre(p, target)

        need_p[p] = val

        if val > current_max:
            current_max = val

    if i >= 10:
        # recompute if necessary
        if current_max not in need_p.values():
            current_max = max(need_p.values())

        answer = (answer + current_max) % MOD

print(answer)
```---
