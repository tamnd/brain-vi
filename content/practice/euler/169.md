## Giải pháp 

**Trả lời:**`178653872807`Chúng ta phải tính số biểu diễn của$$10^{25}$$như tổng sức mạnh của$2$, trong đó mỗi sức mạnh có thể được sử dụng nhiều nhất hai lần. 

Định nghĩa$$f(n)=\#\left\{n=\sum_{k\ge0} a_k2^k \;\middle|\; a_k\in\{0,1,2\}\right\}.$$Chúng tôi được yêu cầu$f(10^{25})$. 

--- 

# Phân tích toán học 

Vấn đề cơ bản là về ** mang nhị phân **. 

Giả định$$n=\sum_{k\ge0} b_k2^k$$là khai triển nhị phân thông thường của$n$, Ở đâu$b_k\in\{0,1\}$. 

Chúng tôi tìm kiếm số dãy chữ số$$a_k\in\{0,1,2\}$$như vậy$$\sum a_k2^k=n.$$Quan sát quan trọng là sự tương tác duy nhất giữa các bit liền kề đến từ các phần mang. 

--- 

## Lập trình động dựa trên thực hiện 

Xử lý các bit từ ít quan trọng nhất đến quan trọng nhất. 

Tại vị trí bit$k$: 

- bit mục tiêu là$b_k\in\{0,1\}$, 
- ta chọn hệ số$a_k\in\{0,1,2\}$, 
- chúng tôi cũng có thể được mang theo$c_k$từ bit trước đó. 

Chúng tôi yêu cầu$$a_k + c_k \equiv b_k \pmod 2.$$Lần mang tiếp theo là$$c_{k+1}=\frac{a_k+c_k-b_k}{2}.$$Bởi vì$a_k\le2$và mang luôn nhỏ bé, không gian trạng thái cực kỳ nhỏ. 

Như vậy chúng ta có thể tính toán$f(n)$với một chữ số DP. 

---

## Ví dụ:$f(10)$Nhị phân:$$10 = 1010_2.$$Chạy đệ quy mang lại chính xác 5 biểu diễn:$$\begin{aligned} 10 &= 8+2\\ &=8+1+1\\ &=4+4+2\\ &=4+4+1+1\\ &=4+2+2+1+1. \end{aligned}$$Vì thế$f(10)=5$, phù hợp với tuyên bố. 

--- 

#Triển khai Python```python
from functools import lru_cache

def f(n):
    # Binary digits of n
    bits = list(map(int, bin(n)[2:]))

    @lru_cache(None)
    def dp(pos, carry):
        """
        pos   : current bit position (from least significant upward)
        carry : incoming carry at this bit

        Returns the number of valid completions.
        """

        # All bits processed
        if pos == len(bits):
            return 1 if carry == 0 else 0

        # Current target bit of n
        bit = bits[-1 - pos]

        total = 0

        # Choose coefficient a_k in {0,1,2}
        for digit in (0, 1, 2):

            s = digit + carry

            # Parity must match the target bit
            if s % 2 == bit:

                # Compute next carry
                next_carry = (s - bit) // 2

                total += dp(pos + 1, next_carry)

        return total

    return dp(0, 0)

# Problem value
print(f(10**25))
```---
