##Giải pháp 

**Trả lời:**`18613426663617118`Cho các số nguyên tố liên tiếp là$p_1$Và$p_2$, với$p_2 > p_1$. 

Chúng tôi tìm kiếm số nguyên nhỏ nhất$S$như vậy: 

1.$S \equiv p_1 \pmod{10^d}$, Ở đâu$d$là số chữ số thập phân của$p_1$, 
2.$S \equiv 0 \pmod{p_2}$. 

Ví dụ, với$p_1=19$,$p_2=23$:$$1219 \equiv 19 \pmod{100}, \qquad 1219 \equiv 0 \pmod{23}.$$Chúng ta phải tính toán$$\sum S$$trên tất cả các cặp số nguyên tố liên tiếp với$$5 \le p_1 \le 10^6.$$--- 

# Phân tích toán học 

Giả sử$d$là số chữ số của$p_1$, và xác định$$m = 10^d.$$Bất kỳ số nào kết thúc bằng chữ số của$p_1$có thể được viết là$$S = m k + p_1$$đối với một số nguyên$k \ge 0$. 

Chúng tôi yêu cầu$S$được chia cho$p_2$:$$mk + p_1 \equiv 0 \pmod{p_2}.$$Như vậy,$$mk \equiv -p_1 \pmod{p_2}.$$Bởi vì$p_2$là số nguyên tố và$p_2 \ne 2,5$, chúng tôi có$$\gcd(m,p_2)=1,$$Vì thế$m$có modulo nghịch đảo mô-đun$p_2$. Vì thế,$$k \equiv -p_1 \cdot m^{-1} \pmod{p_2}.$$Nghiệm không âm nhỏ nhất là$$k = (-p_1)\,m^{-1} \bmod p_2.$$Sau đó$$S = mk + p_1.$$Vì vậy, toàn bộ vấn đề giảm xuống thành nghịch đảo mô-đun lặp đi lặp lại. 

--- 

## Tính nghịch đảo mô-đun 

Kể từ khi$p_2$là số nguyên tố,$$m^{-1} \equiv m^{p_2-2} \pmod{p_2}$$bởi Định lý nhỏ Fermat. 

Python cung cấp điều này trực tiếp:```python
pow(m, -1, p2)
```tính toán nghịch đảo mô-đun một cách hiệu quả. 

--- 

# Thuật toán 

1. Tạo tất cả các số nguyên tố cao hơn một chút$10^6$. 
2. Đối với mỗi cặp liên tiếp$(p_1,p_2)$:

- nhảy$p_1 < 5$, 
- dừng lại một lần$p_1 > 10^6$,
- cho phép$m = 10^{\text{digits}(p_1)}$, 
- tính toán:$$k = (-p_1)\cdot m^{-1} \bmod p_2,$$- tính toán:$$S = mk + p_1,$$- thêm vào tổng số. 
3. Xuất ra tổng số. 

Sự phức tạp bị chi phối bởi sàng:$$O(n \log\log n)$$dễ dàng đủ nhanh cho$10^6$. 

--- 

#Triển khai Python```python
from math import isqrt

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
def sieve(limit):
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, isqrt(limit) + 1):
        if is_prime[i]:
            step = i
            start = i * i
            is_prime[start:limit + 1:step] = [False] * (
                ((limit - start) // step) + 1
            )

    return [i for i, v in enumerate(is_prime) if v]

# We need primes slightly beyond 1,000,000
LIMIT = 1_100_000
primes = sieve(LIMIT)

total = 0

for i in range(len(primes) - 1):
    p1 = primes[i]
    p2 = primes[i + 1]

    if p1 < 5:
        continue

    if p1 > 1_000_000:
        break

    # 10^d where d = number of digits of p1
    m = 10 ** len(str(p1))

    # Solve m*k + p1 ≡ 0 (mod p2)
    inv = pow(m, -1, p2)

    k = (-p1 * inv) % p2

    S = m * k + p1

    total += S

print(total)
```---

# Xác minh bằng ví dụ 

cho$p_1=19$,$p_2=23$:$$m = 100.$$Chúng tôi giải quyết:$$100k + 19 \equiv 0 \pmod{23}.$$Từ$$100 \equiv 8 \pmod{23},$$chúng tôi giải quyết:$$8k \equiv -19 \equiv 4 \pmod{23}.$$Nghịch đảo của$8$mod$23$là$3$, Vì thế:$$k \equiv 12 \pmod{23}.$$Kể từ đây$$S = 100 \cdot 12 + 19 = 1219,$$phù hợp với tuyên bố vấn đề.
