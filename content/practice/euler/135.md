[Vấn đề dự án Euler 135](https://projecteuler.net/problem=135) 

## Giải pháp 

**Trả lời:**`4989`Gọi ba số hạng liên tiếp của cấp số cộng là$$x = a+d,\qquad y=a,\qquad z=a-d,$$Ở đâu$a>d>0$. 

Chúng ta được yêu cầu đếm có bao nhiêu số nguyên$n<10^6$thỏa mãn$$x^2-y^2-z^2=n$$theo đúng mười cách khác nhau. 

--- 

# Bước 1 - Đơn giản hóa đại số 

Thay thế dạng cấp số cộng:$$(a+d)^2-a^2-(a-d)^2.$$Mở rộng:$$(a^2+2ad+d^2)-a^2-(a^2-2ad+d^2).$$Đơn giản hóa:$$= a^2+2ad+d^2-a^2-a^2+2ad-d^2$$

$$=4ad-a^2.$$Như vậy$$n=4ad-a^2.$$Nhân tố:$$n=a(4d-a).$$Định nghĩa$$k=4d-a.$$Sau đó$$n=ak.$$Từ$d=\frac{a+k}{4}$, chúng tôi yêu cầu: 

1.$a+k\equiv 0\pmod 4$, 
2.$k>0$(bởi vì$n>0$), 
3.$a>d$. 

Từ$a>d$:$$a>\frac{a+k}{4}$$

$$4a>a+k$$

$$3a>k.$$Vậy mọi nghiệm đều tương ứng với một phép nhân tử hóa$$n=ak$$với$$0<k<3a, \qquad a+k\equiv 0\pmod 4.$$Mỗi cặp hợp lệ$(a,k)$đưa ra chính xác một nghiệm cấp số cộng. 

Vì vậy, nhiệm vụ trở thành: 

> Đếm xem có bao nhiêu$n<10^6$có đúng mười cặp số chia$(a,k)$thỏa mãn những ràng buộc đó. 

--- 

# Bước 2 - Chiến lược đếm hiệu quả 

Chúng tôi lặp đi lặp lại tất cả những gì có thể$a$Và$k$. 

Từ$$n=ak<10^6,$$cho mỗi$a$,$$k<\frac{10^6}{a}.$$Ngoài ra chúng tôi cần$$k<3a.$$Kể từ đây$$k < \min\left(3a,\frac{10^6}{a}\right).$$Và cuối cùng$$a+k\equiv0\pmod4.$$Chúng tôi duy trì một mảng`count[n]`lưu trữ bao nhiêu biểu diễn hợp lệ mỗi$n$có. 

--- 

# Bước 3 - Triển khai Python```python
LIMIT = 1_000_000

# count[n] = number of valid solutions producing n
count = [0] * LIMIT

# Iterate over a
for a in range(1, LIMIT):

    # k must satisfy:
    #   k < 3a
    #   a*k < LIMIT
    k_max = min(3 * a, (LIMIT - 1) // a)

    # We need a + k ≡ 0 (mod 4)
    # so k ≡ -a (mod 4)
    start = (4 - (a % 4)) % 4
    if start == 0:
        start = 4

    for k in range(start, k_max + 1, 4):
        n = a * k
        count[n] += 1

# Count how many n have exactly 10 solutions
answer = sum(1 for n in range(1, LIMIT) if count[n] == 10)

print(answer)
```--- 

# Bước 4 - Hướng dẫn viết mã 

## Thiết lập mảng```python
count = [0] * LIMIT
```

`count[n]`lưu trữ bao nhiêu bộ ba hợp lệ$(x,y,z)$phát ra$n$. 

--- 

## Lặp lại$a$

```python
for a in range(1, LIMIT):
```

$a$là số hạng giữa của cấp số cộng. 

--- 

## Tính phạm vi hợp lệ cho$k$

```python
k_max = min(3 * a, (LIMIT - 1) // a)
```Từ các ràng buộc rút ra: 

-$k<3a$, 
-$ak<10^6$. 

--- 

## Thực thi điều kiện đồng đẳng 

Chúng tôi cần$$a+k\equiv0\pmod4.$$Vì thế:```python
start = (4 - (a % 4)) % 4
if start == 0:
    start = 4
```Điều này tìm thấy tích cực nhỏ nhất$k$với lớp dư lượng yêu cầu modulo 4. 

Sau đó:```python
for k in range(start, k_max + 1, 4):
```các bước thông qua tất cả hợp lệ$k$. 

--- 

## Ghi lại lời giải```python
n = a * k
count[n] += 1
```Mỗi cặp hợp lệ$(a,k)$tương ứng với một nghiệm cấp số cộng riêng biệt.
