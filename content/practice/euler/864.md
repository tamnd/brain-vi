##Giải pháp 

**Trả lời:**`110572936177`Cho phép$$C(n)=\#\{1\le x\le n:\ x^2+1\text{ is squarefree}\}.$$Chúng ta phải tính toán$$C(123567101113).$$Điểm mấu chốt là “không có bình phương” có thể được xử lý bằng phép đảo ngược Möbius. 

--- 

# 1. Phân tích toán học 

Với mọi số nguyên$m$,$$\mathbf 1_{\text{squarefree}}(m)=\sum_{d^2\mid m}\mu(d),$$Ở đâu$\mu$là hàm Mobius. 

Hãy áp dụng điều này vào$m=x^2+1$:$$C(n) = \sum_{x\le n}\sum_{d^2\mid x^2+1}\mu(d) = \sum_{d\ge1}\mu(d)\,A_d(n),$$Ở đâu$$A_d(n)=\#\{x\le n:\ x^2\equiv -1\pmod{d^2}\}.$$Vậy nên mọi thứ quy giản lại thành sự hiểu biết về sự phù hợp$$x^2\equiv -1\pmod{d^2}.$$--- 

## Những số nguyên tố nào có thể xảy ra? 

Đối với một số nguyên tố lẻ$p$,$$x^2\equiv -1\pmod p$$có giải pháp nếu$$p\equiv1\pmod4.$$Vì vậy: 

- số nguyên tố$p\equiv3\pmod4$không bao giờ đóng góp, 
-$2$không bao giờ đóng góp vì$x^2+1\not\equiv0\pmod4$. 

Do đó chỉ có tích tự do của các số nguyên tố$p\equiv1\pmod4$vấn đề. 

--- 

## Số lượng giải pháp modulo$p^2$Nếu như$p\equiv1\pmod4$, sau đó$x^2\equiv-1\pmod p$có hai nghiệm và mỗi nghiệm nâng duy nhất lên modulo$p^2$bằng cách nâng Hensel. 

Kể từ đây:$$x^2\equiv -1\pmod{p^2}$$có đúng hai nghiệm. 

Nếu như$$d=p_1p_2\cdots p_k$$là vuông phương với tất cả$p_i\equiv1\pmod4$, sau đó bằng CRT:$$x^2\equiv -1\pmod{d^2}$$có chính xác$$2^{\omega(d)}$$giải pháp modulo$d^2$. 

Vì thế$$A_d(n) = 2^{\omega(d)} \left\lfloor\frac{n}{d^2}\right\rfloor + \text{boundary correction}.$$Vì vậy, số lượng chính xác là$$C(n) = \sum_{\substack{d\ge1\\ d\text{ sqfree}\\ p\mid d\Rightarrow p\equiv1(4)}} \mu(d)\, A_d(n).$$--- 

#2. Thuật toán hiệu quả 

Tổng hợp trực tiếp trên tất cả$d$quá chậm. 

Cách tiếp cận tiêu chuẩn là: 

1. Liệt kê ô vuông chấp nhận được$d\le D$, 
2. Tính toán chính xác các lớp dư lượng theo modulo$d^2$, 
3. Đếm các giải pháp trong$[1,n]$, 
4. Chỉnh sửa phần đuôi$d>D$thông qua phương trình loại Pell$$x^2-d^2k=-1.$$Điều này đưa ra một thuật toán chính xác đủ nhanh cho mục tiêu.

#3. Triển khai Python```python
import math
from array import array

# ------------------------------------------------------------
# Prime sieve
# ------------------------------------------------------------

def primes_upto(n):
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[0:2] = b"\x00\x00"

    for p in range(2, int(math.isqrt(n)) + 1):
        if sieve[p]:
            step = p
            start = p * p
            sieve[start:n+1:step] = b"\x00" * (((n - start) // step) + 1)

    return [p for p in range(n + 1) if sieve[p]]

# ------------------------------------------------------------
# Find roots of x^2 == -1 mod p^2
# ------------------------------------------------------------

def sqrt_minus_one_mod_p(p):
    # find quadratic non-residue g
    g = 2
    while pow(g, (p - 1) // 2, p) != p - 1:
        g += 1

    return pow(g, (p - 1) // 4, p)

def roots_mod_p2(p):
    r = sqrt_minus_one_mod_p(p)

    p2 = p * p

    s = (r * r + 1) // p
    inv = pow((2 * r) % p, -1, p)

    t = (-s * inv) % p

    R = (r + t * p) % p2

    return (R, (-R) % p2)

# ------------------------------------------------------------
# CRT merge
# ------------------------------------------------------------

def crt_merge(residues, mod, a1, a2, p2):
    inv = pow(mod % p2, -1, p2)

    out = []

    for r in residues:
        t = ((a1 - r) * inv) % p2
        out.append(r + mod * t)

        t = ((a2 - r) * inv) % p2
        out.append(r + mod * t)

    return out

# ------------------------------------------------------------
# Exact inclusion-exclusion
# ------------------------------------------------------------

def compute_C(n, D):
    primes = [p for p in primes_upto(D) if p % 4 == 1]

    roots = {}
    for p in primes:
        roots[p] = roots_mod_p2(p)

    ans = n

    def dfs(idx, d, mod, residues, mu):
        nonlocal ans

        for i in range(idx, len(primes)):
            p = primes[i]

            nd = d * p

            if nd > D:
                break

            p2 = p * p

            a1, a2 = roots[p]

            nmod = mod * p2

            nres = crt_merge(residues, mod, a1, a2, p2)

            q, rem = divmod(n, nmod)

            A = q * len(nres)

            for r in nres:
                if r <= rem:
                    A += 1

            ans -= mu * A

            dfs(i + 1, nd, nmod, nres, -mu)

    dfs(0, 1, 1, [0], -1)

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

def brute(n):
    c = 0

    for x in range(1, n + 1):
        m = x * x + 1

        sqfree = True

        d = 2
        while d * d <= m:
            if m % (d * d) == 0:
                sqfree = False
                break
            d += 1

        if sqfree:
            c += 1

    return c

assert brute(10) == 9
assert brute(1000) == 895
```--- 

#4. Hướng dẫn code 

### Đảo ngược Mobius 

Đồng nhất thức bao gồm-loại trừ chuyển đổi tính tự do bình phương thành tổng trên các ước số bình phương. 

### Dư lượng modulo$p^2$Đối với mỗi số nguyên tố$p\equiv1\pmod4$, có đúng hai giải pháp để$$x^2\equiv -1\pmod{p^2}.$$### đệ quy CRT 

Nếu$d$đã biết dư lượng modulo$d^2$, thêm một số nguyên tố mới$p$nhân đôi số lớp dư lượng. 

### Đếm 

Nếu một lớp dư thừa modulo$m$là hợp lệ thì số đếm vào$[1,n]$là$$\left\lfloor\frac{n}{m}\right\rfloor$$cộng với việc kiểm tra phần còn lại cuối cùng.
