**Trả lời:**`129448`### 1. Phân tích toán học 

Chúng ta nhận được một bản mã được mã hóa bằng **khóa XOR lặp lại có độ dài 3**, trong đó mỗi ký tự khóa là một chữ cái tiếng Anh viết thường (`a`–`z`). 

Nếu: 

- byte văn bản gốc =$p_i$- byte khóa =$k_i$- byte bản mã =$c_i$thì mã hóa là:$$c_i = p_i \oplus k_{i \bmod 3}$$Ở đâu$\oplus$biểu thị XOR. 

Vì XOR là nghịch đảo của chính nó:$$p_i = c_i \oplus k_{i \bmod 3}$$Vì vậy việc giải mã rất đơn giản **nếu biết khóa**. 

Thử thách là tìm ra khóa 3 ký tự không xác định. 

--- 

#### Quan sát chính: vũ lực rất nhỏ 

Mỗi ký tự chính là một chữ cái viết thường:$$26^3 = 17576$$các phím có thể. 

Cái này rất nhỏ nên chúng ta có thể thử mọi phím. 

Đối với mỗi khóa ứng viên: 

1. XOR-giải mã bản mã theo chu kỳ. 
2. Kiểm tra xem kết quả có giống văn bản tiếng Anh hay không. 

Văn bản tiếng Anh chứa các từ phổ biến như: 

-`" the "`-`" and "`-`" of "`-`" to "`và hầu hết các ký tự ASCII có thể in được. 

Khi chúng tôi tìm thấy tiếng Anh có thể đọc được, hãy tính:$$\sum \text{ASCII values of plaintext}$$Tổng số đó là câu trả lời cần thiết.

### 2. Triển khai Python```python
from itertools import product
import requests

# Download the cipher text
url = "https://projecteuler.net/resources/documents/0059_cipher.txt"
cipher = list(map(int, requests.get(url).text.strip().split(",")))

best_score = -1
best_sum = None
best_text = None
best_key = None

# Try all 3-letter lowercase keys
for key_chars in product(range(ord('a'), ord('z') + 1), repeat=3):
    # Decrypt
    plaintext = [
        c ^ key_chars[i % 3]
        for i, c in enumerate(cipher)
    ]

    # Convert to text
    text = ''.join(map(chr, plaintext))

    # Reject obviously bad plaintext
    if not all(32 <= x <= 126 or x in (10, 13) for x in plaintext):
        continue

    # Score based on common English words
    score = (
        text.count(" the ") * 10 +
        text.count(" and ") * 5 +
        text.count(" of ") * 3 +
        text.count(" to ") * 2 +
        text.count(" in ")
    )

    # Keep best candidate
    if score > best_score:
        best_score = score
        best_sum = sum(plaintext)
        best_text = text
        best_key = ''.join(map(chr, key_chars))

print("Key:", best_key)
print("ASCII sum:", best_sum)
print(best_text[:300])
```---
