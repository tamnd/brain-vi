[Bài toán Euler dự án 130](https://projecteuler.net/problem=130) 

## Giải pháp 

**Trả lời:**`149253`Cho phép$R(k)$biểu thị sự trả đũa$$R(k)=\frac{10^k-1}{9}=111\ldots1$$(với$k$những cái đó). Với mọi số nguyên$n$nguyên tố cùng nhau để$10$, tồn tại một số$k$như vậy$$R(k)\equiv 0 \pmod n.$$Định nghĩa$A(n)$là _nhỏ nhất_ như vậy$k$. 

Chúng tôi tìm kiếm điều đầu tiên$25$**tổng hợp** số nguyên$n$như vậy$$A(n)\mid (n-1),$$Và$\gcd(n,10)=1$. Sau đó chúng ta phải tổng hợp chúng. 

--- 

# 1. Phân tích toán học 

Quan sát chính là:$$R(k)\equiv 0 \pmod n \iff \frac{10^k-1}{9}\equiv 0 \pmod n.$$Từ$\gcd(n,10)=1$, điều này tương đương với$$10^k \equiv 1 \pmod{9n}$$(trừ các yếu tố$3$, nhưng sử dụng$9n$thống nhất hoạt động chính xác). 

Như vậy$A(n)$là thứ tự nhân của$10$modulo$9n$:$$A(n)=\operatorname{ord}_{9n}(10).$$Chúng tôi đang tìm kiếm tổng hợp$n$thỏa mãn$$n-1 \equiv 0 \pmod{A(n)}.$$--- 

## Thuộc tính quan trọng của số nguyên tố 

Đối với số nguyên tố$p>5$,$$A(p)\mid p-1$$theo định lý nhỏ Fermat, vì bậc nhân chia cho kích thước nhóm. 

Bài toán yêu cầu các số tổng hợp hiếm có cùng thuộc tính. 

Những điều này có liên quan đến hành vi giống như giả nguyên tố. 

--- 

#2. Thuật toán hiệu quả 

Chúng tôi kiểm tra số nguyên$n$theo thứ tự tăng dần. 

Điều kiện: 

1.$n$tổng hợp 
2.$\gcd(n,10)=1$3.$(n-1)\bmod A(n)=0$Thách thức tính toán là đánh giá$A(n)$. 

--- 

## Tính toán$A(n)$Chúng ta có thể tính trực tiếp thứ tự nhân: 

Bắt đầu với$$x = 10 \bmod (9n)$$và nhân nhiều lần với$10$:$$x \leftarrow (10x)\bmod (9n)$$cho đến khi$x=1$. 

Số bước là$A(n)$. 

Điều này đủ hiệu quả vì số lượng yêu cầu tương đối nhỏ.

#3. Triển khai Python```python
from math import gcd

# Simple primality test
def is_prime(n):
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    d = 3
    while d * d <= n:
        if n % d == 0:
            return False
        d += 2

    return True

# Compute A(n):
# the smallest k such that R(k) is divisible by n
def A(n):
    # modulus used for multiplicative order
    mod = 9 * n

    x = 10 % mod
    k = 1

    while x != 1:
        x = (x * 10) % mod
        k += 1

    return k

count = 0
total = 0
n = 1

while count < 25:
    n += 1

    # must be coprime to 10
    if gcd(n, 10) != 1:
        continue

    # only composite numbers
    if is_prime(n):
        continue

    an = A(n)

    if (n - 1) % an == 0:
        count += 1
        total += n
        print(count, n)

print("Answer =", total)
```---
