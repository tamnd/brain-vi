## Giải pháp 

**Trả lời:**`134043`Chúng tôi tìm kiếm lần chạy đầu tiên của **bốn số nguyên liên tiếp**, mỗi số có chính xác **bốn thừa số nguyên tố riêng biệt**. 

Cho phép$\omega(n)$biểu thị số thừa số nguyên tố riêng biệt của$n$. 

Chúng tôi muốn cái nhỏ nhất$n$như vậy$$\omega(n)=\omega(n+1)=\omega(n+2)=\omega(n+3)=4.$$--- 

# Phân tích toán học 

Một số có bốn thừa số nguyên tố riêng biệt nếu hệ số nguyên tố của nó chứa bốn số nguyên tố khác nhau, bất kể kích thước số mũ. 

Ví dụ:$$644 = 2^2 \cdot 7 \cdot 23$$có số nguyên tố phân biệt$\{2,7,23\}$, vậy nó có chính xác$3$các thừa số nguyên tố riêng biệt. 

Chiến lược vũ phu sẽ là: 

1. Phân tích mọi số nguyên. 
2. Đếm các ước số nguyên tố khác nhau. 
3. Tìm bốn số nguyên liên tiếp thỏa mãn điều kiện. 

Tuy nhiên, việc phân tích nhân tử lặp đi lặp lại sẽ chậm nếu thực hiện một cách ngây thơ.

## Ý tưởng hiệu quả: sàng cải tiến 

Thay vì phân tích từng số một cách độc lập, chúng ta có thể sử dụng phương pháp sàng. 

Tạo một mảng:$$\text{count}[n]$$Ở đâu`count[n]`sẽ lưu trữ số lượng các thừa số nguyên tố riêng biệt của$n$. 

Ban đầu tất cả các mục đều$0$. 

Bây giờ lặp qua các số nguyên$p$:

- Nếu như`count[p] == 0`, sau đó$p$là nguyên tố. 
- Với mọi bội số của$p$, tăng số lượng của nó lên$1$. 

Điều này hiệu quả vì mỗi số nguyên tố đóng góp chính xác một lần cho mỗi bội số. 

Ví dụ: 

- Thủ tướng$2$tăng tất cả các số chẵn. 
- Xuất sắc$3$tăng tất cả bội số của$3$. 
- v.v. 

Sau khi sàng xong:$$\text{count}[n] = \omega(n)$$cho mọi$n$. 

Sau đó quét bốn mục liên tiếp bằng$4$. 

Điều này cực kỳ hiệu quả và phản ánh Sàng Eratosthenes cổ điển. 

--- 

#Triển khai Python```python
def first_consecutive_integers(target_factors=4, consecutive=4, limit=200000):
    """
    Find the first integer in the first run of `consecutive`
    consecutive integers each having exactly `target_factors`
    distinct prime factors.
    """

    # count[n] will store the number of distinct prime factors of n
    count = [0] * (limit + 1)

    # Modified sieve
    for p in range(2, limit + 1):

        # If count[p] == 0, then p is prime
        if count[p] == 0:

            # Add this prime factor to all multiples of p
            for multiple in range(p, limit + 1, p):
                count[multiple] += 1

    # Search for consecutive integers
    streak = 0

    for n in range(2, limit + 1):

        if count[n] == target_factors:
            streak += 1

            if streak == consecutive:
                return n - consecutive + 1
        else:
            streak = 0

    return None

# Compute the Project Euler answer
answer = first_consecutive_integers()

print(answer)
```---

```Mỗi bội số của$p$nhận thêm một thừa số nguyên tố riêng biệt.

Như vậy:$$count[12] = 2$$bởi vì$12 = 2^2 \cdot 3$.
