[Vấn đề dự án Euler 479](https://projecteuler.net/problem=479) 

##Giải pháp 

**Trả lời:**`191541795`Cho phép$$\frac1x=\left(\frac{k}{x}\right)^2(k+x^2)-kx.$$Chúng tôi được bảo rằng$a_k,b_k,c_k$là ba nghiệm của phương trình này và chúng tôi xác định$$S(n)=\sum_{p=1}^n\sum_{k=1}^n (a_k+b_k)^p(b_k+c_k)^p(c_k+a_k)^p.$$Chúng ta phải tính toán$S(10^6)\bmod 1\,000\,000\,007$. 

--- 

# Bước 1: Chuyển phương trình thành đa thức 

Bắt đầu từ$$\frac1x=\frac{k^2}{x^2}(k+x^2)-kx,$$mở rộng:$$\frac1x=\frac{k^3}{x^2}+k^2-kx.$$Nhân với$x^2$:$$x=k^3+k^2x^2-kx^3.$$Sắp xếp lại:$$kx^3-k^2x^2+x-k^3=0.$$Như vậy$a_k,b_k,c_k$là gốc rễ của$$kx^3-k^2x^2+x-k^3=0.$$Chia cho$k$:$$x^3-kx^2+\frac1k x-k^2=0.$$Vì vậy đối với khối monic$$x^3-s_1x^2+s_2x-s_3,$$Vieta đưa ra$$s_1=a+b+c=k,$$

$$s_2=ab+ac+bc=\frac1k,$$

$$s_3=abc=k^2.$$--- 

# Bước 2: Rút gọn biểu thức 

Chúng tôi cần$$(a+b)(b+c)(c+a).$$Một danh tính đối xứng tiêu chuẩn là$$(a+b)(b+c)(c+a) =(a+b+c)(ab+ac+bc)-abc.$$Vì thế$$(a+b)(b+c)(c+a) =s_1s_2-s_3.$$Thay thế các giá trị Vieta:$$=k\cdot \frac1k-k^2 =1-k^2.$$Kể từ đây$$(a_k+b_k)^p(b_k+c_k)^p(c_k+a_k)^p =(1-k^2)^p.$$Vì thế$$S(n)=\sum_{k=1}^n\sum_{p=1}^n(1-k^2)^p.$$--- 

# Bước 3: Tính chuỗi hình học 

Để cố định$k$,$$\sum_{p=1}^n r^p =\frac{r(r^n-1)}{r-1}, \quad r=1-k^2.$$Như vậy$$S(n)=\sum_{k=1}^n \frac{(1-k^2)\big((1-k^2)^n-1\big)}{-k^2}.$$Chúng tôi chỉ cần modulo này$$M=1\,000\,000\,007.$$Từ$M$là số nguyên tố, chia cho$k^2$là phép nhân với nghịch đảo mô đun. 

Độ phức tạp là$O(n\log M)$, dễ dàng đủ nhanh để$n=10^6$. 

--- 

# Bước 4: Triển khai Python```python
MOD = 1_000_000_007
n = 10**6

ans = 0

for k in range(1, n + 1):
    r = (1 - k * k) % MOD

    # Sum_{p=1}^n r^p
    # = r * (r^n - 1) / (r - 1)

    numerator = r * (pow(r, n, MOD) - 1)
    denominator = (r - 1) % MOD

    geom = numerator * pow(denominator, MOD - 2, MOD)
    ans = (ans + geom) % MOD

print(ans % MOD)
```---

### Tính toán$r=1-k^2$

```python
r = (1 - k * k) % MOD
```Điều này bằng$$(a_k+b_k)(b_k+c_k)(c_k+a_k).$$--- 

### Tổng hình học```python
numerator = r * (pow(r, n, MOD) - 1)
denominator = (r - 1) % MOD
geom = numerator * pow(denominator, MOD - 2, MOD)
```sử dụng$$\sum_{p=1}^n r^p = \frac{r(r^n-1)}{r-1}.$$Nghịch đảo mô-đun được tính toán thông qua định lý Fermat:$$a^{-1}\equiv a^{M-2}\pmod M.$$--- 

### Tích lũy```python
ans = (ans + geom) % MOD
```---
