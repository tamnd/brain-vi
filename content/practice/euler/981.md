# Phân tích toán học 

Chúng tôi giải thích các chữ cái dưới dạng đơn vị quaternion:$$x=i,\qquad y=j,\qquad z=k.$$Nhắc lại quan hệ quaternion:$$i^2=j^2=k^2=-1,\qquad ij=k,\quad jk=i,\quad ki=j,$$và đảo ngược thứ tự thay đổi dấu hiệu:$$ji=-k,\quad kj=-i,\quad ik=-j.$$--- 

## 1. Bất biến khóa 

Vì một lời$w$, định nghĩa$Q(w)$là tích bậc bốn của các chữ cái của nó. 

Ban đầu chuỗi rỗng có tích$$Q(\emptyset)=1.$$Bây giờ hãy kiểm tra từng hoạt động được phép. 

--- 

### Thao tác A: chèn`"xx"`(hoặc`"yy"`,`"zz"`)

Từ$i^2=j^2=k^2=-1$,$$Q \mapsto -Q.$$Vì vậy, dấu hiệu lật. 

--- 

### Thao tác B: thay thế`"x"`qua`"yz"`Bởi vì$$yz=jk=i=x,$$tích quaternion không thay đổi. 

Nhưng số bước tăng thêm$1$. 

Tương tự, tính chẵn lẻ thay đổi trong khi giá trị quaternion vẫn cố định. 

--- 

### Thao tác C: hoán đổi các chữ cái riêng biệt liền kề 

Ví dụ:$$xy=ij=k,\qquad yx=ji=-k.$$Hoán đổi các chữ cái liền kề khác biệt sẽ nhân kết quả với$-1$. 

Một lần nữa, một bước thay đổi tính chẵn lẻ và lật dấu. 

--- 

Vì vậy: 

> Mọi thao tác đều nhân lên$Q(w)$qua$-1$. 

Bắt đầu từ$Q=1$, sau đó$t$các bước:$$Q(w)=(-1)^t.$$Do đó: 

- số bước chẵn$\iff Q(w)=1$, 
- số bước lẻ$\iff Q(w)=-1$. 

Vì thế:$$\boxed{\text{A word is neutral iff }Q(w)=1.}$$--- 

#2. Giá trị bậc bốn của một từ 

Sửa số lượng$X,Y,Z$. 

Hãy xem xét từ có thứ tự kinh điển:$$x^X y^Y z^Z.$$Giá trị quaternion của nó là$$i^X j^Y k^Z.$$Bất kỳ sự sắp xếp nào khác sẽ khác nhau bởi các giao dịch hoán đổi liền kề. 

Mỗi lần hoán đổi giới thiệu một yếu tố$-1$. 

Như vậy:$$Q(w)=(-1)^{\operatorname{inv}(w)} i^X j^Y k^Z,$$Ở đâu$\operatorname{inv}(w)$là số lần đảo ngược modulo$2$. 

--- 

# 3. Khi nào có thể$Q(w)=1$? 

Tính toán đầu tiên$$C=i^X j^Y k^Z.$$Nếu mô hình chẵn lẻ của$(X,Y,Z)$chứa đúng một hoặc đúng hai số lẻ thì$C\in\{\pm i,\pm j,\pm k\}$, Vì thế$Q(w)\neq1$cho mỗi từ. 

Kể từ đây:$$N(X,Y,Z)=0$$trừ khi cả ba số chẵn lẻ đều bằng nhau. 

--- 

## Trường hợp A: đều chẵn 

Viết$$X=2a,\quad Y=2b,\quad Z=2c.$$Sau đó$$C=(-1)^{a+b+c}.$$Vì vậy, những từ trung tính là: 

- thậm chí đảo ngược nếu$a+b+c$thậm chí, 
- nghịch đảo lẻ nếu$a+b+c$số lẻ. 

--- 

##Trường hợp B: đều lẻ 

Viết$$X=2a+1,\quad Y=2b+1,\quad Z=2c+1.$$Sau đó$$C=(-1)^{a+b+c}ijk =(-1)^{a+b+c+1}.$$Áp dụng quy tắc chẵn lẻ tương tự. 

--- 

# 4. Đếm nhiều hoán vị chẵn/lẻ 

hãy để$$T=\binom{X+Y+Z}{X,Y,Z}$$là tổng số từ. 

Cho phép$$D=(\#\text{even inversions})-(\#\text{odd inversions}).$$Sau đó$$\#\text{even}=\frac{T+D}{2},\qquad \#\text{odd}=\frac{T-D}{2}.$$Một tiêu chuẩn$q$-Đánh giá đa thức tại$q=-1$mang lại:$$D= \begin{cases} \displaystyle \binom{\lfloor X/2\rfloor+\lfloor Y/2\rfloor+\lfloor Z/2\rfloor} {\lfloor X/2\rfloor,\lfloor Y/2\rfloor,\lfloor Z/2\rfloor}, & \text{if at most one of }X,Y,Z\text{ is odd},\\[2ex] 0,& \text{otherwise}. \end{cases}$$Ví dụ:$$D(2,2,2)=\binom311=6.$$Từ$$T(2,2,2)=\frac{6!}{2!2!2!}=90,$$và quaternion chính tắc là$-1$, chúng ta cần đảo ngược số lẻ:$$N(2,2,2)=\frac{90-6}{2}=42,$$phù hợp với tuyên bố. 

--- 

#Triển khai Python```python
MOD = 888_888_883
INV2 = (MOD + 1) // 2

# cube values
vals = [i ** 3 for i in range(88)]

# largest factorial needed
MAXN = 3 * vals[-1]

# factorials modulo MOD
fac = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fac[i] = fac[i - 1] * i % MOD

# inverse factorials
invfac = [1] * (MAXN + 1)
invfac[MAXN] = pow(fac[MAXN], MOD - 2, MOD)

for i in range(MAXN, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

def multinomial(a, b, c):
    s = a + b + c
    return (
        fac[s]
        * invfac[a] % MOD
        * invfac[b] % MOD
        * invfac[c] % MOD
    )

def N(X, Y, Z):
    odd = (X & 1) + (Y & 1) + (Z & 1)

    # impossible to get quaternion value 1
    if odd in (1, 2):
        return 0

    T = multinomial(X, Y, Z)

    # parity difference D
    if odd >= 2:
        D = 0
    else:
        D = multinomial(X // 2, Y // 2, Z // 2)

    # sign of canonical product
    if odd == 0:
        sign_parity = ((X + Y + Z) // 2) & 1
    else:
        sign_parity = ((X + Y + Z + 1) // 2) & 1

    # sign_parity = 0 means canonical product = +1
    if sign_parity == 0:
        return (T + D) * INV2 % MOD
    else:
        return (T - D) * INV2 % MOD

ans = 0

for X in vals:
    for Y in vals:
        for Z in vals:
            ans = (ans + N(X, Y, Z)) % MOD

print(ans)
```--- 

# Hướng dẫn sử dụng mã 

- Tính toán trước giai thừa và nghịch đảo giai thừa modulo số nguyên tố$888{,}888{,}883$. 
-`multinomial(a,b,c)`tính toán$$\frac{(a+b+c)!}{a!\,b!\,c!}.$$-`odd`đếm xem có bao nhiêu$X,Y,Z$thật kỳ quặc. 
- Nếu có đúng một hoặc hai số lẻ thì tích bậc bốn không bao giờ bằng$1$, vậy hãy quay lại$0$. 
-`T`là tổng số từ. 
-`D`là hiệu số chẵn-trừ-lẻ. 
- Tùy theo dấu của tích quaternion chính tắc, chọn:$$\frac{T+D}{2} \quad\text{or}\quad \frac{T-D}{2}.$$Cuối cùng tính tổng tất cả các hình khối$i^3,j^3,k^3$vì$0\le i,j,k<88$.
