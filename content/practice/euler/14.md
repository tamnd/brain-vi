[Bài toán dự án Euler 14](https://projecteuler.net/problem=14) 

## Giải pháp 

**Trả lời:**`837799`Chúng tôi tìm kiếm số bắt đầu$n < 1{,}000{,}000$tạo ra chuỗi Collatz dài nhất. 

Với mỗi số nguyên: 

- nếu$n$thậm chí là:$n \to n/2$- nếu như$n$thật kỳ lạ:$n \to 3n+1$Tối ưu hóa chính là **ghi nhớ**: khi đã biết độ dài chuỗi của một số, hãy sử dụng lại nó thay vì phải tính toán lại toàn bộ chuỗi nhiều lần. 

Ví dụ:$$13 \to 40 \to 20 \to 10 \to 5 \to 16 \to 8 \to 4 \to 2 \to 1$$có$10$điều khoản. 

Một giải pháp Python sạch:```python
def collatz_length(n, cache):
    if n in cache:
        return cache[n]

    if n % 2 == 0:
        length = 1 + collatz_length(n // 2, cache)
    else:
        length = 1 + collatz_length(3 * n + 1, cache)

    cache[n] = length
    return length

cache = {1: 1}

best_n = 1
best_len = 1

for n in range(1, 1_000_000):
    length = collatz_length(n, cache)

    if length > best_len:
        best_len = length
        best_n = n

print(best_n)
```Truy tìm kết quả đã biết: 

-$13$cho chiều dài$10$- Khi quá trình tìm kiếm tiếp tục, các bản ghi lớn hơn sẽ xuất hiện 
- Chuỗi tối đa dưới một triệu xảy ra tại:$$837799$$với chiều dài chuỗi là$525$.
