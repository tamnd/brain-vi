## Giải pháp 

**Trả lời:**`5777137137739632912`Cho phép$$T(N)=\#\{(a,b,c): a\le b\le c,\ a+b>c,\ a+b+c\le N\}$$là số lượng tất cả các tam giác có cạnh nguyên có chu vi lớn nhất$N$, và để$$P(N)$$là số **nguyên thủy** (tức là$\gcd(a,b,c)=1$). 

chúng tôi muốn$P(10^7)$. 

--- 

## 1. Phân tích toán học 

### Bước 1: Đếm tất cả các tam giác nguyên chu vi$n$Cho phép$t(n)$là số lượng tam giác nguyên có chu vi chính xác$n$. 

Một kết quả cổ điển cho:$$t(n)=\operatorname{round}\!\left(\frac{n^2}{12}\right) -\left\lfloor \frac n4 \right\rfloor \left\lfloor \frac{n+2}{4}\right\rfloor.$$Chúng ta có thể xác minh trên các ví dụ nhỏ: 

-$n=3$: chỉ một$(1,1,1)$, Vì thế$t(3)=1$-$n=5$: chỉ một$(1,2,2)$, Vì thế$t(5)=1$-$n=6$:$(1,2,3)$thất bại trong bất đẳng thức tam giác, nhưng$(2,2,2)$,$(1,2,3)$không hợp lệ,$(1,1,4)$không hợp lệ, vì vậy chỉ$(2,2,2)$Và$(1,2,3)$bị loại trừ ⇒$t(6)=1$Công thức phù hợp. 

Xác định số tích lũy:$$A(N)=\sum_{n\le N} t(n).$$Từ$t(n)$là bậc hai với sự điều chỉnh định kỳ (giai đoạn 12),$A(N)$trở thành một giả đa thức bậc ba. Viết$$N=12q+r,\qquad 0\le r<12,$$chúng tôi có được một chính xác$O(1)$công thức cho$A(N)$. Ví dụ:$$A(12q)=6q^2(2q+1),$$và tương tự cho 11 loại dư lượng còn lại. 

--- 

### Bước 2: Tam giác nguyên thủy thông qua nghịch đảo Möbius 

Mỗi tam giác$(a,b,c)$có một gcd độc đáo$d$:$$(a,b,c)=d(a',b',c')$$với$(a',b',c')$nguyên thủy. 

Như vậy:$$A(N)=\sum_{d\le N} P\!\left(\left\lfloor \frac Nd\right\rfloor\right).$$Đây là một tích chập chia. 

Áp dụng nghịch đảo Möbius:$$P(N) = \sum_{d\le N} \mu(d)\, A\!\left(\left\lfloor \frac Nd\right\rfloor\right),$$Ở đâu$\mu$là hàm Mobius. 

Vì vậy, nhiệm vụ giảm xuống: 

1. Tính toán$\mu(d)$lên tới$10^7$sử dụng sàng tuyến tính. 
2. Tính tổng tiền tố Mertens$$M(n)=\sum_{k\le n}\mu(k).$$1. Nhóm các giá trị bằng nhau của$\lfloor N/d\rfloor$:$$P(N) = \sum A(v)\, \bigl(M(r)-M(l-1)\bigr),$$Ở đâu$v=\lfloor N/l\rfloor$Và$r=\lfloor N/v\rfloor$. 

Điều này làm giảm tổng thành$O(\sqrt N)$.

## 2. Triển khai Python```python
from array import array

N = 10_000_000

def cumulative_triangles(n):
    """
    A(n) = number of integer-sided triangles
    with perimeter <= n.
    Exact O(1) quasipolynomial formula.
    """
    q, r = divmod(n, 12)

    if r == 0:
        return 6 * q * q * (2 * q + 1)
    elif r == 1:
        return q * (12 * q * q + 9 * q + 2)
    elif r == 2:
        return 3 * q * (2 * q + 1) ** 2
    elif r == 3:
        return 12 * q**3 + 15 * q**2 + 6 * q + 1
    elif r == 4:
        return (2 * q + 1) * (6 * q**2 + 6 * q + 1)
    elif r == 5:
        return 12 * q**3 + 21 * q**2 + 12 * q + 2
    elif r == 6:
        return 3 * (q + 1) * (2 * q + 1) ** 2
    elif r == 7:
        return (q + 1) * (12 * q**2 + 15 * q + 5)
    elif r == 8:
        return 6 * (q + 1) ** 2 * (2 * q + 1)
    elif r == 9:
        return 3 * (q + 1) ** 2 * (4 * q + 3)
    elif r == 10:
        return (q + 1) * (12 * q**2 + 24 * q + 11)
    else:  # r == 11
        return 3 * (q + 1) ** 2 * (4 * q + 5)

# ----- Linear sieve for Möbius function -----

mu = array('b', [0]) * (N + 1)
lp = array('I', [0]) * (N + 1)
primes = array('I')

mu[1] = 1

for i in range(2, N + 1):
    if lp[i] == 0:
        lp[i] = i
        primes.append(i)
        mu[i] = -1

    li = lp[i]

    for p in primes:
        v = i * p
        if v > N or p > li:
            break

        lp[v] = p

        if p == li:
            mu[v] = 0
            break
        else:
            mu[v] = -mu[i]

# ----- Prefix sums of Möbius -----

M = array('i', [0]) * (N + 1)

running = 0
for i in range(1, N + 1):
    running += mu[i]
    M[i] = running

# ----- Möbius inversion with floor-division grouping -----

answer = 0
l = 1

while l <= N:
    v = N // l
    r = N // v

    answer += cumulative_triangles(v) * (M[r] - M[l - 1])

    l = r + 1

print(answer)
```--- 

## 3. Hướng dẫn sử dụng mã 

###`cumulative_triangles(n)`Tính toán$$A(n)=\sum_{k\le n} t(k)$$trong thời gian không đổi bằng cách sử dụng chính xác các công thức cấp dư lượng modulo 12. 

Điều này tránh việc lưu trữ tất cả số lượng tam giác lên đến$10^7$. 

--- 

### Sàng tuyến tính 

Chúng tôi tính toán hàm Möbius:$$\mu(n)= \begin{cases} 1 & n=1\\ (-1)^k & n \text{ squarefree with }k\text{ primes}\\ 0 & \text{otherwise} \end{cases}$$sử dụng một$O(N)$sàng tuyến tính. 

--- 

### Hàm tiền tố Mertens 

Chúng tôi lưu trữ:$$M(n)=\sum_{k\le n}\mu(k)$$để cho phép tính tổng phạm vi nhanh:$$\sum_{d=l}^r \mu(d)=M(r)-M(l-1).$$--- 

### Thủ thuật nhóm hài hòa 

Kể từ khi$$\left\lfloor \frac Nd\right\rfloor$$chỉ mất$O(\sqrt N)$giá trị riêng biệt, chúng tôi xử lý các khoảng thời gian trong đó nó không đổi. 

Điều này làm giảm tổng kết cuối cùng từ$10^7$lặp lại đại khái$2\sqrt N$.
