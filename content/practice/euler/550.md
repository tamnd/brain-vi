[Vấn đề dự án Euler 550](https://projecteuler.net/problem=550) 

## Giải pháp 

**Trả lời:**`328104836`Cho phép$g(n)$biểu thị giá trị Sprague–Grundy của một đống kích thước$n$. 

Một vị trí với$k$cọc sẽ thắng nếu xor của$k$đống giá trị Grundy là khác không. 

Vì vậy, vấn đề giảm xuống: 

1. Tính giá trị Grundy của mọi số nguyên$2\le n\le 10^7$. 
2. Đếm xem mỗi giá trị Grundy có bao nhiêu số. 
3. Đếm xem có bao nhiêu$k$-tuple có xor$=0$sử dụng phép chập xor/biến đổi Walsh–Hadamard. 
4. Trừ tổng số bộ dữ liệu. 

--- 

# 1. Phân tích toán học 

## 1.1 Nước đi được phép 

Từ một đống kích thước$n$, một nước đi chọn hai ước thích hợp$a,b$của$n$thỏa mãn$$1<a<n,\qquad 1<b<n.$$Vị trí trò chơi kết quả là hai cọc độc lập, do đó giá trị Grundy của nó là$$g(a)\oplus g(b).$$Như vậy$$g(n)=\operatorname{mex}\{g(a)\oplus g(b)\}.$$--- 

#1.2 Quan sát chính:$g(n)$chỉ phụ thuộc vào$\Omega(n)$Cho phép$$\Omega(n)=\text{total number of prime factors of }n$$(được tính theo bội số). 

Ví dụ:$$\Omega(12)=\Omega(2^2\cdot3)=3, \qquad \Omega(72)=\Omega(2^3\cdot3^2)=5.$$Giả định$\Omega(n)=m$. 

Mỗi ước số thực sự của$n$có số lượng thừa số nguyên tố nằm giữa$1$Và$m-1$và mọi giá trị trong khoảng đó đều có thể đạt được. 

Thật vậy, nếu$$n=p_1p_2\cdots p_m$$(được phép lặp lại), sau đó lấy bất kỳ$t$của các thừa số nguyên tố này cho một ước số có$\Omega=t$. 

Do đó tập nước đi chỉ phụ thuộc vào$m$. 

Định nghĩa$$G(m)=g(n)\quad\text{whenever }\Omega(n)=m.$$Sau đó$$G(1)=0$$(số nguyên tố không di chuyển) và đối với$m\ge2$,$$G(m)=\operatorname{mex} \left( \{\,G(i)\oplus G(j)\;:\;1\le i,j<m\,\} \right).$$Tính toán đệ quy cho:$$\begin{aligned} G(1)&=0\\ G(2)&=1\\ G(3)&=2\\ G(4)&=4\\ G(5)&=7\\ G(6)&=8\\ &\dots \end{aligned}$$Vì$n\le10^7$,$$\Omega(n)\le23$$bởi vì$$2^{24}>10^7.$$Vì vậy, chỉ cần 23 giá trị Grundy đầu tiên.

# 1.3 Đếm các bộ dữ liệu xor-zero 

hãy để$$c_x=\#\{n\in[2,10^7]:g(n)=x\}.$$Nếu chúng ta chọn$k$xếp độc lập, số lượng bộ có xor bằng 0 là$k$-fold xor tích chập được đánh giá ở mức 0. 

Công cụ tiêu chuẩn là Biến đổi Walsh–Hadamard nhanh (FWHT). 

Nếu như$A$là vectơ tần số$(c_x)$, thì: 

1. Biến đổi FWHT$A$, 
2. nâng từng thành phần được chuyển đổi lên$k$-quyền lực thứ, 
3. biến đổi nghịch đảo. 

Hệ số kết quả tại chỉ số$0$chính xác là số lượng bộ dữ liệu xor-zero. 

Cuối cùng,$$f(n,k)=n^k-(\text{xor-zero tuples}).$$Đây$n=10^7-1$kích thước cọc có thể ($2$bởi vì$10^7$). 

Mọi thứ đều được tính toán modulo$$987654321.$$--- 

#2. Triển khai Python```python
MOD = 987654321
N = 10_000_000
K = 10**12

# ------------------------------------------------------------
# Step 1: compute Omega(n) for all n <= N using a linear sieve
# ------------------------------------------------------------

omega = [0] * (N + 1)
primes = []

for i in range(2, N + 1):
    if omega[i] == 0:
        omega[i] = 1
        primes.append(i)

    for p in primes:
        v = i * p
        if v > N:
            break

        omega[v] = omega[i] + 1

        if i % p == 0:
            break

# ------------------------------------------------------------
# Step 2: compute Grundy values G(m)
# Only m <= 23 is needed
# ------------------------------------------------------------

MAX_OMEGA = max(omega)

G = [0] * (MAX_OMEGA + 1)

grundy_values_so_far = []

for m in range(1, MAX_OMEGA + 1):

    reachable = set()

    for a in grundy_values_so_far:
        for b in grundy_values_so_far:
            reachable.add(a ^ b)

    g = 0
    while g in reachable:
        g += 1

    G[m] = g
    grundy_values_so_far.append(g)

# ------------------------------------------------------------
# Step 3: count how many numbers have each Grundy value
# ------------------------------------------------------------

MAX_G = max(G)

SIZE = 1
while SIZE <= MAX_G:
    SIZE <<= 1

freq = [0] * SIZE

for n in range(2, N + 1):
    freq[G[omega[n]]] += 1

# ------------------------------------------------------------
# Step 4: FWHT for xor convolution
# ------------------------------------------------------------

def fwht(a, inverse=False):
    n = len(a)
    h = 1

    while h < n:
        for i in range(0, n, h * 2):
            for j in range(i, i + h):
                x = a[j]
                y = a[j + h]

                a[j] = (x + y) % MOD
                a[j + h] = (x - y) % MOD

        h <<= 1

    if inverse:
        inv_n = pow(n, -1, MOD)
        for i in range(n):
            a[i] = (a[i] * inv_n) % MOD

# transform
fwht(freq)

# raise pointwise to K
for i in range(SIZE):
    freq[i] = pow(freq[i], K, MOD)

# inverse transform
fwht(freq, inverse=True)

xor_zero = freq[0] % MOD

# total tuples
total = pow(N - 1, K, MOD)

answer = (total - xor_zero) % MOD

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

## Sàng tuyến tính```python
omega[v] = omega[i] + 1
```thêm một thừa số nguyên tố khi nhân với$p$. 

Như vậy chúng ta tính toán$\Omega(n)$cho mọi$n\le10^7$trong thời gian tuyến tính. 

--- 

## Đệ quy Grundy 

Sự đệ quy:```python
reachable.add(a ^ b)
```dụng cụ$$G(m)=\operatorname{mex}\{G(i)\oplus G(j)\}.$$Chỉ có 23 tiểu bang tồn tại nên phần này rất nhỏ. 

--- 

## Bảng tần số```python
freq[G[omega[n]]] += 1
```đếm xem có bao nhiêu kích thước cọc tạo ra mỗi giá trị Grundy. 

--- 

## CÁI GÌ 

Phép biến đổi Walsh–Hadamard chéo hóa tích chập xor. 

Sau khi chuyển đổi:```python
freq[i] = pow(freq[i], K, MOD)
```tính toán$K$-fold xor tích chập trong không gian tần số. 

Phép biến đổi nghịch đảo phục hồi số lượng bộ dữ liệu.`freq[0]`trở thành số vị trí xor-zero.
