[Dự án Euler Vấn đề 127](https://projecteuler.net/problem=127) 

## Giải pháp 

**Trả lời:**`18407904`Cho phép$R(n)=\operatorname{rad}(n)$, tích của các thừa số nguyên tố phân biệt của$n$. 

Chúng tôi tìm kiếm tất cả các bộ ba$(a,b,c)$như vậy$$a+b=c,\qquad a<b,\qquad \gcd(a,b)=\gcd(a,c)=\gcd(b,c)=1,$$Và$$R(abc)<c.$$Chúng ta phải tính toán$$\sum c \quad\text{for all abc-hits with } c<120000.$$--- 

# 1. Phân tích toán học 

Cách tiếp cận bạo lực trực tiếp là vô vọng: 

-$c<120000$- cho mỗi$c$, có khả năng$O(c)$chia tách$a+b=c$Đó sẽ là hàng tỷ tờ séc. 

Chúng ta cần khai thác điều kiện căn bản. 

--- 

## Bước 1: Rút gọn điều kiện gcd 

Kể từ khi$$a+b=c,$$chúng tôi có danh tính tiêu chuẩn:$$\gcd(a,b)=1 \implies \gcd(a,c)=\gcd(b,c)=1.$$Thực vậy,$$\gcd(a,c)=\gcd(a,a+b)=\gcd(a,b),$$và tương tự cho$\gcd(b,c)$. 

Vậy là đủ để yêu cầu$$\gcd(a,b)=1.$$--- 

## Bước 2: Sử dụng căn thức nhân 

Bởi vì$a,b,c$là cặp nguyên tố cùng nhau,$$R(abc)=R(a)R(b)R(c).$$Do đó, điều kiện abc-hit trở thành$$R(a)R(b)R(c)<c.$$Tương đương,$$R(a)R(b)<\frac{c}{R(c)}.$$Điều này cực kỳ hạn chế. 

--- 

## Bước 3: Tính toán trước căn thức 

Chúng tôi tính toán$R(n)$cho tất cả$n<120000$dùng sàng. 

Ban đầu:$$R(n)=1.$$Đối với mỗi số nguyên tố$p$, nhân mọi bội số của$p$qua$p$. 

Độ phức tạp:$$O(n\log\log n).$$--- 

## Bước 4: Tối ưu hóa khóa 

Giả sử$c$đã được sửa. 

Chúng tôi cần:$$R(a)R(b)R(c)<c.$$Từ$b=c-a$,$$R(a)R(c-a)<\frac{c}{R(c)}.$$Bây giờ lưu ý: 

- Nếu$R(c)$thì lớn$c/R(c)$là nhỏ bé. 
- Hầu hết$c$nên không thể hoạt động được. 

Chúng tôi lặp lại:$$1\le a < \frac c2, \qquad b=c-a.$$Nhưng chúng tôi nhanh chóng từ chối trừ khi$$R(a)R(b) < \frac{c}{R(c)}.$$Chúng tôi cũng yêu cầu:$$\gcd(a,b)=1.$$--- 

## Bước 5: Ước tính độ phức tạp 

Đáng ngạc nhiên là có rất ít lượt truy cập. 

Tìm kiếm được tối ưu hóa kết thúc nhanh chóng trong Python vì: 

- căn thức là những số nguyên rất nhỏ, 
- hầu hết các cặp đều thất bại ngay lập tức, 
- séc gcd rẻ. 

--- 

#2. Triển khai Python```python
from math import gcd

LIMIT = 120000

# ---------------------------------------------------------
# Compute rad(n) for all n < LIMIT using a sieve
# ---------------------------------------------------------

rad = [1] * LIMIT

for p in range(2, LIMIT):
    # p is prime iff rad[p] == 1
    if rad[p] == 1:
        for multiple in range(p, LIMIT, p):
            rad[multiple] *= p

# ---------------------------------------------------------
# Search for abc-hits
# ---------------------------------------------------------

total = 0

for c in range(3, LIMIT):

    rc = rad[c]

    # We need:
    # rad(a) * rad(b) * rad(c) < c
    #
    # so:
    # rad(a) * rad(b) < c / rad(c)

    threshold = c // rc

    # If threshold == 1, impossible
    if threshold <= 1:
        continue

    # Only need a < b
    for a in range(1, c // 2 + 1):

        b = c - a

        # Fast radical rejection
        if rad[a] * rad[b] >= threshold:
            continue

        # Need coprime
        if gcd(a, b) != 1:
            continue

        total += c

print(total)
```---
