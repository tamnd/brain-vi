##Giải pháp 

**Trả lời:**`301450082318807027`Cho phép$$R(M,N)=\#\left\{(x,y): M<x\le N,\; M<y\le N,\; \left\lfloor \frac{y^2}{x^2}\right\rfloor \text{ is odd} \right\}.$$chúng tôi muốn$$R(2\cdot 10^6,10^9).$$--- 

## 1. Phân tích toán học 

Chúng ta phải đếm các điểm mạng thỏa mãn$$\left\lfloor \frac{y^2}{x^2}\right\rfloor = 2k+1$$đối với một số nguyên$k\ge0$. 

Tương đương,$$2k+1 \le \frac{y^2}{x^2} < 2k+2,$$kể từ đây$$x\sqrt{2k+1}\le y < x\sqrt{2k+2}.$$Vì vậy để cố định$x$, hợp lệ$y$nằm trong những khoảng cách rời nhau$$[x\sqrt{1},x\sqrt{2}), [x\sqrt{3},x\sqrt{4}), [x\sqrt{5},x\sqrt{6}), \ldots$$hạn chế ở$M<y\le N$. 

Đối với số lẻ cố định$n$, định nghĩa$$I_n(x)=\#\{y: n x^2\le y^2<(n+1)x^2,\; M<y\le N\}.$$Sau đó$$R(M,N)=\sum_{\substack{n\ge1\\ n\text{ odd}}} \sum_{x=M+1}^{N} I_n(x).$$--- 

### Đếm chính xác khoảng thời gian 

Đối với số lẻ$n$,$$y \in \left[ \left\lceil x\sqrt n\right\rceil, \left\lceil x\sqrt{n+1}\right\rceil-1 \right].$$Từ$n+1$chẵn và không bao giờ là hình vuông, điểm cuối trên luôn vô tỷ, vì vậy$$\left\lceil x\sqrt{n+1}\right\rceil-1 = \left\lfloor x\sqrt{n+1}\right\rfloor.$$Do đó, khoản đóng góp trở thành chênh lệch của số tiền sàn:$$I_n(x) = \left\lfloor x\sqrt{n+1}\right\rfloor - \left\lfloor x\sqrt n\right\rfloor + \varepsilon_n(x),$$Ở đâu$\varepsilon_n(x)=1$chỉ khi$n$là một hình vuông lẻ (vì khi đó điểm cuối dưới là tích phân), nếu không$0$. 

Do đó, vấn đề giảm xuống còn việc đánh giá những khoản tiền lớn có dạng$$\sum_{x\le X}\lfloor x\sqrt d\rfloor.$$Đây là các tổng sàn theo trình tự Beatty / bậc hai-vô tỷ cổ điển và có thể được đánh giá theo$O(\log X)$thời gian bằng cách sử dụng quan hệ Beatty bổ sung đệ quy. 

Tổng số lẻ liên quan$n$là nhỏ:$$n \le \left(\frac{N}{M+1}\right)^2 < 250000,$$nên toàn bộ tính toán là khả thi.

## 2. Triển khai Python```python
from math import isqrt

# Sum_{k=1}^n floor(k * sqrt(d))
# Uses recursive Beatty-style reduction.
def beatty_sqrt_sum(d, n):
    if n <= 0:
        return 0

    a = isqrt(d)
    if a * a == d:
        # perfect square
        return a * n * (n + 1) // 2

    # alpha = sqrt(d)
    # beta = alpha / (alpha - floor(alpha))
    m = int((isqrt(d * n * n) + a * n) // (d - a * a))

    # Recursive complementary Beatty identity
    return (
        n * m
        + n * (n + 1) // 2 * a
        - m * (m + 1) // 2
        - beatty_sqrt_sum(d, m)
    )

def F(d, L, R):
    # Sum_{x=L}^R floor(x * sqrt(d))
    if R < L:
        return 0
    return beatty_sqrt_sum(d, R) - beatty_sqrt_sum(d, L - 1)

def R(M, N):
    ans = 0

    max_n = (N // (M + 1)) ** 2

    for n in range(1, max_n + 1, 2):

        # largest x with x*sqrt(n) <= N
        x2 = N // isqrt(n)

        # largest x with x*sqrt(n+1) <= N
        x1 = N // isqrt(n + 1)

        L = M + 1

        # region where upper bound is floor(x*sqrt(n+1))
        if x1 >= L:
            ans += (
                F(n + 1, L, x1)
                - F(n, L, x1)
            )

        # region where upper bound saturates at N
        A = max(L, x1 + 1)
        if x2 >= A:
            cnt = x2 - A + 1
            ans += cnt * N - F(n, A, x2)

        # correction when n is an odd square
        s = isqrt(n)
        if s * s == n:
            ans += max(0, x2 - L + 1)

    return ans

print(R(0, 100))       # 3019
print(R(100, 10000))  # 29750422

print(R(2_000_000, 1_000_000_000))
```--- 

## 3. Hướng dẫn sử dụng mã 

###`beatty_sqrt_sum(d, n)`Tính toán$$\sum_{k=1}^{n}\lfloor k\sqrt d\rfloor$$sử dụng danh tính Beatty bổ sung đệ quy. 

Điều này tránh việc lặp lại$10^9$.
