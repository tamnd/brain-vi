[Vấn đề dự án Euler 64](https://projecteuler.net/problem=64) 

## Giải pháp 

**Trả lời:**`1322`Đối với số nguyên không vuông$N$, sự mở rộng phân số liên tục của$\sqrt N$mang tính định kỳ. Thuật toán tiêu chuẩn để tạo phân số tiếp tục là:$$a_0=\lfloor \sqrt N \rfloor$$và sau đó đệ quy$$m_{k+1}=d_k a_k-m_k$$

$$d_{k+1}=\frac{N-m_{k+1}^2}{d_k}$$

$$a_{k+1}=\left\lfloor \frac{a_0+m_{k+1}}{d_{k+1}} \right\rfloor$$với các giá trị ban đầu$$m_0=0,\qquad d_0=1,\qquad a_0=\lfloor\sqrt N\rfloor.$$Trình tự của$a_k$cuối cùng lặp lại. Đối với căn bậc hai, một định lý cổ điển phát biểu rằng chu kỳ kết thúc chính xác khi$$a_k = 2a_0.$$Vì vậy, với mỗi hình vuông$N$, chúng ta có thể tạo các số hạng cho đến khi$a_k=2a_0$và đếm xem có bao nhiêu bước đã xảy ra. Số đó là độ dài khoảng thời gian. 

Chúng ta cần đếm xem có bao nhiêu$N \le 10000$có độ dài thời gian **lẻ**. 

--- 

## Đạo hàm toán học 

Thuật toán phân số liên tục xuất phát từ việc hợp lý hóa nhiều lần các biểu thức có dạng$$\frac1{\sqrt N - m}.$$Giả sử ở một bước nào đó chúng ta có$$\frac{\sqrt N + m_k}{d_k}.$$Chúng tôi tách phần nguyên:$$a_k = \left\lfloor \frac{a_0+m_k}{d_k}\right\rfloor,$$và viết lại:$$\frac{\sqrt N + m_k}{d_k} = a_k + \frac{\sqrt N - m_{k+1}}{d_{k+1}},$$mang lại các công thức truy hồi ở trên. 

Đối với các số vô tỷ bậc hai như$\sqrt N$, cặp trạng thái$(m_k,d_k)$cuối cùng phải lặp lại, do đó phân số tiếp tục có tính tuần hoàn. 

Một thuộc tính hữu ích cụ thể cho căn bậc hai là:$$\text{period ends when } a_k = 2a_0.$$Do đó, việc tính toán khoảng thời gian là đơn giản.

## Triển khai Python```python
import math

def continued_fraction_period(n):
    """
    Return the period length of the continued fraction
    expansion of sqrt(n).
    """
    
    a0 = int(math.isqrt(n))
    
    # Perfect squares have no periodic continued fraction
    if a0 * a0 == n:
        return 0
    
    m = 0
    d = 1
    a = a0
    
    period = 0
    
    while True:
        # Recurrence relations
        m = d * a - m
        d = (n - m * m) // d
        a = (a0 + m) // d
        
        period += 1
        
        # For square roots, the period completes at 2*a0
        if a == 2 * a0:
            break
    
    return period

count = 0

for n in range(2, 10001):
    if continued_fraction_period(n) % 2 == 1:
        count += 1

print(count)
```--- 

## Hướng dẫn về mã 

### Thiết lập chức năng```python
a0 = int(math.isqrt(n))
```Tính phần nguyên của$\sqrt n$. 

--- 

### Séc vuông hoàn hảo```python
if a0 * a0 == n:
    return 0
```Hình vuông hoàn hảo có các khai triển tận cùng, không phải là khai triển vô tỉ tuần hoàn. 

--- 

### Trạng thái ban đầu```python
m = 0
d = 1
a = a0
```Đây là những giá trị ban đầu tiêu chuẩn cho sự tái phát. 

--- 

### Tái phát chính```python
m = d * a - m
d = (n - m * m) // d
a = (a0 + m) // d
```Điều này tạo ra số hạng phân số tiếp theo. 

--- 

### Tính thời gian```python
period += 1
```Mỗi lần lặp thêm một thuật ngữ vào khối lặp. 

--- 

### Phát hiện hoàn thành```python
if a == 2 * a0:
    break
```Đối với căn bậc hai, điều này đánh dấu sự kết thúc của một khoảng thời gian đầy đủ.
