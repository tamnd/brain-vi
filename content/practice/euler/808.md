##Giải pháp 

**Trả lời:**`3807504276997394`Cho phép$n$là bình phương nguyên tố thuận nghịch (RPS). Theo định nghĩa: 

1.$n$không phải là một bảng màu, 
2.$n=p^2$cho một số nguyên tố$p$, 
3.$\operatorname{rev}(n)=q^2$cho một số nguyên tố$q$. 

Ví dụ:$$169 = 13^2,\qquad 961 = 31^2,\qquad 961=\operatorname{rev}(169)$$vậy là cả hai$169$Và$961$là những bình phương nguyên tố thuận nghịch. 

Chúng ta cần **tổng của 50** số đầu tiên như vậy. 

--- 

# Phân tích toán học 

Giả sử$$n=p^2$$Ở đâu$p$là nguyên tố. 

Chúng tôi tính toán:$$r = \operatorname{rev}(n)$$và kiểm tra xem: 

-$r \neq n$(không phải palindromic), 
-$r$là một hình vuông hoàn hảo, 
-$\sqrt r$là nguyên tố. 

Thế là đủ để mô tả các con số. 

--- 

## Những quan sát chính 

### 1. Đảo ngược giữ nguyên số chữ số 

Nếu$n$kết thúc bằng 0, việc đảo ngược sẽ loại bỏ các số 0 đứng đầu. 

Nhưng dù sao thì một hình vuông nguyên tố cũng không thể có tận cùng bằng 0, vì chỉ có bội số của$10$bình phương với số tận cùng bằng$00$. 

Vì vậy không cần xử lý đặc biệt. 

--- 

### 2. Kiểm tra bình phương hoàn hảo 

Cho$r$, chúng tôi kiểm tra:$$s = \lfloor \sqrt r \rfloor$$Sau đó:$$r \text{ is a square } \iff s^2=r$$Sau đó chúng ta chỉ cần kiểm tra xem$s$là nguyên tố. 

--- 

### 3. Phát điện hiệu quả 

Thay vì kiểm tra tất cả các số nguyên, chúng tôi chỉ tạo ra các số nguyên tố$p$, sau đó tính$p^2$. 

Điều này làm giảm đáng kể không gian tìm kiếm. 

50 giá trị RPS đầu tiên xảy ra đối với các số nguyên tố bên dưới$5\times 10^7$, điều này thật dễ dàng với một cái sàng. 

--- 

#Triển khai Python```python
from math import isqrt

def sieve(limit):
    """
    Classic sieve of Eratosthenes.
    Returns a boolean array where prime[p] is True iff p is prime.
    """
    prime = bytearray(b'\x01') * (limit + 1)
    prime[0] = prime[1] = 0

    for i in range(2, isqrt(limit) + 1):
        if prime[i]:
            start = i * i
            step = i
            prime[start:limit + 1:step] = (
                b'\x00' * (((limit - start) // step) + 1)
            )

    return prime

LIMIT = 50_000_000
prime = sieve(LIMIT)

reversible_prime_squares = []

for p, is_p in enumerate(prime):
    if not is_p:
        continue

    square = p * p

    # Reverse decimal digits
    rev_square = int(str(square)[::-1])

    # Must not be a palindrome
    if rev_square == square:
        continue

    # Check whether reversed value is also a square
    q = isqrt(rev_square)

    if q * q != rev_square:
        continue

    # Check whether sqrt(rev_square) is prime
    if q <= LIMIT and prime[q]:
        reversible_prime_squares.append(square)

# Remove duplicates and sort
reversible_prime_squares = sorted(set(reversible_prime_squares))

answer = sum(reversible_prime_squares[:50])

print(answer)
```---

## Thi công sàng```python
prime = bytearray(b'\x01') * (limit + 1)
```Ban đầu giả sử mọi số đều là số nguyên tố. 

Sau đó với mỗi số nguyên tố$i$, đánh dấu bội số của$i$như tổng hợp. 

Điều này mang lại$O(n \log\log n)$tiền xử lý.

```Ví dụ:```python
169 -> "169" -> "961" -> 961
```---
