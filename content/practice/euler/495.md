##Giải pháp 

**Trả lời:**`789107601`Cho phép$$N=n!=\prod_{p\le n} p^{e_p}, \qquad e_p=\sum_{j\ge1}\left\lfloor \frac n{p^j}\right\rfloor .$$Chúng ta phải tính số$W(N,k)$của sự phân tích không có thứ tự$$N=a_1a_2\cdots a_k$$vào trong$k$**riêng biệt** số nguyên dương. 

Đối với vấn đề này:$$N=10000!,\qquad k=30.$$--- 

# 1. Phân tích toán học 

## Bước 1: Phân tích theo thứ tự 

Giả sử chúng ta đếm theo thứ tự$k$-bộ dữ liệu$(a_1,\dots,a_k)$với sản phẩm$N$. 

Đối với mỗi số nguyên tố$p$,$$a_i=\prod_p p^{x_{i,p}}, \qquad \sum_{i=1}^k x_{i,p}=e_p.$$Vì vậy đối với số nguyên tố cố định$p$, phân phối số mũ là số lượng sao và thanh:$$\binom{e_p+k-1}{k-1}.$$Do đó số lượng các nhân tử có thứ tự là$$F_k(N)=\prod_{p\mid N}\binom{e_p+k-1}{k-1}.$$Nhưng điều này cho phép các yếu tố bình đẳng. Chúng ta cần tất cả các yếu tố khác biệt. 

--- 

## Bước 2: Bao gồm-loại trừ các đẳng thức 

Chúng tôi đếm các bộ dữ liệu có thứ tự với tất cả các mục riêng biệt. 

Cho phép$\sigma\in S_k$. 

Nếu một tuple được cố định bởi$\sigma$, sau đó các mục trong cùng một chu kỳ của$\sigma$phải bằng nhau. 

Giả định$\sigma$có độ dài chu kỳ$$\lambda=(\lambda_1,\lambda_2,\dots,\lambda_r), \qquad \sum \lambda_i=k.$$Khi đó mỗi chu kỳ tương ứng với một biến độc lập$b_i$, Và$$N=\prod_{i=1}^r b_i^{\lambda_i}.$$Đối với số mũ nguyên tố$e$, chúng ta cần số nghiệm của$$\lambda_1x_1+\cdots+\lambda_rx_r=e, \qquad x_i\ge0.$$Đây chính xác là hệ số của$t^e$TRONG$$\prod_{i=1}^r \frac1{1-t^{\lambda_i}}.$$Định nghĩa$$A_\lambda(e) = [t^e]\prod_i \frac1{1-t^{\lambda_i}}.$$Sau đó, số lượng bộ dữ liệu được cố định bằng hoán vị của loại chu trình$\lambda$là$$\prod_{p\mid N} A_\lambda(e_p).$$--- 

## Bước 3: Đảo ngược Möbius trên mạng phân vùng 

Số lượng bộ dữ liệu có thứ tự với tất cả các mục riêng biệt là$$D_k(N) = \sum_{\lambda\vdash k} (-1)^{k-\ell(\lambda)} \frac{k!}{z_\lambda} \prod_{p\mid N} A_\lambda(e_p),$$Ở đâu$$z_\lambda=\prod_j j^{m_j}m_j!,$$Và$m_j$là bội số của một phần$j$TRONG$\lambda$. 

Cuối cùng, phân tích nhân tử không có thứ tự chia cho$k!$:$$W(N,k)=\frac{D_k(N)}{k!}.$$Vì thế:$$\boxed{ W(N,k) = \sum_{\lambda\vdash k} \frac{(-1)^{k-\ell(\lambda)}}{z_\lambda} \prod_{p\mid N} A_\lambda(e_p) }$$(mô-đun$10^9+7$).

#2. Triển khai Python```python
from collections import Counter
from math import factorial
from sympy import primerange

MOD = 1_000_000_007

# ------------------------------------------------------------
# Generate integer partitions of n
# ------------------------------------------------------------
def partitions(n, mx=None):
    if mx is None or mx > n:
        mx = n

    if n == 0:
        yield []
        return

    for first in range(mx, 0, -1):
        for rest in partitions(n - first, first):
            yield [first] + rest

# ------------------------------------------------------------
# Prime exponents in n!
# ------------------------------------------------------------
def factorial_prime_exponents(n):
    exps = []

    for p in primerange(1, n + 1):
        e = 0
        m = n

        while m:
            m //= p
            e += m

        exps.append(e)

    return exps

# ------------------------------------------------------------
# Compute W(n!, k) modulo MOD
# ------------------------------------------------------------
def W_factorial(n, k):
    exps = factorial_prime_exponents(n)
    max_e = max(exps)

    fact_k = factorial(k)
    inv_fact_k = pow(fact_k, MOD - 2, MOD)

    answer = 0

    for lam in partitions(k):

        # ----------------------------------------------------
        # Compute A_lambda(e) for all e <= max_e
        #
        # dp[e] = coefficient of:
        #   product 1/(1 - x^part)
        # ----------------------------------------------------
        dp = [0] * (max_e + 1)
        dp[0] = 1

        for part in lam:
            for e in range(part, max_e + 1):
                dp[e] += dp[e - part]
                dp[e] %= MOD

        # Product over all prime exponents
        prod = 1
        for e in exps:
            prod = (prod * dp[e]) % MOD

        # z_lambda
        c = Counter(lam)

        z = 1
        for part, mult in c.items():
            z *= (part ** mult) * factorial(mult)

        # permutation count k!/z_lambda
        term = (fact_k // z) % MOD

        # sign
        if (k - len(lam)) % 2:
            term = -term

        answer = (answer + term * prod) % MOD

    answer %= MOD

    # divide by k!
    answer = (answer * inv_fact_k) % MOD

    return answer

# ------------------------------------------------------------
# Checks from the statement
# ------------------------------------------------------------
print(W_factorial(100, 10))
# 287549200

# Final answer
print(W_factorial(10000, 30))
```--- 

#3. Hướng dẫn sử dụng mã 

###`partitions(n)`Tạo tất cả các phân vùng số nguyên của$n$. 

Vì$k=30$, chỉ có$5604$phân vùng. 

--- 

###`factorial_prime_exponents(n)`Áp dụng công thức Legendre:$$e_p(n!)=\sum_{j\ge1}\left\lfloor\frac{n}{p^j}\right\rfloor.$$Vì$10000!$, có$1229$số nguyên tố. 

--- 

### Lập trình động cho$A_\lambda(e)$Đối với một phân vùng$\lambda=(\lambda_1,\dots,\lambda_r)$,$$\prod_i \frac1{1-x^{\lambda_i}}$$được mở rộng bởi DP ba lô không giới hạn:```python
for part in lam:
    for e in range(part, max_e + 1):
        dp[e] += dp[e - part]
```Sau đó:```python
dp[e]
```bằng$$A_\lambda(e).$$--- 

### Thuật ngữ bao gồm-loại trừ 

Đối với loại chu kỳ$\lambda$,$$\frac{k!}{z_\lambda}$$đếm các hoán vị với cấu trúc chu trình đó. 

Dấu hiệu là:$$(-1)^{k-\ell(\lambda)}.$$---
