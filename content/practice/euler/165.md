[Vấn đề dự án Euler 165](https://projecteuler.net/problem=165) 

## Giải pháp 

**Trả lời:**`2868868`Chúng ta phải tạo 5000 đoạn đường từ chuỗi Blum–Blum–Shub, sau đó đếm số **điểm giao nhau thực sự khác biệt** trong số tất cả các cặp đoạn. 

Những khó khăn chính là: 

1. Phát hiện chính xác xem hai đoạn thẳng có giao nhau tại một **điểm bên trong** của cả hai đoạn hay không. 
2. Tránh chạm điểm cuối và chồng chéo. 
3. Đếm chính xác các điểm giao nhau **riêng biệt**, việc này đòi hỏi số học hữu tỉ thay vì dấu phẩy động. 

--- 

# Phân tích toán học 

## 1. Tạo các phân đoạn 

Chúng tôi được trao$$s_0 = 290797,\qquad s_{n+1} = s_n^2 \pmod{50515093}$$Và$$t_n = s_n \bmod 500.$$Cứ bốn giá trị liên tiếp xác định một phân đoạn:$$(x_1,y_1)=(t_{4k+1},t_{4k+2}), \qquad (x_2,y_2)=(t_{4k+3},t_{4k+4}).$$Vì chúng ta cần 5000 phân đoạn nên chúng ta cần$20000$giá trị$t_n$. 

--- 

#2. Hình học giao điểm đoạn thẳng 

Hãy xem xét hai phân đoạn$$A=(x_1,y_1),\quad B=(x_2,y_2),$$

$$C=(x_3,y_3),\quad D=(x_4,y_4).$$Xác định vectơ$$\mathbf r = B-A, \qquad \mathbf s = D-C.$$Hai đường vô hạn cắt nhau$$\mathbf r \times \mathbf s \neq 0.$$Nếu tích chéo bằng 0 thì các đường thẳng song song (có thể thẳng hàng) và không có điểm giao nhau thực sự. 

--- 

## Dạng tham số 

Viết các dòng như$$A+t\mathbf r, \qquad C+u\mathbf s.$$Giao lộ xảy ra tại$$A+t\mathbf r = C+u\mathbf s.$$Sử dụng sản phẩm chéo:$$t = \frac{(C-A)\times \mathbf s}{\mathbf r\times \mathbf s},$$

$$u = \frac{(C-A)\times \mathbf r}{\mathbf r\times \mathbf s}.$$Điểm là điểm **bên trong** của đoạn nếu tham số nằm hoàn toàn trong khoảng từ 0 đến 1:$$0<t<1,\qquad 0<u<1.$$Điều này tự động loại trừ các nút giao điểm cuối. 

--- 

#3. Tính toán chính xác 

Tọa độ giao điểm là số hữu tỷ:$$P = A+t\mathbf r.$$Việc sử dụng dấu phẩy động sẽ có nguy cơ làm tròn những khác biệt nhỏ, khiến các điểm trùng lặp được tính riêng. 

Vì vậy, chúng tôi sử dụng số học hợp lý chính xác với Python`Fraction`. 

Mỗi điểm giao nhau được lưu dưới dạng:$$\left(\frac{p_x}{q_x},\frac{p_y}{q_y}\right)$$tự động ở dạng rút gọn. 

Sau đó, các điểm khác biệt có thể được tính bằng Python`set`. 

--- 

# 4. Độ phức tạp 

có$$\binom{5000}{2}=12,\!497,\!500$$các cặp phân đoạn. 

Đối với mỗi cặp, chúng tôi thực hiện số học số nguyên theo thời gian không đổi, điều này khả thi trong Python được tối ưu hóa. 

--- 

#Triển khai Python```python
from fractions import Fraction

# ------------------------------------------------------------
# Generate the 5000 line segments
# ------------------------------------------------------------

MOD = 50515093

s = 290797
t = []

# Need 20000 values
for _ in range(20000):
    s = (s * s) % MOD
    t.append(s % 500)

segments = []

for i in range(0, 20000, 4):
    x1, y1, x2, y2 = t[i:i+4]
    segments.append((x1, y1, x2, y2))

# ------------------------------------------------------------
# Helper: 2D cross product
# ------------------------------------------------------------

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

# ------------------------------------------------------------
# Compute all distinct true intersection points
# ------------------------------------------------------------

points = set()

n = len(segments)

for i in range(n):
    x1, y1, x2, y2 = segments[i]

    rx = x2 - x1
    ry = y2 - y1

    for j in range(i + 1, n):
        x3, y3, x4, y4 = segments[j]

        sx = x4 - x3
        sy = y4 - y3

        denom = cross(rx, ry, sx, sy)

        # Parallel or collinear -> no unique true intersection
        if denom == 0:
            continue

        qpx = x3 - x1
        qpy = y3 - y1

        t_num = cross(qpx, qpy, sx, sy)
        u_num = cross(qpx, qpy, rx, ry)

        # We need strict interior intersections:
        # 0 < t < 1 and 0 < u < 1
        if denom > 0:
            if not (0 < t_num < denom and 0 < u_num < denom):
                continue
        else:
            if not (0 > t_num > denom and 0 > u_num > denom):
                continue

        # Compute exact rational coordinates
        t_frac = Fraction(t_num, denom)

        px = Fraction(x1) + t_frac * rx
        py = Fraction(y1) + t_frac * ry

        points.add((px, py))

print(len(points))
```--- 

# Hướng dẫn sử dụng mã 

## Tạo trình tự```python
s = (s * s) % MOD
t.append(s % 500)
```Điều này thực hiện chính xác phép truy toán Blum–Blum–Shub. 

--- 

## Xây dựng các phân đoạn```python
x1, y1, x2, y2 = t[i:i+4]
```Cứ bốn giá trị liên tiếp xác định một phân đoạn. 

--- 

## Sản phẩm chéo```python
def cross(ax, ay, bx, by):
    return ax * by - ay * bx
```Tích chéo xác định hướng và liệu hai hướng có song song hay không. 

--- 

## Phát hiện đường thẳng song song```python
if denom == 0:
    continue
```Nếu như$$\mathbf r \times \mathbf s = 0,$$các đường thẳng song song hoặc thẳng hàng nên không thể có một giao điểm bên trong thực sự duy nhất. 

--- 

##Kiểm tra giao lộ nội thất 

Các thông số là:```python
t_num = cross(qpx, qpy, sx, sy)
u_num = cross(qpx, qpy, rx, ry)
```với mẫu số`denom`. 

Thay vì chia, chúng ta so sánh trực tiếp các dấu hiệu:```python
0 < t_num < denom
```(hoặc đảo ngược bất đẳng thức nếu mẫu số âm). 

Điều này tránh việc tạo ra phân số không cần thiết. 

--- 

## Tọa độ chính xác```python
t_frac = Fraction(t_num, denom)
```Sau đó```python
px = x1 + t_frac * rx
py = y1 + t_frac * ry
```đưa ra điểm giao nhau hợp lý chính xác. 

Bộ này tự động loại bỏ các bản sao.
