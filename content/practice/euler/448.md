[Vấn đề dự án Euler 448](https://projecteuler.net/problem=448) 

## Giải pháp 

**Trả lời:**`106467648`Cho phép$$A(n)=\frac1n\sum_{i=1}^n \operatorname{lcm}(n,i), \qquad S(n)=\sum_{k=1}^n A(k).$$Chúng tôi cần$$S(99999999019)\pmod{999999017}.$$--- 

# 1. Phân tích toán học 

Chúng ta bắt đầu từ danh tính$$\operatorname{lcm}(a,b)=\frac{ab}{\gcd(a,b)}.$$Vì thế$$A(n) = \frac1n \sum_{i=1}^n \frac{ni}{\gcd(n,i)} = \sum_{i=1}^n \frac{i}{\gcd(n,i)}.$$--- 

## Bước 1: Nhóm theo gcd 

hãy để$$d=\gcd(n,i).$$Viết$$i=d m,\qquad n=d t,$$với$\gcd(m,t)=1$. 

Sau đó$$\frac{i}{\gcd(n,i)}=\frac{dm}{d}=m.$$Kể từ đây$$A(n) = \sum_{d\mid n} \sum_{\substack{1\le m\le n/d\\ \gcd(m,n/d)=1}} m.$$Cho phép$t=n/d$. Sau đó$$A(n) = \sum_{t\mid n} \sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m.$$--- 

## Bước 2: Tổng dư lượng giảm 

Một kết quả cổ điển: 

cho$t>1$,$$\sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m = \frac{t\varphi(t)}2.$$(Dư lượng đi theo cặp$m$Và$t-m$.)

Vì$t=1$, tổng là$1$. 

Định nghĩa$$f(t)= \sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m.$$Sau đó$$f(1)=1,\qquad f(t)=\frac{t\varphi(t)}2 \quad (t>1).$$Vì thế$$A(n)=\sum_{d\mid n} f(d).$$Như vậy$$S(N) = \sum_{n\le N}\sum_{d\mid n} f(d).$$Hoán đổi thứ tự:$$S(N) = \sum_{d\le N} f(d)\left\lfloor \frac{N}{d}\right\rfloor.$$Thay thế$f(d)$:$$S(N) = 1\cdot N + \frac12 \sum_{d=2}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$Tương đương,$$S(N) = \frac12 \left( N+ \sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor \right).$$Vì vậy toàn bộ vấn đề quy về tính toán$$F(N)=\sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$--- 

#2. Tính tổng nhanh 

Chúng tôi cần$$H(n)=\sum_{k\le n} k\varphi(k).$$Sau đó chúng ta có thể đánh giá$F(N)$sử dụng nhóm chia:$$F(N) = \sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$Giá trị của$\left\lfloor N/d\right\rfloor$không đổi trong các khoảng:$$\left\lfloor \frac{N}{d}\right\rfloor = q$$vì$$d\in[L,R].$$Kể từ đây$$F(N) = \sum q\,(H(R)-H(L-1)).$$Điều này mang lại một$O(\sqrt N)$thuật toán. 

--- 

## Bước 3: Tính toán$H(n)$Sử dụng danh tính$$\sum_{d\mid n}\varphi(d)=n.$$nhân với$n$,$$\sum_{d\mid n} d\varphi(d)$$có cấu trúc tích chập Dirichlet dẫn đến sự tái diễn$$H(n) = \sum_{k=1}^n k^2 - \sum_{l=2}^n \left(\sum_{i=l}^r i\right) H\!\left(\left\lfloor\frac nl\right\rfloor\right).$$Việc nhóm các thương số bằng nhau sẽ cho một$O(\sqrt n)$đệ quy được ghi nhớ. 

--- 

#3. Triển khai Python```python
MOD = 999999017
N = 99999999019

INV2 = pow(2, MOD - 2, MOD)
INV6 = pow(6, MOD - 2, MOD)

# Sieve limit
M = 20_000_000

# ------------------------------------------------------------
# Euler phi sieve
# ------------------------------------------------------------

phi = list(range(M + 1))

for p in range(2, M + 1):
    if phi[p] == p:          # p is prime
        for k in range(p, M + 1, p):
            phi[k] -= phi[k] // p

# ------------------------------------------------------------
# Prefix sums:
# H(n) = sum_{k<=n} k * phi(k)
# ------------------------------------------------------------

prefix = [0] * (M + 1)

for i in range(1, M + 1):
    prefix[i] = (prefix[i - 1] + i * phi[i]) % MOD

# ------------------------------------------------------------
# Sum of squares:
# 1^2 + 2^2 + ... + n^2
# ------------------------------------------------------------

def sum_sq(n):
    n %= MOD
    return n * (n + 1) % MOD * (2 * n + 1) % MOD * INV6 % MOD

# ------------------------------------------------------------
# Memoized computation of H(n)
# ------------------------------------------------------------

memo = {}

def H(n):
    if n <= M:
        return prefix[n]

    if n in memo:
        return memo[n]

    ans = sum_sq(n)

    l = 2
    while l <= n:
        q = n // l
        r = n // q

        # sum_{i=l}^r i
        block_sum = (l + r) % MOD
        block_sum = block_sum * ((r - l + 1) % MOD) % MOD
        block_sum = block_sum * INV2 % MOD

        ans -= block_sum * H(q)
        ans %= MOD

        l = r + 1

    memo[n] = ans
    return ans

# ------------------------------------------------------------
# Compute:
# F(N) = sum d*phi(d)*floor(N/d)
# using quotient grouping
# ------------------------------------------------------------

def solve(N):
    total = 0

    l = 1
    while l <= N:
        q = N // l
        r = N // q

        total += q * (H(r) - H(l - 1))
        total %= MOD

        l = r + 1

    # S(N) = (N + F(N)) / 2
    return ((total + N) % MOD) * INV2 % MOD

print(solve(N))
```--- 

#4. Hướng dẫn code 

###Sàng phi```python
phi = list(range(M + 1))
```Khởi tạo$\varphi(n)=n$. 

Đối với mỗi số nguyên tố$p$,```python
phi[k] -= phi[k] // p
```áp dụng$$\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).$$--- 

### Tổng tiền tố```python
prefix[i] = prefix[i - 1] + i * phi[i]
```cửa hàng$$H(i)=\sum_{k\le i} k\varphi(k).$$--- 

###Đệ quy$H(n)$Sự truy hồi tính toán các giá trị lớn của$H(n)$trong khoảng$O(\sqrt n)$thời gian sử dụng nhóm thương số. 

Ghi nhớ tránh tính toán lại. 

--- 

### Tổng kết cuối cùng 

Vòng lặp```python
q = N // l
r = N // q
```nhóm tất cả các chỉ số có cùng thương số. 

Điều này làm giảm sự phức tạp từ$O(N)$đại khái$O(\sqrt N)$.
