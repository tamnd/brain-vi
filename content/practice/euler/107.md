[Vấn đề dự án Euler 107](https://projecteuler.net/problem=107) 

##Giải pháp 

**Trả lời:**`259679`Vấn đề này là một vấn đề **cây bao trùm tối thiểu** cổ điển. 

Chúng ta được cho một đồ thị vô hướng có trọng số được kết nối. 

Chúng tôi muốn loại bỏ càng nhiều cạnh thừa càng tốt trong khi vẫn giữ cho đồ thị được kết nối. 

Thực tế quan trọng là: 

> Trong số tất cả các sơ đồ con được kết nối, sơ đồ con có tổng trọng lượng tối thiểu là **Cây bao trùm tối thiểu (MST)**. 

Vì thế:$$\text{maximum saving} = \text{(total weight of original graph)} - \text{(weight of MST)}$$--- 

# Phân tích toán học 

Giả sử đồ thị có: 

-$V$đỉnh 
-$E$các cạnh vô hướng có trọng số 

Cây bao trùm: 

- kết nối tất cả các đỉnh, 
- không chứa chu kỳ, 
- luôn luôn có chính xác$V-1$các cạnh. 

Bất kỳ lợi thế bổ sung nào ngoài điều này đều là dư thừa nếu kết nối được duy trì. 

Vì vậy ta phải tính: 

1. Tổng trọng lượng của mạng ban đầu 
2. Trọng lượng của cây bao trùm tối thiểu 

Sau đó trừ đi. 

--- 

## Thuật toán Kruskal 

Thuật toán MST tiêu chuẩn là **thuật toán Kruskal**. 

### Nguyên tắc 

1. Sắp xếp tất cả các cạnh theo trọng số tăng dần. 
2. Thêm liên tục cạnh nhỏ nhất **không** tạo thành chu trình. 
3. Dừng lại sau khi chọn$V-1$các cạnh. 

Để phát hiện chu kỳ một cách hiệu quả, chúng tôi sử dụng cấu trúc **Disjoint Set Union (Union-Find)**. 

--- 

# Ví dụ nhỏ từ bài toán 

Trọng lượng đồ thị ban đầu là:$$243$$Mạng kết nối tối ưu có trọng số:$$93$$Do đó số tiền tiết kiệm được là:$$243 - 93 = 150$$phù hợp với tuyên bố.

# Triển khai Python```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        # Path compression
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)

        if ra == rb:
            return False

        # Union by rank
        if self.rank[ra] < self.rank[rb]:
            self.parent[ra] = rb
        elif self.rank[ra] > self.rank[rb]:
            self.parent[rb] = ra
        else:
            self.parent[rb] = ra
            self.rank[ra] += 1

        return True

# Read the matrix
with open("network.txt") as f:
    rows = [line.strip().split(",") for line in f]

n = len(rows)

edges = []
total_weight = 0

# Extract undirected edges once (i < j)
for i in range(n):
    for j in range(i + 1, n):
        if rows[i][j] != "-":
            w = int(rows[i][j])
            edges.append((w, i, j))
            total_weight += w

# Kruskal's algorithm
edges.sort()

dsu = DSU(n)
mst_weight = 0

for w, u, v in edges:
    if dsu.union(u, v):
        mst_weight += w

saving = total_weight - mst_weight

print(saving)
```---
