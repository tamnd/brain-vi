##Giải pháp 

**Trả lời:**`709`## 1. Phân tích toán học 

Chúng tôi muốn xác định dòng nào của tệp chứa **giá trị lớn nhất** của$$a^b$$trong đó mỗi dòng chứa một cặp cơ số/số mũ$(a,b)$. 

Việc so sánh trực tiếp là không thể vì những con số như$$632382^{518061}$$chứa hàng triệu chữ số. 

Nhận xét quan trọng là **logarit bảo toàn thứ tự**. 

Nếu như$$x > y,$$sau đó$$\log(x) > \log(y).$$Vì vậy thay vì so sánh$$a^b \quad \text{and} \quad c^d,$$chúng tôi so sánh logarit của chúng:$$\log(a^b) = b\log(a)$$Và$$\log(c^d) = d\log(c).$$Như vậy,$$a^b > c^d \iff b\log(a) > d\log(c).$$Điều này biến việc so sánh không thể thực hiện được giữa các số nguyên khổng lồ thành việc so sánh các số có dấu phẩy động thông thường. 

### Ví dụ từ bài toán 

So sánh:$$632382^{518061} \quad \text{vs} \quad 519432^{525806}$$Chúng tôi so sánh:$$518061\log(632382)$$Và$$525806\log(519432).$$Điểm logarit lớn hơn tương ứng với giá trị hàm mũ lớn hơn. Điều này tránh việc tự mình tính toán những con số khổng lồ. 

--- 

## 2. Triển khai Python```python
from math import log

# Read the file
with open("base_exp.txt") as f:
    lines = f.readlines()

max_value = float("-inf")
max_line = 0

# Enumerate starting at 1 because Project Euler line numbers are 1-based
for line_number, line in enumerate(lines, start=1):
    base, exponent = map(int, line.strip().split(","))

    # Compare exponent * log(base)
    value = exponent * log(base)

    if value > max_value:
        max_value = value
        max_line = line_number

print(max_line)
```---

### Tính toán số liệu so sánh```python

```Bởi vì:$$\log(a^b)=b\log(a)$$Điều này mang lại một số điểm tương đương mà không cần xây dựng con số khổng lồ.

### Cập nhật tối đa```python

    max_value = value

```Bất cứ khi nào chúng tôi tìm thấy giá trị số mũ lớn hơn, chúng tôi sẽ nhớ số dòng của nó. 

--- 

### Xác minh ví dụ nhỏ 

Vấn đề cho biết hai dòng đầu tiên là:$$632382^{518061}$$Và$$519432^{525806}$$Máy tính:$$518061\log(632382)$$so với$$525806\log(519432)$$cho thấy số lượng đầu tiên lớn hơn, xác nhận:$$632382^{518061} > 519432^{525806}.$$Vì vậy, phương thức hoạt động chính xác trên ví dụ được cung cấp.
