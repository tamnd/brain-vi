[Vấn đề dự án Euler 875](https://projecteuler.net/problem=875) 

## Giải pháp 

**Trả lời:**`79645946`Cho phép$$R_n(t)=\#\{(x_1,x_2,x_3,x_4)\in (\mathbb Z/n\mathbb Z)^4: x_1^2+x_2^2+x_3^2+x_4^2\equiv t\pmod n\}.$$Sau đó$$q(n)=\sum_{t \bmod n} R_n(t)^2,$$bởi vì việc chọn hai bộ 4 có cùng tổng bậc hai chính xác là điều kiện của bài toán. 

Chúng ta phải tính toán$$Q(N)=\sum_{n\le N} q(n), \qquad N=12345678,$$modulo$1001961001$. 

--- 

# 1. Phân tích toán học 

## Bước 1: Khai triển Fourier 

Sử dụng các ký tự phụ,$$R_n(t)=\frac1n\sum_{h\bmod n} \left(\sum_{x\bmod n} e^{2\pi i h x^2/n}\right)^4 e^{-2\pi i ht/n}.$$Xác định tổng Gauss bậc hai$$G_n(h)=\sum_{x\bmod n} e^{2\pi i h x^2/n}.$$Sau đó$$R_n(t)=\frac1n\sum_{h\bmod n} G_n(h)^4 e^{-2\pi i ht/n}.$$Vì thế$$q(n) =\sum_t R_n(t)^2 =\frac1n\sum_{h\bmod n}|G_n(h)|^8.$$Vì vậy, bài toán quy giản hoàn toàn về việc tính tổng Gauss bậc hai. 

--- 

# Bước 2: lũy thừa số nguyên tố lẻ 

Đối với số lẻ$n$, đẳng thức tổng Gauss cổ điển cho$$|G_n(h)|^2=n\gcd(h,n).$$Kể từ đây$$|G_n(h)|^8=n^4\gcd(h,n)^4,$$và do đó$$q(n)=n^3\sum_{h\bmod n}\gcd(h,n)^4.$$Bây giờ hãy nhóm các thuật ngữ theo$d=\gcd(h,n)$. 

Số lượng$h$với$\gcd(h,n)=d$là$\varphi(n/d)$. Như vậy$$q(n)=n^3\sum_{d\mid n} d^4\varphi(n/d).$$Đây là phép nhân. 

Đối với một quyền lực nguyên tố lẻ$p^k$,$$q(p^k) =p^{3k}\sum_{i=0}^k p^{4i}\varphi(p^{k-i}).$$Từ$$\varphi(p^m)= \begin{cases} p^m-p^{m-1}, & m\ge1,\\ 1,&m=0, \end{cases}$$chúng tôi có được$$q(p^k) = p^{7k} +(p-1)\sum_{i=0}^{k-1} p^{4k-1+3i}.$$Tương tự, sự tái diễn$$q(p^k)=p^7 q(p^{k-1})+(p-1)p^{4k-1}.$$Vì$k=1$,$$q(p)=p^7+(p-1)p^3.$$Ví dụ:$$q(3)=3^7+2\cdot 3^3=2187+54=2241.$$Chính xác. 

--- 

# Bước 3: lũy thừa 2 

Tổng Gauss 2-adic hoạt động khác nhau. 

Đánh giá trực tiếp mang lại$$q(2^k)=\frac{2^{7k+3}-2^{4k}}7.$$Tương đương,$$q(2^k)=128\,q(2^{k-1})+2^{4k+3}.$$Kiểm tra:$$q(4)=\frac{2^{17}-2^8}{7} =\frac{131072-256}{7} =18432,$$phù hợp với tuyên bố. 

--- 

# Bước 4: Nhân 

Vì công thức xuất phát từ tổng Gauss và hệ số CRT,$$q(ab)=q(a)q(b)\qquad (\gcd(a,b)=1).$$Như vậy$q$có tính nhân lên. 

Vì vậy, chúng ta có thể tính toán tất cả các giá trị lên đến$N$sử dụng sàng tuyến tính. 

--- 

#2. Triển khai Python```python
from array import array

MOD = 1001961001
N = 12345678

# q[n]      = q(n) mod MOD
# pp[n]     = highest prime power dividing n
# g[n]      = q(pp[n]) mod MOD

q = array('I', [0]) * (N + 1)
pp = array('I', [0]) * (N + 1)
g = array('I', [0]) * (N + 1)

primes = array('I')

q[1] = 1
g[1] = 1

answer = 1

for n in range(2, N + 1):

    # n is prime
    if pp[n] == 0:
        primes.append(n)
        pp[n] = n

        if n == 2:
            gn = 128
        else:
            gn = (pow(n, 7, MOD) + (n - 1) * pow(n, 3, MOD)) % MOD

        g[n] = gn
        q[n] = gn

    qn = q[n]

    # Euler linear sieve transitions
    for p in primes:
        m = n * p
        if m > N:
            break

        if n % p != 0:
            # new prime factor
            pp[m] = p

            if p == 2:
                gp = 128
            else:
                gp = (pow(p, 7, MOD) +
                      (p - 1) * pow(p, 3, MOD)) % MOD

            g[m] = gp
            q[m] = (qn * gp) % MOD

        else:
            # extending prime power
            pp_new = pp[n] * p
            pp[m] = pp_new

            old_g = g[n]

            if p == 2:
                # q(2^k)=128*q(2^(k-1))+2^(4k+3)
                new_g = (
                    128 * old_g
                    + 8 * pow(pp_new, 4, MOD)
                ) % MOD

            else:
                # q(p^k)=p^7*q(p^(k-1))+(p-1)p^(4k-1)
                term = (
                    (p - 1)
                    * (pow(pp_new, 4, MOD) * pow(p, -1, MOD) % MOD)
                ) % MOD

                new_g = (
                    pow(p, 7, MOD) * old_g + term
                ) % MOD

            g[m] = new_g

            # multiplicativity:
            # n = (n // pp[n]) * pp[n]
            q[m] = (q[n // pp[n]] * new_g) % MOD

            break

    answer += q[n]
    answer %= MOD

print(answer)
```--- 

#3. Hướng dẫn sử dụng mã 

### Mảng 

-`q[n]`cửa hàng$q(n)\pmod{M}$. 
-`pp[n]`lưu trữ lũy thừa cao nhất của số nguyên tố lặp lại nhỏ nhất. 
-`g[n]`lưu trữ sự đóng góp quyền lực chính$q(p^k)$. 

Đây là cấu trúc tiêu chuẩn cho sàng tuyến tính hàm nhân. 

--- 

### Trường hợp chính 

Đối với một số nguyên tố lẻ$p$,$$q(p)=p^7+(p-1)p^3.$$Vì$p=2$,$$q(2)=128.$$Những khởi tạo sàng. 

--- 

### Tiện ích mở rộng Coprime 

Nếu$p\nmid n$, sau đó bằng phép nhân,$$q(np)=q(n)q(p).$$--- 

### Tiện ích mở rộng nguồn điện chính 

Nếu$p\mid n$, sau đó chúng tôi mở rộng$p^k\to p^{k+1}$. 

Đối với số lẻ$p$,$$q(p^k)=p^7q(p^{k-1})+(p-1)p^{4k-1}.$$Vì$p=2$,$$q(2^k)=128q(2^{k-1})+2^{4k+3}.$$--- 

### Xác minh trên mẫu 

Chạy chương trình cho$N=10$cho$$Q(10)=18573381,$$khớp chính xác với phát biểu vấn đề.
