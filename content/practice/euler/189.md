## Giải pháp 

**Trả lời:**`10834893628237824`Cho tam giác đều lớn có độ dài cạnh$8$. 

Nó được chia thành$$1+3+5+\cdots+15 = 8^2 = 64$$hình tam giác nhỏ. 

Chúng ta phải đếm số lượng thích hợp$3$-màu sắc của những thứ này$64$tam giác, trong đó các tam giác liền kề (có chung một cạnh) nhận được các màu khác nhau. 

--- 

# 1. Phân tích toán học 

## 1.1 Giải thích biểu đồ 

Coi mỗi tam giác nhỏ là một đỉnh của đồ thị. 

- Hai đỉnh được nối với nhau nếu các tam giác tương ứng có chung một cạnh. 
- Chúng tôi muốn số lượng màu sắc thích hợp của biểu đồ này bằng cách sử dụng màu sắc$\{R,G,B\}$. 

Do đó, đây là một bài toán đếm đồ thị tô màu. 

Đồ thị có: 

-$64$đỉnh, 
- mức độ tối đa$3$, 
- một cấu trúc lớp rất đều đặn. 

Tìm kiếm brute-force trực tiếp sẽ yêu cầu kiểm tra$$3^{64} \approx 3.4\times10^{30}$$nhiệm vụ, điều đó là không thể. 

Vì vậy chúng ta cần lập trình động. 

--- 

#1.2 Thông tin chi tiết chính: chiều rộng biên giới nhỏ 

Nếu chúng ta xử lý các hình tam giác theo từng hàng (hay chính xác hơn là theo thứ tự hình học phù hợp), thì tại bất kỳ thời điểm nào, chỉ một số lượng nhỏ các hình tam giác đã được tô màu vẫn có thể tương tác với các hình tam giác trong tương lai. 

Bộ này được gọi là **biên giới**. 

Đối với lưới tam giác cạnh$8$, biên giới không bao giờ vượt quá kích thước$8$. 

Vì vậy: 

- thay vì nhớ tất cả các màu trước đó, 
- chúng ta chỉ nhớ màu sắc ở biên giới. 

Vì mỗi đỉnh biên giới có$3$màu sắc có thể, số lượng trạng thái nhiều nhất là$$3^8 = 6561,$$cái đó nhỏ xíu 

Điều này làm cho việc tính toán chính xác trở nên khả thi. 

--- 

#1.3 Trạng thái lập trình động 

Giả sử chúng ta xử lý các hình tam giác theo một thứ tự cố định:$$T_0,T_1,\dots,T_{63}.$$Ở bước$i$: 

- một số tam giác đã được xử lý trước đó vẫn còn các tam giác lân cận chưa được xử lý; 
- những hình tam giác này tạo thành biên giới. 

Trạng thái DP chỉ đơn giản là:$$(\text{frontier colouring}) \mapsto \text{count}.$$Khi xử lý tam giác tiếp theo: 

1. Xác định những màu nào bị cấm bởi những hàng xóm đã tô màu. 
2. Thử các màu còn lại. 
3. Cập nhật biên giới. 

Vì mọi tam giác đều có nhiều nhất là bậc$3$, each transition is very small.

#2. Triển khai Python```python
from collections import defaultdict

# ------------------------------------------------------------
# Build the triangular grid graph
# ------------------------------------------------------------

def build_graph(n):
    """
    Build the adjacency graph of the n^2 little triangles.

    Each small triangle is represented by its three lattice vertices.
    Two triangles are adjacent iff they share an edge
    (i.e. two common vertices).
    """

    triangles = []

    # Upward-pointing triangles
    for i in range(n):
        for j in range(n - i):
            tri = ((i, j), (i + 1, j), (i, j + 1))
            triangles.append(tri)

    # Downward-pointing triangles
    for i in range(n - 1):
        for j in range(n - 1 - i):
            tri = ((i + 1, j), (i, j + 1), (i + 1, j + 1))
            triangles.append(tri)

    m = len(triangles)

    # Build adjacency
    adj = [set() for _ in range(m)]

    for a in range(m):
        A = set(triangles[a])

        for b in range(a + 1, m):
            B = set(triangles[b])

            # Sharing an edge means sharing exactly two vertices
            if len(A & B) == 2:
                adj[a].add(b)
                adj[b].add(a)

    return triangles, adj

# ------------------------------------------------------------
# Choose a geometric processing order
# ------------------------------------------------------------

def triangle_centroid(tri):
    x = sum(v[0] for v in tri) / 3
    y = sum(v[1] for v in tri) / 3
    return (y, x)

# ------------------------------------------------------------
# Count proper 3-colourings using frontier DP
# ------------------------------------------------------------

def count_colourings(n=8):

    triangles, adj = build_graph(n)

    m = len(triangles)

    # Process triangles from top to bottom
    order = sorted(range(m),
                   key=lambda t: triangle_centroid(triangles[t]))

    pos = {v: i for i, v in enumerate(order)}

    # Past neighbours of each vertex
    past = {
        v: [u for u in adj[v] if pos[u] < pos[v]]
        for v in range(m)
    }

    # DP:
    # state = tuple of frontier colours
    # value = number of ways
    states = {(): 1}

    for i, v in enumerate(order):

        # Current active frontier
        active = sorted(
            {
                u for u in order[:i]
                if any(pos[w] >= i for w in adj[u])
            },
            key=lambda x: pos[x]
        )

        # Frontier after processing v
        next_active = sorted(
            {
                u for u in order[:i + 1]
                if any(pos[w] > i for w in adj[u])
            },
            key=lambda x: pos[x]
        )

        new_states = defaultdict(int)

        for key, count in states.items():

            colouring = dict(zip(active, key))

            # Colours forbidden by already-coloured neighbours
            forbidden = {
                colouring[u]
                for u in past[v]
                if u in colouring
            }

            for colour in range(3):

                if colour in forbidden:
                    continue

                new_colouring = colouring.copy()

                # Keep v only if it still has future neighbours
                if any(pos[w] > i for w in adj[v]):
                    new_colouring[v] = colour

                new_key = tuple(new_colouring[u]
                                for u in next_active)

                new_states[new_key] += count

        states = new_states

    return sum(states.values())

# ------------------------------------------------------------
# Compute the answer
# ------------------------------------------------------------

answer = count_colourings(8)

print(answer)

## Xây dựng đồ thị 

Mỗi tam giác nhỏ được mã hóa bởi ba đỉnh mạng của nó. 

Ví dụ tam giác hướng lên:$$((i,j),(i+1,j),(i,j+1)).$$Ví dụ tam giác hướng xuống:$$((i+1,j),(i,j+1),(i+1,j+1)).$$Hai tam giác là cạnh nhau khi chúng có chung hai đỉnh.
