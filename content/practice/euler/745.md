[Vấn đề dự án Euler 745](https://projecteuler.net/problem=745) 

## Giải pháp 

**Trả lời:**`94586478`Cho phép$$g(n)=\text{largest perfect square dividing } n.$$Mọi số nguyên dương đều có thể viết duy nhất dưới dạng$$n = s\,t^2$$với$s$Squarefree. Vì thế,$$g(n)=t^2.$$Kể từ đây$$S(N)=\sum_{n\le N} g(n)      =\sum_{t\le \sqrt N} t^2 \cdot Q\!\left(\left\lfloor\frac N{t^2}\right\rfloor\right),$$Ở đâu$Q(x)$đếm số nguyên vuông góc$\le x$. 

Sử dụng nghịch đảo Mobius,$$Q(x)=\sum_{d^2\le x}\mu(d)\left\lfloor \frac{x}{d^2}\right\rfloor.$$Việc thay thế và sắp xếp lại mang lại$$S(N) =\sum_{k\le \sqrt N} \left\lfloor \frac N{k^2}\right\rfloor \sum_{d\mid k} d^2\mu(k/d).$$Tổng bên trong là hàm tổng Jordan$J_2(k)$:$$J_2(k)=k^2\prod_{p\mid k}\left(1-\frac1{p^2}\right).$$Vì vậy, vấn đề giảm xuống$$S(N)=\sum_{k\le \sqrt N} J_2(k)\left\lfloor \frac N{k^2}\right\rfloor.$$Chúng tôi tính toán$J_2(k)$cho tất cả$k\le 10^7$bằng sàng tuyến tính.```python
from array import array

MOD = 1_000_000_007
N = 10**14
V = int(N**0.5)

# Linear sieve for Jordan totient J2(n)
J2 = array('Q', [0]) * (V + 1)
J2[1] = 1

primes = array('I')
is_comp = bytearray(V + 1)

for i in range(2, V + 1):

    if not is_comp[i]:
        primes.append(i)
        J2[i] = i * i - 1

    for p in primes:
        x = i * p
        if x > V:
            break

        is_comp[x] = 1

        if i % p == 0:
            # J2(ip) = J2(i) * p^2 when p divides i
            J2[x] = J2[i] * p * p
            break
        else:
            # multiplicative step
            J2[x] = J2[i] * (p * p - 1)

# Compute S(N)
ans = 0

for k in range(1, V + 1):
    ans += (N // (k * k)) * J2[k]
    ans %= MOD

print(ans)
```### Hướng dẫn 

-`J2[n]`cửa hàng Jordan totient$J_2(n)$. 
- Sàng tuyến tính tính toán tất cả các giá trị lên đến$10^7$. 
- Cuối cùng chúng tôi đánh giá$$\sum_{k\le 10^7} J_2(k)\left\lfloor\frac{10^{14}}{k^2}\right\rfloor \pmod{1\,000\,000\,007}.$$### Séc nhỏ 

cho$N=10$:$$S(10)=24$$Vì$N=100$:$$S(100)=767$$phù hợp với phát biểu vấn đề.
