## Giải pháp 

**Trả lời:**`14854003484704`Hãy để mạng lục giác được xác định bằng số nguyên Eisenstein$$\Lambda=\{a+b\omega : a,b\in \mathbb Z,\ \omega=e^{i\pi/3}\},$$với chuẩn bậc hai$$N(a+b\omega)=a^2+ab+b^2.$$Do đó, bình phương khoảng cách giữa các điểm mạng chính xác là giá trị của$$Q(x,y)=x^2+xy+y^2.$$Chúng ta phải đếm các hình tam giác: 

- với các đỉnh trong$\Lambda$, 
- với incentre cũng có trong$\Lambda$, 
- có ít nhất một$60^\circ$góc, 
- chỉ tính vào bản dịch, 
- nhưng với các góc quay/phản xạ được tính riêng. 

--- 

# 1. Hình học của một$60^\circ$tam giác trên mạng lục giác 

Đặt$60^\circ$đỉnh tại gốc tọa độ. 

Gọi hai cạnh kề với góc đó là vectơ$u,v\in\Lambda$, với góc$60^\circ$giữa họ. 

Sử dụng cơ sở mạng, mọi cặp như vậy có thể được tham số hóa bằng hai số nguyên nguyên tố cùng nhau$k>l>0$:$$u=(k,l),\qquad v=(l,k).$$Độ dài các cạnh trở thành$$|u|=\sqrt{k^2+kl+l^2},\qquad |v|=\sqrt{k^2+kl+l^2},$$và cạnh thứ ba có độ dài$$|u-v|=\sqrt{k^2-kl+l^2}.$$Định nghĩa$$s=\sqrt{k^2-kl+l^2}.$$Điều kiện tam giác có lực hướng tâm$s\in\mathbb Z$. 

Bán kính của một$60^\circ$tam giác thỏa mãn$$r=\frac{\sqrt3}{2}\cdot \frac{ab}{a+b+c},$$và sau khi thay thế tham số hóa ở trên, người ta thu được$$r^2=\frac{Q(p)}{12d^2},$$Ở đâu$$d=k+l-s,$$Và$p$là một vectơ mạng nguyên thủy. 

Do đó, việc đếm các tam giác đáng chú ý sẽ giảm xuống việc đếm các vectơ mạng thỏa mãn$$Q(p)\le \frac{12R^2}{d^2}.$$--- 

#2. Cấu trúc số học 

Các nghiệm số nguyên của$$k^2-kl+l^2=s^2$$chia thành hai gia đình. 

--- 

## Gia đình 1$$d=3uv,$$Ở đâu$$u>v,\qquad \gcd(u,v)=1,\qquad u\not\equiv v\pmod3.$$Để cố định$t=uv$, số cặp như vậy bằng$$2^{\omega(t)-1},$$Ở đâu$\omega(t)$là số các thừa số nguyên tố phân biệt. 

Họ này chỉ tồn tại khi$$t\not\equiv 1\pmod3.$$--- 

## Gia đình 2 

hãy để$$a=u-v.$$Sau đó$$d=a(a+3v),$$với$$\gcd(u,v)=1,\qquad u\not\equiv v\pmod3.$$Vì vậy mọi thứ được chấp nhận$d$có sự đa dạng$M[d]$. 

--- 

#3. Đếm điểm lưới 

Ta cần số cặp số nguyên thỏa mãn$$x^2+xy+y^2\le B.$$Gọi số lượng này$N(B)$. 

Một bản sắc cổ điển mang lại$$N(B) = 1+6\sum_{n\le B}\chi(n)\Big\lfloor\frac{B}{n}\Big\rfloor,$$Ở đâu$\chi$là ký tự Dirichlet modulo không tầm thường$3$:$$\chi(n)= \begin{cases} 1,&n\equiv1\pmod3,\\ -1,&n\equiv2\pmod3,\\ 0,&n\equiv0\pmod3. \end{cases}$$Điều này có thể được đánh giá ở$O(\sqrt B)$bằng cách sử dụng nhóm khối chia. 

--- 

#4. Tam giác đều 

Tam giác đều cũng rất đáng chú ý. 

Nếu bán kính là$r$, thì một vectơ đỉnh$A$thỏa mãn$$Q(A)\le 4R^2.$$Mỗi tam giác đều được biểu diễn ba lần (các phép quay bằng$120^\circ$), Vì thế:$$T_{\text{eq}}(R)=\frac{N(4R^2)-1}{3}.$$--- 

#5. Công thức tính cuối cùng 

Đối với mọi thứ được chấp nhận$d$,$$B=\left\lfloor \frac{12R^2}{d^2}\right\rfloor.$$Nếu như$3\mid d$, tất cả các điểm mạng đều được phép; mặt khác chỉ có một mạng con chỉ số-3 đóng góp. 

Kể từ đây$$T(R) = 2\sum_d M[d]\cdot P_d(R) + \frac{N(4R^2)-1}{3},$$Ở đâu$$P_d(R)= \begin{cases} N(B)-1,&3\mid d,\\[4pt] N(\lfloor B/3\rfloor)-1,&3\nmid d. \end{cases}$$yếu tố$2$chiếm cấu hình được phản ánh. 

--- 

#6. Triển khai Python```python
from array import array
from math import gcd, isqrt

def count_hex_points_leq(B, cache):
    """
    Count integer pairs (x,y) with x^2 + x*y + y^2 <= B.
    """

    if B <= 0:
        return 1

    if B in cache:
        return cache[B]

    def chi_prefix(m):
        # count of 1 mod 3 minus count of 2 mod 3
        return (m + 2) // 3 - (m + 1) // 3

    total = 0
    i = 1

    while i <= B:
        q = B // i
        j = B // q

        total += q * (chi_prefix(j) - chi_prefix(i - 1))
        i = j + 1

    ans = 1 + 6 * total
    cache[B] = ans
    return ans

def remarkable_triangles(R_num, R_den=1):

    Dmax = isqrt((12 * R_num * R_num) // (R_den * R_den))

    # multiplicity for each d
    M = array("I", [0]) * (Dmax + 1)

    #
    # ---- Family 1 ----
    #

    Nmax = Dmax // 3

    omega = array("B", [0]) * (Nmax + 1)

    for p in range(2, Nmax + 1):
        if omega[p] == 0:
            for k in range(p, Nmax + 1, p):
                omega[k] += 1

    for t in range(2, Nmax + 1):

        if t % 3 == 1:
            continue

        M[3 * t] += 1 << (omega[t] - 1)

    #
    # ---- Family 2 ----
    #

    vmax = Dmax // 3

    for v in range(1, vmax + 1):

        disc = 9 * v * v + 4 * Dmax
        amax = (isqrt(disc) - 3 * v) // 2

        for a in range(1, amax + 1):

            u = v + a

            if u % 3 == v % 3:
                continue

            if gcd(u, v) != 1:
                continue

            d = a * (a + 3 * v)
            M[d] += 1

    #
    # ---- Main summation ----
    #

    cache = {}

    total_scalene = 0

    C_num = 12 * R_num * R_num
    C_den = R_den * R_den

    for d in range(1, Dmax + 1):

        mult = M[d]

        if mult == 0:
            continue

        B = C_num // (C_den * d * d)

        if B == 0:
            continue

        if d % 3 == 0:
            pts = count_hex_points_leq(B, cache) - 1
        else:
            pts = count_hex_points_leq(B // 3, cache) - 1

        total_scalene += 2 * mult * pts

    #
    # ---- Equilateral triangles ----
    #

    Beq = (4 * R_num * R_num) // (R_den * R_den)

    equi_points = count_hex_points_leq(Beq, cache) - 1
    total_equilateral = equi_points // 3

    return total_scalene + total_equilateral

# verification
print(remarkable_triangles(1, 2))   # 2
print(remarkable_triangles(2))      # 44
print(remarkable_triangles(10))     # 1302

# final answer
print(remarkable_triangles(10**6))
```--- 

#7. Hướng dẫn code 

###`count_hex_points_leq`Tính toán$$N(B)=\#\{(x,y):x^2+xy+y^2\le B\}$$sử dụng công thức ký tự Dirichlet. 

Thủ thuật khối chia chia nhóm các giá trị bằng nhau của$$\left\lfloor \frac{B}{i}\right\rfloor,$$cho đi$O(\sqrt B)$sự phức tạp. 

---

### Xây dựng`M[d]`

`M[d]`lưu trữ bao nhiêu hình tam giác nguyên thủy tương ứng với một tham số nhất định$d$. 

Hai tham số độc lập được liệt kê: 

- Họ 1 thông qua phân tích nhân tử$uv=t$, 
- Gia đình 2 qua$d=a(a+3v)$. 

--- 

### Tổng hợp chính 

Đối với mỗi chấp nhận được$d$:$$B=\left\lfloor\frac{12R^2}{d^2}\right\rfloor$$xác định có thể có bao nhiêu vectơ mạng. 

Một yếu tố của$2$tính riêng các phiên bản được phản ánh. 

--- 

### Đóng góp bình đẳng 

Tính toán riêng bằng cách sử dụng$$\frac{N(4R^2)-1}{3}.$$---
