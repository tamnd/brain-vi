[Vấn đề dự án Euler 582](https://projecteuler.net/problem=582) 

##Giải pháp 

**Trả lời:**`19903`Đối với một hình tam giác có$120^\circ$góc đối diện$c$, Định luật Cosin cho$$c^2=a^2+b^2+ab.$$Chúng ta được yêu cầu đếm các nghiệm số nguyên với$$a\le b\le c,\qquad b-a\le 100.$$Định nghĩa$$d=b-a \quad (1\le d\le 100).$$Sau đó$b=a+d$, Vì thế$$c^2=a^2+(a+d)^2+a(a+d) =3a^2+3ad+d^2.$$Nhân với$4$:$$4c^2=12a^2+12ad+4d^2 =3(2a+d)^2+d^2.$$Cho phép$$x=2a+d.$$Sau đó$$4c^2-3x^2=d^2,$$hoặc tương đương$y^2-3x^2=d^2\quad (y=2c)$Đây là một phương trình kiểu Pell. 

--- 

# 1. Tham số hóa tất cả các giải pháp nguyên thủy 

Tham số hóa cổ điển của bộ ba Eisenstein là$$a=m^2-n^2,\qquad b=2mn+n^2,\qquad c=m^2+mn+n^2,$$với$$m>n>0,\qquad \gcd(m,n)=1,\qquad m\not\equiv n\pmod 3.$$Bây giờ hãy tính sự khác biệt:$$b-a = 2mn+n^2-(m^2-n^2) = 2n^2+2mn-m^2.$$Cho phép$$x=m-n.$$Sau đó$m=x+n$, Và$$b-a = 3n^2-x^2.$$Kể từ đây$$x^2-3n^2=\pm d, \qquad 1\le d\le100.$$Vậy mọi tam giác nguyên thủy đều tương ứng với một nghiệm nguyên thủy của phương trình kiểu Pell$$x^2-3n^2=\pm d.$$--- 

#2. Pell tái phát 

Nếu$$x^2-3n^2=\pm d,$$sau đó nhân với đơn vị cơ bản$$2+\sqrt3$$tạo ra một giải pháp khác:$$(x+n\sqrt3)(2+\sqrt3) = (2x+3n)+(x+2n)\sqrt3.$$Như vậy sự tái diễn là$$x' = 2x+3n, \qquad n' = x+2n.$$Mọi giải pháp nguyên thủy đều được tạo ra từ một tập hợp hữu hạn các hạt giống tối thiểu. 

Đối với mỗi tam giác nguyên thủy, tất cả các bội số không nguyên thủy đều được phép cung cấp$$k(b-a)\le100.$$Vì vậy, mỗi bộ ba nguyên thủy đóng góp$$\min\!\left(\left\lfloor\frac{10^{100}}{c}\right\rfloor, \left\lfloor\frac{100}{b-a}\right\rfloor\right)$$hình tam giác. 

--- 

#3. Triển khai Python```python
from math import gcd

LIMIT = 10**100

# ------------------------------------------------------------
# Generate minimal Pell seeds
# ------------------------------------------------------------

seeds = []

for x in range(1, 500):
    for n in range(1, 500):

        d = abs(x*x - 3*n*n)

        # difference must satisfy 1 <= d <= 100
        if d == 0 or d > 100:
            continue

        # primitive conditions
        if gcd(x, n) != 1:
            continue

        # equivalent to m != n (mod 3)
        if x % 3 == 0:
            continue

        # test whether this is a minimal seed
        xb = 2*x - 3*n
        nb = 2*n - x

        # if backward step is not positive,
        # this is the start of an orbit
        if xb <= 0 or nb <= 0:
            seeds.append((x, n))

# ------------------------------------------------------------
# Generate all primitive triangles with c <= LIMIT
# ------------------------------------------------------------

primitive = set()

for x, n in seeds:

    while True:

        m = x + n

        a = m*m - n*n
        b = 2*m*n + n*n
        c = m*m + m*n + n*n

        if c > LIMIT:
            break

        a, b = sorted((a, b))

        primitive.add((a, b, c))

        # Pell recurrence
        x, n = 2*x + 3*n, x + 2*n

# ------------------------------------------------------------
# Count all multiples
# ------------------------------------------------------------

total = 0

for a, b, c in primitive:

    d = b - a

    total += min(LIMIT // c, 100 // d)

print(total)
```--- 

#4. Hướng dẫn code 

### Tạo hạt giống 

Chúng ta tìm kiếm mọi nghiệm tối thiểu nguyên thủy của$$x^2-3n^2=\pm d,\qquad d\le100.$$các điều kiện```python
gcd(x, n) == 1
x % 3 != 0
```chính xác là điều kiện nguyên thủy của bộ ba Eisenstein. 

Bước Pell lạc hậu```python
xb = 2*x - 3*n
nb = 2*n - x
```phát hiện xem một giải pháp có tối thiểu trong quỹ đạo của nó hay không. 

--- 

### Pell tái phát```python
x, n = 2*x + 3*n, x + 2*n
```nhân với$2+\sqrt3$, tạo ra tất cả các giải pháp lớn hơn. 

--- 

### Khôi phục hình tam giác 

Từ$m=x+n$,$$a=m^2-n^2,\quad b=2mn+n^2,\quad c=m^2+mn+n^2.$$Sau đó chúng tôi đếm tất cả các bội số vô hướng hợp lệ.
