[Vấn đề dự án Euler 337](https://projecteuler.net/problem=337) 

## Giải pháp 

**Trả lời:**`85068035`Chúng ta hãy xác định một quá trình chuyển đổi có hướng$a_i \to a_{i+1}$bất cứ khi nào$$\phi(a_i) < \phi(a_{i+1}) < a_i < a_{i+1}.$$Sau đó, mọi chuỗi hợp lệ chỉ đơn giản là một đường dẫn trong DAG này bắt đầu từ$6$, Và$S(N)$đếm tất cả các đường đi có nút cuối cùng là$\le N$. 

## 1. Phân tích toán học 

hãy để$dp(n)$là số chuỗi hợp lệ kết thúc tại$n$. 

Vì mọi trình tự đều bắt đầu lúc$6$,$$dp(6)=1.$$Vì$n>6$,$$dp(n) = \sum_{\substack{x<n\\ \phi(x)<\phi(n)<x}} dp(x).$$điều kiện$$\phi(x)<\phi(n)<x$$tương đương với: 

-$x > \phi(n)$, 
-$\phi(x) < \phi(n)$. 

Vậy nếu$t=\phi(n)$,$$dp(n) = \sum_{\substack{x<n\\ \phi(x)<t}} dp(x) - \sum_{\substack{x\le t\\ \phi(x)<t}} dp(x).$$Bây giờ hãy quan sát một sự đơn giản hóa quan trọng: 

Đối với mọi$x>1$,$$\phi(x)<x.$$Như vậy, bất cứ khi nào$x\le t$,$$\phi(x)<x\le t \quad\Rightarrow\quad \phi(x)<t$$tự động. 

Do đó tổng thứ hai trở nên đơn giản$$\sum_{x\le t} dp(x).$$Định nghĩa:$$P(k)=\sum_{x\le k}dp(x)$$(tổng tiền tố của$dp$). 

Đồng thời duy trì cây Fenwick được lập chỉ mục bằng cách lưu trữ tổng giá trị$$\sum_{\phi(x)\le v} dp(x).$$Sau đó:$$dp(n) = \text{FenwickQuery}(\phi(n)-1) - P(\phi(n)).$$Mọi thứ đều theo modulo$10^8$. 

### Độ phức tạp 

- Thành phần qua sàng:$O(N\log\log N)$- Mỗi$n$thực hiện một truy vấn và cập nhật Fenwick:$O(\log N)$Tổng cộng:$$O(N\log N)$$điều đó khả thi đối với$N=20{,}000{,}000$.

## 2. Triển khai Python```python
MOD = 100_000_000
N = 20_000_000

def solve():
    # Compute Euler totients
    phi = list(range(N + 1))

    for i in range(2, N + 1):
        if phi[i] == i:  # prime
            for j in range(i, N + 1, i):
                phi[j] -= phi[j] // i

    # Fenwick tree for sums indexed by phi value
    bit = [0] * (N + 2)

    def add(i, v):
        """Add v at index i in Fenwick tree."""
        i += 1
        while i <= N + 1:
            bit[i] += v
            bit[i] %= MOD
            i += i & -i

    def query(i):
        """Prefix sum [0..i]."""
        s = 0
        i += 1
        while i > 0:
            s += bit[i]
            i -= i & -i
        return s % MOD

    # Prefix sums of dp
    prefix = [0] * (N + 1)

    # Base case: sequence [6]
    prefix[6] = 1
    add(phi[6], 1)

    for n in range(7, N + 1):
        t = phi[n]

        # dp[n]
        val = query(t - 1) - prefix[t]
        val %= MOD

        # Add to structures
        add(t, val)
        prefix[n] = (prefix[n - 1] + val) % MOD

    return prefix[N]

print(solve())
```--- 

## 3. Hướng dẫn sử dụng mã 

###Sàng toàn phần 

Chúng tôi khởi tạo```python
phi[i] = i
```và với mỗi số nguyên tố$p$,$$\phi(k) \leftarrow \phi(k)\left(1-\frac1p\right)$$cho bội số$k$của$p$. 

--- 

###Cây Fenwick 

Chúng tôi lưu trữ, cho mỗi giá trị tổng thể$v$,$$\sum_{\phi(x)=v} dp(x).$$Sau đó:```python
query(t - 1)
```trả lại$$\sum_{\phi(x)<t} dp(x).$$--- 

### Sửa tiền tố 

Chúng ta phải loại trừ tất cả$x \le t$, bởi vì quy tắc yêu cầu$$t < x.$$Từ$\phi(x)<x$, mọi thứ như vậy$x$tự động đáp ứng$\phi(x)<t$, vì vậy chúng tôi trừ:```python
prefix[t]
```cái nào bằng$$\sum_{x\le t} dp(x).$$Như vậy:```python
val = query(t - 1) - prefix[t]
```thực hiện chính xác sự lặp lại.

### Séc nhỏ 

cho$N=10$, chương trình tìm 4 dãy:$$(6),\ (6,8),\ (6,8,9),\ (6,10)$$Vì thế$$S(10)=4.$$Vì$N=100$,$$S(100)=482073668,$$và modulo$10^8$,$$82073668,$$phù hợp với tuyên bố. 

Vì$N=10000$,$$S(10000)\bmod 10^8 = 73808307,$$một lần nữa phù hợp với vấn đề.
