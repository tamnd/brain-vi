[Dự án Euler Vấn đề 215](https://projecteuler.net/problem=215) 

##Giải pháp 

**Trả lời:**`806844323190414`Cho phép$W(w,h)$biểu thị số lượng bức tường không có vết nứt có chiều rộng$w$và chiều cao$h$. 

Chúng ta phải tính toán$W(32,10)$. 

Quan sát chính là: 

- Một hàng được xác định hoàn toàn bởi vị trí các vết nứt đứng bên trong nó. 
- Hai hàng tương thích với nhau nếu chúng không có chung vị trí vết nứt. 
- Như vậy bài toán trở thành: 

1. Tạo tất cả các hàng có chiều rộng hợp lệ$32$, 
2. Xây dựng biểu đồ tương thích, 
3. Đếm các đường dẫn có độ dài 10 trong biểu đồ đó. 

--- 

# Bước 1 - Biểu diễn một hàng 

Gạch là$2\times1$Và$3\times1$, đặt nằm ngang. 

Một hàng có chiều rộng$w$là bất kỳ thành phần nào của$w$sử dụng 2s và 3s. 

Ví dụ về chiều rộng$9$: 

-$2+2+2+3$-$3+3+3$-$2+3+2+2$v.v. 

Đối với mỗi hàng, ghi lại vị trí vết nứt giữa các viên gạch. 

Ví dụ:$$2+3+2+2$$có số tiền tích lũy$$2,5,7,9$$Bỏ qua cạnh tường tại$9$, tập crack là$$\{2,5,7\}$$Hai hàng tương thích nếu tập hợp vết nứt của chúng không khớp nhau. 

--- 

# Bước 2 - Số lượng hàng có thể 

hãy để$R(w)$là số hàng có chiều rộng$w$. 

Sau đó$$R(w)=R(w-2)+R(w-3)$$với:$$R(0)=1,\quad R(1)=0,\quad R(2)=1,\quad R(3)=1$$Vì$w=32$, điều này mang lại:$$R(32)=3329$$Vì vậy, chỉ có 3329 loại hàng - đủ nhỏ cho các phương thức biểu đồ. 

--- 

# Bước 3 - Biểu đồ tương thích 

Tạo biểu đồ: 

- mỗi nút = một mẫu hàng, 
- cạnh giữa các nút nếu không có vết nứt thẳng hàng. 

Nếu hàng$i$tương thích với hàng$j$, thì chúng có thể được xếp chồng lên nhau liên tiếp. 

Bây giờ chúng tôi muốn số lượng ngăn xếp có chiều cao là 10. 

Điều này tương đương với việc đếm số bước đi dài$9$trong biểu đồ tương thích. 

--- 

# Bước 4 - Lập trình động 

Hãy:$$dp_k(i)$$là số bức tường có chiều cao không bị nứt$k$kết thúc bằng hàng$i$. 

Khởi tạo:$$dp_1(i)=1$$Sau đó:$$dp_{k+1}(j)=\sum_{i\sim j} dp_k(i)$$Ở đâu$i\sim j$có nghĩa là tương thích. 

Cuối cùng:$$W(32,10)=\sum_i dp_{10}(i)$$--- 

#Triển khai Python```python
from collections import defaultdict

WIDTH = 32
HEIGHT = 10

# ---------------------------------------------------------
# Generate all possible rows
# Each row is represented by a tuple of crack positions
# ---------------------------------------------------------

rows = []

def build(pos, cracks):
    """
    Recursively build rows of total width WIDTH.

    pos     = current filled width
    cracks  = crack positions so far
    """
    if pos == WIDTH:
        rows.append(tuple(cracks))
        return

    # place a 2-brick
    if pos + 2 <= WIDTH:
        new_pos = pos + 2
        build(
            new_pos,
            cracks + ([new_pos] if new_pos < WIDTH else [])
        )

    # place a 3-brick
    if pos + 3 <= WIDTH:
        new_pos = pos + 3
        build(
            new_pos,
            cracks + ([new_pos] if new_pos < WIDTH else [])
        )

build(0, [])

# ---------------------------------------------------------
# Build compatibility graph
# Two rows are compatible if they share no cracks
# ---------------------------------------------------------

n = len(rows)

compat = [[] for _ in range(n)]

crack_sets = [set(r) for r in rows]

for i in range(n):
    for j in range(i + 1, n):
        if crack_sets[i].isdisjoint(crack_sets[j]):
            compat[i].append(j)
            compat[j].append(i)

# ---------------------------------------------------------
# DP over wall height
# dp[i] = number of ways ending with row i
# ---------------------------------------------------------

dp = [1] * n   # height = 1

for _ in range(HEIGHT - 1):
    new_dp = [0] * n

    for i in range(n):
        for j in compat[i]:
            new_dp[j] += dp[i]

    dp = new_dp

answer = sum(dp)

print(answer)
```--- 

# Hướng dẫn sử dụng mã 

## Tạo hàng 

Hàm đệ quy:```python
build(pos, cracks)
```thử thêm một trong hai: 

- một viên gạch có chiều rộng 2, 
- hoặc một viên gạch có chiều rộng 3. 

Bất cứ khi nào chúng tôi hoàn thành chính xác ở chiều rộng 32, chúng tôi sẽ lưu trữ vị trí vết nứt. 

Ví dụ:```python
2 + 3 + 2 + 2
```sản xuất:```python
(2, 5, 7)
```--- 

## Kiểm tra khả năng tương thích 

Chúng tôi chuyển đổi từng bộ dữ liệu crack thành một bộ. 

Hai hàng tương thích nếu:```python
setA.isdisjoint(setB)
```nghĩa là không có vết nứt nào trùng nhau. 

--- 

## Lập trình động 

Ban đầu mỗi hàng có thể là lớp đầu tiên:```python
dp = [1] * n
```Đối với mỗi lớp bổ sung:```python
new_dp[j] += dp[i]
```bất cứ khi nào hàng$i$Và$j$tương thích. 

Sau 10 lớp, tổng hợp tất cả các khả năng sẽ đưa ra câu trả lời.
