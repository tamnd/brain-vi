[Vấn đề dự án Euler 552](https://projecteuler.net/problem=552) 

## Giải pháp 

**Trả lời:**`326227335`Cho phép$$A_n \equiv i \pmod{p_i}\qquad (1\le i\le n),$$Ở đâu$p_i$là$i$-thứ nguyên tố, và$A_n$là giải pháp _tích cực nhỏ nhất_. 

Chúng ta phải tính toán$$S(300000)=\sum_{\substack{p\le 300000\\ p\mid A_n\text{ for some }n}} p.$$--- 

# 1. Phân tích toán học 

##1.1 Xây dựng$A_n$Định nghĩa$$P_n=\prod_{i=1}^n p_i .$$Giả sử chúng ta đã biết$A_n$. 

Sau đó, mọi giải pháp đầu tiên$n$sự đồng đẳng là$$A_n+kP_n.$$Để có được$A_{n+1}$, chúng tôi cần$$A_n+kP_n \equiv n+1 \pmod{p_{n+1}}.$$Từ$P_n$là nguyên tố cùng nhau$p_{n+1}$, có một giải pháp duy nhất:$$k \equiv (n+1-A_n)\,P_n^{-1}\pmod{p_{n+1}}.$$Chọn số không âm nhỏ nhất$k$cho$A_{n+1}$. 

Như vậy:$$A_{n+1}=A_n+t_nP_n,$$Ở đâu$$t_n=((n+1)-A_n)\,P_n^{-1}\pmod{p_{n+1}}.$$--- 

#1.2 Quan sát chính về khả năng chia hết 

Sửa một số nguyên tố$q=p_k$. 

Đối với mọi$n\ge k$,$$A_n \equiv k \pmod{p_k},$$bởi vì hệ thống xác định đã bao gồm modulo đồng dư$p_k$. 

Vì vậy: 

- nếu$p_k\mid A_n$, thì nhất thiết phải$n<k$. 

Vì vậy với mỗi số nguyên tố$p_k$, chúng ta chỉ cần theo dõi dư lượng$$A_1,A_2,\dots,A_{k-1}\pmod{p_k}.$$--- 

#1.3 Cập nhật dư lượng hiệu quả 

Chúng ta không bao giờ cần những số nguyên khổng lồ$A_n$chính họ. 

Đối với mỗi số nguyên tố tương lai$p_k$, duy trì:

-$r_k = A_n \bmod p_k$, 
-$c_k = P_n \bmod p_k$. 

Ban đầu:$$A_1=1,\qquad P_1=2.$$Do đó đối với tất cả$k>1$:$$r_k=1,\qquad c_k=2.$$Bây giờ giả sử chúng ta di chuyển từ$A_n$ĐẾN$A_{n+1}$. 

Chúng tôi đã tính toán rồi:$$A_{n+1}=A_n+t_nP_n.$$Do đó modulo bất kỳ số nguyên tố tương lai nào$p_k$,$$r_k \leftarrow r_k+t_n c_k \pmod{p_k},$$

$$c_k \leftarrow c_k\,p_{n+1}\pmod{p_k}.$$Bất cứ khi nào$r_k=0$, chúng ta đã tìm thấy một số nguyên tố chia một số$A_n$. 

--- 

#1.4 Độ phức tạp 

có$$\pi(300000)=25997$$số nguyên tố lên đến$300000$. 

Thuật toán thực hiện một tập hợp các cập nhật hình tam giác:$$\sum_{i=1}^{m} (m-i)=O(m^2),$$đó là về$3.4\times 10^8$cập nhật mô-đun. 

Sử dụng các thao tác NumPy được vector hóa, thao tác này diễn ra nhanh chóng trong thực tế.

#2. Triển khai Python```python
import numpy as np
from math import isqrt

LIMIT = 300000

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
is_prime = bytearray(b"\x01") * (LIMIT + 1)
is_prime[0:2] = b"\x00\x00"

for p in range(2, isqrt(LIMIT) + 1):
    if is_prime[p]:
        is_prime[p * p : LIMIT + 1 : p] = (
            b"\x00" * (((LIMIT - p * p) // p) + 1)
        )

primes_list = [i for i, v in enumerate(is_prime) if v]
primes = np.array(primes_list, dtype=np.int64)

m = len(primes)

# ------------------------------------------------------------
# r[k] = current A_n mod p_k
# c[k] = current P_n mod p_k
# ------------------------------------------------------------
r = np.ones(m, dtype=np.int64)

c = np.empty(m, dtype=np.int64)
c[0] = 0
c[1:] = 2

# hit[k] becomes True if p_k divides some A_n
hit = np.zeros(m, dtype=bool)

# ------------------------------------------------------------
# Main recurrence
# ------------------------------------------------------------
for n in range(1, m - 1):

    q = int(primes[n])  # p_(n+1)

    # t_n = ((n+1) - A_n) * P_n^{-1} mod p_(n+1)
    t = ((n + 1) - int(r[n])) * pow(int(c[n]), -1, q) % q

    # Update all future residues simultaneously
    sl = slice(n + 1, m)

    r[sl] = (r[sl] + t * c[sl]) % primes[sl]
    c[sl] = (c[sl] * q) % primes[sl]

    # Any zero residue means divisibility
    hit |= (r == 0)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------
answer = int(primes[hit].sum())

print(answer)
```---
