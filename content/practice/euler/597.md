[Project Euler Problem 597](https://projecteuler.net/problem=597)

 ## Giải pháp 

**Trả lời:**`0.5001817828`Hãy để những chiếc thuyền được lập chỉ mục$1,2,\dots,n$từ thấp nhất đến cao nhất theo thứ tự ban đầu. 

Thuyền$i$bắt đầu$40(i-1)$mét ngược dòng từ chiếc thuyền thấp nhất, do đó khoảng cách còn lại của nó để về đích là$$d_i=L-40(i-1).$$Tốc độ là i.i.d.$$v_i=-\log X_i \sim \text{Exp}(1).$$Chúng ta muốn xác suất hoán vị cuối cùng là chẵn. 

--- 

# 1. Hiểu biết sâu sắc về toán học 

Giả sử thuyền$i$đang đuổi theo thuyền$i+1$. 

Họ bắt đầu$40$cách nhau vài mét nên sẽ xảy ra va chạm nếu$$\frac{40}{v_i-v_{i+1}} \le \frac{d_i}{v_i}.$$Sau khi sắp xếp lại,$$d_{i+1}v_i \ge d_i v_{i+1}.$$Định nghĩa$$w_i=\frac{v_i}{d_i}.$$Khi đó điều kiện va chạm trở nên đơn giản$$w_i \ge w_{i+1}.$$Bây giờ hãy quan sát: 

- kể từ khi$v_i\sim \text{Exp}(1)$, 
- chia tỷ lệ mang lại$$w_i \sim \text{Exp}(d_i).$$Vì thế$w_i$là số mũ độc lập với tỷ lệ$d_i$. 

--- 

##Cấu trúc đệ quy 

Giới thiệu “tọa độ mục tiêu”$$t=\frac{L}{40}+1.$$Sau đó$$d_i=40(t-i).$$Bỏ qua yếu tố chung$40$, chúng ta có thể coi$$w_i \sim \text{Exp}(t-i).$$Một sự thật quan trọng về số mũ: 

Nếu các hàm mũ độc lập có tỷ lệ$\lambda_i$, thì xác suất của biến đó$m$tối thiểu là$$\frac{\lambda_m}{\sum \lambda_j}.$$Thuyền có tối thiểu$w_i$: 

- không bao giờ có thể đụng thuyền khác, 
- do đó vẫn là thuyền thấp nhất trong thứ tự cuối cùng. 

Giả sử rằng mức tối thiểu xảy ra ở vị trí$m$. 

Sau đó: 

- thuyền$l,\dots,m-1$hình thành một bài toán con độc lập mà mục tiêu mới của nó trở thành$m$, 
- thuyền$m+1,\dots,r$tạo thành một bài toán con độc lập khác với mục tiêu ban đầu không thay đổi. 

Thuyền di chuyển$m$về phía trước thay đổi tính chẵn lẻ hoán vị bằng cách$$(-1)^{m-l}.$$Vậy nếu$E(l,r,t)$biểu thị dấu hiệu hoán vị dự kiến 

($+1$thậm chí,$-1$cho số lẻ), 

chúng tôi nhận được đệ quy$$E(l,r,t) = \sum_{m=l}^r \Pr(m\text{ minimum}) (-1)^{m-l} E(l,m-1,m) E(m+1,r,t).$$Xác suất tối thiểu là$$\Pr(m\text{ minimum}) = \frac{t-m} {\sum_{j=l}^r (t-j)}.$$Cuối cùng,$$p(n,L)=\frac{1+E(1,n,L/40+1)}{2}.$$--- 

#2. Triển khai Python```python
from fractions import Fraction
from functools import lru_cache

def probability_even(n, L, spacing=40):
    # target coordinate
    t0 = Fraction(L, spacing) + 1

    @lru_cache(None)
    def expected_sign(l, r, t):
        """
        Expected permutation sign (+1 even, -1 odd)
        for boats l..r with target coordinate t.
        """

        # empty or single boat => identity permutation
        if l >= r:
            return Fraction(1, 1)

        count = r - l + 1

        # S = sum_{j=l}^r (t - j)
        S = Fraction(count, 1) * t - (l + r) * count // 2

        total = Fraction(0, 1)

        for m in range(l, r + 1):

            # probability that m is the minimum
            pm = (t - m) / S

            # parity change caused by moving m to front
            sign_flip = -1 if ((m - l) & 1) else 1

            # left and right independent subproblems
            left = expected_sign(l, m - 1, Fraction(m, 1))
            right = expected_sign(m + 1, r, t)

            total += pm * sign_flip * left * right

        return total

    e = expected_sign(1, n, t0)

    # convert expected sign to probability of even permutation
    return (Fraction(1, 1) + e) / 2

def rounded_decimal(frac, digits=10):
    scale = 10 ** digits
    x = frac * scale

    q = x.numerator // x.denominator
    r = x.numerator % x.denominator

    # round half up
    if 2 * r >= x.denominator:
        q += 1

    integer = q // scale
    decimal = q % scale

    return f"{integer}.{decimal:0{digits}d}"

# verification
print(probability_even(3, 160))          # 56/135
print(rounded_decimal(probability_even(4, 400), 10))
print(rounded_decimal(probability_even(13, 1800), 10))
```---

### Tổng tỷ lệ hàm mũ```python
S = sum(t - j)
```Đây là tổng tỷ lệ của tất cả các số mũ trong khoảng. 

--- 

### Chọn mức tối thiểu```python
pm = (t - m) / S
```Số mũ độc lập chọn mức tối thiểu tỷ lệ thuận với tỷ lệ của chúng. 

--- 

### Đóng góp ngang bằng```python
sign_flip = (-1)^(m-l)
```Di chuyển thuyền tối thiểu về phía trước yêu cầu$m-l$trao đổi.
