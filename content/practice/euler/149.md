- ngang, 
- dọc, 
- đường chéo chính, 
- chống đường chéo. 

Thách thức chính là tính hiệu quả: tác động mạnh mẽ lên tất cả các mảng con có thể có theo mọi hướng sẽ quá chậm.

# Phân tích toán học 

## 1. Tạo chuỗi 

Trình tự$s_k$được xác định bởi: 

cho$1 \le k \le 55$,$$s_k = (100003 - 200003k + 300007k^3) \bmod 1000000 - 500000$$Vì$56 \le k \le 4{,}000{,}000$,$$s_k = (s_{k-24} + s_{k-55} + 1000000)\bmod 1000000 - 500000$$Các giá trị này nằm trong khoảng$$[-500000, 499999]$$các$4{,}000{,}000$các thuật ngữ được viết từng hàng thành một$2000 \times 2000$ma trận. 

--- 

#2. Bài toán mảng con cực đại 

Giả sử chúng ta có mảng 1D:$$[a_1,a_2,\dots,a_n]$$Chúng ta cần tổng tối đa của một khối liền kề. 

Đây chính xác là **bài toán mảng con tối đa** cổ điển, được giải quyết một cách tối ưu bằng **thuật toán Kadane** trong thời gian tuyến tính. 

--- 

## Thuật toán Kadane 

Xác định: 

-$best$= số tiền tốt nhất được thấy cho đến nay, 
-$current$= tổng tốt nhất kết thúc ở vị trí hiện tại. 

Với mỗi giá trị$x$:$$current = \max(x, current+x)$$

$$best = \max(best, current)$$Điều này có hiệu quả vì mọi mảng con tối ưu đều kết thúc ở vị trí$i$hoặc: 

- bắt đầu mới vào lúc$i$hoặc 
- mở rộng mảng con tối ưu kết thúc tại$i-1$. 

Độ phức tạp về thời gian:$$O(n)$$--- 

#3. Áp dụng Kadane theo hướng 2D 

Chúng ta phải điều hành Kadane trên mọi: 

- hàng, 
- cột, 
- đường chéo, 
- chống đường chéo. 

Mỗi dòng có độ dài tối đa là 2000. 

Tổng số phần tử được kiểm tra tỷ lệ thuận với tổng số mục trong lưới:$$O(2000^2)$$điều đó hoàn toàn khả thi. 

--- 

# Triển khai Python```python
def generate_sequence():
    n = 4_000_000
    s = [0] * n

    # First 55 terms
    for k in range(1, 56):
        val = (100003 - 200003 * k + 300007 * k**3) % 1_000_000
        s[k - 1] = val - 500000

    # Remaining terms
    for k in range(55, n):
        val = (s[k - 24] + s[k - 55] + 1_000_000) % 1_000_000
        s[k] = val - 500000

    return s

def kadane(arr):
    best = arr[0]
    current = arr[0]

    for x in arr[1:]:
        current = max(x, current + x)
        best = max(best, current)

    return best

def solve():
    SIZE = 2000

    # Generate sequence
    seq = generate_sequence()

    # Build grid
    grid = [seq[i * SIZE:(i + 1) * SIZE] for i in range(SIZE)]

    ans = -10**18

    # -------------------------------------------------
    # Horizontal
    # -------------------------------------------------
    for row in grid:
        ans = max(ans, kadane(row))

    # -------------------------------------------------
    # Vertical
    # -------------------------------------------------
    for c in range(SIZE):
        col = [grid[r][c] for r in range(SIZE)]
        ans = max(ans, kadane(col))

    # -------------------------------------------------
    # Main diagonals
    # -------------------------------------------------
    # Start from top row
    for start_col in range(SIZE):
        diag = []
        r, c = 0, start_col

        while r < SIZE and c < SIZE:
            diag.append(grid[r][c])
            r += 1
            c += 1

        ans = max(ans, kadane(diag))

    # Start from left column (excluding top-left)
    for start_row in range(1, SIZE):
        diag = []
        r, c = start_row, 0

        while r < SIZE and c < SIZE:
            diag.append(grid[r][c])
            r += 1
            c += 1

        ans = max(ans, kadane(diag))

    # -------------------------------------------------
    # Anti-diagonals
    # -------------------------------------------------
    # Start from top row
    for start_col in range(SIZE):
        diag = []
        r, c = 0, start_col

        while r < SIZE and c >= 0:
            diag.append(grid[r][c])
            r += 1
            c -= 1

        ans = max(ans, kadane(diag))

    # Start from right column (excluding top-right)
    for start_row in range(1, SIZE):
        diag = []
        r, c = start_row, SIZE - 1

        while r < SIZE and c >= 0:
            diag.append(grid[r][c])
            r += 1
            c -= 1

        ans = max(ans, kadane(diag))

    return ans

print(solve())
