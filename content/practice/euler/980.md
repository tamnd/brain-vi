# Phân tích toán học 

Tiêu đề là gợi ý chính: đây là nhóm quaternion$Q_8$. 

Bản đồ$$x \mapsto i,\qquad y \mapsto j,\qquad z \mapsto k$$với quan hệ quaternion$$i^2=j^2=k^2=-1,\qquad ij=k,\quad jk=i,\quad ki=j,$$

$$ji=-k,\quad kj=-i,\quad ik=-j.$$--- 

## Bước 1 - Giải thích các nước đi được phép 

### Di chuyển A: chèn$xx,yy,zz$Ví dụ:$$xx \mapsto i^2=-1.$$Vì vậy, điều này nhân giá trị quaternion với$-1$. 

--- 

### Di chuyển B: thay thế$$x\to yz,\qquad y\to zx,\qquad z\to xy$$bởi vì$$jk=i,\qquad ki=j,\qquad ij=k.$$Vì vậy giá trị quaternion không thay đổi. 

--- 

### Di chuyển C: hoán đổi các chữ cái riêng biệt liền kề 

Ví dụ:$$xy \leftrightarrow yx.$$Nhưng$$ij=k,\qquad ji=-k.$$Hoán đổi các chữ cái lân cận khác nhau sẽ nhân giá trị lên$-1$. 

--- 

## Bước 2 - Bất biến chẵn lẻ 

Mỗi thao tác lật dấu của giá trị quaternion chính xác một lần: 

- chèn$aa$: nhân với$-1$, 
- thay thế: tính chẵn lẻ của bước thay đổi trong khi giá trị không thay đổi, 
- hoán đổi: nhân với$-1$. 

Bắt đầu từ chuỗi trống có giá trị$1$, sau: 

- số bước chẵn → giá trị$1$, 
- số bước lẻ → giá trị$-1$. 

Vì vậy: 

> Một chuỗi là trung hòa nếu tích bậc bốn của nó bằng$1$. 

Điều đó hoàn toàn đặc trưng cho tính trung lập. 

--- 

# Bước 3 - Tính toán$F(N)$Mỗi khối$c(i)$có chiều dài$50$. 

Xác định giá trị quaternion của nó:$$q_i \in Q_8.$$Sau đó$$c(i)c(j)\text{ is neutral} \iff q_i q_j = 1 \iff q_j = q_i^{-1}.$$Vì vậy, chúng ta chỉ cần đếm có bao nhiêu khối đánh giá từng phần tử quaternion. 

--- 

# Bước 4 - Bảng nhân Quaternion 

Tám yếu tố là$$1,-1,i,-i,j,-j,k,-k.$$nghịch đảo của chúng là:$$1^{-1}=1,\quad (-1)^{-1}=-1,$$

$$i^{-1}=-i,\quad (-i)^{-1}=i,$$

$$j^{-1}=-j,\quad (-j)^{-1}=j,$$

$$k^{-1}=-k,\quad (-k)^{-1}=k.$$Nếu như$cnt[g]$là số khối có giá trị$g$, sau đó$$F(N)=\sum_{g\in Q_8} cnt[g]\cdot cnt[g^{-1}].$$--- 

#Triển khai Python```python
MOD = 888_888_883
A = 88_888_888
MULT = 8888

# Quaternion elements:
# 0:  1
# 1: -1
# 2:  i
# 3: -i
# 4:  j
# 5: -j
# 6:  k
# 7: -k

# Multiplication table
mul = [[0] * 8 for _ in range(8)]

names = ["1", "-1", "i", "-i", "j", "-j", "k", "-k"]
idx = {v: i for i, v in enumerate(names)}

base = {
    ("1", "1"): "1",
    ("1", "i"): "i",
    ("1", "j"): "j",
    ("1", "k"): "k",

    ("i", "1"): "i",
    ("j", "1"): "j",
    ("k", "1"): "k",

    ("i", "i"): "-1",
    ("j", "j"): "-1",
    ("k", "k"): "-1",

    ("i", "j"): "k",
    ("j", "k"): "i",
    ("k", "i"): "j",

    ("j", "i"): "-k",
    ("k", "j"): "-i",
    ("i", "k"): "-j",
}

def qmul(a, b):
    sa = -1 if a.startswith("-") else 1
    sb = -1 if b.startswith("-") else 1

    aa = a[1:] if a.startswith("-") else a
    bb = b[1:] if b.startswith("-") else b

    r = base[(aa, bb)]

    sr = -1 if r.startswith("-") else 1
    rr = r[1:] if r.startswith("-") else r

    sign = sa * sb * sr

    if rr == "1":
        return "1" if sign == 1 else "-1"

    return rr if sign == 1 else "-" + rr

# Build numeric multiplication table
for i, a in enumerate(names):
    for j, b in enumerate(names):
        mul[i][j] = idx[qmul(a, b)]

# map:
# x -> i
# y -> j
# z -> k
letter_map = [2, 4, 6]

N = 10**6

counts = [0] * 8
a = A

for _ in range(N):

    q = 0  # quaternion value starts at 1

    for _ in range(50):
        b = a % 3
        q = mul[q][letter_map[b]]
        a = (MULT * a) % MOD

    counts[q] += 1

inverse = [0, 1, 3, 2, 5, 4, 7, 6]

answer = 0
for g in range(8):
    answer += counts[g] * counts[inverse[g]]

print(answer)
```---

## Thế hệ RNG 

Trình tự là:$$a_n = 8888 a_{n-1}\pmod{888888883}.$$Đối với mỗi giá trị được tạo:```python
b = a % 3
```chúng tôi lập bản đồ: 

- 0 →$i$, 
- 1 →$j$, 
- 2 →$k$. 

Mỗi khối sử dụng chính xác 50 ký hiệu. 

--- 

## Đếm khối 

Đối với mỗi khối, chúng tôi tính toán tích bậc bốn của nó`q`. 

Sau đó:```python
counts[q] += 1
```--- 

## Đếm lần cuối 

Một cặp đóng góp nếu:$$q_i q_j = 1.$$Như vậy:```python
counts[g] * counts[inverse[g]]
```cho mọi phần tử nhóm$g$.
