[Vấn đề dự án Euler 458](https://projecteuler.net/problem=458) 

## Giải pháp 

**Trả lời:**`423341841`Đặt bảng chữ cái là 7 chữ cái riêng biệt của **project**:$$A=\{c,e,j,o,p,r,t\}$$Chuỗi con bị cấm là **bất kỳ hoán vị nào của “dự án”**, tức là bất kỳ khối có độ dài 7 nào chứa **tất cả 7 chữ cái chính xác một lần**. 

## 1. Phân tích toán học 

### Quan sát chính 

Vì bảng chữ cái có chính xác 7 chữ cái nên chuỗi con dài 7 bị cấm **nếu tất cả 7 chữ cái đều khác biệt**. 

Vì vậy, vấn đề trở thành: 

> Đếm chuỗi có độ dài$n$trên một bảng chữ cái 7 chữ cái sao cho **không có khối liên tiếp nào có độ dài 7 có tất cả các chữ cái riêng biệt**. 

--- 

### Nén trạng thái 

Thông tin duy nhất cần thiết để xác định xem việc thêm một chữ cái có tạo ra khối bị cấm hay không là: 

> độ dài của hậu tố dài nhất của **các chữ cái liên tiếp riêng biệt**. 

Xác định trạng thái$k$($0\le k\le 6$) BẰNG:

-$k=0$: chuỗi trống, 
-$k\ge1$: chuỗi hiện tại kết thúc bằng hậu tố là$k$chữ cái riêng biệt. 

Chúng tôi không bao giờ cho phép trạng thái 7 vì điều đó có nghĩa là hoán vị bị cấm xuất hiện. 

#### Quy tắc chuyển tiếp 

Giả sử chúng ta đang ở trạng thái$k\ge1$, với hậu tố$$x_1x_2\cdots x_k$$(tất cả đều khác biệt). 

Nếu chúng ta nối thêm: 

- một **chữ cái mới không có hậu tố**: 

độ dài hậu tố trở thành$k+1$, với$7-k$sự lựa chọn. 
- một trong những chữ cái hậu tố hiện có$x_i$: 

hậu tố khác biệt mới trở thành$$x_{i+1}\cdots x_kx_i$$chiều dài của nó là$$k-i+1.$$Như vậy từ trạng thái$k$: 

- chính xác một lần chuyển đổi sang mỗi trạng thái$1,2,\dots,k$,
- Và$7-k$chuyển sang trạng thái$k+1$(nếu như$k<6$). 

Tình trạng$6$không thể chuyển sang$7$, vì điều đó sẽ tạo ra một chuỗi con bị cấm. 

Điều này mang lại một$7\times7$ma trận chuyển tiếp, vì vậy$$T(n)$$có thể được tính bằng cách sử dụng phép lũy thừa ma trận nhanh trong$$O(7^3\log n).$$Kiểm tra nhanh:$$T(7)=7^7-7!=818503,$$phù hợp với phát biểu vấn đề.

## 2. Triển khai Python```python
MOD = 10**9
SIZE = 7

# Build transition matrix
M = [[0] * SIZE for _ in range(SIZE)]

for k in range(SIZE):
    if k == 0:
        # First character: 7 choices -> state 1
        M[1][0] = 7
    else:
        # Repeating one of the suffix letters
        for new_len in range(1, k + 1):
            M[new_len][k] += 1

        # Add a new distinct letter
        if k < 6:
            M[k + 1][k] += (7 - k)

def mat_mul(A, B):
    """Matrix multiplication mod MOD."""
    n = len(A)
    C = [[0] * n for _ in range(n)]

    for i in range(n):
        for k in range(n):
            if A[i][k]:
                a = A[i][k]
                for j in range(n):
                    if B[k][j]:
                        C[i][j] = (C[i][j] + a * B[k][j]) % MOD

    return C

def mat_pow(M, exp):
    """Binary exponentiation of matrix."""
    n = len(M)
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]

    while exp:
        if exp & 1:
            R = mat_mul(R, M)
        M = mat_mul(M, M)
        exp >>= 1

    return R

def T(n):
    # Initial vector: empty string in state 0
    v = [0] * SIZE
    v[0] = 1

    P = mat_pow(M, n)

    result = [0] * SIZE
    for i in range(SIZE):
        total = 0
        for j in range(SIZE):
            total += P[i][j] * v[j]
        result[i] = total % MOD

    return sum(result) % MOD

# Verification
print(T(7))          # 818503
print(T(10**12))     # final answer
```--- 

## 3. Hướng dẫn sử dụng mã 

1. **Xây dựng ma trận chuyển tiếp** 

Mã hóa độ dài hậu tố riêng biệt thay đổi như thế nào sau khi thêm một ký tự. 
2. **Nhân ma trận (`mat_mul`)** 

Nhân ma trận theo modulo$10^9$, vì chỉ cần 9 chữ số cuối. 
3. **Lũy thừa nhanh (`mat_pow`)** 

Tính toán$$M^n$$theo thời gian logarit. 

1. **Vectơ ban đầu** 

Bắt đầu ở trạng thái 0 (chuỗi trống). 
2. **Số tiền cuối cùng** 

Tổng hợp tất cả các trạng thái kết thúc hợp lệ để có được$T(n)$.
