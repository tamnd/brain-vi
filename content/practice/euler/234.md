[Vấn đề dự án Euler 234](https://projecteuler.net/problem=234) 

## Giải pháp 

**Trả lời:**`1259187438574927161`Cho phép$p<q$là số nguyên tố liên tiếp. 

Với mọi số nguyên$n$với$$p^2 < n < q^2,$$chúng tôi có$$\operatorname{lps}(n)=p,\qquad \operatorname{ups}(n)=q,$$bởi vì không có số nguyên tố nào nằm giữa$p$Và$q$. 

Vì vậy bên trong khoảng$(p^2,q^2)$, một số chia hết khi: 

- nó chia hết cho$p$xor chia hết cho$q$, 
- tức là chia hết cho chính xác một trong số chúng. 

Điều đó ngay lập tức biến bài toán thành tổng trên các cặp số nguyên tố liên tiếp. 

--- 

# 1. Phân tích toán học 

Đối với các số nguyên tố liên tiếp$p<q$, định nghĩa$$I_{p,q}=\{n : p^2<n<q^2\}.$$Bên trong khoảng này: 

- các số chia hết cho$p$:$$p\cdot k,\qquad k=p+1,\dots,\left\lfloor\frac{q^2-1}{p}\right\rfloor$$- các số chia hết cho$q$:$$q\cdot k,\qquad k=\left\lfloor\frac{p^2}{q}\right\rfloor+1,\dots,q-1$$Nhưng số chia hết cho cả hai$p$Và$q$là bội số của$pq$, và đây **không** là nửa chia hết, vì cả hai căn bậc hai nguyên tố đều chia hết chúng. 

Do đó, đối với mỗi cặp số nguyên tố, chúng tôi sử dụng phép bao gồm-loại trừ:$$S(p,q) = \sum_{\substack{p^2<n<q^2\\ p\mid n}} n + \sum_{\substack{p^2<n<q^2\\ q\mid n}} n - 2\sum_{\substack{p^2<n<q^2\\ pq\mid n}} n.$$yếu tố$2$loại bỏ bội số được tính gấp đôi của$pq$toàn bộ. 

--- 

## Tính tổng bội số hiệu quả 

Tổng bội số của$m$trong một khoảng thời gian$[A,B]$là:$$m\sum_{k=\lceil A/m\rceil}^{\lfloor B/m\rfloor} k.$$Sử dụng công thức dãy số học,$$\sum_{k=L}^{R} k = \frac{(L+R)(R-L+1)}{2}.$$Vì thế:$$\operatorname{sumMultiples}(m,A,B) = m\cdot \frac{(L+R)(R-L+1)}{2},$$Ở đâu$$L=\left\lceil\frac{A}{m}\right\rceil,\qquad R=\left\lfloor\frac{B}{m}\right\rfloor.$$--- 

#2. Triển khai Python```python
from math import isqrt

LIMIT = 999966663333

# ------------------------------------------------------------
# Generate all primes up to sqrt(LIMIT)
# ------------------------------------------------------------

max_prime = isqrt(LIMIT) + 1000

sieve = bytearray(b'\x01') * (max_prime + 1)
sieve[0] = sieve[1] = 0

for i in range(2, isqrt(max_prime) + 1):
    if sieve[i]:
        sieve[i * i : max_prime + 1 : i] = (
            b'\x00' * (((max_prime - i * i) // i) + 1)
        )

primes = [i for i, v in enumerate(sieve) if v]

# ------------------------------------------------------------
# Sum of multiples of m inside [A, B]
# ------------------------------------------------------------

def sum_multiples(m, A, B):
    L = (A + m - 1) // m
    R = B // m

    if L > R:
        return 0

    count = R - L + 1
    return m * (L + R) * count // 2

# ------------------------------------------------------------
# Main computation
# ------------------------------------------------------------

total = 0

for p, q in zip(primes, primes[1:]):

    # numbers with lps = p and ups = q
    A = p * p + 1
    B = min(q * q - 1, LIMIT)

    if A > B:
        break

    total += (
        sum_multiples(p, A, B)
        + sum_multiples(q, A, B)
        - 2 * sum_multiples(p * q, A, B)
    )

print(total)
```---
